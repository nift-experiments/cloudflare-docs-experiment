<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Reusable components</strong> &gt; <strong>Lists</strong>.</li>
<li>Select <strong>Upload CSV</strong>.</li>
<li>Next, specify a <strong>List name</strong>, enter an optional description, and choose a <strong>List type</strong>.</li>
<li>Drag and drop a file into the <strong>CSV file</strong> window, or select a file.</li>
<li>Select <strong>Create</strong>.</li>
</ol>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Terraform (v5)">

<ol>
<li>Add the following permission to your <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/api_token"><code>cloudflare_api_token</code></a>:</li>
</ol>
<ul>
<li><code>Zero Trust Write</code></li>
</ul>
<ol start="2">
<li>Decode the contents of the CSV file and store it as a local value:</li>
</ol>
<pre><code class="language-tf">locals {
	ip_list = csvdecode(file(&quot;${path.module}/list-test.csv&quot;))
}
</code></pre>
<ol start="3">
<li>Create a list using the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_list"><code>cloudflare_zero_trust_list</code></a> resource:</li>
</ol>
<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_list&quot; &quot;ips_from_csv&quot; {
	account_id  = var.cloudflare_account_id
	name        = &quot;IPs imported from CSV&quot;
	description = &quot;Managed by Terraform&quot;
	type        = &quot;IP&quot;
	items 			= local.ip_list
}
</code></pre>

</section>
