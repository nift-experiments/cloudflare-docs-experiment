

1. Add the following permission to your [`cloudflare_api_token`](https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/api_token):
- `Zero Trust Write`

2. Configure default profile settings using the [`cloudflare_zero_trust_device_default_profile`](https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_device_default_profile) resource:

<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_device_default_profile&quot; &quot;default_profile&quot; {
	account_id            = var.cloudflare_account_id
	allow_mode_switch     = false
	allow_updates         = false
	allowed_to_leave      = false
	auto_connect          = 600
	captive_portal        = 180
	disable_auto_fallback = true
	exclude_office_ips    = false
	service_mode_v2       = {mode = &quot;warp&quot;}
	support_url           = &quot;https://support.example.com&quot;
	switch_locked         = true
	tunnel_protocol       = &quot;wireguard&quot;
}
</code></pre>


3. Configure [global settings](/cloudflare-one/team-and-resources/devices/cloudflare-one-client/configure/settings/#global-settings) using the [`cloudflare_zero_trust_device_settings`](https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_device_settings) resource:

<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_device_settings&quot; &quot;global_warp_settings&quot; {
	account_id            = var.cloudflare_account_id
	disable_for_time      = 3600
	root_certificate_installation_enabled = true
	use_zt_virtual_ip     = false
}
</code></pre>
