<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Traffic policies</strong> &gt; <strong>Firewall policies</strong>.</li>
<li>In the <strong>Network</strong> tab, select <strong>Add a network policy</strong>.</li>
<li>Name the policy.</li>
<li>Under <strong>Traffic</strong>, build a logical expression that defines the traffic you want to allow or block.</li>
<li>Choose an <strong>Action</strong> to take when traffic matches the logical expression. <li>(Optional) Configure your API environment variables to include your <a href="/fundamentals/account/find-account-and-zone-ids/">account ID</a> and API token.</li>
<li>Send a <code>POST</code> request to the <a href="/api/resources/zero_trust/subresources/gateway/subresources/rules/methods/create/">Create a Zero Trust Gateway rule</a> endpoint. For example, you can use a list of <a href="/cloudflare-one/reusable-components/posture-checks/client-checks/corp-device/">device serial numbers</a> to ensure users can only access an application if they connect with the Cloudflare One Client from a company device:</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/rules \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;Enforce device posture&quot;,
&quot;description&quot;: &quot;Ensure only devices in Zero Trust organization can connect to application&quot;,
&quot;precedence&quot;: 0,
&quot;enabled&quot;: true,
&quot;action&quot;: &quot;block&quot;,
&quot;filters&quot;: [
  &quot;l4&quot;
],
&quot;traffic&quot;: &quot;any(net.sni.domains[*] == \&quot;internalapp.com\&quot;)&quot;,
&quot;identity&quot;: &quot;&quot;,
&quot;device_posture&quot;: &quot;not(any(device_posture.checks.passed[*] in {\&quot;LIST_UUID\&quot;}))&quot;
}&#x27;</code></pre>
<pre><code class="language-sh">{
	 &quot;success&quot;: true,
	 &quot;errors&quot;: [],
	 &quot;messages&quot;: []
}
</code></pre>
<p>The API will respond with a summary of the policy and the result of your request.</p>
