<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Traffic policies</strong> &gt; <strong>Traffic settings</strong>.</li>
<li>In <strong>Proxy and inspection</strong>, turn on <strong>Inspect HTTPS requests with TLS decryption</strong>.</li>
</ol>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Terraform (v5)">

<ol>
<li>Add the following permission to your <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/api_token"><code>cloudflare_api_token</code></a>:</li>
</ol>
<ul>
<li><code>Zero Trust Write</code></li>
</ul>
<ol start="2">
<li>Configure the <code>tls_decrypt</code> argument in <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_gateway_settings"><code>cloudflare_zero_trust_gateway_settings</code></a>:</li>
</ol>
<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_gateway_settings&quot; &quot;team_name&quot; {
	account_id = var.cloudflare_account_id
	settings = {
		tls_decrypt = {
			enabled = true
		}
	}
}
</code></pre>

</section>
