<ol>
<li>
<p>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Traffic policies</strong> &gt; <strong>Firewall policies</strong>.</p>
</li>
<li>
<p>In the <strong>HTTP</strong> tab, select <strong>Add a policy</strong>.</p>
</li>
<li>
<p>Name the policy.</p>
</li>
<li>
<p>In <strong>Traffic</strong>, add the following expression:</p>
</li>
</ol>
<table>
<thead>
<tr>
<th>Selector</th>
<th>Operator</th>
<th>Value</th>
<th>Action</th>
</tr>
</thead>
<tbody>
<tr>
<td>Host</td>
<td>in list</td>
<td><em>Shadow IT</em></td>
<td>Isolate</td>
</tr>
</tbody>
</table>
<ol start="5">
<li>In <strong>Configure policy settings</strong>, turn on the following options:</li>
</ol>
<ul>
<li><em>Disable copy / paste</em></li>
<li><em>Disable file downloads</em></li>
<li><em>Disable file uploads</em></li>
</ul>
<ol start="6">
<li>Select <strong>Create policy</strong>.</li>
</ol>
