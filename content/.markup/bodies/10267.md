

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Traffic policies</strong> &gt; <strong>Firewall policies</strong>.</li>
<li>In the <strong>DNS</strong> tab, select <strong>Add a policy</strong>.</li>
<li>Name the policy.</li>
<li>Under <strong>Traffic</strong>, build a logical expression that defines the traffic you want to allow or block.</li>
<li>Choose an <strong>Action</strong> to take when traffic matches the logical expression. For example, we recommend adding a policy to block all <a href="/cloudflare-one/traffic-policies/domain-categories/#security-categories">security categories</a>:</li>
</ol>
<table>
<thead>
<tr>
<th>Selector</th>
<th>Operator</th>
<th>Value</th>
<th>Action</th>
</tr>
</thead>
<tbody>
<tr>
<td>Security Categories</td>
<td>in</td>
<td><em>All security risks</em></td>
<td>Block</td>
</tr>
</tbody>
</table>
<ol start="6">
<li>Select <strong>Create policy</strong>.</li>
</ol>
<p>For more information, refer to <a href="/cloudflare-one/traffic-policies/dns-policies/">DNS policies</a>.</p>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To create a new DNS policy using cURL:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/rules \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;All-DNS-SecurityCategories-Blocklist&quot;,
&quot;description&quot;: &quot;Block known security risks based on Cloudflare&#x27;s threat intelligence&quot;,
&quot;precedence&quot;: 0,
&quot;enabled&quot;: true,
&quot;action&quot;: &quot;block&quot;,
&quot;filters&quot;: [
  &quot;dns&quot;
],
&quot;traffic&quot;: &quot;any(dns.security_category[*] in {68 178 80 83 176 175 117 131 134 151 153})&quot;,
&quot;rule_settings&quot;: {
  &quot;block_page_enabled&quot;: true,
  &quot;block_reason&quot;: &quot;This domain was blocked due to being classified as a security risk to your organization&quot;
}
}&#x27;</code></pre>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Terraform">

<p>To create a new DNS policy using <strong>Terraform</strong>:</p>
<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_gateway_policy&quot; &quot;security_risks_dns_policy&quot; {
  account_id  = var.cloudflare_account_id
  name        = &quot;All-DNS-SecurityCategories-Blocklist&quot;
  description = &quot;Block known security risks based on Cloudflare's threat intelligence&quot;
  precedence  = 0
  enabled     = true
  action      = &quot;block&quot;
  filters     = [&quot;dns&quot;]
  traffic     = &quot;any(dns.security_category[*] in {68 178 80 83 176 175 117 131 134 151 153})&quot;
  rule_settings {
      block_page_enabled = true
      block_page_reason = &quot;This domain was blocked due to being classified as a security risk to your organization&quot;
    }
}
</code></pre>

</section>
