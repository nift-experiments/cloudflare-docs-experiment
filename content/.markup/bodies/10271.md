<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/rules \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;All-DNS-CorporateDomain-AllowList&quot;,
&quot;description&quot;: &quot;Allow access to the corporate domains defined under the Corporate Domains list&quot;,
&quot;precedence&quot;: 1,
&quot;enabled&quot;: true,
&quot;action&quot;: &quot;allow&quot;,
&quot;filters&quot;: [
  &quot;dns&quot;
],
&quot;traffic&quot;: &quot;any(dns.domains[*] in $&lt;CORPORATE_DOMAINS_LIST_UUID&gt;)&quot;
}&#x27;</code></pre>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Terraform">

<p>To create a new DNS policy using <strong>Terraform</strong> to allow access to all approved corporate domains included in a list called <strong>Corporate Domains</strong>.</p>
<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_gateway_policy&quot; &quot;allow_corporate_domain_access&quot; {
  account_id  = var.cloudflare_account_id
  name        = &quot;All-DNS-CorporateDomain-AllowList&quot;
  description = &quot;Allow access to the corporate domains defined under the Corporate Domains list&quot;
  precedence  = 1
  enabled     = false
  action      = &quot;allow&quot;
  filters     = [&quot;dns&quot;]
  traffic     = &quot;any(dns.domains[*] in $&lt;Corporate Domains List UUID&gt;)&quot;
}
</code></pre>

</section>
