<h3 id="body-10299-wrangler-configuration">Wrangler Configuration</h3>
<p>The Wrangler configuration file is used to configure your Worker and Workflows. This includes defining bindings to resources like KV namespaces and setting up schedules for workflows.</p>
<p>The episode repository uses the older pattern of a top-level <code>[triggers]</code> section plus a <code>scheduled</code> handler in the main Worker to create a <code>LEADERBOARD_WORKFLOW</code> instance on a timer.</p>
<p><a href="https://github.com/craigsdennis/punderful-workflows/blob/main/wrangler.toml#L68">See here</a></p>
<p>In current Workflows projects, you can usually schedule the Workflow directly on its binding instead:</p>
<div class="nb-wrangler-config">
<pre><code class="language-toml">[[workflows]]
name = &quot;leaderboard-workflow&quot;
binding = &quot;LEADERBOARD_WORKFLOW&quot;
class_name = &quot;LeaderboardWorkflow&quot;
schedules = [&quot;*/30 * * * *&quot;]
</code></pre>
</div>
<p>Use a separate Cron Trigger and <code>scheduled</code> handler only when you need custom logic before deciding whether to create a Workflow instance. Use the latest Wrangler release when configuring Workflow schedules.</p>

<h3 id="body-10299-workflow-instances">Workflow Instances</h3>
<p>You can trigger workflows manually and inspect their execution status and output using the <code>wrangler</code> command-line tool.</p>
<p>To trigger the <code>PuntificatorWorkflow</code> manually:</p>
<pre><code class="language-bash">npx wrangler workflows trigger puntificator
</code></pre>
<p>This command will queue an instance of the workflow. You will receive a success message and the instance ID.</p>
<p>To describe the latest instance of a workflow:</p>
<pre><code class="language-bash">npx wrangler workflows instances describe puntificator latest
</code></pre>
<p>This command will show details about the most recent run of the specified workflow, including its start time, end time, duration, state, and the state of each individual step within the workflow. You can observe steps like <code>create-new-pun-based-on-trends</code>, <code>judge-pun</code>, <code>save-pun</code>, <code>publish</code>, and <code>wait-for-publish</code> (which shows a 'Sleeping' state).</p>
