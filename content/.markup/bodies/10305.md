<p>The Punderful application processes user-submitted puns by performing content moderation, creating embeddings, categorizing, and adding them to a vector store. This process is defined as a Workflow. To process a batch of existing puns (from an open-source dataset called OPun), a batch endpoint is created that iterates through the puns and triggers the defined Workflow for each one.</p>

<h3 id="body-10305-monitoring-workflow-instances-via-cli">Monitoring Workflow Instances via CLI</h3>
<p>The Cloudflare Wrangler CLI provides commands to monitor and manage Workflows and their instances.</p>
<p>To list the available workflows associated with your account:</p>
<pre><code class="language-bash">npx wrangler workflows list
</code></pre>
<p>To list the instances of a specific workflow (for example, the <code>publish</code> workflow):</p>
<pre><code class="language-bash">npx wrangler workflows instances list publish
</code></pre>
<p>This command will show a list of workflow instances, their status (Queued, Running, Completed, Errored), and timestamps.</p>
<p>To view the details of a specific workflow instance, including its steps and their status, duration, and output:</p>
<pre><code class="language-bash">npx wrangler workflows instances describe publish &lt;instance-id&gt;
</code></pre>
<p>Replace <code>&lt;instance-id&gt;</code> with the actual ID of a running or completed instance from the <code>list</code> command output.</p>
