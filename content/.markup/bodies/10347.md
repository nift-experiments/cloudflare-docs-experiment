<p>To create a virtual network:</p>
<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Settings</strong> &gt; <strong>WARP Client</strong> and find the <strong>Virtual networks</strong> setting.</li>
<li>Select <strong>Add new</strong> or <strong>Manage</strong> &gt; <strong>Create virtual network</strong> to create virtual networks.</li>
<li>Define your virtual network name and select <strong>Save</strong>.</li>
</ol>
<p>To assign the virtual network to the tunnel:</p>
<ol>
<li>Go to <strong>Networks</strong> &gt; <strong>Tunnels</strong>.</li>
<li>Select the tunnel you created in the previous steps and select <strong>Configure</strong>.</li>
<li>Under <strong>Private Network</strong>, select <strong>Add a private network</strong>.</li>
<li>Specify an IP range under <strong>CIDR</strong> and select the virtual network under <strong>Additional settings</strong>.</li>
<li>Select <strong>Save private network</strong>.</li>
</ol>

<p>To create a virtual network:</p>
<pre><code class="language-sh">cloudflared tunnel vnet add &lt;VNET_NAME&gt;
</code></pre>
<p>To assign the virtual network to the tunnel:</p>
<pre><code class="language-sh">cloudflared tunnel route ip add --vnet &lt;VNET_NAME&gt; &lt;IP_RANGE&gt; &lt;TUNNEL_NAME&gt;
</code></pre>
