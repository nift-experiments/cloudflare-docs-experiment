<p>To edit a pool in the dashboard:</p>
<ol>
<li>Go to <strong>Load Balancing</strong>.</li>
<li>Select the <strong>Pools</strong> tab.</li>
<li>On a specific pool, select <strong>Edit</strong>.</li>
<li>Update settings as needed.</li>
<li>Select <strong>Save</strong>.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>When you edit a pool with the API, your request type depends on how much you want to edit.</p>
<p>To update specific settings without having to resubmit the entire configuration, use a <a href="/api/resources/load_balancers/subresources/pools/methods/edit/">PATCH</a> request. For broader changes, use a <a href="/api/resources/load_balancers/subresources/pools/methods/update/">PUT</a> request.</p>
