<p>To edit a load balancer in the dashboard:</p>
<ol>
<li>Go to <strong>Load Balancing</strong>.</li>
<li>On a specific load balancer, select <strong>Edit</strong>.</li>
<li>While going through the <a href="#create-a-load-balancer">creation workflow</a>, update settings as needed.</li>
<li>On the <strong>Review</strong> step, select <strong>Save</strong>.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>When you edit a load balancer with the API, your request type depends on how much you want to edit.</p>
<p>To update specific settings without having to resubmit the entire configuration, use a <a href="/api/resources/load_balancers/methods/edit/">PATCH</a> request. For broader changes, use a <a href="/api/resources/load_balancers/methods/update/">PUT</a> request.</p>
