<p>To create a Public or a Private load balancer in the dashboard:</p>
<h3 id="body-10422-create-a-public-load-balancer">Create a Public load balancer</h3>
<ol>
<li>
<p>Go to <strong>Load Balancing</strong> and select <strong>Create load balancer</strong>.</p>
</li>
<li>
<p>On the <strong>Load Balancer Setup</strong>, select <strong>Public load balancer</strong></p>
</li>
<li>
<p>Choose the website to which you want to add this load balancer.</p>
</li>
<li>
<p>On the <strong>Hostname</strong> page:</p>
</li>
</ol>
<ul>
<li>Enter a <strong>Hostname</strong>, which is the DNS name at which the load balancer is available. For more details on record priority, refer to <a href="/load-balancing/load-balancers/dns-records/">DNS records for load balancing</a>.</li>
<li>From the <strong>Data Localization</strong> dropdown, select the <a href="/data-localization/how-to/load-balancing/#regional-services">region</a> you would like to use on your domain.</li>
<li>Toggle the orange cloud icon to update the <a href="/load-balancing/understand-basics/proxy-modes/">proxy mode</a>, which affects how traffic is routed and which IP addresses are advertised.</li>
<li>Add a description for your load balancer.</li>
<li>If you want <a href="/load-balancing/understand-basics/session-affinity/">session-based load balancing</a>, toggle the <strong>Session Affinity</strong> switch.</li>
<li>If you want <a href="/load-balancing/understand-basics/adaptive-routing/">Adaptive Routing</a>, toggle the <strong>Adaptive Routing</strong> switch.</li>
</ul>
<ol start="5">
<li>
<p>Select <strong>Next</strong>.</p>
</li>
<li>
<p>On the <strong>Add a Pool</strong> page:</p>
</li>
</ol>
<ul>
<li>Select one or more existing pools or <a href="/load-balancing/pools/create-pool/#create-a-pool">create a new pool</a>.</li>
<li>If you are going to set <a href="/load-balancing/understand-basics/traffic-steering/steering-policies/standard-options/">traffic steering</a> to <strong>Off</strong>, re-order the pools in your load balancer to adjust the fallback order.</li>
<li>If needed, update the <a href="/load-balancing/understand-basics/health-details/#fallback-pools"><strong>Fallback Pool</strong></a>.</li>
<li>If you choose to set traffic steering to <strong>Random</strong>, you can set <a href="/load-balancing/understand-basics/traffic-steering/steering-policies/standard-options/#random-steering">Weights</a> (via the API) to your pools to determine the percentage of traffic sent to each pool.</li>
</ul>
<ol start="7">
<li>
<p>Select <strong>Next</strong>.</p>
</li>
<li>
<p>On the <strong>Monitors</strong> page:</p>
</li>
</ol>
<ul>
<li>Review the monitors attached to your pools.</li>
<li>If needed, you can attach an existing monitor or <a href="/load-balancing/monitors/create-monitor/#create-a-monitor">create a new monitor</a>.</li>
</ul>
<ol start="9">
<li>
<p>Select <strong>Next</strong>.</p>
</li>
<li>
<p>On the <strong>Traffic Steering</strong> page, choose an option for <a href="/load-balancing/understand-basics/traffic-steering/steering-policies/">Traffic steering</a> and select <strong>Next</strong>.</p>
</li>
<li>
<p>On the <strong>Custom Rules</strong> page, select an existing rule or <a href="/load-balancing/additional-options/load-balancing-rules/">create a new rule</a>.</p>
</li>
<li>
<p>Select <strong>Next</strong>.</p>
</li>
<li>
<p>On the <strong>Review</strong> page:</p>
</li>
</ol>
<ul>
<li>Review your configuration and make any changes.</li>
<li>Choose whether to <strong>Save as Draft</strong> or <strong>Save and Deploy</strong>.</li>
</ul>
<h3 id="body-10422-create-a-private-load-balancer">Create a Private load balancer</h3>
<ol>
<li>
<p>Go to <strong>Load Balancing</strong> and select <strong>Create load balancer</strong>.</p>
</li>
<li>
<p>On the <strong>Load Balancer Setup</strong>, select <strong>Private load balancer</strong></p>
</li>
<li>
<p>Associate your load balancer with either a Cloudflare private IP or a specified IP address and create a description for your load balancer.</p>
</li>
<li>
<p>On the <strong>Add a Pool</strong> page:</p>
</li>
</ol>
<ul>
<li>Select one or more existing pools or <a href="/load-balancing/pools/create-pool/#create-a-pool">create a new pool</a>.</li>
<li>If you are going to set <a href="/load-balancing/understand-basics/traffic-steering/steering-policies/standard-options/">traffic steering</a> to <strong>Off</strong>, re-order the pools in your load balancer to adjust the fallback order.</li>
<li>If needed, update the <a href="/load-balancing/understand-basics/health-details/#fallback-pools"><strong>Fallback Pool</strong></a>.</li>
<li>If you choose to set traffic steering to <strong>Random</strong>, you can set <a href="/load-balancing/understand-basics/traffic-steering/steering-policies/standard-options/#random-steering">Weights</a> (via the API) to your pools to determine the percentage of traffic sent to each pool.</li>
</ul>
<ol start="5">
<li>
<p>Select <strong>Next</strong>.</p>
</li>
<li>
<p>On the <strong>Monitors</strong> page:</p>
</li>
</ol>
<ul>
<li>Review the monitors attached to your pools.</li>
<li>If needed, you can attach an existing monitor or <a href="/load-balancing/monitors/create-monitor/#create-a-monitor">create a new monitor</a>.</li>
</ul>
<ol start="7">
<li>
<p>Select <strong>Next</strong>.</p>
</li>
<li>
<p>On the <strong>Traffic Steering</strong> page, choose an option for <a href="/load-balancing/understand-basics/traffic-steering/steering-policies/">Traffic steering</a> and select <strong>Next</strong>.</p>
</li>
<li>
<p>Select <strong>Next</strong>.</p>
</li>
<li>
<p>On the <strong>Review</strong> page:</p>
</li>
</ol>
<ul>
<li>Review your configuration and make any changes.</li>
<li>Choose whether to <strong>Save as Draft</strong> or <strong>Save and Deploy</strong>.</li>
</ul>
