<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<p>In the dashboard, this setting appears as a <strong>Flatten CNAME</strong> toggle on each endpoint in a pool. Turn the toggle off to return the endpoint hostname as a <code>CNAME</code> record.</p>
<div class="nb-steps">
<ol>
<li>In the Cloudflare dashboard, go to the <strong>Load Balancing</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select the <strong>Pools</strong> tab.</li>
<li>On the pool that contains the endpoint, select <strong>Edit</strong>.</li>
<li>In the <strong>Endpoints</strong> section, find the endpoint you want to change.</li>
<li>Turn <strong>Flatten CNAME</strong> off.</li>
<li>Select <strong>Save</strong>.</li>
</ol>
</div>
<p><strong>Flatten CNAME</strong> is only available for endpoints whose address is a hostname. Endpoints that use an IP address cannot turn it off.</p>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Use <a href="/api/resources/load_balancers/subresources/pools/methods/create/">Create Pool</a> or <a href="/api/resources/load_balancers/subresources/pools/methods/edit/">Edit Pool</a> and set <code>flatten_cname</code> on each endpoint in the <code>origins</code> array.</p>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/load_balancers/pools \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;primary-pool&quot;,
&quot;origins&quot;: [
  {
    &quot;name&quot;: &quot;origin-a&quot;,
    &quot;address&quot;: &quot;origin-a.example.com&quot;,
    &quot;enabled&quot;: true,
    &quot;weight&quot;: 1,
    &quot;flatten_cname&quot;: false
  },
  {
    &quot;name&quot;: &quot;origin-b&quot;,
    &quot;address&quot;: &quot;origin-b.example.com&quot;,
    &quot;enabled&quot;: true,
    &quot;weight&quot;: 1,
    &quot;flatten_cname&quot;: false
  },
  {
    &quot;name&quot;: &quot;fallback-ip&quot;,
    &quot;address&quot;: &quot;203.0.113.10&quot;,
    &quot;enabled&quot;: true,
    &quot;weight&quot;: 1
  }
]
}&#x27;</code></pre>
<p><code>flatten_cname</code> defaults to <code>true</code> when omitted, preserving today's behavior for existing pools and endpoints.</p>
