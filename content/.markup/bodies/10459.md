<p>When <a href="/load-balancing/load-balancers/create-load-balancer/">creating or editing a load balancer</a>:</p>
<ol>
<li>Go to the <strong>Traffic steering</strong> step.</li>
<li>Select <strong>Geo steering</strong>.</li>
<li>For <strong>Region</strong>, select a region &gt; <strong>Add Region</strong>.</li>
<li>Select <strong>Edit</strong>.</li>
<li>Select a pool &gt; <strong>Add Pool</strong>.</li>
<li>If adding multiple pools, re-order them into your preferred failback order.</li>
<li>(optional) Add more regions if needed.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Use the <code>regions_pool</code> property of the <a href="/api/resources/load_balancers/methods/update/">Update Load Balancers</a> command to specify an array of regions. Specify each region using the <a href="/load-balancing/reference/region-mapping-api/#list-of-load-balancer-regions">appropriate region code</a> followed by a list of endpoints to use for that region.</p>
<p>In the example below, <code>WNAM</code> and <code>ENAM</code> represent the West and East Coasts of North America, respectively.</p>
<pre><code class="language-json">// PUT /zones/:zone_id/load_balancers
{
	&quot;description&quot;: &quot;Load Balancer for www.example.com&quot;,
	&quot;name&quot;: &quot;www.example.com&quot;,
	&quot;ttl&quot;: 30,
	&quot;proxied&quot;: true,
	&quot;fallback_pool&quot;: &quot;ff02c959d17f7bb2b1184a202e3c0af7&quot;,
	&quot;default_pools&quot;: [
		&quot;17b5962d775c646f3f9725cbc7a53df4&quot;,
		&quot;ff02c959d17f7bb2b1184a202e3c0af7&quot;
	],
	&quot;region_pools&quot;: {
		&quot;WNAM&quot;: [
			&quot;17b5962d775c646f3f9725cbc7a53df4&quot;,
			&quot;ff02c959d17f7bb2b1184a202e3c0af7&quot;
		],
		&quot;ENAM&quot;: [
			&quot;17b5962d775c646f3f9725cbc7a53df4&quot;,
			&quot;ff02c959d17f7bb2b1184a202e3c0af7&quot;
		],
		&quot;EEU&quot;: [
			&quot;ff02c959d17f7bb2b1184a202e3c0af7&quot;,
			&quot;17b5962d775c646f3f9725cbc7a53df4&quot;
		]
	}
}
</code></pre>
<p>If you only define <code>WNAM</code>, then traffic from the East Coast will be routed to the <code>default_pools</code>. You can test this using a client in each of those locations.</p>
