<p>When <a href="/load-balancing/load-balancers/create-load-balancer/">creating or editing a load balancer</a>:</p>
<ol>
<li>Follow the <a href="/load-balancing/load-balancers/create-load-balancer/#create-a-load-balancer">create a load balancer procedure</a> until you reach the <strong>Traffic steering</strong> step.</li>
<li>Select <strong>Geo steering</strong>.</li>
<li>For <strong>Country</strong>, select a country &gt; <strong>Add Region</strong>.</li>
<li>Select <strong>Edit</strong>.</li>
<li>Select a pool &gt; <strong>Add Pool</strong>.</li>
<li>If adding multiple pools, re-order them into your preferred failback order.</li>
<li>(optional) Add more countries if needed.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>When creating a load balancer <a href="/api/resources/load_balancers/methods/create/">via the API</a>, include the <code>country_pools</code> object to map countries to a list of pool IDs (ordered by their failover priority).</p>
<p>To get a list of country codes, use the <a href="/load-balancing/reference/region-mapping-api/">Region API</a>.</p>
<p>Any country not explicitly defined will fall back to using the corresponding <code>region_pool</code> mapping (if it exists), then to the associated default pools.</p>
