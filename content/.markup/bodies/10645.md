Send a [`POST` request](/api/resources/alerting/subresources/policies/methods/create/) to create a tunnel health alert. You can set tunnel health alerts with any SLO value between `0` and `99.99`.




<pre class="nb-api-request"><code class="language-bash">curl --request POST \
 --url https://api.cloudflare.com/client/v4/accounts/{account_id}/alerting/v3/policies \
 --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
 --data &#x27;{
 &quot;alert_type&quot;: &quot;magic_tunnel_health_check_event&quot;,
 &quot;description&quot;: &quot;&lt;DESCRIBE_POLICY&gt;&quot;,
 &quot;enabled&quot;: true,
 &quot;filters&quot;: {
   &quot;slo&quot;: [
     &quot;99.9&quot;
   ]
 },
 &quot;mechanisms&quot;: {
   &quot;email&quot;: [
     {
       &quot;id&quot;: &quot;EMAIL_ADDRESS&quot;
     }
   ]
 },
 &quot;name&quot;: &quot;&lt;DESCRIBE_ALERT&gt;&quot;
}&#x27;</code></pre>
