<aside class="nb-aside note">
<p>You can only advertise your prefix after running pre-flight checks with Cloudflare. If your prefix status is grayed out and shows a <em>Withdrawn</em> status, Cloudflare locks your prefix. Contact your account team to close the pre-flight checks phase and unlock your prefixes.</p>
<p>Currently, only the default BGP prefix (that matches the IP prefix) can be controlled through the Cloudflare dashboard.</p>
</aside>
<ol>
<li>Go to the <strong>Routes</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>From the <strong>IP prefixes</strong> tab, select the prefix you want to modify &gt; <strong>Edit</strong>.</li>
<li>From the <strong>Status</strong> drop-down menu, select <em>Advertised</em> or <em>Withdrawn</em>.</li>
<li>(Optional) Edit the description for your prefix.</li>
<li>Select <strong>Edit IP Prefix</strong> to save your changes.</li>
</ol>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Any configured BGP prefix can be controlled through the API using a <a href="/api/resources/addressing/subresources/prefixes/subresources/bgp_prefixes/methods/edit/">PATCH request</a>. For example:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request PATCH \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/addressing/prefixes/{prefix_id}/bgp/prefixes/{bgp_prefix_id} \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;on_demand&quot;: {
  &quot;advertised&quot;: true
}
}&#x27;</code></pre>

</section>
