<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="macos">

<p>If you use the package manager <a href="https://brew.sh">Homebrew</a>, run the <code>brew install</code> command in your terminal to install Hugo:</p>
<pre><code class="language-sh">brew install hugo
</code></pre>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="windows">

<p>If you use the package manager <a href="https://chocolatey.org/">Chocolatey</a>, run the <code>choco install</code> command in your terminal to install Hugo:</p>
<pre><code class="language-sh">choco install hugo --confirm
</code></pre>
<p>If you use the package manager <a href="https://scoop.sh/">Scoop</a>, run the <code>scoop install</code> command in your terminal to install Hugo:</p>
<pre><code class="language-sh">scoop install hugo
</code></pre>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="linux">

<p>The package manager for your Linux distribution may include Hugo. If this is the case, install Hugo directly using the distribution's package manager — for instance, in Ubuntu, run the following command:</p>
<pre><code class="language-sh">sudo apt-get install hugo
</code></pre>
<p>If your package manager does not include Hugo or you would like to download a release directly, refer to the <a href="/pages/framework-guides/deploy-a-hugo-site/#manual-installation"><strong>Manual</strong></a> section.</p>

</section>
