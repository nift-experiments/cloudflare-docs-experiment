
Redirects defined in the `_redirects` file are not applied to requests served by <a href="/pages/functions/">Pages Functions</a>, even if the Function route matches the URL pattern. If your Pages application uses Functions, you must migrate any behaviors from the <code>_redirects</code> file to the code in the appropriate <code>/functions</code> route, or <a href="/pages/functions/routing/#create-a-_routesjson-file">exclude the route from Functions</a>.
