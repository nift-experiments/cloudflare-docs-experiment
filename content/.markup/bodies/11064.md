
Custom headers defined in the `_headers` file are not applied to responses generated by <a href="/pages/functions/">Pages Functions</a>, even if the request URL matches a rule defined in `_headers`. If you use a server-side rendered (SSR) framework, or Pages Functions (with either a folder of <a href="/pages/functions/routing/"><code>functions/</code></a> or an <a href="/pages/functions/advanced-mode/">"advanced mode" <code>_worker.js</code></a>), you will likely need to attach any custom headers you wish to apply directly within that Pages Functions code.
