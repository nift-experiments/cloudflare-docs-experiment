

<details class="nb-details"><summary>Connection volume and ingress bytes overview</summary><div class="nb-details-body">

<p>Get a high-level view of daily ingress connection count and bytes transferred.</p>
<pre><code class="language-graphql">query IngressTrafficOverview(
  $accountTag: String!
  $startDate: Date!
  $endDate: Date!
) {
  viewer {
    accounts(filter: { accountTag: $accountTag }) {
      privacyProxyIngressConnMetricsAdaptiveGroups(
        filter: {
          date_geq: $startDate
          date_leq: $endDate
        }
        limit: 10000
        orderBy: [date_ASC]
      ) {
        count
        sum {
          bytesSentToClient
          bytesRecvdFromClient
        }
        dimensions {
          date
        }
      }
    }
  }
}
</code></pre>
<pre><code class="language-json">{
  &quot;accountTag&quot;: &quot;&lt;YOUR_ACCOUNT_TAG&gt;&quot;,
  &quot;startDate&quot;: &quot;2026-04-04&quot;,
  &quot;endDate&quot;: &quot;2026-04-06&quot;
}
</code></pre>

<details class="nb-details"><summary>Connection duration by data center</summary><div class="nb-details-body">

<p>Compare client-to-proxy connection duration across data centers to identify regions with long-lived or stalled connections.</p>
<pre><code class="language-graphql">query IngressDurationByColo(
  $accountTag: String!
  $startDate: Date!
  $endDate: Date!
) {
  viewer {
    accounts(filter: { accountTag: $accountTag }) {
      privacyProxyIngressConnMetricsAdaptiveGroups(
        filter: {
          date_geq: $startDate
          date_leq: $endDate
        }
        limit: 10000
        orderBy: [quantiles_durationMsP50_DESC]
      ) {
        quantiles {
          durationMsP50
          durationMsP95
          durationMsP99
        }
        dimensions {
          coloCode
        }
      }
    }
  }
}
</code></pre>

<details class="nb-details"><summary>Protocol and TLS version distribution</summary><div class="nb-details-body">

<p>Understanding which transport protocols (QUIC versus TCP) and TLS versions your clients use helps you plan deprecations, detect misconfigured clients, and verify that traffic meets your security requirements.</p>
<pre><code class="language-graphql">query IngressProtocolDistribution(
  $accountTag: String!
  $start: Time!
  $end: Time!
) {
  viewer {
    accounts(filter: { accountTag: $accountTag }) {
      privacyProxyIngressConnMetricsAdaptiveGroups(
        filter: {
          datetimeFifteenMinutes_geq: $start
          datetimeFifteenMinutes_leq: $end
        }
        limit: 10000
        orderBy: [datetimeFifteenMinutes_ASC]
      ) {
        count
        dimensions {
          datetimeFifteenMinutes
          transport
          tlsVersion
        }
      }
    }
  }
}
</code></pre>
<pre><code class="language-json">{
  &quot;accountTag&quot;: &quot;&lt;YOUR_ACCOUNT_TAG&gt;&quot;,
  &quot;start&quot;: &quot;2026-04-04T00:00:00Z&quot;,
  &quot;end&quot;: &quot;2026-04-06T23:59:59Z&quot;
}
</code></pre>

</div></details>
