

<details class="nb-details"><summary>Egress bytes overview</summary><div class="nb-details-body">

<p>Get a high-level view of daily bytes flowing between the proxy and the upstream origin.</p>
<pre><code class="language-graphql">query EgressBytesOverview(
  $accountTag: String!
  $startDate: Date!
  $endDate: Date!
) {
  viewer {
    accounts(filter: { accountTag: $accountTag }) {
      privacyProxyEgressConnMetricsAdaptiveGroups(
        filter: {
          date_geq: $startDate
          date_leq: $endDate
        }
        limit: 10000
        orderBy: [date_ASC]
      ) {
        count
        sum {
          bytesSentToOrigin
          bytesRecvdFromOrigin
        }
        dimensions {
          date
        }
      }
    }
  }
}
</code></pre>
<pre><code class="language-json">{
  &quot;accountTag&quot;: &quot;&lt;YOUR_ACCOUNT_TAG&gt;&quot;,
  &quot;startDate&quot;: &quot;2026-04-04&quot;,
  &quot;endDate&quot;: &quot;2026-04-06&quot;
}
</code></pre>

<details class="nb-details"><summary>Proxy-to-origin latency by data center</summary><div class="nb-details-body">

<p>Compare proxy-to-origin handshake times across data centers to identify regions with degraded origin reachability.</p>
<pre><code class="language-graphql">query EgressLatencyByColo(
  $accountTag: String!
  $startDate: Date!
  $endDate: Date!
) {
  viewer {
    accounts(filter: { accountTag: $accountTag }) {
      privacyProxyEgressConnMetricsAdaptiveGroups(
        filter: {
          date_geq: $startDate
          date_leq: $endDate
        }
        limit: 10000
        orderBy: [quantiles_handshakeDurationUsP50_DESC]
      ) {
        quantiles {
          handshakeDurationUsP50
          handshakeDurationUsP95
          handshakeDurationUsP99
        }
        dimensions {
          coloCode
        }
      }
    }
  }
}
</code></pre>

<details class="nb-details"><summary>Egress performance trend</summary><div class="nb-details-body">

<p>Track proxy-to-origin handshake latency at fine granularity over a specific time window.</p>
<pre><code class="language-graphql">query EgressPerformanceTrend(
  $accountTag: String!
  $start: Time!
  $end: Time!
) {
  viewer {
    accounts(filter: { accountTag: $accountTag }) {
      privacyProxyEgressConnMetricsAdaptiveGroups(
        filter: {
          datetimeFiveMinutes_geq: $start
          datetimeFiveMinutes_leq: $end
        }
        limit: 10000
        orderBy: [datetimeFiveMinutes_ASC]
      ) {
        quantiles {
          handshakeDurationUsP50
          handshakeDurationUsP95
          handshakeDurationUsP99
        }
        count
        dimensions {
          datetimeFiveMinutes
        }
      }
    }
  }
}
</code></pre>
