<p>Below the <code>runtime</code> key, add the following code:</p>
<pre><code class="language-yaml"># new top-level section
variables:
  zone:
    fn::invoke:
      function: cloudflare:getZone
      arguments:
        accountId: ${accountId}
        name: ${domain}
</code></pre>
<p>Below the <code>worker</code> resource, add the following code:</p>
<pre><code class="language-yaml">route:
  type: cloudflare:WorkersRoute
  properties:
    zoneId: ${zone.id}
    pattern: &quot;hello-world.${domain}&quot;
    scriptName: ${worker.name}
</code></pre>
