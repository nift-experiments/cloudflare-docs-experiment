
<div class="nb-steps">

<ol>
<li>In the Cloudflare dashboard, go to <strong>Pipelines</strong> &gt; <strong>Pipelines</strong>.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>
<p>Select <strong>Create Pipeline</strong>.</p>
</li>
<li>
<p><strong>Connect to a Stream</strong>:</p>
</li>
</ol>
<ul>
<li>Pipeline name: <code>raw_events</code></li>
<li>Enable HTTP endpoint for sending data: Enabled</li>
<li>HTTP authentication: Disabled (default)</li>
<li>Select <strong>Next</strong></li>
</ul>
<ol start="4">
<li><strong>Define Input Schema</strong>:</li>
</ol>
<ul>
<li>Select <strong>JSON editor</strong></li>
<li>Copy in the schema:</li>
</ul>
<pre><code class="language-json">{
	&quot;fields&quot;: [
		{ &quot;name&quot;: &quot;transaction_id&quot;, &quot;type&quot;: &quot;string&quot;, &quot;required&quot;: true },
		{ &quot;name&quot;: &quot;user_id&quot;, &quot;type&quot;: &quot;int64&quot;, &quot;required&quot;: true },
		{ &quot;name&quot;: &quot;amount&quot;, &quot;type&quot;: &quot;float64&quot;, &quot;required&quot;: false },
		{
			&quot;name&quot;: &quot;transaction_timestamp&quot;,
			&quot;type&quot;: &quot;string&quot;,
			&quot;required&quot;: false
		},
		{ &quot;name&quot;: &quot;location&quot;, &quot;type&quot;: &quot;string&quot;, &quot;required&quot;: false },
		{ &quot;name&quot;: &quot;merchant_category&quot;, &quot;type&quot;: &quot;string&quot;, &quot;required&quot;: false },
		{ &quot;name&quot;: &quot;is_fraud&quot;, &quot;type&quot;: &quot;bool&quot;, &quot;required&quot;: false }
	]
}
</code></pre>
<ul>
<li>Select <strong>Next</strong></li>
</ul>
<ol start="5">
<li><strong>Define Sink</strong>:</li>
</ol>
<ul>
<li>Select your R2 bucket: <code>fraud-pipeline</code></li>
<li>Storage type: <strong>R2 Data Catalog</strong></li>
<li>Namespace: <code>fraud_detection</code></li>
<li>Table name: <code>transactions</code></li>
<li><strong>Advanced Settings</strong>: Change <strong>Maximum Time Interval</strong> to <code>30 seconds</code></li>
<li>Select <strong>Next</strong></li>
</ul>
<ol start="6">
<li><strong>Credentials</strong>:</li>
</ol>
<ul>
<li>Disable <strong>Automatically create an Account API token for your sink</strong></li>
<li>Enter <strong>Catalog Token</strong> from step 1</li>
<li>Select <strong>Next</strong></li>
</ul>
<ol start="7">
<li><strong>Pipeline Definition</strong>:</li>
</ol>
<ul>
<li>Leave the default SQL query:</li>
</ul>
<pre><code class="language-sql">INSERT INTO raw_events_sink SELECT * FROM raw_events_stream;
</code></pre>
<ul>
<li>Select <strong>Create Pipeline</strong></li>
</ul>
<ol start="8">
<li>After pipeline creation, note the <strong>Stream ID</strong> for the next step.</li>
</ol>

</div>
