<h3 id="body-11344-3-2-create-the-data-sink">3.2. Create the data sink</h3>
<p>Create a sink that writes data to your R2 bucket as Apache Iceberg tables:</p>
<pre><code class="language-bash">npx wrangler pipelines sinks create raw_events_sink \
  --type &quot;r2-data-catalog&quot; \
  --bucket &quot;fraud-pipeline&quot; \
  --roll-interval 30 \
  --namespace &quot;fraud_detection&quot; \
  --table &quot;transactions&quot; \
  --catalog-token $WRANGLER_R2_SQL_AUTH_TOKEN
</code></pre>
<aside class="nb-aside note">
<p>This creates a <code>sink</code> configuration that will write to the Iceberg table <code>fraud_detection.transactions</code> in your R2 Data Catalog every 30 seconds. Pipelines automatically appends an <code>__ingest_ts</code> column that is used to partition the table by <code>DAY</code>.</p>
</aside>
<h3 id="body-11344-3-3-create-the-pipeline">3.3. Create the pipeline</h3>
<p>Connect your stream to your sink with SQL:</p>
<pre><code class="language-bash">npx wrangler pipelines create raw_events_pipeline \
  --sql &quot;INSERT INTO raw_events_sink SELECT * FROM raw_events_stream&quot;
</code></pre>
