

1. Log in to your Cloudflare account:

<pre><code class="language-sh">npx wrangler login
</code></pre>


2. Create a bucket named `my-bucket`:

<pre><code class="language-sh">npx wrangler r2 bucket create my-bucket
</code></pre>


If prompted, select the account you want to create the bucket in.

3. Verify the bucket was created:

<pre><code class="language-sh">npx wrangler r2 bucket list
</code></pre>
