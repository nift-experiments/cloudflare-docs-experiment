
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Wrangler CLI">

<div class="nb-steps">
<ol>
<li>Log in to your Cloudflare account:</li>
</ol>
<pre><code class="language-sh">npx wrangler login
</code></pre>
<ol start="2">
<li>Create a bucket named <code>my-bucket</code>:</li>
</ol>
<pre><code class="language-sh">npx wrangler r2 bucket create my-bucket
</code></pre>
<p>If prompted, select the account you want to create the bucket in.</p>
<ol start="3">
<li>Verify the bucket was created:</li>
</ol>
<pre><code class="language-sh">npx wrangler r2 bucket list
</code></pre>
</div>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<div class="nb-steps">
<ol>
<li>In the Cloudflare Dashboard, go to <strong>R2 object storage</strong>.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select <strong>Create bucket</strong>.</li>
<li>Enter a name for your bucket.</li>
<li>Select a <a href="/r2/reference/data-location">location</a> for your bucket and a <a href="/r2/buckets/storage-classes/">default storage class</a>.</li>
<li>Select <strong>Create bucket</strong>.</li>
</ol>
</div>

</section>
