<div class="nb-steps">
<ol>
<li>Install <a href="https://boto3.amazonaws.com/v1/documentation/api/latest/index.html">boto3</a>:</li>
</ol>
<pre><code class="language-sh">pip install boto3
</code></pre>
<ol start="2">
<li>Create a test file to upload:</li>
</ol>
<pre><code class="language-sh">echo &#x27;Hello, R2!&#x27; &gt; myfile.txt
</code></pre>
<ol start="3">
<li>Use your credentials to create an S3 client and interact with your bucket:</li>
</ol>
<pre><code class="language-python">import boto3
<p>s3 = boto3.client(
service_name='s3',
# Provide your R2 endpoint: https://&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com
endpoint_url='https://&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com',
# Provide your R2 Access Key ID and Secret Access Key
aws_access_key_id='&lt;ACCESS_KEY_ID&gt;',
aws_secret_access_key='&lt;SECRET_ACCESS_KEY&gt;',
region_name='auto',  # Required by boto3, not used by R2
)</p>
<p># Upload a file
s3.upload_file('myfile.txt', 'my-bucket', 'myfile.txt')
print('Uploaded myfile.txt')</p>
<p># Download a file
s3.download_file('my-bucket', 'myfile.txt', 'downloaded.txt')
print('Downloaded to downloaded.txt')</p>
<p># List objects
response = s3.list_objects_v2(Bucket='my-bucket')
for obj in response.get('Contents', []):
print(f&quot;Object: {obj['Key']}&quot;)
</code></pre></p>
<ol start="4">
<li>Save this as <code>example.py</code> and run it:</li>
</ol>
<pre><code class="language-sh">python example.py
</code></pre>
<pre><code class="language-sh">Uploaded myfile.txt
Downloaded to downloaded.txt
Object: myfile.txt
</code></pre>
</div>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="JavaScript">

<div class="nb-steps">
<ol>
<li>Install the <a href="https://www.npmjs.com/package/@aws-sdk/client-s3">@aws-sdk/client-s3</a> package:</li>
</ol>
<pre><code class="language-sh">npm install @aws-sdk/client-s3
</code></pre>
<ol start="2">
<li>Use your credentials to create an S3 client and interact with your bucket:</li>
</ol>
<pre><code class="language-js">import {
	S3Client,
	PutObjectCommand,
	GetObjectCommand,
	ListObjectsV2Command,
} from &quot;@aws-sdk/client-s3&quot;;
<p>const s3 = new S3Client({
region: &quot;auto&quot;, // Required by AWS SDK, not used by R2
// Provide your R2 endpoint: https://&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com
endpoint: &quot;https://&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com&quot;,
credentials: {
// Provide your R2 Access Key ID and Secret Access Key
accessKeyId: &quot;&lt;ACCESS_KEY_ID&gt;&quot;,
secretAccessKey: &quot;&lt;SECRET_ACCESS_KEY&gt;&quot;,
},
});</p>
<p>// Upload a file
await s3.send(
new PutObjectCommand({
Bucket: &quot;my-bucket&quot;,
Key: &quot;myfile.txt&quot;,
Body: &quot;Hello, R2!&quot;,
}),
);
console.log(&quot;Uploaded myfile.txt&quot;);</p>
<p>// Download a file
const response = await s3.send(
new GetObjectCommand({
Bucket: &quot;my-bucket&quot;,
Key: &quot;myfile.txt&quot;,
}),
);
const content = await response.Body.transformToString();
console.log(&quot;Downloaded:&quot;, content);</p>
<p>// List objects
const list = await s3.send(
new ListObjectsV2Command({
Bucket: &quot;my-bucket&quot;,
}),
);
console.log(
&quot;Objects:&quot;,
list.Contents.map((obj) =&gt; obj.Key),
);
</code></pre></p>
<ol start="3">
<li>Save this as <code>example.mjs</code> and run it:</li>
</ol>
<pre><code class="language-sh">node example.mjs
</code></pre>
<pre><code class="language-sh">Uploaded myfile.txt
Downloaded: Hello, R2!
Objects: [ &#x27;myfile.txt&#x27; ]
</code></pre>
</div>
<p>Refer to <a href="/r2/examples/aws/aws-sdk-js-v3/">AWS SDK for JavaScript examples</a> for more operations.</p>
