<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Expo">

<p><strong>Minimum Expo version:</strong> 56 or above.</p>
<p>Install the dependencies:</p>
<pre><code class="language-bash">npx expo install @cloudflare/realtimekit-react-native-ui @cloudflare/realtimekit-react-native @cloudflare/react-native-webrtc @react-native-documents/picker react-native-file-viewer react-native-fs react-native-sound-player react-native-webview react-native-svg@^15.13.0 react-native-safe-area-context@^5.0.0
</code></pre>
<p>Install Expo config plugins:</p>
<pre><code class="language-bash">npx expo install @expo/config-plugins
</code></pre>
<p>Add the plugins to your <code>app.json</code>:</p>
<pre><code class="language-json">{
	&quot;expo&quot;: {
		&quot;plugins&quot;: [
			&quot;@cloudflare/realtimekit-react-native&quot;,
			&quot;@cloudflare/react-native-webrtc&quot;
		]
	}
}
</code></pre>
<p>Run <code>prebuild</code> to set up native modules:</p>
<pre><code class="language-bash">npx expo prebuild
</code></pre>

</section>
