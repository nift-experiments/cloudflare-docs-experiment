

<div class="nb-steps">

<ol>
<li>Change into the directory you just created for your Workers project:</li>
</ol>
<pre><code class="language-sh">cd d1-tutorial
</code></pre>
<ol start="2">
<li>Run the following <code>wrangler@latest d1</code> command and give your database a name. In this tutorial, the database is named <code>prod-d1-tutorial</code>:</li>
</ol>
<aside class="nb-aside note">
<p>The <a href="/workers/wrangler/">Wrangler command-line interface</a> is Cloudflare's tool for managing and deploying Workers applications and D1 databases in your terminal. It was installed when you used <code>npm create cloudflare@latest</code> to initialize your new project.</p>
<p>While Wrangler gets installed locally to your project, you can use it outside the project by using the command <code>npx wrangler</code>.</p>
</aside>
<pre><code class="language-sh">npx wrangler@latest d1 create prod-d1-tutorial
</code></pre>
<pre><code class="language-txt">✅ Successfully created DB &#x27;prod-d1-tutorial&#x27; in region WEUR
Created your new D1 database.

{
	&quot;d1_databases&quot;: [
		{
			&quot;binding&quot;: &quot;prod_d1_tutorial&quot;,
			&quot;database_name&quot;: &quot;prod-d1-tutorial&quot;,
			&quot;database_id&quot;: &quot;&lt;unique-ID-for-your-database&gt;&quot;
		}
	]
}
</code></pre>
<ol start="3">
<li>When prompted: <code>Would you like Wrangler to add it on your behalf?</code>, select <code>Yes</code>. This will automatically add the binding to your Wrangler configuration file.</li>
</ol>

</div>

This creates a new D1 database and outputs the [binding](/workers/runtime-apis/bindings/) configuration needed in the next step.
