

To create a new poll, use the `create` method available on the `meeting.polls` object. The `meeting.polls.create()` function requires the following parameters:

<table>
<thead>
<tr>
<th>Param</th>
<th>Type</th>
<th>Required</th>
<th>Description</th>
</tr>
</thead>
<tbody>
<tr>
<td>question</td>
<td><code>String</code></td>
<td>yes</td>
<td>The question that is to be voted for.</td>
</tr>
<tr>
<td>options</td>
<td><code>List&lt;String&gt;</code></td>
<td>yes</td>
<td>The options of the poll.</td>
</tr>
<tr>
<td>anonymous</td>
<td><code>Boolean</code></td>
<td>yes</td>
<td>If true, the poll votes are anonymous.</td>
</tr>
<tr>
<td>hideVotes</td>
<td><code>Boolean</code></td>
<td>yes</td>
<td>If true, the votes on the poll are hidden.</td>
</tr>
</tbody>
</table>

The following snippet creates a poll where votes are anonymous.

```kotlin
val pollsCreateError: PollsError? = meeting.polls.create(
  question = "Are you an early bird or a night owl?",
  options = listOf("Early bird", "Night owl"),
  anonymous = true,
  hideVotes = false
)
```
