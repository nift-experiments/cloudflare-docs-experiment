

A new poll can be created using the `create` method from the `meeting.polls` object. The `meeting.polls.create()` method accepts the following parameters:

<table>
<thead>
<tr>
<th>Param</th>
<th>Type</th>
<th>Default Value</th>
<th>Required</th>
<th>Description</th>
</tr>
</thead>
<tbody>
<tr>
<td>question</td>
<td><code>string</code></td>
<td>-</td>
<td>yes</td>
<td>The question that is to be voted for.</td>
</tr>
<tr>
<td>options</td>
<td><code>string[]</code></td>
<td>-</td>
<td>yes</td>
<td>The options of the poll.</td>
</tr>
<tr>
<td>anonymous</td>
<td><code>boolean</code></td>
<td>false</td>
<td>no</td>
<td>If true, the poll votes are anonymous.</td>
</tr>
<tr>
<td>hideVotes</td>
<td><code>boolean</code></td>
<td>false</td>
<td>no</td>
<td>If true, the votes on the poll are hidden.</td>
</tr>
</tbody>
</table>

The following snippet creates a poll where votes are anonymous.

```ts
await meeting.poll.create(
	"Are you an early bird or a night owl?",
	["Early bird", "Night owl"],
	true,
);
```
