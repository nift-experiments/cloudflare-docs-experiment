

You can automatically add the binding to your Wrangler configuration file when you run the `wrangler d1 create` command (step 3 of [2. Create a database](/d1/get-started/#2-create-a-database)).

But if you wish to add the binding manually, follow the steps below:

<div class="nb-steps">

<ol>
<li>Copy the lines obtained from step 2 of <a href="/d1/get-started/#2-create-a-database">2. Create a database</a> from your terminal.</li>
<li>Add them to the end of your Wrangler file.</li>
</ol>
<div class="nb-wrangler-config">
<pre><code class="language-jsonc">{
  &quot;d1_databases&quot;: [
    {
      &quot;binding&quot;: &quot;prod_d1_tutorial&quot;, // available in your Worker on env.DB
      &quot;database_name&quot;: &quot;prod-d1-tutorial&quot;,
      &quot;database_id&quot;: &quot;&lt;unique-ID-for-your-database&gt;&quot;
    }
  ]
}
</code></pre>
</div>
<p>Specifically:</p>
<ul>
<li>The value (string) you set for <code>binding</code> is the <strong>binding name</strong>, and is used to reference this database in your Worker. In this tutorial, name your binding <code>prod_d1_tutorial</code>.</li>
<li>The binding name must be <a href="https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Grammar_and_types#variables">a valid JavaScript variable name</a>. For example, <code>binding = &quot;MY_DB&quot;</code> or <code>binding = &quot;productionDB&quot;</code> would both be valid names for the binding.</li>
<li>Your binding is available in your Worker at <code>env.&lt;BINDING_NAME&gt;</code> and the D1 <a href="/d1/worker-api/">Workers Binding API</a> is exposed on this binding.</li>
</ul>

</div>

<aside class="nb-aside note">


<p>When you execute the <code>wrangler d1 create</code> command, the client API package (which implements the D1 API and database class) is automatically installed. For more information on the D1 Workers Binding API, refer to <a href="/d1/worker-api/">Workers Binding API</a>.</p>


</aside>

You can also bind your D1 database to a [Pages Function](/pages/functions/). For more information, refer to [Functions Bindings for D1](/pages/functions/bindings/#d1-databases).
