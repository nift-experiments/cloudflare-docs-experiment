

To perform actions on a specific participant, retrieve their participant object from the `participants` property.
Remote participants are available in `meeting.participants.joined`. The local participant is available in `meeting.localUser`.

```kotlin
val joinedParticipants = meeting.participants.joined
val participant = joinedParticipants.firstOrNull()
if (participant == null) {
	// No remote participants are currently joined.
}
```
