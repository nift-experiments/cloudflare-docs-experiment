<p>After correctly preparing your <a href="/workers/wrangler/configuration/">Wrangler configuration file</a>, set up your database. Create a <code>schema.sql</code> file using the SQL syntax below to initialize your database.</p>
<div class="nb-steps">
<ol>
<li>Copy the following code and save it as a <code>schema.sql</code> file in the <code>d1-tutorial</code> Worker directory you created in step 1:</li>
</ol>
<pre><code class="language-sql">DROP TABLE IF EXISTS Customers;
CREATE TABLE IF NOT EXISTS Customers (CustomerId INTEGER PRIMARY KEY, CompanyName TEXT, ContactName TEXT);
INSERT INTO Customers (CustomerID, CompanyName, ContactName) VALUES (1, &#x27;Alfreds Futterkiste&#x27;, &#x27;Maria Anders&#x27;), (4, &#x27;Around the Horn&#x27;, &#x27;Thomas Hardy&#x27;), (11, &#x27;Bs Beverages&#x27;, &#x27;Victoria Ashworth&#x27;), (13, &#x27;Bs Beverages&#x27;, &#x27;Random Name&#x27;);
</code></pre>
<ol start="2">
<li>Initialize your database to run and test locally first. Bootstrap your new D1 database by running:</li>
</ol>
<pre><code class="language-sh">npx wrangler d1 execute prod-d1-tutorial --local --file=./schema.sql
</code></pre>

<p>Use the Dashboard to create a table and populate it with data.</p>
<div class="nb-steps">
<ol>
<li>In the Cloudflare dashboard, go to the <strong>D1 SQL database</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
2. Select the `prod-d1-tutorial` database you created in [step 2](/d1/get-started/#2-create-a-database).
3. Select **Console**.
4. Paste the following SQL snippet.
<pre><code class="language-sql">DROP TABLE IF EXISTS Customers;
CREATE TABLE IF NOT EXISTS Customers (CustomerId INTEGER PRIMARY KEY, CompanyName TEXT, ContactName TEXT);
INSERT INTO Customers (CustomerID, CompanyName, ContactName) VALUES (1, &#x27;Alfreds Futterkiste&#x27;, &#x27;Maria Anders&#x27;), (4, &#x27;Around the Horn&#x27;, &#x27;Thomas Hardy&#x27;), (11, &#x27;Bs Beverages&#x27;, &#x27;Victoria Ashworth&#x27;), (13, &#x27;Bs Beverages&#x27;, &#x27;Random Name&#x27;);
</code></pre>
<ol start="5">
<li>Select <strong>Execute</strong>. This creates a table called <code>Customers</code> in your <code>prod-d1-tutorial</code> database.</li>
<li>Select <strong>Tables</strong>, then select the <code>Customers</code> table to view the contents of the table.</li>
</ol>
