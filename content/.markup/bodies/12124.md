<ol start="2">
<li>Call <code>disableAudio()</code> on the target participant.</li>
</ol>
<p>If the local participant does not have the required permission, <code>disableAudio()</code> throws a <code>ClientError</code> with code <code>1201</code>.</p>
<pre><code class="language-ts">try {
	await participant.disableAudio();
} catch (err: any) {
	if (err?.code === 1201) {
		// The local participant does not have permission to mute other participants’ audio.
		return;
	}
	throw err;
}
</code></pre>
<ol start="3">
<li>Handle the result by listening for updates.</li>
</ol>
<p>After the call succeeds, the target participant's <code>audioEnabled</code> becomes <code>false</code>, and the SDK emits an <code>audioUpdate</code> event.</p>
<p><strong>Option A</strong>: Listen on the participant object</p>
<pre><code class="language-ts">participant.on(&quot;audioUpdate&quot;, ({ audioEnabled, audioTrack }) =&gt; {
	// audioEnabled is false
	// Update UI for the participant
});
</code></pre>
<p><strong>Option B</strong>: Listen on the <code>joined</code> map</p>
<pre><code class="language-ts">meeting.participants.joined.on(
	&quot;audioUpdate&quot;,
	(participant, { audioEnabled, audioTrack }) =&gt; {
		if (participant.id === targetParticipantId) {
			// audioEnabled is false
			// Update UI for the participant
		}
	},
);
</code></pre>
