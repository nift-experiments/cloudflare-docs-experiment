<ol start="2">
<li>Call <code>disableAllAudio()</code>.</li>
</ol>
<p>If the local participant does not have the required permission, <code>disableAllAudio()</code> throws a <code>ClientError</code> with code <code>1201</code>.</p>
<pre><code class="language-ts">try {
	await meeting.participants.disableAllAudio();
} catch (err: any) {
	if (err?.code === 1201) {
		// The local participant does not have permission to mute other participants’ audio.
		return;
	}
	throw err;
}
</code></pre>
<ol start="3">
<li>Handle the result by listening for updates.</li>
</ol>
<p>After the call succeeds, each participant’s <code>audioEnabled</code> becomes <code>false</code>, and the SDK emits an <code>audioUpdate</code> event.
The local participant also receives <code>audioUpdate</code> on <code>meeting.self</code>.</p>
<p>Listen to remote participant updates on the <code>joined</code> map:</p>
<pre><code class="language-ts">meeting.participants.joined.on(
	&quot;audioUpdate&quot;,
	(participant, { audioEnabled, audioTrack }) =&gt; {
		// audioEnabled is false
		// Update UI for the participant
	},
);
</code></pre>
<p>Listen to the local participant update on <code>meeting.self</code>:</p>
<pre><code class="language-ts">meeting.self.on(&quot;audioUpdate&quot;, ({ audioEnabled, audioTrack }) =&gt; {
	// audioEnabled is false
	// Update UI for the local participant
});
</code></pre>
