<p>If the local participant does not have the required permission, <code>disableAllVideo()</code> throws a <code>ClientError</code> with code <code>1201</code>.</p>
<pre><code class="language-ts">try {
	await meeting.participants.disableAllVideo();
} catch (err: any) {
	if (err?.code === 1201) {
		// The local participant does not have permission to disable other participants’ video.
		return;
	}
	throw err;
}
</code></pre>
<ol start="3">
<li>Handle the result by listening for updates.</li>
</ol>
<p>After the call succeeds, each participant’s <code>videoEnabled</code> becomes <code>false</code>, and the SDK emits a <code>videoUpdate</code> event.
The local participant also receives <code>videoUpdate</code> on <code>meeting.self</code>.</p>
<p>Listen to remote participant updates on the <code>joined</code> map:</p>
<pre><code class="language-ts">meeting.participants.joined.on(
	&quot;videoUpdate&quot;,
	(participant, { videoEnabled, videoTrack }) =&gt; {
		// videoEnabled is false
		// Update UI for the participant
	},
);
</code></pre>
<p>Listen to local participant update on <code>meeting.self</code>:</p>
<pre><code class="language-ts">meeting.self.on(&quot;videoUpdate&quot;, ({ videoEnabled, videoTrack }) =&gt; {
	// videoEnabled is false
	// Update UI for the local participant
});
</code></pre>
