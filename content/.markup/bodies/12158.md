<ol start="2">
<li>Call <code>pin()</code> on the target participant.</li>
</ol>
<p>If the local participant does not have the required permission, <code>pin()</code> throws a <code>ClientError</code> with code <code>1201</code>.</p>
<pre><code class="language-ts">try {
	await participant.pin();
} catch (err: any) {
	if (err?.code === 1201) {
		// The local participant does not have permission to pin participants.
		return;
	}
	throw err;
}
</code></pre>
<ol start="3">
<li>Handle the result by listening for updates.</li>
</ol>
<p>After the call succeeds:</p>
<ul>
<li>The target participant's <code>isPinned</code> becomes true.</li>
<li>The participant is added to <code>meeting.participants.pinned</code>.</li>
<li>The SDK emits a <code>pinned</code> event.</li>
</ul>
<p><strong>Option A</strong>: Listen on the participant object</p>
<pre><code class="language-ts">participant.on(&quot;pinned&quot;, (updatedParticipant) =&gt; {
	// updatedParticipant.isPinned is true
	// Update your UI.
});
</code></pre>
<p><strong>Option B</strong>: Listen on the <code>joined</code> map</p>
<pre><code class="language-ts">meeting.participants.joined.on(&quot;pinned&quot;, (updatedParticipant) =&gt; {
	// updatedParticipant.isPinned is true
	// Update your UI.
});
</code></pre>
<p>If there was an existing pinned participant before, then the SDK emits an <code>unpinned</code> event for that participant.</p>
<ol start="4">
<li>On the target pinned participant's side, <code>meeting.self.isPinned</code> becomes <code>true</code> and <code>meeting.self</code> emits <code>pinned</code>:</li>
</ol>
<pre><code class="language-ts">meeting.self.on(&quot;pinned&quot;, (selfParticipant) =&gt; {
	// Update the local UI to indicate the participant is pinned.
});
</code></pre>
