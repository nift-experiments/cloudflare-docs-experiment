<ol start="2">
<li>Call <code>unpin()</code> on the target participant.</li>
</ol>
<p>If the local participant does not have the required permission, <code>unpin()</code> throws a <code>ClientError</code> with code <code>1201</code>.</p>
<pre><code class="language-ts">try {
	await participant.unpin();
} catch (err: any) {
	if (err?.code === 1201) {
		// The local participant does not have permission to unpin participants.
		return;
	}
	throw err;
}
</code></pre>
<ol start="3">
<li>Handle the result by listening for updates.</li>
</ol>
<p>After the call succeeds:</p>
<ul>
<li>The target participant's <code>isPinned</code> becomes <code>false</code>.</li>
<li>The participant is removed from <code>meeting.participants.pinned</code>.</li>
<li>The SDK emits an <code>unpinned</code> event.</li>
</ul>
<p><strong>Option A</strong>: Listen on the participant object</p>
<pre><code class="language-ts">participant.on(&quot;unpinned&quot;, (updatedParticipant) =&gt; {
	// updatedParticipant.isPinned is false
	// Update your UI.
});
</code></pre>
<p><strong>Option B</strong>: Listen on the <code>joined</code> map</p>
<pre><code class="language-ts">meeting.participants.joined.on(&quot;unpinned&quot;, (updatedParticipant) =&gt; {
	// updatedParticipant.isPinned is false
	// Update your UI.
});
</code></pre>
<ol start="4">
<li>On the target unpinned participant's side, <code>meeting.self.isPinned</code> becomes <code>false</code> and <code>meeting.self</code> emits <code>unpinned</code>:</li>
</ol>
<pre><code class="language-ts">meeting.self.on(&quot;unpinned&quot;, (selfParticipant) =&gt; {
	// Update the local UI to indicate the participant is no longer pinned.
});
</code></pre>
