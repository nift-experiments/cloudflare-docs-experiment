<pre><code class="language-ts">try {
	await participant.kick();

	if (err?.code === 1201) {
		// The local participant does not have permission to remove participants.
		return;
	}
	throw err;
}
</code></pre>
<ol start="3">
<li>Handle the result by listening for updates.</li>
</ol>
<p>After the call succeeds:</p>
<ul>
<li>The kicked participant is removed from <code>meeting.participants.joined</code>.</li>
<li>The participant is removed from other participant maps they were in (for example, <code>meeting.participants.pinned</code>).</li>
<li>The SDK emits <code>participantLeft</code> on <code>meeting.participants.joined</code>.</li>
</ul>
<pre><code class="language-ts">meeting.participants.joined.on(&quot;participantLeft&quot;, (participant) =&gt; {
	// Remove the participant tile from the UI.
});
</code></pre>
<p>Other participants in the session also observe the participant leaving through <code>participantLeft</code>.</p>
<ol start="4">
<li>On the removed participant's side, the session disconnects and <code>meeting.self</code> emits <code>roomLeft</code> event with state set to <code>kicked</code>.</li>
</ol>
<pre><code class="language-ts">meeting.self.on(&quot;roomLeft&quot;, ({ state }) =&gt; {
