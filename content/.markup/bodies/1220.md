class Default(WorkerEntrypoint):
    async def fetch(self, request):
        pathname = urlparse(request.url).path
        if pathname == &quot;/api/beverages&quot;:

                .run()

<p>In the code above, you:</p>
<ol>
<li>Define a binding to your D1 database in your code. This binding matches the <code>binding</code> value you set in the <a href="/workers/wrangler/configuration/">Wrangler configuration file</a> under <code>d1_databases</code>.</li>
<li>Query your database using <code>env.prod_d1_tutorial.prepare</code> to issue a <a href="/d1/worker-api/d1-database/#prepare">prepared query</a> with a placeholder (the <code>?</code> in the query).</li>
<li>Call <code>bind()</code> to safely and securely bind a value to that placeholder. In a real application, you would allow a user to pass the <code>CompanyName</code> they want to list results for. Using <code>bind()</code> prevents users from executing arbitrary SQL (known as &quot;SQL injection&quot;) against your application and deleting or otherwise modifying your database.</li>
<li>Execute the query by calling <a href="/d1/worker-api/prepared-statements/#run"><code>run()</code></a> to return all rows (or none, if the query returns none).</li>
<li>Return your query results, if any, in JSON format with <code>Response.json(results)</code>.</li>
</ol>
