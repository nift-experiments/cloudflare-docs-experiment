<aside class="nb-aside note">
<h3 class="nb-aside-title" id="body-12225-android-api-14-and-above">Android API 14 and above</h3>


<p>Declare the following permission in your app's AndroidManifest.xml to use screenshare on Android devices running Android API 14 and above:</p>
<pre><code>&lt;uses-permission android:name=&quot;android.permission.FOREGROUND_SERVICE_MEDIA_PROJECTION&quot; /&gt;
</code></pre>
<p>Adding this permission requires extra steps on Google Play Console. Refer to <a href="https://support.google.com/googleplay/android-developer/answer/13392821?hl=en#declare">Google's documentation</a> for more information.</p>


</aside>
