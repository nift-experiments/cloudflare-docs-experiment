

<h3 id="body-12315-update-video-constraints">Update Video Constraints</h3>

Update camera resolution while already streaming:

```jsx
meeting.self.updateVideoConstraints({
	width: { ideal: 1920 },
	height: { ideal: 1080 },
});
```

<h3 id="body-12315-update-screenshare-constraints">Update Screenshare Constraints</h3>

Update screenshare resolution while already streaming:

```jsx
meeting.self.updateScreenshareConstraints({
	width: { ideal: 1920 },
	height: { ideal: 1080 },
});
```
