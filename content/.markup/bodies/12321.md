
Initialize the RealtimeKit SDK by obtaining an instance of `RealtimeKitClient` using the `RealtimeKitMeetingBuilder` helper.

<pre><code class="language-kotlin">val meeting = RealtimeKitMeetingBuilder.build(activity)
</code></pre>


   Configure the meeting properties in the `RtkMeetingInfo` class with a valid participant `authToken` from the [Add participant API](/api/resources/realtime_kit/subresources/meetings/methods/add_participant/).

<pre><code class="language-kotlin">val meetingInfo =
  RtkMeetingInfo(
    authToken = authToken,
    enableAudio = true,
    enableVideo = true,
  )
</code></pre>


   Initialize the meeting by calling the `init()` method. This establishes a connection with the RealtimeKit meeting server.

<pre><code class="language-kotlin">meeting.init(
  meetingInfo,
  onInitCompleted = { ... },
  onInitFailed = { ... },
)
</code></pre>
