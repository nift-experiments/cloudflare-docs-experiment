

Border Width and Border Radius properties can also be customized with design tokens!

<table>
<thead>
<tr>
<th>Token Name</th>
<th>Values</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>borderWidth</code></td>
<td><code>none</code>, <code>thin</code>, <code>fat</code></td>
</tr>
<tr>
<td><code>borderRadius</code></td>
<td><code>sharp</code>, <code>rounded</code>, <code>extra-rounded</code>, <code>circular</code></td>
</tr>
</tbody>
</table>

<h4 id="body-12685-usage-4">Usage</h4>

```javascript
const designTokens = {
	borderWidth: "thin",
	borderRadius: "rounded",
};
```
