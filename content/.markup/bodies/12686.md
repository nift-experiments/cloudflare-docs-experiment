

All mobile platforms support the same border radius and border width options.

<table>
<thead>
<tr>
<th>Token</th>
<th>Values</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>borderRadius</code></td>
<td><code>sharp</code>, <code>rounded</code>, <code>extra-rounded</code>, <code>circular</code></td>
</tr>
<tr>
<td><code>borderWidth</code></td>
<td><code>none</code>, <code>thin</code>, <code>fat</code></td>
</tr>
</tbody>
</table>

<aside class="nb-aside note">


<p>iOS uses the enum value <code>extrarounded</code> (no hyphen). React Native uses the string <code>extra-rounded</code> (with a hyphen).</p>


</aside>
