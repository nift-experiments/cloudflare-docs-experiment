<h3 id="body-12695-create-webrtc-tracks-from-external-audio">Create WebRTC tracks from external audio</h3>
<p>Ingest audio from external sources via WebSocket to create WebRTC tracks for distribution.</p>
<pre><code class="language-mermaid">graph LR
    A[External System] --&gt;|Audio Data| B[WebSocket Endpoint]
    B --&gt;|Adapter| C[Realtime SFU]
    C --&gt;|New Session| D[WebRTC Track]
    D --&gt;|WebRTC| E[WebRTC Clients]
</code></pre>
<p><strong>Use cases:</strong></p>
<ul>
<li>AI text-to-speech generation streaming into WebRTC</li>
<li>Audio from backend services or databases</li>
<li>Live audio feeds from external systems</li>
</ul>
<p><strong>Key characteristics:</strong></p>
<ul>
<li>Creates a new session ID automatically</li>
<li>Uses <code>buffer</code> mode for chunked audio transmission</li>
<li>Maximum 32 KB per WebSocket message</li>
</ul>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Stream (WebRTC → WebSocket)">

<h3 id="body-12695-stream-webrtc-audio-and-video-to-external-systems">Stream WebRTC audio and video to external systems</h3>
<p>Stream audio and video from existing WebRTC tracks to external systems via WebSocket for processing or storage.</p>
<pre><code class="language-mermaid">graph LR
    A[WebRTC Source] --&gt;|WebRTC| B[Realtime SFU Session]
    B --&gt;|Adapter| C[WebSocket Endpoint]
    C --&gt;|Media Data| D[External System]
</code></pre>
<p><strong>Use cases:</strong></p>
<ul>
<li>Real-time speech-to-text transcription</li>
<li>Audio recording and archival</li>
<li>Live audio processing pipelines</li>
<li>Video snapshotting and thumbnails</li>
<li>Computer vision ingestion (low FPS)</li>
</ul>
<p><strong>Key characteristics:</strong></p>
<ul>
<li>Requires existing session ID with track</li>
<li>Audio: Sends individual PCM frames as they are produced; each includes timestamp and sequence number</li>
<li>Video: Sends individual JPEG frames at approximately 1 FPS; each includes timestamp (sequence number may be unset)</li>
<li>Automatically retries the same WebSocket endpoint for up to 5 seconds after brief disconnects or endpoint restarts. Refer to <a href="#automatic-reconnection-for-streaming">Automatic reconnection for streaming</a>.</li>
</ul>

</section>
