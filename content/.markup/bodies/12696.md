

<h4 id="body-12696-request-body">Request body</h4>

```json
{
  "tracks": [
    {
      "location": "local",
      "trackName": "string",
      "endpoint": "wss://...",
      "inputCodec": "pcm",
      "mode": "buffer"
    }
  ]
}
```

<h4 id="body-12696-parameters">Parameters</h4>

<table>
<thead>
<tr>
<th>Parameter</th>
<th>Type</th>
<th>Description</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>location</code></td>
<td>string</td>
<td><strong>Required</strong>. Must be <code>&quot;local&quot;</code> for ingesting audio</td>
</tr>
<tr>
<td><code>trackName</code></td>
<td>string</td>
<td><strong>Required</strong>. Name for the new WebRTC track to create</td>
</tr>
<tr>
<td><code>endpoint</code></td>
<td>string</td>
<td><strong>Required</strong>. WebSocket URL to receive audio from</td>
</tr>
<tr>
<td><code>inputCodec</code></td>
<td>string</td>
<td><strong>Required</strong>. Codec of incoming audio. Currently only <code>&quot;pcm&quot;</code></td>
</tr>
<tr>
<td><code>mode</code></td>
<td>string</td>
<td><strong>Required</strong>. Must be <code>&quot;buffer&quot;</code> for local mode</td>
</tr>
</tbody>
</table>

<h4 id="body-12696-response">Response</h4>

```json
{
  "tracks": [
    {
      "trackName": "string",
      "adapterId": "string",
      "sessionId": "string",    // New session ID generated
      "endpoint": "string"      // Echo of the requested endpoint
    }
  ]
}
```

<aside class="nb-aside note">
<h3 class="nb-aside-title" id="body-12696-important">Important</h3>


<ul>
<li>A new session ID is automatically generated.</li>
<li>The <code>sessionId</code> field in the request is ignored if provided.</li>
<li>Send audio in chunks up to 32 KB per WebSocket message.</li>
</ul>


</aside>
