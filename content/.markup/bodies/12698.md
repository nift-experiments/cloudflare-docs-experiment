<h4 id="body-12698-request-body">Request body</h4>
<pre><code class="language-json">{
  &quot;tracks&quot;: [
    {
      &quot;location&quot;: &quot;local&quot;,
      &quot;trackName&quot;: &quot;string&quot;,
      &quot;endpoint&quot;: &quot;wss://...&quot;,
      &quot;inputCodec&quot;: &quot;pcm&quot;,
      &quot;mode&quot;: &quot;buffer&quot;
    }
  ]
}
</code></pre>
<h4 id="body-12698-parameters">Parameters</h4>
<table>
<thead>
<tr>
<th>Parameter</th>
<th>Type</th>
<th>Description</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>location</code></td>
<td>string</td>
<td><strong>Required</strong>. Must be <code>&quot;local&quot;</code> for ingesting audio</td>
</tr>
<tr>
<td><code>trackName</code></td>
<td>string</td>
<td><strong>Required</strong>. Name for the new WebRTC track to create</td>
</tr>
<tr>
<td><code>endpoint</code></td>
<td>string</td>
<td><strong>Required</strong>. WebSocket URL to receive audio from</td>
</tr>
<tr>
<td><code>inputCodec</code></td>
<td>string</td>
<td><strong>Required</strong>. Codec of incoming audio. Currently only <code>&quot;pcm&quot;</code></td>
</tr>
<tr>
<td><code>mode</code></td>
<td>string</td>
<td><strong>Required</strong>. Must be <code>&quot;buffer&quot;</code> for local mode</td>
</tr>
</tbody>
</table>
<h4 id="body-12698-response">Response</h4>
<pre><code class="language-json">{
  &quot;tracks&quot;: [
    {
      &quot;trackName&quot;: &quot;string&quot;,
      &quot;adapterId&quot;: &quot;string&quot;,
      &quot;sessionId&quot;: &quot;string&quot;,    // New session ID generated
      &quot;endpoint&quot;: &quot;string&quot;      // Echo of the requested endpoint
    }
  ]
}
</code></pre>
<aside class="nb-aside note">
<h3 class="nb-aside-title" id="body-12698-important">Important</h3>
<ul>
<li>A new session ID is automatically generated.</li>
<li>The <code>sessionId</code> field in the request is ignored if provided.</li>
<li>Send audio in chunks up to 32 KB per WebSocket message.</li>
</ul>
</aside>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Stream">

<h4 id="body-12698-request-body-1">Request body</h4>
<pre><code class="language-json">{
  &quot;tracks&quot;: [
    {
      &quot;location&quot;: &quot;remote&quot;,
      &quot;sessionId&quot;: &quot;string&quot;,
      &quot;trackName&quot;: &quot;string&quot;,
      &quot;endpoint&quot;: &quot;wss://...&quot;,
      &quot;outputCodec&quot;: &quot;pcm&quot;
    }
  ]
}
</code></pre>
<h4 id="body-12698-parameters-1">Parameters</h4>
<table>
<thead>
<tr>
<th>Parameter</th>
<th>Type</th>
<th>Description</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>location</code></td>
<td>string</td>
<td><strong>Required</strong>. Must be <code>&quot;remote&quot;</code> for streaming media out</td>
</tr>
<tr>
<td><code>sessionId</code></td>
<td>string</td>
<td><strong>Required</strong>. Existing session ID containing the track</td>
</tr>
<tr>
<td><code>trackName</code></td>
<td>string</td>
<td><strong>Required</strong>. Name of the existing track to stream</td>
</tr>
<tr>
<td><code>endpoint</code></td>
<td>string</td>
<td><strong>Required</strong>. WebSocket URL to send media to</td>
</tr>
<tr>
<td><code>outputCodec</code></td>
<td>string</td>
<td><strong>Required</strong>. Codec for outgoing media. Use <code>&quot;pcm&quot;</code> for audio, <code>&quot;jpeg&quot;</code> for video (egress only)</td>
</tr>
</tbody>
</table>
<h4 id="body-12698-response-1">Response</h4>
<pre><code class="language-json">{
  &quot;tracks&quot;: [
    {
      &quot;trackName&quot;: &quot;string&quot;,
      &quot;adapterId&quot;: &quot;string&quot;,
      &quot;sessionId&quot;: &quot;string&quot;,    // Same as request sessionId
      &quot;endpoint&quot;: &quot;string&quot;      // Echo of the requested endpoint
    }
  ]
}
</code></pre>
<aside class="nb-aside note">
<h3 class="nb-aside-title" id="body-12698-important-1">Important</h3>
<ul>
<li>Requires an existing session with the specified track.</li>
<li>Audio frames are sent individually with timestamp and sequence number.</li>
<li>Video frames are sent individually as JPEG at approximately 1 FPS with timestamp; sequence number may be unset.</li>
<li>Each frame is a separate WebSocket message.</li>
<li>No mode parameter; frames are sent as produced.</li>
<li>The SFU automatically retries the same WebSocket endpoint for up to 5 seconds after brief disconnects.</li>
</ul>
</aside>
