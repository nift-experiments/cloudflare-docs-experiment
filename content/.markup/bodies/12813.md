

**Context:**

You configured a Page Rule to perform an automatic redirect from HTTP to HTTPS for all subdomains of `example.com` and the `example.com` domain itself:

- **URL** `*example.com/*`
- **Setting**: _Always Use HTTPS_

**How to migrate**:

<div class="nb-steps">

<ol>
<li><a href="/rules/url-forwarding/single-redirects/create-dashboard/">Create a single redirect</a> to always redirect HTTP requests to HTTPS. You can select the <strong>Redirect from HTTP to HTTPS</strong> rule template or enter the following rule configuration:</li>
</ol>
<ul>
<li><strong>If incoming requests match</strong>: Wildcard pattern
<ul>
<li><strong>Request URL</strong>: <code>http://*</code></li>
</ul>
</li>
<li><strong>Then</strong>:
<ul>
<li><strong>Target URL</strong>: <code>https://${1}</code></li>
<li><strong>Status code</strong>: <em>301</em></li>
<li><strong>Preserve query string</strong>: Enabled</li>
</ul>
</li>
</ul>
<ol start="2">
<li>
<p>Turn off your existing Page Rule and validate the behavior of the redirect you created.</p>
</li>
<li>
<p>If your tests succeed, delete the existing Page Rule.</p>
</li>
</ol>

</div>
