<p><strong>Context:</strong></p>
<p>You configured a Page Rule permanently redirecting <code>example.com/old-path</code> to <code>example.com/new-path</code>:</p>
<ul>
<li><strong>URL</strong>: <code>example.com/old-path/*</code></li>
<li><strong>Setting</strong>: <em>Forwarding URL</em></li>
<li><strong>Select Status code</strong>: <em>301 - Permanent Redirect</em></li>
<li><strong>Destination URL</strong>: <code>https://example.com/new-path/$1</code></li>
</ul>
<p><strong>How to migrate</strong>:</p>
<div class="nb-steps">
<ol>
<li><a href="/rules/url-forwarding/single-redirects/create-dashboard/">Create a single redirect</a> to permanently redirect requests for <code>example.com/old-path</code> to <code>example.com/new-path</code>:</li>
</ol>
<ul>
<li><strong>If incoming requests match</strong>: Wildcard pattern
<ul>
<li><strong>Request URL</strong>: <code>https://example.com/old-path/*</code></li>
</ul>
</li>
<li><strong>Then</strong>:
<ul>
<li><strong>Target URL</strong>: <code>https://example.com/new-path/${1}</code></li>
<li><strong>Status code</strong>: <em>301</em></li>
<li><strong>Preserve query string</strong>: Enabled</li>
</ul>
</li>
</ul>
<ol start="2">
<li>
<p>Turn off your existing Page Rule and validate the behavior of the redirect you created.</p>
</li>
<li>
<p>If your tests succeed, delete the existing Page Rule.</p>
</li>
</ol>
</div>
<details class="nb-details"><summary>Notes about the rule equivalence</summary><div class="nb-details-body">
<p>The provided example using Single Redirects is not an exact match for the previously existing Page Rule in the same example.</p>
<p>The exact equivalent would need to match both HTTP and HTTPS incoming requests, which you could achieve using a wildcard pattern like the following (notice the extra <code>*</code> after <code>http</code>):</p>
<ul>
<li><strong>Request URL</strong>: <code>http*://example.com/old-path/*</code></li>
</ul>
<p>This would require you to also change the <strong>Target URL</strong> to use the second wildcard capture group instead of the first one (corresponding to the text captured by second <code>*</code> in the wildcard pattern above):</p>
<ul>
<li><strong>Target URL</strong>: <code><a href="https://example.com/new-path/$%7B2%7D">https://example.com/new-path/${2}</a></code></li>
</ul>
</div></details>
