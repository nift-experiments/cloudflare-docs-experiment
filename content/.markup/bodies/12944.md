

To create a page rule in the dashboard:

<div class="nb-steps">

<ol>
<li>In the Cloudflare dashboard, go to the <strong>Page Rules</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select <strong>Create Page Rule</strong>.</li>
<li>For <strong>URL</strong>, enter the URL or URL pattern that should match the rule (<a href="/rules/page-rules/reference/wildcard-matching/">more details about wildcard matching</a>).</li>
<li>For <strong>Pick a Setting</strong>, select a <a href="/rules/page-rules/reference/settings/">Cloudflare setting</a> to adjust. If desired, select <strong>Add a Setting</strong> to adjust multiple Cloudflare settings with the same rule.</li>
<li>In the <strong>Order</strong> dropdown, specify the desired order: <em>First, Last</em> or <em>Custom</em>.</li>
<li>To save and deploy your rule, select <strong>Save and Deploy Page Rule</strong>. If you are not ready to deploy your rule, select <strong>Save as Draft</strong>.</li>
</ol>
<p>If you are matching a hostname in your rule expression, you may be prompted to create a proxied DNS record for that hostname. Refer to <a href="/rules/reference/troubleshooting/#this-rule-may-not-apply-to-your-traffic">Troubleshooting</a> for more information.</p>

</div>

For ideas about what rules you can create, refer to [Recommended page rules](/rules/page-rules/reference/recommended-rules/).
