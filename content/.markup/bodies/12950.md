<p>To edit a page rule in the dashboard:</p>
<div class="nb-steps">
<ol>
<li>In the Cloudflare dashboard, go to the <strong>Page Rules</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>For a specific rule:</li>
</ol>
<ul>
<li>To enable or disable the rule, select the on/off toggle.</li>
<li>To modify the URL pattern, settings, and order, select <strong>Edit</strong> (wrench icon). Then, enter the information you want to change.</li>
</ul>
</div>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To update one or more fields using the API, send a <a href="/api/resources/page_rules/methods/edit/"><code>PATCH</code> request</a>.</p>
<p>To entirely replace the configuration of a page rule, send a <a href="/api/resources/page_rules/methods/update/"><code>PUT</code> request</a>.</p>
