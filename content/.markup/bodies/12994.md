

To edit a zone-level custom error page:

<div class="nb-steps">

<ol>
<li>In the Cloudflare dashboard, go to the <strong>Error Pages</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Identify your desired custom error page type.</li>
<li>(Optional) To preview the current error page (default or custom), select the link in the <strong>Show</strong> column.</li>
<li>To edit the error page, select the three dots &gt; <strong>Edit</strong> next to the page type you previously identified.</li>
<li>To use Cloudflare's default page, select <strong>Cloudflare default page.</strong> To provide a custom error page, select <strong>Custom page</strong> and enter the URL of the custom error page you created.</li>
<li>Select <strong>Confirm</strong>.</li>
</ol>

</div>
