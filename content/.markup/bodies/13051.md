<p>The following example rule will configure Gzip compression as the preferred compression method for CSV files. If the visitor does not support this algorithm, Cloudflare will try to compress the response using a different algorithm supported by the visitor.</p>
<div class="nb-example"><h3 class="nb-component-title" id="body-13051-example">Example</h3>
<p><strong>When incoming requests match</strong></p>
<ul>
<li>Custom filter expression:</li>
<li><em>File extension</em> <em>equals</em> <code>csv</code></li>
</ul>
<p><strong>Then</strong></p>
<ul>
<li><strong>Compression options</strong>: Custom</li>
<li><strong>Define a custom order for compression types</strong>: <code>Gzip</code>, <code>Auto</code></li>
</ul>
</div>

<p>The following example sets the rules of an existing <a href="/ruleset-engine/about/rulesets/#entry-point-ruleset">entry point ruleset</a> (with ID <code>{ruleset_id}</code>) for the <code>http_response_compression</code> phase to a single compression rule, using the <a href="/api/resources/rulesets/methods/update/">Update a zone ruleset</a> operation:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request PUT \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/rulesets/{ruleset_id} \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;rules&quot;: [
  {
    &quot;ref&quot;: &quot;use_gzip_for_csv&quot;,
    &quot;expression&quot;: &quot;http.request.uri.path.extension eq \&quot;csv\&quot;&quot;,
    &quot;action&quot;: &quot;compress_response&quot;,
    &quot;action_parameters&quot;: {
      &quot;algorithms&quot;: [
        {
          &quot;name&quot;: &quot;gzip&quot;
        },
        {
          &quot;name&quot;: &quot;auto&quot;
        }
      ]
    }
  }
]
}&#x27;</code></pre>
<p>Use the <code>ref</code> field to get stable rule IDs across updates when using Terraform. Adding this field prevents Terraform from recreating the rule on changes. For more information, refer to <a href="/terraform/troubleshooting/rule-id-changes/#how-to-keep-the-same-rule-id-between-modifications">Troubleshooting</a> in the Terraform documentation.</p>
