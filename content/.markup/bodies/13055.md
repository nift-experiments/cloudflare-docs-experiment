<p>The following example rule will turn on Zstandard compression for response content types where <a href="/speed/optimization/content/compression/">Cloudflare applies compression by default</a>. If the client does not support Zstandard compression, it will use Brotli or Gzip compression as a fallback.</p>
<div class="nb-example"><h3 class="nb-component-title" id="body-13055-example">Example</h3>
<p><strong>When incoming requests match</strong></p>
<ul>
<li>Custom filter expression:</li>
<li><em>Media Type</em> <em>is in</em> <code>text/html, text/richtext, text/plain, text/css, text/x-script, text/x-component, text/x-java-source, text/x-markdown, application/javascript, application/x-javascript, text/javascript, text/js, image/x-icon, image/vnd.microsoft.icon, application/x-perl, application/x-httpd-cgi, text/xml, application/xml, application/rss+xml, application/vnd.api+json, application/x-protobuf, application/json, multipart/bag, multipart/mixed, application/xhtml+xml, font/ttf, font/otf, font/x-woff, image/svg+xml, application/vnd.ms-fontobject, application/ttf, application/x-ttf, application/otf, application/x-otf, application/truetype, application/opentype, application/x-opentype, application/font-woff, application/eot, application/font, application/font-sfnt, application/wasm, application/javascript-binast, application/manifest+json, application/ld+json, application/graphql+json, application/geo+json</code></li>
</ul>
<p><strong>Then</strong></p>
<ul>
<li><strong>Compression options</strong>: Custom</li>
<li><strong>Define a custom order for compression types</strong>: <code>Zstandard</code>, <code>Brotli</code>, <code>Gzip</code></li>
</ul>
</div>

<p>The following example sets the rules of an existing <a href="/ruleset-engine/about/rulesets/#entry-point-ruleset">entry point ruleset</a> (with ID <code>{ruleset_id}</code>) for the <code>http_response_compression</code> phase to a single compression rule, using the <a href="/api/resources/rulesets/methods/update/">Update a zone ruleset</a> operation:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request PUT \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/rulesets/{ruleset_id} \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;rules&quot;: [
  {
    &quot;ref&quot;: &quot;use_zstd_compression&quot;,
    &quot;expression&quot;: &quot;(http.response.content_type.media_type in {\&quot;text/html\&quot; \&quot;text/richtext\&quot; \&quot;text/plain\&quot; \&quot;text/css\&quot; \&quot;text/x-script\&quot; \&quot;text/x-component\&quot; \&quot;text/x-java-source\&quot; \&quot;text/x-markdown\&quot; \&quot;application/javascript\&quot; \&quot;application/x-javascript\&quot; \&quot;text/javascript\&quot; \&quot;text/js\&quot; \&quot;image/x-icon\&quot; \&quot;image/vnd.microsoft.icon\&quot; \&quot;application/x-perl\&quot; \&quot;application/x-httpd-cgi\&quot; \&quot;text/xml\&quot; \&quot;application/xml\&quot; \&quot;application/rss+xml\&quot; \&quot;application/vnd.api+json\&quot; \&quot;application/x-protobuf\&quot; \&quot;application/json\&quot; \&quot;multipart/bag\&quot; \&quot;multipart/mixed\&quot; \&quot;application/xhtml+xml\&quot; \&quot;font/ttf\&quot; \&quot;font/otf\&quot; \&quot;font/x-woff\&quot; \&quot;image/svg+xml\&quot; \&quot;application/vnd.ms-fontobject\&quot; \&quot;application/ttf\&quot; \&quot;application/x-ttf\&quot; \&quot;application/otf\&quot; \&quot;application/x-otf\&quot; \&quot;application/truetype\&quot; \&quot;application/opentype\&quot; \&quot;application/x-opentype\&quot; \&quot;application/font-woff\&quot; \&quot;application/eot\&quot; \&quot;application/font\&quot; \&quot;application/font-sfnt\&quot; \&quot;application/wasm\&quot; \&quot;application/javascript-binast\&quot; \&quot;application/manifest+json\&quot; \&quot;application/ld+json\&quot; \&quot;application/graphql+json\&quot; \&quot;application/geo+json\&quot;})&quot;,

For more information, refer to <a href="/terraform/troubleshooting/rule-id-changes/#how-to-keep-the-same-rule-id-between-modifications">Troubleshooting</a> in the Terraform documentation.</p>
