

The following example rule will disable Brotli compression for all incoming requests of a given zone. The only available compression algorithm will be Gzip.

<div class="nb-example"><h3 class="nb-component-title" id="body-13061-example">Example</h3>

<p><strong>When incoming requests match</strong></p>
<ul>
<li>All incoming requests</li>
</ul>
<p><strong>Then</strong></p>
<ul>
<li><strong>Compression options</strong>: Custom</li>
<li><strong>Define a custom order for compression types</strong>: <code>Gzip</code></li>
</ul>

</div>

If the client does not support Gzip compression, the response will be uncompressed.
