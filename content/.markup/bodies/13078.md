

1. In the Cloudflare dashboard, go to the Rules **Overview** page.

<div class="nb-dash-button"></div>

2. Select **Create rule** > **URL Rewrite Rule**.
3. Enter a descriptive name for the rule in **Rule name**.
4. Under **If incoming requests match**, select **Custom filter expression**, select **Edit expression**, and enter the following expression:

<div class="nb-example"><h3 class="nb-component-title" id="body-13078-example">Example</h3>

<p>Text in <strong>Expression Editor</strong>:</p>
<pre><code class="language-txt">raw.http.request.uri.path matches &quot;^/uploads/.*&quot;
</code></pre>

</div>

5. Under **Set Rewrite parameters**, select **Path** > **Rewrite to**, and select _Dynamic_.

6. Define the action for your rewrite URL rule:

<div class="nb-example"><h3 class="nb-component-title" id="body-13078-example-1">Example</h3>

<p>Text after <strong>Path</strong> &gt; <strong>Rewrite to</strong> &gt; <em>Dynamic</em>:</p>
<pre><code class="language-txt">regex_replace(raw.http.request.uri.path, &quot;^/uploads/&quot;, &quot;/&quot;)
</code></pre>

</div>

The [`regex_replace()`](/ruleset-engine/rules-language/functions/#regex_replace) function replaces the `/uploads/` part of the path with `/`, changing `/uploads/example.jpg` to `/example.jpg`.

7. Select **Deploy**.
