

1. In the Cloudflare dashboard, go to the Rules **Overview** page.

<div class="nb-dash-button"></div>

2. Select **Create rule** > **Origin Rule**.
3. Enter a descriptive name for the rule in **Rule name**.
4. Under **When incoming requests match**, define the rule expression:

<div class="nb-example"><h3 class="nb-component-title" id="body-13082-example">Example</h3>

<p>Text in <strong>Expression Editor</strong>:</p>
<pre><code class="language-txt">raw.http.request.uri.path matches &quot;^/uploads/.*&quot;
</code></pre>

</div>

5. Under **Set origin parameters**, select **Host Header** > **Rewrite to**.

6. Configure the rule to modify the `Host` header to desired hostname:

<div class="nb-example"><h3 class="nb-component-title" id="body-13082-example-1">Example</h3>

<p>Text after <strong>Host Header</strong> &gt; <strong>Rewrite to</strong>:</p>
<pre><code class="language-txt">example.com
</code></pre>

</div>

This will set the [`Host` header](/rules/origin-rules/features/#host-header) to `example.com` for matching requests. Make sure to replace `example.com` with your actual hostname.

7. (Optional) To route requests to a different origin (DNS target), use [DNS override](/rules/origin-rules/features/#dns-record):

<div class="nb-example"><h3 class="nb-component-title" id="body-13082-example-2">Example</h3>

<p>Text after <strong>DNS Record</strong> &gt; <strong>Override to</strong>:</p>
<pre><code class="language-txt">example.com
</code></pre>

</div>

This will route requests to the DNS target of `example.com` instead of your default [DNS record](/dns/manage-dns-records/how-to/create-dns-records/).

8. Select **Deploy**.
