<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>The following example sets the rules of an existing phase ruleset (<code>$RULESET_ID</code>) to a single origin rule — overriding the port of incoming requests — using the <a href="/api/resources/rulesets/methods/update/">Update a zone ruleset</a> operation. The response will contain the complete definition of the ruleset you updated.</p>
<pre class="nb-api-request"><code class="language-bash">curl --request PUT \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/rulesets/{ruleset_id} \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;rules&quot;: [
  {
    &quot;ref&quot;: &quot;calendar_app_change_port&quot;,
    &quot;expression&quot;: &quot;starts_with(http.request.uri.path, \&quot;/team/calendar/\&quot;)&quot;,
    &quot;description&quot;: &quot;Origin rule for the team calendar application&quot;,
    &quot;action&quot;: &quot;route&quot;,
    &quot;action_parameters&quot;: {
      &quot;origin&quot;: {
        &quot;port&quot;: 8081
      }
    }
  }
]
}&#x27;</code></pre>
<pre><code class="language-json">{
	&quot;result&quot;: {
		&quot;id&quot;: &quot;&lt;RULESET_ID&gt;&quot;,
		&quot;name&quot;: &quot;Origin Rules ruleset&quot;,
		&quot;description&quot;: &quot;Zone-level ruleset that will execute origin rules.&quot;,
		&quot;kind&quot;: &quot;zone&quot;,
		&quot;version&quot;: &quot;2&quot;,
		&quot;rules&quot;: [
			{
				&quot;ref&quot;: &quot;calendar_app_change_port&quot;,
				&quot;id&quot;: &quot;&lt;RULE_ID&gt;&quot;,
				&quot;version&quot;: &quot;1&quot;,
				&quot;action&quot;: &quot;route&quot;,
				&quot;action_parameters&quot;: {
					&quot;origin&quot;: {
						&quot;port&quot;: 8081
					}
				},
				&quot;expression&quot;: &quot;starts_with(http.request.uri.path, \&quot;/team/calendar/\&quot;)&quot;,
				&quot;description&quot;: &quot;Origin rule for the team calendar application&quot;,
				&quot;last_updated&quot;: &quot;2022-06-03T14:42:04.219025Z&quot;,
				&quot;ref&quot;: &quot;&lt;RULE_REF&gt;&quot;
			}
		],
		&quot;last_updated&quot;: &quot;2022-06-03T14:42:04.219025Z&quot;,
		&quot;phase&quot;: &quot;http_request_origin&quot;
	},
	&quot;success&quot;: true,
	&quot;errors&quot;: [],
	&quot;messages&quot;: []
}
</code></pre>
<p>Use the <code>ref</code> field to get stable rule IDs across updates when using Terraform. Adding this field prevents Terraform from recreating the rule on changes. For more information, refer to <a href="/terraform/troubleshooting/rule-id-changes/#how-to-keep-the-same-rule-id-between-modifications">Troubleshooting</a> in the Terraform documentation.</p>
