

<details class="nb-details"><summary>Required API token permissions</summary><div class="nb-details-body">

<p>All of the following <a href="/fundamentals/api/reference/permissions/">token permissions</a> are required:</p>
<ul>
<li><code>Managed headers Write</code></li>
<li><code>Account Rulesets Read</code></li>
</ul>

</div></details>

Configure the [`cloudflare_managed_transforms`](https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/managed_transforms) resource:

```tf
resource "cloudflare_managed_transforms" "tf_example" {
  zone_id = var.cloudflare_zone_id

  managed_request_headers = [{
    id      = "add_visitor_location_headers"
    enabled = true
  }]

  managed_response_headers = [{
    id      = "remove_x-powered-by_header"
    enabled = true
  }]
}
```
