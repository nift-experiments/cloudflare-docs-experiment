<p>All of the following <a href="/fundamentals/api/reference/permissions/">token permissions</a> are required:</p>
<ul>
<li><code>Managed headers Write</code></li>
<li><code>Account Rulesets Read</code></li>
</ul>

<p>Configure the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/managed_transforms"><code>cloudflare_managed_transforms</code></a> resource:</p>
<pre><code class="language-tf">resource &quot;cloudflare_managed_transforms&quot; &quot;tf_example&quot; {
  zone_id = var.cloudflare_zone_id
<p>managed_request_headers = [{
id      = &quot;add_visitor_location_headers&quot;
enabled = true
}]</p>
<p>managed_response_headers = [{
id      = &quot;remove_x-powered-by_header&quot;
enabled = true
}]
}
</code></pre></p>
</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Terraform (v4)">
<pre><code class="language-tf">resource &quot;cloudflare_managed_headers&quot; &quot;tf_example&quot; {
  zone_id = &quot;&lt;ZONE_ID&gt;&quot;

  managed_request_headers {
    id      = &quot;add_visitor_location_headers&quot;
    enabled = true
  }

  managed_response_headers {
    id      = &quot;remove_x-powered-by_header&quot;
    enabled = true
  }
}
</code></pre>

Make sure you include the Managed Transforms you are updating in the correct object (`managed_request_headers` or `managed_response_headers`).
