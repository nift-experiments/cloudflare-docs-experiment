<p><strong>1. Get list of available Managed Transforms</strong></p>
<p>Check the Managed Transform's current status and availability using the <a href="/api/resources/managed_transforms/methods/list/">List Managed Transforms</a> operation.</p>
<p>The following example request obtains a list of available Managed Transforms, organized by request or response, with information about their current status (<code>enabled</code> field) and if you can update them, based on conflicts with other enabled Managed Transforms (<code>has_conflict</code> field).</p>
<p>Each Managed Transform item will optionally contain a <code>conflicts_with</code> array informing you about any Managed Transforms that will conflict with the current Managed Transform when enabled.</p>
<p>The response will only include available Managed Transforms according to your Cloudflare plan and product subscriptions.</p>

<p><strong>2. Change the status of Managed Transforms</strong></p>
<p>Change the status of the <a href="/rules/transform/managed-transforms/reference/">desired Managed Transforms</a> using the <a href="/api/resources/managed_transforms/methods/edit/">Update status of Managed Transforms</a> operation.</p>
<p>Add the Managed Transforms you wish to change to the request body, and update their status in the <code>enabled</code> field. You cannot enable a Managed Transform that has a conflict with a currently enabled Managed Transform (that is, an item where <code>has_conflict</code> is <code>true</code>).</p>
<p>Make sure you include the Managed Transforms you are updating in the correct JSON object (<code>managed_request_headers</code> or <code>managed_response_headers</code>).</p>
<p>The response will include all the available Managed Transforms and their new status after the update.</p>
<pre class="nb-api-request"><code class="language-bash">curl --request PATCH \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/managed_headers \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;managed_request_headers&quot;: [
  {
    &quot;id&quot;: &quot;add_visitor_location_headers&quot;,
    &quot;enabled&quot;: true
  }
],
&quot;managed_response_headers&quot;: [
  {
    &quot;id&quot;: &quot;remove_x-powered-by_header&quot;,
    &quot;enabled&quot;: true

]
}&#x27;</code></pre>
