

**When incoming requests match**

- **Field:** _URI Path_
- **Operator:** _equals_
- **Value:** `/contact-us/`

If you are using the Expression Editor, enter the following expression:<br/>
`http.request.uri.path eq "/contact-us/"`

**Then**

- **Type:** _Static_
- **URL:** `/contacts/`
- **Status code:** _301_
- **Preserve query string:** Enabled
