
1. In the Cloudflare dashboard, go to the **Bulk redirects** page.

<div class="nb-dash-button"></div>

2. Under **Bulk Redirect Lists**, select **Create Bulk Redirect List**.
3. Enter a list name and description, and select **Next**.
4. You can import a CSV file containing several URL redirects or enter URL redirects one at a time in the dashboard.

<aside class="nb-aside note">


<p>The source URL of each redirect cannot include a query string. For more information, refer to the <a href="/rules/url-forwarding/bulk-redirects/reference/url-components/">supported URL components</a>.</p>


</aside>

<details class="nb-details"><summary>Import a CSV file</summary><div class="nb-details-body">

<ol>
<li>Drag and drop a CSV file containing URL redirects or select <strong>browse</strong> and select a CSV file. For more information on the file format, refer to <a href="/rules/url-forwarding/bulk-redirects/reference/csv-file-format/">CSV file format for Bulk Redirects</a>.</li>
<li>The dashboard will display the URL redirects that were successfully imported from the file. You can manually adjust the displayed records or add/remove URL redirects before proceeding.</li>
<li>Select <strong>Next</strong>.</li>
</ol>

</div></details>

<details class="nb-details"><summary>Add URL redirects manually</summary><div class="nb-details-body">

<ol>
<li>Select <strong>Or, manually add URL redirects</strong>.</li>
<li>Enter the URL redirects you wish to add to the list. You must enter at least the following three fields: <strong>Source URL</strong>, <strong>Target URL</strong>, and <strong>Status</strong>. To set additional options, expand <strong>Edit parameters</strong>.</li>
<li>Add more URL redirects, if required.</li>
<li>Select <strong>Next</strong>.</li>
</ol>

</div></details>

5. Review and edit the URL redirects you imported or created, and select **Next**.
6. Select **Continue to Redirect Rules** to go to the rule creation page, and follow the instructions in the next section. You must create a Bulk Redirect Rule to enable the URL redirects you defined.
