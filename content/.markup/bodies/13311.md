
1. **Create an OpenAI agent.** Set your OpenAI API key, then create an agent:

```bash
export OPENAI_API_KEY="<OPENAI_API_KEY>"
```

<pre><code class="language-bash">curl --request POST --url https://api.openai.com/v1/agents</code></pre>

Copy the `id` field from the response and save it as the agent ID:

```bash
export OPENAI_AGENT_ID="agent_..."
```

2. **Deploy the worker and container.** Generate and save a shared secret for the container cleanup endpoint:

<pre><code class="language-bash">openssl rand -hex 32
</code></pre>


Select **Deploy to Cloudflare**:

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/cloudflare/sandbox-sdk/tree/main/openai/agents-api)

Enter these values when prompted:

<table>
<thead>
<tr>
<th>Variable</th>
<th>Value</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>OPENAI_API_KEY</code></td>
<td>The OpenAI key used to retrieve session state</td>
</tr>
<tr>
<td><code>OPENAI_EXECUTOR_API_KEY</code></td>
<td>The restricted executor key</td>
</tr>
<tr>
<td><code>OPENAI_AGENT_ID</code></td>
<td>The agent ID created above</td>
</tr>
<tr>
<td><code>OPENAI_WEBHOOK_SECRET</code></td>
<td><code>pending-webhook-registration</code> for the first deployment</td>
</tr>
<tr>
<td><code>EXECUTOR_CLIENT_SECRET</code></td>
<td>The shared secret generated above</td>
</tr>
</tbody>
</table>

Save the deployed Worker URL:

<pre><code class="language-bash">export WORKER_URL=&quot;https://&lt;YOUR_WORKER&gt;.workers.dev&quot;
</code></pre>


The container stays available for 30 seconds (configurable via `EXECUTOR_KEEP_ALIVE_SECONDS`). Prewarming and idle snapshots are enabled by default.

3. **Register the webhook.** In [OpenAI project webhook settings](https://platform.openai.com/settings/project/webhooks), register the publicly reachable endpoint `https://<YOUR_WORKER>.workers.dev/webhook`.

Subscribe to these events:
- `agent.session.created`
- `agent.session.action_required`
- `agent.session.in_progress`
- `agent.session.idle`
- `agent.session.failed`

Copy the signing secret returned by OpenAI. Replace `OPENAI_WEBHOOK_SECRET` in the Worker's **Settings** &gt; **Variables and Secrets**, then select **Deploy**. If you used manual deployment, set it with Wrangler from the Cloudflare template directory:

<pre><code class="language-bash">npx wrangler secret put OPENAI_WEBHOOK_SECRET
</code></pre>


Verify the setup:

<pre><code class="language-bash">curl --fail-with-body &quot;$WORKER_URL/health&quot;
</code></pre>


The Worker is ready for this guide when the response contains both `"configured": true` and `"webhook_configured": true`.

4. **Run a test task.** Create a self-hosted session:

<pre><code class="language-bash">curl --request POST --url https://api.openai.com/v1/agents/sessions</code></pre>

Copy the `id` field from the response and save it as the session ID:

```bash
export SESSION_ID="sess_..."
```

Open the session event stream in one terminal:

```bash
curl --no-buffer \
  "https://api.openai.com/v1/agents/sessions/$SESSION_ID/events" \
  --header "OpenAI-Beta: agents=v1" \
  --header "Authorization: Bearer $OPENAI_API_KEY" \
  --header "Accept: text/event-stream"
```

While the stream is open, submit a task from another terminal:

<pre><code class="language-bash">curl --request POST --url https://api.openai.com/v1/agents/sessions/$SESSION_ID/events</code></pre>

The event stream shows the agent's progress and response.
