This page documents command execution on today's stable `@cloudflare/sandbox` package.

**Sandbox SDK 1.0** (preview on `@cloudflare/sandbox@next`) uses argv `exec()` and process handles instead of string `exec` / `startProcess` / `execStream`. Refer to [Process execution](/sandbox/1-0-preview/processes/), the [Processes API](/sandbox/1-0-preview/api/processes/), or [migrate to the preview](/sandbox/1-0-preview/migrate/).
