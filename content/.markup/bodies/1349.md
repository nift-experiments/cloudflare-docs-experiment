
1. In the Cloudflare dashboard, go to the **Web assets** page.

<div class="nb-dash-button"></div>

2. Select the **Client-side resources** tab.
3. Review the list of detected scripts, checking for any unknown or unexpected scripts. [Depending on your plan and subscriptions](/client-side-security/#availability), Cloudflare will also:
- Inform you if a script is [considered malicious](/client-side-security/how-it-works/malicious-script-detection/).
- [Show the details](/client-side-security/detection/monitor-connections-scripts/#view-details) about each detected script.
