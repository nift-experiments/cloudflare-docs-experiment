

<aside class="nb-aside note">


<p>A secret <code>name</code> cannot contain spaces. Refer to <a href="/api/resources/secrets_store/">Secrets Store API</a> for the full API documentation.</p>


</aside>

```bash
curl https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/secrets_store/stores/$STORE_ID/secrets/$SECRET_ID/duplicate \
--header "Authorization: Bearer $CLOUDFLARE_API_TOKEN" \
--header "Content-Type: application/json" \
--data '{
    "name":"<NEW_DUPLICATE_NAME>",
    "scopes":["workers"],
    "comment":""
}'
```
