

You can find and copy the store ID from the [Secrets Store tab](https://dash.cloudflare.com/?to=/:account/secrets-store/) on the dashboard or use the [Wrangler command](/workers/wrangler/commands/secrets-store/#secrets-store-store). Also, make sure your secret `name` does not contain spaces.

Refer to [Secrets Store API](/api/resources/secrets_store/) for the full API documentation.

--url https://api.cloudflare.com/client/v4/accounts/{account_id}/secrets_store/stores/{store_id}/secrets \

--data &#x27;[
{
  &quot;name&quot;: &quot;&lt;MY_SECRET_NAME&gt;&quot;,
  &quot;value&quot;: &quot;&lt;SECRET_VALUE&gt;&quot;,
