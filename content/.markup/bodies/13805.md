<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Wrangler">

<p>Use the <a href="/workers/wrangler/commands/secrets-store/#secrets-store-secret">Wrangler command</a> <code>secrets-store secret create</code>.</p>
<p>To use the following example, replace the store ID and secret name by your actual data. You can find and copy the store ID from the <a href="https://dash.cloudflare.com/?to=/:account/secrets-store/">Secrets Store tab</a> on the dashboard or use <code>wrangler secrets-store store list</code>.</p>
<p>Note that a secret name cannot contain spaces.</p>
<pre><code class="language-sh">npx wrangler secrets-store secret create &lt;STORE_ID&gt; --name MY_SECRET_NAME --scopes workers --remote
</code></pre>
<pre><code class="language-sh">✓ Enter a secret value: › ***

✓ Select an account: › My account
✅ Created secret! (ID: 13bc7498c6374a4e9d13be091c3c65f1)
</code></pre>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the Cloudflare dashboard, go to the <strong>Secrets Store</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select <strong>Create secret</strong>.</li>
<li>Fill in the required fields, choosing <em>Workers</em> as the <strong>Permission scope</strong>. Once the secret is saved, the secret value will no longer be available for viewing.</li>
<li>(Optional) Select <strong>Add additional secret</strong> to create more than one secret at a time.</li>
<li>Select <strong>Save</strong> to confirm.</li>
</ol>
