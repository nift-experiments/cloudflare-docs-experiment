

Use the following `PATCH` request to enable Speed Brain:



<pre class="nb-api-request"><code class="language-bash">curl --request PATCH \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/settings/speed_brain \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;value&quot;: &quot;on&quot;
}&#x27;</code></pre>



To disable Speed Brain, set `value:` to `"off"`.
