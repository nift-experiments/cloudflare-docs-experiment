<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<p>To enable or disable <strong>Speed Brain</strong> in the dashboard:</p>
<ol>
<li>In the Cloudflare dashboard, go to the <strong>Speed</strong> &gt; <strong>Settings</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Go to <strong>Content Optimization</strong>.</li>
<li>Toggle <strong>Speed Brain</strong> to <strong>On</strong> or <strong>Off</strong>.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Use the following <code>PATCH</code> request to enable Speed Brain:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request PATCH \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/settings/speed_brain \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;value&quot;: &quot;on&quot;
}&#x27;</code></pre>
<p>To disable Speed Brain, set <code>value:</code> to <code>&quot;off&quot;</code>.</p>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Terraform">

<p>You can also configure Speed Brain using Terraform. For more details, refer to the <code>cloudflare_zone_settings_override</code> resource in the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs">Terraform documentation</a>.</p>
