<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<p>To enable shared dictionaries in the dashboard:</p>
<ol>
<li>In the Cloudflare dashboard, go to the Speed <strong>Settings</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Go to <strong>Content Optimization</strong>.</li>
<li>Toggle <strong>Shared Dictionaries</strong> to <strong>On</strong>.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Use the following <code>PATCH</code> request to enable shared dictionaries:</p>
<pre><code class="language-bash">curl --request PATCH --url https://api.cloudflare.com/client/v4/zones/$ZONE_ID/settings/shared_dictionary_mode</code></pre>
<p>To turn shared dictionaries off, set <code>value</code> to <code>&quot;disabled&quot;</code>.</p>
<p>Valid values for this setting are:</p>
<table>
<thead>
<tr>
<th>Value</th>
<th>Behavior</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>passthrough</code></td>
<td>Cloudflare forwards shared dictionary request and response headers, accepts <code>dcb</code>/<code>dcz</code> responses from the origin, and varies cache entries.</td>
</tr>
<tr>
<td><code>disabled</code></td>
<td>Cloudflare strips shared dictionary headers and does not cache <code>dcb</code>/<code>dcz</code> variants.</td>
</tr>
</tbody>
</table>
