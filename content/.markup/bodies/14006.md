CAA records are inherited. This means that, if you are using a [subdomain setup](/dns/zone-setups/subdomain-setup/) -  with `subdomain.example.com` on Cloudflare but `example.com` on a different DNS provider -, you should make sure that the parent domain (`example.com`) either has CAA records that allow [Cloudflare's partner CAs](/ssl/reference/certificate-authorities/), or has no CAA records at all.
