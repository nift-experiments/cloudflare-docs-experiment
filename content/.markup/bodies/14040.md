<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the Cloudflare dashboard, go to the <strong>Client Certificates</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select <strong>Add Certificate</strong>.</li>
<li>In the <strong>Certificate Authority</strong> dropdown, select <strong>Bring your own CA</strong>.</li>
<li>Upload your CA certificate file (PEM encoded) and enter a name for the CA.</li>
<li>Select <strong>Continue</strong>.</li>
<li>On the <strong>Associate Hostnames</strong> page, enter the hostname that should use this CA for mTLS validation and select <strong>Add</strong> for each one. You can also skip this step and associate hostnames later.</li>
<li>Select <strong>Save</strong> to confirm.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<ol>
<li>Use the <a href="/api/resources/mtls_certificates/methods/create/">Upload mTLS certificate endpoint</a> to upload the CA root certificate.</li>
</ol>
<ul>
<li>
<p><code>ca</code> boolean required</p>
</li>
<li>
<p>Set to <code>true</code> to indicate that the certificate is a CA certificate.</p>
</li>
<li>
<p><code>certificates</code> string required</p>
</li>
<li>
<p>Insert content from the <code>.pem</code> file associated with the CA certificate, formatted as a single string with <code>\n</code> replacing the line breaks.</p>
</li>
<li>
<p><code>name</code> string optional</p>
</li>
<li>
<p>Indicate a unique name for your CA certificate.</p>
</li>
<li>
<p><code>private_key</code> string optional</p>
</li>
<li>
<p>Insert content from the <code>.pem</code> file associated with the private key for the certificate, formatted as a single string with <code>\n</code> replacing the line breaks.</p>
</li>
</ul>
<ol start="2">
<li>Take note of the certificate ID (<code>id</code>) that is returned in the API response.</li>
<li>Use the <a href="/api/resources/certificate_authorities/subresources/hostname_associations/methods/update/">Replace Hostname Associations endpoint</a> to enable mTLS in each hostname that should use the CA for mTLS validation. Use the following parameters:</li>
</ol>
<ul>
<li><code>hostnames</code> array required</li>
<li>List the hostnames that will be using the CA for client certificate validation.</li>
</ul>
<aside class="nb-aside caution">
<p>Submitting an empty array will remove all hostname associations.</p>
</aside>
<ul>
<li><code>mtls_certificate_id</code> string required</li>
<li>Indicate the certificate ID obtained from the previous step.</li>
</ul>
<aside class="nb-aside caution">
<p>If no <code>mtls_certificate_id</code> is provided, the action will be performed against the <a href="/ssl/client-certificates/">Cloudflare-managed CA</a>.</p>
</aside>
<ol start="4">
<li>(Optional) Make a <a href="#list-ca-hostname-associations">GET request</a> to confirm the CA hostname associations.</li>
</ol>
