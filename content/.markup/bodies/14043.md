<ol>
<li>In the Cloudflare dashboard, go to the <strong>Client Certificates</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>On the <strong>Hosts</strong> section under <strong>Cloudflare-issued Client Certificates</strong>, select <strong>Edit</strong>.</li>
<li>Select the cross next to the hostname you want to remove.</li>
<li>Select <strong>Save</strong> to confirm.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<ol>
<li><a href="/api/resources/certificate_authorities/subresources/hostname_associations/methods/get/">List the hostname associations</a> <strong>without</strong> the <code>mtls_certificate_id</code> parameter.</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request GET \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/certificate_authorities/hostname_associations \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;</code></pre>
<ol start="2">
<li>Copy the <code>hostnames</code> array returned by the API and update it, removing the hostname that should no longer use the Cloudflare-managed CA.</li>
<li>Use the <a href="/api/resources/certificate_authorities/subresources/hostname_associations/methods/update/">Replace Hostname Associations endpoint</a> <strong>without</strong> the <code>mtls_certificate_id</code> parameter to perform the action against the Cloudflare-managed CA. For <code>hostnames</code> use the list from the previous step.</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request PUT \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/certificate_authorities/hostname_associations \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;hostnames&quot;: [
  &quot;&lt;UPDATED_HOSTNAME_ASSOCIATIONS&gt;&quot;
]
}&#x27;</code></pre>
