<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the Cloudflare dashboard, go to the <strong>Client Certificates</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select the <strong>BYOCA</strong> tab.</li>
<li>Find the CA you want to delete and select the three dots next to it.</li>
<li>Remove all associated hostnames first, if any exist.</li>
<li>Select the delete option and confirm.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<ol>
<li>Make a request to the <a href="/api/resources/certificate_authorities/subresources/hostname_associations/methods/update/">Replace Hostname Associations endpoint</a>, with an empty array for <code>hostnames</code> and specifying your CA certificate ID in <code>mtls_certificate_id</code>:</li>
</ol>
<pre><code class="language-txt">  &quot;hostnames&quot;: [],
  &quot;mtls_certificate_id&quot;: &quot;&lt;CERTIFICATE_ID&gt;&quot;
</code></pre>
<ol start="2">
<li>Use the <a href="/api/resources/mtls_certificates/methods/delete/">Delete mTLS certificate endpoint</a> to delete the certificate.</li>
</ol>
