<p>To re-enable Universal SSL in the dashboard:</p>
<ol>
<li>In the Cloudflare dashboard, go to the <strong>Edge Certificates</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>For <strong>Disable Universal SSL</strong>, select <strong>Enable Universal SSL</strong>.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To re-enable Universal SSL with the Cloudflare API, send a <a href="/api/resources/ssl/subresources/universal/subresources/settings/methods/edit/"><code>PATCH</code></a> request and include the <code>&quot;enabled&quot;: true</code> parameter.</p>

</section>
