<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<p>To use Geo Key Manager in the dashboard:</p>
<ol>
<li>Follow the steps to <a href="/ssl/edge-certificates/custom-certificates/uploading/#upload-a-custom-certificate">upload a custom certificate</a>.</li>
<li>For <strong>Private Key Restriction</strong>, choose one of the following options:</li>
</ol>
<ul>
<li><strong>Distribute to all Cloudflare data centers (optimal performance)</strong></li>
<li><strong>Distribute only to U.S. data centers</strong></li>
<li><strong>Distribute only to E.U. data centers</strong></li>
<li><strong>Distribute only to highest security data centers</strong> (<a href="/ssl/edge-certificates/geokey-manager/supported-options/#highest-security-data-centers">more details</a>)</li>
</ul>
<ol start="3">
<li>Select <strong>Upload Custom Certificate</strong>.</li>
</ol>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To use Geo Key Manager with the API, generally, follow the steps to <a href="/ssl/edge-certificates/custom-certificates/uploading/#upload-a-custom-certificate">upload a custom certificate</a>.</p>
<p>When sending the <a href="/api/resources/custom_certificates/methods/create/"><code>POST</code></a> request, include the <code>geo_restrictions</code> parameter set to one of the following options:</p>
<ul>
<li><code>us</code></li>
<li><code>eu</code></li>
<li><code>highest_security</code>(<a href="/ssl/edge-certificates/geokey-manager/supported-options/#highest-security-data-centers">more details</a>)</li>
</ul>

</section>
