<p>To update a certificate in the dashboard:</p>
<ol>
<li>In the Cloudflare dashboard, go to the <strong>Edge Certificates</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>
<p>In <strong>Edge Certificates</strong>, locate a custom certificate and select it to expand.</p>
</li>
<li>
<p>Select the wrench button and choose <strong>Replace SSL certificate and key</strong>.</p>
</li>
<li>
<p>Follow the same steps as <a href="#upload-a-custom-certificate">upload a new certificate</a>.</p>
</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To update a certificate using the API, send a <a href="/api/resources/custom_certificates/methods/edit/"><code>PATCH</code></a> command.</p>
