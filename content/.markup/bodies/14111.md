<p>To create a new advanced certificate in the dashboard:</p>
<ol>
<li>In the Cloudflare dashboard, go to the <strong>Edge Certificates</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select <strong>Order Advanced Certificate</strong>.</li>
<li>If Cloudflare does not have your billing information, you will need to enter that information.</li>
<li>Enter the following information:</li>
</ol>
<ul>
<li>Certificate authority</li>
<li>Certificate hostnames
<ul>
<li>For hostnames longer than 64 characters, use the API.</li>
</ul>
</li>
<li>Validation method</li>
<li>Certificate validity period</li>
</ul>
<ol start="5">
<li>Select <strong>Save</strong>.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To create a new certificate using the API, send a <a href="/api/resources/ssl/subresources/certificate_packs/methods/create/">POST request</a> to the Cloudflare API.</p>
<p>If you need certificates for hostnames longer than 64 characters (<a href="https://www.rfc-editor.org/rfc/rfc5280.html">RFC 5280</a>), set the <code>cloudflare_branding</code> option to <code>true</code>. This will add <code>sni.cloudflaressl.com</code> in the Common Name (CN) field and will include the long hostname as a part of the Subject Alternative Name (SAN).</p>

</section>
