<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<p>To enable HSTS using the dashboard:</p>
<ol>
<li>In the Cloudflare dashboard, go to the <strong>Edge Certificates</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>For <strong>HTTP Strict Transport Security (HSTS)</strong>, select <strong>Enable HSTS</strong>.</li>
<li>Read the dialog and select <strong>I understand</strong>.</li>
<li>Select <strong>Next</strong>.</li>
<li>Configure the <a href="#configuration-settings">HSTS settings</a>.</li>
<li>Select <strong>Save</strong>.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To enable HSTS with the API, send a <a href="/api/resources/zones/subresources/settings/methods/edit/"><code>PATCH</code></a> request with <code>security_header</code> as the setting name in the URI path, and specify the <code>value</code> object that includes your HSTS settings.</p>

</section>
