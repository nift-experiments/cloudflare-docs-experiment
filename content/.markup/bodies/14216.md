<p>To create a Keyless certificate in the dashboard:</p>
<ol>
<li>In the Cloudflare dashboard, go to the <strong>Edge Certificates</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select <strong>Upload Keyless SSL Certificate</strong>.</li>
<li>Fill in the upload modal with the certificate and other details and select <strong>Add</strong>.</li>
</ol>
<table>
<thead>
<tr>
<th>Label</th>
<th>Description</th>
<th>Example Values</th>
</tr>
</thead>
<tbody>
<tr>
<td>Key server label</td>
<td>Any unique identifier for your key server.</td>
<td>“test-keyless”, “production-keyless-1”</td>
</tr>
<tr>
<td>Key server hostname</td>
<td>The hostname of your key server that holds the key for this certificate (such as the random hostname generated earlier).</td>
<td>11aa40b4a5db06d4889e48e2f738950ddfa50b7349d09b5f.example.com</td>
</tr>
<tr>
<td>Key server port</td>
<td>Set to 2407 unless you have changed this on the key server.</td>
<td>2407</td>
</tr>
<tr>
<td>SSL Certificate</td>
<td>The valid X509v3 SSL certificate (in PEM form) for which you hold the private key.</td>
<td>(PEM bytes)</td>
</tr>
<tr>
<td>Bundle method</td>
<td>This should almost always be <strong>Compatible</strong>. Refer to <a href="/ssl/edge-certificates/custom-certificates/uploading/">Uploading Custom Certificates</a> for more details.</td>
<td>Compatible</td>
</tr>
</tbody>
</table>
