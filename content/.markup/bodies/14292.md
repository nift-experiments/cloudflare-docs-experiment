

Use the [Upload a zone-level client certificate](/api/resources/origin_tls_client_auth/subresources/zone_certificates/methods/create/) endpoint to upload your certificate.

<aside class="nb-aside note">


<p>You must upload a <a href="/ssl/concepts/#chain-of-trust">leaf certificate</a>. If you upload a root CA instead, the API will return a <code>missing leaf certificate</code> error.</p>


</aside>
