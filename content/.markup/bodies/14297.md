

Use the [Set Enablement for Zone](/api/resources/origin_tls_client_auth/subresources/settings/methods/update/) endpoint to enable zone-level Authenticated Origin Pulls.

<aside class="nb-aside caution">


<p>This endpoint is separate from the <a href="/ssl/origin-configuration/authenticated-origin-pull/set-up/global/">global AOP toggle</a>, which uses the zone settings <code>tls_client_auth</code> setting. Make sure you use the correct endpoint for the configuration you intend.</p>


</aside>
