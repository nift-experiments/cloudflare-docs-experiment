<p>Use the <a href="/api/resources/origin_tls_client_auth/subresources/hostname_certificates/methods/create/">Upload a Hostname Client Certificate</a> endpoint to upload your custom certificate.</p>
<aside class="nb-aside note">
<p>You must upload a <a href="/ssl/concepts/#chain-of-trust">leaf certificate</a>. If you upload a root CA instead, the API will return a <code>missing leaf certificate</code> error.</p>
</aside>
<pre><code class="language-bash">MYCERT=&quot;$(cat cert.crt|perl -pe 's/\r?\n/\\n/'|sed -e 's/..$//')&quot;
MYKEY=&quot;$(cat cert.key|perl -pe 's/\r?\n/\\n/'|sed -e's/..$//')&quot;

request_body=$(&lt; &lt;(cat &lt;&lt;EOF
{
&quot;certificate&quot;: &quot;$MYCERT&quot;,
&quot;private_key&quot;: &quot;$MYKEY&quot;,
&quot;bundle_method&quot;:&quot;ubiquitous&quot;
}
EOF
))

# Push the certificate

curl --silent \
&quot;https://api.cloudflare.com/client/v4/zones/$ZONEID/origin_tls_client_auth/hostnames/certificates&quot; \
--header &quot;Content-Type: application/json&quot; \
--header &quot;X-Auth-Email: $MYAUTHEMAIL&quot; \
--header &quot;X-Auth-Key: $MYAUTHKEY&quot; \
--data &quot;$request_body&quot;
</code></pre>
<p>In the API response, save the certificate <code>id</code> since it will be required in step 3.</p>
