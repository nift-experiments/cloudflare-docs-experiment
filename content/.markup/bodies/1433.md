

<h3 id="body-1433-prerequisites-1">Prerequisites</h3>

- Install [Node.js](https://docs.npmjs.com/downloading-and-installing-node-js-and-npm).

For setup, select the following options:

- For _What would you like to start with?_, choose `Hello World example`.
- For _Which template would you like to use?_, choose <code>Worker only</code>.
- For _Which language do you want to use?_, choose <code>TypeScript</code>.
- For _Do you want to use git for version control?_, choose `Yes`.
- For _Do you want to deploy your application?_, choose `No` (we will be making some changes before deploying).


<h4 id="body-1433-2-configure-the-browser-binding"><ol start="2">
<li>Configure the browser binding</li>
</ol></h4>

Update your [Wrangler configuration file](/workers/wrangler/configuration/) with a browser [binding](/browser-run/reference/wrangler/#bindings):

<div class="nb-wrangler-config">

<pre><code class="language-toml">name = &quot;browser-quick-action&quot;
main = &quot;src/index.ts&quot;
compatibility_date = &quot;$today&quot;

[browser]
binding = &quot;BROWSER&quot;
</code></pre>

</div>

<aside class="nb-aside caution">


<p>Using the <code>.quickAction()</code> method requires a <code>compatibility_date</code> of <code>2026-03-24</code> or later.</p>


</aside>

<h4 id="body-1433-3-write-the-worker-code"><ol start="3">
<li>Write the Worker code</li>
</ol></h4>

Replace the contents of `src/index.ts` with the following:

<div class="nb-type-script-example">

<pre><code class="language-ts">interface Env {
	BROWSER: BrowserRun;
}

export default {
	async fetch(request, env): Promise&lt;Response&gt; {
		return await env.BROWSER.quickAction(&quot;screenshot&quot;, {
			url: &quot;https://example.com&quot;,
		});
	},
} satisfies ExportedHandler&lt;Env&gt;;
</code></pre>

</div>

This Worker uses the browser binding to take a screenshot of `example.com` and returns the image directly in the response.

<h4 id="body-1433-4-test"><ol start="4">
<li>Test</li>
</ol></h4>

Run `npx wrangler dev --remote` to test your Worker locally.


<aside class="nb-aside note">
<h3 class="nb-aside-title" id="body-1433-use-real-headless-browser-during-local-development">Use real headless browser during local development</h3>


<p>To interact with a real headless browser during local development, set <code>&quot;remote&quot; : true</code> in the Browser binding configuration. Learn more in our <a href="/workers/local-development/#remote-bindings">remote bindings documentation</a>.</p>


</aside>

Visit your local URL to see the screenshot.

<h4 id="body-1433-5-deploy"><ol start="5">
<li>Deploy</li>
</ol></h4>

Run `npx wrangler deploy` to deploy your Worker to the Cloudflare global network.
