<h4 id="body-1434-2-configure-the-browser-binding"><ol start="2">
<li>Configure the browser binding</li>
</ol></h4>
<p>Update your <a href="/workers/wrangler/configuration/">Wrangler configuration file</a> with a browser <a href="/browser-run/reference/wrangler/#bindings">binding</a>:</p>
<div class="nb-wrangler-config">
<pre><code class="language-toml">name = &quot;browser-quick-action&quot;
main = &quot;src/index.ts&quot;
compatibility_date = &quot;$today&quot;

[browser]
binding = &quot;BROWSER&quot;
</code></pre>
</div>
<aside class="nb-aside caution">
<p>Using the <code>.quickAction()</code> method requires a <code>compatibility_date</code> of <code>2026-03-24</code> or later.</p>
</aside>
<h4 id="body-1434-3-write-the-worker-code"><ol start="3">
<li>Write the Worker code</li>
</ol></h4>
<p>Replace the contents of <code>src/index.ts</code> with the following:</p>
<div class="nb-type-script-example">
<pre><code class="language-ts">interface Env {
	BROWSER: BrowserRun;
}

export default {
	async fetch(request, env): Promise&lt;Response&gt; {
		return await env.BROWSER.quickAction(&quot;screenshot&quot;, {
			url: &quot;https://example.com&quot;,
		});
	},
} satisfies ExportedHandler&lt;Env&gt;;
</code></pre>
</div>
<p>This Worker uses the browser binding to take a screenshot of <code>example.com</code> and returns the image directly in the response.</p>
<h4 id="body-1434-4-test"><ol start="4">
<li>Test</li>
</ol></h4>
<p>Run <code>npx wrangler dev --remote</code> to test your Worker locally.</p>
<aside class="nb-aside note">
<h3 class="nb-aside-title" id="body-1434-use-real-headless-browser-during-local-development">Use real headless browser during local development</h3>
<p>To interact with a real headless browser during local development, set <code>&quot;remote&quot; : true</code> in the Browser binding configuration. Learn more in our <a href="/workers/local-development/#remote-bindings">remote bindings documentation</a>.</p>
</aside>
<p>Visit your local URL to see the screenshot.</p>
<h4 id="body-1434-5-deploy"><ol start="5">
<li>Deploy</li>
</ol></h4>
<p>Run <code>npx wrangler deploy</code> to deploy your Worker to the Cloudflare global network.</p>
