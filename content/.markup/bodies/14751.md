<p>To view any accounts owned by your tenant using the dashboard:</p>
<ol>
<li>Log into the <a href="https://dash.cloudflare.com">Cloudflare dashboard</a>.</li>
<li>Go to <strong>Tenants</strong> &gt; <strong>Managed Accounts</strong>.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To fetch any accounts owned by your tenant using the API, send a <a href="/api/resources/accounts/methods/list/"><code>GET</code></a> request to the <code>/accounts</code> endpoint.</p>
<p>You will get back a list of all the accounts you have created plus any accounts your user already had access to.</p>
<pre><code class="language-bash">curl https://api.cloudflare.com/client/v4/accounts \
--header &quot;X-Auth-Email: &lt;EMAIL&gt;&quot; \
--header &quot;X-Auth-Key: &lt;API_KEY&gt;&quot;
</code></pre>
