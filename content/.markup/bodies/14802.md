<p>Configure the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/ruleset"><code>cloudflare_ruleset</code></a> resource:</p>
<pre><code class="language-tf">resource &quot;cloudflare_ruleset&quot; &quot;zone_custom_firewall&quot; {
  zone_id     = var.cloudflare_zone_id
  name        = &quot;Phase entry point ruleset for custom rules in my zone&quot;
  description = &quot;&quot;
  kind        = &quot;zone&quot;
  phase       = &quot;http_request_firewall_custom&quot;

  rules = [{
    ref         = &quot;block_non_default_ports&quot;
    description = &quot;Block ports other than 80 and 443&quot;
    expression  = &quot;(not cf.edge.server_port in {80 443})&quot;
    action      = &quot;block&quot;
  }]
}
</code></pre>

  zone_id     = &quot;&lt;ZONE_ID&gt;&quot;
  name        = &quot;Phase entry point ruleset for custom rules in my zone&quot;
  description = &quot;&quot;
  kind        = &quot;zone&quot;
  phase       = &quot;http_request_firewall_custom&quot;

  rules {
    ref         = &quot;block_non_default_ports&quot;
    description = &quot;Block ports other than 80 and 443&quot;
    expression  = &quot;(not cf.edge.server_port in {80 443})&quot;
    action      = &quot;block&quot;
  }
}
</code></pre>
<p>To create another custom rule, add a new <code>rules</code> object to the same <code>cloudflare_ruleset</code> resource.</p>
