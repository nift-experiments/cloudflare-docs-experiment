<details class="nb-details"><summary>Required API token permissions</summary><div class="nb-details-body">
<p>All of the following <a href="/fundamentals/api/reference/permissions/">token permissions</a> are required:</p>
<ul>
<li><code>Zone Transform Rules Write</code></li>
<li><code>Account Rulesets Read</code></li>
</ul>
</div></details>
<p>Configure the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/ruleset"><code>cloudflare_ruleset</code></a> resource:</p>
<pre><code class="language-tf">resource &quot;cloudflare_ruleset&quot; &quot;transform_url_rewrite&quot; {
  zone_id     = var.cloudflare_zone_id
  name        = &quot;Transform Rule performing a static URL rewrite&quot;
  description = &quot;&quot;
  kind        = &quot;zone&quot;
  phase       = &quot;http_request_transform&quot;

  rules = [{
    ref         = &quot;url_rewrite_old_folder&quot;
    description = &quot;Example URL rewrite rule&quot;
    expression  = &quot;(http.host eq \&quot;example.com\&quot; and http.request.uri.path eq \&quot;/old-folder\&quot;)&quot;
    action      = &quot;rewrite&quot;
    action_parameters = {
      uri = {
        path = {
          value = &quot;/new-folder&quot;
        }
      }
    }
  }]
}
</code></pre>

  rules {
    ref         = &quot;url_rewrite_old_folder&quot;

        }
      }
    }
  }

</code></pre>
<p>To create another URL rewrite rule, add a new <code>rules</code> object to the same <code>cloudflare_ruleset</code> resource.</p>
