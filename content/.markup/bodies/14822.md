<details class="nb-details"><summary>Required API token permissions</summary><div class="nb-details-body">
<p>All of the following <a href="/fundamentals/api/reference/permissions/">token permissions</a> are required:</p>
<ul>
<li><code>Zone Transform Rules Write</code></li>
<li><code>Account Rulesets Read</code></li>
</ul>
</div></details>
<p>Configure the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/ruleset"><code>cloudflare_ruleset</code></a> resource:</p>
<pre><code class="language-tf">resource &quot;cloudflare_ruleset&quot; &quot;transform_modify_response_headers&quot; {
  zone_id     = var.cloudflare_zone_id
  name        = &quot;Transform Rule performing HTTP response header modifications&quot;
  description = &quot;&quot;
  kind        = &quot;zone&quot;
  phase       = &quot;http_response_headers_transform&quot;

  rules = [{
    ref         = &quot;modify_response_headers&quot;
    description = &quot;Example response header transform rule&quot;
    expression  = &quot;true&quot;
    action      = &quot;rewrite&quot;
    action_parameters = {
      headers = {
        &quot;my-header-1&quot; = {
          operation = &quot;set&quot;
          value     = &quot;Fixed value&quot;
        }
        &quot;my-header-2&quot; = {
          operation  = &quot;set&quot;
          expression = &quot;cf.zone.name&quot;
        }
        &quot;existing-header&quot; = {
          operation = &quot;remove&quot;
        }
      }
    }
  }]
}
</code></pre>
