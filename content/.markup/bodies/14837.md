<details class="nb-details"><summary>Required API token permissions</summary><div class="nb-details-body">
<p>All of the following <a href="/fundamentals/api/reference/permissions/">token permissions</a> are required:</p>
<ul>
<li><code>Account WAF Write</code></li>
<li><code>Account Rulesets Write</code></li>
</ul>
</div></details>
<p>Configure the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/ruleset"><code>cloudflare_ruleset</code></a> resource:</p>
<pre><code class="language-tf">resource &quot;cloudflare_ruleset&quot; &quot;account_rl&quot; {
  account_id  = var.cloudflare_account_id
  name        = &quot;Rate limiting rules for APIs&quot;
  description = &quot;&quot;
  kind        = &quot;custom&quot;
  phase       = &quot;http_ratelimit&quot;

  rules = [{
    ref         = &quot;rate_limit_api_ip&quot;
    description = &quot;Rate limit API requests by IP&quot;
    expression  = &quot;http.request.uri.path contains \&quot;/api/\&quot;&quot;
    action      = &quot;block&quot;
    ratelimit = {
      characteristics     = [&quot;cf.colo.id&quot;, &quot;ip.src&quot;]
      period              = 60
      requests_per_period = 100
      mitigation_timeout  = 600
    }
  }]
}

# Account-level entry point ruleset for the 'http_ratelimit' phase
resource &quot;cloudflare_ruleset&quot; &quot;account_rl_entrypoint&quot; {
  account_id  = var.cloudflare_account_id
  name        = &quot;Account-level rate limiting&quot;
  description = &quot;&quot;
  kind        = &quot;root&quot;
  phase       = &quot;http_ratelimit&quot;

  depends_on = [cloudflare_ruleset.account_rl]

  rules = [{
    # Deploy the previously defined custom ruleset containing a rate limiting rule
    ref         = &quot;deploy_rate_limit_example_com&quot;
    description = &quot;Deploy custom ruleset with RL rule&quot;
    expression  = &quot;cf.zone.name eq \&quot;example.com\&quot; and cf.zone.plan eq \&quot;ENT\&quot;&quot;
    action      = &quot;execute&quot;
    action_parameters = {
      id = cloudflare_ruleset.account_rl.id
    }
  }]
}
</code></pre>
