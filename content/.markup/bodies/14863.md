
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Networking</strong> &gt; <strong>Tunnels</strong>.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select your tunnel.</li>
<li>Select <strong>Add a replica</strong>.</li>
<li>Copy the <code>cloudflared</code> installation command into a text editor (do not run the command). The token is the <code>eyJ...</code> string.</li>
</ol>
