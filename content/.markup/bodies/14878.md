<p>On Linux, Cloudflare Tunnel installs itself as a system service using <code>systemctl</code>. By default, the service will be named <code>cloudflared.service</code>. To configure your tunnel on Linux:</p>
<ol>
<li>Open <code>cloudflared.service</code>.</li>
</ol>
<pre><code class="language-sh">sudo systemctl edit --full cloudflared.service
</code></pre>
<ol start="2">
<li>Modify the <code>cloudflared tunnel run</code> command with the desired configuration flag. For example,</li>
</ol>
<pre><code class="language-txt">[Unit]
Description=Cloudflare Tunnel
After=network.target

[Service]
TimeoutStartSec=0
Type=notify
ExecStart=/usr/local/bin/cloudflared tunnel --loglevel info --logfile /var/log/cloudflared/cloudflared.log run --token &lt;TOKEN VALUE&gt;
Restart=on-failure
RestartSec=5s

[Install]
WantedBy=multi-user.target
</code></pre>
<ol start="3">
<li>Restart <code>cloudflared.service</code>:</li>
</ol>
<pre><code class="language-sh">sudo systemctl restart cloudflared
</code></pre>
<ol start="4">
<li>To verify the new configuration, check the service status:</li>
</ol>

<p>On macOS, Cloudflare Tunnel installs itself as a launch agent using <code>launchctl</code>. By default, the agent will be called <code>com.cloudflare.cloudflared</code>. To configure your tunnel on macOS:</p>
<ol>
<li>Stop the <code>cloudflared</code> service.</li>
</ol>
<pre><code class="language-sh">sudo launchctl stop com.cloudflare.cloudflared
</code></pre>
<ol start="2">
<li>Unload the configuration file.</li>
</ol>
<pre><code class="language-sh">sudo launchctl unload /Library/LaunchDaemons/com.cloudflare.cloudflared.plist
</code></pre>
<ol start="3">
<li>
<p>Open <code>/Library/LaunchDaemons/com.cloudflare.cloudflared.plist</code> in a text editor.</p>
</li>
<li>
<p>Modify the <code>ProgramArguments</code> key with the desired configuration flag. For example,</p>
</li>
</ol>
<pre><code class="language-txt">&lt;plist version=&quot;1.0&quot;&gt;
    &lt;dict&gt;
        &lt;key&gt;Label&lt;/key&gt;
        &lt;string&gt;com.cloudflare.cloudflared&lt;/string&gt;
        &lt;key&gt;ProgramArguments&lt;/key&gt;
        &lt;array&gt;
            &lt;string&gt;/opt/homebrew/bin/cloudflared&lt;/string&gt;
            &lt;string&gt;tunnel&lt;/string&gt;
            &lt;string&gt;--logfile&lt;/string&gt;
            &lt;string&gt;&lt;PATH&gt;&lt;/string&gt;
            &lt;string&gt;--loglevel&lt;/string&gt;
            &lt;string&gt;debug&lt;/string&gt;
            &lt;string&gt;run&lt;/string&gt;
            &lt;string&gt;--token&lt;/string&gt;
            &lt;string&gt;&lt;TOKEN VALUE&gt; &lt;/string&gt;
        &lt;/array&gt;
</code></pre>
<ol start="5">
<li>Load the updated configuration file.</li>
</ol>
<pre><code class="language-sh">sudo launchctl load /Library/LaunchDaemons/com.cloudflare.cloudflared.plist
</code></pre>
<ol start="6">
<li>Start the <code>cloudflared</code> service.</li>
</ol>
<pre><code class="language-sh">sudo launchctl start com.cloudflare.cloudflared
</code></pre>

<p>On Windows, Cloudflare Tunnel installs itself as a system service using the Registry Editor. By default, the service will be named <code>cloudflared</code>. To configure your tunnel on Windows:</p>
<ol>
<li>
<p>Open the Registry Editor.</p>
</li>
<li>
<p>Go to <strong>HKEY_LOCAL_MACHINE</strong> &gt; <strong>SYSTEM</strong> &gt; <strong>CurrentControlSet</strong> &gt; <strong>Services</strong> &gt; <strong>cloudflared</strong>.</p>
</li>
<li>
<p>Double-click <strong>ImagePath</strong>.</p>
</li>
<li>
<p>Modify <strong>Value data</strong> with the desired configuration flag. For example,</p>
</li>
</ol>
<pre><code class="language-txt">C:\Program Files (x86)\cloudflared\.\cloudflared.exe tunnel --loglevel info --logfile &lt;PATH&gt; run --token &lt;TOKEN VALUE&gt;
</code></pre>
