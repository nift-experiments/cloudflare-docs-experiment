The `cloudflared` daemon can stream logs from any tunnel in your account to the local command line. `cloudflared` must be installed on both your local machine and the origin server.

1. On your local machine, authenticate `cloudflared` to your Cloudflare account:

<pre><code class="language-sh">cloudflared tunnel login
</code></pre>


2. Run `cloudflared tail` for a specific tunnel:

<pre><code class="language-sh">cloudflared tail &lt;UUID&gt;
</code></pre>


For a more structured view of the JSON message, you can pipe the output to tools like [jq](https://stedolan.github.io/jq/):

<pre><code class="language-sh">cloudflared tail --output=json &lt;UUID&gt; | jq .
</code></pre>



3. If you are running multiple [replicas](/tunnel/configuration/#replicas-and-high-availability), you can specify which replica to stream logs from:
<pre><code class="language-sh">cloudflared tail --connector-id &lt;REPLICA ID&gt; &lt;UUID&gt;
</code></pre>

To find the replica ID, go to **Networking** > **Tunnels** and select your tunnel. All active replicas appear in the **Connectors** list on the tunnel overview page. The replica ID is the **Connector ID**.

<details class="nb-details"><summary>Log filtering options</summary><div class="nb-details-body">

<p>You can filter logs by event type (<code>--event</code>), event level (<code>--level</code>), or sampling rate (<code>-sampling</code>) to reduce the volume of logs streamed from the origin. This helps mitigate the performance impact on the origin, especially when the origin is normally under high load. For example:</p>
<pre><code class="language-sh">cloudflared tail --level debug &lt;UUID&gt;
</code></pre>
