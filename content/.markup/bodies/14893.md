To stream tunnel logs from the dashboard:

1. In the Cloudflare dashboard, go to **Networking** > **Tunnels** and select your tunnel.

<div class="nb-dash-button"></div>

2. Go to the **Live logs** tab.
3. Select **Live** to start streaming.

<h4 id="body-14893-view-logs-for-a-replica">View logs for a replica</h4>

If you are running multiple `cloudflared` instances for the same tunnel (also known as [replicas](/tunnel/configuration/#replicas-and-high-availability)), logs from all connected replicas are streamed automatically and grouped by hostname, making it easy to identify which host machine produced each log entry.

To filter the stream to specific replicas, select the **Filter** icon and expand the **Replicas** section. You can also filter by **Log Level** and **Event Type**.
