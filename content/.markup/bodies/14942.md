2. Create a tunnel:



<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/cfd_tunnel \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;api-tunnel&quot;,
&quot;config_src&quot;: &quot;cloudflare&quot;
}&#x27;</code></pre>



3. Copy the `id` and `token` values from the response. You will need them to configure and run the tunnel.
