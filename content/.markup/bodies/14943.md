<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Networking</strong> &gt; <strong>Tunnels</strong>.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>
<p>Select <strong>Create Tunnel</strong>.</p>
</li>
<li>
<p>Enter a name for your tunnel (for example, <code>production-web</code> or <code>staging-api</code>).</p>
</li>
<li>
<p>Select <strong>Create Tunnel</strong>.</p>
</li>
<li>
<p>Under <strong>Setup Environment</strong>, select the operating system and architecture of your server.</p>
</li>
<li>
<p>Copy the install commands shown under <strong>Install and Run</strong> and run them in a terminal on your server.</p>
</li>
<li>
<p>Once the tunnel connects, select <strong>Continue</strong>.</p>
</li>
</ol>
<p>Your tunnel should appear on the <strong>Tunnels</strong> page with a <code>Healthy</code> <a href="/tunnel/observability/#tunnel-health">status</a>.</p>

</section>

<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/cfd_tunnel \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;api-tunnel&quot;,
&quot;config_src&quot;: &quot;cloudflare&quot;
}&#x27;</code></pre>
<ol start="3">
