<li>
<p>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Networking</strong> &gt; <strong>Tunnels</strong> and select your tunnel. <div class="nb-dash-button"></div></p>
</li>
<li>
<p>Under <strong>Routes</strong>, select <strong>Add route</strong>.</p>
</li>
<li>
<p>Select <strong>Published application</strong>.</p>
</li>
<li>
<p>Under <strong>Hostname</strong>, enter a subdomain and select a domain from the drop-down menu.</p>
</li>
<li>
<p>For <strong>Service URL</strong>, enter the local address and port of your application.</p>
</li>
</ol>
<p>For example, if your web server runs on the same machine as <code>cloudflared</code>:</p>
<ul>
<li>HTTP on port <code>80</code>: <code>http://localhost:80</code></li>
<li>HTTPS on port <code>443</code>: <code>https://localhost:443</code></li>
</ul>
<p>If your web server runs on a different machine: <code>http://192.0.2.1:80</code></p>
<p>If the origin certificate covers the public hostname rather than the service address, set <strong>Origin Server Name</strong> to the certificate hostname and keep <strong>Disable TLS certificate verification</strong> turned off. Refer to <a href="/tunnel/troubleshooting/https-origins/">Troubleshoot HTTPS origins</a> for the complete configuration.</p>
<ol start="6">
<li>Select <strong>Add route</strong>.</li>
</ol>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<ol>
<li>Configure your tunnel's ingress rules:</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request PUT \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/cfd_tunnel/{tunnel_id}/configurations \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;config&quot;: {
  &quot;ingress&quot;: [
    {
      &quot;hostname&quot;: &quot;app.example.com&quot;,
      &quot;service&quot;: &quot;http://localhost:80&quot;,
      &quot;originRequest&quot;: {}
    },
    {
      &quot;service&quot;: &quot;http_status:404&quot;
    }
  ]
}
}&#x27;</code></pre>
<p>Your ingress rules must include a catch-all rule at the end. In this example, <code>cloudflared</code> will respond with a 404 status code when the request does not match any hostname.</p>
<ol start="2">
<li>Create a DNS record for your application:</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/dns_records \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;type&quot;: &quot;CNAME&quot;,
&quot;proxied&quot;: true,
&quot;name&quot;: &quot;app.example.com&quot;,
&quot;content&quot;: &quot;&lt;TUNNEL_ID&gt;.cfargotunnel.com&quot;
}&#x27;</code></pre>
