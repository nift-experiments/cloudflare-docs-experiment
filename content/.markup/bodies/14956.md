
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<p>To deploy a replica for a remotely-managed tunnel:</p>
<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Networking</strong> &gt; <strong>Tunnels</strong>.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select your tunnel.</li>
<li>Select <strong>Add a replica</strong>.</li>
<li>Select the operating system of the host where you want to deploy a replica.</li>
<li>Copy the installation command and run it on the host.</li>
</ol>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="CLI">

<p>To deploy a replica for a <a href="/tunnel/features/locally-managed-tunnels/">locally-managed tunnel</a>, run <code>cloudflared tunnel run &lt;NAME&gt;</code> on an additional host using the same <a href="/tunnel/features/locally-managed-tunnels/tunnel-permissions/">tunnel credentials</a>.</p>

</section>
