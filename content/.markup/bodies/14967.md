<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>Log in to the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a> and go to <strong>DNS Records</strong> for your domain.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select <strong>Add record</strong>.</li>
<li>Enter the following values:</li>
</ol>
<ul>
<li><strong>Type</strong>: <em>CNAME</em></li>
<li><strong>Name</strong>: Subdomain of your application</li>
<li><strong>Target</strong>: <code>&lt;UUID&gt;.cfargotunnel.com</code></li>
</ul>
<ol start="4">
<li>Select <strong>Save</strong>.</li>
</ol>
<p><img src="/assets/upstream/images/cloudflare-one/connections/connect-apps/dns/dns-record.png" alt="Example of fields completed to create a new CNAME record." /></p>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="CLI">

<p>For locally-managed tunnels, run the following command to create a CNAME record pointing to your tunnel subdomain:</p>
<pre><code class="language-sh">cloudflared tunnel route dns &lt;UUID or NAME&gt; www.app.com
</code></pre>
<p>This creates a CNAME record but does not proxy traffic unless the tunnel is running.</p>
<aside class="nb-aside note">
<p>To create DNS records using <code>cloudflared</code>, the <a href="/tunnel/features/locally-managed-tunnels/local-tunnel-terms/#certpem"><code>cert.pem</code></a> file must be installed on your system.</p>
</aside>

</section>
