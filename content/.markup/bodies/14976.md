</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Linux">

<p><strong>Debian and Ubuntu APT</strong></p>
<p>Use the apt package manager to install <code>cloudflared</code> on compatible machines.</p>
<ol>
<li>Add Cloudflare's package signing key:</li>
</ol>
<pre><code class="language-sh">sudo mkdir -p --mode=0755 /usr/share/keyrings
curl -fsSL https://pkg.cloudflare.com/cloudflare-main.gpg | sudo tee /usr/share/keyrings/cloudflare-main.gpg &gt;/dev/null
</code></pre>
<ol start="2">
<li>Add Cloudflare's apt repo to your apt repositories:</li>
</ol>
<pre><code class="language-sh">echo &quot;deb [signed-by=/usr/share/keyrings/cloudflare-main.gpg] https://pkg.cloudflare.com/cloudflared any main&quot; | sudo tee /etc/apt/sources.list.d/cloudflared.list
</code></pre>
<ol start="3">
<li>Update repositories and install cloudflared:</li>
</ol>
<pre><code class="language-sh">sudo apt-get update &amp;&amp; sudo apt-get install cloudflared
</code></pre>
<p><strong>RHEL RPM</strong></p>
<p>Use the rpm package manager to install <code>cloudflared</code> on compatible machines.</p>
<ol>
<li>Add Cloudflare's repository:</li>
</ol>
<pre><code class="language-sh">curl -fsSl https://pkg.cloudflare.com/cloudflared.repo | sudo tee /etc/yum.repos.d/cloudflared.repo
</code></pre>
<ol start="2">
<li>Update repositories and install cloudflared:</li>
</ol>
<pre><code class="language-sh">sudo yum update &amp;&amp; sudo yum install cloudflared
</code></pre>
<p><strong>Arch Linux</strong></p>
<p><code>cloudflared</code> is in the Arch Linux <a href="https://wiki.archlinux.org/title/official_repositories#community"><code>community</code> repository</a>.
Use <code>pacman</code> to install <code>cloudflared</code> on compatible machines.</p>
<pre><code class="language-sh">pacman -Syu cloudflared
</code></pre>
<p><strong>Other</strong></p>
<p>Alternatively you can download the <code>cloudflared</code> binary or the linux packages to your machine and install manually. Visit the <a href="/tunnel/downloads/">downloads</a> page to find the right package for your OS.</p>

<pre><code class="language-sh">git clone https://github.com/cloudflare/cloudflared.git
cd cloudflared
make cloudflared
go install github.com/cloudflare/cloudflared/cmd/cloudflared
</code></pre>
<p>Depending on where you installed <code>cloudflared</code>, you can move it to a known path as well.</p>
<pre><code class="language-sh">mv /root/cloudflared/cloudflared /usr/bin/cloudflared
</code></pre>
