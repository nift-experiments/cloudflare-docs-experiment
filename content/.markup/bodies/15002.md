

1. Update the client-side integration by inserting the Turnstile script snippet in your HTML's `<head>` element.

<pre><code class="language-html">&lt;script
	src=&quot;https://challenges.cloudflare.com/turnstile/v0/api.js?compat=recaptcha&quot;
	async
	defer
&gt;&lt;/script&gt;
</code></pre>


<aside class="nb-aside note">


<p>Adding <code>?compat=recaptcha</code> runs Turnstile in compatibility mode, which
enables the following features:</p>
<ul>
<li>implicit rendering for reCAPTCHA</li>
<li><code>g-recaptcha-response</code> input name for forms</li>
<li>register the Turnstile API as <code>grecaptcha</code></li>
</ul>


</aside>

2. Locate the `grecaptcha.render()` calls and replace the sitekey with your Turnstile sitekey.

<aside class="nb-aside note">


<p>Turnstile supports:</p>
<ul>
<li>the <code>render()</code> call</li>
<li>reCAPTCHA v2 invisible mode with the <code>execute()</code> call</li>
</ul>


</aside>
