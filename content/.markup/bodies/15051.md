
Explicit rendering gives you programmatic control over when and how widgets are created using JavaScript functions. It is best used for dynamic websites and single-page applications (SPAs), when you need to control timing of widget creation, conditional rendering based on visitor interactions, or for multiple widgets with different configurations.

**How it works**
<div class="nb-steps">

<ol>
<li>Add the Turnstile script with <code>?render=explicit</code> parameter.</li>
<li>Create container elements (without the <code>cf-turnstile</code> class).</li>
<li>Call <code>turnstile.render()</code> function when you want to create widgets.</li>
<li>Configure the widget using JavaScript object parameters.</li>
</ol>

</div>

<pre><code class="language-html">	&lt;script src=&quot;https://challenges.cloudflare.com/turnstile/v0/api.js?render=explicit&quot; defer&gt;&lt;/script&gt;
	&lt;div id=&quot;my-widget&quot;&gt;&lt;/div&gt;
	
	&lt;script&gt;
	window.onload = function() {
		turnstile.render(&#x27;#my-widget&#x27;, {
			sitekey: &#x27;&lt;YOUR-SITE-KEY&gt;&#x27;,
			theme: &#x27;light&#x27;,
			callback: function(token) {
				console.log(&#x27;Success:&#x27;, token);
			}
		});
	};
	&lt;/script&gt;
