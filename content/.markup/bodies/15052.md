
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Implicit rendering">

<p>Implicit rendering automatically scans your HTML for elements with the <code>cf-turnstile</code> class and renders the widget when the page loads. It is best used for simple implementations, static websites, or when you want widgets to appear immediately on page load.</p>
<p><strong>How it works</strong></p>
<div class="nb-steps">
<ol>
<li>Add the Turnstile script to your page.</li>
<li>Include <code>&lt;div class=&quot;cf-turnstile&quot; data-sitekey=&quot;your-key&quot;&gt;&lt;/div&gt;</code> elements.</li>
<li>Widgets will render automatically when the page loads.</li>
<li>Configure the widget using <code>data-*</code> attributes on the HTML element.</li>
</ol>
</div>
<pre><code class="language-html">	&lt;script src=&quot;https://challenges.cloudflare.com/turnstile/v0/api.js&quot; async defer&gt;&lt;/script&gt;
	&lt;div class=&quot;cf-turnstile&quot; data-sitekey=&quot;&lt;YOUR-SITE-KEY&gt;&quot; data-theme=&quot;light&quot;&gt;&lt;/div&gt;
</code></pre>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Explicit rendering">

<p>Explicit rendering gives you programmatic control over when and how widgets are created using JavaScript functions. It is best used for dynamic websites and single-page applications (SPAs), when you need to control timing of widget creation, conditional rendering based on visitor interactions, or for multiple widgets with different configurations.</p>
<p><strong>How it works</strong></p>
<div class="nb-steps">
<ol>
<li>Add the Turnstile script with <code>?render=explicit</code> parameter.</li>
<li>Create container elements (without the <code>cf-turnstile</code> class).</li>
<li>Call <code>turnstile.render()</code> function when you want to create widgets.</li>
<li>Configure the widget using JavaScript object parameters.</li>
</ol>
</div>
<pre><code class="language-html">	&lt;script src=&quot;https://challenges.cloudflare.com/turnstile/v0/api.js?render=explicit&quot; defer&gt;&lt;/script&gt;
	&lt;div id=&quot;my-widget&quot;&gt;&lt;/div&gt;
	
	&lt;script&gt;
	window.onload = function() {
		turnstile.render(&#x27;#my-widget&#x27;, {
			sitekey: &#x27;&lt;YOUR-SITE-KEY&gt;&#x27;,
			theme: &#x27;light&#x27;,
			callback: function(token) {
				console.log(&#x27;Success:&#x27;, token);
			}
		});
	};
	&lt;/script&gt;
</code></pre>

</section>
