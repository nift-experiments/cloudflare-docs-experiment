<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<p>To enable <strong>Always Use HTTPS</strong> in the dashboard:</p>
<ol>
<li>In the Cloudflare dashboard, go to the <strong>SSL/TLS Overview</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Make sure that your <a href="/ssl/origin-configuration/ssl-modes/off/">SSL/TLS encryption mode</a> is not set to <strong>Off</strong>. When you set your encryption mode to <strong>Off</strong>, the <strong>Always Use HTTPS</strong> option will not be visible in your Cloudflare dashboard.</li>
<li>Go to the <a href="https://dash.cloudflare.com/?to=/:account/:zone/ssl-tls/edge-certificates"><strong>Edge Certificates</strong></a> page.</li>
<li>Turn on <strong>Always Use HTTPS</strong>.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To enable or disable <strong>Always Use HTTPS</strong> with the API:</p>
<ol>
<li>Make sure that your <a href="/ssl/origin-configuration/ssl-modes/off/">SSL/TLS encryption mode</a> <strong>is not</strong> set to <strong>Off</strong>.</li>
<li>Send a <a href="/api/resources/zones/subresources/settings/methods/edit/"><code>PATCH</code></a> request with <code>always_use_https</code> as the setting name in the URI path, and the <code>value</code> parameter set to your desired setting (<code>&quot;on&quot;</code> or <code>&quot;off&quot;</code>).</li>
</ol>

</section>
