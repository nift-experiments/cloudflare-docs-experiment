

<div class="nb-steps">

<ol>
<li>In the Cloudflare dashboard, go to the <strong>SSL/TLS Overview</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>
<p>Make sure that your <a href="/ssl/origin-configuration/ssl-modes/">SSL/TLS encryption mode</a> is not set to <strong>Off</strong>. When the encryption mode is Off, the Always Use HTTPS option is not visible in the dashboard.</p>
</li>
<li>
<p>Go to the <a href="https://dash.cloudflare.com/?to=/:account/:zone/ssl-tls/edge-certificates"><strong>Edge Certificates</strong></a> page.</p>
</li>
<li>
<p>Turn on <strong>Always Use HTTPS</strong>.</p>
</li>
</ol>
