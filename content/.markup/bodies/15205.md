
Instead of manually creating rules for each endpoint, consider creating a single [fallthrough custom rule](/api-shield/security/schema-validation/#add-validation-by-adding-a-fallthrough-rule). You need to:

1. Add your API endpoints to Endpoint Management [from a schema](/api-shield/management-and-monitoring/endpoint-management/#add-endpoints-from-schema-validation) or [manually](/api-shield/management-and-monitoring/endpoint-management/#add-endpoints-manually).
2. Create a fallthrough rule that blocks requests that do not match a saved endpoint in [Endpoint Management](/api-shield/management-and-monitoring/endpoint-management/).
