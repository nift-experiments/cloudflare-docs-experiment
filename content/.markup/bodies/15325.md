

<aside class="nb-aside note">


<p>The <strong>Zone lockdown rules</strong> option appears only if you have configured at least one zone lockdown rule.</p>


</aside>

**If you have access to Zone Lockdown rules**

<div class="nb-steps">

<ol>
<li>In the Cloudflare dashboard, go to the <strong>Security rules</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>
<p>Select <strong>Create rule</strong> &gt; <strong>Zone lockdown rules</strong>.<br/>
If this option is not available, refer to the instructions below.</p>
</li>
<li>
<p>Enter a descriptive name for the rule in <strong>Name</strong>.</p>
</li>
<li>
<p>For <strong>URLs</strong>, enter the domains, subdomains, or URLs you wish to protect from unauthorized IPs. You can use wildcards such as <code>*</code>. Enter one item per line.</p>
</li>
<li>
<p>For <strong>IP Range</strong>, enter one or more allowed IPv4/IPv6 addresses or CIDR ranges, one per line. Only these IP addresses and ranges will be able to access the resources you entered in <strong>URLs</strong>.</p>
</li>
<li>
<p>(Optional) If you are creating a zone lockdown rule that overlaps with an existing rule, expand <strong>Advanced Options</strong> and enter a priority for the rule in <strong>Priority</strong>. The lower the number, the higher the priority. Higher priority rules take precedence.</p>
</li>
<li>
<p>Select <strong>Save and Deploy lockdown rule</strong>.</p>
</li>
</ol>

</div>

**If you do not have access to Zone Lockdown rules**

Create a [custom rule](/waf/custom-rules/create-dashboard/) to perform zone lockdown:

<div class="nb-steps">

<ol>
<li>In the Cloudflare dashboard, go to the <strong>Security rules</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>
<p>Select <strong>Templates</strong>, and then select the template <strong>Allow only specified IP addresses</strong>.</p>
</li>
<li>
<p>Fill in the required fields and select <strong>Deploy</strong>.</p>
</li>
</ol>

</div>
