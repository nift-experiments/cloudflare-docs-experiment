<aside class="nb-aside note">
<p>The <strong>User agent rules</strong> option appears only if you have configured at least one user agent rule. Cloudflare recommends that you use <a href="/waf/custom-rules/">custom rules</a> instead of user agent rules.</p>
</aside>
<div class="nb-steps">
<ol>
<li>In the Cloudflare dashboard, go to the <strong>Security rules</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>
<p>Select <strong>Create rule</strong> &gt; <strong>User agent rules</strong>.</p>
</li>
<li>
<p>Enter a descriptive name for the rule in <strong>Name/Description</strong>.</p>
</li>
<li>
<p>In <strong>Action</strong>, select the action to perform: <em>Block</em>, <em>Non-Interactive Challenge</em>, <em>Managed Challenge</em>, or <em>Interactive Challenge</em>.</p>
</li>
<li>
<p>Enter a user agent value in <strong>User Agent</strong> (wildcards such as <code>*</code> are not supported). For example, to block the Bad Bot web spider, enter <code>BadBot/1.0.2 (+http://bad.bot)</code>.</p>
</li>
<li>
<p>Select <strong>Save and Deploy blocking rule</strong>.</p>
</li>
</ol>
</div>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Issue a <code>POST</code> request for the <a href="/api/resources/firewall/subresources/ua_rules/methods/create/">Create a User Agent Blocking rule</a> operation similar to the following:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/firewall/ua_rules \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;description&quot;: &quot;Block Bad Bot web spider&quot;,
&quot;mode&quot;: &quot;block&quot;,
&quot;configuration&quot;: {
  &quot;target&quot;: &quot;ua&quot;,
  &quot;value&quot;: &quot;BadBot/1.0.2 (+http://bad.bot)&quot;
}
}&#x27;</code></pre>
