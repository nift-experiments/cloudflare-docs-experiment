
1. In the Cloudflare dashboard, go to the **Security Settings** page.

<div class="nb-dash-button"></div>
2. Filter by **API abuse**.
3. On **Session identifiers**, select **Configure session identifiers**.
4. Select **Manage identifiers**.
5. Choose the type of session identifier (cookie, HTTP header, or JWT claim).
<aside class="nb-aside note">


<p>The session identifier cookie must comply with RFC 6265. Otherwise, it will be rejected.</p>
<p>If you are using a JWT claim, choose the <a href="/api-shield/security/jwt-validation/api/#token-configurations">Token Configuration</a> that will verify the JWT. Token Configurations are required to use JWT claims as session identifiers. Refer to <a href="/api-shield/security/jwt-validation/">JWT Validation</a> for more information.</p>


</aside>
6. Enter the name of the session identifier.
7. Select **Save**.
