<div class="nb-steps">
<ol>
<li>
<p>Log in to the <a href="https://dash.cloudflare.com/login">Cloudflare dashboard</a> and select your account and domain.</p>
</li>
<li>
<p>Go to <strong>Security</strong> &gt; <strong>Security rules</strong>.</p>
</li>
<li>
<p>Select <strong>Create rule</strong> &gt; <strong>Custom rules</strong>.</p>
</li>
<li>
<p>Enter a rule name.</p>
</li>
<li>
<p>Select <strong>Edit expression</strong> and enter an expression using threat intelligence fields. For example:</p>
</li>
</ol>
<pre><code class="language-txt">any(cf.intel.ip.target_countries[*] == &quot;FR&quot;) and any(cf.intel.ip.datasets[*] == &quot;ddos&quot;)
</code></pre>
<ol start="6">
<li>
<p>Set the action to <em>Log</em> to validate matches before enforcing.</p>
</li>
<li>
<p>Select <strong>Deploy</strong>.</p>
</li>
</ol>
</div>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Threat intelligence fields work with the <a href="/api/resources/rulesets/">Cloudflare API</a> and the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs">Terraform provider</a>. To create a custom rule via the API, refer to <a href="/waf/custom-rules/create-api/">Create a custom rule via API</a>.</p>
<p>Use the following expression to match IP addresses associated with DDoS activity targeting France:</p>
<pre><code class="language-txt">any(cf.intel.ip.target_countries[*] == &quot;FR&quot;) and any(cf.intel.ip.datasets[*] == &quot;ddos&quot;)
</code></pre>
<p>Set the action to <code>log</code> to validate matches before enforcing.</p>
