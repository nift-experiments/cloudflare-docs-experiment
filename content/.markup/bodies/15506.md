

You can combine the previous expression with other [fields](/ruleset-engine/rules-language/fields/) and [functions](/ruleset-engine/rules-language/functions/) of the Rules language. This allows you to customize the rule scope or combine content scanning with other security features. For example:

- The following expression will match requests with malicious content objects uploaded to a specific endpoint:

<table>
<thead>
<tr>
<th>Field</th>
<th>Operator</th>
<th>Value</th>
<th>Logic</th>
</tr>
</thead>
<tbody>
<tr>
<td>Has malicious content object</td>
<td>equals</td>
<td>True</td>
<td>And</td>
</tr>
<tr>
<td>URI Path</td>
<td>contains</td>
<td><code>upload.php</code></td>
<td></td>
</tr>
</tbody>
</table>

Expression when using the editor:

<pre><code class="language-txt">(cf.waf.content_scan.has_malicious_obj and http.request.uri.path contains &quot;upload.php&quot;)
</code></pre>


- The following expression will match requests from bots uploading content objects:

<table>
<thead>
<tr>
<th>Field</th>
<th>Operator</th>
<th>Value</th>
<th>Logic</th>
</tr>
</thead>
<tbody>
<tr>
<td>Has content object</td>
<td>equals</td>
<td>True</td>
<td>And</td>
</tr>
<tr>
<td>Bot Score</td>
<td>less than</td>
<td><code>10</code></td>
<td></td>
</tr>
</tbody>
</table>

Expression when using the editor:

<pre><code class="language-txt">(cf.waf.content_scan.has_obj and cf.bot_management.score lt 10)
</code></pre>
