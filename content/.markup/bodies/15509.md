

Use a `POST` request similar to the following:



<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/content-upload-scan/payloads \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;[
{
  &quot;payload&quot;: &quot;lookup_json_string(http.request.body.raw, \&quot;file\&quot;)&quot;
}
]&#x27;</code></pre>



The above request will add the following expression to the current list of custom scan expressions:

```txt
lookup_json_string(http.request.body.raw, "file")
```
