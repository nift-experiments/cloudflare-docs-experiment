<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<div class="nb-steps">
<ol>
<li>In the Cloudflare dashboard, go to the Security <strong>Settings</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>(Optional) Filter by <strong>Detection tools</strong>.</li>
<li>Under <strong>Malicious uploads detection</strong> &gt; <strong>Configurations</strong>, select the edit icon.</li>
<li>Select <strong>Add content location</strong>.</li>
<li>In <strong>Content location</strong>, enter your custom scan expression. For example:</li>
</ol>
<pre><code class="language-txt">lookup_json_string(http.request.body.raw, &quot;file&quot;)
</code></pre>
<ol start="6">
<li>Select <strong>Save</strong>.</li>
</ol>
</div>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Use a <code>POST</code> request similar to the following:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/content-upload-scan/payloads \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;[
{
  &quot;payload&quot;: &quot;lookup_json_string(http.request.body.raw, \&quot;file\&quot;)&quot;
}
]&#x27;</code></pre>
<p>The above request will add the following expression to the current list of custom scan expressions:</p>
<pre><code class="language-txt">lookup_json_string(http.request.body.raw, &quot;file&quot;)
</code></pre>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Terraform">

<p>Use the <code>cloudflare_content_scanning_expression</code> resource to add a custom scan expression. For example:</p>
<pre><code class="language-terraform">resource &quot;cloudflare_content_scanning_expression&quot; &quot;my_custom_scan_expression&quot; {
  zone_id = var.cloudflare_zone_id
  payload = &quot;lookup_json_string(http.request.body.raw, \&quot;file\&quot;)&quot;
}
</code></pre>
