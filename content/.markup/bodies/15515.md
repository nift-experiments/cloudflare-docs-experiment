<details class="nb-details"><summary>Required API token permissions</summary><div class="nb-details-body">
<p>At least one of the following <a href="/fundamentals/api/reference/permissions/">token permissions</a> is required:</p>
<ul>
<li><code>Zone WAF Write</code></li>
</ul>
</div></details>
<p>Configure the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/ruleset"><code>cloudflare_ruleset</code></a> resource:</p>
<pre><code class="language-tf">resource &quot;cloudflare_ruleset&quot; &quot;zone_custom_firewall_leaked_creds&quot; {
  zone_id     = var.cloudflare_zone_id
  name        = &quot;Phase entry point ruleset for custom rules in my zone&quot;
  description = &quot;&quot;
  kind        = &quot;zone&quot;
  phase       = &quot;http_request_firewall_custom&quot;

  rules = [{
    ref         = &quot;challenge_leaked_username_password&quot;
    description = &quot;Challenge requests with a leaked username and password&quot;
    expression  = &quot;(cf.waf.credential_check.username_and_password_leaked)&quot;
    action      = &quot;managed_challenge&quot;
  }]
}
</code></pre>
