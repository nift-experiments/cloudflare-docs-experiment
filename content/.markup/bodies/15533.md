<div class="nb-steps">
<ol>
<li>In the Cloudflare dashboard, go to the Security <strong>Settings</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>(Optional) Filter by <strong>Detection tools</strong>.</li>
<li>Under <strong>Leaked credential detection</strong> &gt; <strong>Configurations</strong>, select the edit icon.</li>
<li>Select <strong>Add custom username and password location</strong>.</li>
<li>In <strong>Username location</strong> and <strong>Password location</strong> (optional), enter expressions for obtaining the username and the password from the HTTP request. For example, you could use the following expressions:</li>
</ol>
<ul>
<li>Username location:<br/>
<code>lookup_json_string(http.request.body.raw, &quot;user&quot;)</code></li>
<li>Password location:<br/>
<code>lookup_json_string(http.request.body.raw, &quot;secret&quot;)</code></li>
</ul>
<p>This configuration will scan incoming HTTP requests containing a JSON body with a structure similar to the following:</p>
<pre><code class="language-js">{&quot;user&quot;: &quot;&lt;USERNAME&gt;&quot;, &quot;secret&quot;: &quot;&lt;PASSWORD&gt;&quot;}
</code></pre>
<p>Refer to the <a href="/ruleset-engine/rules-language/functions/#lookup_json_string"><code>lookup_json_string()</code></a> documentation for more information on this function.</p>
<ol start="6">
<li>Select <strong>Save</strong>.</li>
</ol>
</div>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Use a <code>POST</code> request similar to the following:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/leaked-credential-checks/detections \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;username&quot;: &quot;lookup_json_string(http.request.body.raw, \&quot;user\&quot;)&quot;,
&quot;password&quot;: &quot;lookup_json_string(http.request.body.raw, \&quot;secret\&quot;)&quot;
}&#x27;</code></pre>
<p>This pair of lookup expressions (for username and password) will scan incoming HTTP requests containing a JSON body with a structure similar to the following:</p>
<pre><code class="language-js">{&quot;user&quot;: &quot;&lt;USERNAME&gt;&quot;, &quot;secret&quot;: &quot;&lt;PASSWORD&gt;&quot;}
</code></pre>
<p>Refer to the <a href="/ruleset-engine/rules-language/functions/#lookup_json_string"><code>lookup_json_string()</code></a> documentation for more information on this function.</p>

<p>Use the <code>cloudflare_leaked_credential_check_rule</code> resource to add a custom detection location. For example:</p>
<pre><code class="language-terraform">resource &quot;cloudflare_leaked_credential_check_rule&quot; &quot;custom_location_example&quot; {
	zone_id = var.cloudflare_zone_id
	username = &quot;lookup_json_string(http.request.body.raw, \&quot;user\&quot;)&quot;
	password = &quot;lookup_json_string(http.request.body.raw, \&quot;secret\&quot;)&quot;
}
</code></pre>
<p>Refer to the <a href="/ruleset-engine/rules-language/functions/#lookup_json_string"><code>lookup_json_string()</code></a> documentation for more information on this function.</p>
