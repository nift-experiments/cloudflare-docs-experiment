<div class="nb-steps">
<ol>
<li>In the Cloudflare dashboard, go to the Security <strong>Settings</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<p>Alternatively, go to the <a href="/waf/custom-rules/create-dashboard/">custom rules creation page</a>, select the <strong>LLM Custom topic</strong> field, and select <strong>Manage custom topics</strong> to open the sidebar.</p>
<ol start="2">
<li>Add a topic by providing:</li>
</ol>
<ul>
<li><strong>Label</strong>: A short, hyphenated identifier (for example, <code>competitors</code>).</li>
<li><strong>Topic Description</strong>: A descriptive English phrase the model uses for classification (for example, <code>seeking info on competitors</code>).</li>
</ul>
<ol start="3">
<li>Select <strong>Save</strong>.</li>
</ol>
</div>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Update your custom topics list using a <code>PUT</code> request:</p>
<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/zones/$ZONE_ID/ai-security/custom-topics&quot; \
  --request PUT \
  --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
  --json '{
    &quot;topics&quot;: [
      {
        &quot;label&quot;: &quot;competitors&quot;,
        &quot;topic&quot;: &quot;seeking info on competitors&quot;
      },
      {
        &quot;label&quot;: &quot;financial-advice&quot;,
        &quot;topic&quot;: &quot;seeking financial advice&quot;
      },
      {
        &quot;label&quot;: &quot;hr-internal&quot;,
        &quot;topic&quot;: &quot;asking about internal HR policies&quot;
      }
    ]
  }'
</code></pre>
<aside class="nb-aside caution">
<p>This request replaces your entire topic list. Include all topics you want to keep, not just new ones.</p>
</aside>
<p>To retrieve your current topics, use a <code>GET</code> request:</p>
<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/zones/$ZONE_ID/ai-security/custom-topics&quot; \
  --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;
</code></pre>
