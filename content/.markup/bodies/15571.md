

Deploy the managed ruleset using a `PUT` request:



<pre class="nb-api-request"><code class="language-bash">curl --request PUT \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/rulesets/phases/{ruleset_phase}/entrypoint \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;rules&quot;: [
  {
    &quot;action&quot;: &quot;execute&quot;,
    &quot;action_parameters&quot;: {
      &quot;id&quot;: &quot;b7cd52df92f74c848cec0c2ed385e336&quot;
    },
    &quot;expression&quot;: &quot;true&quot;
  }
]
}&#x27;</code></pre>



The ID of the AI Security Log Mode Ruleset is <code class="nb-rule-id" title="b7cd52df92f74c848cec0c2ed385e336">d385e336</code>.

To set individual rule actions to `log`, override the rules within the managed ruleset using `action_parameters.overrides`. For more information, refer to [Override a managed ruleset](/ruleset-engine/managed-rulesets/override-managed-ruleset/).
