<div class="nb-steps">
<ol>
<li>In the Cloudflare dashboard, go to the Security <strong>Settings</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Under <strong>AI Security for Apps</strong>, find the <strong>Managed Ruleset</strong> section.</li>
<li>Enable the <strong>AI Security Log Mode Ruleset</strong>.</li>
<li>Set the action to <em>Log</em>.</li>
<li>(Recommended) Configure <a href="/waf/managed-rules/payload-logging/">payload logging</a> so you can decrypt and view the full prompt content alongside detection results.</li>
</ol>
</div>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Deploy the managed ruleset using a <code>PUT</code> request:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request PUT \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/rulesets/phases/{ruleset_phase}/entrypoint \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;rules&quot;: [
  {
    &quot;action&quot;: &quot;execute&quot;,
    &quot;action_parameters&quot;: {
      &quot;id&quot;: &quot;b7cd52df92f74c848cec0c2ed385e336&quot;
    },
    &quot;expression&quot;: &quot;true&quot;
  }
]
}&#x27;</code></pre>
<p>The ID of the AI Security Log Mode Ruleset is <code class="nb-rule-id" title="b7cd52df92f74c848cec0c2ed385e336">d385e336</code>.</p>
<p>To set individual rule actions to <code>log</code>, override the rules within the managed ruleset using <code>action_parameters.overrides</code>. For more information, refer to <a href="/ruleset-engine/managed-rulesets/override-managed-ruleset/">Override a managed ruleset</a>.</p>
