<aside class="nb-aside note">
<p>AI Security for Apps (formerly Firewall for AI) is only available in the <a href="/security/">application security dashboard</a>.</p>
</aside>
<div class="nb-steps">
<ol>
<li>In the Cloudflare dashboard, go to the Security <strong>Settings</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>(Optional) Filter by <strong>Detection tools</strong>.</li>
<li>Turn on <strong>AI Security for Apps</strong>.</li>
</ol>
</div>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Enable the feature using a <code>PUT</code> request similar to the following:</p>
<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/zones/$ZONE_ID/ai-security/settings&quot; \
--request PUT \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--json '{ &quot;enabled&quot;: true }'
</code></pre>
