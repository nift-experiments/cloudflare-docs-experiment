<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<p>To enable <strong>Hotlink Protection</strong> in the dashboard:</p>
<div class="nb-steps">
<ol>
<li>In the Cloudflare dashboard, go to the Security <strong>Settings</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>
<p>(Optional) Filter by <strong>Client-side abuse</strong>.</p>
</li>
<li>
<p>For <strong>Hotlink Protection</strong>, switch the toggle to <strong>On</strong>.</p>
</li>
</ol>
</div>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To enable <strong>Hotlink Protection</strong> with the API, send a <a href="/api/resources/zones/subresources/settings/methods/edit/"><code>PATCH</code></a> request with <code>hotlink_protection</code> as the setting name in the URI path, and the <code>value</code> parameter set to <code>&quot;on&quot;</code>.</p>

</section>
