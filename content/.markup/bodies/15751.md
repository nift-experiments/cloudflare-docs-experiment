<li>Within your application, go to <strong>Traffic</strong> &gt; <strong>Waiting Room</strong>.</li>
<li>Select <strong>Create</strong>.</li>
<li>Customize the <a href="/waiting-room/reference/configuration-settings/">settings</a> for your waiting room. For additional guidance refer to <a href="/waiting-room/reference/best-practices/">Best practices</a>.</li>
<li>Select <strong>Next</strong>.</li>
<li>In this section, you can choose whether to enable <a href="/turnstile/">Turnstile</a> for your waiting room. If you select <strong>Yes</strong>, you will need to choose your <a href="/turnstile/concepts/widget/">Widget mode</a> and define the action to take if a turnstile challenge fails. The available Widget modes and actions depend on your plan type. Refer to the <a href="/waiting-room/plans/">Plans</a> for more details.</li>
<li>If you wish to <a href="/waiting-room/how-to/customize-waiting-room/">customize your waiting room</a>, update the HTML and CSS as needed. If you are using this waiting room to manage traffic for your mobile app or API, enable the JSON response toggle. Make sure that you have set up a <a href="/waiting-room/how-to/json-response/">JSON friendly response</a> for your client (mobile or web app).</li>
<li>Select the <strong>Queuing status code</strong> to determine the HTTP status code that is returned when a user is in the waiting room.</li>
<li>Select <strong>Next</strong>.</li>
<li>Review your settings before saving. If you customized your waiting room, make sure to <a href="/waiting-room/how-to/customize-waiting-room/#preview-waiting-room">preview the result</a>.</li>
<li>Select <strong>Save</strong>. Your new waiting room will be enabled by default.</li>
</ol>

<p>To create a Waiting Room using the API, send a <a href="/api/resources/waiting_rooms/methods/create/"><code>POST</code> request</a> to the <code>/zones/{zone_identifier}/waiting_rooms</code> endpoint:</p>
<ul>
<li>For parameter references, refer to <a href="/waiting-room/reference/configuration-settings/">Configuration settings</a></li>
<li>For authentication instructions, refer to <a href="/fundamentals/api/get-started/create-token/">Create an API token</a>.</li>
<li>For help with endpoints and pagination, refer to <a href="/fundamentals/api/how-to/make-api-calls/">Make API calls</a>.</li>
</ul>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \

--data &#x27;{
&quot;name&quot;: &quot;shop_waiting_room&quot;,
&quot;description&quot;: &quot;Waiting room for webshop&quot;,
&quot;host&quot;: &quot;shop.example.com&quot;,

  &quot;samesite&quot;: &quot;auto&quot;,
