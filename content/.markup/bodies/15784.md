<p>To create a gateway using the dashboard:</p>
<ol>
<li>In the Cloudflare dashboard, go to the <strong>Web3</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Click <strong>Create Gateway</strong>.</li>
<li>Enter the following information:</li>
</ol>
<ul>
<li><strong>Hostname</strong>: Enter a hostname to use as your gateway, which has to be a subdomain of the current Cloudflare zone.</li>
<li><strong>Gateway Description</strong>: Enter a description to help distinguish between different gateways.</li>
<li><strong>Gateway Type</strong>: Select a gateway target of <a href="/web3/ipfs-gateway/concepts/dnslink/">IPFS DNSLink</a>, <a href="/web3/ipfs-gateway/concepts/universal-gateway/">IPFS Universal Path</a>, or <a href="/web3/ethereum-gateway/">Ethereum</a>.</li>
<li><strong>DNSLink</strong>: Only applicable to IPFS gateways, more details at <a href="/web3/ipfs-gateway/concepts/dnslink/#how-is-it-used-with-cloudflare">DNSLink</a>.</li>
</ul>
<ol start="4">
<li>Click <strong>Deploy</strong>.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To create a gateway using the API, send a <a href="/api/resources/web3/subresources/hostnames/methods/create/"><code>POST</code></a> request that includes the following parameters:</p>
<ul>
<li><code>name</code>: The hostname that will point to the target gateway via a <code>CNAME</code> record.</li>
<li><code>target</code>: The gateway target for the hostname (<code>ethereum</code>, <code>ipfs</code>, <code>ipfs_universal_path</code>).</li>
</ul>
<p>If you need help with API authentication, refer to <a href="/fundamentals/api/">Cloudflare API documentation</a>.</p>
<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/zones/{zone_id}/web3/hostnames&quot; \
--header &quot;X-Auth-Email: &lt;EMAIL&gt;&quot; \
--header &quot;X-Auth-Key: &lt;API_KEY&gt;&quot; \
--header &quot;Content-Type: application/json&quot; \
--data '{
  &quot;name&quot;: &quot;gateway.example.com&quot;,
  &quot;description&quot;: &quot;This is my IPFS gateway.&quot;,
  &quot;target&quot;: &quot;ipfs&quot;,
  &quot;dnslink&quot;: &quot;/ipns/onboarding.ipfs.cloudflare.com&quot;
}'
</code></pre>
<p>The response contains the complete definition of the new gateway.</p>
<pre><code class="language-json">{
  &quot;success&quot;: true,
  &quot;errors&quot;: [],
  &quot;messages&quot;: [],
  &quot;result&quot;: {
    &quot;id&quot;: &quot;&lt;WEB3_GATEWAY_ID&gt;&quot;,
    &quot;name&quot;: &quot;gateway.example.com&quot;,
    &quot;description&quot;: &quot;This is my IPFS gateway.&quot;,
    &quot;status&quot;: &quot;active&quot;,
    &quot;target&quot;: &quot;ipfs&quot;,
    &quot;dnslink&quot;: &quot;/ipns/onboarding.ipfs.cloudflare.com&quot;,
    &quot;created_on&quot;: &quot;&lt;CREATED_ON_DATE&gt;&quot;,
    &quot;modified_on&quot;: &quot;&lt;MODIFIED_ON_DATE&gt;&quot;
  }
}
</code></pre>
