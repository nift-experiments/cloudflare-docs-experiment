<p>To edit a gateway using the dashboard:</p>
<ol>
<li>In the Cloudflare dashboard, go to the <strong>Web3</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>On a specific gateway, click <strong>Edit</strong>.</li>
<li>Update the <strong>Gateway Description</strong> and — if editing an <strong>IPFS</strong> gateway — the value for the <a href="/web3/ipfs-gateway/concepts/dnslink/">DNSLink</a>.</li>
<li>Click <strong>Reapply</strong>.</li>
</ol>
