<p>To add an item to the blocklist using the dashboard:</p>
<ol>
<li>In the Cloudflare dashboard, go to the <strong>Web3</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>On a specific gateway, click the dropdown then <strong>Blocklist</strong>.</li>
<li>Click <strong>Add entry</strong>.</li>
<li>Enter the following information:</li>
</ol>
<ul>
<li><strong>Blocklist entry type</strong>: Choose <strong>CID</strong> or <strong>Content path</strong>.</li>
<li><strong>Blocklist entry content</strong>: Add a CID or content path to block, meaning either a valid CIDv0 or CIDv1 string (CID) or the entry should start with <code>/ipfs/</code> or <code>/ipns/</code> (content path).</li>
<li><strong>Blocklist entry description</strong>: Add a description to help you identify the blocklist entry.</li>
</ul>
<ol start="5">
<li>Click <strong>Add</strong>.</li>
</ol>
