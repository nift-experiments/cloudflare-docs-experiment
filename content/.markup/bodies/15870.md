

<div class="nb-steps">

<ol>
<li>
<p>Navigate to the <a href="https://dash.cloudflare.com/?to=/:account/workers/vpc">Workers VPC dashboard</a> and select the <strong>VPC Services</strong> tab.</p>
</li>
<li>
<p>Select <strong>Create</strong> to create a new VPC Service.</p>
</li>
<li>
<p>Enter a <strong>Service name</strong> for your VPC Service (for example, <code>my-private-api</code>).</p>
</li>
<li>
<p>Select your tunnel from the <strong>Tunnel</strong> dropdown, or select <strong>Create Tunnel</strong> if you need to create a new one.</p>
</li>
<li>
<p>Enter the <strong>Host or IP address</strong> of your internal service (for example, <code>localhost</code>, <code>internal-api.company.local</code>, or <code>10.0.1.50</code>).</p>
</li>
<li>
<p>Configure <strong>Ports</strong>. Select either:</p>
</li>
</ol>
<ul>
<li><strong>Use default ports</strong> for standard HTTP (80) and HTTPS (443)</li>
<li><strong>Provide port values</strong> to specify custom HTTP and HTTPS ports</li>
</ul>
<ol start="7">
<li>Configure <strong>DNS Resolver</strong>. Select either:</li>
</ol>
<ul>
<li><strong>Use tunnel as resolver</strong> to use the tunnel's built-in DNS resolution</li>
<li><strong>Custom resolver</strong> and enter your DNS resolver IP (for example, <code>8.8.8.8</code>)</li>
</ul>
<ol start="8">
<li>Select <strong>Create service</strong> to create your VPC Service.</li>
</ol>

</div>

The dashboard will display your new VPC Service with a unique Service ID. Save this Service ID for the next step.
