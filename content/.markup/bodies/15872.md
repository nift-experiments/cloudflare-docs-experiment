
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<div class="nb-steps">
<ol>
<li>
<p>Navigate to the <a href="https://dash.cloudflare.com/?to=/:account/workers/vpc">Workers VPC dashboard</a> and select the <strong>VPC Services</strong> tab.</p>
</li>
<li>
<p>Select <strong>Create</strong> to create a new VPC Service.</p>
</li>
<li>
<p>Enter a <strong>Service name</strong> for your VPC Service (for example, <code>my-private-api</code>).</p>
</li>
<li>
<p>Select your tunnel from the <strong>Tunnel</strong> dropdown, or select <strong>Create Tunnel</strong> if you need to create a new one.</p>
</li>
<li>
<p>Enter the <strong>Host or IP address</strong> of your internal service (for example, <code>localhost</code>, <code>internal-api.company.local</code>, or <code>10.0.1.50</code>).</p>
</li>
<li>
<p>Configure <strong>Ports</strong>. Select either:</p>
</li>
</ol>
<ul>
<li><strong>Use default ports</strong> for standard HTTP (80) and HTTPS (443)</li>
<li><strong>Provide port values</strong> to specify custom HTTP and HTTPS ports</li>
</ul>
<ol start="7">
<li>Configure <strong>DNS Resolver</strong>. Select either:</li>
</ol>
<ul>
<li><strong>Use tunnel as resolver</strong> to use the tunnel's built-in DNS resolution</li>
<li><strong>Custom resolver</strong> and enter your DNS resolver IP (for example, <code>8.8.8.8</code>)</li>
</ul>
<ol start="8">
<li>Select <strong>Create service</strong> to create your VPC Service.</li>
</ol>
</div>
<p>The dashboard will display your new VPC Service with a unique Service ID. Save this Service ID for the next step.</p>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Wrangler CLI">

<p>For an HTTP service:</p>
<pre><code class="language-sh">npx wrangler vpc service create my-private-api \
  --type http \
  --tunnel-id &lt;YOUR_TUNNEL_ID&gt; \
  --hostname &lt;YOUR_HOSTNAME&gt;
</code></pre>
<p>For a TCP service (for example, a PostgreSQL database):</p>
<pre><code class="language-sh">npx wrangler vpc service create my-database \
  --type tcp \
  --tcp-port 5432 \
  --app-protocol postgresql \
  --tunnel-id &lt;YOUR_TUNNEL_ID&gt; \
  --ipv4 &lt;YOUR_IPV4_ADDRESS&gt;
</code></pre>
<p>Replace:</p>
<ul>
<li><code>&lt;YOUR_TUNNEL_ID&gt;</code> with your tunnel ID from step 2</li>
<li><code>&lt;YOUR_HOSTNAME&gt;</code> with your internal service hostname (for example, <code>internal-api.company.local</code>)</li>
<li><code>&lt;YOUR_IPV4_ADDRESS&gt;</code> with the private IP address of your service (for example, <code>10.0.1.50</code>)</li>
</ul>
<p>You can also:</p>
<ul>
<li>Create services using IP addresses by replacing <code>--hostname &lt;YOUR_HOSTNAME&gt;</code> with <code>--ipv4 &lt;YOUR_IPV4_ADDRESS&gt;</code>, <code>--ipv6 &lt;YOUR_IPV6_ADDRESS&gt;</code>, or both for dual-stack configuration</li>
<li>Specify custom ports for HTTP services by adding <code>--http-port &lt;PORT&gt;</code> and/or <code>--https-port &lt;PORT&gt;</code> (for example, <code>--http-port 8080 --https-port 8443</code>)</li>
<li>Set the TLS certificate verification mode with <code>--cert-verification-mode</code> (<code>verify_full</code>, <code>verify_ca</code>, or <code>disabled</code>)</li>
</ul>
<p>The command will return a service ID. Save this for the next step.</p>
