
1. Create and activate a profile for each environment.

<pre><code class="language-sh">wrangler auth create staging
wrangler auth activate staging ~/projects/staging

wrangler auth create production
wrangler auth activate production ~/projects/production
</code></pre>


2. Set the matching `account_id` in each project's [Wrangler configuration file](/workers/wrangler/configuration/).

<div class="nb-wrangler-config">

<pre><code class="language-toml">name = &quot;my-worker&quot;
account_id = &quot;&lt;PRODUCTION_ACCOUNT_ID&gt;&quot;
</code></pre>

</div>
