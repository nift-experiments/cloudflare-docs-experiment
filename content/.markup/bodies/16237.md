<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/accounts/$CLOUDFLARE_ACCOUNT_ID/workers/scripts/$SCRIPT_NAME&quot; \
  -X PUT \
  -H &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
  -F 'metadata={&quot;main_module&quot;:&quot;worker.mjs&quot;,&quot;compatibility_date&quot;:&quot;&lt;YYYY-MM-DD&gt;&quot;};type=application/json' \
  -F 'worker.mjs=@worker.mjs;type=application/javascript+module'
</code></pre>
<p>Call the <a href="/api/operations/worker-subdomain-get-subdomain/">Get Subdomain endpoint</a> with the temporary credentials:</p>
<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/accounts/$CLOUDFLARE_ACCOUNT_ID/workers/subdomain&quot; \
  -H &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;
</code></pre>
<p>For a script available on <code>workers.dev</code>, combine <code>result.subdomain</code> with the script name to create the deployment URL: <code>https://&lt;SCRIPT_NAME&gt;.&lt;SUBDOMAIN&gt;.workers.dev</code>.</p>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="TypeScript SDK">

<p>Use the <a href="https://github.com/cloudflare/cloudflare-typescript">Cloudflare TypeScript SDK</a> for supported resource operations after provisioning the temporary account:</p>
<pre><code class="language-typescript">import Cloudflare from &quot;cloudflare&quot;;

export async function deployWorker(
	accountId: string,
	apiToken: string,
	scriptName: string,
	compatibilityDate: string,
	scriptContent: string,
) {
	const client = new Cloudflare({ apiToken });
	const workerModule = new File([scriptContent], &quot;worker.mjs&quot;, {
		type: &quot;application/javascript+module&quot;,
	});

	await client.workers.scripts.update(scriptName, {
		account_id: accountId,
		metadata: {
			main_module: &quot;worker.mjs&quot;,
			compatibility_date: compatibilityDate,
		},
		files: [workerModule],
	});

	const { subdomain } = await client.workers.subdomains.get({
		account_id: accountId,
	});

	return `https://${scriptName}.${subdomain}.workers.dev`;
}
</code></pre>
