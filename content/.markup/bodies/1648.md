
	<details><summary>Does Copilot support Cloudflare Skills?</summary>

<p>Yes. GitHub Copilot added Agent Skills support for VS Code agent mode, the
Copilot CLI, and the cloud agent. Run <code>npx skills add https://github.com/cloudflare/skills</code> to install them. Refer to the <a href="https://docs.github.com/en/copilot/concepts/agents/about-agent-skills">About
agent
skills</a>
guide for details on where Copilot looks for Skills.</p>

</details>
	<details><summary>Should I use Skills, the MCP server, Wrangler CLI, or all of them?</summary>

<p>All three. Skills load Cloudflare expertise into every agent-mode session.
The Cloudflare API MCP server handles platform operations (DNS, WAF, Zero
Trust, R2 buckets). Wrangler runs local dev and deploys in the VS Code
terminal. The bundled <code>wrangler</code> Skill teaches Copilot when to reach for
which.</p>

</details>
	<details><summary>Do I still need .github/copilot-instructions.md?</summary>

<p>It's complementary. Use custom instructions for simple repository-wide
conventions that apply to almost every task (coding standards, preferred
libraries). Use Skills for detailed, situational guidance Copilot should
only load when relevant.</p>

</details>
	<details><summary>Can Copilot deploy to Cloudflare directly?</summary>

<p>Yes, via Wrangler in the VS Code terminal, or via a GitHub Actions workflow
that Copilot can generate for you.</p>

</details>
