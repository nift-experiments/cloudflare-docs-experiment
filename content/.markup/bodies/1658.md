
	<details><summary>Should I use Skills, the MCP server, Wrangler CLI, or all of them?</summary>

<p>All three work together. Skills give Cursor persistent Cloudflare knowledge
loaded into every Composer prompt. The Cloudflare API MCP server handles
platform operations (DNS, WAF, R2 buckets, Zero Trust). Wrangler runs local
dev and Workers-specific commands. The bundled <code>wrangler</code> Skill teaches
Cursor when to reach for which.</p>

</details>
	<details><summary>How do I give Cursor access to Cloudflare?</summary>

<p>Install the Skills plugin (from the Cursor Marketplace, or Settings &gt; Rules</p>
<blockquote>
<p>Add Rule &gt; Remote Rule with <code>cloudflare/skills</code>). The first time Cursor
calls a Cloudflare tool, you will be redirected to authorize via OAuth and
choose permissions.</p>
</blockquote>

</details>
	<details><summary>Can Cursor deploy to Cloudflare without leaving the IDE?</summary>

<p>Yes. Ask Composer to deploy your project. Cursor runs Wrangler commands in
the integrated terminal and can also call the API MCP server for managed
deploys and resource creation.</p>

</details>
