<p>Dashboard path: <strong>Workers &amp; Pages</strong> overview page &gt; <strong>Protect all Workers</strong>.</p>

<div class="nb-steps">
<ol>
<li>In the Cloudflare dashboard, go to the <strong>Workers &amp; Pages</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Find the <strong>Protect all Workers</strong> card.</li>
<li>If the card says <strong>Not enabled</strong>, select <strong>Enable Access</strong>.</li>
<li>Choose <strong>Previews only</strong> or <strong>All traffic</strong>.</li>
<li>Under <strong>Authentication policy</strong>, select an existing policy or configure one of the <a href="#policy-options">policy options</a>.</li>
<li>Select <strong>Enable Access</strong>.</li>
<li>(Optional) Review the session duration.</li>
</ol>
<p><img src="/assets/upstream/images/workers/access/manage-access-all-workers.png" alt="Manage Access for all Workers dialog showing traffic scope and policy options." /></p>
<ol start="8">
<li>Select <strong>Apply Access</strong>.</li>
</ol>
</div>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To protect only preview deployments for every Worker, create a self-hosted Access application with an <code>all_preview_workers</code> destination:</p>
<pre><code class="language-json">&quot;destinations&quot;: [
  {
    &quot;type&quot;: &quot;all_preview_workers&quot;
  }
]
</code></pre>
<p>To protect every Worker's production and preview deployments, use <code>all_workers</code> instead:</p>
<pre><code class="language-json">&quot;destinations&quot;: [
  {
    &quot;type&quot;: &quot;all_workers&quot;
  }
]
</code></pre>
<p>Send these <code>destinations</code> in a <code>POST /accounts/{account_id}/access/apps</code> request. For the full request schema, including <a href="#policy-options">policy options</a>, session settings, and advanced Access options, refer to the <a href="/api/resources/zero_trust/subresources/access/subresources/applications/methods/create/">Access applications API</a>.</p>

</section>
