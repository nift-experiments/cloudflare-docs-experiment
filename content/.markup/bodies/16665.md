<p>Dashboard path: <strong>Workers &amp; Pages</strong> &gt; select your Worker &gt; <strong>Access</strong>.</p>
<p><img src="/assets/upstream/images/workers/access/worker-access-tab-unprotected.png" alt="Worker Access tab showing an unprotected Worker and the Protect this Worker behind Access button." /></p>
<div class="nb-steps">
<ol>
<li>In the Cloudflare dashboard, go to the <strong>Workers &amp; Pages</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select your Worker from the application list.</li>
<li>Select the <strong>Access</strong> tab.</li>
<li>Select <strong>Protect this Worker behind Access</strong>.</li>
<li>Choose <strong>Previews only</strong> or <strong>All traffic</strong>.</li>
<li>Under <strong>Authentication policy</strong>, select an existing policy or configure one of the <a href="#policy-options">policy options</a>.</li>
<li>(Optional) Review the session duration.</li>
</ol>
<p><img src="/assets/upstream/images/workers/access/enable-access-one-worker.png" alt="Enable Access on one Worker dialog showing traffic scope and policy options." /></p>
<ol start="8">
<li>Select <strong>Apply Access</strong>.</li>
</ol>
</div>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To protect only preview deployments for one Worker, create a self-hosted Access application with a <code>preview_worker</code> destination. Set <code>worker_id</code> to your Worker's ID:</p>
<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/access/apps&quot; \
  --request POST \
  --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
  --json '{
    &quot;type&quot;: &quot;self_hosted&quot;,
    &quot;name&quot;: &quot;Access for my-worker&quot;,
    &quot;destinations&quot;: [
      {
        &quot;type&quot;: &quot;preview_worker&quot;,
        &quot;worker_id&quot;: &quot;c81a2d22c29840ed9d61681a3270dbff&quot;
      }
    ],
    &quot;policies&quot;: [
      {
        &quot;decision&quot;: &quot;allow&quot;,
        &quot;include&quot;: [
          {
            &quot;email_domain&quot;: {
              &quot;domain&quot;: &quot;example.com&quot;
            }
          }
        ]
      }
    ]
  }'
</code></pre>
<p>To protect the Worker's production and preview deployments, use <code>worker</code> instead:</p>
<pre><code class="language-json">&quot;destinations&quot;: [
  {
    &quot;type&quot;: &quot;worker&quot;,
    &quot;worker_id&quot;: &quot;c81a2d22c29840ed9d61681a3270dbff&quot;
  }
]
</code></pre>
<p>For the full request schema, including <a href="#policy-options">policy options</a> and session settings, refer to the <a href="/api/resources/zero_trust/subresources/access/subresources/applications/methods/create/">Access applications API</a>.</p>
