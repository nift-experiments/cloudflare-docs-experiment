
Add the Cloudflare documentation MCP server at
`https://docs.mcp.cloudflare.com/mcp` so Command Code can retrieve
current documentation. Alternatively, point Command Code to
[developers.cloudflare.com/llms.txt](/llms.txt) for a directory of
all products, or `developers.cloudflare.com/<product>/llms.txt`
for a product-specific index.
