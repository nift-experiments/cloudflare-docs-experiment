
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<p>To add environment variables via the dashboard:</p>
<ol>
<li>In the Cloudflare dashboard, go to the <strong>Workers &amp; Pages</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>In <strong>Overview</strong>, select your Worker.</li>
<li>Select <strong>Settings</strong> &gt; <strong>Environment variables</strong>.</li>
</ol>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Wrangler">

<p>To add env variables using Wrangler, define text and JSON via the <code>[vars]</code> configuration in your Wrangler file.</p>
<div class="nb-wrangler-config">
<pre><code class="language-jsonc">{
	&quot;$schema&quot;: &quot;./node_modules/wrangler/config-schema.json&quot;,
	&quot;name&quot;: &quot;my-worker-dev&quot;,
	&quot;vars&quot;: {
		&quot;API_HOST&quot;: &quot;example.com&quot;,
		&quot;API_ACCOUNT_ID&quot;: &quot;example_user&quot;,
		&quot;SERVICE_X_DATA&quot;: {
			&quot;URL&quot;: &quot;service-x-api.dev.example&quot;,
			&quot;MY_ID&quot;: 123
		}
	}
}
</code></pre>
</div>

</section>
