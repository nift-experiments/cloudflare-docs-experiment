<ol>
<li>
<p><strong>Install Codex</strong></p>
<p>Install the Codex CLI. macOS and Linux are fully supported; use WSL2 on Windows. For Homebrew or other install methods, see the <a href="https://developers.openai.com/codex/cli/">Codex CLI setup guide</a>.</p>
</li>
</ol>
<pre><code class="language-bash">npm install -g @openai/codex
</code></pre>
<ol start="2">
<li>
<p><strong>Launch Codex in your project</strong></p>
<p>Start Codex from the root of your project, where <code>wrangler.jsonc</code> lives (if it already exists).</p>
</li>
</ol>
<pre><code class="language-bash">codex
</code></pre>
<ol start="3">
<li>
<p><strong>Install the Cloudflare plugin</strong></p>
<p>Inside Codex, run <code>/plugins</code>, then search for and install <strong>Cloudflare</strong>. This installs Cloudflare Skills and registers the Cloudflare MCP servers.</p>
</li>
</ol>
<pre><code class="language-txt">/plugins
</code></pre>
<ol start="4">
<li>
<p><strong>Try a prompt</strong></p>
<p>For example:</p>
 <pre><code class="language-txt">Help me build and deploy this project on Cloudflare. Review the configuration, implement the required changes, run tests, and explain the result.</code></pre>
</li>
</ol>
