<h3 id="body-16867-supabase-client-setup">Supabase client setup</h3>
<p>To set up an integration with Supabase:</p>
<ol>
<li>
<p>You need to have an existing Supabase database to connect to. <a href="https://supabase.com/docs/guides/database/tables#creating-tables">Create a Supabase database</a> or <a href="https://supabase.com/docs/guides/database/tables#loading-data">have an existing database to connect to Supabase and load data from</a>.</p>
</li>
<li>
<p>Create a <code>countries</code> table with the following query. You can create a table in your Supabase dashboard in two ways:</p>
</li>
</ol>
<ul>
<li>Use the table editor, which allows you to set up Postgres similar to a spreadsheet.</li>
<li>Alternatively, use the <a href="https://supabase.com/docs/guides/database/overview#the-sql-editor">SQL editor</a>:</li>
</ul>
<pre><code class="language-sql">CREATE TABLE countries (
id SERIAL PRIMARY KEY,
name VARCHAR(255) NOT NULL
);
</code></pre>
<ol start="3">
<li>Insert some data in your newly created table. Run the following commands to add countries to your table:</li>
</ol>
<pre><code class="language-sql">INSERT INTO countries (name) VALUES (&#x27;United States&#x27;);
INSERT INTO countries (name) VALUES (&#x27;Canada&#x27;);
INSERT INTO countries (name) VALUES (&#x27;The Netherlands&#x27;);
</code></pre>
<ol start="4">
<li>Configure the Supabase database credentials in your Worker:</li>
</ol>
<p>You need to add your Supabase URL and anon key as secrets to your Worker. Get these from your <a href="https://supabase.com/dashboard">Supabase Dashboard</a> under <strong>Settings</strong> &gt; <strong>API</strong>, then add them as secrets using Wrangler:</p>
<pre><code class="language-sh">&#35; Add the Supabase URL as a secret
npx wrangler secret put SUPABASE_URL
&#35; When prompted, paste your Supabase project URL

&#35; Add the Supabase anon key as a secret
npx wrangler secret put SUPABASE_KEY
&#35; When prompted, paste your Supabase anon/public key
</code></pre>
<ol start="5">
<li>In your Worker, install the <code>@supabase/supabase-js</code> driver to connect to your database and start manipulating data:</li>
</ol>

<ol start="6">
<li>The following example shows how to make a query to your Supabase database in a Worker. The credentials needed to connect to Supabase have been added as secrets to your Worker.</li>
</ol>
<pre><code class="language-js">import { createClient } from &quot;@supabase/supabase-js&quot;;

export default {
	async fetch(request, env) {
		const supabase = createClient(env.SUPABASE_URL, env.SUPABASE_KEY);
		const { data, error } = await supabase.from(&quot;countries&quot;).select(&quot;*&quot;);
		if (error) throw error;
		return new Response(JSON.stringify(data), {
			headers: {
				&quot;Content-Type&quot;: &quot;application/json&quot;,
			},
		});
	},
};
</code></pre>
<p>To learn more about Supabase, refer to <a href="https://supabase.com/docs">Supabase's official documentation</a>.</p>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Hyperdrive">

<p>When connecting to Supabase with Hyperdrive, you connect directly to the underlying Postgres database. This provides the lowest latency for database queries when accessed server-side from Workers. To connect to Supabase using <a href="/hyperdrive">Hyperdrive</a>, follow these steps:</p>
<h2 id="body-16867-1-allow-hyperdrive-access"><ol>
<li>Allow Hyperdrive access</li>
</ol></h2>
<p>You can connect Hyperdrive to any existing Supabase database as the Postgres user which is set up during project creation.
Alternatively, to create a new user for Hyperdrive, run these commands in the <a href="https://supabase.com/dashboard/project/_/sql/new">SQL Editor</a>.</p>
<p>The database endpoint can be found in the <a href="https://supabase.com/dashboard/project/_/settings/database">database settings page</a>.</p>
<p>With a database user, password, database endpoint (hostname and port) and database name (default: postgres), you can now set up Hyperdrive.</p>
<h2 id="body-16867-2-create-a-database-configuration"><ol start="2">
<li>Create a database configuration</li>
</ol></h2>
<p>To configure Hyperdrive, you will need:</p>
<ul>
<li>The IP address (or hostname) and port of your database.</li>
<li>The database username (for example, <code>hyperdrive-demo</code>) you configured in a previous step.</li>
<li>The password associated with that username.</li>
<li>The name of the database you want Hyperdrive to connect to. For example, <code>postgres</code>.</li>
</ul>
<p>Hyperdrive accepts the combination of these parameters in the common connection string format used by database drivers:</p>
<pre><code class="language-txt">postgres://USERNAME:PASSWORD@HOSTNAME_OR_IP_ADDRESS:PORT/database_name
</code></pre>
<p>Most database providers will provide a connection string you can directly copy-and-paste directly into Hyperdrive.</p>

<div class="nb-steps">
<ol>

<p>Create a new <code>Client</code> instance and pass the Hyperdrive <code>connectionString</code>:</p>
<pre><code class="language-ts">// filepath: src/index.ts
import { Client } from &quot;pg&quot;;

export default {
	async fetch(
		request: Request,
		env: Env,
		ctx: ExecutionContext,
	): Promise&lt;Response&gt; {
		// Create a new client instance for each request. Hyperdrive maintains the
		// underlying database connection pool, so creating a new client is fast.
		const client = new Client({
			connectionString: env.HYPERDRIVE.connectionString,
		});

		try {
			// Connect to the database
			await client.connect();

			// Perform a simple query
			const result = await client.query(&quot;SELECT * FROM pg_tables&quot;);

			return Response.json({
				success: true,
				result: result.rows,
			});
		} catch (error: any) {
			console.error(&quot;Database error:&quot;, error.message);

			return new Response(&quot;Internal error occurred&quot;, { status: 500 });
		}
	},
};
</code></pre>
<aside class="nb-aside note">
<p>When connecting to a Supabase database with Hyperdrive, you should use a driver like <a href="/hyperdrive/examples/connect-to-postgres/postgres-drivers-and-libraries/node-postgres/">node-postgres (pg)</a> or <a href="/hyperdrive/examples/connect-to-postgres/postgres-drivers-and-libraries/postgres-js/">Postgres.js</a> to connect directly to the underlying database instead of the <a href="https://github.com/supabase/supabase-js">Supabase JavaScript client</a>. Hyperdrive is optimized for database access for Workers and will perform global connection pooling and fast query routing by connecting directly to your database.</p>
</aside>
