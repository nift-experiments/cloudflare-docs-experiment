
	<details><summary>Should I use Skills, the MCP server, Wrangler CLI, or all of them?</summary>

<p>All three. Skills load Cloudflare knowledge into every Codex session (when
to use Durable Objects, how to structure a Workers project, etc.). The
Cloudflare API MCP server handles platform operations (DNS, WAF, Zero
Trust). Wrangler handles local dev, deploys, and migrations. The bundled
<code>wrangler</code> Skill teaches Codex when to run CLI commands vs. call the MCP
API.</p>

</details>
	<details><summary>How do I connect Codex to my Cloudflare account?</summary>

<p>The first time Codex calls a Cloudflare tool, you will be redirected to
authorize via OAuth and choose permissions.</p>

</details>
