<p>To connect to PlanetScale using <a href="/hyperdrive">Hyperdrive</a>, follow these steps:</p>
<h2 id="body-16878-1-allow-hyperdrive-access"><ol>
<li>Allow Hyperdrive access</li>
</ol></h2>
<p>You can connect Hyperdrive to any existing PlanetScale MySQL-compatible database by creating a new user and fetching your database connection string.</p>
<h3 id="body-16878-planetscale-dashboard">PlanetScale Dashboard</h3>
<ol>
<li>Go to the <a href="https://app.planetscale.com/"><strong>PlanetScale dashboard</strong></a> and select the database you wish to connect to.</li>
<li>Click <strong>Connect</strong>. Enter <code>hyperdrive-user</code> as the password name (or your preferred name) and configure the permissions as desired. Select <strong>Create password</strong>. Note the username and password as they will not be displayed again.</li>
<li>Select <strong>Other</strong> as your language or framework. Note down the database host, database name, database username, and password. You will need these to create a database configuration in Hyperdrive.</li>
</ol>
<p>With the host, database name, username and password, you can now create a Hyperdrive database configuration.</p>
<aside class="nb-aside note">
<p>To reduce latency, use a <a href="/workers/configuration/placement/#configure-explicit-placement-hints">Placement Hint</a> to run your Worker close to your PlanetScale database. This is especially useful when a single request makes multiple queries.</p>
<pre><code class="language-jsonc">{
	&quot;placement&quot;: {
		// Match to your PlanetScale region, for example &quot;gcp:us-east4&quot; or &quot;aws:us-east-1&quot;
		&quot;region&quot;: &quot;gcp:us-east4&quot;,
	},
}
</code></pre>
</aside>
<h2 id="body-16878-2-create-a-database-configuration"><ol start="2">
<li>Create a database configuration</li>
</ol></h2>
<p>To configure Hyperdrive, you will need:</p>
<ul>
<li>The IP address (or hostname) and port of your database.</li>
<li>The database username (for example, <code>hyperdrive-demo</code>) you configured in a previous step.</li>
<li>The password associated with that username.</li>
<li>The name of the database you want Hyperdrive to connect to. For example, <code>mysql</code>.</li>
</ul>
<p>Hyperdrive accepts the combination of these parameters in the common connection string format used by database drivers:</p>
<pre><code class="language-txt">mysql://USERNAME:PASSWORD@HOSTNAME_OR_IP_ADDRESS:PORT/database_name
</code></pre>
<p>Most database providers will provide a connection string you can copy-and-paste directly into Hyperdrive.</p>
<p>To create a Hyperdrive configuration with the <a href="/workers/wrangler/install-and-update/">Wrangler CLI</a>, open your terminal and run the following command.</p>
<ul>
<li>Replace &lt;NAME_OF_HYPERDRIVE_CONFIG&gt; with a name for your Hyperdrive configuration and paste the connection string provided from your database host, or,</li>
<li>Replace <code>user</code>, <code>password</code>, <code>HOSTNAME_OR_IP_ADDRESS</code>, <code>port</code>, and <code>database_name</code> placeholders with those specific to your database:</li>
</ul>
<pre><code class="language-sh">npx wrangler hyperdrive create &lt;NAME_OF_HYPERDRIVE_CONFIG&gt; --connection-string=&quot;mysql://user:password@HOSTNAME_OR_IP_ADDRESS:PORT/database_name&quot;
</code></pre>
<aside class="nb-aside note">
<p>Hyperdrive will attempt to connect to your database with the provided credentials to verify they are correct before creating a configuration. If you encounter an error when attempting to connect, refer to Hyperdrive's <a href="/hyperdrive/observability/troubleshooting/">troubleshooting documentation</a> to debug possible causes.</p>
</aside>
<p>This command outputs a binding for the <a href="/workers/wrangler/configuration/">Wrangler configuration file</a>:</p>
<div class="nb-wrangler-config">
<pre><code class="language-jsonc">{
	&quot;$schema&quot;: &quot;./node_modules/wrangler/config-schema.json&quot;,
	&quot;name&quot;: &quot;hyperdrive-example&quot;,
	&quot;main&quot;: &quot;src/index.ts&quot;,
	&quot;compatibility_date&quot;: &quot;$today&quot;,
	&quot;compatibility_flags&quot;: [
		&quot;nodejs_compat&quot;
	],
	// Pasted from the output of `wrangler hyperdrive create &lt;NAME_OF_HYPERDRIVE_CONFIG&gt; --connection-string=[...]` above.
	&quot;hyperdrive&quot;: [
		{
			&quot;binding&quot;: &quot;HYPERDRIVE&quot;,
			&quot;id&quot;: &quot;&lt;ID OF THE CREATED HYPERDRIVE CONFIGURATION&gt;&quot;
		}
	]
}
</code></pre>
</div>

<p><code>mysql2</code> v3.13.0 or later is required</p>
</aside>
<p>Add the required Node.js compatibility flags and Hyperdrive binding to your <code>wrangler.jsonc</code> file:</p>
<div class="nb-wrangler-config">
<pre><code class="language-jsonc">{
	// required for database drivers to function
	&quot;compatibility_flags&quot;: [
		&quot;nodejs_compat&quot;
	],
	&quot;compatibility_date&quot;: &quot;$today&quot;,
	&quot;hyperdrive&quot;: [
		{
			&quot;binding&quot;: &quot;HYPERDRIVE&quot;,
			&quot;id&quot;: &quot;&lt;your-hyperdrive-id-here&gt;&quot;
		}
	]
}
</code></pre>
</div>
<p>Create a new <code>connection</code> instance and pass the Hyperdrive parameters:</p>
<pre><code class="language-ts">// mysql2 v3.13.0 or later is required
import { createConnection } from &quot;mysql2/promise&quot;;

export default {
	async fetch(request, env, ctx): Promise&lt;Response&gt; {
		// Create a new connection on each request. Hyperdrive maintains the underlying
		// database connection pool, so creating a new connection is fast.
		const connection = await createConnection({
			host: env.HYPERDRIVE.host,
			user: env.HYPERDRIVE.user,
			password: env.HYPERDRIVE.password,
			database: env.HYPERDRIVE.database,
			port: env.HYPERDRIVE.port,

			// Required to enable mysql2 compatibility for Workers
			disableEval: true,
		});

		try {
			// Sample query
			const [results, fields] = await connection.query(&quot;SHOW tables;&quot;);

			// Return result rows as JSON
			return Response.json({ results, fields });
		} catch (e) {
			console.error(e);
			return Response.json(
				{ error: e instanceof Error ? e.message : e },
				{ status: 500 },
			);
		}
	},
} satisfies ExportedHandler&lt;Env&gt;;
</code></pre>
<aside class="nb-aside note">
<p>The minimum version of <code>mysql2</code> required for Hyperdrive is <code>3.13.0</code>.</p>
</aside>
<aside class="nb-aside note">
<p>When connecting to a PlanetScale database with Hyperdrive, you should use a driver like <a href="/hyperdrive/examples/connect-to-postgres/postgres-drivers-and-libraries/node-postgres/">node-postgres (pg)</a> or <a href="/hyperdrive/examples/connect-to-postgres/postgres-drivers-and-libraries/postgres-js/">Postgres.js</a> to connect directly to the underlying database instead of the <a href="https://planetscale.com/docs/tutorials/planetscale-serverless-driver">PlanetScale serverless driver</a>. Hyperdrive is optimized for database access for Workers and will perform global connection pooling and fast query routing by connecting directly to your database.</p>
</aside>

<h2 id="body-16878-set-up-an-integration-with-planetscale">Set up an integration with PlanetScale</h2>
<p>To set up an integration with PlanetScale:</p>
<ol>
<li>
<p>You need to have an existing PlanetScale database to connect to. <a href="https://planetscale.com/docs/tutorials/planetscale-quick-start-guide#create-a-database">Create a PlanetScale database</a> or <a href="https://planetscale.com/docs/imports/database-imports#overview">import an existing database to PlanetScale</a>.</p>
</li>
<li>
<p>From the <a href="https://planetscale.com/docs/concepts/web-console#get-started">PlanetScale web console</a>, create a <code>products</code> table with the following query:</p>
</li>
</ol>
<pre><code class="language-sql">CREATE TABLE products (
  id int NOT NULL AUTO_INCREMENT PRIMARY KEY,
  name varchar(255) NOT NULL,
  image_url varchar(255),
  category_id INT,
  KEY category_id_idx (category_id)
);
</code></pre>
<ol start="3">
<li>Insert some data in your newly created table. Run the following command to add a product and category to your table:</li>
</ol>
<pre><code class="language-sql">INSERT INTO products (name, image_url, category_id)
VALUES (&#x27;Ballpoint pen&#x27;, &#x27;https://example.com/500x500&#x27;, &#x27;1&#x27;);
</code></pre>
<ol start="4">
<li>Configure the PlanetScale database credentials in your Worker:</li>
</ol>
<p>You need to add your PlanetScale database credentials as secrets to your Worker. Get your connection details from the <a href="https://app.planetscale.com">PlanetScale Dashboard</a> by creating a connection string, then add them as secrets using Wrangler:</p>
<pre><code class="language-sh">&#35; Add the database host as a secret
npx wrangler secret put DATABASE_HOST
&#35; When prompted, paste your PlanetScale host

&#35; Add the database username as a secret
npx wrangler secret put DATABASE_USERNAME
&#35; When prompted, paste your PlanetScale username

&#35; Add the database password as a secret
npx wrangler secret put DATABASE_PASSWORD
&#35; When prompted, paste your PlanetScale password
</code></pre>
<ol start="5">
<li>In your Worker, install the <code>@planetscale/database</code> driver to connect to your PlanetScale database and start manipulating data:</li>
</ol>

<ol start="6">
<li>The following example shows how to make a query to your PlanetScale database in a Worker. The credentials needed to connect to PlanetScale have been added as secrets to your Worker.</li>
</ol>
<pre><code class="language-js">import { connect } from &quot;@planetscale/database&quot;;

export default {
	async fetch(request, env) {
		const config = {
			host: env.DATABASE_HOST,
			username: env.DATABASE_USERNAME,
			password: env.DATABASE_PASSWORD,
			// see https://github.com/cloudflare/workerd/issues/698
			fetch: (url, init) =&gt; {
				delete init[&quot;cache&quot;];
				return fetch(url, init);
			},
		};

		const conn = connect(config);
		const data = await conn.execute(&quot;SELECT * FROM products;&quot;);
		return new Response(JSON.stringify(data.rows), {
			status: 200,
			headers: {
				&quot;Content-Type&quot;: &quot;application/json&quot;,
			},
		});
	},
};
</code></pre>
