<p>To connect to Neon using <a href="/hyperdrive">Hyperdrive</a>, follow these steps:</p>
<h2 id="body-16892-1-allow-hyperdrive-access"><ol>
<li>Allow Hyperdrive access</li>
</ol></h2>
<p>You can connect Hyperdrive to any existing Neon database by creating a new user and fetching your database connection string.</p>
<h3 id="body-16892-neon-dashboard">Neon Dashboard</h3>
<ol>
<li>Go to the <a href="https://console.neon.tech/app/projects"><strong>Neon dashboard</strong></a> and select the project (database) you wish to connect to.</li>
<li>Select <strong>Roles</strong> from the sidebar and select <strong>New Role</strong>. Enter <code>hyperdrive-user</code> as the name (or your preferred name) and <strong>copy the password</strong>. Note that the password will not be displayed again: you will have to reset it if you do not save it somewhere.</li>
<li>Select <strong>Dashboard</strong> from the sidebar &gt; go to the <strong>Connection Details</strong> pane &gt; ensure you have selected the <strong>branch</strong>, <strong>database</strong> and <strong>role</strong> (for example,<code>hyperdrive-user</code>) that Hyperdrive will connect through.</li>
<li>Select the <code>psql</code> and <strong>uncheck the connection pooling</strong> checkbox. Note down the connection string (starting with <code>postgres://hyperdrive-user@...</code>) from the text box.</li>
</ol>
<p>With both the connection string and the password, you can now create a Hyperdrive database configuration.</p>
<h2 id="body-16892-2-create-a-database-configuration"><ol start="2">
<li>Create a database configuration</li>
</ol></h2>
<p>To configure Hyperdrive, you will need:</p>
<ul>
<li>The IP address (or hostname) and port of your database.</li>
<li>The database username (for example, <code>hyperdrive-demo</code>) you configured in a previous step.</li>
<li>The password associated with that username.</li>
<li>The name of the database you want Hyperdrive to connect to. For example, <code>postgres</code>.</li>
</ul>
<p>Hyperdrive accepts the combination of these parameters in the common connection string format used by database drivers:</p>
<pre><code class="language-txt">postgres://USERNAME:PASSWORD@HOSTNAME_OR_IP_ADDRESS:PORT/database_name
</code></pre>
<p>Most database providers will provide a connection string you can directly copy-and-paste directly into Hyperdrive.</p>

<p>Create a new <code>Client</code> instance and pass the Hyperdrive <code>connectionString</code>:</p>
<pre><code class="language-ts">// filepath: src/index.ts
import { Client } from &quot;pg&quot;;

export default {
	async fetch(
		request: Request,
		env: Env,
		ctx: ExecutionContext,
	): Promise&lt;Response&gt; {
		// Create a new client instance for each request. Hyperdrive maintains the
		// underlying database connection pool, so creating a new client is fast.
		const client = new Client({
			connectionString: env.HYPERDRIVE.connectionString,
		});

		try {
			// Connect to the database
			await client.connect();

			// Perform a simple query
			const result = await client.query(&quot;SELECT * FROM pg_tables&quot;);

			return Response.json({
				success: true,
				result: result.rows,
			});
		} catch (error: any) {
			console.error(&quot;Database error:&quot;, error.message);

			return new Response(&quot;Internal error occurred&quot;, { status: 500 });
		}
	},
};
</code></pre>
<aside class="nb-aside note">
<p>When connecting to a Neon database with Hyperdrive, you should use a driver like <a href="/hyperdrive/examples/connect-to-postgres/postgres-drivers-and-libraries/node-postgres/">node-postgres (pg)</a> or <a href="/hyperdrive/examples/connect-to-postgres/postgres-drivers-and-libraries/postgres-js/">Postgres.js</a> to connect directly to the underlying database instead of the <a href="https://neon.tech/docs/serverless/serverless-driver">Neon serverless driver</a>. Hyperdrive is optimized for database access for Workers and will perform global connection pooling and fast query routing by connecting directly to your database.</p>

<p>To connect to Neon using <code>@neondatabase/serverless</code>, follow these steps:</p>
<ol>
<li>
<p>You need to have an existing Neon database to connect to. <a href="https://neon.tech/docs/postgres/tutorial-createdb#create-a-table">Create a Neon database</a> or <a href="https://neon.tech/docs/import/import-from-postgres">load data from an existing database to Neon</a>.</p>
</li>
<li>
<p>Create an <code>elements</code> table using the Neon SQL editor. The SQL Editor allows you to query your databases directly from the Neon Console.</p>
</li>
</ol>
<pre><code class="language-sql">CREATE TABLE elements (
  id INTEGER NOT NULL,
  elementName TEXT NOT NULL,
  atomicNumber INTEGER NOT NULL,
  symbol TEXT NOT NULL
);
</code></pre>
<ol start="3">
<li>Insert some data into your newly created table.</li>
</ol>
<pre><code class="language-sql">INSERT INTO elements (id, elementName, atomicNumber, symbol)
VALUES
  (1, &#x27;Hydrogen&#x27;, 1, &#x27;H&#x27;),
  (2, &#x27;Helium&#x27;, 2, &#x27;He&#x27;),

  (4, &#x27;Beryllium&#x27;, 4, &#x27;Be&#x27;),

  (6, &#x27;Carbon&#x27;, 6, &#x27;C&#x27;),

  (8, &#x27;Oxygen&#x27;, 8, &#x27;O&#x27;),
  (9, &#x27;Fluorine&#x27;, 9, &#x27;F&#x27;),
  (10, &#x27;Neon&#x27;, 10, &#x27;Ne&#x27;);

</ol>
