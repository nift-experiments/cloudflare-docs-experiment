<p><code>react-router.config.ts</code> is your <a href="https://reactrouter.com/api/framework-conventions/react-router.config.ts">React Router config file</a>.
In this file:
- <code>ssr</code> is set to <code>true</code>, meaning that your application will use server-side rendering.</p>
<p><code>vite.config.ts</code> is your <a href="https://vite.dev/config/">Vite config file</a>.
The React Router and Cloudflare plugins are included in the <code>plugins</code> array.
The <a href="/workers/vite-plugin/">Cloudflare Vite plugin</a> runs your server code in the Workers runtime, ensuring your local development environment is as close to production as possible.</p>
<p><code>wrangler.jsonc</code> is your <a href="/workers/wrangler/configuration/">Worker config file</a>.
In this file:
- <code>main</code> points to <code>./workers/app.ts</code>.
This is the entry file for your Worker.
The default export includes a <a href="/workers/runtime-apis/fetch/"><code>fetch</code> handler</a>, which delegates the request to React Router.
- If you want to add <a href="/workers/runtime-apis/bindings/">bindings</a> to resources on Cloudflare's developer platform, you configure them here.</p>

</div></details>

3.  **Deploy your project**

Your project can be deployed to a `*.workers.dev` subdomain or a [Custom Domain](/workers/configuration/routing/custom-domains/) from your own machine or from any CI/CD system, including Cloudflare's own [Workers Builds](/workers/ci-cd/builds/).

The following command will build and deploy your project. If you are using CI, ensure you update your ["deploy command"](/workers/ci-cd/builds/configuration/#build-settings) configuration appropriately.
