3. **Add a Wrangler configuration file.**

In your project root, create a [Wrangler configuration file](/workers/wrangler/configuration/) with the following content:

<div class="nb-wrangler-config">

<pre><code class="language-toml">name = &quot;my-app&quot;
main = &quot;.open-next/worker.js&quot;
compatibility_date = &quot;$today&quot;
compatibility_flags = [&quot;nodejs_compat&quot;]

[assets]
directory = &quot;.open-next/assets&quot;
binding = &quot;ASSETS&quot;

[observability]
enabled = true
</code></pre>

</div>

<aside class="nb-aside note">


<p>You must turn on the <a href="/workers/runtime-apis/nodejs/"><code>nodejs_compat</code> compatibility flag</a> and set your <a href="/workers/configuration/compatibility-dates/">compatibility date</a> to <code>2024-09-23</code> or later.</p>


</aside>

4. **Add an OpenNext configuration file.**

In your project root, create `open-next.config.ts`:

<pre><code class="language-ts">import { defineCloudflareConfig } from &quot;@opennextjs/cloudflare&quot;;

export default defineCloudflareConfig();
</code></pre>


Use this file to configure OpenNext features such as caching. For more information, refer to [OpenNext caching](https://opennext.js.org/cloudflare/caching).

5. **Update `package.json`.**

Add scripts for previewing, deploying, and generating Cloudflare types:

<pre><code class="language-json">{
  &quot;scripts&quot;: {
    &quot;preview&quot;: &quot;opennextjs-cloudflare build &amp;&amp; opennextjs-cloudflare preview&quot;,
    &quot;deploy&quot;: &quot;opennextjs-cloudflare build &amp;&amp; opennextjs-cloudflare deploy&quot;,
    &quot;cf-typegen&quot;: &quot;wrangler types --env-interface CloudflareEnv cloudflare-env.d.ts&quot;
  }
}
</code></pre>


<details class="nb-details"><summary>Script usage</summary><div class="nb-details-body">

<ul>
<li><code>preview</code>: Builds your app and serves it locally in the Workers
runtime.</li>
<li><code>deploy</code>: Builds your app and deploys it to Cloudflare Workers.</li>
<li><code>cf-typegen</code>: Generates <code>cloudflare-env.d.ts</code> with Cloudflare binding
types.</li>
</ul>

</div></details>
