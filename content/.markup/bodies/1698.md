
	<details><summary>Should I use Skills, the MCP server, Wrangler CLI, or all of them?</summary>

<p>All three — and the Skills plugin configures them together. Skills give
Claude persistent Cloudflare knowledge (when to use Durable Objects vs KV,
what a good Workers project layout looks like). The Cloudflare API MCP
server handles platform operations (DNS, WAF, R2 buckets, Zero Trust).
Wrangler runs local dev and Workers-specific commands. The <code>wrangler</code> Skill
teaches Claude when to reach for which.</p>

</details>
	<details><summary>How do I give Claude Code access to my Cloudflare account?</summary>

<p>The first time Claude calls a Cloudflare tool, you will be redirected to
authorize via OAuth and choose what permissions to grant.</p>

</details>
	<details><summary>Can Claude Code deploy to existing Workers projects?</summary>

<p>Yes. Run Claude Code from your existing project directory where
<code>wrangler.jsonc</code> is located, and it will understand your project
configuration and deploy accordingly.</p>

</details>
	<details><summary>What does Code Mode mean for MCP?</summary>

<p>Code Mode is how the Cloudflare API MCP server fits all 2,500+ API endpoints
into ~1,000 tokens. Instead of exposing every endpoint as a separate tool,
it exposes two — <code>search()</code> and <code>execute()</code> — and Claude writes JavaScript
to call them. <a href="https://blog.cloudflare.com/code-mode-mcp/">Learn more about Code Mode</a>.</p>

</details>
