

1. Create `src/worker.py` with your flask application:

<pre><code class="language-python">from flask import Flask
from workers import wsgi

app = Flask(__name__)

@app.get(&quot;/&quot;)
def index():
    return {&quot;message&quot;: &quot;Hello from Flask&quot;}

Default = wsgi.entrypoint(app)
</code></pre>


2. In the project root, create `wrangler.jsonc`:

<div class="nb-wrangler-config">

<pre><code class="language-jsonc">{
  &quot;$schema&quot;: &quot;node_modules/wrangler/config-schema.json&quot;,
  &quot;name&quot;: &quot;my-flask-worker&quot;,
  &quot;main&quot;: &quot;src/worker.py&quot;,
  &quot;compatibility_date&quot;: &quot;$today&quot;,
  &quot;compatibility_flags&quot;: [&quot;python_workers&quot;]
}
</code></pre>

</div>

3. Create a `pyproject.toml` to declare dependencies:

<pre><code class="language-toml">[project]
name = &quot;flask-worker&quot;
version = &quot;0.1.0&quot;
requires-python = &quot;&gt;=3.12&quot;
dependencies = [
    &quot;flask&quot;,
]

[dependency-groups]
dev = [
    &quot;workers-py&quot;,
    &quot;workers-runtime-sdk&quot;,
]
</code></pre>


4. Start the local development server:

<pre><code class="language-sh">uv run pywrangler dev
</code></pre>


5. In another terminal, send a request to the Worker:

<pre><code class="language-sh">curl http://localhost:8787/
</code></pre>


The Worker returns:

<pre><code class="language-json">{&quot;message&quot;:&quot;Hello from Flask&quot;}
</code></pre>
