

1. Create a `src/main.py` file with your FastAPI application:
```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def read_root():
    return {"Hello": "World"}

from workers import asgi
Default = asgi.entrypoint(app)
```

2. Create a `wrangler.jsonc` file to configure your Worker:

<div class="nb-wrangler-config">

<pre><code class="language-jsonc">{
    &quot;$schema&quot;: &quot;node_modules/wrangler/config-schema.json&quot;,
	&quot;name&quot;: &quot;my-fastapi-app&quot;,
	&quot;main&quot;: &quot;src/main.py&quot;,
	&quot;compatibility_date&quot;: &quot;$today&quot;,
	&quot;compatibility_flags&quot;: [&quot;python_workers&quot;],
}
</code></pre>

</div>

3. Create a `pyproject.toml` file to manage your dependencies:
```toml
[project]
name = "my-fastapi-app"
version = "0.1.0"
requires-python = ">=3.13"
dependencies = [
    "fastapi",
]

[dependency-groups]
dev = [
    "workers-py",
    "workers-runtime-sdk"
]
```

4. Run your Worker locally:
```bash
uv run pywrangler dev
```

5. In another terminal, send a request to the Worker:

<pre><code class="language-sh">curl http://localhost:8787/
</code></pre>


The Worker returns:

<pre><code class="language-json">{&quot;Hello&quot;: &quot;World&quot;}
</code></pre>
