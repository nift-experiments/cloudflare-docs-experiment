

1. Create a Django project using `pywrangler init`:

<pre><code class="language-bash">uv run pywrangler init django-worker --template https://github.com/cloudflare/python-workers-examples/tree/main/django
cd django-worker
</code></pre>


2. Run your worker locally:

<pre><code class="language-bash">uv run pywrangler dev
</code></pre>
