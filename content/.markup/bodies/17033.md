

<aside class="nb-aside caution">
<h3 class="nb-aside-title" id="body-17033-service-workers-are-deprecated">Service Workers are deprecated</h3>


<p>Service Workers are deprecated, but still supported. We recommend using <a href="/workers/reference/migrate-to-module-workers/">Module Workers</a> instead. New features may not be supported for Service Workers.</p>


</aside>

```js
addEventListener("fetch", (event) => {
	event.respondWith(handleRequest(event.request));
});

/**
 * Respond with hello worker text
 * @param {Request} request
 */
async function handleRequest(request) {
	const { cf } = request;
	const { city, country } = cf;

	console.log(`Request came from city: ${city} in country: ${country}`);

	return new Response("Hello worker!", {
		headers: { "content-type": "text/plain" },
	});
}
```
