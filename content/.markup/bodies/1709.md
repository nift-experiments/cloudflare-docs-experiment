
	<details><summary>Should I use the MCP server, Wrangler CLI, or both?</summary>

<p>Use both. The Cloudflare API MCP server handles Cloudflare account operations,
such as DNS, WAF, R2, and Zero Trust. Wrangler handles local development,
deployments, and migrations. In a Code Project, Bionic can run local shell
commands, including Wrangler commands.</p>

</details>
	<details><summary>How do I give Bionic access to my Cloudflare account?</summary>

<p>Add <code><a href="https://mcp.cloudflare.com/mcp">https://mcp.cloudflare.com/mcp</a></code> as a remote MCP server. When
Bionic prompts you, complete the OAuth authorization flow in your browser and
choose the permissions to grant.</p>

</details>
	<details><summary>Can Bionic deploy existing Workers projects?</summary>

<p>Yes. Create a Code Project from the existing project directory where
<code>wrangler.jsonc</code> is located. You can then ask Bionic to run the
deployment command for that project.</p>

</details>
	<details><summary>What does Code Mode mean for MCP?</summary>

<p>Code Mode is how the Cloudflare API MCP server fits all 2,500+ API endpoints
into about 1,000 tokens. Instead of exposing every endpoint as a separate tool,
it exposes <code>search()</code> and <code>execute()</code>. Bionic writes
JavaScript to call them. For more information, refer to
<a href="https://blog.cloudflare.com/code-mode-mcp/">Code Mode</a>.</p>

</details>
