

1. Create a [`.env` file](/workers/wrangler/environments/#secrets-in-local-development) for local development:

<pre><code class="language-sh">ANTHROPIC_API_KEY=your-api-key-here
</code></pre>


2. Start the dev server:

<pre><code class="language-sh">npx wrangler dev
</code></pre>


3. Start a research task:

<pre><code class="language-sh">curl -X POST http://localhost:8787/research \
  &#45;H &quot;Content-Type: application/json&quot; \
  &#45;d &#x27;{&quot;task&quot;: &quot;Compare open-source LLM projects&quot;}&#x27;
</code></pre>


<pre><code class="language-json">{ &quot;instanceId&quot;: &quot;abc-123-def&quot; }
</code></pre>


4. Check progress (may take a few seconds to complete):

<pre><code class="language-sh">curl &quot;http://localhost:8787/status?instanceId=abc-123-def&quot;
</code></pre>
