

1. Deploy the Worker:

<pre><code class="language-sh">npx wrangler deploy
</code></pre>


2. Add your API key as a secret:

<pre><code class="language-sh">npx wrangler secret put ANTHROPIC_API_KEY
</code></pre>


3. Start a research task on your deployed Worker:

<pre><code class="language-sh">curl -X POST https://durable-ai-agent.&lt;your-subdomain&gt;.workers.dev/research \
  &#45;H &quot;Content-Type: application/json&quot; \
  &#45;d &#x27;{&quot;task&quot;: &quot;Compare open-source LLM projects&quot;}&#x27;
</code></pre>


4. Inspect workflow runs with the CLI:

<pre><code class="language-sh">npx wrangler workflows instances describe research-workflow latest
</code></pre>


This shows every step the agent took, including LLM calls, tool executions, timing, and any retries.

You can also view this in the Cloudflare dashboard under **research-workflow**.
