
	<details><summary>Why does the MCP server only show three tools?</summary>

<p>The Cloudflare API specification is roughly two million tokens, which is far
too large to hand an agent directly. The Cloudflare MCP server uses a
code-execution pattern: the agent gets a tool to search the API spec and a
tool to execute calls, and the spec stays server-side. Three tools is the
correct, healthy state.</p>

</details>
	<details><summary>Does this only work with Visual Studio Code?</summary>

<p>No. The same server URL (<code>https://mcp.cloudflare.com/mcp</code>) works in Claude
Code, Cursor, Claude Desktop, or any MCP-capable client. Visual Studio Code
is one option among many.</p>

</details>
	<details><summary>Can I use a Cloudflare API token instead of OAuth?</summary>

<p>Yes. You can pass a Cloudflare API token as a bearer credential, which makes
sense for CI/CD or shared automation. For interactive editor use, OAuth is
the recommended path. API tokens using Client IP Address Filtering are not
supported.</p>

</details>
	<details><summary>Do I need GitHub Copilot to use MCP in Visual Studio Code?</summary>

<p>Copilot Chat is the MCP client used in this guide, so yes — you need Copilot
(or another MCP-capable extension) to actually drive the server. Visual
Studio Code itself provides the MCP configuration and lifecycle, but the
chat UI comes from Copilot.</p>

</details>
