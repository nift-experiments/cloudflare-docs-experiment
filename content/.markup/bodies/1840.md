
1. **Confirm your Visual Studio Code version**

Open Visual Studio Code and select **Help** > **About**. Confirm you are on a current build. If an **Update** button appears in the title bar, select it and let Visual Studio Code restart before continuing.

![Visual Studio Code Help menu showing the About dialog used to confirm the installed version](/assets/upstream/images/agent-setup/visual-studio-code/vscode-help-about.png)

2. **Sign in to Copilot**

Select the Copilot icon in the Status Bar, select **Use AI Features**, then sign in with a GitHub account. Visual Studio Code opens your browser to authorize.

![Visual Studio Code prompt to enable AI features and sign in with GitHub](/assets/upstream/images/agent-setup/visual-studio-code/vscode-pilot-signin.png)

3. **Authenticate to Copilot**

Follow the browser pages to authenticate to GitHub.

![GitHub sign-in page for authorizing GitHub Copilot](/assets/upstream/images/agent-setup/visual-studio-code/vscode-copilot-login.png)

4. **Create a folder and open it**

Create an empty folder for this project, then open it in Visual Studio Code with **File** > **Open Folder**. For example, `~/cloudflare-api-mcp/`.

![Visual Studio Code Open Folder dialog selecting an empty project folder](/assets/upstream/images/agent-setup/visual-studio-code/vscode-open-folder.png)

5. **Create the configuration file**

Inside the folder, create one file: `.vscode/mcp.json`. Typing `.vscode/mcp.json` in the Explorer creates the folder and file together.

![Visual Studio Code Explorer creating the .vscode/mcp.json configuration file](/assets/upstream/images/agent-setup/visual-studio-code/vscode-create-mcp-json.png)

Paste the following into the file, then save:

<pre><code class="language-json">{
  &quot;servers&quot;: {
    &quot;cloudflare-api&quot;: {
      &quot;type&quot;: &quot;http&quot;,
      &quot;url&quot;: &quot;https://mcp.cloudflare.com/mcp&quot;
    }
  }
}
</code></pre>


<aside class="nb-aside note">


<p>The root key in Visual Studio Code is <code>servers</code>. Configurations written for Cursor or Claude Desktop use <code>mcpServers</code>, which does nothing here.</p>


</aside>

6. **Start the server**

After you save the file, a **Start** link appears on the `cloudflare-api` server definition. It looks like a comment, but it is a button (a [CodeLens](https://learn.microsoft.com/en-us/visualstudio/ide/find-code-changes-and-other-history-with-codelens)). Select it, then allow the authentication prompt. Your browser opens the Cloudflare authorization page.

![Visual Studio Code showing the Start CodeLens on the Cloudflare MCP server definition in mcp.json](/assets/upstream/images/agent-setup/visual-studio-code/vscode-start-cloudflare-mcp.png)

7. **Choose an access template**

The authorization page is where you decide what the agent can access. This example selects **Full access** to modify DNS records. You can also start with **Read only** or build a **Custom** permission set. Scope the grant to a single account, then review what you are granting.

![Cloudflare MCP authorization page showing access templates and account scope options](/assets/upstream/images/agent-setup/visual-studio-code/cloudflare-mcp-access-template.png)

Before you authorize, know two things. **Full access** lets the agent create and delete real resources, which is why this belongs on a demo account. You can revoke the grant at any time from the dashboard under **My Profile** > **Access Management** > **Connected Applications**, which is also the page to visit if a re-authorization behaves unexpectedly.

8. **Verify permissions and authorize**

Review the list of permissions, then select **Authorize** to let the Cloudflare API interact with your account.

![Cloudflare MCP authorization page listing the requested permission groups before authorizing](/assets/upstream/images/agent-setup/visual-studio-code/cloudflare-mcp-confirm-authorization.png)

<aside class="nb-aside note">


<p>You may see 401 errors in the Visual Studio Code logs. This is expected until you select <strong>Allow in this Session</strong> in the authorization prompt.</p>


</aside>

![Visual Studio Code Copilot prompt to allow the Cloudflare MCP server in the current session](/assets/upstream/images/agent-setup/visual-studio-code/vscode-chat-allow-in-this-session.png)

9. **Open Copilot Chat**

If Copilot is minimized, open it with **View** > **Chat**.

![Visual Studio Code View menu opening the Copilot Chat panel](/assets/upstream/images/agent-setup/visual-studio-code/vscode-open-copilot-chat.png)

10. **Confirm the server is running**

The server now shows as running. The CodeLens reads **Running | 3 tools**. Three tools is correct, not a broken install: the server uses a search-and-execute pattern instead of registering thousands of individual endpoints.

![Visual Studio Code CodeLens showing the Cloudflare MCP server running with three tools](/assets/upstream/images/agent-setup/visual-studio-code/vscode-cloudflare-mcp-status.png)

11. **List your zones**

In Copilot Chat, set the mode to **Agent**, then ask it to list your zones. The agent requests your approval before running the call and returns a live list of every domain in the account.

![Copilot Chat returning a list of Cloudflare zones from the account](/assets/upstream/images/agent-setup/visual-studio-code/cloudflare-mcp-list-available-zones.png)

<pre><code class="language-txt">List zones in my account
</code></pre>


<pre><code class="language-txt">Ran Cloudflare API Code Executor

&#45; Zones returned: 1
&#45; Zone: cloudflaredemo.net — id: &lt;ZONE_ID&gt; — status: active
</code></pre>


12. **Create a DNS record**

Ask the agent to create a DNS AAAA record and turn on the Cloudflare proxy. This example points `test.cloudflaredemo.net` at `100::`, a reserved placeholder address from the IPv6 discard prefix `0100::/64` ([RFC 6666](https://www.rfc-editor.org/rfc/rfc6666)). Because the record is proxied, Cloudflare intercepts requests before they reach this address. Approve the tool call (**Always Allow**), and the agent reports the record created.

![Copilot Chat creating a proxied AAAA DNS record through the Cloudflare MCP server](/assets/upstream/images/agent-setup/visual-studio-code/cloudflare-mcp-create-aaaa-record.png)

<pre><code class="language-txt">Create a AAAA record for test.cloudflaredemo.net pointing to 100:: and enable the proxy.
</code></pre>


<pre><code class="language-txt">Ran Cloudflare API Code Executor

&#45; Record created: test.cloudflaredemo.net
&#45; Type: AAAA
&#45; Value: 100::
&#45; Proxied: true
&#45; Record ID: &lt;RECORD_ID&gt;
</code></pre>


Do not rely on the agent's report alone. Open the dashboard and check the zone.

![Cloudflare dashboard DNS records page confirming the new AAAA record exists](/assets/upstream/images/agent-setup/visual-studio-code/cloudflare-dash-verify-dns-record.png)

13. **Verify DNS propagation**

Ask the Cloudflare MCP server to verify that the record propagated.

![Copilot Chat verifying DNS propagation across public resolvers](/assets/upstream/images/agent-setup/visual-studio-code/cloudflare-mcp-verify-dns-propagation.png)

<pre><code class="language-txt">Verify DNS propagation for test.cloudflaredemo.net
</code></pre>


<pre><code class="language-txt">Ran: dig @1.1.1.1 test.cloudflaredemo.net AAAA +short

&#45; Result: DNS resolves to Cloudflare IPv6 addresses (proxy active).
&#45; Resolvers returning AAAA: 1.1.1.1, 8.8.8.8, 9.9.9.9
  &#45; 2606:4700::6812:2f3
  &#45; 2606:4700::6812:3f3
</code></pre>


<aside class="nb-aside note">


<p>Because you turned on the proxy, the response returns Cloudflare-owned IP addresses rather than the origin <code>100::</code> address.</p>


</aside>

14. **Delete the DNS record**

You can delete the record as easily as you created it.

![Copilot Chat deleting the test DNS record through the Cloudflare MCP server](/assets/upstream/images/agent-setup/visual-studio-code/cloudflare-mcp-delete-dns-record.png)

<pre><code class="language-txt">Delete test.cloudflaredemo.net
</code></pre>


<pre><code class="language-txt">Ran Cloudflare API Code Executor

Deleted the DNS record for test.cloudflaredemo.net.
</code></pre>
