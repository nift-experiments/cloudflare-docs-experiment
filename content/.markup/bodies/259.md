<p>To create an account under your tenant using the dashboard:</p>
<ol>
<li>Log into the <a href="https://dash.cloudflare.com">Cloudflare dashboard</a>.</li>
<li>Go to <strong>Tenants</strong> &gt; <strong>Managed Accounts</strong>.</li>
<li>Select <strong>Create Account</strong>.</li>
<li>Enter the <strong>Account Name</strong>, <strong>Account Description</strong>, and <strong>Tenant Unit</strong>.</li>
<li>Choose the appropriate account subscription.</li>
<li>Select <strong>Add Account</strong>.</li>
</ol>

<p>To create an account using the API, make a <code>POST</code> request to the <code>/accounts</code> endpoint and include the following values:</p>
<ul>
<li>
<p><code>name</code> string</p>
</li>
<li>
<p>The name of the account that is displayed in the Cloudflare dashboard.</p>
</li>
<li>
<p><code>type</code> enum</p>
</li>
<li>
<p>Valid values are <code>standard</code> (default) and <code>enterprise</code>. For self-serve customers, use <code>standard</code>. For enterprise customers, use <code>enterprise</code>.</p>
</li>
<li>
<p><code>unit</code> object</p>
</li>
<li>
<p>Information related to the tenant unit.</p>
</li>
<li>
<p><code>id</code> string</p>
<ul>
<li>(optional) ID of the unit to create this account on. Needs to be specified if user administers multiple tenants. Unit ID is the <code>unit_tag</code> from your <a href="/tenant/how-to/get-tenant-details/">tenant details</a>.</li>
</ul>
</li>
</ul>
<h3 id="body-259-know-your-customer-optional">Know-Your-Customer (optional)</h3>
<p>All KYC parameters are text fields, have a 120 character limit, and are optional unless enforced by the Tenant.</p>
<ul>
<li>
<p><code>business_name</code> string</p>
</li>
<li>
<p>(optional) The name of the business associated with this account.</p>
</li>
<li>
<p><code>business_address</code> string</p>
</li>
<li>
<p>(optional) The address of the business associated with this account.</p>
</li>
<li>
<p><code>business_email</code> string</p>
</li>
<li>
<p>(optional) The email of the business associated with this account.</p>
</li>
<li>
<p><code>business_phone</code> string</p>
</li>
<li>
<p>(optional) The phone number of the business associated with this account.</p>
</li>
<li>
<p><code>external_metadata</code> string</p>
</li>
<li>
<p>(optional) External metadata for this account.</p>
</li>
</ul>
