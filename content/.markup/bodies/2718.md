<p>To enable Redirects for AI Training for your zone in the dashboard:</p>
<ol>
<li>Log into the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a> and select your account (you need a Pro or Business plan).</li>
<li>Select the zone you want to configure.</li>

</ol>
<h3 id="body-2718-enable-for-specific-subdomains-or-paths">Enable for specific subdomains or paths</h3>
<p>To enable Redirects for AI Training for specific subdomains or paths instead of your entire zone, create a <a href="/rules/configuration-rules/">configuration rule</a>:</p>
<ol>
<li>Log in to the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a> and select your account.</li>
<li>Select the zone you want to configure.</li>
<li>Go to <strong>Rules</strong> &gt; <strong>Overview</strong> and select <strong>Create rule</strong> &gt; <strong>Configuration Rules</strong>.</li>
<li>Under <strong>When incoming requests match</strong>, build an expression to match your subdomain (for example, <code>http.host eq &quot;docs.example.com&quot;</code>) or path.</li>
<li>Under <strong>Then the settings are</strong>, select <strong>Add setting</strong> &gt; <strong>Redirects for AI Training</strong> and set it to <strong>On</strong>.</li>
<li>Select <strong>Deploy</strong>.</li>
</ol>

<p>To enable Redirects for AI Training for your zone using APIs, send a <code>PATCH</code> to <code>/client/v4/zones/{zone_tag}/settings/redirects_for_ai_training</code> with the payload <code>{&quot;value&quot;: &quot;on&quot;}</code> to the Cloudflare API.</p>
<p>You will need to create an API token with the Zone Settings edit permissions enabled.</p>
<p>Example:</p>
<pre><code class="language-bash">curl -X PATCH 'https://api.cloudflare.com/client/v4/zones/{zone_tag}/settings/redirects_for_ai_training' \
  --header 'Content-Type: application/json' \
  --header &quot;Authorization: Bearer {api_token}&quot; --data-raw '{&quot;value&quot;: &quot;on&quot;}'
</code></pre>
<h3 id="body-2718-enable-for-specific-subdomains-or-paths-1">Enable for specific subdomains or paths</h3>
<p>To enable Redirects for AI Training for specific subdomains or paths instead of your entire zone, create a <a href="/rules/configuration-rules/create-api/">configuration rule</a>:</p>
<pre><code class="language-bash">curl --request PUT \
  --url &quot;https://api.cloudflare.com/client/v4/zones/{zone_id}/rulesets/phases/http_config_settings/entrypoint&quot; \
  --header &quot;Authorization: Bearer {api_token}&quot; \
  --header &quot;Content-Type: application/json&quot; \
  --data '{
    &quot;rules&quot;: [{
      &quot;expression&quot;: &quot;http.host eq \&quot;docs.example.com\&quot;&quot;,
      &quot;action&quot;: &quot;set_config&quot;,
      &quot;action_parameters&quot;: {
        &quot;redirects_for_ai_training&quot;: true
      },
      &quot;description&quot;: &quot;Enable Redirects for AI Training for docs subdomain&quot;
    }]
  }'
</code></pre>
<p>You can also use path-based expressions like <code>starts_with(http.request.uri.path, &quot;/docs/&quot;)</code>. For more information on building expressions, refer to <a href="/ruleset-engine/rules-language/">Rules language</a>.</p>

<p>If you are using <a href="/cloudflare-for-platforms/cloudflare-for-saas/">Cloudflare for SaaS</a> and want to enable Redirects for AI Training for your <a href="/cloudflare-for-platforms/cloudflare-for-saas/domain-support/">custom hostnames</a>, you have two options:</p>
<h3 id="body-2718-enable-for-all-custom-hostnames">Enable for all custom hostnames</h3>
<p>To enable Redirects for AI Training for all custom hostnames on your SaaS zone:</p>
<ol>
<li>Log into the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a> and select your account.</li>
<li>Select your SaaS zone.</li>
<li>Look for <strong>Quick Actions</strong>.</li>
<li>Toggle the <strong>Redirects for AI Training</strong> button to enable.</li>
</ol>
<h3 id="body-2718-enable-for-specific-custom-hostnames">Enable for specific custom hostnames</h3>
<p>Enabling Redirects for AI Training for specific custom hostnames requires an <a href="/cloudflare-for-platforms/cloudflare-for-saas/plans/">advanced subscription</a> with access to <a href="/cloudflare-for-platforms/cloudflare-for-saas/domain-support/custom-metadata/">custom metadata</a>.</p>
<h4 id="body-2718-step-1-set-custom-metadata-on-the-custom-hostname">Step 1: Set custom metadata on the custom hostname</h4>
<p>When creating or updating a custom hostname via API, add <code>redirects_for_ai_training</code> to the <code>custom_metadata</code> object:</p>
<pre><code class="language-bash">curl --request PATCH \
  --url &quot;https://api.cloudflare.com/client/v4/zones/{zone_id}/custom_hostnames/{custom_hostname_id}&quot; \
  --header &quot;Authorization: Bearer {api_token}&quot; \
  --header &quot;Content-Type: application/json&quot; \
  --data '{
    &quot;custom_metadata&quot;: {
      &quot;redirects_for_ai_training&quot;: &quot;enabled&quot;
    }
  }'
</code></pre>
<h4 id="body-2718-step-2-create-a-configuration-rule">Step 2: Create a Configuration Rule</h4>
<p>Create a Configuration Rule on your SaaS zone that matches custom hostnames with the metadata and enables the feature:</p>
<pre><code class="language-bash">curl --request PUT \
  --url &quot;https://api.cloudflare.com/client/v4/zones/{zone_id}/rulesets/phases/http_config_settings/entrypoint&quot; \
  --header &quot;Authorization: Bearer {api_token}&quot; \
  --header &quot;Content-Type: application/json&quot; \
  --data '{
    &quot;rules&quot;: [{
      &quot;expression&quot;: &quot;lookup_json_string(cf.hostname.metadata, \&quot;redirects_for_ai_training\&quot;) eq \&quot;enabled\&quot;&quot;,
      &quot;action&quot;: &quot;set_config&quot;,
      &quot;action_parameters&quot;: {
        &quot;redirects_for_ai_training&quot;: true
      },
      &quot;description&quot;: &quot;Enable Redirects for AI Training for opted-in custom hostnames&quot;
    }]
  }'
</code></pre>
<p>This will enable the feature on custom hostnames that have the <code>redirects_for_ai_training</code> custom metadata tag set.</p>
