

To set ZDR as the default for Unified Billing using the API:

1. [Create an API token](/fundamentals/api/get-started/create-token/) with the following permissions:
- `AI Gateway - Read`
- `AI Gateway - Edit`
2. Get your [Account ID](/fundamentals/account/find-account-and-zone-ids/).
3. Send a [`PUT` request](/api/resources/ai_gateway/methods/update/) to update the gateway and include `zdr: true` or `zdr: false` in the request body.
