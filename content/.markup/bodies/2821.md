<p>To set ZDR as the default for Unified Billing in the dashboard:</p>
<ol>
<li>Log into the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a> and select your account.</li>
<li>Go to <strong>AI</strong> &gt; <strong>AI Gateway</strong>.</li>
<li>Select your gateway.</li>
<li>Go to <strong>Settings</strong> and toggle <strong>Zero Data Retention (ZDR)</strong>.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To set ZDR as the default for Unified Billing using the API:</p>
<ol>
<li><a href="/fundamentals/api/get-started/create-token/">Create an API token</a> with the following permissions:</li>
</ol>
<ul>
<li><code>AI Gateway - Read</code></li>
<li><code>AI Gateway - Edit</code></li>
</ul>
<ol start="2">
<li>Get your <a href="/fundamentals/account/find-account-and-zone-ids/">Account ID</a>.</li>
<li>Send a <a href="/api/resources/ai_gateway/methods/update/"><code>PUT</code> request</a> to update the gateway and include <code>zdr: true</code> or <code>zdr: false</code> in the request body.</li>
</ol>
