
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Retrieve all custom providers with optional filtering and pagination:</p>
<pre><code class="language-bash"># Run `wrangler whoami` to get your account ID to replace $CLOUDFLARE_ACCOUNT_ID,
# and `wrangler auth token` to get an auth token to replace $CLOUDFLARE_API_TOKEN.
curl &quot;https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/ai-gateway/custom-providers&quot; \
  -H &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;
</code></pre>
<p><strong>Query parameters:</strong></p>
<ul>
<li><code>page</code> (number): Page number (default: <code>1</code>)</li>
<li><code>per_page</code> (number): Items per page (default: <code>20</code>, max: <code>100</code>)</li>
<li><code>enable</code> (boolean): Filter by enabled status</li>
<li><code>beta</code> (boolean): Filter by beta status</li>
<li><code>search</code> (string): Search in id, name, or slug fields</li>
<li><code>order_by</code> (string): Sort field and direction (default: <code>&quot;name ASC&quot;</code>)</li>
</ul>
<p><strong>Examples:</strong></p>
<p>List only enabled providers:</p>
<pre><code class="language-bash"># Run `wrangler whoami` to get your account ID to replace $CLOUDFLARE_ACCOUNT_ID,
# and `wrangler auth token` to get an auth token to replace $CLOUDFLARE_API_TOKEN.
curl &quot;https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/ai-gateway/custom-providers?enable=true&quot; \
  -H &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;
</code></pre>
<p>Search for specific providers:</p>
<pre><code class="language-bash"># Run `wrangler whoami` to get your account ID to replace $CLOUDFLARE_ACCOUNT_ID,
# and `wrangler auth token` to get an auth token to replace $CLOUDFLARE_API_TOKEN.
curl &quot;https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/ai-gateway/custom-providers?search=custom&quot; \
  -H &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;
</code></pre>
