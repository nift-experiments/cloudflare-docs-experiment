<p>Update an existing custom provider. All fields are optional - only include the fields you want to change:</p>
<pre><code class="language-bash"># Run `wrangler whoami` to get your account ID to replace $CLOUDFLARE_ACCOUNT_ID,
# and `wrangler auth token` to get an auth token to replace $CLOUDFLARE_API_TOKEN.
curl -X PATCH &quot;https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/ai-gateway/custom-providers/{provider_id}&quot; \
  -H &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
  -H &quot;Content-Type: application/json&quot; \
  -d '{
    &quot;name&quot;: &quot;Updated Provider Name&quot;,
    &quot;enable&quot;: true,
    &quot;description&quot;: &quot;Updated description&quot;
  }'
</code></pre>
<p><strong>Updatable fields:</strong></p>
<ul>
<li><code>name</code> (string): Provider display name</li>
<li><code>slug</code> (string): Provider identifier</li>
<li><code>base_url</code> (string): API endpoint URL (must be HTTPS)</li>
<li><code>description</code> (string): Provider description</li>
<li><code>link</code> (string): Documentation URL</li>
<li><code>enable</code> (boolean): Active status</li>
<li><code>beta</code> (boolean): Beta flag</li>
<li><code>curl_example</code> (string): Example cURL command</li>
<li><code>js_example</code> (string): Example JavaScript code</li>
</ul>
<p><strong>Examples:</strong></p>
<p>Enable a provider:</p>
<pre><code class="language-bash"># Run `wrangler whoami` to get your account ID to replace $CLOUDFLARE_ACCOUNT_ID,
# and `wrangler auth token` to get an auth token to replace $CLOUDFLARE_API_TOKEN.
curl -X PATCH &quot;https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/ai-gateway/custom-providers/{provider_id}&quot; \
  -H &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
  -H &quot;Content-Type: application/json&quot; \
  -d '{&quot;enable&quot;: true}'
</code></pre>
<p>Update provider URL:</p>
<pre><code class="language-bash"># Run `wrangler whoami` to get your account ID to replace $CLOUDFLARE_ACCOUNT_ID,
# and `wrangler auth token` to get an auth token to replace $CLOUDFLARE_API_TOKEN.
curl -X PATCH &quot;https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/ai-gateway/custom-providers/{provider_id}&quot; \
  -H &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
  -H &quot;Content-Type: application/json&quot; \
  -d '{&quot;base_url&quot;: &quot;https://api.newprovider.com&quot;}'
</code></pre>
<aside class="nb-aside note">
<h3 class="nb-aside-title" id="body-2879-cache-invalidation">Cache invalidation</h3>
<p>Updates to custom providers automatically invalidate any cached entries related to that provider.</p>
</aside>

<p>To update an existing custom provider:</p>
<ol>
<li>Log in to the <a href="https://dash.cloudflare.com">Cloudflare dashboard</a> and select your account.</li>
<li>Go to <a href="https://dash.cloudflare.com/?to=/:account/ai/ai-gateway/custom-providers"><strong>Compute &amp; AI</strong> &gt; <strong>AI Gateway</strong> &gt; <strong>Custom Providers</strong></a>.</li>
<li>Find the custom provider you want to update and select <strong>Edit</strong>.</li>
<li>Update the fields you want to change (name, slug, base URL, etc.).</li>
<li>Select <strong>Save</strong> to apply your changes.</li>
</ol>
