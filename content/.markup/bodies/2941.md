

1. Generate private key:
Use the following command to generate a RSA private key:

<pre><code class="language-bash">openssl genpkey -algorithm RSA -out private_key.pem -pkeyopt rsa_keygen_bits:4096
</code></pre>


2. Generate public key:
After generating the private key, you can extract the corresponding public key using:

<pre><code class="language-bash">openssl rsa -pubout -in private_key.pem -out public_key.pem
</code></pre>
