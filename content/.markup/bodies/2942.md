<ol>
<li>Generate private key:
Use the following command to generate a RSA private key:</li>
</ol>
<pre><code class="language-bash">openssl genpkey -algorithm RSA -out private_key.pem -pkeyopt rsa_keygen_bits:4096
</code></pre>
<ol start="2">
<li>Generate public key:
After generating the private key, you can extract the corresponding public key using:</li>
</ol>
<pre><code class="language-bash">openssl rsa -pubout -in private_key.pem -out public_key.pem
</code></pre>
