<pre><code class="language-js">await env.MY_BUCKET.put(&quot;docs/document.pdf&quot;, fileContent, {

		version: &quot;2.5&quot;,
		is_public: &quot;true&quot;,
	},
});
</code></pre>

<p>Use the <code>Metadata</code> option with the <a href="/r2/api/s3/api/">AWS SDK for JavaScript</a>:</p>
<pre><code class="language-js">import { S3Client, PutObjectCommand } from &quot;@aws-sdk/client-s3&quot;;

const client = new S3Client({
	region: &quot;auto&quot;,
	endpoint: `https://${accountId}.r2.cloudflarestorage.com`,
	credentials: {
		accessKeyId: R2_ACCESS_KEY_ID,
		secretAccessKey: R2_SECRET_ACCESS_KEY,
	},
});

await client.send(
	new PutObjectCommand({
		Bucket: &quot;your-bucket&quot;,
		Key: &quot;docs/document.pdf&quot;,
		Body: fileContent,
		Metadata: {
			category: &quot;documentation&quot;,
			version: &quot;2.5&quot;,
			is_public: &quot;true&quot;,
		},
	}),
);
</code></pre>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Wrangler CLI">

<p>Use the <code>--header</code> flag with <a href="/r2/reference/wrangler-commands/">Wrangler</a> to set <code>x-amz-meta-*</code> headers:</p>
<pre><code class="language-sh">wrangler r2 object put your-bucket/docs/document.pdf \
  --file=./document.pdf \
  --header=&quot;x-amz-meta-category:documentation&quot; \
  --header=&quot;x-amz-meta-version:2.5&quot; \
  --header=&quot;x-amz-meta-is_public:true&quot;
</code></pre>
