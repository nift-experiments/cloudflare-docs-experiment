

<div class="nb-steps">

</ol>
<pre><code class="language-bash">npm install @cloudflare/ai-search-snippet
</code></pre>

<li>In your component file (for example, <code>src/App.vue</code>), import the package and add the component:</li>
</ol>
<pre><code class="language-vue">&lt;template&gt;
	&lt;search-bar-snippet :api-url=&quot;apiUrl&quot; placeholder=&quot;Search...&quot; /&gt;
&lt;/template&gt;

&lt;script setup&gt;
import &quot;@cloudflare/ai-search-snippet&quot;;

const apiUrl = &quot;https://&lt;PUBLIC_ENDPOINT_ID&gt;.search.ai.cloudflare.com/&quot;;
&lt;/script&gt;
</code></pre>
<ol start="3">
<li>Before testing, <a href="#configure-cors-for-local-testing">configure CORS</a> to allow your local origin. Then run your development server:</li>
</ol>
<pre><code class="language-bash">npm run dev
</code></pre>
