
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="React">

<div class="nb-steps">
<ol>
<li>Open your React project and install the package:</li>
</ol>
<pre><code class="language-bash">npm install @cloudflare/ai-search-snippet
</code></pre>
<ol start="2">
<li>In your component file (for example, <code>src/App.tsx</code>), import the package:</li>
</ol>
<pre><code class="language-tsx">import &quot;@cloudflare/ai-search-snippet&quot;;
</code></pre>
<ol start="3">
<li>Add a component to your JSX:</li>
</ol>
<pre><code class="language-tsx">export default function App() {
	return (
		&lt;search-bar-snippet
			api-url=&quot;https://&lt;PUBLIC_ENDPOINT_ID&gt;.search.ai.cloudflare.com/&quot;
			placeholder=&quot;Search...&quot;
		/&gt;
	);
}
</code></pre>
<ol start="4">
<li>Before testing, <a href="#configure-cors-for-local-testing">configure CORS</a> to allow your local origin. Then run your development server:</li>
</ol>
<pre><code class="language-bash">npm run dev
</code></pre>
</div>
<p>The package includes TypeScript types and works with React, Next.js, and other React frameworks.</p>
