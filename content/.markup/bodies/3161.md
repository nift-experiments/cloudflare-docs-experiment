

The following metric groups are available. Each group exposes multiple fields — use GraphQL introspection or the [GraphQL API Explorer](/analytics/graphql-api/getting-started/explore-graphql-schema/) to discover the full list.

<table>
<thead>
<tr>
<th>Group</th>
<th>Examples</th>
<th>Description</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>count</code></td>
<td>—</td>
<td>Number of metric samples received.</td>
</tr>
<tr>
<td><code>avg</code></td>
<td><code>memory</code>, <code>cpuUtilization</code>, <code>rxBandwidthBps</code>, <code>txBandwidthBps</code>, <code>gpuMemory</code>, <code>containerUptime</code></td>
<td>Average of the metric over the selected time range.</td>
</tr>
<tr>
<td><code>sum</code></td>
<td><code>cpuTimeSec</code>, <code>allocatedMemory</code>, <code>allocatedDisk</code>, <code>allocatedCpu</code>, <code>rxBytes</code>, <code>txBytes</code>, <code>containerUptime</code></td>
<td>Total value of the metric over the selected time range.</td>
</tr>
<tr>
<td><code>max</code></td>
<td><code>memory</code>, <code>cpuUtilization</code>, <code>diskUsage</code>, <code>diskUsagePercentage</code>, <code>rxBandwidthBps</code>, <code>txBandwidthBps</code>, <code>containerUptime</code></td>
<td>Maximum observed value of the metric.</td>
</tr>
<tr>
<td><code>quantiles</code></td>
<td><code>memory</code>, <code>cpuUtilization</code>, <code>rxBandwidthBps</code>, <code>txBandwidthBps</code>, <code>diskUsage</code>, <code>diskUsagePercentage</code>, <code>gpuMemory</code>, <code>containerUptime</code></td>
<td>Weighted quantiles. Each metric is available with a <code>P50</code>, <code>P95</code>, or <code>P99</code> suffix (for example, <code>memoryP95</code>).</td>
</tr>
