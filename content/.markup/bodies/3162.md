

You can group results by any of the following dimensions:

<table>
<thead>
<tr>
<th>Dimension</th>
<th>Description</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>instanceId</code></td>
<td>The container instance ID. This is the same ID shown in the Cloudflare dashboard and by <a href="/workers/wrangler/">Wrangler</a>.</td>
</tr>
<tr>
<td><code>placementId</code></td>
<td>A single container instance can be placed in different locations over its lifetime (for example, when moved between data centers). Group by <code>placementId</code> to separate metrics across each placement.</td>
</tr>
<tr>
<td><code>applicationId</code></td>
<td>The Containers application the instance belongs to.</td>
</tr>
<tr>
<td><code>location</code></td>
<td>The Cloudflare data center where the container is running.</td>
</tr>
<tr>
<td><code>region</code></td>
<td>The region the container is running in.</td>
</tr>
<tr>
<td><code>label(name: &quot;...&quot;)</code></td>
<td>The value of a specific container label. See <a href="#filter-and-group-by-labels">Filter and group by labels</a>.</td>
</tr>
<tr>
<td><code>date</code>, <code>datetime</code>, <code>datetimeMinute</code>, <code>datetimeFiveMinutes</code>, <code>datetimeFifteenMinutes</code>, <code>datetimeHour</code>, <code>datetimeSixHours</code></td>
<td>Time buckets of varying granularity.</td>
</tr>
</tbody>
</table>
