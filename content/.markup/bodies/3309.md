  --data '{

<p>Your Worker will call <code>env.ARTIFACTS.create()</code> and return three values you will need for Git operations:</p>
<pre><code class="language-json">{
	&quot;name&quot;: &quot;starter-repo&quot;,
	&quot;remote&quot;: &quot;https://&lt;ACCOUNT_ID&gt;.artifacts.cloudflare.net/git/default/starter-repo.git&quot;,
	&quot;token&quot;: &quot;art_v1_0123456789abcdef0123456789abcdef01234567?expires=1760000000&quot;
}
</code></pre>
<ul>
<li><code>name</code>: the repo name. Must be unique within the namespace.</li>
<li><code>remote</code>: the Git remote URL for this repo. <code>&lt;ACCOUNT_ID&gt;</code> will be your actual Cloudflare account ID.</li>
<li><code>token</code>: a short-lived credential for Git operations. The token encodes its expiry directly in the <code>?expires=</code> suffix as a Unix timestamp.</li>
</ul>
<p>Copy the <code>remote</code> and <code>token</code> values into local shell variables:</p>
<pre><code class="language-sh">export ARTIFACTS_REMOTE=&quot;&lt;PASTE_REMOTE_FROM_RESPONSE&gt;&quot;
export ARTIFACTS_TOKEN=&quot;&lt;PASTE_TOKEN_FROM_RESPONSE&gt;&quot;
</code></pre>
