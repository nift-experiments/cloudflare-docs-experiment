<pre><code class="language-bash">curl --request POST &quot;$ARTIFACTS_BASE_URL/repos&quot; \
  --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
  --header &quot;Content-Type: application/json&quot; \
  --data &quot;{\&quot;name\&quot;:\&quot;$ARTIFACTS_REPO\&quot;}&quot;
</code></pre>
<p>The response resembles the following:</p>
<pre><code class="language-json">{
	&quot;result&quot;: {
		&quot;id&quot;: &quot;repo_123&quot;,
		&quot;name&quot;: &quot;starter-repo&quot;,
		&quot;description&quot;: null,
		&quot;default_branch&quot;: &quot;main&quot;,
		&quot;remote&quot;: &quot;https://&lt;ACCOUNT_ID&gt;.artifacts.cloudflare.net/git/default/starter-repo.git&quot;,
		&quot;token&quot;: &quot;art_v1_0123456789abcdef0123456789abcdef01234567?expires=1760000000&quot;
	},
	&quot;success&quot;: true,
	&quot;errors&quot;: [],
	&quot;messages&quot;: []
}
</code></pre>
<p>The response includes two values which you will need for Git operations:</p>
<ul>
<li><code>remote</code>: the Git remote URL for this repo. <code>&lt;ACCOUNT_ID&gt;</code> will be your actual Cloudflare account ID. Use this URL for all Git commands (git push, git clone). Note that this uses a different URL than the REST API you used to create the repo.</li>
<li><code>token</code>: a short-lived credential for Git operations. The token encodes its expiry directly in the <code>?expires=</code> suffix as a Unix timestamp.</li>
</ul>
<p>Copy the <code>remote</code> and <code>token</code> values from <code>result</code> into local shell variables:</p>
<pre><code class="language-sh">export ARTIFACTS_REMOTE=&quot;&lt;PASTE_RESULT_REMOTE_FROM_RESPONSE&gt;&quot;
export ARTIFACTS_TOKEN=&quot;&lt;PASTE_RESULT_TOKEN_FROM_RESPONSE&gt;&quot;
</code></pre>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="jq">

<p>Capture the create response once and extract the fields with <code>jq</code>:</p>
<pre><code class="language-bash">CREATE_RESPONSE=$(curl --silent --request POST &quot;$ARTIFACTS_BASE_URL/repos&quot; \
  --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
  --header &quot;Content-Type: application/json&quot; \
  --data &quot;{\&quot;name\&quot;:\&quot;$ARTIFACTS_REPO\&quot;}&quot;)

export ARTIFACTS_REMOTE=$(printf '%s' &quot;$CREATE_RESPONSE&quot; | jq -r '.result.remote')
export ARTIFACTS_TOKEN=$(printf '%s' &quot;$CREATE_RESPONSE&quot; | jq -r '.result.token')
</code></pre>
