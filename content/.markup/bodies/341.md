

Below is a curl example and the associated data being posted to the API.

**API example:**



<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/spectrum/apps \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;dns&quot;: {
  &quot;type&quot;: &quot;CNAME&quot;,
  &quot;name&quot;: &quot;spectrum-cname.example.com&quot;
},
&quot;ip_firewall&quot;: false,
&quot;protocol&quot;: &quot;tcp/22&quot;,
&quot;proxy_protocol&quot;: &quot;off&quot;,
&quot;tls&quot;: &quot;off&quot;,
&quot;origin_dns&quot;: {
  &quot;name&quot;: &quot;cname-to-origin.example.com&quot;,
  &quot;ttl&quot;: 1200
},
&quot;origin_port&quot;: 22
}&#x27;</code></pre>
