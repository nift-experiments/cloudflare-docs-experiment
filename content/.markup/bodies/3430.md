
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<p>To change the Cloudflare plan for a domain in the dashboard:</p>
<div class="nb-steps">
<ol>
<li>
<p>Log in to the <a href="https://dash.cloudflare.com">Cloudflare dashboard</a> and select your account and domain.</p>
</li>
<li>
<p>Go to <strong>Overview</strong>.</p>
</li>
<li>
<p>For Active Subscriptions, select <strong>Change</strong>.</p>
</li>
</ol>
<p><img src="/assets/upstream/images/fundamentals/get-started/change-plan.png" alt="Screenshot of the Overview page with the Plan extension section highlighted" /></p>
<ol start="4">
<li>
<p>Choose the appropriate plan type, then select <strong>Continue</strong>.</p>
</li>
<li>
<p>Select <strong>Confirm</strong>.</p>
</li>
</ol>
</div>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To change the Cloudflare plan for a domain using the API, first send a <a href="/api/resources/zones/subresources/plans/methods/list/"><code>GET</code></a> request to review available subscriptions.</p>
<p>Then, send a <a href="/api/resources/zones/subresources/subscriptions/methods/update/"><code>PUT</code></a> request with your desired plan type in the <code>rate_plan</code> object.</p>

</section>
