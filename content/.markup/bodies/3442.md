

1. Log in to the [Cloudflare dashboard](https://dash.cloudflare.com/) and select your account.
2. Go to **Manage Account** > **Billing**.

<div class="nb-dash-button"></div>

3. Select **Billable Usage**.
4. Select **Create budget alert**.
5. Configure the alert:

<table>
<thead>
<tr>
<th>Field</th>
<th>Description</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>Alert name</strong></td>
<td>A descriptive name for the alert (for example, &quot;R2 spend warning&quot;).</td>
</tr>
<tr>
<td><strong>Description</strong></td>
<td><em>(Optional)</em> A note about when this alert should fire.</td>
</tr>
<tr>
<td><strong>Budget threshold (USD)</strong></td>
<td>The dollar amount that triggers the alert. When your cumulative usage-based spend for the current billing period crosses this value, Cloudflare sends a notification.</td>
</tr>
<tr>
<td><strong>Email recipients</strong></td>
<td>One or more email addresses to notify. Select <strong>Add email</strong> to add additional recipients.</td>
</tr>
</tbody>
</table>

6. Select **Save**.
