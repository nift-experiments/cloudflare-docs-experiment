
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Enterprise">

<p>Enterprise customers have access to all Smart Shield packages, including Smart Shield Advanced.</p>
<h3 id="body-352-smart-shield">Smart Shield</h3>
<p>The base package for reducing origin load through caching and connection optimization.</p>
<ul>
<li>Includes <a href="/smart-shield/configuration/smart-tiered-cache/">Smart Tiered Cache</a> and <a href="/smart-shield/concepts/connection-reuse/">Connection Reuse</a>.</li>
</ul>
<h3 id="body-352-smart-shield-argo">Smart Shield + Argo</h3>
<p>Adds network path optimization on top of the base package. Use when visitors are geographically distant from the origin server.</p>
<ul>
<li>Includes <a href="/smart-shield/configuration/smart-tiered-cache/">Smart Tiered Cache</a>, <a href="/smart-shield/concepts/connection-reuse/">Connection Reuse</a>, and <a href="/smart-shield/configuration/argo/">Argo Smart Routing</a>.</li>
</ul>
<h3 id="body-352-smart-shield-advanced">Smart Shield Advanced</h3>
<p>The full package with additional caching customization through regional and persistent storage options.</p>
<ul>
<li>Includes <a href="/smart-shield/configuration/smart-tiered-cache/">Smart Tiered Cache</a>, <a href="/smart-shield/concepts/connection-reuse/">Connection Reuse</a>, <a href="/smart-shield/configuration/argo/">Argo Smart Routing</a>, <a href="/smart-shield/configuration/regional-tiered-cache/">Regional Tiered Cache</a>, and <a href="/smart-shield/configuration/cache-reserve/">Cache Reserve</a>.</li>
</ul>
<p>Enterprise customers have access to <a href="/smart-shield/configuration/regional-tiered-cache/">Regional Tiered Cache</a> as part of their plan, regardless of which Smart Shield package they use.</p>
<p>Enterprise customers also have the option to configure <a href="/smart-shield/configuration/dedicated-egress-ips/">Dedicated CDN Egress IPs</a>, allowing you to increase origin security by only allowing traffic from a small list of IP addresses. If you are interested, reach out to your account team.</p>
