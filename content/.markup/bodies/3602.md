<p>Sets the HTML content of the page to <code>Hello World!</code> and then takes a screenshot. The option <code>omitBackground</code> hides the default white background and allows capturing screenshots with transparency.</p>
<pre><code class="language-bash">curl -X POST 'https://api.cloudflare.com/client/v4/accounts/&lt;accountId&gt;/browser-rendering/screenshot' \
  -H 'Authorization: Bearer &lt;apiToken&gt;' \
  -H 'Content-Type: application/json' \
  -d '{
    &quot;html&quot;: &quot;Hello World!&quot;,
    &quot;screenshotOptions&quot;: {
      &quot;omitBackground&quot;: true
    }
  }' \
  --output &quot;screenshot.png&quot;
</code></pre>
