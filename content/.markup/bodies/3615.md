<p>Navigate to <code>https://example.com/</code> and inject custom CSS and an external stylesheet. Then return the rendered page as a PDF.</p>
<pre><code class="language-bash">curl -X POST 'https://api.cloudflare.com/client/v4/accounts/&lt;accountId&gt;/browser-rendering/pdf' \
  -H 'Authorization: Bearer &lt;apiToken&gt;' \
  -H 'Content-Type: application/json' \
  -d '{
    &quot;url&quot;: &quot;https://example.com/&quot;,
    &quot;addStyleTag&quot;: [
      { &quot;content&quot;: &quot;body { font-family: Arial; }&quot; }
    ]
  }' \
  --output &quot;output.pdf&quot;
</code></pre>
