
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<p>To create a DNS record in the dashboard:</p>
<ol>
<li>In the Cloudflare dashboard, go to the <strong>DNS Records</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select <strong>Add record</strong>.</li>
<li>Choose an address (<code>A</code>/<code>AAAA</code>) <a href="/dns/manage-dns-records/reference/dns-record-types/">record type</a>.</li>
<li>Complete the required fields, setting the <strong>Proxy status</strong> to <strong>proxied</strong>.</li>
<li>Select <strong>Save</strong>.</li>
</ol>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To create records with the API, use a <a href="/api/resources/dns/subresources/records/methods/create/">POST request</a>. For field definitions, select a record type under the request body specification.</p>

</section>
