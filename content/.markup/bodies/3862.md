<p>To delete Cache Reserve data via API use the following example requests. For more information, refer to the <a href="/api/resources/cache/subresources/cache_reserve/methods/clear/">API documentation</a>.</p>
<p><strong>Request 1: Get Cache Reserve status</strong></p>
<pre class="nb-api-request"><code class="language-bash">curl --request GET \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/cache/cache_reserve \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;</code></pre>
<pre><code class="language-json">{
	&quot;result&quot;: {
		&quot;editable&quot;: true,
		&quot;id&quot;: &quot;cache_reserve&quot;,
		&quot;value&quot;: &quot;off&quot;
	},
	&quot;success&quot;: true,
	&quot;errors&quot;: [],
	&quot;messages&quot;: []
}
</code></pre>
<p>If Cache Reserve is turned off, you can proceed to the Cache Reserve Clear operation.</p>
<p><strong>Request 2: Start Cache Reserve Clear</strong></p>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/cache/cache_reserve_clear \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;</code></pre>
<pre><code class="language-json">{
	&quot;result&quot;: {
		&quot;id&quot;: &quot;cache_reserve_clear&quot;,
		&quot;start_ts&quot;: &quot;2024-06-02T10:00:00.12345Z&quot;,
		&quot;state&quot;: &quot;In-progress&quot;
	},
	&quot;success&quot;: true,
	&quot;errors&quot;: [],
	&quot;messages&quot;: []
}
</code></pre>
