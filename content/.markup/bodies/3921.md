

API action: `set_cache_control`.

```json title="API configuration example"
"action_parameters": {
  "max-age": {
    "operation": "set",
    "value": 3600,
    "cloudflare_only": true
  },
  "stale-if-error": {
    "operation": "remove"
  }
}
```

Refer to [Create a rule via API](/cache/how-to/cache-response-rules/create-api/) for complete API examples.
