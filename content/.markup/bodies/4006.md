
1. In the Cloudflare dashboard, go to the **Web assets** page.

<div class="nb-dash-button"></div>

2. Select the **Client-side resources** tab.
3. Select **Scripts**, **Connections**, or **Cookies** (the available options depend on your plan).
4. Next to a script, connection, or cookie in the list, select **Details**.

<details class="nb-details"><summary>Script and connection details</summary><div class="nb-details-body">

<ul>
<li><strong>Last seen</strong>: How long ago the resource was last detected (in the last 30 days).</li>
<li><strong>First seen at</strong>: The date and time when the resource was first detected.</li>
<li><strong>Seen on host</strong>: The host where the script is being loaded or the connection is being made.</li>
<li><strong>Seen on pages</strong>: The most recent pages where the resource was detected (up to 10 pages).</li>
<li><strong>First seen on</strong>: The page where the resource was first detected.</li>
</ul>
<p>The script details also include the last 10 script versions detected by client-side security.</p>
<aside class="nb-aside note">
<p>The <strong>Hash</strong> value shown in the script details for each script version is an internal identifier. This differs from the file content hash defined by <a href="https://developer.mozilla.org/en-US/docs/Web/Security/Subresource_Integrity">Subresource Integrity (SRI)</a> that is required to be used in <a href="/client-side-security/rules/">content security rules</a>.</p>
</aside>

</div></details>

<details class="nb-details"><summary>Cookie details</summary><div class="nb-details-body">

<ul>
<li>
<p><strong>Type</strong>: A cookie can have the following types:</p>
</li>
<li>
<p><strong>First-party</strong>: Cookies set by the origin server through a <code>set-cookie</code> HTTP response header.</p>
</li>
<li>
<p><strong>Unknown</strong>: All other detected cookies.</p>
</li>
<li>
<p><strong>Domain</strong>: The value of the <code>Domain</code> cookie attribute. When not set or unknown, this value is derived from the host.</p>
</li>
<li>
<p><strong>Path</strong>: The value of the <code>Path</code> cookie attribute. When not set or unknown, this value is derived from the most recent page where the cookie was detected.</p>
</li>
<li>
<p><strong>Last seen</strong>: How long ago the resource was last detected (in the last 30 days).</p>
</li>
<li>
<p><strong>First seen at</strong>: The date and time when the cookie was first detected.</p>
</li>
<li>
<p><strong>Seen on host</strong>: The host where the cookie was first detected.</p>
</li>
<li>
<p><strong>Seen on pages</strong>: The most recent pages where the cookie was detected (up to 10 pages).</p>
</li>
<li>
<p>Additional cookie attributes (only available with Client-Side Security Advanced):</p>
</li>
<li>
<p><strong>Max age</strong>: The value of the <code>Max-Age</code> cookie attribute.</p>
</li>
<li>
<p><strong>Expires</strong>: The value of the <code>Expires</code> cookie attribute.</p>
</li>
<li>
<p><strong>Lifetime</strong>: The approximate cookie lifetime, based on the <code>Max-Age</code> and <code>Expires</code> cookie attributes.</p>
</li>
<li>
<p><strong>HTTP only</strong>: The value of the <code>HttpOnly</code> cookie attribute.</p>
</li>
<li>
<p><strong>Secure</strong>: The value of the <code>Secure</code> cookie attribute.</p>
</li>
<li>
<p><strong>Same site</strong>: The value of the <code>SameSite</code> cookie attribute.</p>
</li>
</ul>
<p>Except for <strong>Domain</strong> and <strong>Path</strong>, <a href="https://developer.mozilla.org/en-US/docs/Web/HTTP/Cookies">standard cookie attributes</a> are only available for first-party cookies, where Cloudflare detected the <code>set-cookie</code> HTTP response header in HTTP traffic.</p>

</div></details>
