<p>To upload a custom certificate in the dashboard, select <strong>Custom certificate</strong> while <a href="/cloudflare-for-platforms/cloudflare-for-saas/domain-support/create-custom-hostnames/">creating your custom hostname</a>.</p>
<p>For information about the <strong>bundle method</strong> options, refer to the <a href="/ssl/edge-certificates/custom-certificates/bundling-methodologies/">Cloudflare SSL/TLS documentation</a>.</p>

<p>The call below will upload a certificate for use with <code>app.example.com</code>.</p>
<p>Note that if you are using an ECC key generated by OpenSSL, you will need to first remove the <code>-----BEGIN EC PARAMETERS-----...-----END EC PARAMETERS-----</code> section of the file.</p>
<ol>
<li>Update the file and build the payload</li>
</ol>
<pre><code class="language-sh">cat app_example_com.pem
</code></pre>
<pre><code class="language-sh">-----BEGIN CERTIFICATE-----
MIIFJDCCBAygAwIBAgIQD0ifmj/Yi5NP/2gdUySbfzANBgkqhkiG9w0BAQsFADBN
MQswCQYDVQQGEwJVUzEVMBMGA1UEChMMRGlnaUNlcnQgSW5jMScwJQYDVQQDEx5E
...
SzSHfXp5lnu/3V08I72q1QNzOCgY1XeL4GKVcj4or6cT6tX6oJH7ePPmfrBfqI/O
OeH8gMJ+FuwtXYEPa4hBf38M5eU5xWG7
-----END CERTIFICATE-----
</code></pre>
<pre><code class="language-sh">MYCERT=&quot;$(cat app_example_com.pem|perl -pe 's/\r?\n/\\n/'|sed -e 's/..$//')&quot;
MYKEY=&quot;$(cat app_example_com.key|perl -pe 's/\r?\n/\\n/'|sed -e's/..$//')&quot;
</code></pre>
<p>With the certificate and key saved to environment variables (using escaped newlines), build the payload:</p>
<pre><code class="language-bash">$ echo $MYCERT
-----BEGIN CERTIFICATE-----\nMIIFJDCCBAygAwIBAgIQD0ifmj/Yi5NP/2gdUySbfzANBgkqhkiG9w0BAQsFADBN\nMQswCQYDVQQGEwJVUzEVMBMGA1UEChMMRGlnaUNlcnQgSW5jMScwJQYDVQQDEx5E...SzSHfXp5lnu/3V08I72q1QNzOCgY1XeL4GKVcj4or6cT6tX6oJH7ePPmfrBfqI/O\nOeH8gMJ+FuwtXYEPa4hBf38M5eU5xWG7\n-----END CERTIFICATE-----\n

$ request_body=$(&lt; &lt;(cat &lt;&lt;EOF
{
  &quot;hostname&quot;: &quot;app.example.com&quot;,
  &quot;ssl&quot;: {
    &quot;custom_certificate&quot;: &quot;$MYCERT&quot;,
    &quot;custom_key&quot;: &quot;$MYKEY&quot;
  }
}
EOF
))
</code></pre>
<ol start="2">
<li>Use a <a href="/api/resources/custom_hostnames/methods/create/"><code>POST</code> request</a> to upload your certificate and key.</li>
</ol>
<aside class="nb-aside note">
<p>The serial number returned is unique to the issuer, but not globally unique. Additionally, it is returned as a string, not an integer.</p>
</aside>
