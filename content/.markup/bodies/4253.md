

The PCAPs API needs both `system` and `type` to be specified to start a capture. A PCAP's `system` is the product or logical subsystem where packets are captured, and a PCAP's `type` is how the captured packets are built into a PCAP file.

Currently, you can only send one collect request per minute for sample PCAPs, and you can only have one running or pending full PCAP at a time.

<details class="nb-details"><summary>Full PCAP</summary><div class="nb-details-body">

<p>For full PCAP requests, refer to the required parameters listed at <a href="/api/resources/magic_transit/subresources/pcaps/methods/create/">Create full PCAP requests</a>. Note that full packet captures require two more parameters than sample packets.</p>
<p>The full PCAP request endpoint also contains optional fields you can use to limit the amount of packets captured. Both full and sample packet requests contain an optional <code>filter_v1</code> parameter you can use to filter packets by IPv4 Source address, for example. For a full list of the filter options, refer to the parameter lists above.</p>
<p>Leave <code>filter_v1</code> empty to collect all packets without any filtering.</p>
<pre><code class="language-bash">curl https://api.cloudflare.com/client/v4/accounts/{account_id}/pcaps \
--header &quot;X-Auth-Email: &lt;EMAIL&gt;&quot; \
--header &quot;X-Auth-Key: &lt;API_KEY&gt;&quot; \
--header &quot;Content-Type: application/json&quot; \
--data '{
  &quot;filter_v1&quot;: {},
  &quot;time_limit&quot;: 300,
  &quot;packet_limit&quot;: 10000,
  &quot;byte_limit&quot;: 100000000,
  &quot;type&quot;: &quot;full&quot;,
  &quot;colo&quot;: &quot;ORD&quot;,
  &quot;system&quot;: &quot;magic-transit&quot;,
  &quot;destination_conf&quot;: &quot;${BUCKET}&quot;
}'
</code></pre>
<p>While the collection is in progress, the response returns the <code>status</code> field as <code>pending</code>. You must wait for the PCAP collection to complete before downloading the file. When the PCAP is ready to download, the status changes to <code>success</code>.</p>
<pre><code class="language-json">{
	&quot;result&quot;: {
		&quot;id&quot;: &quot;7d7c88382f0b4d5daa9587aa45a1a877&quot;,
		&quot;submitted&quot;: &quot;2022-06-02T18:38:22.269047Z&quot;,
		&quot;filter_v1&quot;: {},
		&quot;time_limit&quot;: 300,
		&quot;status&quot;: &quot;pending&quot;,
		&quot;type&quot;: &quot;full&quot;,
		&quot;system&quot;: &quot;magic-transit&quot;,
		&quot;packet_limit&quot;: 10000,
		&quot;byte_limit&quot;: 100000000,
		&quot;colo&quot;: &quot;ORD&quot;,
		&quot;destination_conf&quot;: &quot;gs://&lt;bucket-name&gt;&quot; // Ensure you use a bucket that you created and registered in the Cloudflare dashboard
	},
	&quot;success&quot;: true,
	&quot;errors&quot;: [],
	&quot;messages&quot;: []
}
</code></pre>

<details class="nb-details"><summary>Sample PCAP</summary><div class="nb-details-body">

<p>To create a sample PCAP request, send a JSON body with the required parameter listed at <a href="/api/resources/magic_transit/subresources/pcaps/methods/create/">Create sample PCAP request</a>.</p>
<p>Leave <code>filter_v1</code> to collect all packets without any filtering.</p>
<pre><code class="language-bash">curl https://api.cloudflare.com/client/v4/accounts/{account_id}/pcaps \
--header &quot;X-Auth-Email: &lt;EMAIL&gt;&quot; \
--header &quot;X-Auth-Key: &lt;API_KEY&gt;&quot; \
--header &quot;Content-Type: application/json&quot; \
--data '{
  &quot;filter_v1&quot;: {
    &quot;source_address&quot;: &quot;1.2.3.4&quot;,
    &quot;source_port&quot;: 123,
    &quot;destination_address&quot;: &quot;5.6.7.8&quot;,
    &quot;destination_port&quot;: 80,
    &quot;protocol&quot;: 6
  },
  &quot;time_limit&quot;: 300,
  &quot;packet_limit&quot;: 10000,
  &quot;type&quot;: &quot;simple&quot;,
  &quot;system&quot;: &quot;magic-transit&quot;
}'
</code></pre>
<p>The response is a JSON body that contains the details of the job running to build the packet capture. The response contains a unique identifier for the packet capture request along with the details sent in the request.</p>
<pre><code class="language-json">{
	&quot;result&quot;: {
		&quot;id&quot;: &quot;6d1f0aac13cd40e3900d29f5dd0e8a2b&quot;,
		&quot;submitted&quot;: &quot;2021-12-20T17:29:20.641845Z&quot;,
		&quot;filter_v1&quot;: {
			&quot;source_address&quot;: &quot;1.2.3.4&quot;,
			&quot;source_port&quot;: 123,
			&quot;destination_address&quot;: &quot;5.6.7.8&quot;,
			&quot;destination_port&quot;: 80,
			&quot;protocol&quot;: 6
		},
		&quot;time_limit&quot;: 60,
		&quot;status&quot;: &quot;pending&quot;,
		&quot;packets_remaining&quot;: 0,
		&quot;type&quot;: &quot;simple&quot;,
		&quot;system&quot;: &quot;magic-transit&quot;
	},
	&quot;success&quot;: true,
	&quot;errors&quot;: [],
	&quot;messages&quot;: []
}
</code></pre>

</div></details>
