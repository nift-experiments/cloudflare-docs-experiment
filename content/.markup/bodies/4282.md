<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the Cloudflare dashboard, go to <strong>Networking</strong> &gt; <strong>Routes</strong>.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>In <strong>Virtual networks</strong>, select <strong>Create virtual network</strong>.</li>
<li>Name your virtual network. We recommend using a name related to the location of the corresponding dedicated egress IP. For example, if your users will egress from the Americas, you can name the virtual network <code>vnet-AMER</code>.</li>
<li>Select <strong>Save</strong>.</li>
<li>Repeat Steps 2-4 for each dedicated egress IP you want users to switch between. For example, you can create another virtual network called <code>vnet-EMEA</code> for egress from Europe, the Middle East, and Africa.</li>
</ol>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<ol>
<li>Create a <a href="/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/cloudflared/tunnel-virtual-networks/">virtual network</a> corresponding to one of your dedicated egress IPs. We recommend using a name related to the location of the corresponding dedicated egress IP. For example, if your users will egress from the Americas, you can name the virtual network <code>vnet-AMER</code>.</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/teamnet/virtual_networks \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;comment&quot;: &quot;Virtual network to egress from the Americas&quot;,
&quot;is_default&quot;: false,
&quot;name&quot;: &quot;vnet-AMER&quot;
}&#x27;</code></pre>
<p>For more information, refer to <a href="/api/resources/zero_trust/subresources/networks/subresources/virtual_networks/methods/create/">Create a virtual network</a>.</p>
<ol start="2">
<li>Repeat Step 1 for each dedicated egress IP you want users to switch between. For example, you can create another virtual network called <code>vnet-EMEA</code> for egress from Europe, the Middle East, and Africa.</li>
</ol>

</section>
