<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>Go to <strong>Networking</strong> &gt; <strong>Routes</strong>.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select <strong>Create route</strong>, then choose <strong>Tunnel CIDR</strong>.</li>
<li>Select the tunnel that routes <code>10.0.0.0/8</code> and enter <code>10.0.0.0/8</code> as the network.</li>
<li>Under <strong>Virtual network</strong>, choose your first virtual network. For example, <code>vnet-AMER</code>.</li>
<li>Select <strong>Create route</strong>.</li>
<li>To route <code>10.0.0.0/8</code> over another virtual network, repeat Steps 2-5 using a different virtual network (for example, <code>vnet-EMEA</code>).</li>
<li>Repeat for each virtual network you created and for each private network tunnel route.</li>
</ol>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<ol>
<li>Assign your first virtual network to your private network route. For example, assign <code>vnet-AMER</code> to your tunnel that routes <code>10.0.0.0/8</code>:</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request PATCH \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/teamnet/routes/{route_id} \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;network&quot;: &quot;10.0.0.0/8&quot;,
&quot;tunnel_id&quot;: &quot;&lt;TUNNEL_UUID&gt;&quot;,
&quot;virtual_network_id&quot;: &quot;&lt;VNET_AMER_UUID&gt;&quot;
}&#x27;</code></pre>
<p>For more information, refer to <a href="/api/resources/zero_trust/subresources/networks/subresources/routes/methods/edit/">Update a tunnel route</a>.</p>
<ol start="2">
<li>Repeat this process for each virtual network you created. For example:</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request PATCH \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/teamnet/routes/{route_id} \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;network&quot;: &quot;10.0.0.0/8&quot;,
&quot;tunnel_id&quot;: &quot;&lt;TUNNEL_UUID&gt;&quot;,
&quot;virtual_network_id&quot;: &quot;&lt;VNET_EMEA_UUID&gt;&quot;
}&#x27;</code></pre>
<ol start="3">
<li>Repeat Steps 1-2 for each private network tunnel route.</li>
</ol>
