<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>
<p>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Traffic policies</strong> &gt; <strong>Egress policies</strong>.</p>
</li>
<li>
<p>Select <strong>Add a policy</strong>.</p>
</li>
<li>
<p>Name your policy. We recommend including the country or region traffic will egress from.</p>
</li>
<li>
<p>Add the virtual network with the <em>Virtual Network</em> selector. For example:</p>
</li>
</ol>
<table>
<thead>
<tr>
<th>Selector</th>
<th>Operator</th>
<th>Value</th>
</tr>
</thead>
<tbody>
<tr>
<td>Virtual Network</td>
<td>is</td>
<td><em>vnet-AMER</em></td>
</tr>
</tbody>
</table>
<ol start="5">
<li>
<p>In <strong>Select an egress IP</strong>, choose <strong>Use dedicated Cloudflare egress IPs</strong>. Choose the dedicated IPv4 and IPv6 addresses you want traffic to egress with.</p>
</li>
<li>
<p>Select <strong>Create policy</strong>.</p>
</li>
<li>
<p>Repeat Steps 1-6 to create a separate egress policy for each virtual network you created.</p>
</li>
</ol>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<ol>
<li>Add a Gateway egress policy that matches the corresponding virtual network. For example:</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/rules \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
      		action: &quot;egress&quot;,
      		description: &quot;Egress via North America by connecting to vnet-AMER&quot;,
      		enabled: true,
      		filters: [
      			&quot;egress&quot;
      		],
      		name: &quot;Egress AMER vnet&quot;,
      		precedence: 0,
      		traffic: &quot;net.vnet_id == &lt;VNET_AMER_UUID&gt;&quot;,
      		rule_settings: {
      			egress: {
      				ipv4: &quot;&lt;DEDICATED_IPV4_ADDRESS&gt;&quot;,
      				ipv4_fallback: &quot;&lt;SECONDARY_DEDICATED_IPV6_ADDRESS&gt;&quot;, // Note: Typo in original JSON - suggests IPv6 for fallback
      				ipv6: &quot;&lt;DEDICATED_IPV6_ADDRESS&gt;&quot;,
      			}
      		},
      	}&#x27;</code></pre>
<p>For more information, refer to <a href="/api/resources/zero_trust/subresources/gateway/subresources/rules/methods/create/">Create a Zero Trust Gateway rule</a>.</p>
<ol start="2">
<li>Repeat Step 1 to create an egress policy for each virtual network you created.</li>
</ol>
