

1. In a terminal, log in to your Cloudflare account:

<pre><code class="language-bash">wrangler login
</code></pre>


2. Initiate the project locally:

<pre><code class="language-bash">mkdir ai-agent-wrapper
cd ai-agent-wrapper
wrangler init
</code></pre>


3. Create a Wrangler configuration file:

<pre><code class="language-toml">name = &quot;ai-agent-wrapper&quot;
main = &quot;src/index.js&quot;
compatibility_date = &quot;2023-10-30&quot;

[vars]
&#35; Add any environment variables here
</code></pre>


4. Add your AI provider's API key as a [secret](/workers/configuration/secrets/):

<pre><code class="language-bash">wrangler secret put &lt;OPENAI_API_KEY&gt;
</code></pre>


You can now build the Worker using the `index.js` file created by Wrangler.
