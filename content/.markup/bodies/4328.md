<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Wrangler">

<ol>
<li>In a terminal, log in to your Cloudflare account:</li>
</ol>
<pre><code class="language-bash">wrangler login
</code></pre>
<ol start="2">
<li>Initiate the project locally:</li>
</ol>
<pre><code class="language-bash">mkdir ai-agent-wrapper
cd ai-agent-wrapper
wrangler init
</code></pre>
<ol start="3">
<li>Create a Wrangler configuration file:</li>
</ol>
<pre><code class="language-toml">name = &quot;ai-agent-wrapper&quot;
main = &quot;src/index.js&quot;
compatibility_date = &quot;2023-10-30&quot;

[vars]
&#35; Add any environment variables here
</code></pre>
<ol start="4">
<li>Add your AI provider's API key as a <a href="/workers/configuration/secrets/">secret</a>:</li>
</ol>
<pre><code class="language-bash">wrangler secret put &lt;OPENAI_API_KEY&gt;
</code></pre>
<p>You can now build the Worker using the <code>index.js</code> file created by Wrangler.</p>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the Cloudflare dashboard, go to the <strong>Workers &amp; Pages</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select <strong>Create</strong>.</li>
<li>In <strong>Workers</strong>, choose the <strong>Hello world</strong> template.</li>
<li>Name your worker, then select <strong>Deploy</strong>.</li>
<li>Select your Worker, then go to the <strong>Settings</strong> tab.</li>
<li>Go to <strong>Variables and Secrets</strong>, then select <strong>Add</strong>.</li>
<li>Choose <em>Secret</em> as the type, name your secret (for example, <code>OPENAI_API_KEY</code>), and enter the value of your AI provider's API key in <strong>Value</strong>.</li>
</ol>
<p>You can now build the Worker using the online code editor by selecting <strong>Edit code</strong> on your Worker page.</p>

</section>
