<p>Edit the Wrangler configuration file and add the following information to ensure that the Worker is only accessible using the custom hostname:</p>
<pre><code class="language-diff">name = &quot;ai-agent-wrapper&quot;
main = &quot;src/index.js&quot;
compatibility_date = &quot;2023-10-30&quot;
workers_dev = false

+# Replace with your custom domain
+routes = [
+  { pattern = &quot;&lt;YOUR_CUSTOM_DOMAIN&gt;&quot;, custom_domain = true }
+]

[vars]
# Add any environment variables here
</code></pre>
<p>To publish the worker, run <code>wrangler deploy</code>.</p>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<p>If you built your Worker remotely using the <a href="/workers/get-started/dashboard/">code editor</a> available in the Cloudflare dashboard, you can deploy it by selecting <strong>Deploy</strong>.</p>
<p>To ensure that the Worker is only accessible from the custom hostname:</p>
<ol>
<li>In the Cloudflare dashboard, go to the <strong>Workers &amp; Pages</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select your Worker.</li>
<li>Go to <strong>Settings</strong>.</li>
<li>Within <strong>Domains &amp; Routes</strong>, select <strong>Add</strong>.</li>
<li>Choose <strong>Custom domain</strong>.</li>
<li>Enter your desired custom domain name.</li>
<li>Select <strong>Add domain</strong>.</li>
</ol>
<p>The Worker is now behind an addressable public hostname. Make sure to turn off both <strong>workers.dev</strong> and <strong>Preview URLs</strong> so that the Worker can only be accessed with its custom domain.</p>
