

1. On the end user device, open the Cloudflare One Client and select **Disconnect**.

<aside class="nb-aside note">
<h3 class="nb-aside-title" id="body-4355-what-if-the-end-user-cannot-disconnect">What if the end user cannot disconnect?</h3>


<p>If the end user does not see the <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/configure/settings/#lock-device-client-switch">disconnect button</a>, they will need to enter an <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/configure/settings/#allow-admin-override-codes">admin override code</a>.</p>
<p><a href="#option-b-reset-the-encryption-keys">Resetting the encryption keys</a> may be a faster solution.</p>


</aside>

2. Select **Connect**.
