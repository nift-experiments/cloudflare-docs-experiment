<aside class="nb-aside note">
<h3 class="nb-aside-title" id="body-4357-what-if-the-end-user-cannot-disconnect-1">What if the end user cannot disconnect?</h3>
<p>If the end user's <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/configure/settings/#lock-device-client-switch">connection toggle</a> is locked, they will need an <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/configure/settings/#allow-admin-override-codes">admin override code</a> to be able to disconnect.</p>
<p><a href="#option-b-reset-the-encryption-keys">Resetting the encryption keys</a> may be a faster solution.</p>
</aside>
