</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To start using IDS via the API, first create a new ruleset in the <code>magic-transit-ids-managed</code> phase with a rule which is enabled.</p>
<ol>
<li>
<p>Follow instructions in the <a href="/ruleset-engine/basic-operations/view-rulesets/">Rulesets Engine Page</a> to view all rulesets for your account. You must see a ruleset with phase <code>magic-transit-ids-managed</code> and kind <code>managed</code>. If not, please contact your account team. The managed ruleset ID will be used in the next step.</p>
</li>
<li>
<p>Create a new root ruleset with a single rule in the <code>magic_transit_ids_managed</code> phase by running:</p>
</li>
</ol>
<pre><code class="language-bash">curl https://api.cloudflare.com/client/v4/accounts/{account_id}/rulesets \
--header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \
--header &quot;Content-Type: application/json&quot; \
--data '{
  &quot;name&quot;: &quot;IDS Execute ruleset&quot;,
  &quot;description&quot;: &quot;Ruleset to enable IDS&quot;,
  &quot;kind&quot;: &quot;root&quot;,
  &quot;phase&quot;: &quot;magic_transit_ids_managed&quot;,
  &quot;rules&quot;: [
    {
      &quot;enabled&quot;: true,
      &quot;expression&quot;: &quot;true&quot;,
      &quot;action&quot;: &quot;execute&quot;,
      &quot;description&quot;: &quot;enable ids&quot;,
      &quot;action_parameters&quot;: {
        &quot;id&quot;: &quot;${managed_ruleset_id}&quot;
      }
    }
  ]
}'
</code></pre>
<p>With this ruleset added, IDS will start inspecting packets and report any anomalous traffic. Next, you can <a href="/cloudflare-network-firewall/how-to/use-logpush-with-ids/">configure Logpush</a> to start receiving details about the anomalous traffic.</p>
<ol start="3">
<li>Use the rule created in the previous step to enable or disable IDS. The Rulesets API documentation describes <a href="/ruleset-engine/rulesets-api/update-rule/">how to patch a rule</a>. <br/><br/> For example, the following patch request to set the <code>enabled</code> field to <code>false</code> will disable IDS. The ruleset and rule ID from the ruleset created in the previous step are used below.</li>
</ol>
<pre><code class="language-bash">curl --request PATCH \
https://api.cloudflare.com/client/v4/accounts/{account_id}/rulesets/{root_ruleset_id}/rules/{rule_id} \
--header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \
--header &quot;Content-Type: application/json&quot; \
--data '{
  &quot;enabled&quot;: false,
  &quot;expression&quot;: &quot;true&quot;,
  &quot;action&quot;: &quot;execute&quot;,
  &quot;action_parameters&quot;: {
    &quot;id&quot;: &quot;${managed_ruleset_id}&quot;
  }
}'
</code></pre>
<p>Similarly, sending a patch request with the <code>enabled</code> field set to <code>true</code> will enable IDS.</p>
