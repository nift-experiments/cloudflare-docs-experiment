<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Posture finding">

<ol>
<li>In <a href="https://one.dash.cloudflare.com">Cloudflare One</a>, go to <strong>Cloud &amp; SaaS findings</strong> &gt; <strong>Posture Findings</strong>.</li>
<li>Choose <strong>SaaS</strong> or <strong>Cloud</strong>.</li>
<li>Locate the individual finding, then select <strong>Manage</strong>.</li>
<li>In <strong>Active Instances</strong>, select the file name.</li>
<li>In <strong>Shared Links</strong>, select the linked file instance.</li>
</ol>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Content finding">

<ol>
<li>In <a href="https://one.dash.cloudflare.com">Cloudflare One</a>, go to <strong>Cloud &amp; SaaS findings</strong> &gt; <strong>Content Findings</strong>.</li>
<li>Choose <strong>SaaS</strong> or <strong>Cloud</strong>.</li>
<li>Select the file name of the detected asset.</li>
<li>In <strong>Sharing details</strong>, select the linked file instance.</li>
</ol>

</section>
