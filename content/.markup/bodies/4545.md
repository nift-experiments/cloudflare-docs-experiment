<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>
<p>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Access controls</strong> &gt; <strong>Service credentials</strong> &gt; <strong>Service Tokens</strong>.</p>
</li>
<li>
<p>Select <strong>Create Service Token</strong>.</p>
</li>
<li>
<p>Name the service token. The name allows you to easily identify events related to the token in the logs and to revoke the token individually.</p>
</li>
<li>
<p>Choose a <strong>Service Token Duration</strong>. This sets the expiration date for the token.</p>
</li>
<li>
<p>Select <strong>Generate token</strong>. You will see the generated Client ID and Client Secret for the service token, as well as their respective request headers.</p>
</li>
<li>
<p>Copy the Client Secret.</p>
</li>
</ol>
<aside class="nb-aside caution">
<p>This is the only time Cloudflare Access will display the Client Secret. If you lose the Client Secret, you must generate a new service token.</p>
</aside>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<ol>
<li>Make a <code>POST</code> request to the <a href="/api/resources/zero_trust/subresources/access/subresources/service_tokens/methods/create/">Access Service Tokens</a> endpoint:</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/service_tokens \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;CI/CD token&quot;,
&quot;duration&quot;: &quot;8760h&quot;
}&#x27;</code></pre>
<ol start="2">
<li>Copy the <code>client_id</code> and <code>client_secret</code> values returned in the response.</li>
</ol>
<pre><code class="language-json">&quot;result&quot;: {

	&quot;client_secret&quot;: &quot;bdd31cbc4dec990953e39163fbbb194c93313ca9f0a6e420346af9d326b1d2a5&quot;,
	&quot;created_at&quot;: &quot;2025-09-25T22:26:26Z&quot;,
	&quot;expires_at&quot;: &quot;2026-09-25T22:26:26Z&quot;,
	&quot;id&quot;: &quot;3537a672-e4d8-4d89-aab9-26cb622918a1&quot;,
	&quot;name&quot;: &quot;CI/CD token&quot;,
	&quot;updated_at&quot;: &quot;2025-09-25T22:26:26Z&quot;,

<aside class="nb-aside caution">

</aside>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Terraform (v5)">

<ol>
<li>Add the following permission to your <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/api_token"><code>cloudflare_api_token</code></a>:</li>
</ol>
<ul>
<li><code>Access: Service Tokens Write</code></li>
</ul>
<ol start="2">
<li>Configure the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_access_service_token"><code>cloudflare_zero_trust_access_service_token</code></a> resource:</li>
</ol>
<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_access_service_token&quot; &quot;example_service_token&quot; {
	account_id = var.cloudflare_account_id
	name       = &quot;Example service token&quot;
	duration  = &quot;8760h&quot;

	lifecycle {
		create_before_destroy = true
	}
}
</code></pre>
<ol start="3">
<li>Get the Client ID and Client Secret of the service token:</li>
</ol>
<details class="nb-details" open><summary>Example: Output to CLI</summary><div class="nb-details-body">
<pre><code>1. Output the Client ID and Client Secret to the Terraform state file:
</code></pre>
<pre><code class="language-tf">output &quot;example_service_token_client_id&quot; {
	value     = cloudflare_zero_trust_access_service_token.example_service_token.client_id
}

output &quot;example_service_token_client_secret&quot; {
	value     = cloudflare_zero_trust_access_service_token.example_service_token.client_secret
	sensitive = true
}
</code></pre>
<ol start="2">
<li>Apply the configuration:</li>
</ol>
<pre><code class="language-sh">terraform apply
</code></pre>
<ol start="3">
<li>Read the Client ID and Client Secret:</li>
</ol>
<pre><code class="language-sh">terraform output -raw example_service_token_client_id
</code></pre>
<pre><code class="language-sh">terraform output -raw example_service_token_client_secret
</code></pre>
</div></details>
