<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Access controls</strong> &gt; <strong>Service credentials</strong> &gt; <strong>Service Tokens</strong>.</li>
<li>Locate the token you want to renew.</li>
<li>To extend the token's lifetime by one year, select <strong>Refresh</strong>.</li>
<li>To extend the token's lifetime by more than a year:</li>
<li>Select <strong>Edit</strong>.</li>
<li>Choose a new <strong>Service Token Duration</strong>.</li>
<li>Select <strong>Save</strong>. The expiration date will be extended by the selected amount of time.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To extend the token's lifetime by one year, make a <code>POST</code> request to the <a href="/api/resources/zero_trust/subresources/access/subresources/service_tokens/methods/refresh/">Refresh a service token</a> endpoint:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/service_tokens/{service_token_id}/refresh \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;</code></pre>
<p>To extend the token's lifetime by a custom duration, make a <code>PUT</code> request to the <a href="/api/resources/zero_trust/subresources/access/subresources/service_tokens/methods/update/">Update a service token</a> endpoint with the new <code>duration</code>:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request PUT \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/service_tokens/{service_token_id} \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;duration&quot;: &quot;17520h&quot;
}&#x27;</code></pre>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Terraform (v5)">

<p>To renew the service token, update the <code>duration</code> attribute on the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_access_service_token"><code>cloudflare_zero_trust_access_service_token</code></a> resource and apply the change. Cloudflare resets the expiration relative to the time of the update.</p>
<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_access_service_token&quot; &quot;example_service_token&quot; {
	account_id = var.cloudflare_account_id
	name       = &quot;Example service token&quot;
	duration   = &quot;17520h&quot;

	lifecycle {
		create_before_destroy = true
	}
}
</code></pre>
