<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<div class="nb-steps">
<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Access controls</strong> &gt; <strong>Service credentials</strong> &gt; <strong>Service Tokens</strong>.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Locate the token and select the three dots.</li>
<li>To stop the token from authenticating, select <strong>Disable token</strong> &gt; <strong>Disable</strong>.</li>
<li>To restore authentication, select <strong>Enable token</strong> &gt; <strong>Enable</strong>.</li>
</ol>
</div>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Make a <code>PUT</code> request to the <a href="/api/resources/zero_trust/subresources/access/subresources/service_tokens/methods/update/">Update a service token</a> endpoint. Set <code>enabled</code> to <code>false</code> to turn off the token:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request PUT \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/service_tokens/{service_token_id} \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;&lt;TOKEN_NAME&gt;&quot;,
&quot;enabled&quot;: false
}&#x27;</code></pre>
<p>To turn the token on again, set <code>enabled</code> to <code>true</code>.</p>
