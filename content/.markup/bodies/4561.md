<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Access controls</strong> &gt; <strong>Service credentials</strong> &gt; <strong>Service Tokens</strong>.</li>
<li><strong>Delete</strong> the token you need to revoke.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Make a <code>DELETE</code> request to the <a href="/api/resources/zero_trust/subresources/access/subresources/service_tokens/methods/delete/">Delete a service token</a> endpoint:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request DELETE \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/service_tokens/{service_token_id} \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;</code></pre>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Terraform (v5)">

<p>To revoke the service token, remove the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_access_service_token"><code>cloudflare_zero_trust_access_service_token</code></a> resource from your configuration and run <code>terraform apply</code>, or target the resource for destruction:</p>
<pre><code class="language-sh">terraform destroy -target=cloudflare_zero_trust_access_service_token.example_service_token
</code></pre>
