<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Access controls</strong> &gt; <strong>Policies</strong>, and select the <strong>Rule groups</strong> tab.</li>
<li>Select <strong>Add a group</strong>.</li>
<li>Enter a name for the group (for example, <code>Lisbon-team</code>).</li>
<li>Specify as many rules as needed to define your user group. For example, the following rules define a team based in Lisbon, Portugal:</li>
</ol>
<table>
<thead>
<tr>
<th>Rule type</th>
<th>Selector</th>
<th>Value</th>
</tr>
</thead>
<tbody>
<tr>
<td>Include</td>
<td>Country</td>
<td><code>Portugal</code></td>
</tr>
<tr>
<td>Require</td>
<td>Emails Ending In</td>
<td><code>@team.com</code></td>
</tr>
</tbody>
</table>
<ol start="5">
<li>Select <strong>Save</strong>.</li>
</ol>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Send a <code>POST</code> request to the <a href="/api/resources/zero_trust/subresources/access/subresources/groups/methods/create/"><code>/access/groups</code></a> endpoint:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/groups \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;Lisbon-team&quot;,
&quot;include&quot;: [
  {
    &quot;geo&quot;: {
      &quot;country_code&quot;: &quot;PT&quot;
    }
  }
],
&quot;exclude&quot;: [],
&quot;require&quot;: [
  {
    &quot;email_domain&quot;: {
      &quot;domain&quot;: &quot;team.com&quot;
    }
  }
],
&quot;is_default&quot;: false
}&#x27;</code></pre>
