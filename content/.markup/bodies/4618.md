<p>At least one of the following <a href="/fundamentals/api/reference/permissions/">token permissions</a> is required:</p>
<ul>
<li><code>Access: Apps and Policies Write</code></li>
</ul>
</div></details>
<p>Configure the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_access_policy"><code>cloudflare_zero_trust_access_policy</code></a> resource:</p>
<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_access_policy&quot; &quot;allow_employees_from_specific_countries&quot; {
  account_id = var.cloudflare_account_id
  name       = &quot;Allow employees from specific countries&quot;
  decision   = &quot;allow&quot;
  include = [{
    email_domain = {
      domain = &quot;example.com&quot;
    }
  }]
  require = [{
    group = {
      id = cloudflare_zero_trust_access_group.approved_countries.id
    }
  }]
  exclude = [
    {
      email = {
        email = &quot;user-1@example.com&quot;
      }
    },
    {
      email = {
        email = &quot;user-2@example.com&quot;
      }
    },
  ]
}
</code></pre>
<p>The <code>cloudflare_zero_trust_access_group.approved_countries</code> reference points to the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_access_group"><code>cloudflare_zero_trust_access_group</code></a> resource created above.</p>
