To get the integration UIDs for your device posture checks, use the <a href="/api/resources/zero_trust/subresources/devices/subresources/posture/methods/list/">List device posture checks</a> endpoint.</p>

<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_access_policy&quot; &quot;require_device_posture&quot; {
  account_id = var.cloudflare_account_id
  name       = &quot;Require device posture for sensitive apps&quot;
  decision   = &quot;allow&quot;
  include = [{
    okta = {
      name                 = &quot;Full-Time Employees&quot;
      identity_provider_id = cloudflare_zero_trust_access_identity_provider.okta.id
    }
  }]
  require = [
    {
      device_posture = {
        integration_uid = cloudflare_zero_trust_device_posture_rule.gateway_check.id
      }
    },
    {
      device_posture = {
        integration_uid = cloudflare_zero_trust_device_posture_rule.os_version_check.id
      }
    },
  ]
}
</code></pre>
<ul>
<li>Replace the <code>okta</code> rule with the appropriate <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_access_identity_provider"><code>cloudflare_zero_trust_access_identity_provider</code></a> resource for your identity provider. To configure the identity provider resource, refer to <a href="/cloudflare-one/integrations/identity-providers/">Identity providers</a>.</li>
<li>To configure the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_device_posture_rule"><code>cloudflare_zero_trust_device_posture_rule</code></a> resources referenced above, refer to <a href="/cloudflare-one/reusable-components/posture-checks/">Device posture checks</a>.</li>
</ul>
