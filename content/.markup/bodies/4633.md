--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/policies \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;Allow contractor access with OTP&quot;,
&quot;decision&quot;: &quot;allow&quot;,
&quot;include&quot;: [
  {
    &quot;email_domain&quot;: {
      &quot;domain&quot;: &quot;contractor-a.com&quot;
    }
  },
  {
    &quot;email_domain&quot;: {

    }
  }
],
&quot;require&quot;: [
  {

<details class="nb-details"><summary>Required API token permissions</summary><div class="nb-details-body">
<p>At least one of the following <a href="/fundamentals/api/reference/permissions/">token permissions</a> is required:</p>
<ul>
<li><code>Access: Apps and Policies Write</code></li>
</ul>
</div></details>
<p>Configure the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_access_policy"><code>cloudflare_zero_trust_access_policy</code></a> resource:</p>
<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_access_policy&quot; &quot;allow_contractor_access_with_otp&quot; {
  account_id = var.cloudflare_account_id
  name       = &quot;Allow contractor access with OTP&quot;
  decision   = &quot;allow&quot;
  include = [
    {
      email_domain = {
        domain = &quot;contractor-a.com&quot;
      }
    },
    {
      email_domain = {
        domain = &quot;contractor-b.com&quot;
      }
    },
  ]
  require = [{
    login_method = {
      id = cloudflare_zero_trust_access_identity_provider.otp.id
    }
  }]
}
</code></pre>
<p>To configure the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_access_identity_provider"><code>cloudflare_zero_trust_access_identity_provider</code></a> resource for OTP (configured with <code>type = &quot;onetimepin&quot;</code>), refer to <a href="/cloudflare-one/integrations/identity-providers/one-time-pin/">One-time PIN</a>.</p>
