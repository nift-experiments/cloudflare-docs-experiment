

First, enable Clientless Web Isolation on your account if you have not already:



<pre class="nb-api-request"><code class="language-bash">curl --request PATCH \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/configuration \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;settings&quot;: {
  &quot;browser_isolation&quot;: {
    &quot;url_browser_isolation_enabled&quot;: true
  }
}
}&#x27;</code></pre>



Then, create the Access policy with `isolation_required` set to `true`:



<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/policies \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;Isolate contractor access&quot;,
&quot;decision&quot;: &quot;allow&quot;,
&quot;include&quot;: [
  {
    &quot;email_domain&quot;: {
      &quot;domain&quot;: &quot;contractor-a.com&quot;
    }
  },
  {
    &quot;email_domain&quot;: {
      &quot;domain&quot;: &quot;contractor-b.com&quot;
    }
  }
],
&quot;isolation_required&quot;: true
}&#x27;</code></pre>
