<p><strong>Additional settings</strong>: Turn on <strong>Isolate application</strong>.</p>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>First, enable Clientless Web Isolation on your account if you have not already:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request PATCH \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/configuration \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;settings&quot;: {
  &quot;browser_isolation&quot;: {
    &quot;url_browser_isolation_enabled&quot;: true
  }
}
}&#x27;</code></pre>
<p>Then, create the Access policy with <code>isolation_required</code> set to <code>true</code>:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/policies \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;Isolate contractor access&quot;,
&quot;decision&quot;: &quot;allow&quot;,
&quot;include&quot;: [
  {
    &quot;email_domain&quot;: {
      &quot;domain&quot;: &quot;contractor-a.com&quot;
    }
  },
  {
    &quot;email_domain&quot;: {
      &quot;domain&quot;: &quot;contractor-b.com&quot;
    }
  }
],
&quot;isolation_required&quot;: true
}&#x27;</code></pre>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Terraform">

<p>First, configure the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_gateway_settings"><code>cloudflare_zero_trust_gateway_settings</code></a> resource to enable Clientless Web Isolation on your account if you have not already:</p>
<details class="nb-details"><summary>Required API token permissions</summary><div class="nb-details-body">
<p>At least one of the following <a href="/fundamentals/api/reference/permissions/">token permissions</a> is required:</p>
<ul>
<li><code>Zero Trust Write</code></li>
</ul>
</div></details>
<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_gateway_settings&quot; &quot;gateway_settings&quot; {
  account_id = var.cloudflare_account_id
  settings = {
    browser_isolation = {
      url_browser_isolation_enabled = true
    }
  }
}
</code></pre>
<p>Then, configure the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_access_policy"><code>cloudflare_zero_trust_access_policy</code></a> resource with <code>isolation_required</code> set to <code>true</code>:</p>
<details class="nb-details"><summary>Required API token permissions</summary><div class="nb-details-body">
<p>At least one of the following <a href="/fundamentals/api/reference/permissions/">token permissions</a> is required:</p>
<ul>
<li><code>Access: Apps and Policies Write</code></li>
</ul>
</div></details>
<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_access_policy&quot; &quot;isolate_contractor_access&quot; {
  account_id         = var.cloudflare_account_id
  name               = &quot;Isolate contractor access&quot;
  decision           = &quot;allow&quot;
  isolation_required = true
  include = [
    {
      email_domain = {
        domain = &quot;contractor-a.com&quot;
      }
    },
    {
      email_domain = {
        domain = &quot;contractor-b.com&quot;
      }
    },
  ]
}
</code></pre>
