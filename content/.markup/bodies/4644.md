

<details class="nb-details"><summary>Required API token permissions</summary><div class="nb-details-body">

<p>At least one of the following <a href="/fundamentals/api/reference/permissions/">token permissions</a> is required:</p>
<ul>
<li><code>Access: Apps and Policies Write</code></li>
</ul>

</div></details>

Configure the [`cloudflare_zero_trust_access_policy`](https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_access_policy) resource:

```tf
resource "cloudflare_zero_trust_access_policy" "block_high_risk_countries" {
  account_id = var.cloudflare_account_id
  name       = "Block requests from high-risk countries"
  decision   = "deny"
  include = [{
    geo = {
      country_code = "RU"
    }
  }]
  exclude = [{
    ip_list = {
      id = cloudflare_zero_trust_list.corporate_ip_allowlist.id
    }
  }]
}
```

To configure the [`cloudflare_zero_trust_list`](https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_list) resource referenced above (configured with `type = "IP"`), refer to [Lists](/cloudflare-one/reusable-components/lists/).
