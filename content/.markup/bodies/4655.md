<p>Configure the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_access_policy"><code>cloudflare_zero_trust_access_policy</code></a> resource:</p>
<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_access_policy&quot; &quot;authenticate_service_with_token&quot; {
  account_id = var.cloudflare_account_id
  name       = &quot;Authenticate service with service token&quot;
  decision   = &quot;non_identity&quot;
  include = [{
    service_token = {
      token_id = cloudflare_zero_trust_access_service_token.my_service_token.id
    }
  }]
  require = [{
    ip = {
      ip = &quot;192.0.2.0/24&quot;
    }
  }]
}
</code></pre>
<p>To configure the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_access_service_token"><code>cloudflare_zero_trust_access_service_token</code></a> resource referenced above, refer to <a href="/cloudflare-one/access-controls/service-credentials/service-tokens/">Service tokens</a>.</p>
