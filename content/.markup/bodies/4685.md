<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Access controls</strong> &gt; <strong>Applications</strong>.</li>
<li>Select the self-hosted app (Application B) and select <strong>Edit</strong>.</li>
<li>Go to the <strong>Policies</strong> tab and select <strong>Create new policy</strong>.</li>
<li>Set the policy <strong>Action</strong> to <em>Service Auth</em>.</li>
</ol>
<aside class="nb-aside note">
<p>The Linked App Token selector only works with the <a href="/cloudflare-one/access-controls/policies/#service-auth">Service Auth</a> action, similar to service token rules.</p>
</aside>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<ol>
<li>Get the <code>uid</code> of the Access for SaaS app (Application A):</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request GET \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/apps \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;</code></pre>
 <pre><code class="language-json">`{\n\t"id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",\n\t"uid": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",\n\t"type": "saas",\n\t"name": "my-saas-app",\n\t...\n}`</code></pre>
<ol start="2">
<li>Create an Access policy on the downstream application, replacing the <code>app_uid</code> value with the <code>uid</code> of the Access for SaaS app (Application A):</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/policies \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;Allow requests from SaaS app&quot;,
&quot;decision&quot;: &quot;non_identity&quot;,
&quot;include&quot;: [
  {
    &quot;linked_app_token&quot;: {
      &quot;app_uid&quot;: &quot;a1b2c3d4-e5f6-7890-abcd-ef1234567890&quot;
    }
  }
]
}&#x27;</code></pre>
<aside class="nb-aside note">
<p>The <code>linked_app_token</code> rule type only works with <a href="/cloudflare-one/access-controls/policies/#service-auth"><code>non_identity</code> decisions</a>, similar to service token rules.</p>
</aside>
