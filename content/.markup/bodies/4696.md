

You can use the [Wrangler CLI](/workers/wrangler) to create the MCP server on your local machine and deploy it to Cloudflare.

<aside class="nb-aside note">
<h3 class="nb-aside-title" id="body-4696-prerequisites">Prerequisites</h3>


<ul>
<li>Install <a href="https://docs.npmjs.com/getting-started">npm</a></li>
<li>Install <a href="https://nodejs.org/en/">Node.js</a></li>
</ul>


</aside>

1.  Open a terminal and clone our example project:

<pre><code class="language-sh">npm create cloudflare@latest -- mcp-server-cf-access --template=cloudflare/ai/demos/remote-mcp-cf-access
</code></pre>


During setup, select the following options: - For _Do you want to add an AGENTS.md file to help AI coding tools understand
Cloudflare APIs?_, choose `No`. - For _Do you want to use git for version control?_, choose `No`. - For _Do you want to deploy your application?_, choose `No` (we will be making some changes before deploying).

2.  Go to the project directory:

<pre><code class="language-sh">cd mcp-server-cf-access
</code></pre>


3.  Create a [Workers KV namespace](/kv/concepts/kv-namespaces/) to store the key. The binding name should be `OAUTH_KV` if you want to run the example as written.

<pre><code class="language-sh">npx wrangler kv namespace create &quot;OAUTH_KV&quot;
</code></pre>


    The command will output the binding name and KV namespace ID:

<pre><code class="language-sh">{
	&quot;kv_namespaces&quot;: [
		{
			&quot;binding&quot;: &quot;OAUTH_KV&quot;,
			&quot;id&quot;: &quot;&lt;YOUR_KV_NAMESPACE_ID&gt;&quot;
		}
	]
}
</code></pre>


4.  Open `wrangler.jsonc` in an editor and insert your `OAUTH_KV` namespace ID:

<pre><code class="language-jsonc">&quot;kv_namespaces&quot;: [
	{
		&quot;binding&quot;: &quot;OAUTH_KV&quot;,
		&quot;id&quot;: &quot;&lt;YOUR_KV_NAMESPACE_ID&gt;&quot;
	}
],
</code></pre>


5.  You can now deploy the Worker to Cloudflare's global network:

<pre><code class="language-sh">npx wrangler deploy
</code></pre>


The Worker will be deployed to your `*.workers.dev` subdomain at `mcp-server-cf-access.<YOUR_SUBDOMAIN>.workers.dev`.
