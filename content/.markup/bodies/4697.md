<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="CLI">

<p>You can use the <a href="/workers/wrangler">Wrangler CLI</a> to create the MCP server on your local machine and deploy it to Cloudflare.</p>
<aside class="nb-aside note">
<h3 class="nb-aside-title" id="body-4697-prerequisites">Prerequisites</h3>
<ul>
<li>Install <a href="https://docs.npmjs.com/getting-started">npm</a></li>
<li>Install <a href="https://nodejs.org/en/">Node.js</a></li>
</ul>
</aside>
<ol>
<li>Open a terminal and clone our example project:</li>
</ol>
<pre><code class="language-sh">npm create cloudflare@latest -- mcp-server-cf-access --template=cloudflare/ai/demos/remote-mcp-cf-access
</code></pre>
<p>During setup, select the following options: - For <em>Do you want to add an AGENTS.md file to help AI coding tools understand
Cloudflare APIs?</em>, choose <code>No</code>. - For <em>Do you want to use git for version control?</em>, choose <code>No</code>. - For <em>Do you want to deploy your application?</em>, choose <code>No</code> (we will be making some changes before deploying).</p>
<ol start="2">
<li>Go to the project directory:</li>
</ol>
<pre><code class="language-sh">cd mcp-server-cf-access
</code></pre>
<ol start="3">
<li>Create a <a href="/kv/concepts/kv-namespaces/">Workers KV namespace</a> to store the key. The binding name should be <code>OAUTH_KV</code> if you want to run the example as written.</li>
</ol>
<pre><code class="language-sh">npx wrangler kv namespace create &quot;OAUTH_KV&quot;
</code></pre>
<pre><code>The command will output the binding name and KV namespace ID:
</code></pre>
<pre><code class="language-sh">{
	&quot;kv_namespaces&quot;: [
		{
			&quot;binding&quot;: &quot;OAUTH_KV&quot;,
			&quot;id&quot;: &quot;&lt;YOUR_KV_NAMESPACE_ID&gt;&quot;
		}
	]
}
</code></pre>
<ol start="4">
<li>Open <code>wrangler.jsonc</code> in an editor and insert your <code>OAUTH_KV</code> namespace ID:</li>
</ol>
<pre><code class="language-jsonc">&quot;kv_namespaces&quot;: [
	{
		&quot;binding&quot;: &quot;OAUTH_KV&quot;,
		&quot;id&quot;: &quot;&lt;YOUR_KV_NAMESPACE_ID&gt;&quot;
	}
],
</code></pre>
<ol start="5">
<li>You can now deploy the Worker to Cloudflare's global network:</li>
</ol>
<pre><code class="language-sh">npx wrangler deploy
</code></pre>
<p>The Worker will be deployed to your <code>*.workers.dev</code> subdomain at <code>mcp-server-cf-access.&lt;YOUR_SUBDOMAIN&gt;.workers.dev</code>.</p>
