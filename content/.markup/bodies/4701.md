
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Access controls</strong> &gt; <strong>Applications</strong>.</li>
<li>Select <strong>Create new application</strong>.</li>
<li>Select <strong>SaaS application</strong>.</li>
<li>In <strong>Application</strong>, enter a custom name (for example, <code>MCP server</code>) and select the textbox that appears below.</li>
<li>Select <strong>OIDC</strong> as the authentication protocol.</li>
<li>Select <strong>Add application</strong>.</li>
<li>In <strong>Redirect URLs</strong>, enter the authorization callback URL for your MCP server. The callback URL for our <a href="#1-deploy-an-example-mcp-server">example MCP server</a> is
<code>https://mcp-server-cf-access.&lt;YOUR_SUBDOMAIN&gt;.workers.dev/callback</code>.</li>
<li>Copy the following values to input into our example MCP server. Other MCP servers may require different sets of input values.</li>
</ol>
<ul>
<li><strong>Client secret</strong></li>
<li><strong>Client ID</strong></li>
<li><strong>Token endpoint</strong></li>
<li><strong>Authorization endpoint</strong></li>
<li><strong>Key endpoint</strong></li>
</ul>
<ol start="9">
<li>(Optional) Under <strong>Advanced settings</strong>, turn on <a href="/cloudflare-one/access-controls/applications/http-apps/saas-apps/generic-oidc-saas/#advanced-settings"><strong>Refresh tokens</strong></a> if you want to reduce the number of times a user needs to log in to the identity provider.</li>
<li>Configure <a href="/cloudflare-one/access-controls/policies/">Access policies</a> to define the users who can access the MCP server.</li>
<li></li>
</ol>
<p>Configure how users will authenticate:</p>
<ol>
<li>
Select the [identity providers](/cloudflare-one/integrations/identity-providers/) you want to enable for your application.
</li>
<li>
(Recommended) If you plan to only allow access via a single IdP, turn on **Apply instant authentication**. End users will not be shown the [Cloudflare Access login page](/cloudflare-one/reusable-components/custom-pages/access-login-page/). Instead, Cloudflare will redirect users directly to your SSO login event.
</li>
<li> (Optional) Turn on  <b>Authenticate with Cloudflare One Client</b> to allow users to authenticate to the application using their <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/configure/client-sessions/"> Cloudflare One Client session identity</a>. </li>
</ol>
<ol start="12">
<li>Select <strong>Create</strong>.</li>
</ol>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<ol>
<li>Make a <code>POST</code> request to the <a href="/api/resources/zero_trust/subresources/access/subresources/applications/methods/create/">Access applications</a> endpoint:</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/apps \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;MCP server&quot;,
&quot;type&quot;: &quot;saas&quot;,
&quot;saas_app&quot;: {
  &quot;auth_type&quot;: &quot;oidc&quot;,
  &quot;redirect_uris&quot;: [
    &quot;https://mcp-server-cf-access.&lt;YOUR_SUBDOMAIN&gt;.workers.dev/callback&quot;
  ],
  &quot;grant_type&quot;: [
    &quot;authorization_code&quot;,
    &quot;refresh_tokens&quot;
  ],
  &quot;refresh_token_options&quot;: {
    &quot;lifetime&quot;: &quot;90d&quot;
  }
},
&quot;policies&quot;: [
  &quot;f174e90a-fafe-4643-bbbc-4a0ed4fc8415&quot;
],
&quot;allowed_idps&quot;: []
}&#x27;</code></pre>
