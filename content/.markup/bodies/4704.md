
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to the <strong>Workers &amp; Pages</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select the <code>mcp-server-cf-access</code> Worker.</li>
<li>Go to <strong>Settings</strong>.</li>
<li>Under <strong>Variables and Secrets</strong>, update each secret with the corresponding value obtained from the <a href="#2-create-an-access-for-saas-app">Access for SaaS app</a>.</li>
</ol>
<table>
<thead>
<tr>
<th>Workers secret</th>
<th>SaaS app field</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>ACCESS_CLIENT_ID</code></td>
<td>Client ID</td>
</tr>
<tr>
<td><code>ACCESS_CLIENT_SECRET</code></td>
<td>Client secret</td>
</tr>
<tr>
<td><code>ACCESS_TOKEN_URL</code></td>
<td>Token endpoint</td>
</tr>
<tr>
<td><code>ACCESS_AUTHORIZATION_URL</code></td>
<td>Authorization endpoint</td>
</tr>
<tr>
<td><code>ACCESS_JWKS_URL</code></td>
<td>Key endpoint</td>
</tr>
</tbody>
</table>
<aside class="nb-aside note">
<p>Use the Client ID, Client secret, and OAuth endpoints copied from the Cloudflare One dashboard. Do not use the OAuth values from your <a href="/cloudflare-one/integrations/identity-providers/generic-oidc/">third-party identity provider</a>.</p>
</aside>
<ol start="5">
<li>For <code>COOKIE_ENCRYPTION_KEY</code>, you can use the following command to generate a random string:</li>
</ol>
<pre><code class="language-sh">openssl rand -hex 32
</code></pre>
<p>Enter the output of this command into <code>COOKIE_ENCRYPTION_KEY</code>.</p>

</ol>
<pre><code class="language-sh">npx wrangler secret put ACCESS_CLIENT_ID
npx wrangler secret put ACCESS_CLIENT_SECRET
npx wrangler secret put ACCESS_TOKEN_URL
npx wrangler secret put ACCESS_AUTHORIZATION_URL
npx wrangler secret put ACCESS_JWKS_URL
</code></pre>
