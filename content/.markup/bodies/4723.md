<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Portal-level alias">

<p>To set an alias that applies to a specific portal:</p>
<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Access controls</strong> &gt; <strong>MCP Portals</strong>.</li>
<li>Find the portal you want to configure, then select the three dots &gt; <strong>Edit</strong>.</li>
<li>Go to the <strong>Servers</strong> tab.</li>
<li>Select the <strong>Tools authorized</strong> or <strong>Prompts authorized</strong> value for the server you want to configure (for example, <code>10/10</code>).</li>
<li>Find the tool or prompt you want to modify, then select the three dots &gt; <strong>Edit</strong>.</li>
<li>In the modal, update the <strong>Name</strong> and <strong>Description</strong> as needed.</li>
<li>Select <strong>Confirm</strong>.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Server-level alias">

<p>To set an alias that applies across all portals using a server:</p>
<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Access controls</strong> &gt; <strong>MCP Portals</strong>.</li>
<li>Go to the <strong>MCP servers</strong> tab.</li>
<li>Find the server you want to configure, then select the three dots &gt; <strong>Edit</strong>.</li>
<li>Go to the <strong>Tools</strong> or <strong>Prompts</strong> tab.</li>
<li>Find the tool or prompt you want to modify, then select the three dots &gt; <strong>Edit</strong>.</li>
<li>In the modal, update the <strong>Name</strong> and <strong>Description</strong> as needed.</li>
<li>Select <strong>Confirm</strong>.</li>
<li>Scroll to the bottom of the page and select <strong>Save server</strong>.</li>
</ol>

</section>
