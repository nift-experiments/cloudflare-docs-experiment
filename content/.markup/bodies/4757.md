
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Resources</strong> &gt; <strong>Lists</strong>.</li>
<li>Select <strong>Create new list</strong>.</li>
<li>Enter a <strong>List name</strong> (for example, <code>Approved security keys</code>) and an optional description.</li>
<li>Set <strong>List type</strong> to <strong>MFA AAGUIDs</strong>.</li>
<li>Add one or more AAGUID entries:</li>
</ol>
<ul>
<li>To add predefined AAGUIDs, select authenticators from the <strong>Known authenticators</strong> list.</li>
<li>To add a custom AAGUID, fill out the following fields:
<ul>
<li><strong>MFA AAGUIDs</strong> — The AAGUID of the authenticator, in 32-character hexadecimal format without dashes (for example, <code>8c39ee867f9a4a959ba3f6b097e5c2ee</code>).</li>
<li><strong>Description</strong> — An optional label such as the authenticator's name and model.</li>
</ul>
</li>
</ul>
<ol start="6">
<li>Select <strong>Save</strong>.</li>
</ol>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Send a <code>POST</code> request to create the list:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/lists \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;Approved security keys&quot;,
&quot;description&quot;: &quot;AAGUIDs for MFA enrollment&quot;,
&quot;type&quot;: &quot;AAGUID&quot;,
&quot;items&quot;: [
  {
    &quot;value&quot;: &quot;8c39ee867f9a4a959ba3f6b097e5c2ee&quot;,
    &quot;description&quot;: &quot;YubiKey Bio Series - FIDO Edition (Enterprise Profile)&quot;
  }
]
}&#x27;</code></pre>
<p>The response contains an <code>id</code> (UUID) for the list. Use this ID when you assign the list to your organization's MFA configuration.</p>
