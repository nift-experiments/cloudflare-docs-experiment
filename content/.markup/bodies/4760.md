
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Access controls</strong> &gt; <strong>Access settings</strong>.</li>
<li>Under <strong>Allow multi-factor authentication (MFA)</strong>, go to <strong>Limit MFA to specific authentication methods</strong>.</li>
<li>Select an existing <a href="#1-create-an-aaguid-list">AAGUID list</a>.</li>
<li>Select <strong>Save</strong>.</li>
</ol>
<p>After you save, only authenticators whose AAGUIDs appear in the list can be enrolled. Users with previously enrolled security keys or biometrics outside the list can continue to use them until they are <a href="#delete-a-user-authenticator">deleted by an administrator</a>. A previously enrolled FIDO2 key outside the list stops working on the next connection. To remove the restriction, unset the AAGUID list.</p>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<ol>
<li>Get your existing Zero Trust organization configuration:</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request GET \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/organizations \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;</code></pre>
<ol start="2">
<li>Send a <code>PUT</code> request to assign the list. To avoid overwriting your existing configuration, the <code>PUT</code> request body should contain all fields returned by the previous <code>GET</code> request. Set <code>mfa_config.required_aaguids</code> to the ID of your AAGUID list.</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request PUT \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/organizations \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;auth_domain&quot;: &quot;your-team-name.cloudflareaccess.com&quot;,
&quot;name&quot;: &quot;Your Team Name&quot;,
&quot;mfa_config&quot;: {
  &quot;allowed_authenticators&quot;: [
    &quot;security_key&quot;,
    &quot;totp&quot;,
    &quot;biometrics&quot;
  ],
  &quot;session_duration&quot;: &quot;24h&quot;,
  &quot;required_aaguids&quot;: &quot;05ddacda-5131-41ab-9eeb-6763f8dce3be&quot;
}
}&#x27;</code></pre>
<p>To remove the restriction, set <code>required_aaguids</code> to <code>null</code>.</p>

</section>
