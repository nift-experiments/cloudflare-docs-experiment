
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Access controls</strong> &gt; <strong>Access settings</strong>.</li>
<li>Under <strong>Allow multi-factor authentication (MFA)</strong>, turn on <strong>Use identity provider MFA</strong>.</li>
<li>Under <strong>Authentication Method Reference (AMR) matching duration</strong>, set how long a successful IdP MFA remains valid. During this period, users can log in to Access without an additional MFA prompt. You can set a custom duration (default 24 hours) or check for a <a href="#supported-amr-values">valid AMR value</a> on every login.</li>
<li>Select <strong>Save</strong>.</li>
</ol>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<ol>
<li>Get your existing Zero Trust organization configuration:</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request GET \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/organizations \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;</code></pre>
<ol start="2">
<li>Send a <code>PUT</code> request to update your organization's AMR matching settings. To avoid overwriting your existing configuration, the <code>PUT</code> request body should contain all fields returned by the previous <code>GET</code> request.</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request PUT \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/organizations \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;auth_domain&quot;: &quot;your-team-name.cloudflareaccess.com&quot;,
&quot;name&quot;: &quot;Your Team Name&quot;,
&quot;mfa_config&quot;: {
  &quot;allowed_authenticators&quot;: [
    &quot;totp&quot;,
    &quot;biometrics&quot;,
    &quot;security_key&quot;
  ],
  &quot;session_duration&quot;: &quot;24h&quot;,
  &quot;amr_matching_enabled&quot;: true,
  &quot;amr_session_duration&quot;: &quot;1h&quot;
}
}&#x27;</code></pre>
