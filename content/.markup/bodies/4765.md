

1. Get your existing Zero Trust organization configuration:



<pre class="nb-api-request"><code class="language-bash">curl --request GET \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/organizations \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;</code></pre>



2. Send a `PUT` request with an empty `allowed_authenticators` array. To avoid overwriting your existing configuration, the `PUT` request body should contain all fields returned by the previous `GET` request.



<pre class="nb-api-request"><code class="language-bash">curl --request PUT \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/organizations \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;auth_domain&quot;: &quot;your-team-name.cloudflareaccess.com&quot;,
&quot;name&quot;: &quot;Your Team Name&quot;,
&quot;mfa_config&quot;: {
  &quot;allowed_authenticators&quot;: []
}
}&#x27;</code></pre>
