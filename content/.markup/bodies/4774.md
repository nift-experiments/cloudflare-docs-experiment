
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Team &amp; Resources</strong> &gt; <strong>Users</strong>.</li>
<li>Select the user whose authenticator you want to delete.</li>
<li>Under <strong>MFA devices</strong>, find the authenticator and select <strong>Delete</strong>.</li>
</ol>
<p>The user will need to enroll a new authenticator the next time they access an application that requires MFA.</p>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Send a <code>DELETE</code> request to remove a specific authenticator:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request DELETE \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/users/{user_id}/mfa_authenticators/{authenticator_id} \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;</code></pre>
<p>Parameters:</p>
<ul>
<li><code>user_id</code> — The UUID of the user. You can find this in the user details under <strong>Team &amp; Resources</strong> &gt; <strong>Users</strong>.</li>
<li><code>authenticator_id</code> — The unique identifier for the authenticator.</li>
</ul>

</section>
