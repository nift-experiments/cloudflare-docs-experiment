
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<p>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Access controls</strong> &gt; <strong>Targets</strong>. Use the filter and sort controls to narrow the list by tag key or value.</p>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To filter targets by tag, add one or more <code>tag</code> query parameters:</p>
<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/infrastructure/targets?tag=environment:production&amp;tag=team:platform&quot; \
  -H &quot;Authorization: Bearer $API_TOKEN&quot;
</code></pre>
<p>Use <code>:</code> between the tag key and value in each filter. If you add multiple <code>tag</code> parameters, Cloudflare applies AND logic.</p>
<p>To sort by tag key, use the <code>order</code> and <code>direction</code> parameters:</p>
<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/infrastructure/targets?order=tag:environment&amp;direction=asc&quot; \
  -H &quot;Authorization: Bearer $API_TOKEN&quot;
</code></pre>
<p>The sort parameter also uses <code>:</code> in <code>order=tag:&lt;key&gt;</code> because it identifies the tag field to sort by.</p>
