

Make a `POST` request to the [Access applications](/api/resources/zero_trust/subresources/access/subresources/applications/methods/create/) endpoint:

The following example uses the operator-based target criteria format with `include`, `require`, and `exclude`:



<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/apps \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;Example infrastructure app&quot;,
&quot;type&quot;: &quot;infrastructure&quot;,
&quot;target_criteria&quot;: [
  {
    &quot;port&quot;: 22,
    &quot;protocol&quot;: &quot;SSH&quot;,
    &quot;include&quot;: {
      &quot;target_attributes&quot;: {
        &quot;hostname&quot;: [
          &quot;infra-access-target&quot;
        ]
      },
      &quot;tags&quot;: {
        &quot;environment&quot;: [
          &quot;production&quot;,
          &quot;staging&quot;
        ]
      }
    },
    &quot;require&quot;: {
      &quot;tags&quot;: {
        &quot;team&quot;: [
          &quot;platform&quot;
        ]
      }
    },
    &quot;exclude&quot;: {
      &quot;tags&quot;: {
        &quot;lifecycle&quot;: [
          &quot;decommissioned&quot;
        ]
      }
    }
  }
],
&quot;policies&quot;: [
  {
    &quot;name&quot;: &quot;Allow a specific email&quot;,
    &quot;decision&quot;: &quot;allow&quot;,
    &quot;include&quot;: [
      {
        &quot;email&quot;: {
          &quot;email&quot;: &quot;jdoe@company.com&quot;
        }
      }
    ],
    &quot;connection_rules&quot;: {
      &quot;ssh&quot;: {
        &quot;usernames&quot;: [
          &quot;root&quot;,
          &quot;ec2-user&quot;
        ]
      }
    }
  }
]
}&#x27;</code></pre>



For more information about target criteria formats, refer to [Target criteria](/cloudflare-one/access-controls/applications/non-http/infrastructure-apps/#target-criteria).
