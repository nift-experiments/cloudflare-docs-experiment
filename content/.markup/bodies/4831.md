
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Access controls</strong> &gt; <strong>Applications</strong>.</li>
<li>Find the MCP server application you want to configure, then select the three dots on the right &gt; <strong>Edit</strong>.</li>
<li>Go to the <strong>Advanced settings</strong> tab and turn on <strong>Managed OAuth</strong>.</li>
<li>(Optional) Configure <a href="#managed-oauth-settings">Managed OAuth settings</a>.</li>
<li>Select <strong>Save</strong>.</li>
</ol>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<ol>
<li>Get your existing Access application configuration:</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request GET \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/apps/{app_id} \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;</code></pre>
<ol start="2">
<li>Make a <code>PUT</code> request and set <code>oauth_configuration.enabled</code> to <code>true</code>. To avoid overwriting your existing configuration, the request body should contain all fields returned by the previous <code>GET</code> request.</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request PUT \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/apps/{app_id} \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;oauth_configuration&quot;: {
  &quot;enabled&quot;: true
}
}&#x27;</code></pre>

</section>
