

Configure these settings via the `oauth_configuration` object on the [Access applications](/api/resources/zero_trust/subresources/access/subresources/applications/methods/update/) endpoint.

1. Get your existing Access application configuration:



<pre class="nb-api-request"><code class="language-bash">curl --request GET \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/apps/{app_id} \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;</code></pre>



2. Make a `PUT` request with your Managed OAuth settings. To avoid overwriting your existing configuration, the request body should contain all fields returned by the previous `GET` request.



<pre class="nb-api-request"><code class="language-bash">curl --request PUT \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/apps/{app_id} \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;oauth_configuration&quot;: {
  &quot;enabled&quot;: true,
  &quot;dynamic_client_registration&quot;: {
    &quot;enabled&quot;: true,
    &quot;allow_any_on_localhost&quot;: true,
    &quot;allow_any_on_loopback&quot;: true,
    &quot;allowed_uris&quot;: [
      &quot;https://playground.ai.cloudflare.com/*&quot;
    ]
  },
  &quot;grant&quot;: {
    &quot;access_token_lifetime&quot;: &quot;5m&quot;,
    &quot;session_duration&quot;: &quot;24h&quot;
  }
}
}&#x27;</code></pre>
