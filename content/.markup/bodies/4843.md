<ol>
<li>In Slack, go to <strong>Settings &amp; administrations</strong> &gt; <strong>Workspace settings</strong> &gt; <strong>Authentication</strong>.</li>
<li>Select <strong>Configure</strong>.</li>
<li>Turn on <strong>Test</strong>. Configuration changes will not apply until <strong>Configure</strong> is turned on.</li>
<li>Fill in the following fields:</li>
</ol>
<ul>
<li><strong>Service Provider Issuer URL</strong>: Ensure set to <code>https://slack.com</code>.</li>
<li><strong>SAML SSO URL</strong>: SSO endpoint from application configuration in Cloudflare One.</li>
<li><strong>Identity Provider Issuer</strong>: Access Entity ID or Issuer from application configuration in Cloudflare One.</li>
<li><strong>Public Certificate</strong>: Paste the entire x.509 certificate from step <a href="#2-create-a-x509-certificate">2. Create a x.509 certificate</a>.</li>
</ul>
<ol start="5">
<li>Under <strong>Advanced Options</strong>, select <strong>Expand</strong>.</li>
<li>For <strong>AuthnContextClassRef</strong>, ensure <em>urn:oasis:names:tc:SAML:2.0:ac:classes:PasswordProtectedTransport</em> is selected.</li>
<li>Ensure <strong>Sign the AuthnRequest</strong> is turned off.</li>
<li>For <strong>SAML Response Signing</strong>, turn on <strong>Sign the Response</strong> and <strong>Sign the Assertion</strong>.</li>
<li>In the main configuration page under <strong>Settings</strong>, choose whether SSO is <em>required</em>, <em>partially required</em>, or <em>optional</em> for workspace members.</li>
<li>(Optional) Under <strong>Customize</strong>, enter a <strong>Sign in Button Label</strong>.</li>
<li>Test your set-up. If all works well, turn <strong>Test</strong> to <strong>Configure</strong>.</li>
</ol>

<li>In Slack, go to <strong>Settings &amp; administration</strong> &gt; <strong>Organization settings</strong> &gt; <strong>Security</strong> &gt; <strong>SSO Settings</strong>.</li>
<li>For <strong>SSO name</strong>, enter your desired name.</li>
<li>Fill in the following fields:</li>
</ol>
<ul>
<li><strong>SAML 2.0 Endpoint URL</strong>: SSO endpoint from application configuration in Cloudflare One.</li>
<li><strong>Identity Provider Issuer URL</strong>: Access Entity ID or Issuer from application configuration in Cloudflare One.</li>
<li><strong>Service Provider Issuer URL</strong>: Ensure set to <code>https://slack.com</code>.</li>
<li><strong>x.509 Certificate</strong>: Paste the entire x.509 certificate from step <a href="#2-create-a-x509-certificate">2. Create a x.509 certificate</a>.</li>
</ul>
<ol start="4">
<li>For <strong>AuthnContextClassRef</strong>, ensure <em>urn:oasis:names:tc:SAML:2.0:ac:classes:PasswordProtectedTransport</em> is selected.</li>
<li>Ensure <strong>Sign the AuthnRequest</strong> is turned off.</li>
<li>For <strong>SAML Response Signing</strong>, turn on <strong>Sign the Response</strong> and <strong>Sign the Assertion</strong>.</li>
<li>Select <strong>Test Configuration</strong>.</li>
<li>If all works well, select <strong>Turn on SSO</strong> or <strong>Add SSO</strong>.</li>
</ol>
