<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="business plan">

<ol>
<li>In Miro, select your profile picture &gt; <strong>Settings</strong> &gt; <strong><strong>Security</strong></strong>.</li>
<li>Turn on <strong>SSO/SAML</strong>.</li>
<li>Fill in the following fields:</li>
</ol>
<ul>
<li><strong>SAML Sign-in URL</strong>: SSO endpoint from application configuration in Cloudflare One</li>
<li><strong>Key x509 Certificate</strong>: Public key from application configuration in Cloudflare One</li>
</ul>
<ol start="4">
<li>In <strong>Domain</strong>, enter the domain you want to configure SSO for and select <strong>Enter</strong>.</li>
<li>Enter an email address from that domain and select <strong>send verification</strong>.</li>
<li>Once you receive a verification email, select the link in the email, then select <strong>Save</strong>. When the domain is successfully configured, the <strong>VERIFY EMAIL</strong> label next to the domain in the SSO/SAML configuration page will disappear.</li>
<li>If you have additional domains you want to configure SSO for, repeat steps 4-6 for each domain.</li>
</ol>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="enterprise plan">

<ol>
<li>In Miro, select your profile picture &gt; <strong>Settings</strong> &gt; <strong><strong>Security and Compliance</strong> &gt; <strong>Authentication</strong> &gt; <strong>Single sign-on</strong></strong>.</li>
<li>Turn on <strong>SSO/SAML</strong>.</li>
<li>Fill in the following fields:</li>
</ol>
<ul>
<li><strong>SAML Sign-in URL</strong>: SSO endpoint from application configuration in Cloudflare One</li>
<li><strong>Key x509 Certificate</strong>: Public key from application configuration in Cloudflare One</li>
</ul>
<ol start="4">
<li>In <strong>Domain</strong>, enter the domain you want to configure SSO for and select <strong>Enter</strong>.</li>
<li>If you have not previously <a href="https://help.miro.com/hc/articles/360034831793-Domain-control">verified the domain</a>, enter an email address from that domain and select <strong>send verification</strong>.</li>
<li>Once you receive a verification email, select the link in the email, then select <strong>Save</strong>. When the domain is successfully configured, the <strong>VERIFY EMAIL</strong> label next to the domain in the SSO/SAML configuration page will disappear.</li>
<li>If you have additional domains you want to configure SSO for, repeat steps 4-6 for each domain.</li>
</ol>

</section>
