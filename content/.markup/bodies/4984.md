

The [Access authentication logs](/api/resources/zero_trust/subresources/access/subresources/logs/subresources/access_requests/methods/list/) API endpoint provides a custom URL to export audit log events for your account.



<pre class="nb-api-request"><code class="language-bash">curl --request GET \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/logs/access_requests \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;</code></pre>
