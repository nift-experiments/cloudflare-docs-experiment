<p>To view logs for identity-based authentication events:</p>
<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Insights</strong> &gt; <strong>Logs</strong>.</li>
<li>Select <strong>Access authentication logs</strong>.</li>
</ol>
<aside class="nb-aside note">
<h3 class="nb-aside-title" id="body-4985-log-viewer-beta">Log viewer (beta)</h3>
<p>Access authentication logs use an updated log viewer with enhanced filtering capabilities. To switch to the classic view, select <strong>Return to old logs</strong>.</p>
</aside>
3. (Optional) Filter the logs that display in the log viewer. You can filter logs by their timestamp and event details (such as the Access application, user email, policy decision, and more).
<aside class="nb-aside tip">
<p>Querying for fewer fields improves log loading performance.</p>
</aside>
4. Select an individual timestamp to investigate the event in more detail.
