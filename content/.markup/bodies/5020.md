<li>From the <strong>Prove ownership</strong> step of the <strong>Bucket configuration</strong>, locate the <strong>Ownership token</strong> field.</li>
<li>Find the ownership challenge file that Cloudflare placed in your bucket, copy its contents, and enter them in the <strong>Ownership token</strong> field.</li>

<p>The <strong>Buckets</strong> tab displays a list of the buckets associated with your account. Refer to the <strong>Status</strong> column to see the status of your bucket configuration.</p>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>The <code>bucket</code> field should be the URI of the bucket. For Amazon S3, the <code>bucket</code> field is in the form <code>s3://&lt;bucket-name&gt;/&lt;directory&gt;?region=&lt;bucket-region&gt;</code>, and for Google Cloud Storage the form is <code>gs://&lt;bucket-name&gt;/&lt;directory&gt;</code>.</p>
<pre><code class="language-bash">curl https://api.cloudflare.com/client/v4/accounts/{account_id}/pcaps/ownership \
--header &quot;X-Auth-Email: &lt;EMAIL&gt;&quot; \
--header &quot;X-Auth-Key: &lt;API_KEY&gt;&quot; \
--header &quot;Content-Type: application/json&quot; \
--data '{
  &quot;destination_conf&quot;: &quot;'${bucket}'&quot;
}'
</code></pre>
<p>The response has a <code>&quot;filename&quot;</code> parameter which contains the content of the <code>ownership-challenge</code> text. Find the file in your bucket and copy the contents of the file.</p>
<pre><code class="language-json">{
	&quot;result&quot;: {
		&quot;id&quot;: &quot;cc20c2d6c62e11ecbe646b173af3b6b9&quot;,
		&quot;status&quot;: &quot;pending&quot;,
		&quot;submitted&quot;: &quot;2022-04-22T18:54:13.397413Z&quot;,
		&quot;validated&quot;: &quot;&quot;,
		&quot;destination_conf&quot;: &quot;gs://bucket-test&quot;, // Ensure you use a bucket that you created and registered in the Cloudflare dashboard.
		&quot;filename&quot;: &quot;ownership-challenge-1234.txt&quot;
	},
	&quot;success&quot;: true,
	&quot;errors&quot;: [],
	&quot;messages&quot;: []
}
</code></pre>
<p>Validate the bucket by inserting the copied text in the <code>ownership_text</code> below:</p>
<pre><code class="language-bash">curl https://api.cloudflare.com/client/v4/accounts/{account_id}/pcaps/ownership/validate \
--header &quot;X-Auth-Email: &lt;EMAIL&gt;&quot; \
--header &quot;X-Auth-Key: &lt;API_KEY&gt;&quot; \
--header &quot;Content-Type: application/json&quot; \
--data '{
  &quot;destination_conf&quot;: &quot;'${bucket}'&quot;,
  &quot;ownership_challenge&quot;: &quot;'${ownership_text}'&quot;
}'
</code></pre>
<pre><code class="language-json">{
	&quot;result&quot;: {
		&quot;id&quot;: &quot;cc20c2d6c62e11ecbe646b173af3b6b9&quot;,
		&quot;status&quot;: &quot;success&quot;,
		&quot;submitted&quot;: &quot;2022-04-22T18:54:13.397413Z&quot;,
		&quot;validated&quot;: &quot;2022-04-27T14:54:46.440548Z&quot;,
		&quot;destination_conf&quot;: &quot;gs://&lt;bucket-name&gt;&quot;, // Ensure you use a bucket that you created and registered in the Cloudflare dashboard
		&quot;filename&quot;: &quot;ownership-challenge-1234.txt&quot;
	},
	&quot;success&quot;: true,
	&quot;errors&quot;: [],
	&quot;messages&quot;: []
}
</code></pre>
<p>If the <code>status</code> shows <code>success</code>, the bucket is configured and ready to use.</p>
