<ol>
<li>
<p>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Integrations</strong> &gt; <strong>Identity providers</strong>.</p>
</li>
<li>
<p>In the <strong>Your identity providers</strong> card, select <strong>Add new identity provider</strong>.</p>
</li>
<li>
<p>Select the identity provider you want to add.</p>
</li>
</ol>
<p>If you do not see your identity provider listed, these providers can typically still be enabled. If they support OIDC or OAuth, select the <a href="/cloudflare-one/integrations/identity-providers/generic-oidc/">generic OIDC</a> option. If they support SAML, select the <a href="/cloudflare-one/integrations/identity-providers/generic-saml/">generic SAML</a> option. Cloudflare supports all SAML and OIDC providers and can integrate with the majority of OAuth providers. If your provider supports both SAML and OIDC, we recommend OIDC for ease of configuration.</p>
<ol start="4">
<li>Fill in the necessary fields to set up your identity provider.</li>
</ol>
<p>Each identity provider will have different required fields for you to fill in. Step-by-step instructions are shown in the dashboard side panel. Alternatively, refer to the <a href="/cloudflare-one/integrations/identity-providers/">IdP-specific documentation</a>.</p>
<ol start="5">
<li>Once you have filled in the necessary fields, select <strong>Save</strong>.</li>
</ol>

<ol start="2">
<li>Add an identity provider to Cloudflare One using the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_access_identity_provider"><code>cloudflare_zero_trust_access_identity_provider</code></a> resource. For example, to add a Microsoft Entra ID integration:</li>
</ol>
<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_access_identity_provider&quot; &quot;microsoft_entra_id&quot; {
	account_id = var.cloudflare_account_id
	name       = &quot;Entra ID example&quot;
	type       = &quot;azureAD&quot;
	config 		 = {
		client_id                  = var.entra_id_client_id
		client_secret              = var.entra_id_client_secret
		directory_id               = var.entra_id_directory_id
		support_groups             = true
		}
}
</code></pre>
<pre><code>Each identity provider integration has different required attributes. You will need to obtain these attribute values from your identity provider. For more information, refer to the [IdP-specific documentation](/cloudflare-one/integrations/identity-providers/).
</code></pre>
