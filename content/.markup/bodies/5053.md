

Unfederating an IdP via the API is a two-step process. Deleting the grant stops the sharing and removes the read-only IdP from recipient accounts. You can optionally clean up the share record afterward.

<h4 id="body-5053-1-delete-the-federation-grant"><ol>
<li>Delete the federation grant</li>
</ol></h4>

<pre><code class="language-bash">curl --request DELETE --url https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/access/idp_federation_grants/$GRANT_ID</code></pre>

<h4 id="body-5053-2-optional-delete-the-share"><ol start="2">
<li>(Optional) Delete the share</li>
</ol></h4>

<pre><code class="language-bash">curl --request DELETE --url https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/shares/$SHARE_ID</code></pre>
