<p>The dashboard handles both grant and share deletion in a single flow.</p>
<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Integrations</strong> &gt; <strong>Identity providers</strong>.</li>
<li>Find the shared IdP and select the three dots menu.</li>
<li>Select <strong>Unshare</strong>.</li>
<li>Confirm the action.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Unfederating an IdP via the API is a two-step process. Deleting the grant stops the sharing and removes the read-only IdP from recipient accounts. You can optionally clean up the share record afterward.</p>
<h4 id="body-5054-1-delete-the-federation-grant"><ol>
<li>Delete the federation grant</li>
</ol></h4>
<pre><code class="language-bash">curl --request DELETE --url https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/access/idp_federation_grants/$GRANT_ID</code></pre>
<h4 id="body-5054-2-optional-delete-the-share"><ol start="2">
<li>(Optional) Delete the share</li>
</ol></h4>
<pre><code class="language-bash">curl --request DELETE --url https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/shares/$SHARE_ID</code></pre>
