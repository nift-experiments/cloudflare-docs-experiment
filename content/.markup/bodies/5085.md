<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Integrations</strong> &gt; <strong>Identity providers</strong>.</li>
<li>Under <strong>Your identity providers</strong>, select <strong>Add new identity provider</strong>.</li>
<li>Select <strong>Cloudflare</strong>.</li>
<li>(Optional) Enable <strong>Restrict to account members</strong> if you want to limit authentication to users who are members of your Cloudflare account. When disabled, any user with a Cloudflare account can authenticate.</li>
<li>Select <strong>Save</strong>.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Make a <code>POST</code> request to the <a href="/api/resources/zero_trust/subresources/identity_providers/methods/create/">Identity Providers</a> endpoint:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/identity_providers \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;Cloudflare&quot;,
&quot;type&quot;: &quot;cloudflare&quot;,
&quot;config&quot;: {
  &quot;restrict_to_account_members&quot;: true
}
}&#x27;</code></pre>
