<p>With an API token that has either <code>Cloudflare One Connectors Write</code> or <code>Cloudflare One Connector: WARP Write</code> permission, create a node and retrieve its connector token:</p>
<pre><code class="language-bash">set -euo pipefail

NODE_RESPONSE=$(
	curl --fail-with-body --silent --show-error \
		&quot;https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/warp_connector&quot; \
		--request POST \
		--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
		--header &quot;Content-Type: application/json&quot; \
		--data '{&quot;name&quot;:&quot;k8s-gateway&quot;}'
)

jq -e '.success == true and (.result.id | type == &quot;string&quot;)' \
	&lt;&lt;&lt; &quot;$NODE_RESPONSE&quot; &gt; /dev/null
NODE_ID=$(jq -r '.result.id' &lt;&lt;&lt; &quot;$NODE_RESPONSE&quot;)

TOKEN_RESPONSE=$(
	curl --fail-with-body --silent --show-error \
		&quot;https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/warp_connector/$NODE_ID/token&quot; \
		--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;
)

MESH_NODE_TOKEN=$(jq -er \
	'select(.success == true) | .result | select(type == &quot;string&quot; and length &gt; 0)' \
	&lt;&lt;&lt; &quot;$TOKEN_RESPONSE&quot;)
</code></pre>
<p>Install <code>jq</code>, then set <code>ACCOUNT_ID</code> and <code>CLOUDFLARE_API_TOKEN</code> before running the commands. The commands stop on an HTTP or API error. Do not continue until they return zero and set <code>NODE_ID</code> and <code>MESH_NODE_TOKEN</code>. If token retrieval fails after node creation, retry only the token request with the existing <code>NODE_ID</code>. Do not rerun the node creation request. Pass <code>MESH_NODE_TOKEN</code> to the container.</p>
