

The setup wizard [configures your account for Mesh networking](#required-account-settings) and optionally guides you through creating a Mesh node. This is a one-time setup.

<div class="nb-steps">

<ol>
<li>In the Cloudflare dashboard, go to <strong>Networking</strong> &gt; <strong>Mesh</strong>.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select <strong>Add a node</strong>.</li>
<li>Enter a name for your node (for example, <code>web-server</code> or <code>staging-db</code>).</li>
<li>Select <strong>Create node</strong>.</li>
<li>(Optional) If you have a Linux server, run the install commands shown in the dashboard to bring the node online. If you do not have a server ready, select <strong>I'll connect later</strong> — you can install the node at any time from the node detail page.</li>
</ol>
<details class="nb-details"><summary>Installation commands</summary><div class="nb-details-body">
<p>IP forwarding is not required to reach the node by its Mesh IP. If the node will advertise <a href="/mesh/features/routes/">CIDR routes</a>, enable persistent forwarding before connecting it:</p>
<pre><code class="language-sh">printf 'net.ipv4.ip_forward = 1\nnet.ipv6.conf.all.forwarding = 1\nnet.ipv6.conf.all.accept_ra = 2\n' | sudo tee /etc/sysctl.d/99-zzz-cloudflare-warp-connector.conf &amp;&amp;
sudo sysctl --system
</code></pre>
<div class="nb-tabs" data-nb-tabs><div role="tablist" aria-label="Options" data-nb-tabs-list></div><div data-nb-tabs-panels>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Debian / Ubuntu">
<pre><code class="language-sh">curl -fsSL https://pkg.cloudflareclient.com/pubkey.gpg | sudo gpg --yes --dearmor -o /usr/share/keyrings/cloudflare-warp-archive-keyring.gpg &amp;&amp;
echo &quot;deb [signed-by=/usr/share/keyrings/cloudflare-warp-archive-keyring.gpg] https://pkg.cloudflareclient.com/ $(. /etc/os-release &amp;&amp; echo $VERSION_CODENAME) main&quot; | sudo tee /etc/apt/sources.list.d/cloudflare-client.list &amp;&amp;
sudo apt-get update -qq &amp;&amp; sudo apt-get install -y -qq cloudflare-warp
</code></pre>
<pre><code class="language-sh">sudo warp-cli --accept-tos connector new &lt;TOKEN&gt; &amp;&amp; sudo warp-cli --accept-tos connect
</code></pre>
</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="RedHat / CentOS">
<p>On RHEL 9 and later, enable the Extra Packages for Enterprise Linux (EPEL) repository before installing <code>cloudflare-warp</code>. EPEL provides dependencies required by the Cloudflare One Client UI:</p>
<pre><code class="language-sh">sudo dnf install -y epel-release
</code></pre>
<p>Then install the package:</p>
<pre><code class="language-sh">curl -fsSl https://pkg.cloudflareclient.com/cloudflare-warp-ascii.repo | sudo tee /etc/yum.repos.d/cloudflare-warp.repo &amp;&amp;
sudo yum install -y cloudflare-warp
</code></pre>
<pre><code class="language-sh">sudo warp-cli --accept-tos connector new &lt;TOKEN&gt; &amp;&amp; sudo warp-cli --accept-tos connect
</code></pre>
</section>
</div></div>

<li>Select <strong>View node details</strong> to complete the setup wizard.</li>
</ol>

If you installed the node, it should appear as **Online** on the Mesh overview page along with its assigned **Mesh IP**. If the node does not come online, refer to [Troubleshooting](#troubleshooting).
