

<div class="nb-steps">

<ol>
<li>In the Cloudflare dashboard, go to <strong>Pipelines</strong> &gt; <strong>Pipelines</strong>.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>
<p>Select <strong>Create Pipeline</strong>.</p>
</li>
<li>
<p><strong>Connect to a Stream</strong>:</p>
</li>
</ol>
<ul>
<li>Pipeline name: <code>ecommerce</code></li>
<li>Enable HTTP endpoint for sending data: Enabled</li>
<li>HTTP authentication: Disabled (default)</li>
<li>Select <strong>Next</strong></li>
</ul>
<ol start="4">
<li><strong>Define Input Schema</strong>:</li>
</ol>
<ul>
<li>Select <strong>JSON editor</strong></li>
<li>Copy in the schema:</li>
</ul>
<pre><code class="language-json">{
	&quot;fields&quot;: [
		{
			&quot;name&quot;: &quot;user_id&quot;,
			&quot;type&quot;: &quot;string&quot;,
			&quot;required&quot;: true
		},
		{
			&quot;name&quot;: &quot;event_type&quot;,
			&quot;type&quot;: &quot;string&quot;,
			&quot;required&quot;: true
		},
		{
			&quot;name&quot;: &quot;product_id&quot;,
			&quot;type&quot;: &quot;string&quot;,
			&quot;required&quot;: false
		},
		{
			&quot;name&quot;: &quot;amount&quot;,
			&quot;type&quot;: &quot;f64&quot;,
			&quot;required&quot;: false
		}
	]
}
</code></pre>
<ul>
<li>Select <strong>Next</strong></li>
</ul>
<ol start="5">
<li><strong>Define Sink</strong>:</li>
</ol>
<ul>
<li>Select your R2 bucket: <code>pipelines-tutorial</code></li>
<li>Storage type: <strong>R2 Data Catalog</strong></li>
<li>Namespace: <code>default</code></li>
<li>Table name: <code>ecommerce</code></li>
<li><strong>Advanced Settings</strong>: Change <strong>Maximum Time Interval</strong> to <code>10 seconds</code></li>
<li>Select <strong>Next</strong></li>
</ul>
<ol start="6">
<li><strong>Credentials</strong>:</li>
</ol>
<ul>
<li>Disable <strong>Automatically create an Account API token for your sink</strong></li>
<li>Enter <strong>Catalog Token</strong> from step 3</li>
<li>Select <strong>Next</strong></li>
</ul>
<ol start="7">
<li><strong>Pipeline Definition</strong>:</li>
</ol>
<ul>
<li>Leave the default SQL query:</li>
</ul>
<pre><code class="language-sql">INSERT INTO ecommerce_sink SELECT * FROM ecommerce_stream;
</code></pre>
<ul>
<li>Select <strong>Create Pipeline</strong></li>
</ul>
<ol start="8">
<li>After pipeline creation, note the <strong>Stream ID</strong> for the next step.</li>
</ol>

</div>
