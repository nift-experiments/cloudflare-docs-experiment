<p>When you create a Mesh node through the dashboard, high availability is enabled by default. To create a new node:</p>
<ol>
<li>In the Cloudflare dashboard, go to <strong>Networking</strong> &gt; <strong>Mesh</strong>.</li>
</ol>
<div class="nb-dash-button"></div>
2. Select **Add a node**.
3. Follow the setup wizard. The node is created with HA enabled automatically.
4. Copy the install commands and run them on your Linux host.

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To create a node with high availability via the API, set <code>ha: true</code> in the request body:</p>
<pre><code class="language-sh">curl -X POST &quot;https://api.cloudflare.com/client/v4/accounts/{account_id}/warp_connector&quot; \
  -H &quot;Authorization: Bearer {api_token}&quot; \
  -H &quot;Content-Type: application/json&quot; \
  -d '{
    &quot;name&quot;: &quot;web-server&quot;,
    &quot;ha&quot;: true
  }'
</code></pre>
<p>The response includes a <code>token</code> field. Use this token to register replicas.</p>
