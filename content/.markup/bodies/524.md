<p>First, create a schema file that defines your ecommerce data structure:</p>
<p><strong>Create <code>schema.json</code>:</strong></p>
<pre><code class="language-json">{
	&quot;fields&quot;: [
		{
			&quot;name&quot;: &quot;user_id&quot;,
			&quot;type&quot;: &quot;string&quot;,
			&quot;required&quot;: true
		},
		{
			&quot;name&quot;: &quot;event_type&quot;,
			&quot;type&quot;: &quot;string&quot;,
			&quot;required&quot;: true
		},
		{
			&quot;name&quot;: &quot;product_id&quot;,
			&quot;type&quot;: &quot;string&quot;,
			&quot;required&quot;: false
		},
		{
			&quot;name&quot;: &quot;amount&quot;,
			&quot;type&quot;: &quot;float64&quot;,
			&quot;required&quot;: false
		}
	]
}
</code></pre>
<p>Use the interactive setup to create a pipeline that writes to R2 Data Catalog:</p>
<pre><code class="language-bash">npx wrangler pipelines setup
</code></pre>
<p>Follow the prompts:</p>
<ol>
<li>
<p><strong>Pipeline name</strong>: Enter <code>ecommerce</code></p>
</li>
<li>
<p><strong>Stream configuration</strong>:</p>
</li>
</ol>
<ul>
<li>Enable HTTP endpoint: <code>yes</code></li>
<li>Require authentication: <code>no</code> (for simplicity)</li>
<li>Configure custom CORS origins: <code>no</code></li>
<li>Schema definition: <code>Load from file</code></li>
<li>Schema file path: <code>schema.json</code> (or your file path)</li>
</ul>
<ol start="3">
<li><strong>Sink configuration</strong>:</li>
</ol>
<ul>
<li>Destination type: <code>Data Catalog Table</code></li>
<li>R2 bucket name: <code>pipelines-tutorial</code></li>
<li>Namespace: <code>default</code></li>
<li>Table name: <code>ecommerce</code></li>
<li>Catalog API token: Enter your token from step 3</li>
<li>Compression: <code>zstd</code></li>
<li>Roll file when size reaches (MB): <code>100</code></li>
<li>Roll file when time reaches (seconds): <code>10</code> (for faster data visibility in this tutorial)</li>
</ul>
<ol start="4">
<li><strong>SQL transformation</strong>: Choose <code>Use simple ingestion query</code> to use:</li>
</ol>
<pre><code class="language-sql">INSERT INTO ecommerce_sink SELECT * FROM ecommerce_stream
</code></pre>
<p>After setup completes, note the HTTP endpoint URL displayed in the final output.</p>
