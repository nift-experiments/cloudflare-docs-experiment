<ol>
<li>In the Cloudflare dashboard, go to <strong>Networking</strong> &gt; <strong>Mesh</strong>.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select an HA-enabled node. HA nodes display an <strong>HA</strong> badge in the overview table.</li>
<li>The node detail page shows a tab for each replica. Each tab displays:</li>
</ol>
<ul>
<li><strong>Active</strong> or <strong>Passive</strong> badge</li>
<li>Mesh IP (IPv4 and IPv6)</li>
<li>Edge data center</li>
<li>Origin IP</li>
<li>Platform, version, and device name</li>
<li>Connected since timestamp</li>
</ul>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<pre><code class="language-sh">curl &quot;https://api.cloudflare.com/client/v4/accounts/{account_id}/warp_connector/{node_id}/connections&quot; \
  -H &quot;Authorization: Bearer {api_token}&quot;
</code></pre>
