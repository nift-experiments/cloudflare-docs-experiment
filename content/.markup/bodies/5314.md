<p><strong>If you created a remotely-managed tunnel using the dashboard:</strong></p>
<ol>
<li>In the Cloudflare dashboard, go to <strong>Networking</strong> &gt; <strong>Tunnels</strong>.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select your tunnel to open its detail page.</li>
<li>On the <strong>Overview</strong> tab, copy the Docker installation command. The copied command will contain your token.</li>
<li>Paste this command into a terminal window.</li>
</ol>
<p>This command creates a new container from the latest <code>cloudflared</code> image. You can now delete the old container.</p>
<aside class="nb-aside caution">
<p>Cloudflare recommends creating remotely-managed tunnels when working with Docker.</p>
</aside>
<p><strong>If you created a remotely or locally-managed tunnel using the API, run the following command:</strong></p>
<pre><code class="language-sh">docker run --pull always cloudflare/cloudflared:latest tunnel --no-autoupdate run --token &lt;TOKEN&gt;
</code></pre>
<p><strong>If you created a locally-managed tunnel using the CLI:</strong></p>
<ol>
<li>
<p>Mount your local <code>.cloudflared</code> directory into the Docker container using a volume.</p>
</li>
<li>
<p>Run the following command to update <code>cloudflared</code>:</p>
</li>
</ol>
<pre><code class="language-sh">docker run --pull always -v &lt;PATH-TO-YOUR-LOCAL-CLOUDFLARED&gt;:/home/nonroot/.cloudflared cloudflare/cloudflared:latest tunnel --no-autoupdate run &lt;TUNNEL-ID&gt;
</code></pre>
