

On Linux, Cloudflare Tunnel installs itself as a system service using `systemctl`. By default, the service will be named `cloudflared.service`. To configure your tunnel on Linux:

1. Open `cloudflared.service`.

<pre><code class="language-sh">sudo systemctl edit --full cloudflared.service
</code></pre>


2. Modify the `cloudflared tunnel run` command with the desired configuration flag. For example,

<pre><code class="language-txt">[Unit]
Description=Cloudflare Tunnel
After=network.target

[Service]
TimeoutStartSec=0
Type=notify
ExecStart=/usr/local/bin/cloudflared tunnel --loglevel info --logfile /var/log/cloudflared/cloudflared.log run --token &lt;TOKEN VALUE&gt;
Restart=on-failure
RestartSec=5s

[Install]
WantedBy=multi-user.target
</code></pre>


3. Restart `cloudflared.service`:

<pre><code class="language-sh">sudo systemctl restart cloudflared
</code></pre>


4. To verify the new configuration, check the service status:

<pre><code class="language-sh">sudo systemctl status cloudflared
</code></pre>
