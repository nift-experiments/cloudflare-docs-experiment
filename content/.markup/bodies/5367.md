
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the Cloudflare dashboard, go to <strong>Networking</strong> &gt; <strong>Tunnels</strong>.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select a tunnel to open its detail page.</li>
<li>On the <strong>Overview</strong> tab, select <strong>Refresh token</strong>.</li>
<li>Copy the <code>cloudflared</code> installation command for your operating system. This command contains the new token.</li>
</ol>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<pre><code>1. Generate a random base64 string (minimum size 32 bytes) to use as a tunnel secret:
</code></pre>
<pre><code class="language-sh">openssl rand -base64 32
</code></pre>
<pre><code class="language-sh">AQIDBAUGBwgBAgMEBQYHCAECAwQFBgcIAQIDBAUGBwg=
</code></pre>
<ol start="2">
<li>Make a <code>PATCH</code> request to the <a href="/api/resources/zero_trust/subresources/tunnels/methods/edit/">Cloudflare Tunnel</a> endpoint:</li>

 --data &#x27;{
 &quot;name&quot;: &quot;Example tunnel&quot;,
 &quot;tunnel_secret&quot;: &quot;AQIDBAUGBwgBAgMEBQYHCAECAwQFBgcIAQIDBAUGBwg=&quot;
}&#x27;</code></pre>
