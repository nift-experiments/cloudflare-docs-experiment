<p>To increase the number of ports available to <code>cloudflared</code> on Linux:</p>
<p>If your machine has a <code>/etc/sysctl.d/</code> directory:</p>
<pre><code class="language-sh">echo 'net.ipv4.ip_local_port_range = 11000 60999' | sudo tee -a /etc/sysctl.d/99-cloudflared.conf
sudo sysctl -p /etc/sysctl.d/99-cloudflared.conf
</code></pre>
<p>Otherwise:</p>
<pre><code class="language-sh">echo 'net.ipv4.ip_local_port_range = 11000 60999' | sudo tee -a /etc/sysctl.conf
sudo sysctl -p /etc/sysctl.conf
</code></pre>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Windows">

<p>To increase the number of ports available to <code>cloudflared</code> on Windows, set the <a href="https://learn.microsoft.com/en-us/troubleshoot/windows-client/networking/tcp-ip-port-exhaustion-troubleshooting">dynamic port range</a> for TCP and UDP:</p>
<pre><code class="language-txt">netsh int ipv4 set dynamicport tcp start=11000 num=50000
netsh int ipv4 set dynamicport udp start=11000 num=50000
netsh int ipv6 set dynamicport tcp start=11000 num=50000
netsh int ipv6 set dynamicport udp start=11000 num=50000
</code></pre>
