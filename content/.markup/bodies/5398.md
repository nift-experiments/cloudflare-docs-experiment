
To delete a virtual network for [locally-managed tunnels](/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/local-management/):

1. Delete all IP routes in the virtual network. For example,

<pre><code class="language-sh">cloudflared tunnel route ip delete --vnet staging-vnet 10.128.0.3/32
</code></pre>


2. (Optional) Delete the tunnel associated with the virtual network.

<pre><code class="language-sh">cloudflared tunnel delete staging-tunnel
</code></pre>


3. Delete the virtual network.

<pre><code class="language-sh">cloudflared tunnel vnet delete staging-vnet
</code></pre>


You can verify that the virtual network was successfully deleted by typing `cloudflared tunnel vnet list`.
