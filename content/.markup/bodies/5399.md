
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<p>To delete a virtual network:</p>
<ol>
<li>In the Cloudflare dashboard, go to <strong>Networking</strong> &gt; <strong>Routes</strong>.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>
<p>On the <strong>Routes</strong> tab, check that no routes are assigned to the virtual network you are trying to delete. If the virtual network is in use, delete those routes or reassign them to a different virtual network first.</p>
</li>
<li>
<p>Go to the <strong>Virtual networks</strong> tab and find your virtual network.</p>
</li>
<li>
<p>Select the three-dot menu and choose <strong>Delete</strong>.</p>
</li>
</ol>
<p>You can optionally delete the tunnel associated with your virtual network.</p>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Locally-managed tunnels">

<p>To delete a virtual network for <a href="/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/local-management/">locally-managed tunnels</a>:</p>
<ol>
<li>Delete all IP routes in the virtual network. For example,</li>
</ol>
<pre><code class="language-sh">cloudflared tunnel route ip delete --vnet staging-vnet 10.128.0.3/32
</code></pre>
<ol start="2">
<li>(Optional) Delete the tunnel associated with the virtual network.</li>
</ol>
<pre><code class="language-sh">cloudflared tunnel delete staging-tunnel
</code></pre>
<ol start="3">
<li>Delete the virtual network.</li>
</ol>
<pre><code class="language-sh">cloudflared tunnel vnet delete staging-vnet
</code></pre>
<p>You can verify that the virtual network was successfully deleted by typing <code>cloudflared tunnel vnet list</code>.</p>

</section>
