

To attract a hostname's traffic to a Mesh node instead of a `cloudflared` tunnel, add a [hostname route](/mesh/features/routes/#hostname-routes) to the node. The <span class="nb-glossary-tooltip" title="initial resolved IP">initial resolved IP</span> listed above must route through Cloudflare on both the Mesh node and client device profiles, and — for a private hostname — the node must be able to resolve the hostname (via its local hosts file or a Gateway resolver policy). Refer to [Hostname routes](/mesh/features/routes/#hostname-routes).
