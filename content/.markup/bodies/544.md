<div class="nb-steps">
<ol>
<li>In the Cloudflare dashboard, go to the <strong>R2 Data Catalog</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
2. Select the catalog you want to enable compaction on.
3. Go to the **Settings** tab and scroll to the **Table Maintenance** section.
4. Select **Enable** or **Edit** next to compaction.
5. Toggle compaction on and optionally set a target file size. The default is 128 MB.
6. Select **Save**.
</div>
<aside class="nb-aside note">
<p>If no service credential has been generated for this catalog, the dashboard will prompt you to generate one. Compaction requires a credential to access and rewrite files in your bucket.</p>
</aside>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Wrangler CLI">

<p>To enable the compaction on your catalog, run the <a href="/workers/wrangler/commands/r2/#r2-bucket-catalog-compaction-enable"><code>r2 bucket catalog compaction enable</code> command</a>:</p>
<pre><code class="language-bash"># Enable catalog-level compaction (all tables)
npx wrangler r2 bucket catalog compaction enable &lt;BUCKET_NAME&gt; --target-size 128 --token &lt;API_TOKEN&gt;

# Enable compaction for a specific table
npx wrangler r2 bucket catalog compaction enable &lt;BUCKET_NAME&gt; &lt;NAMESPACE&gt; &lt;TABLE&gt; --target-size 128
</code></pre>
<aside class="nb-aside note">
<h3 class="nb-aside-title" id="body-544-table-level-vs-catalog-level-compaction">Table-level vs Catalog-level compaction</h3>
<ul>
<li><strong>Catalog-level</strong>: Applies to all tables in the bucket; requires an API token as a service credential.</li>
<li><strong>Table-level</strong>: Applies to a specific table only.</li>
</ul>
</aside>
