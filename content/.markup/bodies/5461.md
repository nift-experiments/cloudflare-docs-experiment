
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>
<p>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Access controls</strong> &gt; <strong>Service credentials</strong> &gt; <strong>SSH</strong>.</p>
</li>
<li>
<p>Select <strong>Add a certificate</strong>.</p>
</li>
<li>
<p>Under <strong>SSH with Access for Infrastructure</strong>, select <strong>Generate SSH CA</strong>. A new row will appear in the short-lived certificates table called <strong>SSH with Access for Infrastructure</strong>.</p>
</li>
<li>
<p>Select the <strong>SSH with Access for Infrastructure</strong> certificate.</p>
</li>
<li>
<p>Copy its <strong>CA public key</strong>. You can return to copy this public key at any time.</p>
</li>
</ol>

</section>

<ol start="2">
<li>If you have not yet generated a Cloudflare SSH CA, make a <code>POST</code> request to the Cloudflare API:</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/gateway_ca \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;</code></pre>
<ol start="3">
<li>If you have already created a Cloudflare SSH CA or receive the error message <code>access.api.error.gateway_ca_already_exists</code>, make a <code>GET</code> request instead:</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request GET \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/gateway_ca \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;</code></pre>
<ol start="4">
<li>Copy the <code>public_key</code> value returned in the response.</li>
</ol>
