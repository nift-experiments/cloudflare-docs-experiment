<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Wrangler CLI">

<p>To disable the compaction on your catalog, run the <a href="/workers/wrangler/commands/r2/#r2-bucket-catalog-compaction-disable"><code>r2 bucket catalog compaction disable</code> command</a>:</p>
<pre><code class="language-bash"># Disable catalog-level compaction (all tables)
npx wrangler r2 bucket catalog compaction disable &lt;BUCKET_NAME&gt;

# Disable compaction for a specific table
npx wrangler r2 bucket catalog compaction disable &lt;BUCKET_NAME&gt; &lt;NAMESPACE&gt; &lt;TABLE&gt;
</code></pre>
