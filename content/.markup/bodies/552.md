<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Wrangler CLI">

<aside class="nb-aside note">
<p>Snapshot expiration commands are available as of Wrangler version 4.56.0.</p>
</aside>
<p>To enable snapshot expiration on your catalog, run the <a href="/workers/wrangler/commands/r2/#r2-bucket-catalog-snapshot-expiration-enable"><code>r2 bucket catalog snapshot-expiration enable</code> command</a>:</p>
<pre><code class="language-bash"># Enable catalog-level snapshot expiration (all tables)
npx wrangler r2 bucket catalog snapshot-expiration enable &lt;BUCKET_NAME&gt; \
  --token &lt;API_TOKEN&gt; \
  --older-than-days 7 \
  --retain-last 10

# Enable snapshot expiration for a specific table
npx wrangler r2 bucket catalog snapshot-expiration enable &lt;BUCKET_NAME&gt; &lt;NAMESPACE&gt; &lt;TABLE&gt; \
  --older-than-days 2 \
  --retain-last 5
</code></pre>
