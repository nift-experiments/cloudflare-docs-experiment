
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Access controls</strong> &gt; <strong>Applications</strong>.</li>
<li>Locate your browser-based RDP application and select <strong>Configure</strong>.</li>
<li>Select the <strong>Policies</strong> tab.</li>
<li>Create a new policy or select an existing policy to edit.</li>
<li>Expand <strong>Connection context</strong>.</li>
<li>Under <strong>Connection settings</strong>, configure the following settings:</li>
</ol>
<ul>
<li><strong>Text controls</strong> — Select a directional setting for text copy and paste.</li>
<li><strong>File controls</strong> — Select a directional setting for file uploads and downloads.</li>
</ul>
<ol start="7">
<li>Select <strong>Save policy</strong>.</li>
</ol>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>When <a href="/api/resources/zero_trust/subresources/access/subresources/policies/">creating or updating an Access policy</a> for an RDP application, configure the allowed formats in each direction. Use <code>text</code> for text clipboard and <code>file</code> for file transfer. For example, the following policy allows text clipboard in both directions but only allows file uploads (local to remote).</p>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/policies \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;Allow engineers with clipboard and upload&quot;,
&quot;decision&quot;: &quot;allow&quot;,
&quot;include&quot;: [
  {
    &quot;email_domain&quot;: {
      &quot;domain&quot;: &quot;example.com&quot;
    }
  }
],
&quot;connection_rules&quot;: {
  &quot;rdp&quot;: {
    &quot;allowed_clipboard_local_to_remote_formats&quot;: [
      &quot;text&quot;,
      &quot;file&quot;
    ],
    &quot;allowed_clipboard_remote_to_local_formats&quot;: [
      &quot;text&quot;
    ]
  }
}
}&#x27;</code></pre>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Terraform">

<p>Using the <code>connection_rules</code> attribute within a <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_access_policy"><code>cloudflare_zero_trust_access_policy</code></a> resource, configure the allowed formats in each direction. Use <code>text</code> for text clipboard and <code>file</code> for file transfer. For example, the following policy allows text clipboard in both directions but only allows file uploads (local to remote).</p>
<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_access_policy&quot; &quot;rdp-policy&quot; {
	account_id = var.cloudflare_account_id
	name       = &quot;Allow engineers with clipboard and upload&quot;
	decision   = &quot;allow&quot;

	include = [
		{
			email_domain = {
				domain = &quot;example.com&quot;
			}
		}
	]

	connection_rules = {
		rdp = {
			allowed_clipboard_local_to_remote_formats = [&quot;text&quot;, &quot;file&quot;]
			allowed_clipboard_remote_to_local_formats = [&quot;text&quot;]
		}
	}
}
</code></pre>
