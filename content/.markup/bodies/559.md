
1. If not already logged in, run:

<pre><code class="language-bash">npx wrangler login
</code></pre>


2.  Create an R2 bucket:

<pre><code class="language-bash">npx wrangler r2 bucket create r2-data-catalog-tutorial
</code></pre>


3.  Enable the catalog on your bucket:

<pre><code class="language-bash">npx wrangler r2 bucket catalog enable r2-data-catalog-tutorial
</code></pre>


When you run this command, take note of the **Warehouse** and **Catalog URI**. You will need these later.
