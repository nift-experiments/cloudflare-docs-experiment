

<aside class="nb-aside note">


<p>You will need your <a href="/fundamentals/account/find-account-and-zone-ids/">account ID</a> and <a href="/fundamentals/api/get-started/account-owned-tokens/">API token</a> to use the API.</p>


</aside>

Create a `POST` request [using the API](/api/resources/magic_transit/subresources/routes/methods/create/) to create one or more static routes.

Example:



<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/routes \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;nexthop&quot;: &quot;&lt;IP_NEXT_HOP&gt;&quot;,
&quot;prefix&quot;: &quot;&lt;YOUR_IP_PREFIX&gt;&quot;,
&quot;priority&quot;: 0,
&quot;id&quot;: &quot;023e105f4ecef8ad9ca31a8372d0c353&quot;,
&quot;description&quot;: &quot;&lt;ROUTE_DESCRIPTION&gt;&quot;,
&quot;scope&quot;: {
  &quot;colo_names&quot;: [
    &quot;den01&quot;
  ],
  &quot;colo_regions&quot;: [
    &quot;APAC&quot;
  ]
},
&quot;weight&quot;: 0
}&#x27;</code></pre>
