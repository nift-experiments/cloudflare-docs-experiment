<details class="nb-details"><summary>Alert by tunnel</summary><div class="nb-details-body">
<ol start="5">
<li>Select <strong>Alert by tunnel</strong>.</li>
<li>Enter a name and description for the notification.</li>
<li>Add webhooks or an email address for the person who should receive the notification, and select <strong>Next</strong>.</li>
<li>Select the <strong>Alert Sensitivity Level</strong> threshold from the drop-down menu. The threshold defaults to <em>Medium (98.0)</em>. You can choose from options between <em>Minimum (95.0)</em> and <em>Maximum (99.9)</em>. For details, refer to <a href="/cloudflare-one/networks/connectors/cloudflare-wan/reference/how-cloudflare-calculates-tunnel-health-alerts/">How Cloudflare calculates Tunnel health alerts</a>.</li>
<li>From the <strong>Alert interval</strong> drop-down menu, set the minimum amount of time that must pass before Cloudflare sends you a duplicate alert. Options range from five minutes to seven days.</li>
<li>Enable <strong>Set as default alert for any new tunnels created in the future</strong> if you want the alert sensitivity level you chose to be automatically applied to all new tunnels you create.</li>
<li>Select <strong>Next</strong>.</li>
<li>Choose the tunnels you want to receive alerts for. You can search by specific tunnel names, or filter them by type (Generic Routing Encapsulation (GRE), Internet Protocol Security (IPsec), and CNI (Cloudflare Network Interconnect)). Select <strong>Next</strong>.</li>
<li>Review the details of your alert. If these details are correct, select <strong>Create alert</strong>.</li>
</ol>
