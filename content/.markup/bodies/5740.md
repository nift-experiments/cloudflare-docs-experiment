<ol>
<li>In <strong>LAN configuration</strong>, select <strong>Create</strong>.</li>
<li>Enter a descriptive name for your LAN in <strong>Interface name</strong>.</li>
<li><strong>Interface number</strong> needs to correspond to the virtual LAN interface on the Virtual Appliance instance you have set up in VMware. Following our example from the previous steps, you need to choose port <code>2</code> since that is what corresponds to the <code>eno2</code> port we set up in VMware.</li>
<li>In <strong>VLAN ID</strong>, specify a <a href="/cloudflare-one/networks/connectors/cloudflare-wan/configuration/appliance/reference/#vlan-id">VLAN ID</a> to create virtual LANs.</li>
<li>In <strong>Static addressing</strong> &gt; <strong>Static address</strong> give your Virtual Appliance's LAN interface its IP address. You can also enable the following options if they suit your use case:</li>
</ol>
<ul>
<li><strong>This is a DHCP server</strong>: If your Virtual Appliance is a <a href="/cloudflare-one/networks/connectors/cloudflare-wan/configuration/appliance/network-options/dhcp/dhcp-server/">DHCP server</a>.</li>
<li><strong>This is a DHCP relay</strong>: If your Virtual Appliance is a <a href="/cloudflare-one/networks/connectors/cloudflare-wan/configuration/appliance/network-options/dhcp/dhcp-relay/">DHCP relay</a>.</li>
</ul>
<ol start="6">
<li>(Optional) In <strong>Directly attached subnet</strong> &gt; <strong>Static NAT prefix</strong>, enter a CIDR prefix to enable NAT (network address translation). The prefix you enter here should be the same size as the prefix entered in <strong>Static addressing</strong>. For example, both networks have a subnet mask of <code>/24</code>: <code>192.168.100.0/24</code> and <code>10.10.100.0/24</code>.</li>
<li>(Optional) If your LAN contains additional subnets behind a layer 3 router, select <strong>Add routed subnet</strong> under <strong>Routed subnets</strong> to add them:</li>
</ol>
<ul>
<li><strong>Prefix</strong>: The CIDR prefix for the subnet behind the L3 router.</li>
<li><strong>Next hop</strong>: The address of the L3 router to which the Virtual Appliance should forward packets for this subnet.</li>
<li><strong>Static NAT prefix</strong>: Optional setting. If you want to enable NAT for a routed subnet, supply an &quot;external&quot; prefix for the overlay-facing side of the NAT to use. It must be the same size as <strong>Prefix</strong>. <br /> For details, refer to <a href="/cloudflare-one/networks/connectors/cloudflare-wan/configuration/appliance/network-options/routed-subnets/">Routed subnets</a>.</li>
</ul>
<ol start="8">
<li>Select <strong>Save</strong>.</li>
<li>Select <strong>Done</strong> to finish your configuration. Tunnels and <span class="nb-glossary-tooltip" title="static route">static routes</span> will be automatically created for your Virtual Appliance, once it boots up.</li>
</ol>
