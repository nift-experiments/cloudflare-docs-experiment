<p>Follow these steps to create a new LAN policy to segment your network. Only the fields marked <strong>required</strong> are mandatory.</p>
<ol>
<li>
<p>Log in to <a href="https://one.dash.cloudflare.com/">Cloudflare One</a>, and go to <strong>Networks</strong>.</p>
</li>
<li>
<p>Go to <strong>Connectors</strong> &gt; <strong>Appliances</strong> &gt; <strong>Profiles</strong>.</p>
</li>
<li>
<p>Select the Cloudflare One Appliance you want to configure &gt; <strong>Edit</strong>.</p>
</li>
<li>
<p>Go to <strong>Network Configuration</strong> &gt; <strong>LAN configuration</strong>.</p>
</li>
<li>
<p>Select <strong>LAN policies</strong> &gt; <strong>Create</strong>.</p>
</li>
<li>
<p>In <strong>Policy name</strong>, enter a descriptive name for the policy you are creating.</p>
</li>
<li>
<p>From the drop-down menu <strong>Origin (required)</strong>, select your origin LAN.</p>
</li>
<li>
<p>Specify a subnet for your first LAN in <strong>Subnets</strong>.</p>
</li>
<li>
<p>In <strong>Ports</strong> specify the TCP/UDP ports you want to use. Valid ports range from <code>1</code> to <code>65535</code>. Zero (<code>0</code>) is not a valid port number. Add a comma to separate each of the ports or add a port range. For example, <code>2,5,6,9-14</code>.</p>
</li>
<li>
<p>In <strong>Destination (required)</strong>, select the destination LAN and repeat the above process to configure it.</p>
</li>
<li>
<p>In <strong>Protocols</strong>, select the type of traffic you want to allow. You can choose <strong>TCP</strong>, <strong>UDP</strong>, and <strong>ICMP</strong>. You can also select <strong>Any</strong> to choose all types of traffic.</p>
</li>
<li>
<p>In <strong>Traffic direction</strong> you can choose between bidirectional traffic (the default) and unidirectional traffic. What you can choose depends on the protocol that you chose for the policy:</p>
</li>
</ol>
<ul>
<li><strong>Any</strong>: If <strong>Any</strong> is selected and you choose <strong>Unidirectional</strong>, the system will alert you that this will break TCP traffic.</li>
<li><strong>TCP</strong>: You can only select <strong>Bidirectional</strong>.</li>
<li><strong>UDP</strong>: The system defaults to <strong>Bidirectional</strong> but you can choose <strong>Unidirectional</strong>.</li>
<li><strong>ICMP</strong>: The system defaults to <strong>Bidirectional</strong> but you can choose <strong>Unidirectional</strong>.</li>
</ul>
<ol start="13">
<li>In <strong>Traffic path</strong>, select <strong>Forwarded via Cloudflare</strong> if you want traffic to be forwarded to Cloudflare to be processed. If you do not select this option, traffic will flow locally in your premises, without passing through Cloudflare.</li>
<li>Select <strong>Save</strong>.</li>
</ol>
