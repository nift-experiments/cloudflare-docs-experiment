

<aside class="nb-aside note">


<p>You will need your <a href="/fundamentals/account/find-account-and-zone-ids/">account ID</a> and <a href="/fundamentals/api/get-started/account-owned-tokens/">API token</a> to use the API.</p>


</aside>

Create a `DELETE` request [using the API](/api/resources/magic_transit/subresources/sites/subresources/acls/methods/delete/) to delete a network policy.

Example:



<pre class="nb-api-request"><code class="language-bash">curl --request DELETE \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/sites/{site_id}/acls/{acl_id} \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;</code></pre>
