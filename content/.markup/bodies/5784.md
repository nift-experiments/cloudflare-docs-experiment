<ol>
<li>Configure your Cloudflare One Appliance to be a <a href="/cloudflare-one/networks/connectors/cloudflare-wan/configuration/appliance/network-options/dhcp/dhcp-server/">DHCP server</a>.</li>
<li>Select <strong>Add DHCP Reservation</strong>.</li>
<li>In <strong>Hardware Address</strong> enter the <a href="https://en.wikipedia.org/wiki/MAC_address">MAC address</a> for the device you want a specific IP address for.</li>
<li>In <strong>IP Address</strong>, enter the IP address for that device.</li>
<li>(Optional) If you need to reserve more IP addresses, select <strong>Add DHCP Reservation</strong> as many times as needed, and enter the new values.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<aside class="nb-aside note">
<p>You will need your <a href="/fundamentals/account/find-account-and-zone-ids/">account ID</a> and <a href="/fundamentals/api/get-started/account-owned-tokens/">API token</a> to use the API.</p>
</aside>
<p>Create a <a href="/api/resources/magic_transit/subresources/sites/subresources/lans/methods/update/"><code>PUT</code> request</a> to update the LAN where you want to reserve addresses:</p>
<p>Example:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request PUT \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/sites/{site_id}/lans/{lan_id} \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;lan&quot;: {
  &quot;static_addressing&quot;: {
    &quot;dhcp_server&quot;: {
      &quot;reservations&quot;: {
        &quot;&lt;HARDWARE_MAC_ADDRESS&gt;&quot;: &quot;&lt;IP_ADDRESS&gt;&quot;,
        &quot;&lt;HARDWARE_MAC_ADDRESS_2&gt;&quot;: &quot;&lt;IP_ADDRESS&gt;&quot;
      }
    }
  }
}
}&#x27;</code></pre>
