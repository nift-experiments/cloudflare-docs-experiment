<ol>
<li>Log in to <a href="https://one.dash.cloudflare.com/">Cloudflare One</a>, and go to <strong>Networks</strong>.</li>
<li>Go to <strong>Connectors</strong> &gt; <strong>Appliances</strong> &gt; <strong>Profiles</strong>.</li>
<li>Select the Cloudflare One Appliance you want to configure &gt; <strong>Edit</strong>.</li>
<li>Select <strong>Network Configuration</strong> &gt; <strong>LAN configuration</strong>.</li>
<li>In <strong>LAN configuration</strong>, select the LAN where you want to enable DHCP server.</li>
<li>Select <strong>Edit</strong>.</li>
<li>Under <strong>Static addressing</strong>, select <strong>This is a DHCP Server</strong>. You also have to specify:</li>
</ol>
<ul>
<li>The DNS server address. You can have more than one IP address. Select <strong>Add DNS Server</strong> for each server you want to add.</li>
<li>The DHCP pool start</li>
<li>The DHCP pool end</li>
</ul>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<aside class="nb-aside note">
<p>You will need your <a href="/fundamentals/account/find-account-and-zone-ids/">account ID</a> and <a href="/fundamentals/api/get-started/account-owned-tokens/">API token</a> to use the API.</p>
</aside>
<p>Create a <a href="/api/resources/magic_transit/subresources/sites/subresources/lans/methods/update/"><code>PUT</code> request</a> to update the LAN where you want to enable DHCP server:</p>
<p>Example:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request PUT \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/sites/{site_id}/lans/{lan_id} \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;lan&quot;: {
  &quot;static_addressing&quot;: {
    &quot;dhcp_server&quot;: {
      &quot;dhcp_pool_end&quot;: &quot;&lt;IP_ADDRESS&gt;&quot;,
      &quot;dhcp_pool_start&quot;: &quot;&lt;IP_ADDRESS&gt;&quot;,
      &quot;dns_server&quot;: &quot;&lt;IP_ADDRESS&gt;&quot;
    }
  }
}
}&#x27;</code></pre>
