<ol>
<li>
<p>Log in to the <a href="https://one.dash.cloudflare.com/">Cloudflare One dashboard</a>, and go to <strong>Networks</strong>.</p>
</li>
<li>
<p>Go to <strong>Connectors</strong> &gt; <strong>Appliances</strong> &gt; <strong>Profiles</strong>.</p>
</li>
<li>
<p>Select the Cloudflare One Appliance you want to configure &gt; <strong>Edit</strong>.</p>
</li>
<li>
<p>Select <strong>Traffic Steering</strong>.</p>
</li>
<li>
<p>In <strong>Prioritized traffic</strong>, select <strong>Create</strong>.</p>
</li>
<li>
<p>Select one or more applications that should bypass Cloudflare filtering from the list. You can also use the search box.</p>
</li>
<li>
<p>Select <strong>Save</strong>.</p>
</li>
</ol>
<p>The traffic for the application you chose is now processed first by Connector.</p>

<aside class="nb-aside note">
<p>You will need your <a href="/fundamentals/account/find-account-and-zone-ids/">account ID</a> and <a href="/fundamentals/api/get-started/account-owned-tokens/">API token</a> to use the API.</p>
</aside>
<ol>
<li>Send a <code>GET</code> <a href="/api/resources/magic_transit/subresources/apps/methods/list/">request</a> to list the applications associated with an account.</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request GET \
 --url https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/apps \
 --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;</code></pre>
<pre><code class="language-json">	{
		&quot;result&quot;: [
			{
				&quot;managed_app_id&quot;: &quot;&lt;APP_ID&gt;&quot;,
				&quot;name&quot;: &quot;&lt;APP_NAME&gt;&quot;,
				&quot;type&quot;: &quot;File Sharing&quot;,
				&quot;hostnames&quot;: [
					&quot;&lt;app_name.com&gt;&quot;,
					&quot;&lt;app-name.info&gt;&quot;
				]
			}
		]
	}
</code></pre>
<p>Take note of the <code>&quot;managed_app_id&quot;</code> value for any application you want to add.</p>
<ol start="2">
<li>Send a <code>POST</code> request to add new apps to the Prioritized traffic policy.</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
 --url https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/sites/{site_id}/app_configs \
 --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
 --data &#x27;{
 &quot;managed_app_id&quot;: &quot;&lt;MANAGED_APP_ID&gt;&quot;,
 &quot;breakout&quot;: true
}&#x27;</code></pre>
<pre><code class="language-json">{
	&quot;result&quot;: {

		&quot;name&quot;: &quot;&lt;APP_NAME&gt;&quot;,

	},
