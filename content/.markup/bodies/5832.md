

<details class="nb-details" open><summary>Authorization endpoint</summary><div class="nb-details-body">

<p>To add an <a href="#authorization-endpoint">authorization endpoint</a>:</p>
<ol>
<li>In <a href="https://one.dash.cloudflare.com/">Cloudflare One</a>, go to <strong>Networks</strong> &gt; <strong>Resolvers &amp; Proxies</strong>, then go to <strong>Proxy endpoints</strong>.</li>
<li>In <strong>Proxy endpoints</strong>, select <strong>Add an endpoint</strong>.</li>
<li>Choose <strong>Add an authorization endpoint</strong>.</li>
<li>Name your endpoint.</li>
<li>Add <a href="/cloudflare-one/access-controls/policies/">Access policies</a> to control who can access your applications. You can select existing policies or create new policies.</li>
<li>Choose which login methods to support. To accept all login methods, turn on <strong>Accept all available identity providers</strong>.</li>
<li>(Optional) If only one identity provider is configured, turn on <strong>Apply instant authentication</strong> to skip identity provider selection when your users reach the proxy endpoint.</li>
<li>Select <strong>Create</strong>.</li>
</ol>

</div></details>

<details class="nb-details" open><summary>Source IP endpoint</summary><div class="nb-details-body">

<p>To add a <a href="#source-ip-endpoint">source IP endpoint</a>:</p>
<ol>
<li>In <a href="https://one.dash.cloudflare.com/">Cloudflare One</a>, go to <strong>Networks</strong> &gt; <strong>Resolvers &amp; Proxies</strong>, then go to <strong>Proxy endpoints</strong>.</li>
<li>In <strong>Proxy endpoints</strong>, select <strong>Add an endpoint</strong>.</li>
<li>Choose <strong>Add a source IP endpoint</strong>.</li>
<li>Name your endpoint.</li>
<li>Add the source IP addresses of your devices in CIDR notation. For example:</li>
</ol>
<ul>
<li><strong>IPv4</strong>: <code>192.0.2.0/8</code></li>
<li><strong>IPv6</strong>: <code>2001:0db8:0000:0000:0000:1234:5678:0000/32</code></li>
</ul>
<ol start="6">
<li>Select <strong>Save endpoint</strong>.</li>
</ol>

</div></details>
