<details class="nb-details" open><summary>Authorization endpoint</summary><div class="nb-details-body">
<p>To add an <a href="#authorization-endpoint">authorization endpoint</a>:</p>
<ol>
<li>In <a href="https://one.dash.cloudflare.com/">Cloudflare One</a>, go to <strong>Networks</strong> &gt; <strong>Resolvers &amp; Proxies</strong>, then go to <strong>Proxy endpoints</strong>.</li>
<li>In <strong>Proxy endpoints</strong>, select <strong>Add an endpoint</strong>.</li>
<li>Choose <strong>Add an authorization endpoint</strong>.</li>
<li>Name your endpoint.</li>
<li>Add <a href="/cloudflare-one/access-controls/policies/">Access policies</a> to control who can access your applications. You can select existing policies or create new policies.</li>
<li>Choose which login methods to support. To accept all login methods, turn on <strong>Accept all available identity providers</strong>.</li>
<li>(Optional) If only one identity provider is configured, turn on <strong>Apply instant authentication</strong> to skip identity provider selection when your users reach the proxy endpoint.</li>
<li>Select <strong>Create</strong>.</li>
</ol>
</div></details>
<details class="nb-details" open><summary>Source IP endpoint</summary><div class="nb-details-body">
<p>To add a <a href="#source-ip-endpoint">source IP endpoint</a>:</p>
<ol>
<li>In <a href="https://one.dash.cloudflare.com/">Cloudflare One</a>, go to <strong>Networks</strong> &gt; <strong>Resolvers &amp; Proxies</strong>, then go to <strong>Proxy endpoints</strong>.</li>
<li>In <strong>Proxy endpoints</strong>, select <strong>Add an endpoint</strong>.</li>
<li>Choose <strong>Add a source IP endpoint</strong>.</li>
<li>Name your endpoint.</li>
<li>Add the source IP addresses of your devices in CIDR notation. For example:</li>
</ol>
<ul>
<li><strong>IPv4</strong>: <code>192.0.2.0/8</code></li>
<li><strong>IPv6</strong>: <code>2001:0db8:0000:0000:0000:1234:5678:0000/32</code></li>
</ul>
<ol start="6">
<li>Select <strong>Save endpoint</strong>.</li>
</ol>
</div></details>

<details class="nb-details" open><summary>Authorization endpoint</summary><div class="nb-details-body">
<p>To create an authorization endpoint:</p>
<ol>
<li>Use <a href="/api/resources/zero_trust/subresources/gateway/subresources/proxy_endpoints/methods/create/">Create a Proxy Endpoint</a> with the following call:</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/proxy_endpoints \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;kind&quot;: &quot;identity&quot;,
&quot;name&quot;: &quot;any_name&quot;
}&#x27;</code></pre>
<ol start="2">
<li>The response returns output similar to the following:</li>
</ol>
<pre><code class="language-json">{
	&quot;result&quot;: {
		&quot;kind&quot;: &quot;identity&quot;,
		&quot;id&quot;: &quot;d969d7bf-ec28-4291-9af0-86825f472c21&quot;,
		&quot;name&quot;: &quot;Identity Proxy Endpoint&quot;,
		&quot;created_at&quot;: &quot;2014-01-01T05:20:00.12345Z&quot;,
		&quot;updated_at&quot;: &quot;2014-01-01T05:20:00.12345Z&quot;,
		&quot;subdomain&quot;: &quot;3ele0ss56t&quot;
	},
	&quot;success&quot;: true,
	&quot;errors&quot;: [],
	&quot;messages&quot;: []
}
</code></pre>
<p>Note the <code>subdomain</code> value returned by the API. You will use this to create the Access application.</p>
<ol start="3">
<li>Use <a href="/api/resources/zero_trust/subresources/access/subresources/applications/methods/create/">Add An Access Application</a> to associate the proxy endpoint with Access policies:</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/access/apps \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;domain&quot;: &quot;&lt;SUBDOMAIN&gt;.proxy.cloudflare-gateway.com&quot;,
&quot;name&quot;: &quot;Proxy Endpoint App&quot;,
&quot;session_duration&quot;: &quot;12h&quot;,
&quot;type&quot;: &quot;proxy_endpoint&quot;,
&quot;policies&quot;: [
  {
    &quot;id&quot;: &quot;&lt;ACCESS_POLICY_ID&gt;&quot;
  }
]
}&#x27;</code></pre>
<p>Replace <code>&lt;SUBDOMAIN&gt;</code> with the subdomain from step 2 and <code>&lt;ACCESS_POLICY_ID&gt;</code> with the ID of an existing <a href="/cloudflare-one/access-controls/policies/">Access policy</a>.</p>
</div></details>
<details class="nb-details" open><summary>Source IP endpoint</summary><div class="nb-details-body">
<p>To create a source IP endpoint:</p>
<ol>
<li>Use <a href="/api/resources/zero_trust/subresources/gateway/subresources/proxy_endpoints/methods/create/">Create A Proxy Endpoint</a> with the following call:</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/proxy_endpoints \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;any_name&quot;,
&quot;ips&quot;: [
  &quot;&lt;PUBLIC_IP&gt;&quot;,
  &quot;&lt;PUBLIC_IP2&gt;&quot;,
  &quot;&lt;PUBLIC_IP3&gt;&quot;
]
}&#x27;</code></pre>
<p>Replace <code>&lt;PUBLIC_IP&gt;</code> with the source IP address of your device in CIDR notation. For example:</p>
<ul>
<li><strong>IPv4</strong>: <code>192.0.2.0/8</code></li>
<li><strong>IPv6</strong>: <code>2001:0db8:0000:0000:0000:1234:5678:0000/32</code></li>
</ul>
<aside class="nb-aside note">
<p>Gateway limits the prefix length of source networks for proxy endpoints to <code>/8</code> for IPv4 networks and <code>/32</code> for IPv6 networks.</p>
</aside>
<ol start="2">
<li>The response returns output similar to the following:</li>
</ol>
<pre><code class="language-json">{
	&quot;result&quot;: {
		&quot;id&quot;: &quot;d969d7bf-ec28-4291-9af0-86825f472c21&quot;,
		&quot;name&quot;: &quot;test&quot;,
		&quot;created_at&quot;: &quot;2022-03-02T10:57:18.094789Z&quot;,
		&quot;updated_at&quot;: &quot;2022-03-02T10:57:18.094789Z&quot;,
		&quot;ips&quot;: [&quot;90.90.241.229/8&quot;],
		&quot;subdomain&quot;: &quot;3ele0ss56t&quot;
	},
	&quot;success&quot;: true,
	&quot;errors&quot;: [],
	&quot;messages&quot;: []
}
</code></pre>
<p>Note the <code>subdomain</code> value returned by the API. Your Cloudflare proxy server domain is of the form:</p>
<pre><code class="language-txt">&lt;SUBDOMAIN&gt;.proxy.cloudflare-gateway.com
</code></pre>
<p>In the example above, the subdomain is <code>3ele0ss56t</code> and the proxy server domain is <code>3ele0ss56t.proxy.cloudflare-gateway.com</code>.</p>
</div></details>
