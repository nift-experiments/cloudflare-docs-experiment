

For more information, refer to [Change proxy settings on Mac](https://support.apple.com/guide/mac-help/mchlp2591/mac).

1. Open the Apple menu and select **System Settings**.
2. Select **Network** in the sidebar.
3. Select your active network service (for example, **Wi-Fi**), then select **Details**.
4. Select **Proxies**.
5. Turn on **Automatic proxy configuration**.
6. In the **URL** field, enter your PAC file URL.

The setting saves automatically. Chromium-based browsers will now route traffic through your proxy endpoint.

<aside class="nb-aside note">


<p>Safari does not support the HTTPS proxy type required by Cloudflare proxy endpoints. Use a Chromium-based browser (Chrome, Edge, Brave) or <a href="/cloudflare-one/networks/resolvers-and-proxies/proxy-endpoints/configure-pac-file-on-device/#configure-firefox-separately">Firefox</a> on macOS instead.</p>


</aside>
