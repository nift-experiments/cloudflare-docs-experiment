

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Windows">

<p>For more information, refer to <a href="https://support.microsoft.com/windows/use-a-proxy-server-in-windows-03096c53-0554-4ffe-b6ab-8b1deee8dae1">Use a proxy server in Windows</a>.</p>
<ol>
<li>Open the <strong>Settings</strong> app and select <strong>Network &amp; internet</strong> &gt; <strong>Proxy</strong>.</li>
<li>Next to <strong>Use setup script</strong>, select <strong>Set up</strong>.</li>
<li>In the <strong>Edit setup script</strong> dialog, turn on <strong>Use setup script</strong>.</li>
<li>In the <strong>Script address</strong> field, enter your PAC file URL.</li>
<li>Select <strong>Save</strong>.</li>
</ol>
<aside class="nb-aside note">
<p>On Windows 10, the <strong>Use setup script</strong> toggle and script address field are on the same page under <strong>Automatic proxy setup</strong>. On Windows 11, you must select <strong>Set up</strong> to open the <strong>Edit setup script</strong> dialog.</p>
</aside>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="macOS">

<p>For more information, refer to <a href="https://support.apple.com/guide/mac-help/mchlp2591/mac">Change proxy settings on Mac</a>.</p>
<ol>
<li>Open the Apple menu and select <strong>System Settings</strong>.</li>
<li>Select <strong>Network</strong> in the sidebar.</li>
<li>Select your active network service (for example, <strong>Wi-Fi</strong>), then select <strong>Details</strong>.</li>
<li>Select <strong>Proxies</strong>.</li>
<li>Turn on <strong>Automatic proxy configuration</strong>.</li>
<li>In the <strong>URL</strong> field, enter your PAC file URL.</li>
</ol>
<p>The setting saves automatically. Chromium-based browsers will now route traffic through your proxy endpoint.</p>
<aside class="nb-aside note">
<p>Safari does not support the HTTPS proxy type required by Cloudflare proxy endpoints. Use a Chromium-based browser (Chrome, Edge, Brave) or <a href="/cloudflare-one/networks/resolvers-and-proxies/proxy-endpoints/configure-pac-file-on-device/#configure-firefox-separately">Firefox</a> on macOS instead.</p>
</aside>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Linux">

<p>Steps vary depending on your desktop environment.</p>
<details class="nb-details"><summary>GNOME (Ubuntu, Fedora)</summary><div class="nb-details-body">
<ol>
<li>Open <strong>Settings</strong> &gt; <strong>Network</strong>.</li>
<li>Select the gear icon next to your active connection.</li>
<li>Select the <strong>Proxy</strong> tab.</li>
<li>Set the method to <strong>Automatic</strong>.</li>
<li>In the <strong>Configuration URL</strong> field, enter your PAC file URL.</li>
</ol>
</div></details>
<details class="nb-details"><summary>KDE Plasma</summary><div class="nb-details-body">
<ol>
<li>Open <strong>System Settings</strong> &gt; <strong>Network Settings</strong> &gt; <strong>Proxy</strong>.</li>
<li>Select <strong>Use proxy auto configuration URL</strong>.</li>
<li>In the URL field, enter your PAC file URL.</li>
<li>Select <strong>Apply</strong>.</li>
</ol>
</div></details>
<aside class="nb-aside note">
<p>Most Linux command-line tools (such as <code>curl</code> and <code>wget</code>) do not natively support PAC files. The system proxy settings apply to GUI browsers only. For command-line tools, configure the <code>http_proxy</code> and <code>https_proxy</code> environment variables with your proxy endpoint address directly.</p>
</aside>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="iOS / iPadOS">

<aside class="nb-aside caution">
<p>iOS and iPadOS do not support the HTTPS proxy settings which are used by Gateway proxy endpoints. iOS and iPadOS are not supported at this time. Cloudflare recommends installing the <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/">Cloudflare One Client</a> where possible.</p>
</aside>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Android">

<p>Android does not have a global proxy setting. You must configure the proxy for each Wi-Fi network. Steps vary by device manufacturer and Android version.</p>
<p>On stock Android (Pixel) and most Android devices:</p>
<ol>
<li>Open <strong>Settings</strong> &gt; <strong>Network &amp; internet</strong> &gt; <strong>Internet</strong> (or <strong>Wi-Fi</strong>).</li>
<li>Tap the gear icon next to your connected network.</li>
<li>Select <strong>Advanced options</strong> (or tap the edit icon).</li>
<li>Under <strong>Proxy</strong>, select <strong>Proxy Auto-Config</strong>.</li>
<li>In the <strong>PAC URL</strong> field, enter your PAC file URL.</li>
<li>Tap <strong>Save</strong>.</li>
</ol>
<p>For more information, refer to <a href="https://support.google.com/android/answer/9654714">Manage advanced network settings on your Android phone</a>.</p>
<aside class="nb-aside note">
<p>The exact menu names and paths differ across manufacturers (Samsung, OnePlus, Xiaomi) and Android versions. If you cannot find the proxy settings, search for &quot;proxy&quot; in your device Settings.</p>
</aside>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="ChromeOS">

<p>ChromeOS uses system-level proxy settings that apply to the Chrome browser.</p>
<ol>
<li>Select the time in the status area, then select <strong>Settings</strong>.</li>
<li>Select <strong>Network</strong>, then select <strong>Wi-Fi</strong> (or <strong>Ethernet</strong>).</li>
<li>Select your active connection.</li>
<li>Expand the <strong>Proxy</strong> section.</li>
<li>Select <strong>Automatic proxy configuration</strong>.</li>
<li>Enter your PAC file URL.</li>
<li>Close the settings window. The configuration saves automatically.</li>
</ol>
<p>For managed ChromeOS devices, refer to <a href="#deploy-pac-files-at-scale">Deploy PAC files at scale</a> for Google Admin console instructions.</p>

</section>
