<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Reusable components</strong> &gt; <strong>Custom pages</strong>.</li>
<li>Under <strong>Account Gateway block page</strong>, select <strong>Customize</strong>.</li>
<li>Choose <strong>Custom Gateway block page</strong>. Gateway will display a preview of your custom block page. Available customizations include:</li>
</ol>
<ul>
<li>Your organization's name</li>
<li><a href="/cloudflare-one/reusable-components/custom-pages/gateway-block-page/#add-a-logo-image">Logo</a></li>
<li>Header text</li>
<li>Global block message, which will be displayed above the policy-specific block message</li>
<li><a href="/cloudflare-one/reusable-components/custom-pages/gateway-block-page/#allow-users-to-email-an-administrator">Mailto link</a></li>
<li>Background color</li>
</ul>
<ol start="4">
<li>Select <strong>Save</strong>.</li>
</ol>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Terraform (v5)">

<ol>
<li>Add the following permission to your <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/api_token"><code>cloudflare_api_token</code></a>:</li>
</ol>
<ul>
<li><code>Zero Trust Write</code></li>
</ul>
<ol start="2">
<li>In <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_gateway_settings"><code>cloudflare_zero_trust_gateway_settings</code></a>, configure the <code>block_page</code> argument with your customizations:</li>
</ol>
<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_gateway_settings&quot; &quot;team_name&quot; {
	account_id = var.cloudflare_account_id
	settings = {
		block_page = {
			enabled = true //do not use the default Gateway block page
			mode = &quot;customized_block_page&quot; //use a custom block page
			name = &quot;Cloudflare&quot;
			logo_path = &quot;https://logos.com/a.png&quot;
			header_text = &quot;--header--&quot;
			footer_text = &quot;--footer--&quot;
			mailto_address = &quot;admin@example.com&quot;
			mailto_subject = &quot;Blocked Request&quot;
			background_color = &quot;#ffffff&quot;
			suppress_footer = false
		}
	}
}
</code></pre>
