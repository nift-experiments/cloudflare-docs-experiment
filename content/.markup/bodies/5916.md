
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Windows">

<p>To check that Windows devices have required security patches and features installed, include an Update Build Revision (UBR) number in the OS version check.</p>
<ul>
<li><strong>Update Build Revision</strong>: Enter the Windows UBR you want devices to match (for example, <code>3803</code>). The UBR is the fourth part of the full Windows version number (for example, in <code>10.0.19045.3803</code>, the UBR is <code>3803</code>).</li>
</ul>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="macOS">

<ul>
<li><strong>Rapid Security Response Version</strong>: Enter the macOS <a href="https://support.apple.com/guide/deployment/rapid-security-responses-dep93ff7ea78/web">Rapid Security Response (RSR)</a> version you want devices to match (for example, <code>(a)</code>). Be sure to include the parenthesis around the letter.</li>
</ul>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Linux">

<ul>
<li>
<p><strong>Distro name</strong> and <strong>Distro revision</strong>: Enter the Linux distribution you want devices to match (for example, <code>ubuntu 22.04</code>). The distro version always matches with an equal-to operator (==) regardless of the <strong>Operator</strong> setting.</p>
</li>
<li>
<p><strong>Patch Version</strong>: Enter the <a href="#linux">patch version</a> of the kernel. For example, if the kernel is <code>6.50.0-1007-oem</code>, enter <code>1007</code>.</p>
</li>
</ul>

</section>

Be sure to include the parenthesis around the letter.</li>
