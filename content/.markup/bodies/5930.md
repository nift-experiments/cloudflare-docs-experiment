

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Windows">

<ol>
<li>Open a PowerShell window.</li>
<li>To search the local machine trust store for a certificate with a specific common name, run the following command:</li>
</ol>
<pre><code class="language-powershell">Get-ChildItem Cert:\LocalMachine\My\ | where{$_.Subject -like &quot;*&lt;COMMON_NAME&gt;*&quot;}
</code></pre>
<ol start="3">
<li>To search the user trust store for a certificate with a specific common name, run the following command:</li>
</ol>
<pre><code class="language-powershell">Get-ChildItem Cert:\CurrentUser\My\ | where{$_.Subject -like &quot;*&lt;COMMON_NAME&gt;*&quot;}
</code></pre>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="macOS">

<ol>
<li>Open Terminal.</li>
<li>To search System Keychain for a certificate with a specific common name, run the following command:</li>
</ol>
<pre><code class="language-sh">/usr/bin/security find-certificate -c &quot;&lt;COMMON_NAME&gt;&quot; -p /Library/Keychains/System.keychain
</code></pre>

</section>
