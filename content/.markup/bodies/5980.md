
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Keychain Access">

<ol>
<li>
<p>Download a Cloudflare certificate.</p>
</li>
<li>
<p>Open the <code>.crt</code> file in Keychain Access. If prompted, enter your local password.</p>
</li>
<li>
<p>In <strong>Keychain</strong>, choose the access option that suits your needs and select <strong>Add</strong>.</p>
</li>
<li>
<p>In the list of certificates, locate the newly installed certificate. Keychain Access will mark this certificate as not trusted. Right-click the certificate and select <strong>Get Info</strong>.</p>
</li>
<li>
<p>Select <strong>Trust</strong>. Under <strong>When using this certificate</strong>, select <em>Always Trust</em>.</p>
</li>
</ol>
<p>The root certificate is now installed and ready to be used.</p>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Terminal">

<ol>
<li>Download a Cloudflare certificate.</li>
<li>Open Terminal.</li>
<li>Add the certificate to your keychain:</li>
</ol>
<pre><code class="language-sh">sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain &lt;path-to-certificate.crt&gt;
</code></pre>
<p>This keychain will allow all users on the system access to the certificate. If you want to install the certificate to a different keychain, replace <code>System.keychain</code> with the name of that keychain.</p>
<ol start="4">
<li>Update the OpenSSL CA Store to include the Cloudflare certificate:</li>
</ol>
<pre><code class="language-sh">echo | sudo tee -a /etc/ssl/cert.pem &lt; certificate.pem
</code></pre>
<p>The root certificate is now installed and ready to be used.</p>

</section>
