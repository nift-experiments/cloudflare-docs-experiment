
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Windows">

<p>The command to install the certificate with Python on Windows automatically includes <code>pip</code> and <code>certifi</code> (the default certificate bundle for certificate validation).</p>
<ol>
<li><a href="#download-a-cloudflare-root-certificate">Download a Cloudflare certificate</a> in <code>.crt</code> format.</li>
<li>In a PowerShell terminal, install the <code>certifi</code> package:</li>
</ol>
<pre><code class="language-powershell">python -m pip install certifi
</code></pre>
<ol start="3">
<li>Identify the Python CA store:</li>
</ol>
<pre><code class="language-powershell">$CERT_PATH = python -c &quot;import certifi; print(certifi.where())&quot;
</code></pre>
<ol start="4">
<li>Update the bundle to include the Cloudflare certificate:</li>
</ol>
<pre><code class="language-powershell">gc &quot;$env:USERPROFILE\Downloads\certificate.crt&quot; | ac $CERT_PATH
</code></pre>
<ol start="5">
<li>(Optional) Configure your system variables to point to the CA store by adding them to PowerShell's configuration file:</li>
</ol>
<pre><code class="language-powershell">[System.Environment]::SetEnvironmentVariable(&#x27;CERT_PATH&#x27;, $CERT_PATH, &#x27;Machine&#x27;)
[System.Environment]::SetEnvironmentVariable(&#x27;SSL_CERT_FILE&#x27;, $CERT_PATH, &#x27;Machine&#x27;)
[System.Environment]::SetEnvironmentVariable(&#x27;REQUESTS_CA_BUNDLE&#x27;, $CERT_PATH, &#x27;Machine&#x27;)
</code></pre>
<ol start="6">
<li>Restart your terminal.</li>
</ol>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="macOS and Linux">

<ol>
<li><a href="#download-a-cloudflare-root-certificate">Download a Cloudflare certificate</a> in <code>.pem</code> format.</li>
<li>In a terminal, install the <code>certifi</code> package:</li>
</ol>
<pre><code class="language-sh">python -m pip install certifi
</code></pre>
<ol start="3">
<li>Append the Cloudflare certificate to this CA store by running:</li>
</ol>
<pre><code class="language-sh">echo | cat - certificate.pem &gt;&gt; $(python -m certifi)
</code></pre>
<ol start="4">
<li>(Optional) Configure your system variables to point to the CA store by adding them to your shell's configuration file (such as <code>~/.zshrc</code> or <code>~/.bash_profile</code>). For example:</li>
</ol>
<pre><code class="language-sh">echo &#x27;export CERT_PATH=$(python -c &quot;import certifi; print(certifi.where())&quot;)
export SSL_CERT_FILE=${CERT_PATH}
export REQUESTS_CA_BUNDLE=${CERT_PATH}&#x27; &gt;&gt; ~/.zshrc
</code></pre>
<ol start="5">
<li>Restart your terminal.</li>
</ol>
