

1. Install [OpenSSL for Windows](https://slproweb.com/products/Win32OpenSSL.html).

2. In an administrator PowerShell terminal, format the Cloudflare certificate for Java.

<pre><code class="language-powershell">openssl x509 -in Cloudflare_CA.pem -inform pem -out Cloudflare_CA.der -outform der
</code></pre>


3. Import the converted certificate into the Java keystore.

<pre><code class="language-powershell">&quot;%JAVA_HOME%\bin\keytool&quot; -import -trustcacerts -alias &quot;Cloudflare Root CA&quot; -file Cloudflare_CA.der -keystore &quot;%JAVA_HOME%\jre\lib\security\cacerts&quot; -storepass changeit -noprompt
</code></pre>


4. Restart any instances of Java.
