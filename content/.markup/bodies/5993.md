
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="macOS and Linux">

<ol>
<li>
<p>Install <a href="https://www.openssl.org/">OpenSSL</a>.</p>
</li>
<li>
<p>In a terminal, format the Cloudflare certificate for Java.</p>
</li>
</ol>
<pre><code class="language-sh">openssl x509 -in Cloudflare_CA.pem -inform pem -out Cloudflare_CA.der -outform der
</code></pre>
<ol start="3">
<li>Import the converted certificate into the Java keystore.</li>
</ol>
<pre><code class="language-sh">sudo $JAVA_HOME/bin/keytool -import -trustcacerts -alias &#x27;Cloudflare Root CA&#x27; -file Cloudflare_CA.der -keystore $JAVA_HOME/jre/lib/security/cacerts -storepass changeit -noprompt 2&gt;&amp;1
</code></pre>
<ol start="4">
<li>Restart any instances of Java.</li>
</ol>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Windows">

</ol>
<pre><code class="language-powershell">&quot;%JAVA_HOME%\bin\keytool&quot; -import -trustcacerts -alias &quot;Cloudflare Root CA&quot; -file Cloudflare_CA.der -keystore &quot;%JAVA_HOME%\jre\lib\security\cacerts&quot; -storepass changeit -noprompt
</code></pre>
<ol start="4">

</ol>
