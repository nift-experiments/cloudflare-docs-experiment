

1. Install [OpenSSL](https://www.openssl.org/).

2. In a terminal, format the Cloudflare certificate for Ruby.

<pre><code class="language-sh">openssl x509 -in ~/Downloads/certificate.pem -out ~/Downloads/ruby-root-ca.crt
</code></pre>


3. Create a RubyGems certificate directory in your home folder.

<pre><code class="language-sh">mkdir -p ~/.gem/ssl
</code></pre>


4. Copy the Cloudflare certificate to your RubyGems certificate store.

<pre><code class="language-sh">cp ~/Downloads/ruby-root-ca.crt ~/.gem/ssl/rubygems.org.pem
</code></pre>


5. Configure RubyGems to use the certificate.

<pre><code class="language-sh">gem sources --add-trusted-cert ~/.gem/ssl/rubygems.org.pem
</code></pre>


Alternatively, add the following line to your RubyGems configuration file located in `~/.gemrc` file to globally trust the certificate:

<pre><code class="language-yaml">:ssl_cert: ~/.gem/ssl/rubygems.org.pem
</code></pre>


6. Restart any terminal sessions.
