

1. Install [OpenSSL for Windows](https://slproweb.com/products/Win32OpenSSL.html).

2. In a PowerShell terminal, format the Cloudflare certificate for Ruby.

<pre><code class="language-powershell">openssl x509 -in %UserProfile%\Downloads\certificate.pem -out %UserProfile%\Downloads\ruby-root-ca.crt
</code></pre>


3. Create a RubyGems certificate directory in your home folder.

<pre><code class="language-powershell">mkdir -Force &quot;$env:USERPROFILE\.gem\ssl&quot;
</code></pre>


4. Copy the Cloudflare certificate to your RubyGems certificate store.

<pre><code class="language-powershell">Copy-Item &quot;$env:USERPROFILE\Downloads\ruby-root-ca.crt&quot; &quot;$env:USERPROFILE\.gem\ssl\rubygems.org.pem&quot;
</code></pre>


5. Configure RubyGems to use the certificate.

<pre><code class="language-powershell">gem sources --add-trusted-cert &quot;$env:USERPROFILE\.gem\ssl\rubygems.org.pem&quot;
</code></pre>


Alternatively, add the following line to your RubyGems configuration file located in `$HOME\.gemrc` to globally trust the certificate:

<pre><code class="language-yaml">:ssl_cert: C:/Users/&lt;username&gt;/.gem/ssl/rubygems.org.pem
</code></pre>


6. Restart any terminal sessions.
