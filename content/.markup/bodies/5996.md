
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="macOS and Linux">

<ol>
<li>
<p>Install <a href="https://www.openssl.org/">OpenSSL</a>.</p>
</li>
<li>
<p>In a terminal, format the Cloudflare certificate for Ruby.</p>
</li>
</ol>
<pre><code class="language-sh">openssl x509 -in ~/Downloads/certificate.pem -out ~/Downloads/ruby-root-ca.crt
</code></pre>
<ol start="3">
<li>Create a RubyGems certificate directory in your home folder.</li>
</ol>
<pre><code class="language-sh">mkdir -p ~/.gem/ssl
</code></pre>
<ol start="4">
<li>Copy the Cloudflare certificate to your RubyGems certificate store.</li>
</ol>
<pre><code class="language-sh">cp ~/Downloads/ruby-root-ca.crt ~/.gem/ssl/rubygems.org.pem
</code></pre>
<ol start="5">
<li>Configure RubyGems to use the certificate.</li>
</ol>
<pre><code class="language-sh">gem sources --add-trusted-cert ~/.gem/ssl/rubygems.org.pem
</code></pre>
<p>Alternatively, add the following line to your RubyGems configuration file located in <code>~/.gemrc</code> file to globally trust the certificate:</p>
<pre><code class="language-yaml">:ssl_cert: ~/.gem/ssl/rubygems.org.pem
</code></pre>
<ol start="6">
<li>Restart any terminal sessions.</li>
</ol>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Windows">

<ol>
<li>
<p>Install <a href="https://slproweb.com/products/Win32OpenSSL.html">OpenSSL for Windows</a>.</p>
</li>
<li>
<p>In a PowerShell terminal, format the Cloudflare certificate for Ruby.</p>
</li>
</ol>
<pre><code class="language-powershell">openssl x509 -in %UserProfile%\Downloads\certificate.pem -out %UserProfile%\Downloads\ruby-root-ca.crt
</code></pre>
<ol start="3">
<li>Create a RubyGems certificate directory in your home folder.</li>
</ol>
<pre><code class="language-powershell">mkdir -Force &quot;$env:USERPROFILE\.gem\ssl&quot;
</code></pre>
<ol start="4">
<li>Copy the Cloudflare certificate to your RubyGems certificate store.</li>
</ol>
<pre><code class="language-powershell">Copy-Item &quot;$env:USERPROFILE\Downloads\ruby-root-ca.crt&quot; &quot;$env:USERPROFILE\.gem\ssl\rubygems.org.pem&quot;
</code></pre>
<ol start="5">
<li>Configure RubyGems to use the certificate.</li>
</ol>
<pre><code class="language-powershell">gem sources --add-trusted-cert &quot;$env:USERPROFILE\.gem\ssl\rubygems.org.pem&quot;
</code></pre>
<p>Alternatively, add the following line to your RubyGems configuration file located in <code>$HOME\.gemrc</code> to globally trust the certificate:</p>
<pre><code class="language-yaml">:ssl_cert: C:/Users/&lt;username&gt;/.gem/ssl/rubygems.org.pem
</code></pre>
<ol start="6">
<li>Restart any terminal sessions.</li>
</ol>

</section>
