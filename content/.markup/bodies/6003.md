

To add the certificate to your Dockerfile to install it during the build process:
1. Add the certificate install directions to your Dockerfile. For example:

<pre><code class="language-docker">FROM registry.access.redhat.com/ubi9/ubi:latest
&#35; Or FROM centos:7 or FROM fedora:38

&#35; Install necessary certificates package
RUN dnf install -y ca-certificates

&#35; Copy and add Cloudflare root certificate
COPY certs/certificate.pem /etc/pki/ca-trust/source/anchors/certificate.crt
RUN update-ca-trust extract
</code></pre>


<pre><code class="language-docker">FROM debian:12
&#35; Or FROM ubuntu:22.04

&#35; Install necessary certificates package
RUN apt-get update &amp;&amp; apt-get install -y ca-certificates

&#35; Copy and add Cloudflare root certificate
COPY certs/certificate.pem /usr/local/share/ca-certificates/certificate.crt
RUN update-ca-certificates
</code></pre>


<pre><code class="language-docker">FROM alpine:3.18

&#35; Install necessary certificates package
RUN apk add --no-cache ca-certificates

&#35; Copy and add Cloudflare root certificate
COPY certs/certificate.pem /usr/local/share/ca-certificates/certificate.crt
RUN update-ca-certificates
</code></pre>


2. Build the Docker image:

<pre><code class="language-sh">docker build -t &lt;your-container-name&gt; .
</code></pre>


3. Verify the certificate was installed:

<pre><code class="language-sh">docker run --rm your-image-name sh -c &quot;cat /etc/pki/ca-trust/extracted/pem/tls-ca-bundle.pem | grep Cloudflare&quot;
</code></pre>


<pre><code class="language-sh">docker run --rm your-image-name sh -c &quot;cat /etc/ssl/certs/certificate.pem&quot;
</code></pre>
