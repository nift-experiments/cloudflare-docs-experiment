<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="During build process">

<p>To add the certificate to your Dockerfile to install it during the build process:</p>
<ol>
<li>Add the certificate install directions to your Dockerfile. For example:</li>
</ol>
<pre><code class="language-docker">FROM registry.access.redhat.com/ubi9/ubi:latest
&#35; Or FROM centos:7 or FROM fedora:38

&#35; Install necessary certificates package
RUN dnf install -y ca-certificates

&#35; Copy and add Cloudflare root certificate
COPY certs/certificate.pem /etc/pki/ca-trust/source/anchors/certificate.crt
RUN update-ca-trust extract
</code></pre>
<pre><code class="language-docker">FROM debian:12
&#35; Or FROM ubuntu:22.04

&#35; Install necessary certificates package
RUN apt-get update &amp;&amp; apt-get install -y ca-certificates

&#35; Copy and add Cloudflare root certificate
COPY certs/certificate.pem /usr/local/share/ca-certificates/certificate.crt
RUN update-ca-certificates
</code></pre>
<pre><code class="language-docker">FROM alpine:3.18

&#35; Install necessary certificates package
RUN apk add --no-cache ca-certificates

&#35; Copy and add Cloudflare root certificate
COPY certs/certificate.pem /usr/local/share/ca-certificates/certificate.crt
RUN update-ca-certificates
</code></pre>
<ol start="2">
<li>Build the Docker image:</li>
</ol>
<pre><code class="language-sh">docker build -t &lt;your-container-name&gt; .
</code></pre>
<ol start="3">
<li>Verify the certificate was installed:</li>
</ol>
<pre><code class="language-sh">docker run --rm your-image-name sh -c &quot;cat /etc/pki/ca-trust/extracted/pem/tls-ca-bundle.pem | grep Cloudflare&quot;
</code></pre>
<pre><code class="language-sh">docker run --rm your-image-name sh -c &quot;cat /etc/ssl/certs/certificate.pem&quot;
</code></pre>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="During runtime">

<p>To add the certificate to your Docker Compose file to install it during runtime:</p>
<ol>
<li>Add the certificate install directions to your <code>docker-compose.yml</code> file. For example:</li>
</ol>
<pre><code class="language-yaml">version: &#x27;3&#x27;
services:
	redhat-app:
		image: registry.access.redhat.com/ubi9/ubi:latest
 		volumes:
 			&#45; certs/certificate.pem:/etc/pki/ca-trust/source/anchors/certificate.pem
 		entrypoint: /bin/sh -c &quot;dnf install -y ca-certificates &amp;&amp; update-ca-trust extract &amp;&amp; app start&quot;
</code></pre>
<pre><code class="language-yaml">version: &#x27;3&#x27;
services:
	debian-app:
		image: debian:12
 		volumes:
 			&#45; certs/certificate.pem:/usr/local/share/ca-certificates/certificate.crt
 		entrypoint: /bin/sh -c &quot;apt-get update &amp;&amp; apt-get install -y ca-certificates &amp;&amp; update-ca-certificates &amp;&amp; app start&quot;
</code></pre>
<pre><code class="language-yaml">version: &#x27;3&#x27;
services:
	alpine-app:
		image: alpine:3.18
 		volumes:
 			&#45; certs/certificate.pem:/usr/local/share/ca-certificates/certificate.pem
 		entrypoint: /bin/sh -c &quot;apk add --no-cache ca-certificates &amp;&amp; update-ca-certificates &amp;&amp; app start&quot;
</code></pre>
<ol start="2">
<li>Run the container:</li>
</ol>
<pre><code class="language-sh">docker-compose up
</code></pre>
<ol start="3">
<li>Verify the certificate was installed:</li>
</ol>
<pre><code class="language-sh">docker exec -it &lt;container-name&gt; sh -c &quot;cat /etc/pki/ca-trust/extracted/pem/tls-ca-bundle.pem | grep Cloudflare&quot;
</code></pre>
<pre><code class="language-sh">docker exec -it &lt;container-name&gt; sh -c &quot;cat /etc/ssl/certs/ca-certificates.crt | grep Cloudflare&quot;
</code></pre>

</section>
