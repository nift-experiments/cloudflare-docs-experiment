
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="macOS">

<p>To use a Cloudflare root certificate with cURL on macOS, <a href="#macos">install the certificate to the operating system keychain</a>. cURL will use the macOS root certificate by default.</p>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Windows">

<p>To use a Cloudflare certificate with the version of cURL preinstalled on Windows or another version that uses the Schannel (WinSSL) backend, <a href="#windows">install the certificate to the Windows certificate store</a>. If you use an older or custom version of cURL built with the OpenSSL backend, you will need to <a href="#curl">manually configure cURL to use the certificate</a>.</p>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Linux">

<p>To use a Cloudflare root certificate with cURL on Linux, <a href="#linux">install the certificate to your distribution's certificate store</a>. cURL will use the Linux root certificate by default.</p>

</section>
