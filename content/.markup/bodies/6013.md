<p>To use a Cloudflare root certificate with Wget on macOS, <a href="#macos">install the certificate to the operating system keychain</a>. Wget will use the macOS root certificate by default.</p>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Windows">

<p>To use a Cloudflare certificate with Wget on Windows, <a href="#windows">install the certificate to the Windows certificate store</a>. Wget will use the Windows root certificate by default.</p>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Linux">

<p>To use a Cloudflare root certificate with Wget on Linux, <a href="#linux">install the certificate to your distribution's certificate store</a>. Wget will use the Linux root certificate by default.</p>
<p>Alternatively, you can specify a certificate file directly:</p>
<pre><code class="language-sh">wget --ca-certificate=[PATH_TO_CLOUDFLARE_CERT.pem] https://example.com
</code></pre>
<p>To make this permanent, add the following to your <code>~/.wgetrc</code> file:</p>
<pre><code class="language-sh">ca_certificate = [PATH_TO_CLOUDFLARE_CERT.pem]
</code></pre>

</section>
