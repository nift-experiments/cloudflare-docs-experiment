

1. In a terminal, add the JRE path you copied as an environment variable.

<pre><code class="language-sh">export JAVA_HOME=&quot;/path/to/jre&quot;
</code></pre>


2. Run `keytool` to install and trust the Cloudflare certificate.

<pre><code class="language-sh">&quot;$JAVA_HOME/bin/keytool&quot; -import -file ~/Downloads/certificate.crt -alias CloudflareRootCA -keystore &quot;$JAVA_HOME/lib/security/cacerts&quot; -storepass changeit -trustcacerts -noprompt
</code></pre>


3. Restart Android Studio.
