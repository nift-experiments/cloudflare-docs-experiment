
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="macOS and Linux">

<ol>
<li>In a terminal, add the JRE path you copied as an environment variable.</li>
</ol>
<pre><code class="language-sh">export JAVA_HOME=&quot;/path/to/jre&quot;
</code></pre>
<ol start="2">
<li>Run <code>keytool</code> to install and trust the Cloudflare certificate.</li>
</ol>
<pre><code class="language-sh">&quot;$JAVA_HOME/bin/keytool&quot; -import -file ~/Downloads/certificate.crt -alias CloudflareRootCA -keystore &quot;$JAVA_HOME/lib/security/cacerts&quot; -storepass changeit -trustcacerts -noprompt
</code></pre>
<ol start="3">
<li>Restart Android Studio.</li>
</ol>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Windows">

<ol>
<li>In an administrator PowerShell terminal, add the JRE path you copied as an environment variable.</li>
</ol>
<pre><code class="language-powershell">$env:JAVA_HOME = &quot;C:\Program Files\Android\Android Studio\jbr&quot;
</code></pre>
<ol start="2">
<li>Run <code>keytool</code> to install and trust the Cloudflare certificate.</li>
</ol>
<pre><code class="language-powershell">&amp; &quot;$env:JAVA_HOME\bin\keytool.exe&quot; -import -file &quot;$env:USERPROFILE\Downloads\certificate.crt&quot; -alias CloudflareRootCA -keystore &quot;$env:JAVA_HOME\lib\security\cacerts&quot; -storepass changeit -trustcacerts -noprompt
</code></pre>
<ol start="3">
<li>Restart Android Studio.</li>
</ol>

</section>
