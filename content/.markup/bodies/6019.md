
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="macOS and Linux">

<ol>
<li>In a terminal, add the <code>java.home</code> value you copied as an environment variable.</li>
</ol>
<pre><code class="language-sh">export JAVA_HOME=$(echo /path/to/java.home)
</code></pre>
<ol start="2">
<li>Run <code>keytool</code> to install and trust the Cloudflare certificate.</li>
</ol>
<pre><code class="language-sh">&quot;$JAVA_HOME/bin/keytool&quot; -import -file ~/Downloads/certificate.crt -alias CloudflareRootCA -keystore &quot;$JAVA_HOME/lib/security/cacerts&quot; -storepass changeit -trustcacerts -noprompt
</code></pre>
<ol start="3">
<li>Restart Eclipse.</li>
</ol>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Windows">

<ol>
<li>In a terminal, add the <code>java.home</code> value you copied as an environment variable.</li>
</ol>
<pre><code class="language-powershell">set JAVA_HOME=&quot;\path\to\java.home&quot;
</code></pre>
<ol start="2">
<li>Run <code>keytool</code> to install and trust the Cloudflare certificate.</li>
</ol>
<pre><code class="language-powershell">&quot;%JAVA_HOME%\bin\keytool.exe&quot; -import -file &quot;%UserProfile%\Downloads\Cloudflare_CA.crt&quot; -alias CloudflareRootCA -keystore &quot;%JAVA_HOME%\lib\security\cacerts&quot; -storepass changeit -trustcacerts -noprompt
</code></pre>
<ol start="3">
<li>Restart Eclipse.</li>
</ol>

</section>
