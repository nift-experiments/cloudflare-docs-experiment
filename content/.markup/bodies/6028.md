
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="macOS">

<ol>
<li>In a terminal, copy the contents of the Google Drive certificate file to a new certificate file in a permanent location, such as your Documents folder. For example:</li>
</ol>
<pre><code class="language-sh">cat /Applications/&quot;Google Drive.app&quot;/Contents/Resources/roots.pem &gt; ~/Documents/gdrivecerts.pem
</code></pre>
<ol start="2">
<li>Append the contents of the downloaded certificate to the end of the new file. For example:</li>
</ol>
<pre><code class="language-sh">cat ~/Downloads/certificate.pem &gt;&gt; ~/Documents/gdrivecerts.pem
</code></pre>
<ol start="3">
<li>Apply the newly created root certificate to your Google Drive application. For example:</li>
</ol>
<pre><code class="language-sh">sudo defaults write /Library/Preferences/com.google.drivefs.settings TrustedRootCertsFile &quot;/Users/$(whoami)/Documents/gdrivecerts.pem&quot;
</code></pre>
<p>You can verify the update with the following command.</p>
<pre><code class="language-sh">defaults read /Library/Preferences/com.google.drivefs.settings
</code></pre>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Windows">

<ol>
<li>In an administrator PowerShell terminal, copy the contents of the Google Drive certificate file to a new certificate file in a permanent location, such as your Documents folder. For example:</li>
</ol>
<pre><code class="language-powershell">Get-Content &quot;C:\Program Files\Google\Drive File Stream\roots.pem&quot; | Set-Content &quot;$HOME\Documents\gdrivecerts.pem&quot;
</code></pre>
<ol start="2">
<li>Append the contents of the downloaded certificate to the end of the new file. For example:</li>
</ol>
<pre><code class="language-powershell">Get-Content &quot;$HOME\Downloads\certificate.pem&quot; | Add-Content &quot;$HOME\Documents\gdrivecerts.pem&quot;
</code></pre>
<ol start="3">
<li>Apply the newly created root certificate to your Google Drive application. For example:</li>
</ol>
<pre><code class="language-powershell">Set-ItemProperty -Path &quot;HKLM:\SOFTWARE\Google\DriveFS&quot; -Name &quot;TrustedRootCertsFile&quot; -Value &quot;$HOME\Documents\gdrivecerts.pem&quot;
</code></pre>
<p>You can verify the update with the following command.</p>
<pre><code class="language-powershell">Get-ItemProperty -Path &quot;HKLM:\SOFTWARE\Google\DriveFS&quot; | Select-Object TrustedRootCertsFile
</code></pre>

</section>
