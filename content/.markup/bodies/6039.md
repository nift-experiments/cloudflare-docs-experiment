<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Traffic policies</strong> &gt; <strong>Traffic settings</strong>.</li>
<li>Select <strong>Certificates</strong>.</li>
<li>Select the certificate you want to turn on.</li>
<li>In <strong>Basic information</strong>, select <strong>Confirm and turn on certificate</strong>.</li>
</ol>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Send a <code>PUT</code> request to the <a href="/api/resources/zero_trust/subresources/gateway/subresources/configurations/methods/update/">Update Zero Trust account configuration</a> endpoint. For example:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request PUT \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/configuration \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;settings&quot;: {
  &quot;certificate&quot;: {
    &quot;id&quot;: &quot;{certificate_id}&quot;,
    &quot;in_use&quot;: true
  }
}
}&#x27;</code></pre>

</section>
