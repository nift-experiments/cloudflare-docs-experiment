
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="iOS">

<ol>
<li>Open the Cloudflare One Agent app.</li>
<li>Go to <strong>Settings</strong> &gt; <strong>Advanced</strong> &gt; <strong>Diagnostics</strong>.</li>
<li>Collect extension logs:</li>
<li>From the <strong>Diagnostics</strong> page, select <strong>Console logs</strong> &gt; <strong>Extension logs</strong>.</li>
<li>Select <strong>Share</strong> and choose a file sharing method.</li>
<li>Enter a descriptive file name (such as <code>extension.log</code>) if available for your sharing method. Then share or save the file.</li>
<li>Collect application logs:</li>
<li>From the <strong>Diagnostics</strong> page, select <strong>Console logs</strong> &gt; <strong>Application logs</strong>.</li>
<li>Select <strong>Share</strong> and choose a file sharing method.</li>
<li>Enter a descriptive file name (such as <code>application.log</code>) if available for your sharing method. Then share or save the file.</li>
<li>(Optional) Collect qlogs for devices using the <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/configure/settings/#device-tunnel-protocol">MASQUE tunnel protocol</a>:</li>
<li>From the <strong>Diagnostics</strong> page, turn on <strong>Enable qlogs</strong>.</li>
<li>Select <strong>Export QLogs</strong>.</li>
<li>Enter a descriptive file name (such as <code>qlogs.zip</code>) if available for your sharing method. Then share or save the file.</li>
</ol>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Android/ChromeOS">

<ol>
<li>Open the Cloudflare One Agent app.</li>
<li>Go to <strong>Settings</strong> &gt; <strong>Advanced</strong> &gt; <strong>Diagnostics</strong>.</li>
<li>Scroll down to the <strong>Debug logs</strong> section.</li>
<li>(Optional) Turn on <strong>Enable qlogs</strong> for devices using the <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/configure/settings/#device-tunnel-protocol">MASQUE tunnel protocol</a>.</li>
<li>Select <strong>Download logs</strong>.</li>
<li>Share the <code>warp-debugging-info-&lt;date&gt;-&lt;time&gt;.zip</code> file via email, Google Drive, or another installed app.</li>
</ol>

</section>
