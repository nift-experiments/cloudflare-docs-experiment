<ol>
<li>
<p>Using your MDM tool, update the <strong>1.1.1.1</strong> app to version 6.29 or above. The update ensures that 1.1.1.1 can co-exist with the new Cloudflare One Agent app during the migration.</p>
</li>
<li>
<p>Add the <strong>Cloudflare One Agent</strong> app from the Google Play store. Its application ID is <code>com.cloudflare.cloudflareoneagent</code>.</p>
</li>
<li>
<p>Copy your <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/deployment/mdm-deployment/#android--chromeos">MDM deployment parameters</a> for the <strong>1.1.1.1</strong> app.</p>
</li>
<li>
<p>Paste the MDM deployment parameters into the <strong>Cloudflare One Agent</strong> app configuration. Make sure that you do not accidentally overwrite the application ID (<code>com.cloudflare.cloudflareoneagent</code>).</p>
</li>
<li>
<p>Using your MDM tool, install the <strong>Cloudflare One Agent</strong> on your devices.</p>
</li>
<li>
<p>On Android, the user will need to <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/deployment/manual-deployment/#ios-android-and-chromeos">re-authenticate</a> to the new application, following the same onboarding steps they went through initially.</p>
</li>
</ol>

<ol>
<li>
<p>Using your MDM tool, update the <strong>1.1.1.1</strong> app to version 6.22 or above. The update ensures that 1.1.1.1 can co-exist with the new Cloudflare One Agent app during the migration.</p>
</li>
<li>
<p>Add the <strong>Cloudflare One Agent</strong> app from the App store. Its application ID is <code>com.cloudflare.cloudflareoneagent</code>.</p>
</li>
<li>
<p>Copy your <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/deployment/mdm-deployment/#ios">MDM deployment parameters</a> for the <strong>1.1.1.1</strong> app.</p>
</li>
<li>

</li>
<li>
<p>Using your MDM tool, install the <strong>Cloudflare One Agent</strong> on your devices.</p>
</li>
</ol>
<p>On iOS, the user does not need to re-authenticate — registration data from the 1.1.1.1 app is automatically migrated to the new Cloudflare One Agent app.</p>
