

1. Add the following permissions to your [`cloudflare_api_token`](https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/api_token):
- `Access: Apps and Policies Write`
- `Access: Service Tokens Write`

2. [Create a service token](/cloudflare-one/access-controls/service-credentials/service-tokens/#create-a-service-token) and copy its **Client ID** and **Client Secret**.

3. Create the following Access policy:

<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_access_policy&quot; &quot;warp_enrollment_service_token&quot; {
	account_id     = var.cloudflare_account_id
	name           = &quot;Allow service token&quot;
	decision       = &quot;non_identity&quot;
	include = [
		{
			service_token = {
				token_id = cloudflare_zero_trust_access_service_token.example_service_token.id
			}
		}
	]
}
</code></pre>


4. Add the policy to your [`cloudflared_zero_trust_access_application` for the Cloudflare One Client](/cloudflare-one/team-and-resources/devices/cloudflare-one-client/deployment/device-enrollment/#set-device-enrollment-permissions).

5. In your MDM [deployment parameters](/cloudflare-one/team-and-resources/devices/cloudflare-one-client/deployment/mdm-deployment/parameters/), add the following fields:
- `auth_client_id`: The **Client ID** of your service token.
- `auth_client_secret`: The **Client Secret** of your service token.
