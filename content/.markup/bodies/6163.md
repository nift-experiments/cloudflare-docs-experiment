

1. Add the following permissions to your [`cloudflare_api_token`](https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/api_token):
- `Access: Mutual TLS Certificates Write`
- `Access: Apps and Policies Write`

2. Use the [`cloudflare_zero_trust_access_mtls_certificate`](https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_access_mtls_certificate) resource to add an mTLS certificate to your account:

<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_access_mtls_certificate&quot; &quot;example_mtls_cert&quot; {
	account_id     = var.cloudflare_account_id
	name           = &quot;WARP enrollment mTLS cert&quot;
	certificate    = &lt;&lt;EOT
	&#45;----BEGIN CERTIFICATE-----
	xxxx
	xxxx
	&#45;----END CERTIFICATE-----
	EOT
	associated_hostnames = [&quot;your-team-name.cloudflareaccess.com&quot;]
}
</code></pre>


3. Create the following Access policy:

<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_access_policy&quot; &quot;warp_enrollment_mtls&quot; {
	account_id     = var.cloudflare_account_id
	name           = &quot;Allow employees with mTLS cert&quot;
	decision       = &quot;allow&quot;
	include = [
		{
			email_domain = {
				domain = &quot;@example.com&quot;
			}
		}
	]

	require = [
		{
			common_name = {
				common_name = &quot;Common name 1&quot;
			}
		},
				{
			common_name = {
				common_name = &quot;Common name 2&quot;
			}
		}
	]
}
</code></pre>


4. Add the policy to your [`cloudflared_zero_trust_access_application` for the Cloudflare One Client](/cloudflare-one/team-and-resources/devices/cloudflare-one-client/deployment/device-enrollment/#set-device-enrollment-permissions).

5. On your device, add the client certificate to the [system keychain](/cloudflare-one/access-controls/service-credentials/mutual-tls-authentication/#test-in-the-browser).
