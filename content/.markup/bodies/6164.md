<ol>
<li>
<p>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Access controls</strong> &gt; <strong>Service credentials</strong> &gt; <strong>Mutual TLS</strong>.</p>
</li>
<li>
<p>Select <strong>Add mTLS Certificate</strong>.</p>
</li>
<li>
<p>Enter any name for the root CA.</p>
</li>
<li>
<p>In <strong>Certificate content</strong>, paste the contents of your root CA.</p>
</li>
</ol>
<p>If the client certificate is directly signed by the root CA, you only need to upload the root. If the client certificate is signed by an intermediate certificate, you must upload the entire CA chain (intermediate and root). For example:</p>
<pre><code class="language-txt">&#45;----BEGIN CERTIFICATE-----
&lt;intermediate.pem&gt;
&#45;----END CERTIFICATE-----
&#45;----BEGIN CERTIFICATE-----
&lt;rootCA.pem&gt;
&#45;----END CERTIFICATE-----
</code></pre>
<ol start="5">
<li>In <strong>Associated hostnames</strong>, enter your Zero Trust <div class="nb-interactive-component" data-cf-component="GlossaryTooltip"></li>
</ol>
<p>team domain</p>
</div>: `<team-name>.cloudflareaccess.com`
<ol start="6">
<li>In your <a href="#set-device-enrollment-permissions">device enrollment permissions</a>, add a <em>Common Name</em> or <em>Valid Certificate</em> rule. For example, the following policy requires a client certificate with a specific common name:</li>
</ol>

</ol>

<ol>
<li>Add the following permissions to your <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/api_token"><code>cloudflare_api_token</code></a>:</li>
</ol>
<ul>
<li><code>Access: Mutual TLS Certificates Write</code></li>
<li><code>Access: Apps and Policies Write</code></li>
</ul>
<ol start="2">
<li>Use the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_access_mtls_certificate"><code>cloudflare_zero_trust_access_mtls_certificate</code></a> resource to add an mTLS certificate to your account:</li>
</ol>
<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_access_mtls_certificate&quot; &quot;example_mtls_cert&quot; {
	account_id     = var.cloudflare_account_id
	name           = &quot;WARP enrollment mTLS cert&quot;
	certificate    = &lt;&lt;EOT
	&#45;----BEGIN CERTIFICATE-----
	xxxx
	xxxx
	&#45;----END CERTIFICATE-----
	EOT
	associated_hostnames = [&quot;your-team-name.cloudflareaccess.com&quot;]
}
</code></pre>
<ol start="3">
<li>Create the following Access policy:</li>
</ol>
<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_access_policy&quot; &quot;warp_enrollment_mtls&quot; {
	account_id     = var.cloudflare_account_id
	name           = &quot;Allow employees with mTLS cert&quot;
	decision       = &quot;allow&quot;
	include = [
		{
			email_domain = {
				domain = &quot;@example.com&quot;
			}
		}
	]

	require = [
		{
			common_name = {
				common_name = &quot;Common name 1&quot;
			}
		},
				{
			common_name = {
				common_name = &quot;Common name 2&quot;
			}
		}
	]
}
</code></pre>
<ol start="4">
<li>
<p>Add the policy to your <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/deployment/device-enrollment/#set-device-enrollment-permissions"><code>cloudflared_zero_trust_access_application</code> for the Cloudflare One Client</a>.</p>
</li>
<li>
<p>On your device, add the client certificate to the <a href="/cloudflare-one/access-controls/service-credentials/mutual-tls-authentication/#test-in-the-browser">system keychain</a>.</p>
</li>
</ol>
