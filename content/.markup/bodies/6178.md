<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Terraform (v5)">

<p>In <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_device_custom_profile"><code>cloudflare_zero_trust_device_custom_profile</code></a>, configure a <code>match</code> expression using the <code>network</code> selector. For example, the following device profile will match all devices connected a specific managed network:</p>
<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_device_custom_profile&quot; &quot;office&quot; {
	account_id            = var.cloudflare_account_id
	name                  = &quot;Office&quot;
	description           = &quot;Devices connected to the office network&quot;
	precedence            = 1
	service_mode_v2       = {mode = &quot;warp&quot;}

	match = trimspace(replace(&lt;&lt;-EOT
		network == &quot;${cloudflare_zero_trust_device_managed_networks.office.name}&quot;
	EOT
	, &quot;\n&quot;, &quot; &quot;))
}
</code></pre>
