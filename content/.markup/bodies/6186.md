<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Team &amp; Resources</strong> &gt; <strong>Devices</strong> &gt; <strong>Device profiles</strong> &gt; <strong>General profiles</strong>.</li>
<li>Select <strong>Create new profile</strong>. This will make a copy of the <strong>Default</strong> profile.</li>
<li>Enter any name for the profile.</li>
<li>Create rules to define the devices that will use this profile. Learn more about the available <a href="#selectors">Selectors</a>, <a href="/cloudflare-one/traffic-policies/network-policies/#comparison-operators">Operators</a>, and <a href="/cloudflare-one/traffic-policies/network-policies/#value">Values</a>.</li>
<li>Configure <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/configure/settings/#device-settings">device client settings</a> for these devices.</li>
</ol>
<aside class="nb-aside note">
<p>At this time, <strong>Split Tunnels</strong> and <strong>Local Domain Fallback</strong> can only be modified after you save the profile.</p>
</aside>
<ol start="6">
<li>Select <strong>Create profile</strong>.</li>
</ol>
<p>Your profile will appear in the <strong>Profile settings</strong> list. You can rearrange the profiles in the list according to your desired <a href="#order-of-precedence">order of precedence</a>.</p>
