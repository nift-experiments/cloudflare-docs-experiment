<ol>
<li>Open the Cloudflare One Client and go to <strong>Settings</strong>.</li>
<li>In <strong>Temporarily disconnect Cloudflare One Client</strong>, select <strong>Enter admin code</strong>.</li>
<li>Enter the override code and select <strong>Disconnect</strong>.</li>
</ol>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Version 2026.1 and earlier">

<ol>
<li>In the Cloudflare One Client, go to <strong>Settings</strong> &gt; <strong>Preferences</strong> &gt; <strong>Advanced</strong>.</li>
<li>Select <strong>Enter code</strong>.</li>
<li>Enter the override code.</li>
</ol>
