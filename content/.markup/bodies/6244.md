

To check if **SCCM VPN Boundary Support** is active on a device, run the following command:

<pre><code class="language-cmd">warp-cli settings | findstr &quot;SCCM VPN Boundary&quot;
</code></pre>


<pre><code class="language-cmd">(network policy) SCCM VPN Boundary Support: true
</code></pre>

<pre><code class="language-cmd">ipconfig /all
