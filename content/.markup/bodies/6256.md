<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<p>To configure External Emergency Disconnect using the dashboard:</p>
<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Team &amp; Resources</strong> &gt; <strong>Devices</strong> &gt; <strong>Management</strong>.</li>
<li>Select <strong>Global disconnection settings</strong>.</li>
<li>Find <strong>Manage device connection using an external signal</strong> and select <strong>Edit</strong>.</li>
<li>Configure the following fields:</li>
</ol>
<ul>
<li><strong>Endpoint IP address and port</strong>: Enter the HTTPS URL from which to fetch the external disconnect signal (for example, <code>https://192.0.2.1:3333/status/disconnect</code>). The endpoint must use HTTPS and have an IPv4 or IPv6 address as the host.</li>
<li><strong>Polling frequency</strong>: Choose how often the Cloudflare One Client should fetch the external disconnect signal.</li>
<li><strong>Certificate fingerprint</strong>: Enter the <a href="#2-extract-the-sha-256-fingerprint">SHA-256 fingerprint</a> of the HTTPS server certificate (for example, <code>DD4F4806C57A5BBAF1AA5B080F0541DA75DB468D0A1FE731310149500CCD8662</code>).</li>
</ul>
<ol start="5">
<li>Select <strong>Save</strong>.</li>
<li>Turn on <strong>Manage device connection using an external signal</strong>.</li>
</ol>
<p>All Cloudflare One Clients in your organization will now start polling the external endpoint and connect or disconnect based on the response payload.</p>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To configure External Emergency Disconnect using the API, send a <code>PATCH</code> request to the <code>/devices/settings</code> endpoint:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request PATCH \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/devices/settings \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;external_emergency_signal_enabled&quot;: true,
&quot;external_emergency_signal_url&quot;: &quot;https://192.0.2.1:3333/status/disconnect&quot;,
&quot;external_emergency_signal_fingerprint&quot;: &quot;DD4F4806C57A5BBAF1AA5B080F0541DA75DB468D0A1FE731310149500CCD8662&quot;,
&quot;external_emergency_signal_interval&quot;: &quot;1m&quot;
}&#x27;</code></pre>

</section>
