<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Team &amp; Resources</strong> &gt; <strong>Devices</strong> &gt; <strong>Management</strong>.</li>
<li>Select <strong>Global disconnection settings</strong>.</li>
<li>Turn off <strong>Manage device connection using an external signal</strong>.</li>
</ol>
<p>Cloudflare will propagate the new setting to clients, instructing them to stop polling and discard the cached emergency state.</p>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Send a <code>PATCH</code> request with the endpoint URL and fingerprint set to empty strings:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request PATCH \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/devices/settings \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;external_emergency_signal_enabled&quot;: false,
&quot;external_emergency_signal_url&quot;: &quot;&quot;,
&quot;external_emergency_signal_fingerprint&quot;: &quot;&quot;,
&quot;external_emergency_signal_interval&quot;: &quot;1m&quot;
}&#x27;</code></pre>
<p>Cloudflare will propagate the new settings to clients, instructing them to stop polling and discard the cached emergency state.</p>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="MDM">

<p>If you deployed External Emergency Disconnect using an MDM, remove the <code>external_emergency_signal_url</code> key (and other related keys) from the MDM profile. Then, use your MDM to push the changes to devices. The Cloudflare One Client will stop polling the external endpoint and discard its cached emergency state.</p>
<p>Alternatively, users can switch the Cloudflare One Client to a <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/deployment/mdm-deployment/switch-organizations/">different MDM configuration</a> that does not have the feature configured.</p>

</section>
