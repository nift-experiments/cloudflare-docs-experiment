
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Version 2026.2+">

<ol>
<li>Open a terminal window.</li>
<li>Run the following command:</li>
</ol>
<pre><code class="language-sh">warp-diag captive-portal
</code></pre>
<ol start="3">
<li>When prompted with <code>You're currently connected via interface '&lt;INTERFACE&gt;' (&lt;SSID&gt;). Is this interface connected to the network causing issues?</code>, select <strong>Yes</strong> to confirm.</li>
</ol>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Version 2026.1 and earlier">

<ol>
<li>Open the Cloudflare One Client.</li>
<li>Go to <strong>Settings</strong> (gear icon) &gt; <strong>Preferences</strong> &gt; <strong>Advanced</strong>.</li>
<li>Select <strong>Collect Captive Portal Diag</strong>.</li>
<li>The Cloudflare One Client will ask if the device is connected (or attempting to connect) to the Wi-Fi network that is causing issues. Select <strong>Yes</strong> to confirm.</li>
</ol>
