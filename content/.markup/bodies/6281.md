<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Team &amp; Resources</strong> &gt; <strong>Devices</strong> &gt; <strong>Device profiles</strong> &gt; <strong>General profiles</strong>.</li>
<li>Locate the <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/configure/device-profiles/">device profile</a> you would like to modify and select <strong>Configure</strong>.</li>
<li>Scroll down to <strong>Split Tunnels</strong>.</li>
<li>(Optional) To view your existing Split Tunnel configuration, select <strong>Manage</strong>. You will see a list of the IPs and domains Cloudflare Zero Trust excludes or includes, depending on the mode you have selected. We recommend making a copy of your Split Tunnel entries, as they will revert to the default upon switching modes.</li>
<li>Under <strong>Split Tunnels</strong>, choose a mode:</li>
</ol>
<ul>
<li><strong>Exclude IPs and domains</strong> — (Default) All traffic will be sent to Cloudflare Gateway except for the IPs and domains you specify.</li>
<li><strong>Include IPs and Domains</strong> — Only traffic destined to the IPs or domains you specify will be sent to Cloudflare Gateway. All other traffic will bypass Gateway and will no longer be filtered by your network or HTTP policies. In order to use certain features, you will need to manually add <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/configure/route-traffic/split-tunnels/#cloudflare-zero-trust-domains">Zero Trust domains</a>.</li>
</ul>

<ol>
<li>Add the following permission to your <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/api_token"><code>cloudflare_api_token</code></a>:</li>
</ol>
<ul>
<li><code>Zero Trust Write</code></li>
</ul>
<ol start="2">
<li>
<p>Choose a <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_device_default_profile"><code>cloudflare_zero_trust_device_default_profile</code></a> or <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_device_custom_profile"><code>cloudflare_zero_trust_device_custom_profile</code></a> resource to modify, or <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/configure/device-profiles/#create-a-new-profile">create a new device profile</a>.</p>
</li>
<li>
<p>In your device profile, configure either the <code>exclude</code> or <code>include</code> argument. You cannot set both <code>exclude</code> and <code>include</code> in a given device profile.</p>
</li>
</ol>
<p>a. To manage Split Tunnel routes in <strong>Exclude</strong> mode, use the <code>exclude</code> argument:</p>
<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_device_custom_profile&quot; &quot;exclude_example&quot; {
	account_id            = var.cloudflare_account_id
	name                  = &quot;Custom profile in Split Tunnels Exclude mode&quot;
	enabled               = true
	precedence            = 101
	service_mode_v2       = {mode = &quot;warp&quot;}
	match 								=  &quot;identity.email == \&quot;test@cloudflare.com\&quot;&quot;

	exclude = [{
			address = &quot;10.0.0.0/8&quot;
			description = &quot;Example route to exclude from WARP tunnel&quot;
	}]
}
</code></pre>
<pre><code>In this example, all traffic will be sent to Cloudflare Gateway except for traffic destined to `10.0.0.0/8`. To exclude the default IPs and domains recommended by Cloudflare, refer to [Add a route](#add-a-route).
</code></pre>
<p>b. To manage Split Tunnel routes in <strong>Include</strong> mode, use the <code>include</code> argument:</p>
<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_device_custom_profile&quot; &quot;include_example&quot; {
	account_id            = var.cloudflare_account_id
	name                  = &quot;Custom profile in Split Tunnels Include mode&quot;
	enabled               = true
	precedence            = 101
	service_mode_v2       = {mode = &quot;warp&quot;}
	match 								=  &quot;identity.email == \&quot;test@cloudflare.com\&quot;&quot;

	include = [{
			address = &quot;10.0.0.0/8&quot;
			description = &quot;Example route to include in WARP tunnel&quot;
	}]
}
</code></pre>
<pre><code>In this example, only traffic destined to `10.0.0.0/8` will be sent to Cloudflare Gateway.
</code></pre>
