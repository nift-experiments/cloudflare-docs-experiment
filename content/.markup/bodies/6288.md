<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Team &amp; Resources</strong> &gt; <strong>Devices</strong> &gt; <strong>Device profiles</strong> &gt; <strong>General profiles</strong>.</li>
<li>Locate the <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/configure/device-profiles/">device profile</a> you would like to modify and select <strong>Configure</strong>.</li>
<li>Under <strong>Split Tunnels</strong>, check whether your <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/configure/route-traffic/split-tunnels/#change-split-tunnels-mode">Split Tunnels mode</a> is set to <strong>Exclude</strong> or <strong>Include</strong>.</li>
<li>Select <strong>Manage</strong>.</li>
<li>You can exclude or include routes based on either their IP address or domain. When possible we recommend adding an IP address instead of a domain. To learn about the consequences of adding a domain, refer to <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/configure/route-traffic/split-tunnels/#domain-based-split-tunnels">Domain-based Split Tunnels</a>.</li>
</ol>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Add an IP">
<p>To add an IP address to Split Tunnels:</p>
<ol>
<li>Select <em>IP Address</em>.</li>
<li>Enter the IP address or <span class="nb-glossary-tooltip" title="CIDR">CIDR</span> you want to exclude or include.</li>
<li>Select <strong>Save destination</strong>.</li>
</ol>
<p>Traffic to this IP address is now excluded or included from the WARP tunnel.</p>
<aside class="nb-aside note">
<p>If you would like to exclude a specific IP range from a larger IP range, you can use this calculator:</p>
<div class="nb-interactive-component" data-cf-component="SubtractIPCalculator"></div>
</aside>
</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Add a domain">
<p>To add a domain to Split Tunnels:</p>
<ol>
<li>Select <em>Domain</em>.</li>
<li>Enter a <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/configure/route-traffic/split-tunnels/#valid-domains">valid domain</a> to exclude or include.</li>
<li>Select <strong>Save destination</strong>.</li>
<li>(Optional) If your domain does not have a public DNS record, create a <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/configure/route-traffic/local-domains/">Local Domain Fallback</a> entry to allow a private DNS server to handle domain resolution.</li>
</ol>
<p>When a user goes to the domain, the domain gets resolved according to your Local Domain Fallback configuration (either by Gateway or by your private DNS server). Split Tunnels will then dynamically include or exclude the IP address returned in the DNS lookup.</p>
