<p>To view the entire routing table on Linux, run <code>ip -6 route show table all</code> or <code>ip -4 route show table all</code>.</p>
<p>You can also search the routing table for an IP address. In this example, we see that traffic to <code>1.1.1.1</code> is sent through the Cloudflare One Client's virtual interface:</p>
<pre><code class="language-sh">ip route get 1.1.1.1
</code></pre>
<pre><code class="language-sh">1.1.1.1 dev CloudflareWARP table 65743 src 172.16.0.2 uid 1000
    cache
</code></pre>
<p>In contrast, this DHCP address is excluded from the Cloudflare One Client and uses the default interface:</p>
<pre><code class="language-sh">ip route get 169.254.0.0
</code></pre>
<pre><code class="language-sh">169.254.0.0 dev ens18 src 172.24.8.6 uid 1000
    cache
</code></pre>
