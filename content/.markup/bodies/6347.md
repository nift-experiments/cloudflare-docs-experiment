
On Windows, you can configure `AutoLaunchProtocolsFromOrigins` by adding a new registry key.

To add the registry key manually:

1. Open Registry Editor as Administrator.
2. Navigate to the policies folder for your browser:
- Google Chrome: `HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Google\Chrome`
- Microsoft Edge: `HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Edge`
<aside class="nb-aside note">


<p>You may need to create the <code>HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Google\Chrome</code> folder if it does not already exist.</p>


</aside>
3. Create a new string value:
- **Value Name**: `AutoLaunchProtocolsFromOrigins`
- **Value Data**: `[{"allowed_origins": ["https://<your-team-name>.cloudflareaccess.com/"], "protocol": "com.cloudflare.warp"}]`

Be sure to replace `<your-team-name>` with your actual <span class="nb-glossary-tooltip" title="team name">Zero Trust team name</span>.

Instead of using the Registry Editor, the registry key can also be created using a Group Policy Object (GPO), PowerShell script, or with an MDM such as [Intune](/cloudflare-one/team-and-resources/devices/cloudflare-one-client/deployment/mdm-deployment/partners/intune/#update-mdm-parameters).
