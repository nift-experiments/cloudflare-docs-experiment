
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Windows">

<p>On Windows, you can configure <code>AutoLaunchProtocolsFromOrigins</code> by adding a new registry key.</p>
<p>To add the registry key manually:</p>
<ol>
<li>Open Registry Editor as Administrator.</li>
<li>Navigate to the policies folder for your browser:</li>
</ol>
<ul>
<li>Google Chrome: <code>HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Google\Chrome</code></li>
<li>Microsoft Edge: <code>HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Edge</code></li>
</ul>
<aside class="nb-aside note">
<p>You may need to create the <code>HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Google\Chrome</code> folder if it does not already exist.</p>
</aside>
3. Create a new string value:
- **Value Name**: `AutoLaunchProtocolsFromOrigins`
- **Value Data**: `[{"allowed_origins": ["https://<your-team-name>.cloudflareaccess.com/"], "protocol": "com.cloudflare.warp"}]`
<p>Be sure to replace <code>&lt;your-team-name&gt;</code> with your actual <span class="nb-glossary-tooltip" title="team name">Zero Trust team name</span>.</p>
<p>Instead of using the Registry Editor, the registry key can also be created using a Group Policy Object (GPO), PowerShell script, or with an MDM such as <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/deployment/mdm-deployment/partners/intune/#update-mdm-parameters">Intune</a>.</p>

<p>On macOS, you can configure <code>AutoLaunchProtocolsFromOrigins</code> by deploying a property list (plist) file for the browser. The exact instructions will vary depending on your <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/deployment/mdm-deployment/partners/">MDM</a>. The general procedure is as follows:</p>
<ol>
<li>Create a new plist file with the following name (case sensitive):</li>
</ol>
<ul>
<li>Google Chrome: <code>com.google.Chrome.plist</code></li>
<li>Microsoft Edge: <code>com.microsoft.Edge.plist</code></li>
</ul>
<ol start="2">
<li>Using a text editor, add the following content to your plist:</li>
</ol>
