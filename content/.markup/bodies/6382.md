
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Team &amp; Resources</strong> &gt; <strong>Devices</strong>.</li>
<li>Select the <strong>Management</strong> tab.</li>
<li>Under <strong>Client version assignments</strong>, select <strong>Manage</strong>.</li>
<li>Select <strong>Create new deployment group</strong>.</li>
<li>Under <strong>Name your deployment group</strong>, enter a name.</li>
<li>Under <strong>Select device profiles</strong>, select one or more device profiles whose devices should receive this assignment.</li>
<li>Under <strong>Assign client version</strong>, select an operating system, a release track, and a client version. To target additional platforms with the same group, select <strong>Add OS</strong> and repeat.</li>
<li>Select <strong>Save</strong>.</li>
</ol>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Send a <code>POST</code> request to the <a href="/api/resources/zero_trust/subresources/devices/subresources/deployment_groups/methods/create/">Deployment Groups API</a>:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/devices/deployment-groups \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;Engineering Ring 0&quot;,
&quot;version_config&quot;: [
  {
    &quot;target_environment&quot;: &quot;windows&quot;,
    &quot;version&quot;: &quot;2026.6.0&quot;
  },
  {
    &quot;target_environment&quot;: &quot;macos&quot;,
    &quot;version&quot;: &quot;2026.6.0&quot;
  }
],
&quot;policy_ids&quot;: [
  &quot;&lt;POLICY_UUID_1&gt;&quot;,
  &quot;&lt;POLICY_UUID_2&gt;&quot;
]
}&#x27;</code></pre>

</section>
