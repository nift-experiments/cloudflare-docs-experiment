

First, create a schema file that defines your ecommerce data structure:

**Create `schema.json`:**

```json
{
	"fields": [
		{
			"name": "user_id",
			"type": "string",
			"required": true
		},
		{
			"name": "event_type",
			"type": "string",
			"required": true
		},
		{
			"name": "product_id",
			"type": "string",
			"required": false
		},
		{
			"name": "amount",
			"type": "float64",
			"required": false
		}
	]
}
```

Use the interactive setup to create a pipeline that writes to R2 Data Catalog:

```bash
npx wrangler pipelines setup
```

<aside class="nb-aside note">


<p>The setup command automatically creates the <a href="/r2/buckets/">R2 bucket</a> and enables <a href="/r2-data-catalog/">R2 Data Catalog</a> if they do not already exist, so you do not need to create them beforehand.</p>


</aside>

Follow the prompts:

1. **Pipeline name**: Enter `ecommerce`

2. **Stream configuration**:
- Enable HTTP endpoint: `yes`
- Require authentication: `no` (for simplicity)
- Configure custom CORS origins: `no`
- Schema definition: `Load from file`
- Schema file path: `schema.json` (or your file path)

3. **Sink configuration**:
- Destination type: `Data Catalog (Iceberg)`
- Setup mode: `Simple (recommended defaults)`
- R2 bucket name: `pipelines-tutorial` (created automatically if it does not exist)
- Table name: `ecommerce`
- Catalog API token: Enter your token from step 1

4. **Review**: Confirm the summary and select `Create resources`

5. **SQL transformation**: Choose `Simple ingestion (SELECT * FROM stream)`

<aside class="nb-aside note">


<p>If you make a mistake during setup (such as an invalid name or incorrect credentials), you will be prompted to retry rather than needing to restart the entire setup process.</p>


</aside>

<details class="nb-details"><summary>Advanced mode options</summary><div class="nb-details-body">

<p>If you select <strong>Advanced</strong> instead of <strong>Simple</strong> during sink configuration, you can customize the following additional options:</p>
<ul>
<li><strong>Format</strong>: Output file format (for example, Parquet)</li>
<li><strong>Compression</strong>: Compression algorithm (for example, zstd)</li>
<li><strong>Rolling policy</strong>: File size threshold (minimum 5 MB) and time interval (minimum 10 seconds) for creating new files</li>
<li><strong>Credentials</strong>: Choose between automatic credential generation or manually entering R2 credentials</li>
<li><strong>Namespace</strong>: Data Catalog namespace (defaults to <code>default</code>)</li>
</ul>

</div></details>

After setup completes, the command outputs a configuration snippet for your Wrangler file, a Worker binding example with sample data, and a curl command for the HTTP endpoint. Note the HTTP endpoint URL and the `pipelines` configuration for use in the following steps.

You can also pre-set the pipeline name using the `--name` flag:

```bash
npx wrangler pipelines setup --name ecommerce
```
