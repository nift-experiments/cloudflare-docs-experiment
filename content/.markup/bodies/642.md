<p>First, create a schema file that defines your ecommerce data structure:</p>
<p><strong>Create <code>schema.json</code>:</strong></p>
<pre><code class="language-json">{
	&quot;fields&quot;: [
		{
			&quot;name&quot;: &quot;user_id&quot;,
			&quot;type&quot;: &quot;string&quot;,
			&quot;required&quot;: true
		},
		{
			&quot;name&quot;: &quot;event_type&quot;,
			&quot;type&quot;: &quot;string&quot;,
			&quot;required&quot;: true
		},
		{
			&quot;name&quot;: &quot;product_id&quot;,
			&quot;type&quot;: &quot;string&quot;,
			&quot;required&quot;: false
		},
		{
			&quot;name&quot;: &quot;amount&quot;,
			&quot;type&quot;: &quot;float64&quot;,
			&quot;required&quot;: false
		}
	]
}
</code></pre>
<p>Use the interactive setup to create a pipeline that writes to R2 Data Catalog:</p>
<pre><code class="language-bash">npx wrangler pipelines setup
</code></pre>
<aside class="nb-aside note">
<p>The setup command automatically creates the <a href="/r2/buckets/">R2 bucket</a> and enables <a href="/r2-data-catalog/">R2 Data Catalog</a> if they do not already exist, so you do not need to create them beforehand.</p>
</aside>
<p>Follow the prompts:</p>
<ol>
<li>
<p><strong>Pipeline name</strong>: Enter <code>ecommerce</code></p>
</li>
<li>
<p><strong>Stream configuration</strong>:</p>
</li>
</ol>
<ul>
<li>Enable HTTP endpoint: <code>yes</code></li>
<li>Require authentication: <code>no</code> (for simplicity)</li>
<li>Configure custom CORS origins: <code>no</code></li>
<li>Schema definition: <code>Load from file</code></li>
<li>Schema file path: <code>schema.json</code> (or your file path)</li>
</ul>
<ol start="3">
<li><strong>Sink configuration</strong>:</li>
</ol>
<ul>
<li>Destination type: <code>Data Catalog (Iceberg)</code></li>
<li>Setup mode: <code>Simple (recommended defaults)</code></li>
<li>R2 bucket name: <code>pipelines-tutorial</code> (created automatically if it does not exist)</li>
<li>Table name: <code>ecommerce</code></li>
<li>Catalog API token: Enter your token from step 1</li>
</ul>
<ol start="4">
<li>
<p><strong>Review</strong>: Confirm the summary and select <code>Create resources</code></p>
</li>
<li>
<p><strong>SQL transformation</strong>: Choose <code>Simple ingestion (SELECT * FROM stream)</code></p>
</li>
</ol>
<aside class="nb-aside note">
<p>If you make a mistake during setup (such as an invalid name or incorrect credentials), you will be prompted to retry rather than needing to restart the entire setup process.</p>
</aside>
<details class="nb-details"><summary>Advanced mode options</summary><div class="nb-details-body">
<p>If you select <strong>Advanced</strong> instead of <strong>Simple</strong> during sink configuration, you can customize the following additional options:</p>
<ul>
<li><strong>Format</strong>: Output file format (for example, Parquet)</li>
<li><strong>Compression</strong>: Compression algorithm (for example, zstd)</li>
<li><strong>Rolling policy</strong>: File size threshold (minimum 5 MB) and time interval (minimum 10 seconds) for creating new files</li>
<li><strong>Credentials</strong>: Choose between automatic credential generation or manually entering R2 credentials</li>
<li><strong>Namespace</strong>: Data Catalog namespace (defaults to <code>default</code>)</li>
</ul>
</div></details>
<p>After setup completes, the command outputs a configuration snippet for your Wrangler file, a Worker binding example with sample data, and a curl command for the HTTP endpoint. Note the HTTP endpoint URL and the <code>pipelines</code> configuration for use in the following steps.</p>
<p>You can also pre-set the pipeline name using the <code>--name</code> flag:</p>
<pre><code class="language-bash">npx wrangler pipelines setup --name ecommerce
</code></pre>
