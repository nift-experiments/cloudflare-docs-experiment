<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Pass through policy">

<p>To disable automatic HTTPS upgrades for a URL across your Zero Trust organization, create a Gateway pass through policy.</p>
<ol>
<li>
<p>Deploy a <a href="/cloudflare-one/team-and-resources/devices/user-side-certificates/custom-certificate/">custom root certificate</a>.</p>
</li>
<li>
<p>Create an <a href="/cloudflare-one/traffic-policies/http-policies/">HTTP policy</a> to match the domain of the URL being automatically upgraded. For example:</p>
</li>
</ol>
<table>
<thead>
<tr>
<th>Selector</th>
<th>Operator</th>
<th>Value</th>
<th>Action</th>
</tr>
</thead>
<tbody>
<tr>
<td>URL</td>
<td>in</td>
<td><code>example.com</code></td>
<td>Allow</td>
</tr>
</tbody>
</table>
<ol start="3">
<li>
<p>In <strong>Untrusted certificate action</strong>, choose <em>Pass through</em>.</p>
</li>
<li>
<p>Select <strong>Create policy</strong>.</p>
</li>
</ol>
<p>The pass through policy will bypass insecure connection upgrades for any device connected to your Zero Trust organization. For more information, refer to <a href="/cloudflare-one/traffic-policies/http-policies/#untrusted-certificates">Untrusted certificates</a>.</p>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Chrome browser flag">

<p>To disable automatic HTTPS upgrades on a per-browser basis, go to <a href="chrome://flags/#https-upgrades">Chrome flags</a> and turn off <strong>HTTPS Upgrades</strong>.</p>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Chrome enterprise policy">

<p>Chrome Enterprise users can turn off automatic HTTPS upgrades for all URLs with a <a href="https://chromeenterprise.google/policies/#HttpsUpgradesEnabled"><code>HttpsUpgradesEnabled</code> management policy</a>.</p>

</section>
