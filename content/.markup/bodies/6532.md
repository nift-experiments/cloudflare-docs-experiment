<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Traffic policies</strong> &gt; <strong>Firewall policies</strong> &gt; <strong>HTTP</strong>.</li>
<li>Select <strong>Add a policy</strong>.</li>
<li>Name the policy.</li>
<li>Under <strong>Traffic</strong>, build a logical expression that defines the traffic you want to allow or block. Because granular controls are specific to each application, you must use the <em>Application</em> selector with the <em>is</em> operator.</li>
<li>In <strong>Value</strong>, select your desired application.</li>
<li>In <strong>Controls</strong>, choose one or more Application Controls or individual Operations. For example, you can create a policy to block file uploads to ChatGPT:</li>
</ol>

<tr>
<th>Selector</th>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Use the <a href="/api/resources/zero_trust/subresources/gateway/subresources/rules/methods/create/">Create a Zero Trust Gateway rule</a> endpoint to create a policy. For example, you can create a policy to block file uploads to ChatGPT:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/rules \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;Block ChatGPT uploads&quot;,
&quot;description&quot;: &quot;Block file uploads to ChatGPT while allowing other usage&quot;,
&quot;enabled&quot;: true,
&quot;action&quot;: &quot;block&quot;,
&quot;filters&quot;: [
  &quot;http&quot;
],
&quot;traffic&quot;: &quot;any(app.ids[*] == 1199) and any(app_control.controls[*] in {1653})&quot;,
&quot;identity&quot;: &quot;&quot;,
&quot;device_posture&quot;: &quot;&quot;
}&#x27;</code></pre>
