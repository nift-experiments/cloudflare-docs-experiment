2. (Optional) Configure your API environment variables to include your [account ID](/fundamentals/account/find-account-and-zone-ids/) and API token.
3. Send a `POST` request to the [Create a Zero Trust Gateway rule](/api/resources/zero_trust/subresources/gateway/subresources/rules/methods/create/) endpoint. For example, you can use a list of [device serial numbers](/cloudflare-one/reusable-components/posture-checks/client-checks/corp-device/) to ensure users can only access an application if they connect with the Cloudflare One Client from a company device:



<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/rules \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;Enforce device posture&quot;,
&quot;description&quot;: &quot;Ensure only devices in Zero Trust organization can connect to application&quot;,
&quot;precedence&quot;: 0,
&quot;enabled&quot;: true,
&quot;action&quot;: &quot;block&quot;,
&quot;filters&quot;: [
  &quot;l4&quot;
],
&quot;traffic&quot;: &quot;any(net.sni.domains[*] == \&quot;internalapp.com\&quot;)&quot;,
&quot;identity&quot;: &quot;&quot;,
&quot;device_posture&quot;: &quot;not(any(device_posture.checks.passed[*] in {\&quot;LIST_UUID\&quot;}))&quot;
}&#x27;</code></pre>



```sh output
{
	 "success": true,
	 "errors": [],
	 "messages": []
}
```

The API will respond with a summary of the policy and the result of your request.
