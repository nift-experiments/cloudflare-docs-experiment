<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Traffic policies</strong> &gt; <strong>Firewall policies</strong>.</li>
<li>In the <strong>HTTP</strong> tab, select <strong>Add a policy</strong>.</li>
<li>Name the policy.</li>
<li>Under <strong>Traffic</strong>, build a logical expression that defines the traffic you want to allow or block.</li>
<li>Choose an <strong>Action</strong> to take when traffic matches the logical expression. For example, if you have configured TLS decryption, some applications that use <a href="/cloudflare-one/traffic-policies/http-policies/tls-decryption/#inspection-limitations">embedded certificates</a> may not support HTTP inspection, such as some Google products. You can create a policy to bypass inspection for these applications:</li>

<li>(Optional) Configure your API environment variables to include your <a href="/fundamentals/account/find-account-and-zone-ids/">account ID</a> and API token.</li>
<li>Send a <code>POST</code> request to the <a href="/api/resources/zero_trust/subresources/gateway/subresources/rules/methods/create/">Create a Zero Trust Gateway rule</a> endpoint. For example, if you have configured TLS decryption, some applications that use <a href="/cloudflare-one/traffic-policies/http-policies/tls-decryption/#inspection-limitations">embedded certificates</a> may not support HTTP inspection, such as some Google products. You can create a policy to bypass inspection for these applications:</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/rules \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;Do not inspect applications&quot;,
&quot;description&quot;: &quot;Bypass TLS decryption for unsupported applications&quot;,
&quot;precedence&quot;: 0,
&quot;enabled&quot;: true,
&quot;action&quot;: &quot;off&quot;,
&quot;filters&quot;: [
  &quot;http&quot;
],
&quot;traffic&quot;: &quot;any(app.type.ids[*] in {16})&quot;,
&quot;identity&quot;: &quot;&quot;,
&quot;device_posture&quot;: &quot;&quot;
}&#x27;</code></pre>
<pre><code class="language-sh">{
	 &quot;success&quot;: true,
	 &quot;errors&quot;: [],
	 &quot;messages&quot;: []
}
</code></pre>
<p>The API will respond with a summary of the policy and the result of your request.</p>
