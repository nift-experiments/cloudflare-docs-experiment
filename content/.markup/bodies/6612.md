2. (Optional) Configure your API environment variables to include your [account ID](/fundamentals/account/find-account-and-zone-ids/) and API token.
3. Send a `POST` request to the [Create a Zero Trust Gateway rule](/api/resources/zero_trust/subresources/gateway/subresources/rules/methods/create/) endpoint. For example, the following request creates a policy that blocks all default [security categories](/cloudflare-one/traffic-policies/domain-categories/#security-categories). The numeric IDs in the `traffic` field (such as `68`, `178`, `80`) correspond to Cloudflare's predefined security threat categories — refer to [domain categories](/cloudflare-one/traffic-policies/domain-categories/#security-categories) for the full mapping. The `precedence` field controls evaluation order when multiple policies match (`0` means this policy is evaluated first).



<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/rules \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;Block security threats&quot;,
&quot;description&quot;: &quot;Block all default Cloudflare DNS security categories&quot;,
&quot;precedence&quot;: 0,
&quot;enabled&quot;: true,
&quot;action&quot;: &quot;block&quot;,
&quot;filters&quot;: [
  &quot;dns&quot;
],
&quot;traffic&quot;: &quot;any(dns.security_category[*] in {68 178 80 83 176 175 117 131 134 151 153})&quot;,
&quot;identity&quot;: &quot;&quot;
}&#x27;</code></pre>



<pre><code class="language-sh">{
	 &quot;success&quot;: true,
	 &quot;errors&quot;: [],
	 &quot;messages&quot;: []
}
</code></pre>


 The API will respond with a summary of the policy and the result of your request.
