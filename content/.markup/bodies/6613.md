<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Traffic policies</strong> &gt; <strong>Firewall policies</strong>.</li>
<li>In the <strong>DNS</strong> tab, select <strong>Add a policy</strong>.</li>
<li>Name the policy.</li>
<li>Under <strong>Traffic</strong>, use the condition builder to define which DNS queries this policy applies to. Select a selector (such as <strong>Security Categories</strong>), an operator (such as <strong>in</strong>), and one or more values.</li>
<li>Choose an <strong>Action</strong> to take when traffic matches the condition. For example, we recommend adding a policy to block all <a href="/cloudflare-one/traffic-policies/domain-categories/#security-categories">security categories</a>:</li>
</ol>

<th>Operator</th>
<th>Value</th>
<th>Action</th>
</tr>
</thead>

<tr>
<td>Security Categories</td>
<td>in</td>
<td><em>All security risks</em></td>

</tr>

<ol start="2">
<li>(Optional) Configure your API environment variables to include your <a href="/fundamentals/account/find-account-and-zone-ids/">account ID</a> and API token.</li>
<li>Send a <code>POST</code> request to the <a href="/api/resources/zero_trust/subresources/gateway/subresources/rules/methods/create/">Create a Zero Trust Gateway rule</a> endpoint. For example, the following request creates a policy that blocks all default <a href="/cloudflare-one/traffic-policies/domain-categories/#security-categories">security categories</a>. The numeric IDs in the <code>traffic</code> field (such as <code>68</code>, <code>178</code>, <code>80</code>) correspond to Cloudflare's predefined security threat categories — refer to <a href="/cloudflare-one/traffic-policies/domain-categories/#security-categories">domain categories</a> for the full mapping. The <code>precedence</code> field controls evaluation order when multiple policies match (<code>0</code> means this policy is evaluated first).</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/rules \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;Block security threats&quot;,
&quot;description&quot;: &quot;Block all default Cloudflare DNS security categories&quot;,
&quot;precedence&quot;: 0,
&quot;enabled&quot;: true,
&quot;action&quot;: &quot;block&quot;,
&quot;filters&quot;: [
  &quot;dns&quot;
],
&quot;traffic&quot;: &quot;any(dns.security_category[*] in {68 178 80 83 176 175 117 131 134 151 153})&quot;,
&quot;identity&quot;: &quot;&quot;
}&#x27;</code></pre>
<pre><code class="language-sh">{
	 &quot;success&quot;: true,
	 &quot;errors&quot;: [],
	 &quot;messages&quot;: []
}
</code></pre>
<p>The API will respond with a summary of the policy and the result of your request.</p>
