<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Traffic policies</strong> &gt; <strong>Traffic settings</strong>.</li>
<li>In <strong>Policy settings</strong>, turn on <strong>Allow egress policy host selectors</strong>.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Use the <a href="/api/resources/zero_trust/subresources/gateway/subresources/configurations/methods/edit/">Patch Zero Trust account configuration</a> endpoint to update your Zero Trust configuration. For example:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request PATCH \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/configuration \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;settings&quot;: {
  &quot;host_selector&quot;: {
    &quot;enabled&quot;: true
  }
}
}&#x27;</code></pre>
