<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In <a href="https://dash.cloudflare.com/one">Zero Trust</a>, go to <strong>Traffic Policies</strong> &gt; <strong>Traffic Settings</strong>.</li>
<li>Under <strong>Proxy and inspection</strong>, find the <strong>Configure time-to-live for DNS resolution</strong> section.</li>
<li>Enter a value in seconds (between 60 and 36,000).</li>
<li>Select <strong>Save</strong>.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<pre><code class="language-sh">curl --request PUT \
  https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/configuration \
  --header &quot;Authorization: Bearer {api_token}&quot; \
  --header &quot;Content-Type: application/json&quot; \
  --data '{
    &quot;settings&quot;: {
      &quot;max_ttl_secs&quot;: 3600
    }
  }'
</code></pre>
<p>To remove the account-level cap (allow upstream TTLs to pass through), omit the <code>max_ttl_secs</code> field or set it to <code>null</code>.</p>
