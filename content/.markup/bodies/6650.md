<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In <a href="https://dash.cloudflare.com/one">Zero Trust</a>, go to <strong>Networks</strong> &gt; <strong>Resolvers &amp; Proxies</strong> &gt; <strong>DNS locations</strong>.</li>
<li>Select a location, or create a new one.</li>
<li>In the <strong>DNS Endpoints</strong> tab, find the <strong>Configure time-to-live for this location</strong> section.</li>
<li>Choose one of:</li>
</ol>
<ul>
<li><strong>Respect account-level setting</strong> - inherits the account-level TTL cap.</li>
<li><strong>Do not set max value</strong> - disables the TTL cap for this location.</li>
<li><strong>Custom</strong> - enter a TTL value in seconds.</li>
</ul>
<ol start="5">
<li>Select <strong>Save</strong>.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<pre><code class="language-sh"># Inherit account-level setting (default)
curl --request PUT \
  https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/locations/{location_id} \
  --header &quot;Authorization: Bearer {api_token}&quot; \
  --header &quot;Content-Type: application/json&quot; \
  --data '{
    &quot;max_ttl&quot;: {
      &quot;mode&quot;: &quot;inherit&quot;
    }
  }'
</code></pre>
<pre><code class="language-sh"># Disable max TTL for this location
curl --request PUT \
  https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/locations/{location_id} \
  --header &quot;Authorization: Bearer {api_token}&quot; \
  --header &quot;Content-Type: application/json&quot; \
  --data '{
    &quot;max_ttl&quot;: {
      &quot;mode&quot;: &quot;disabled&quot;
    }
  }'
</code></pre>
<pre><code class="language-sh"># Override with a custom value
curl --request PUT \
  https://api.cloudflare.com/client/v4/accounts/{account_id}/gateway/locations/{location_id} \
  --header &quot;Authorization: Bearer {api_token}&quot; \
  --header &quot;Content-Type: application/json&quot; \
  --data '{
    &quot;max_ttl&quot;: {
      &quot;mode&quot;: &quot;override&quot;,
      &quot;ttl_secs&quot;: 3600
    }
  }'
</code></pre>
