<p>To enable <strong>Onion Routing</strong> in the dashboard:</p>
<ol>
<li>In the Cloudflare dashboard, go to the <strong>Network</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>For <strong>Onion Routing</strong>, switch the toggle to <strong>On</strong>.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To enable <strong>Onion Routing</strong> with the API, send a <a href="/api/resources/zones/subresources/settings/methods/edit/"><code>PATCH</code></a> request with <code>opportunistic_onion</code> as the setting name in the URI path, and the <code>value</code> parameter set to <code>&quot;on&quot;</code>.</p>
