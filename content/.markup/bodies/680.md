<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<p>To turn off IPv6 compatibility in the dashboard:</p>
<ol>
<li>In the Cloudflare dashboard, go to the <strong>Network</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Turn off <strong>IPv6 Compatibility</strong>.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To turn off IPv6 compatibility using the API, send a <a href="/api/resources/zones/subresources/settings/methods/edit/"><code>PATCH</code></a> request with <code>ipv6</code> as the setting name in the URI path, and the <code>value</code> parameter set to <code>&quot;off&quot;</code>.</p>

</section>
