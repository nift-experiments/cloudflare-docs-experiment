- **Encryption**:

 - AES-GCM-16 with 128-bit or 256-bit key length
 - AES-CBC with 128-bit or 256-bit key length

- **Integrity** (sometimes referred to as Authentication.)

 - SHA2-256
 - SHA-1

<aside class="nb-aside note">


<p>When using AES-GCM-16, you do not need an integrity algorithm because AES GCM includes integrity checking (since it is an Authenticated Encryption with Associated Data (AEAD) algorithm). Even when using an AEAD algorithm, however, some routers still require you to select an integrity algorithm.</p>


</aside>

- **Perfect Forward Secrecy (PFS) group**

Documentation sometimes refers to this as Phase 2 Diffie-Hellman Group. Do not confuse this with PRF. Cloudflare supports the following Diffie-Hellman (DH) groups.

 - DH group 20 (384-bit random ECP group)
 - DH group 14 (2048-bit MODP group)
 - DH group 5 (1536-bit MODP group)

<aside class="nb-aside note">
<h3 class="nb-aside-title" id="body-6801-post-quantum-security">Post-quantum security</h3>


<p>If the Child SA uses DH groups for Perfect Forward Secrecy, it is still protected against quantum threats if the parent IKE SA was established using a hybrid ML-KEM exchange.</p>


</aside>

<aside class="nb-aside caution">


<p>Cloudflare recommends that you use only one DH group when configuring your device, specifically <strong>DH group 20</strong>.</p>


</aside>

<aside class="nb-aside note">


<p>Cloudflare recommends configuring the Child SA rekey interval (SA lifetime) between 30 minutes and 8 hours.</p>


</aside>
