<p>To set up your source IPs, send a <code>PATCH</code> request to the <a href="/api/resources/zero_trust/subresources/networks/subresources/subnets/subresources/cloudflare_source/">Update Cloudflare Source Subnet endpoint</a> with your desired network range. The payload must include the network (your new <code>/12</code> range), and may include a name and comment.</p>
<p>Example:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request PATCH \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/zerotrust/subnets/cloudflare_source/{address_family} \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;comment&quot;: &quot;example_comment&quot;,
&quot;name&quot;: &quot;IPv4 Cloudflare Source IPs&quot;,
&quot;network&quot;: &quot;100.64.0.0/12&quot;
}&#x27;</code></pre>
