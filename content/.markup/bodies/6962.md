<div class="nb-steps">
<ol>
<li>Go to the <strong>Connectors</strong> page.</li>
<li>Select <strong>Add an appliance</strong>.</li>
<li>Choose <strong>Virtual appliance</strong> as the connector type.</li>
</ol>
<p>Unlike a hardware appliance — which requires the serial number printed on the physical device, obtained through your account team — a virtual appliance only needs a name, since Cloudflare generates the license key for you.</p>
<ol start="4">
<li>In <strong>Name</strong>, enter a descriptive name for your virtual appliance.</li>
<li>Select <strong>Generate authentication key</strong>.</li>
<li>Copy the authentication key shown in the dialog. Use it as the license key when you <a href="#configure-a-virtual-machine">configure your virtual machine</a>.</li>
</ol>
</div>
<p>To rotate the key for an existing virtual appliance:</p>
<div class="nb-steps">
<ol>
<li>Go to the <strong>Connectors</strong> page.</li>
<li>Find the connector in the table, select the three dots next to it, then select <strong>Regenerate authentication key</strong>.</li>
<li>Confirm the action. The existing key is immediately and irrevocably revoked, and a new key is generated and shown in the dialog.</li>
</ol>
</div>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<ul>
<li>Create a virtual appliance: <code>POST /accounts/{account_id}/magic/connectors</code> with <code>device.provision_license: true</code>. The response includes <code>result.license_key</code>.</li>
<li>Rotate the license key: <code>PATCH /accounts/{account_id}/magic/connectors/{connector_id}</code> with <code>provision_license: true</code>. The previous key is immediately and irrevocably revoked.</li>
<li>Delete a virtual appliance: deletes the associated licensed device in the same operation.</li>
</ul>
<p>This is also available via Terraform.</p>
