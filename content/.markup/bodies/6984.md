

<aside class="nb-aside note">


<p>You will need your <a href="/fundamentals/account/find-account-and-zone-ids/">account ID</a> and <a href="/fundamentals/api/get-started/account-owned-tokens/">API token</a> to use the API.</p>


</aside>

Create a `POST` request [using the API](/api/resources/magic_transit/subresources/sites/subresources/acls/methods/create/) to create a network policy.

Example:



<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/sites/{site_id}/acls \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;description&quot;: &quot;&lt;POLICY_DESCRIPTION&gt;&quot;,
&quot;forward_locally&quot;: true,
&quot;lan_1&quot;: {
  &quot;lan_id&quot;: &quot;&lt;LAN_ID&gt;&quot;,
  &quot;lan_name&quot;: &quot;&lt;LAN_NAME&gt;&quot;,
  &quot;ports&quot;: [
    1
  ],
  &quot;subnets&quot;: [
    &quot;192.0.2.1&quot;
  ]
},
&quot;lan_2&quot;: {
  &quot;lan_id&quot;: &quot;&lt;LAN_ID&gt;&quot;,
  &quot;lan_name&quot;: &quot;&lt;LAN_NAME&quot;,
  &quot;ports&quot;: [
    1
  ],
  &quot;subnets&quot;: [
    &quot;192.0.2.1&quot;
  ]
},
&quot;name&quot;: &quot;&lt;POLICY_NAME&gt;&quot;,
&quot;protocols&quot;: [
  &quot;tcp&quot;
]
}&#x27;</code></pre>
