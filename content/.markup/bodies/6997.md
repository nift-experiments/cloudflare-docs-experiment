</ol>

</ul>
<ol start="7">

</ol>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Send a <code>POST</code> request to the interrupts endpoint with one of the following actions:</p>
<p><strong>Restart managed services:</strong></p>
<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/connectors/{connector_id}/interrupts&quot; \
--header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \
--header &quot;Content-Type: application/json&quot; \
--data '{&quot;restart&quot;: {&quot;purge&quot;: false}}'
</code></pre>
<p><strong>Reboot (power cycle):</strong></p>
<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/connectors/{connector_id}/interrupts&quot; \
--header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \
--header &quot;Content-Type: application/json&quot; \
--data '{&quot;reboot&quot;: {&quot;purge&quot;: false}}'
</code></pre>
<p><strong>Shut down:</strong></p>
<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/connectors/{connector_id}/interrupts&quot; \
--header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \
--header &quot;Content-Type: application/json&quot; \
--data '{&quot;shutdown&quot;: {&quot;purge&quot;: false}}'
</code></pre>
<p>Set <code>&quot;purge&quot;: true</code> to also purge persistent state.</p>
<p>The response includes a <code>submitted_at</code> timestamp. To check whether the appliance has executed the operation, poll the list endpoint:</p>
<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/connectors/{connector_id}/interrupts&quot; \
--header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot;
</code></pre>
<p>When <code>triggered_at</code> is populated in the response, the appliance has executed the operation.</p>
<aside class="nb-aside note">
<p>Only one operation can be pending at a time. If an operation is already pending, the API returns a <code>409 Conflict</code> response.</p>
</aside>
