<li>Go to the <strong>Appliances</strong> tab &gt; <strong>Profiles</strong>.</li>
<li>Select your Cloudflare One Appliance &gt; <strong>Edit</strong>.</li>
<li>Select <strong>Network Configuration</strong>.</li>
<li>In <strong>LAN configuration</strong>, select the LAN where you need to configure DHCP relay.</li>
<li>Select <strong>Edit</strong>.</li>
<li>Select <strong>This is a DHCP Relay</strong>.</li>
<li>In <strong>Upstream DHCP server addresses</strong>, enter the IP address of your DHCP server.</li>
<li>(Optional) If you need to add more DHCP server addresses, select <strong>Add upstream DHCP server address</strong> as many times as needed, and enter the new values.</li>
</ol>

<aside class="nb-aside note">
<p>You will need your <a href="/fundamentals/account/find-account-and-zone-ids/">account ID</a> and <a href="/fundamentals/api/get-started/account-owned-tokens/">API token</a> to use the API.</p>
</aside>
<p>Create a <a href="/api/resources/magic_transit/subresources/sites/subresources/lans/methods/update/"><code>PUT</code> request</a> to update the LAN where you want to enable DHCP relay:</p>
<p>Example:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request PUT \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/sites/{site_id}/lans/{lan_id} \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;lan&quot;: {
  &quot;static_addressing&quot;: {
    &quot;dhcp_relay&quot;: {
      &quot;server_addresses&quot;: [
        &quot;192.0.2.1&quot;
      ]
    }
  }
}
}&#x27;</code></pre>
