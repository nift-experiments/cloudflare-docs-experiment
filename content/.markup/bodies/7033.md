<p>You can also configure DHCP options via the API and Terraform using the <code>dhcp_options</code> field on the LAN's <code>dhcp_server</code> configuration. Create a <a href="/api/resources/magic_transit/subresources/sites/subresources/lans/methods/update/"><code>PUT</code> request</a> to update the LAN where you want to configure DHCP options:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request PUT \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/sites/{site_id}/lans/{lan_id} \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;lan&quot;: {
  &quot;static_addressing&quot;: {
    &quot;dhcp_server&quot;: {
      &quot;dhcp_options&quot;: [
        {
          &quot;code&quot;: 67,
          &quot;type&quot;: &quot;text&quot;,
          &quot;value&quot;: &quot;boot/x64/pxelinux.0&quot;
        }
      ]
    }
  }
}
}&#x27;</code></pre>
