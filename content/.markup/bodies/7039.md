<li>Go to the <strong>Appliances</strong> tab &gt; <strong>Profiles</strong>.</li>
<li>Select the Cloudflare One Appliance you want to configure &gt; <strong>Edit</strong>.</li>
<li>Select <strong>Traffic Steering</strong>.</li>
<li>In <strong>Prioritized traffic</strong>, select <strong>Assign application traffic</strong>.</li>
<li>In <strong>Custom applications</strong>, select <strong>Add</strong> to create a new custom application, and enter:</li>
</ol>
<ul>
<li><strong>Name</strong> — a display name for the application.</li>
<li><strong>Category</strong> — an optional group label, such as <code>Productivity</code> or <code>Video conferencing</code>.</li>
<li>At least one of <strong>Hostnames</strong>, <strong>IP subnets</strong>, or <strong>Source subnets</strong> — the traffic that identifies this application. Hostnames must be valid FQDNs (for example <code>auth.example.com</code>). IP subnets and source subnets must be valid IPv4 CIDRs (for example <code>10.0.0.0/24</code>). A single address needs a <code>/32</code> suffix. IPv6 is not yet supported.</li>
</ul>
<ol start="7">
<li>Select <strong>Add application</strong>.</li>
<li>To change or remove an existing custom application, select the <strong>three dots</strong> next to it in the <strong>Custom applications</strong> table, then <strong>Edit</strong> or <strong>Delete</strong>.</li>
</ol>

<p>Send a <code>POST</code> request to create a custom application in your account. The following example uses all three optional match criteria:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/apps \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;Example application&quot;,
&quot;type&quot;: &quot;Productivity&quot;,
&quot;hostnames&quot;: [
  &quot;auth.example.com&quot;
],
&quot;ip_subnets&quot;: [
  &quot;192.0.2.0/24&quot;
],
&quot;source_subnets&quot;: [
  &quot;10.0.0.0/24&quot;
]
}&#x27;</code></pre>
<pre><code class="language-json">{
	&quot;result&quot;: {
		&quot;account_app_id&quot;: &quot;eb09v665c0784618a3e4ba9809258fd4&quot;,
		&quot;name&quot;: &quot;Example application&quot;,
		&quot;type&quot;: &quot;Productivity&quot;,
		&quot;hostnames&quot;: [&quot;auth.example.com&quot;],
		&quot;ip_subnets&quot;: [&quot;192.0.2.0/24&quot;],
		&quot;source_subnets&quot;: [&quot;10.0.0.0/24&quot;]
	},
	&quot;success&quot;: true,
	&quot;errors&quot;: [],
	&quot;messages&quot;: []
}
</code></pre>
<p>You can now add this new app to the Prioritized traffic list in your Cloudflare One Appliance.</p>
