<aside class="nb-aside note">
<p>You will need your <a href="/fundamentals/account/find-account-and-zone-ids/">account ID</a> and <a href="/fundamentals/api/get-started/account-owned-tokens/">API token</a> to use the API.</p>
</aside>
<p>You need to delete Prioritized traffic applications for each of your existing sites, as this is a per-site configuration.</p>
<ol>
<li>Send a <a href="/api/resources/magic_transit/subresources/apps/methods/list/"><code>GET</code> request</a> to list the applications associated with a site.</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request GET \
 --url https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/sites/{site_id}/app_configs \
 --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;</code></pre>
<pre><code class="language-json">	{
		&quot;result&quot;: [
			{
				&quot;id&quot;: &quot;&lt;APP_ID&gt;&quot;,
				&quot;site_id&quot;: &quot;&lt;SITE_ID&gt;&quot;,
				&quot;managed_app_id&quot;: &quot;&lt;APP_NAME&gt;&quot;,
				&quot;breakout&quot;: true
			}
		]
	}
</code></pre>
<p>Take note of the <code>&quot;id&quot;</code> value for the application that you want to delete.</p>
<ol start="2">
<li>Send a <code>DELETE</code> request to delete an application from the Prioritized traffic policy.</li>
</ol>
<pre><code class="language-bash">curl --request DELETE --url https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/sites/{site_id}/app_configs/{id}</code></pre>
<pre><code class="language-json">{
		&quot;result&quot;: {
				&quot;id&quot;: &quot;&lt;APP_ID&gt;&quot;,
				&quot;site_id&quot;: &quot;&lt;SITE_ID&gt;&quot;,
				&quot;managed_app_id&quot;: &quot;&lt;APP_NAME&gt;&quot;,
				&quot;breakout&quot;: true
		},
		&quot;success&quot;: true,
		&quot;errors&quot;: [],
		&quot;messages&quot;: []
}
</code></pre>
