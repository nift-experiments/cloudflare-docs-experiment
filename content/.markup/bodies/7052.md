

Send a `POST` request to create a custom application in your account. The following example uses all three optional match criteria:



<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/apps \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;Example application&quot;,
&quot;type&quot;: &quot;Productivity&quot;,
&quot;hostnames&quot;: [
  &quot;auth.example.com&quot;
],
&quot;ip_subnets&quot;: [
  &quot;192.0.2.0/24&quot;
],
&quot;source_subnets&quot;: [
  &quot;10.0.0.0/24&quot;
]
}&#x27;</code></pre>



```json output
{
	"result": {
		"account_app_id": "eb09v665c0784618a3e4ba9809258fd4",
		"name": "Example application",
		"type": "Productivity",
		"hostnames": ["auth.example.com"],
		"ip_subnets": ["192.0.2.0/24"],
		"source_subnets": ["10.0.0.0/24"]
	},
	"success": true,
	"errors": [],
	"messages": []
}
```

You can now add this new app to the Breakout traffic list in your Cloudflare One Appliance.
