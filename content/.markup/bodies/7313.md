

1. Create a `schemas/schema.sql` file with the following contents:

<pre><code class="language-sql">DROP TABLE IF EXISTS comments;
CREATE TABLE IF NOT EXISTS comments (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  author TEXT NOT NULL,
  body TEXT NOT NULL,
  post_slug TEXT NOT NULL
);
CREATE INDEX idx_comments_post_slug ON comments (post_slug);

&#45;- Optionally, uncomment the below query to insert seed data
&#45;- INSERT INTO comments (author, body, post_slug) VALUES (&#x27;Kristian&#x27;, &#x27;Great post!&#x27;, &#x27;hello-world&#x27;);
</code></pre>


2. Run the schema against your local database first:

<pre><code class="language-sh">npx wrangler d1 execute d1-comments-api --local --file schemas/schema.sql
</code></pre>


3. Verify the table was created locally:

<pre><code class="language-sh">npx wrangler d1 execute d1-comments-api --local --command &quot;SELECT name FROM sqlite_schema WHERE type = &#x27;table&#x27;&quot;
</code></pre>


<pre><code class="language-txt">┌──────────┐
│ name     │
├──────────┤
│ comments │
└──────────┘
</code></pre>


4. Once you are satisfied with the schema, apply it to your remote (production) database:

<pre><code class="language-sh">npx wrangler d1 execute d1-comments-api --remote --file schemas/schema.sql
</code></pre>
