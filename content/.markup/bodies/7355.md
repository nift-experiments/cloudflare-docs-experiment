<h3 class="nb-aside-title" id="body-7355-retry-operations">Retry operations</h3>


<p>While some D1 errors can be resolved by retrying the operation, retrying is only safe if your query is idempotent (produces the same result when executed multiple times).</p>
<p>Before retrying any failed operation:</p>
<ul>
<li>Verify your query is idempotent (for example, read-only operations, or queries such as <code>CREATE TABLE IF NOT EXISTS</code>).</li>
<li>Consider <a href="/d1/best-practices/retry-queries/">implementing application-level checks</a> to identify if the operation can be retried, and retrying only when it is safe and necessary.</li>
</ul>
