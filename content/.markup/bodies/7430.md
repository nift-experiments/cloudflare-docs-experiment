

Here is an example request using cURL to set regions:



<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/logs/control/cmb/config \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;regions&quot;: &quot;eu&quot;,
&quot;allow_out_of_region_access&quot;: false
}&#x27;</code></pre>



This will overwrite any previous regions.
Change will be in effect after several minutes.
