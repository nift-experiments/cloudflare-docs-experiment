
1. In the Cloudflare dashboard, go to the [Network analytics](https://dash.cloudflare.com/?to=/:account/networking-insights/analytics/network-analytics/transport-analytics) page.
2. Apply filters to the displayed data.

<details class="nb-details"><summary>For WAF/CDN customers</summary><div class="nb-details-body">

<ol>
<li>Select the zone that is experiencing an incomplete mitigation of a DDoS attack.</li>
<li>Go to <strong>Security</strong> &gt; <strong>Analytics</strong> &gt; <strong>Events</strong> tab.</li>
<li>Select <strong>Add filter</strong> and filter by <code>Service equals HTTP DDoS</code>.</li>
</ol>

</div></details>

<details class="nb-details"><summary>For Magic Transit and Spectrum customers</summary><div class="nb-details-body">

<ol>
<li>Go to Account Home &gt; <strong>Analytics &amp; Logs</strong> &gt; <strong>Network Analytics</strong>.</li>
<li>Identify the DDoS attack that is having incomplete mitigations. Use the Attack ID number included in the DDoS alert (if you received one), or apply dashboard filters such as destination IP address and port.</li>
</ol>

</div></details>

3. Scroll down to **Top events by source** > **HTTP DDoS rules**.
4. Copy the rule name.
5. Go to your zone > **Security** > **Security rules** > **DDoS protection** tab and select **Create override**. If you cannot deploy any additional overrides, edit an existing override to adjust rule configuration.
6. Select **Browse rules** and paste the rule name in the search field.
7. Change the rule's **Action** to _Block_.
8. Select **Next** and then select **Save**.
