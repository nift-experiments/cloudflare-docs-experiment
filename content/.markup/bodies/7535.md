
1. Enter a descriptive name for the override in **Override name**.
2. If you are an Enterprise customer with the Advanced DDoS Protection subscription:
	1. Under **Override scope**, review the scope of the override — by default, all incoming requests for the current zone.
	2. If necessary, select **Edit scope** and configure the [custom filter expression](/ddos-protection/managed-rulesets/http/http-overrides/override-expressions/) that will determine the override scope.
3. Depending on what you wish to override, refer to the following sections (you can perform both configurations on the same override):

<details class="nb-details"><summary>Configure all the rules in the ruleset (ruleset override)</summary><div class="nb-details-body">

<ol start="4">
<li>To always apply a given action for all the rules in the ruleset, select an action in <strong>Ruleset action</strong>.</li>
<li>To set the sensitivity level for all the rules in the ruleset, select a value in <strong>Ruleset sensitivity</strong>.</li>
</ol>

</div></details>

<details class="nb-details"><summary>Configure one or more rules</summary><div class="nb-details-body">

<ol start="4">
<li>Under <strong>Rule configuration</strong>, select <strong>Browse rules</strong>.</li>
<li>Search for the rules you wish to configure using the available filters. You can search by <a href="/ddos-protection/managed-rulesets/http/rule-categories/">tag</a> (also known as category).</li>
<li>To configure a single rule, select the desired value for a field in the displayed dropdowns next to the rule.</li>
</ol>
<p>To configure more than one rule, select the rules using the row checkboxes and update the fields for the selected rules using the dropdowns displayed before the table. You can also configure all the rules with a given tag. For more information, refer to <a href="/waf/managed-rules/deploy-zone-dashboard/#configure-a-managed-ruleset">Configure a managed ruleset</a>.
7. Select <strong>Next</strong>.</p>

</div></details>
