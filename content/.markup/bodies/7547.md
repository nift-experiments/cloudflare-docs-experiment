
1. In the Cloudflare dashboard, go to the **L3/4 DDoS protection** page.

<div class="nb-dash-button"></div>
2. Go to **Network-layer DDoS Protection**.
3. Select **Deploy a DDoS override**.
4. In **Set scope**, specify if you wish to apply the override to all incoming packets or to a subset of the packets.
5. If you are creating an override for a subset of the incoming packets, define the [custom expression](/ddos-protection/managed-rulesets/network/network-overrides/override-expressions/) that matches the incoming packets you wish to target in the override, using either the Rule Builder or the Expression Editor.
6. Select **Next**.
7. Depending on what you wish to override, refer to the following sections (you can perform both configurations on the same override):
<details class="nb-details"><summary>Configure all the rules in the ruleset (ruleset override)</summary><div class="nb-details-body">

<ol start="8">
<li>Select <strong>Next</strong>.</li>
<li>Enter a name for your override in <strong>Execution name</strong>.</li>
<li>To always apply a given action for all the rules in the ruleset, select an action in <strong>Ruleset action</strong>.</li>
<li>To set the sensitivity level for all the rules in the ruleset, select a value in <strong>Ruleset sensitivity</strong>.</li>
</ol>

</div></details>
<details class="nb-details"><summary>Configure one or more rules</summary><div class="nb-details-body">

<ol start="12">
<li>Search for the rules you wish to override using the available filters. You can search for tags.</li>
<li>To override a single rule, select the desired value for a field in the displayed dropdowns next to the rule.</li>
</ol>
<p>To configure more than one rule, select the rules using the row checkboxes and update the fields for the selected rules using the dropdowns displayed before the table. You can also configure all the rules with a given tag. For more information, refer to <a href="/waf/managed-rules/deploy-zone-dashboard/#configure-a-managed-ruleset">Configure a managed ruleset</a>.
14. Select <strong>Next</strong>.
15. Enter a name for your override in <strong>Execution name</strong>.</p>

</div></details>

<aside class="nb-aside note">
<h3 class="nb-aside-title" id="body-7547-notes">Notes</h3>


<ul>
<li>Tag and rule overrides have priority over ruleset overrides.</li>
<li></li>
</ul>
<p>The managed ruleset includes some read-only rules that you cannot override.</p>


</aside>
8. To save and deploy the override, select **Deploy**. If you are not ready to deploy your override, select **Save as Draft**.
