<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the Cloudflare dashboard, go to the <strong>DNS Records</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select <strong>Add record</strong> or select <strong>Edit</strong> on an existing <code>A</code> or <code>AAAA</code> record.</li>
<li>Enter the origin IP address.</li>
<li>Verify that <strong>Proxy status</strong> is enabled (orange cloud).</li>
<li>Turn on <strong>Use private network routing</strong>.</li>
</ol>
<p>For <a href="#ip-ranges">private IP addresses</a> (for example, <code>10.0.0.50</code>), the toggle turns on automatically. For public IP addresses used with private infrastructure, turn on the toggle manually.</p>
<ol start="6">
<li>Select <strong>Save</strong>.</li>
</ol>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To create a record with private routing enabled, use a <a href="/api/resources/dns/subresources/records/methods/create/">POST request</a> and set <code>private_routing</code> to <code>true</code>:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/dns_records \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;type&quot;: &quot;A&quot;,
&quot;name&quot;: &quot;app.example.com&quot;,
&quot;content&quot;: &quot;10.0.0.50&quot;,
&quot;proxied&quot;: true,
&quot;private_routing&quot;: true
}&#x27;</code></pre>
<p>To enable private routing on an existing record, use a <a href="/api/resources/dns/subresources/records/methods/edit/">PATCH request</a>:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request PATCH \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/dns_records/{dns_record_id} \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;private_routing&quot;: true
}&#x27;</code></pre>

</section>
