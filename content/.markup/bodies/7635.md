<p>When creating a token for Internal DNS, we recommend scoping it to specific internal zones rather than using &quot;All zones&quot;. This follows the principle of least privilege. If you create new internal zones later, you will need to update the token scope to include them. Support for automatic zone-type scoping (for example, &quot;all internal zones&quot;) is planned for a future release.</p>
