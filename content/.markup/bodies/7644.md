

1. Use the [Update DNS settings](/api/resources/dns/subresources/settings/subresources/zone/methods/edit/) endpoint to add a reference from an internal zone to another internal zone. In `--json`, specify the `internal_dns` object with the parameter `reference_zone_id`.

<div class="nb-example"><h3 class="nb-component-title" id="body-7644-example">Example</h3>

<p>In the following example, internal zone A (ID <code>8a904aeb565c42cfa207d98f6edea2f3</code>) is referencing internal zone B (ID <code>8e64c6fb4b514f3faf64de81efc11e51</code>).</p>
<pre class="nb-api-request"><code class="language-bash">curl --request PATCH \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/dns_settings \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;internal_dns&quot;: {
  &quot;reference_zone_id&quot;: &quot;8e64c6fb4b514f3faf64de81efc11e51&quot;
}
}&#x27;</code></pre>

</div>
