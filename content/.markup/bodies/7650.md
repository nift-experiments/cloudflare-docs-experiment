<ol>
<li>In the Cloudflare dashboard, go to the <strong>Internal DNS</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Go to <strong>Internal DNS Views</strong>.</li>
<li>Select <strong>Create a view</strong>.</li>
<li>Give your view a descriptive name.</li>
</ol>
<details class="nb-details"><summary>DNS view configuration conditions</summary><div class="nb-details-body">
<ul>
<li>DNS views can be empty, with no <a href="/dns/internal-dns/internal-zones/">internal zones</a> linked to them.</li>
<li>A DNS view cannot contain public DNS zones.<sup>1</sup></li>
<li>Each internal DNS zone name must be unique within a given DNS view.</li>
<li>Each DNS view name must be unique within a given Cloudflare account.</li>
</ul>
<p><sup>1</sup> DNS zones that contain public DNS records and are accessible by public resolvers.</p>
</div></details>
<ol start="5">
<li>Select <strong>Manage zones</strong> to add zones to your view. Select the internal zones that should be used to resolve queries sent by Gateway resolver to this view.</li>
<li>Choose <strong>Save</strong> to confirm.</li>
</ol>
