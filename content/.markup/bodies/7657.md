<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the Cloudflare dashboard, go to the <strong>Internal DNS</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>
<p>Go to <strong>Internal DNS Views</strong>.</p>
</li>
<li>
<p>Select <strong>Create a view</strong>.</p>
</li>
<li>
<p>Give your view a descriptive name.</p>
</li>
<li>
<p>Select <strong>Manage zones</strong> to add zones to your view. Select the internal zones that should be used to resolve queries sent by Gateway resolver to this view.</p>
</li>
<li>
<p>Choose <strong>Save</strong> to confirm.</p>
</li>
</ol>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Use the <a href="/api/resources/dns/subresources/settings/subresources/account/subresources/views/methods/create/">Create Internal DNS View</a> endpoint. For each view you create, list all the internal zones that should be grouped under that view.</p>
<aside class="nb-aside note">
<p>DNS views are managed at the account level. Make sure your API token includes <strong>Account</strong> &gt; <strong>DNS Views</strong> &gt; <strong>Edit</strong> permission.</p>
</aside>

</section>
