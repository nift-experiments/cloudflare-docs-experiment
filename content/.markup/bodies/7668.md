

 Use the [Update DNS Settings](/api/resources/dns/subresources/settings/subresources/zone/methods/edit/) endpoint to send a PATCH request like the following:



<pre class="nb-api-request"><code class="language-bash">curl --request PATCH \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/dns_settings \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;nameservers&quot;: {
  &quot;type&quot;: &quot;cloudflare.advanced&quot;
}
}&#x27;</code></pre>



 The response body will contain your assigned nameservers in the `nameservers` object. You will use these nameservers in the next step.
