</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Use the <a href="/api/resources/dns/subresources/settings/subresources/zone/methods/edit/">Update DNS Settings</a> endpoint to send a PATCH request like the following:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request PATCH \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/dns_settings \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;nameservers&quot;: {
  &quot;type&quot;: &quot;cloudflare.advanced&quot;
}
}&#x27;</code></pre>
<p>The response body will contain your assigned nameservers in the <code>nameservers</code> object. You will use these nameservers in the next step.</p>
