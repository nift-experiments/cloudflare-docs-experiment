<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the Cloudflare dashboard, go to the <strong>DNS Firewall Clusters</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select <strong>Add Firewall Cluster</strong>.</li>
<li>Fill out the required fields, including:</li>
</ol>
<ul>
<li><strong>IP Addresses</strong>: The upstream IPv4 and/or IPv6 addresses of your authoritative nameservers.</li>
<li><strong>Minimum Cache TTL</strong>: Recommended setting of <strong>30 seconds</strong>.</li>
<li><strong>Maximum Cache TTL</strong>: Recommended setting of <strong>4 hours</strong>. Larger values increase the cache hit ratio, but also increase the time required for DNS changes to propagate.</li>
<li><strong>ANY queries</strong>: Recommended setting is <strong>Off</strong> because these are often used as part of DDoS attacks. Also refer to this <a href="https://blog.cloudflare.com/rfc8482-saying-goodbye-to-any/">blog post</a>.</li>
</ul>
<ol start="4">
<li>Optionally, configure any of the <a href="#additional-options">additional options</a> available on the same form.</li>
<li>Select <strong>Continue</strong>.</li>
<li>On the following screen, save the values for <strong>Your new DNS Firewall IP Addresses</strong>.</li>
</ol>
<aside class="nb-aside note">
<h3 class="nb-aside-title" id="body-7701-note">Note:</h3>
<p>If you forget to save your new IP addresses, find your cluster and click <strong>IP Addresses</strong>.</p>
<p>If you delete your cluster, the assigned set of IPs will be lost. If you recreate the cluster you will get a different set of IPs.</p>
</aside>
