

1. On the [**DNS Settings**](https://dash.cloudflare.com/?to=/:account/:zone/dns/settings) page, make sure that **CNAME flattening for all CNAME records** is turned off.
2. Go to the [**DNS Records**](https://dash.cloudflare.com/?to=/:account/:zone/dns/records) page and find the CNAME record you would like to flatten.
3. Select **Edit** and turn on the **Flatten** option.
4. Select **Save** to confirm.

<aside class="nb-aside note">
<h3 class="nb-aside-title" id="body-7714-unavailable-flatten-option">Unavailable flatten option</h3>


<p>For the following cases, <strong>Flatten</strong> will not be available:</p>
<ul>
<li>The record is at the <a href="#for-your-zone-apex">zone apex</a>.</li>
<li>The record is already proxied, which means it will be flattened by default.</li>
<li><strong>CNAME flattening for all CNAME records</strong> is turned on, which means you cannot override it per record.</li>
</ul>


</aside>
