<ol>
<li>On the <a href="https://dash.cloudflare.com/?to=/:account/:zone/dns/settings"><strong>DNS Settings</strong></a> page, make sure that <strong>CNAME flattening for all CNAME records</strong> is turned off.</li>
<li>Go to the <a href="https://dash.cloudflare.com/?to=/:account/:zone/dns/records"><strong>DNS Records</strong></a> page and find the CNAME record you would like to flatten.</li>
<li>Select <strong>Edit</strong> and turn on the <strong>Flatten</strong> option.</li>
<li>Select <strong>Save</strong> to confirm.</li>
</ol>
<aside class="nb-aside note">
<h3 class="nb-aside-title" id="body-7716-unavailable-flatten-option">Unavailable flatten option</h3>
<p>For the following cases, <strong>Flatten</strong> will not be available:</p>
<ul>
<li>The record is at the <a href="#for-your-zone-apex">zone apex</a>.</li>
<li>The record is already proxied, which means it will be flattened by default.</li>
<li><strong>CNAME flattening for all CNAME records</strong> is turned on, which means you cannot override it per record.</li>
</ul>
</aside>
