<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the Cloudflare dashboard, go to the <strong>DNS Firewall Clusters</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select the cluster you want to update, then select <strong>Edit</strong>.</li>
<li>Turn on <strong>Attack mitigation</strong> and choose whether Cloudflare should only mitigate attacks when the upstream is unhealthy.</li>
<li>Select <strong>Save</strong>.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Send a <a href="/api/resources/dns_firewall/methods/edit/"><code>PATCH</code> request</a> to update your DNS Firewall cluster:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request PATCH \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/dns_firewall/{dns_firewall_id} \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;attack_mitigation&quot;: {
  &quot;enabled&quot;: true,
  &quot;only_when_upstream_unhealthy&quot;: true
}
}&#x27;</code></pre>
