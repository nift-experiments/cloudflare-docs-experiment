<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the Cloudflare dashboard, go to the <strong>Internal DNS</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>
<p>Select <strong>Create an internal zone</strong>.</p>
</li>
<li>
<p>Give your internal zone a name.</p>
</li>
<li>
<p>Add DNS records to your internal zone using your preferred option:</p>
</li>
</ol>
<ul>
<li><a href="/dns/manage-dns-records/how-to/import-and-export/">Import</a> a formatted BIND file.</li>
<li>Select <strong>Add a record</strong> and choose <strong>Create</strong> under the record type you want to add. Refer to <a href="/dns/manage-dns-records/reference/dns-record-types/">DNS record types</a> for details.</li>
</ul>
<ol start="5">
<li>Repeat this process for each internal zone you wish to add.</li>
</ol>
<aside class="nb-aside note">
<p>Creating multiple internal DNS records in batch is currently only supported via API.</p>
</aside>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<ol>
<li>Use the <a href="/api/resources/zones/methods/create/">Create Zone</a> endpoint to create an <a href="/dns/internal-dns/internal-zones/">internal zone</a>. Specify your account ID and set the <code>type</code> to <code>internal</code>.</li>
</ol>
<details class="nb-details"><summary>Example</summary><div class="nb-details-body">
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/zones \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;account&quot;: {
  &quot;id&quot;: &quot;&lt;ACCOUNT_ID&gt;&quot;
},
&quot;name&quot;: &quot;&lt;ZONE_NAME&gt;&quot;,
&quot;type&quot;: &quot;internal&quot;
}&#x27;</code></pre>
</div></details>
<ol start="2">
<li>Add DNS records to your internal zone using your preferred option:</li>
</ol>
<ul>
<li><a href="/api/resources/dns/subresources/records/methods/import/">Import</a> a formatted BIND file. Refer to the <a href="/dns/manage-dns-records/how-to/import-and-export/">DNS records how-to</a> for guidance.</li>
<li>Use other API endpoints, such as <a href="/api/resources/dns/subresources/records/methods/batch/"><code>/batch</code></a>, to manage DNS records. Refer to <a href="/dns/manage-dns-records/how-to/batch-record-changes/#use-the-api">Batch record changes</a> for details.</li>
</ul>
<ol start="3">
<li>Repeat this process for each internal zone you wish to add.</li>
</ol>

</section>
