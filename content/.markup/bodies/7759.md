<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the Cloudflare dashboard, go to the <strong>Internal DNS</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select a zone.</li>
<li>Within the selected zone, go to <strong>Reference zone</strong>.</li>
<li>Select <strong>Add reference zone</strong>. If your zone already has a reference zone set up, you must first remove it. As explained in the <a href="#configuration-conditions">configuration conditions</a>, each internal zone can only reference one other zone at a time.</li>
<li>Find the zone you want to use as reference and choose <strong>Select</strong> in the respective row.</li>
</ol>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Use the <a href="/api/resources/dns/subresources/settings/subresources/zone/methods/edit/">Update DNS settings</a> endpoint. In <code>--json</code>, specify the <code>internal_dns</code> object with the parameter <code>reference_zone_id</code>.</p>
<aside class="nb-aside note">
<p>If your API token is scoped to specific zones, make sure it includes both the zone you are updating and the zone you are referencing.</p>
</aside>
<div class="nb-example"><h3 class="nb-component-title" id="body-7759-example">Example</h3>
<p>In the following example, internal zone A (ID <code>8a904aeb565c42cfa207d98f6edea2f3</code>) is referencing internal zone B (ID <code>8e64c6fb4b514f3faf64de81efc11e51</code>).</p>
<pre class="nb-api-request"><code class="language-bash">curl --request PATCH \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/dns_settings \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;internal_dns&quot;: {
  &quot;reference_zone_id&quot;: &quot;8e64c6fb4b514f3faf64de81efc11e51&quot;
}
}&#x27;</code></pre>
<p>A third zone (C) could also point to zone B as a reference, but zone A cannot add another zone as a reference while also having zone B configured as its reference zone.</p>
</div>
