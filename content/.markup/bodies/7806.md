

For Cloudflare to serve a manually-added HTTPS record, every record with the same name must be DNS-only (grey cloud).

<div class="nb-example"><h3 class="nb-component-title" id="body-7806-example">Example</h3>

<p><strong>Will work</strong> — All records with the same name are DNS-only:</p>
<table>
<thead>
<tr>
<th>Type</th>
<th>Name</th>
<th>Content</th>
<th>Proxy status</th>
</tr>
</thead>
<tbody>
<tr>
<td>A</td>
<td>example.com</td>
<td><code>192.0.2.1</code></td>
<td>DNS only</td>
</tr>
<tr>
<td>HTTPS</td>
<td>example.com</td>
<td><code>1 . alpn=&quot;h3&quot;</code></td>
<td>-</td>
</tr>
</tbody>
</table>
<p>The HTTPS record will be served because the A record is DNS-only.</p>

</div>

<div class="nb-example"><h3 class="nb-component-title" id="body-7806-example-1">Example</h3>

<p><strong>Will not work</strong> — Mixed proxy status for the same name:</p>
<table>
<thead>
<tr>
<th>Type</th>
<th>Name</th>
<th>Content</th>
<th>Proxy status</th>
</tr>
</thead>
<tbody>
<tr>
<td>AAAA</td>
<td>example.com</td>
<td><code>2001:db8::1</code></td>
<td>Proxied</td>
</tr>
<tr>
<td>HTTPS</td>
<td>example.com</td>
<td><code>1 . alpn=&quot;h3&quot;</code></td>
<td>-</td>
</tr>
</tbody>
</table>
<p>The HTTPS record will <strong>not</strong> be served because the AAAA record with the same name is proxied.</p>

</div>
