<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<p>To import a zone file using the dashboard:</p>
<ol>
<li>In the Cloudflare dashboard, go to the <strong>DNS Records</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select <strong>Import and Export</strong>.</li>
<li>For <strong>Import DNS records</strong>, select your <a href="#format-your-zone-file">formatted file</a>.</li>
<li>If you do not want <a href="/dns/proxy-status/">applicable records</a> proxied, unselect <strong>Proxy imported DNS records</strong>.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To import records using the API, send a <a href="/api/resources/dns/subresources/records/methods/import/">POST request</a> with a properly <a href="#format-your-zone-file">formatted file</a>.</p>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/dns_records/import \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--form &#x27;file=@your_formatted_file.txt&#x27;</code></pre>

</section>
