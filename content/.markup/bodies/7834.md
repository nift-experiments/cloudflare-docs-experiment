
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the Cloudflare dashboard, go to the <strong>DNS Records</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select <strong>Add record</strong>.</li>
<li>Select <code>A</code>, <code>AAAA</code>, or <code>CNAME</code> as the record <strong>Type</strong>, according to your needs:</li>
</ol>
<ul>
<li>To point to an IPv4 address, select <code>A</code>, use your zone apex (<code>@</code>) for the record <strong>Name</strong>, and insert the IPv4 address in the respective field.</li>
<li>To point to an IPv6 address, select <code>AAAA</code>, use your zone apex (<code>@</code>) for the record <strong>Name</strong>, and insert the IPv6 address in the respective field.</li>
<li>To point to a <a href="https://en.wikipedia.org/wiki/Fully_qualified_domain_name">fully qualified domain name (FQDN)</a> (such as <code>your-site.host.example.com</code>), select <code>CNAME</code>, use your zone apex (<code>@</code>) for the record <strong>Name</strong>, and insert the fully qualified domain name in the <strong>Target</strong> field.</li>
</ul>
<ol start="4">
<li>Specify the <span class="nb-glossary-tooltip" title="proxy status"><strong>Proxy status</strong></span> and <span class="nb-glossary-tooltip" title="time-to-live (TTL)"><strong>TTL</strong></span> according to your needs.</li>
<li>Select <strong>Save</strong> to confirm.</li>
</ol>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Use the <a href="/api/resources/dns/subresources/records/methods/create/">Create DNS Record API endpoint</a>.</p>
<p>For field definitions, refer to the <a href="/api/resources/dns/subresources/records/methods/create/">API documentation</a> (visible once you select the record type under the request body specification).</p>
<ul>
<li>To point to an IPv4 address, select <strong>A Record</strong>, use your zone apex (<code>@</code>) for the field <code>name</code>, and use the IPv4 address for the field <code>content</code>.</li>
<li>To point to an IPv6 address, select <strong>AAAA Record</strong>, use your zone apex (<code>@</code>) for the field <code>name</code>, and use the IPv6 address for the field <code>content</code>.</li>
<li>To point to a <a href="https://en.wikipedia.org/wiki/Fully_qualified_domain_name">fully qualified domain name (FQDN)</a> (such as <code>your-site.host.example.com</code>), select <strong>CNAME Record</strong>, use your zone apex (<code>@</code>) for the field <code>name</code>, and use the fully qualified domain name for the field <code>content</code>.</li>
</ul>

</section>
