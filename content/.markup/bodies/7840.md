
Use the [Create DNS Record API endpoint](/api/resources/dns/subresources/records/methods/create/).

For field definitions, refer to the [API documentation](/api/resources/dns/subresources/records/methods/create/) (visible once you select the record type under the request body specification).

- To point to an IPv4 address, select **A Record**, use your subdomain (<code>blog</code>) for the field `name`, and use the IPv4 address for the field `content`.
- To point to an IPv6 address, select **AAAA Record**, use your subdomain (<code>blog</code>) for the field `name`, and use the IPv6 address for the field `content`.
- To point to a [fully qualified domain name (FQDN)](https://en.wikipedia.org/wiki/Fully_qualified_domain_name) (such as `your-site.host.example.com`), select **CNAME Record**, use your subdomain (<code>blog</code>) for the field `name`, and use the fully qualified domain name for the field `content`.
