<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<p>To create a DNS record in the dashboard:</p>
<ol>
<li>In the Cloudflare dashboard, go to the <strong>DNS Records</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select <strong>Add record</strong>.</li>
<li>Choose a record <a href="/dns/manage-dns-records/reference/dns-record-types/"><strong>Type</strong></a>.</li>
<li>Complete the required fields, which vary per record. Particularly important fields (for some records) include:</li>
</ol>
<ul>
<li><strong>Proxy status</strong>: For <code>A</code>, <code>AAAA</code>, and <code>CNAME</code> records, decide whether hostname traffic is <span class="nb-glossary-tooltip" title="proxy status">proxied through Cloudflare</span>.</li>
<li><strong>TTL</strong>: Short for <a href="/dns/manage-dns-records/reference/ttl/"><em>Time to Live</em></a>, this field controls how long each record is valid and — as a result — how long it takes for record updates to reach your end users.</li>
<li><strong>Comment</strong> and <strong>Tag</strong>: <a href="/dns/manage-dns-records/reference/record-attributes/">Record attributes</a> meant for your reference.</li>
<li><strong>Private network routing</strong>: Some Enterprise customers also have access to <a href="/dns/private-origins/private-network-routing/">private network routing</a>. For <code>A</code> and <code>AAAA</code> records, this feature allows you to proxy HTTP/HTTPS traffic from public hostnames to origins in your private network.</li>
</ul>
<ol start="5">
<li>Select <strong>Save</strong>.</li>
</ol>

</section>
