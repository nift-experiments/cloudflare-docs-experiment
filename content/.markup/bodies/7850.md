<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<p>To edit DNS records in the dashboard:</p>
<ol>
<li>In the Cloudflare dashboard, go to the <strong>DNS Records</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>On a specific record, select <strong>Edit</strong>.</li>
<li>Make any necessary changes.</li>
<li>Select <strong>Save</strong>.</li>
</ol>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To update part of a record with the API, use a <a href="/api/resources/dns/subresources/records/methods/edit/">PATCH request</a>. If you want to overwrite the entire existing record, use a <a href="/api/resources/dns/subresources/records/methods/update/">PUT request</a>.</p>

</section>
