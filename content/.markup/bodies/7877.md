
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the Cloudflare dashboard, go to the account <strong>Settings</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Go to <strong>DNS Settings</strong>.</li>
<li>For <strong>Account custom nameservers</strong>, select <strong>Configure custom nameservers</strong>.</li>
<li>Insert a fully qualified domain name for <strong>Nameserver name</strong> and choose a <strong>Nameserver set</strong>. Follow the <a href="#configuration-conditions">configuration conditions</a>.</li>
</ol>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Use the <a href="/api/resources/custom_nameservers/methods/create/">Add account custom nameserver endpoint</a> to create account custom nameservers. Follow the <a href="#configuration-conditions">conditions</a> for <code>ns_name</code> and <code>ns_set</code>.</p>
<aside class="nb-aside note">
<p>If the parameter <code>ns_set</code> is omitted, the default set <code>1</code> will be assigned.</p>
</aside>

</section>
