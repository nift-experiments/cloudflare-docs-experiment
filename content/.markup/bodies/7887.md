<ul>
<li>If you are using <a href="/registrar/">Cloudflare Registrar</a>, use the <a href="/api/resources/dns/subresources/settings/subresources/zone/methods/edit/">Update DNS settings endpoint</a> to set the <code>type</code> parameter in the <code>nameservers</code> object to <code>&quot;cloudflare.standard&quot;</code>. Then, <a href="/support/contacting-cloudflare-support/">contact Cloudflare Support</a> to set your nameservers back to the regular Cloudflare branded nameservers.</li>
<li>If you are not using <a href="/registrar/">Cloudflare Registrar</a>, modify the domain's registrar to use your regular Cloudflare branded nameservers and then use the <a href="/api/resources/dns/subresources/settings/subresources/zone/methods/edit/">Update DNS settings endpoint</a> to set the <code>type</code> parameter in the <code>nameservers</code> object to <code>&quot;cloudflare.standard&quot;</code>.</li>
</ul>
