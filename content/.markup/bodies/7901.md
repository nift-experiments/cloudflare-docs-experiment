
<aside class="nb-aside caution">
<h3 class="nb-aside-title" id="body-7901-warning">Warning</h3>


<p>This script uses <a href="https://jqlang.github.io/jq/">jq</a> to format <code>JSON</code> outputs for readability. Refer to <a href="/fundamentals/api/how-to/make-api-calls/">Make API calls</a> for details.</p>


</aside>

```bash
zoneid=<ZONE_ID>
bearer=<API_TOKEN>
curl --silent "https://api.cloudflare.com/client/v4/zones/$zoneid/dns_records?per_page=50000" \
--header "Authorization: Bearer $bearer" \
| jq --raw-output '.result[].id' | while read id
do
  curl --silent --request DELETE "https://api.cloudflare.com/client/v4/zones/$zoneid/dns_records/$id" \
--header "Authorization: Bearer $bearer"
done
```
