<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the Cloudflare dashboard, go to the <strong>DNS Settings</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Enable <strong>Secondary DNS override</strong>.</li>
<li>On the <a href="https://dash.cloudflare.com/?to=/:account/:zone/dns/records"><strong>DNS Records</strong></a> page, for specific A, AAAA, or CNAME records, select the grey cloud icon to set their <strong>Proxy status</strong> to <strong>Proxied</strong>.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<ol>
<li>To enable Secondary DNS override on a zone, use the following PATCH request:</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request PATCH \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/dns_settings \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;secondary_overrides&quot;: true
}&#x27;</code></pre>
<ol start="2">
<li>For specific A, AAAA, or CNAME records, send a <a href="/api/resources/dns/subresources/records/methods/create/">POST</a> request with the <code>proxied</code> status as <code>true</code>.</li>
</ol>
<ul>
<li>Make sure the added record has the same name as the transferred record you intend to proxy. Cloudflare only looks at the name and the proxy status, so the record content does not matter.</li>
</ul>
