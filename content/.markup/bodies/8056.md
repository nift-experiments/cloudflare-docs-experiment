<p>Use the <a href="/api/resources/dns/subresources/dnssec/methods/edit/">Edit DNSSEC Status endpoint</a> and set the <code>dnssec_presigned</code> value to <code>true</code>.</p>
<pre class="nb-api-request"><code class="language-bash">curl --request PATCH \
--url https://api.cloudflare.com/client/v4/zones/{zone_id}/dnssec \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;dnssec_presigned&quot;: true
}&#x27;</code></pre>
