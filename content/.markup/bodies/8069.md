<p>To create a peer using the dashboard:</p>
<ol>
<li>In the Cloudflare dashboard, go to the account <strong>Settings</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Go to <strong>DNS Settings</strong>.</li>
<li>Under <strong>DNS Zone Transfers</strong>, for <strong>Peer DNS servers</strong>, select <strong>Create</strong>.</li>
<li>Enter the following information, paying particular attention to:</li>
</ol>
<ul>
<li><strong>IP</strong>: If configured, specifies where Cloudflare sends NOTIFY requests to.</li>
<li><strong>Port</strong>: Specifies the IP Port for the NOTIFY IP.</li>
<li><strong>Enable incremental (IXFR) zone transfers</strong>: Does not apply when you are using Cloudflare as your primary DNS provider (Cloudflare zones always accept IXFR requests).</li>
<li><strong>Link an existing TSIG</strong>: If desired, link the TSIG you <a href="#1-create-tsig-optional">previously created</a>.</li>
</ul>
<ol start="5">
<li>Select <strong>Create</strong>.</li>
</ol>
