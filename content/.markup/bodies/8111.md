
1. Add the class to your Worker code and export it:

<pre><code class="language-ts">import { DurableObject } from &quot;cloudflare:workers&quot;;

export class MyDurableObject extends DurableObject {
  // ...
}
</code></pre>


2. Add a binding for the class (if your Worker needs to access it through `env`) and declare the class in `exports`:

<div class="nb-wrangler-config">

<pre><code class="language-jsonc">{
  &quot;durable_objects&quot;: {
    &quot;bindings&quot;: [
      {
        &quot;name&quot;: &quot;MY_DURABLE_OBJECT&quot;,
        &quot;class_name&quot;: &quot;MyDurableObject&quot;
      }
    ]
  },
  &quot;exports&quot;: {
    &quot;MyDurableObject&quot;: {
      &quot;type&quot;: &quot;durable-object&quot;,
      &quot;storage&quot;: &quot;sqlite&quot;
    }
  }
}
</code></pre>

</div>

3. Deploy the Worker:

<pre><code class="language-sh">npx wrangler deploy
</code></pre>
