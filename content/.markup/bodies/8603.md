<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Send an email with a single <code>curl</code> command. Replace <code>{account_id}</code> with your <a href="/fundamentals/account/find-account-and-zone-ids/">Cloudflare account ID</a> and <code>&lt;API_TOKEN&gt;</code> with an <a href="/fundamentals/api/get-started/create-token/">API token</a>.</p>
<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/accounts/{account_id}/email/sending/send&quot; \
  --header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \
  --header &quot;Content-Type: application/json&quot; \
  --data '{
    &quot;to&quot;: &quot;recipient@example.com&quot;,
    &quot;from&quot;: &quot;welcome@yourdomain.com&quot;,
    &quot;subject&quot;: &quot;Welcome to our service!&quot;,
    &quot;html&quot;: &quot;&lt;h1&gt;Welcome!&lt;/h1&gt;&lt;p&gt;Thanks for signing up.&lt;/p&gt;&quot;,
    &quot;text&quot;: &quot;Welcome! Thanks for signing up.&quot;
  }'
</code></pre>
<p>A successful response includes the delivery status for each recipient:</p>
<pre><code class="language-json">{
	&quot;success&quot;: true,
	&quot;errors&quot;: [],
	&quot;messages&quot;: [],
	&quot;result&quot;: {
		&quot;delivered&quot;: [&quot;recipient@example.com&quot;],
		&quot;permanent_bounces&quot;: [],
		&quot;queued&quot;: []
	}
}
</code></pre>
<p>For more details, see the <a href="/email-service/api/send-emails/rest-api/">REST API reference</a>.</p>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="SMTP">

<p>Send an email with a single <code>curl</code> command. Replace <code>&lt;API_TOKEN&gt;</code> with a <a href="/fundamentals/api/get-started/create-token/">Cloudflare API token</a> that has the <strong>Email Sending: Edit</strong> permission, and replace the <code>--mail-from</code> and <code>--mail-rcpt</code> addresses with your own.</p>
<pre><code class="language-sh">cat &gt; mail.txt &lt;&lt;EOF
From: welcome@yourdomain.com
To: recipient@example.com
Subject: Welcome to our service!

Thanks for signing up.
EOF

curl --ssl-reqd \
  --url &quot;smtps://smtp.mx.cloudflare.net:465&quot; \
  --user &quot;api_token:&lt;API_TOKEN&gt;&quot; \
  --mail-from &quot;welcome@yourdomain.com&quot; \
  --mail-rcpt &quot;recipient@example.com&quot; \
  --upload-file mail.txt
</code></pre>
<p>The sender domain (<code>welcome@yourdomain.com</code>) must be onboarded for <a href="/email-service/configuration/domains/">Email Sending</a> on the account that owns the API token.</p>
<p>For connection details, authentication, response codes, and language-specific examples, see the <a href="/email-service/api/send-emails/smtp/">SMTP reference</a>.</p>
