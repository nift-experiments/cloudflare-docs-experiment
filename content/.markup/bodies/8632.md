
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="MX records">

<p><strong>Purpose</strong>: Route bounce emails back to Cloudflare for processing.</p>
<pre><code class="language-txt">MX cf-bounce.yourdomain.com route1.mx.cloudflare.net
MX cf-bounce.yourdomain.com route2.mx.cloudflare.net
MX cf-bounce.yourdomain.com route3.mx.cloudflare.net
</code></pre>
<p><strong>Configuration:</strong></p>
<ul>
<li><strong>Type</strong>: MX</li>
<li><strong>Name</strong>: <code>cf-bounce</code> (subdomain)</li>
<li><strong>Mail server</strong>: Cloudflare MX servers</li>
<li><strong>Priority</strong>: Assigned automatically by Cloudflare</li>
</ul>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="SPF record">

<p><strong>Purpose</strong>: Authorizes Cloudflare to send emails on behalf of your domain.</p>
<pre><code class="language-txt">TXT cf-bounce.yourdomain.com &quot;v=spf1 include:_spf.mx.cloudflare.net ~all&quot;
</code></pre>
<p><strong>Configuration:</strong></p>
<ul>
<li><strong>Type</strong>: TXT</li>
<li><strong>Name</strong>: <code>cf-bounce</code> (subdomain)</li>
<li><strong>Value</strong>: <code>v=spf1 include:_spf.mx.cloudflare.net ~all</code></li>
<li><strong>TTL</strong>: Auto</li>
</ul>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="DKIM record">

<p><strong>Purpose</strong>: Provides cryptographic authentication for your emails.</p>
<pre><code class="language-txt">TXT cf-bounce._domainkey.yourdomain.com &quot;v=DKIM1; h=sha256; k=rsa; p=MIIBIjANBgkqhkiG9w0BAQEFAAOCAQ8AMIIBCgKCAQEA...&quot;
</code></pre>
<p><strong>Configuration:</strong></p>
<ul>
<li><strong>Type</strong>: TXT</li>
<li><strong>Name</strong>: <code>cf-bounce._domainkey</code> (selector managed by Cloudflare)</li>
<li><strong>Value</strong>: DKIM public key (provided by Cloudflare)</li>
<li><strong>TTL</strong>: Auto</li>
</ul>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="DMARC record">

<p><strong>Purpose</strong>: Sets policy for email authentication failures.</p>
<pre><code class="language-txt">TXT _dmarc.yourdomain.com &quot;v=DMARC1; p=reject;&quot;
</code></pre>
<p><strong>Configuration:</strong></p>
<ul>
<li><strong>Type</strong>: TXT</li>
<li><strong>Name</strong>: <code>_dmarc</code></li>
<li><strong>Value</strong>: DMARC policy</li>
<li><strong>TTL</strong>: Auto</li>
</ul>
<p><strong>Policy options:</strong></p>
<ul>
<li><code>p=none</code> - Monitor only (recommended for new setups)</li>
<li><code>p=quarantine</code> - Quarantine suspicious emails</li>
<li><code>p=reject</code> - Reject unauthenticated emails</li>
</ul>

</section>
