<h3 id="body-8670-send-an-email">Send an email</h3>
<pre><code class="language-sh">cat &gt; mail.txt &lt;&lt;EOF
From: welcome@yourdomain.com
To: recipient@example.com
Subject: Welcome to our service!

Thanks for signing up.
EOF

curl --ssl-reqd \
  --url &quot;smtps://smtp.mx.cloudflare.net:465&quot; \
  --user &quot;api_token:$CF_API_TOKEN&quot; \
  --mail-from &quot;welcome@yourdomain.com&quot; \
  --mail-rcpt &quot;recipient@example.com&quot; \
  --upload-file mail.txt
</code></pre>
<p>The sender domain must be onboarded for Email Sending on the account that owns the API token.</p>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Node.js (Nodemailer)">

<p>Install <a href="https://nodemailer.com/">Nodemailer</a> with <code>npm install nodemailer</code>.</p>
<h3 id="body-8670-send-an-email-1">Send an email</h3>
<pre><code class="language-js">import nodemailer from &quot;nodemailer&quot;;

const transporter = nodemailer.createTransport({
	host: &quot;smtp.mx.cloudflare.net&quot;,
	port: 465,
	secure: true, // implicit TLS
	auth: {
		user: &quot;api_token&quot;,
		pass: process.env.CF_API_TOKEN,
	},
});

const info = await transporter.sendMail({
	from: '&quot;Acme&quot; &lt;welcome@yourdomain.com&gt;',
	to: &quot;user@example.com&quot;,
	subject: &quot;Welcome to Acme&quot;,
	text: &quot;Thanks for signing up.&quot;,
	html: &quot;&lt;h1&gt;Welcome to Acme&lt;/h1&gt;&lt;p&gt;Thanks for signing up.&lt;/p&gt;&quot;,
});

console.log(&quot;Message sent:&quot;, info.messageId);
</code></pre>
<h3 id="body-8670-send-with-an-attachment">Send with an attachment</h3>
<pre><code class="language-js">const info = await transporter.sendMail({
	from: '&quot;Acme Billing&quot; &lt;billing@yourdomain.com&gt;',
	to: &quot;customer@example.com&quot;,
	subject: &quot;Your invoice&quot;,
	text: &quot;Please find your invoice attached.&quot;,
	attachments: [
		{
			filename: &quot;invoice-2026-04.pdf&quot;,
			path: &quot;./invoices/invoice-2026-04.pdf&quot;,
			contentType: &quot;application/pdf&quot;,
		},
	],
});
</code></pre>
<p>Total message size (including base64-encoded attachments) must not exceed 5 MiB. See <a href="/email-service/platform/limits/">Limits</a>.</p>
<h3 id="body-8670-error-handling">Error handling</h3>
<p>Nodemailer rejects the promise with an <code>Error</code> whose <code>.responseCode</code> reflects the SMTP reply code. See <a href="/email-service/api/send-emails/smtp/#response-codes">SMTP response codes</a> and <a href="/email-service/api/send-emails/smtp/#troubleshooting">Troubleshooting</a>.</p>
<pre><code class="language-js">try {
	await transporter.sendMail({
		/* ... */
	});
} catch (err) {
	console.error(err.responseCode, err.message);
}
</code></pre>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Python (smtplib)">

<p>Uses the standard-library <a href="https://docs.python.org/3/library/smtplib.html"><code>smtplib</code></a> (Python 3.8 or later).</p>
<h3 id="body-8670-send-an-email-2">Send an email</h3>
<pre><code class="language-python">import os
import smtplib
from email.message import EmailMessage

msg = EmailMessage()
msg[&quot;From&quot;] = &quot;Acme &lt;welcome@yourdomain.com&gt;&quot;
msg[&quot;To&quot;] = &quot;user@example.com&quot;
msg[&quot;Subject&quot;] = &quot;Welcome to Acme&quot;
msg.set_content(&quot;Thanks for signing up.&quot;)
msg.add_alternative(
    &quot;&lt;h1&gt;Welcome to Acme&lt;/h1&gt;&lt;p&gt;Thanks for signing up.&lt;/p&gt;&quot;,
    subtype=&quot;html&quot;,
)

with smtplib.SMTP_SSL(&quot;smtp.mx.cloudflare.net&quot;, 465) as s:
    s.login(&quot;api_token&quot;, os.environ[&quot;CF_API_TOKEN&quot;])
    s.send_message(msg)
</code></pre>
<p><code>smtplib.SMTP_SSL</code> opens an implicit-TLS connection on port <code>465</code>, which is what Cloudflare's SMTP endpoint requires. Do not use <code>smtplib.SMTP</code> with <code>starttls()</code>; <code>STARTTLS</code> is not supported.</p>
<h3 id="body-8670-send-to-multiple-recipients">Send to multiple recipients</h3>
<pre><code class="language-python">msg[&quot;To&quot;] = &quot;, &quot;.join([
    &quot;user1@example.com&quot;,
    &quot;user2@example.com&quot;,
    &quot;user3@example.com&quot;,
])
</code></pre>
<p>A single SMTP session can deliver to up to 50 <code>RCPT TO</code> addresses. See <a href="/email-service/platform/limits/">Limits</a>.</p>
<h3 id="body-8670-send-with-an-attachment-1">Send with an attachment</h3>
<pre><code class="language-python">from pathlib import Path

pdf = Path(&quot;invoice-2026-04.pdf&quot;).read_bytes()
msg.add_attachment(
    pdf,
    maintype=&quot;application&quot;,
    subtype=&quot;pdf&quot;,
    filename=&quot;invoice-2026-04.pdf&quot;,
)
</code></pre>
<h3 id="body-8670-error-handling-1">Error handling</h3>
<p><code>smtplib</code> raises subclasses of <code>smtplib.SMTPException</code> with the SMTP reply code attached. See <a href="/email-service/api/send-emails/smtp/#response-codes">SMTP response codes</a> and <a href="/email-service/api/send-emails/smtp/#troubleshooting">Troubleshooting</a>.</p>
<pre><code class="language-python">try:
    with smtplib.SMTP_SSL(&quot;smtp.mx.cloudflare.net&quot;, 465) as s:
        s.login(&quot;api_token&quot;, os.environ[&quot;CF_API_TOKEN&quot;])
        s.send_message(msg)
except smtplib.SMTPAuthenticationError as e:
    print(f&quot;Auth failed: {e.smtp_code} {e.smtp_error!r}&quot;)
except smtplib.SMTPResponseException as e:
    print(f&quot;SMTP error: {e.smtp_code} {e.smtp_error!r}&quot;)
</code></pre>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="PHP (PHPMailer)">

<h3 id="body-8670-send-an-email-3">Send an email</h3>
<pre><code class="language-php">&lt;?php
use PHPMailer\PHPMailer\PHPMailer;

require 'vendor/autoload.php';

$mail = new PHPMailer(true);
$mail-&gt;isSMTP();
$mail-&gt;Host       = 'smtp.mx.cloudflare.net';
$mail-&gt;Port       = 465;
$mail-&gt;SMTPSecure = PHPMailer::ENCRYPTION_SMTPS;
$mail-&gt;SMTPAuth   = true;
$mail-&gt;Username   = 'api_token';
$mail-&gt;Password   = getenv('CF_API_TOKEN');

$mail-&gt;setFrom('welcome@yourdomain.com', 'Acme');
$mail-&gt;addAddress('recipient@example.com');
$mail-&gt;Subject = 'Welcome to our service!';
$mail-&gt;Body    = 'Thanks for signing up.';
$mail-&gt;send();
</code></pre>
