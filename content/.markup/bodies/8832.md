
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<div class="nb-steps">
<ol>
<li>Log in to the Cloudflare dashboard.</li>
<li>Select your account.</li>
<li>Go to <strong>Manage Account</strong> &gt; <strong>OAuth clients</strong>.</li>
<li>Select <strong>Create client</strong>.</li>
<li>Enter the required configuration details:</li>
</ol>
<ul>
<li>Client name</li>
<li>Response type</li>
<li>Grant type</li>
<li>Token authentication method</li>
<li>Redirect URLs</li>
</ul>
<ol start="6">
<li>Optional: Add non-required fields.</li>
<li>Select <strong>Continue</strong> and define the scopes required for your client.</li>
<li>Optional: In <strong>Choose optional scopes</strong>, turn off <strong>Required</strong> for each scope you want to make optional. All scopes are required by default.</li>
<li>Select <strong>Create client</strong>.</li>
<li>Save your <strong>Client ID</strong> and <strong>Client Secret</strong> in a secure location.</li>
</ol>
</div>
<div class="nb-dash-button"></div>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To create OAuth clients with the Cloudflare API, create an API token with the <code>OAuth Clients Write</code> permission.</p>
<pre><code class="language-bash">curl -X POST &quot;https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/oauth_clients&quot; \
	&#45;H &quot;Content-Type: application/json&quot; \
	&#45;H &quot;Authorization: Bearer $API_TOKEN&quot; \
	&#45;d &#x27;{
		&quot;client_name&quot;: &quot;Cloudflare OAuth Client&quot;,
		&quot;grant_types&quot;: [&quot;authorization_code&quot;],
		&quot;redirect_uris&quot;: [&quot;https://example.com/oauth/callback&quot;],
		&quot;scopes&quot;: [&quot;workers-platform.read&quot;, &quot;workers-platform.write&quot;],
		&quot;optional_scopes&quot;: [&quot;workers-platform.read&quot;],
		&quot;post_logout_redirect_uris&quot;: [&quot;https://example.com/logout&quot;],
		&quot;response_types&quot;: [&quot;code&quot;],
		&quot;token_endpoint_auth_method&quot;: &quot;client_secret_basic&quot;,
		&quot;logo_uri&quot;: &quot;https://example.com/logo.png&quot;,
		&quot;policy_uri&quot;: &quot;https://example.com/policy&quot;,
		&quot;tos_uri&quot;: &quot;https://example.com/tos&quot;,
		&quot;client_uri&quot;: &quot;https://example.com&quot;,
		&quot;allowed_cors_origins&quot;: [&quot;https://example.com&quot;]
	}&#x27;
</code></pre>
