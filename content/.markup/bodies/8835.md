
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<p>When you create or edit an OAuth client, select at least one scope. All selected scopes are required by default.</p>
<p>In <strong>Choose optional scopes</strong>, turn off <strong>Required</strong> for each scope you want to make optional.</p>
<p>Required scopes must be granted on the consent screen, while optional scopes can be declined by the user.</p>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Fetch the available scopes from the API. Use the scope ID when you create a client through the API.</p>
<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/oauth/scopes&quot; \
	&#45;H &quot;Content-Type: application/json&quot; \
	&#45;H &quot;Authorization: Bearer $API_TOKEN&quot;
</code></pre>
<p>To mark scopes as optional, include them in the <code>optional_scopes</code> of the request. This must be a subset of the <code>scopes</code> for the client. Optional scopes may be declined by the user during authorization.</p>

</section>
