<p>Using the role identifiers from the previous section, you can create a permission policy for your group.</p>
<p><code>export ADMIN_ROLE='...' # id field from admin or desired role entry from permission_groups API response</code></p>
<pre><code class="language-curl">$ cat &lt;&lt;-PAYLOAD | curl -XPUT  -H &quot;Authorization: Bearer $AOT&quot; -H &quot;Content-type: application/json&quot; --data-binary @- https://api.cloudflare.com/client/v4/accounts/$ACCT/iam/user_groups/$PUSHED_GROUP  | jq .
{
    &quot;policies&quot;: [
        {
            &quot;access&quot;: &quot;allow&quot;,
            &quot;permission_groups&quot;: [{&quot;id&quot;: &quot;$ADMIN_ROLE&quot;}],
            &quot;resource_groups&quot;: [{
                &quot;scope&quot;: {
                    &quot;key&quot;: &quot;com.cloudflare.api.account.$ACCT&quot;,
                    &quot;objects&quot;: [{&quot;key&quot;:&quot;*&quot;}]
                }
            }]
        }
    ]
}
PAYLOAD
</code></pre>
<p><strong>Reset a policy to an empty state</strong></p>
<p>If you made a mistake while creating the group policy or need to reset the policy to an empty state, send another PUT request to the group API with an empty policy array to overwrite with your new policy.</p>
<pre><code class="language-curl">$ cat &lt;&lt;-PAYLOAD | curl -XPUT  -H &quot;Authorization: Bearer $AOT&quot; -H &quot;Content-type: application/json&quot; --data-binary @- https://api.cloudflare.com/client/v4/accounts/$ACCT/iam/user_groups/$PUSHED_GROUP  | jq .
{
    &quot;policies&quot;: []
}
PAYLOAD
</code></pre>
