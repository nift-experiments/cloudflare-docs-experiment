<ol>
<li>Go to <strong>Manage members</strong> &gt; <strong>Members</strong> &gt; <strong>User groups</strong>.</li>
<li>Select the user group you want to attach permissions to.</li>
<li>Select the <strong>Permission policies</strong> tab and select <strong>Add policy</strong>.</li>
<li>Choose the scope and role that you want to apply to the policy.</li>
<li>Select <strong>Save</strong> to apply the policy.</li>
</ol>

<p><strong>2. Make a query against the resource ID</strong></p>
<p>Locate the tag of the group you pushed from the IdP and use it to make a direct query against its resource ID:</p>
<p><code>export PUSHED_GROUP='...' # Pull this value from the &quot;id&quot; json field in the group list response</code></p>
<pre><code class="language-curl">$ curl -XGET -H &quot;Authorization: Bearer $AOT&quot; https://api.cloudflare.com/client/v4/accounts/$ACCT/iam/user_groups/$PUSHED_GROUP | jq .
</code></pre>
<p>The response for this should have the group name that was specified in the identity provider with no attached policies.</p>
