

To edit member permissions using the API, get a [list of roles](/api/resources/accounts/subresources/roles/methods/list/) available for an account.

Then, send a [`PUT` request](/api/resources/accounts/subresources/members/methods/update/) to edit their permissions.


```bash title="Request"

curl --request PUT \
  --url https://api.cloudflare.com/client/v4/accounts/{account_id}/members/{member_id} \
  --header 'Authorization: Bearer <API_TOKEN>' \
  --header 'Content-Type: application/json' \
  --data '{
	  "roles": [
	        {
	            "id": "<ROLE_ID1>"
	        },
	        {
	            "id": "<ROLE_ID2>"
	        }
	  	]
		}'
```
