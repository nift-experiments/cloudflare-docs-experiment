<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Using a command line terminal where you have already set the environment variable <code>CLOUDFLARE_API_TOKEN</code> to a user or account API token which has the <code>SSO Connector Edit</code> permission, run the following command to create an SSO connector. Replace <code>{account_id}</code> with your account ID, and <code>{domain}</code> with your email domain.</p>
<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/accounts/{account_id}/sso_connectors&quot; \
  --request POST \
  --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
  --json '{&quot;email_domain&quot;:&quot;{domain}&quot;}'
</code></pre>
