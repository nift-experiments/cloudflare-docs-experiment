<p>If you are unable to change your DNS records right away, the option to verify later is available. The verification process can be manually triggered from the actions menu for that connector in the list.</p>
<p><img src="/assets/upstream/images/fundamentals/members/sso/verify_modal.png" alt="Screenshot of the SSO connector create modal" /></p>
<p>Copy the verification code and create a TXT record in your DNS configuration with that value. The record must include all of the text including the <code>cloudflare_dashboard_sso=</code> prefix.</p>
<p>Cloudflare will automatically poll this DNS record until it is found or a timeout is reached within two days.</p>
<p>If the verification process fails due to timeout, you can manually reinitiate the polling by selecting <strong>Begin verification</strong> in the actions menu for that connector in the list.</p>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>Copy the verification code (for example <code>cloudflare_dashboard_sso=1111111</code>) and create a <code>TXT</code> record in your DNS configuration with that value. To test that the DNS record was correctly configured, you can use the <code>dig</code> command to query your email domain:</p>
<pre><code class="language-sh">dig cool.cats TXT +short
</code></pre>
<pre><code class="language-sh">&quot;cloudflare_dashboard_sso=111111111&quot;
</code></pre>
<p>The <code>TXT</code> record must include the <code>cloudflare_dashboard_sso=</code> prefix along with the numerical code.</p>
<p>Cloudflare will automatically poll this DNS record until it is found or a timeout is reached within two days. If verification fails due to timeout, you may manually reinitiate the polling by running the following command:</p>
<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/accounts/{account_id}/sso_connectors/{sso_connector_id}/begin_verification&quot; \
  --request POST \
  --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;
</code></pre>
