

The following API calls will disable SSO enforcement for an account. This action can only be performed by API tokens with the `SSO connectors edit` role or Super Administrators.

1. Get your SSO connector `id`:

<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/accounts/{account_id}/sso_connectors&quot; \
  &#45;-request GET \
  &#45;-header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;
</code></pre>


```txt
   {
   	"result": [
   		{
   			"id": "d616ac82cc7f87153112d75a711c5c3c",
   			"email_domain": "cool.cats",
   			"enabled": true
   			// ...
   		}
   	],
   	"success": true,
   	"errors": [],
   	"messages": []
   }
   ```

2. Disable the SSO connector:

<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/accounts/{account_id}/sso_connectors/{connector_id}&quot; \
  &#45;-request PATCH \
  &#45;-header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
  &#45;-json &#x27;{
    &quot;enabled&quot;: false
  }&#x27;
</code></pre>


```txt
   {
   	"result": [
   		{
   			"id": "d616ac82cc7f87153112d75a711c5c3c",
   			"email_domain": "cool.cats",
   			"enabled": false
   			// ...
   		}
   	],
   	"success": true,
   	"errors": [],
   	"messages": []
   }
   ```
