<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>The following API calls will disable SSO enforcement for an account. This action can only be performed by API tokens with the <code>SSO connectors edit</code> role or Super Administrators.</p>
<ol>
<li>Get your SSO connector <code>id</code>:</li>
</ol>
<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/accounts/{account_id}/sso_connectors&quot; \
  &#45;-request GET \
  &#45;-header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;
</code></pre>
<pre><code class="language-txt">   {
   	&quot;result&quot;: [
   		{
   			&quot;id&quot;: &quot;d616ac82cc7f87153112d75a711c5c3c&quot;,
   			&quot;email_domain&quot;: &quot;cool.cats&quot;,
   			&quot;enabled&quot;: true
   			// ...
   		}
   	],
   	&quot;success&quot;: true,
   	&quot;errors&quot;: [],
   	&quot;messages&quot;: []
   }
</code></pre>
<ol start="2">
<li>Disable the SSO connector:</li>
</ol>
<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/accounts/{account_id}/sso_connectors/{connector_id}&quot; \
  &#45;-request PATCH \
  &#45;-header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
  &#45;-json &#x27;{
    &quot;enabled&quot;: false
  }&#x27;
</code></pre>
<pre><code class="language-txt">   {
   	&quot;result&quot;: [
   		{
   			&quot;id&quot;: &quot;d616ac82cc7f87153112d75a711c5c3c&quot;,
   			&quot;email_domain&quot;: &quot;cool.cats&quot;,
   			&quot;enabled&quot;: false
   			// ...
   		}
   	],
   	&quot;success&quot;: true,
   	&quot;errors&quot;: [],
   	&quot;messages&quot;: []
   }
</code></pre>
