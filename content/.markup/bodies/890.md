

You can use [Wrangler](/workers/wrangler/) to create a new KV namespace. You can also use it to perform operations such as put, list, get, and delete within your KV namespace.

<aside class="nb-aside note">


<p>KV operations are scoped to your account.</p>


</aside>

To create a KV namespace via Wrangler:

<div class="nb-steps">

<ol>
<li>Open your terminal and run the following command:</li>
</ol>
<pre><code class="language-sh">npx wrangler kv namespace create &lt;BINDING_NAME&gt;
</code></pre>
<p>The <code>npx wrangler kv namespace create &lt;BINDING_NAME&gt;</code> subcommand takes a new binding name as its argument. A KV namespace is created using a concatenation of your Worker's name (from your Wrangler file) and the binding name you provide. A <code>&lt;BINDING_ID&gt;</code> is randomly generated for you.</p>
<p>For this tutorial, use the binding name <code>USERS_NOTIFICATION_CONFIG</code>.</p>
<pre><code class="language-sh">npx wrangler kv namespace create USERS_NOTIFICATION_CONFIG
</code></pre>
<pre><code class="language-sh">🌀 Creating namespace with title &quot;USERS_NOTIFICATION_CONFIG&quot;
✨ Success!
Add the following to your configuration file in your kv_namespaces array:
{
	&quot;kv_namespaces&quot;: [
		{
			&quot;binding&quot;: &quot;USERS_NOTIFICATION_CONFIG&quot;,
			&quot;id&quot;: &quot;&lt;BINDING_ID&gt;&quot;
		}
	]
}
</code></pre>

</div>
