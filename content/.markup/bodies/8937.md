
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API token">

<p>Set <code>CLOUDFLARE_API_TOKEN</code> to a user-owned API token. Set <code>IDEMPOTENCY_KEY</code> to a unique value for this account creation request.</p>
<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/accounts&quot; \
	&#45;-request POST \
	&#45;-header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
	&#45;-header &quot;Content-Type: application/json&quot; \
	&#45;-header &quot;Idempotency-Key: $IDEMPOTENCY_KEY&quot; \
	&#45;-data &#x27;{&quot;name&quot;:&quot;Example account&quot;,&quot;type&quot;:&quot;standard&quot;,&quot;standalone&quot;:true}&#x27;
</code></pre>
