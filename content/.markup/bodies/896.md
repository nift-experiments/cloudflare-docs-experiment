		{
			&quot;binding&quot;: &quot;USERS_NOTIFICATION_CONFIG&quot;,
			&quot;id&quot;: &quot;&lt;BINDING_ID&gt;&quot;
		}
	]
}
</code></pre>

<p>Binding names do not need to correspond to the namespace you created. Binding names are only a reference. Specifically:</p>
<ul>
<li>The value (string) you set for <code>binding</code> is used to reference this KV namespace in your Worker. For this tutorial, this should be <code>USERS_NOTIFICATION_CONFIG</code>.</li>
<li>The binding must be <a href="https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Grammar_and_types#variables">a valid JavaScript variable name</a>. For example, <code>binding = &quot;MY_KV&quot;</code> or <code>binding = &quot;routingConfig&quot;</code> would both be valid names for the binding.</li>
<li>Your binding is available in your Worker at <code>env.&lt;BINDING_NAME&gt;</code> from within your Worker. For this tutorial, the binding is available at <code>env.USERS_NOTIFICATION_CONFIG</code>.</li>
</ul>
