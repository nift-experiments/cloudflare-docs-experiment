<p>To define a <code>ZONE_ID</code> environment variable for the current shell session, run the following command:</p>
<pre><code class="language-sh">export ZONE_ID='f2ea6707005a4da1af1b431202e96ac5'
</code></pre>
<p>To define the variable for all new shell sessions for the current user, add the command above at the end of your shell configuration file (for example, <code>~/.bashrc</code> for the <code>bash</code> shell and <code>~/.zshrc</code> for the <code>zsh</code> shell).</p>

<p>To define a <code>ZONE_ID</code> environment variable for the current PowerShell session, run the following command:</p>
<pre><code class="language-powershell">$Env:ZONE_ID='f2ea6707005a4da1af1b431202e96ac5'
</code></pre>
<p>To define the environment variable for all new PowerShell sessions of the current user, set the variable in your PowerShell profile. You can get the path to your PowerShell profile by running <code>echo $PROFILE</code>.</p>
<p>Alternatively, set the variable for all new PowerShell sessions of the current user using the <code>SetEnvironmentVariable()</code> method of the <code>System.Environment</code> class. For example:</p>
<pre><code class="language-powershell">[Environment]::SetEnvironmentVariable(&quot;ZONE_ID&quot;, &quot;f2ea6707005a4da1af1b431202e96ac5&quot;, &quot;User&quot;)
</code></pre>
<p>Running this command will not affect the current session. You will need to close and start a new PowerShell session.</p>

<p>To define a <code>ZONE_ID</code> environment variable for the current Command Prompt session, run the following command:</p>
<pre><code class="language-txt">set ZONE_ID=f2ea6707005a4da1af1b431202e96ac5
</code></pre>
<p>To define an environment variable for all future Command Prompt sessions of the current user, run the following command:</p>
<pre><code class="language-txt">setx ZONE_ID f2ea6707005a4da1af1b431202e96ac5

<p>Running this command will not affect the current window. You will need to either run the <code>set</code> command or close and start a new Command Prompt window.</p>
