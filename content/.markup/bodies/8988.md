<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Linux and macOS">

<p>When referencing an environment variable in a command, add a <code>$</code> prefix to the variable name (for example, <code>$ZONE_ID</code>). Make sure that the full string referencing the variable is either unquoted (if it does not contain spaces) or enclosed in double quotes (<code>&quot;&quot;</code>).</p>
<p>For example:</p>
<pre><code class="language-sh">curl &quot;https://api.cloudflare.com/client/v4/zones/$ZONE_ID&quot; \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;
</code></pre>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="PowerShell">

<p>When referencing an environment variable in a command, add an <code>$Env:</code> prefix to the variable name (for example, <code>$Env:ZONE_ID</code>). Make sure that the full string referencing the variable is either unquoted or enclosed in double quotes (<code>&quot;&quot;</code>).</p>
<p>For example:</p>
<pre><code class="language-powershell">Invoke-RestMethod -URI &quot;https://api.cloudflare.com/client/v4/zones/$Env:ZONE_ID&quot; -Method 'GET' -Headers @{'Authorization'=&quot;Bearer $Env:CLOUDFLARE_API_TOKEN&quot;}
</code></pre>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Windows Command Prompt">

<p>When referencing an environment variable in a command, enclose the variable name in <code>%</code> characters (for example, <code>%ZONE_ID%</code>).</p>
<p>For example:</p>
<pre><code class="language-txt">curl &quot;https://api.cloudflare.com/client/v4/zones/%ZONE_ID%&quot; --header &quot;Authorization: Bearer %CLOUDFLARE_API_TOKEN%&quot;
</code></pre>
