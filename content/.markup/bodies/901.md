

To write a value to your empty KV namespace using Wrangler:

<div class="nb-steps">

<ol>
<li>Run the <code>wrangler kv key put</code> subcommand in your terminal, and input your key and value respectively. <code>&lt;KEY&gt;</code> and <code>&lt;VALUE&gt;</code> are values of your choice.</li>
</ol>
<pre><code class="language-sh">npx wrangler kv key put --binding=&lt;BINDING_NAME&gt; &quot;&lt;KEY&gt;&quot; &quot;&lt;VALUE&gt;&quot;
</code></pre>
<p>In this tutorial, you will add a key <code>user_1</code> with value <code>enabled</code> to the KV namespace you created in <a href="/kv/get-started/#2-create-a-kv-namespace">step 2</a>.</p>
<pre><code class="language-sh">npx wrangler kv key put --binding=USERS_NOTIFICATION_CONFIG &quot;user_1&quot; &quot;enabled&quot;
</code></pre>
<pre><code class="language-sh">Writing the value &quot;enabled&quot; to key &quot;user_1&quot; on namespace &lt;BINDING_ID&gt;.
</code></pre>

</div>

<aside class="nb-aside note">
<h3 class="nb-aside-title" id="body-901-using-namespace-id">Using `--namespace-id`</h3>


<p>Instead of using <code>--binding</code>, you can also use <code>--namespace-id</code> to specify which KV namespace should receive the operation:</p>
<pre><code class="language-sh">npx wrangler kv key put --namespace-id=&lt;BINDING_ID&gt; &quot;&lt;KEY&gt;&quot; &quot;&lt;VALUE&gt;&quot;
</code></pre>
<pre><code class="language-sh">Writing the value &quot;&lt;VALUE&gt;&quot; to key &quot;&lt;KEY&gt;&quot; on namespace &lt;BINDING_ID&gt;.
</code></pre>


</aside>

<aside class="nb-aside note">
<h3 class="nb-aside-title" id="body-901-storing-values-in-remote-kv-namespace">Storing values in remote KV namespace</h3>


<p>By default, the values are written locally. To create a key and a value in your remote KV namespace, add the <code>--remote</code> flag at the end of the command:</p>
<pre><code class="language-sh">npx wrangler kv key put --namespace-id=xxxxxxxxxxxxxxxx &quot;&lt;KEY&gt;&quot; &quot;&lt;VALUE&gt;&quot; --remote
</code></pre>


</aside>
