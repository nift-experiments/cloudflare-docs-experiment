

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Wrangler">

<p>Using Wrangler, enter the following command in your terminal to create a Hyperdrive configuration with the CA certificate and SSL mode:</p>
<pre><code class="language-bash"># PostgreSQL with verify-full
npx wrangler hyperdrive create &lt;NAME_OF_HYPERDRIVE_CONFIG&gt; --connection-string=&quot;postgres://user:password@HOSTNAME_OR_IP_ADDRESS:PORT/database_name&quot; --ca-certificate-id &lt;YOUR_CA_CERT_ID&gt; --sslmode verify-full

# MySQL with VERIFY_IDENTITY
npx wrangler hyperdrive create &lt;NAME_OF_HYPERDRIVE_CONFIG&gt; --connection-string=&quot;mysql://user:password@HOSTNAME_OR_IP_ADDRESS:PORT/database_name&quot; --ca-certificate-id &lt;YOUR_CA_CERT_ID&gt; --sslmode VERIFY_IDENTITY
</code></pre>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<p>From the dashboard, follow these steps to create a Hyperdrive configuration with server certificates:</p>
<ol>
<li>In the Cloudflare dashboard, go to the <strong>Hyperdrive</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select <strong>Create configuration</strong>.</li>
<li>Select <strong>Server certificates</strong>.</li>
<li>Specify a SSL mode of <strong>Verify CA</strong> or <strong>Verify full</strong>.</li>
<li>Select the SSL certificate of the certificate authority (CA) of your database that you have previously uploaded with Wrangler.</li>
</ol>

</section>
