

To access the value from your KV namespace using Wrangler:

<div class="nb-steps">

<ol>
<li>Run the <code>wrangler kv key get</code> subcommand in your terminal, and input your key value:</li>
</ol>
<pre><code class="language-sh">npx wrangler kv key get --binding=&lt;BINDING_NAME&gt; &quot;&lt;KEY&gt;&quot;
</code></pre>
<p>In this tutorial, you will get the value of the key <code>user_1</code> from the KV namespace you created in <a href="/kv/get-started/#2-create-a-kv-namespace">step 2</a>.</p>
<aside class="nb-aside note">
<p>To view the value directly within the terminal, you use the <code>--text</code> flag.</p>
</aside>
<pre><code class="language-sh">npx wrangler kv key get --binding=USERS_NOTIFICATION_CONFIG &quot;user_1&quot; --text
</code></pre>
<p>Similar to the <code>put</code> command, the <code>get</code> command can also be used to access a KV namespace in two ways - with <code>--binding</code> or <code>--namespace-id</code>:</p>

</div>

<aside class="nb-aside caution">


<p>Exactly <strong>one</strong> of <code>--binding</code> or <code>--namespace-id</code> is required.</p>


</aside>

Refer to the [`kv bulk` documentation](/kv/reference/kv-commands/#kv-bulk) to write a file of multiple key-value pairs to a given KV namespace.
