

<h3 id="body-9061-2-1-automatic-create-a-hyperdrive-configuration-in-the-cloudflare-dashboard">2.1. (Automatic) Create a Hyperdrive configuration in the Cloudflare dashboard</h3>

Create a Hyperdrive configuration in the Cloudflare dashboard to automatically configure Hyperdrive to connect to your Cloudflare Tunnel.

<div class="nb-steps">

<ol>
<li>In the <a href="https://dash.cloudflare.com/?to=/:account/workers/hyperdrive">Cloudflare dashboard</a>, navigate to <strong>Storage &amp; Databases &gt; Hyperdrive</strong> and click <strong>Create configuration</strong>.</li>
<li>Select <strong>Private database</strong>.</li>
<li>In the <strong>Networking details</strong> section, select the tunnel you are connecting to.</li>
<li>In the <strong>Networking details</strong> section, select the hostname associated to the tunnel. If there is no hostname for your database, return to step <a href="/hyperdrive/configuration/connect-to-private-database/#12-connect-your-database-using-a-public-hostname">1.2. Connect your database using a public hostname</a>.</li>
<li>In the <strong>Access Service Authentication Token</strong> section, select <strong>Create new (automatic)</strong>.</li>
<li>In the <strong>Access Application</strong> section, select <strong>Create new (automatic)</strong>.</li>
<li>In the <strong>Database connection details</strong> section, enter the database <strong>name</strong>, <strong>user</strong>, and <strong>password</strong>.</li>
</ol>

</div>
