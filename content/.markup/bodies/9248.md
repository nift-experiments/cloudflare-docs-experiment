
1. Open your terminal and run the following command. Replace `<NAME_OF_HYPERDRIVE_CONFIG>` with a name for your Hyperdrive configuration and paste the connection string provided from your database host, or replace `user`, `password`, `HOSTNAME_OR_IP_ADDRESS`, `port`, and `database_name` placeholders with those specific to your database:

<pre><code class="language-sh">npx wrangler hyperdrive create &lt;NAME_OF_HYPERDRIVE_CONFIG&gt; --connection-string=&quot;postgres://user:password@HOSTNAME_OR_IP_ADDRESS:PORT/database_name&quot;
</code></pre>


2. This command outputs a binding for the [Wrangler configuration file](/workers/wrangler/configuration/):

<div class="nb-wrangler-config">

<pre><code class="language-jsonc">{
	&quot;$schema&quot;: &quot;./node_modules/wrangler/config-schema.json&quot;,
	&quot;name&quot;: &quot;hyperdrive-example&quot;,
	&quot;main&quot;: &quot;src/index.ts&quot;,
	&quot;compatibility_date&quot;: &quot;$today&quot;,
	&quot;compatibility_flags&quot;: [
		&quot;nodejs_compat&quot;
	],
	// Pasted from the output of `wrangler hyperdrive create &lt;NAME_OF_HYPERDRIVE_CONFIG&gt; --connection-string=[...]` above.
	&quot;hyperdrive&quot;: [
		{
			&quot;binding&quot;: &quot;HYPERDRIVE&quot;,
			&quot;id&quot;: &quot;&lt;ID OF THE CREATED HYPERDRIVE CONFIGURATION&gt;&quot;
		}
	]
}
</code></pre>

</div>
