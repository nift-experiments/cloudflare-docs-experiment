
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Remote image (transformation)">

<p>When optimizing images outside of Images, the default transformation URL uses the following structure:</p>
<pre><code class="language-txt">https://&lt;ZONE&gt;/cdn-cgi/image/&lt;OPTIONS&gt;/&lt;SOURCE-IMAGE&gt;
</code></pre>
<details class="nb-details"><summary>URL breakdown</summary><div class="nb-details-body">
<table>
<thead>
<tr>
<th>Part</th>
<th>Description</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>&lt;ZONE&gt;</code></td>
<td>Your domain name at Cloudflare. Transformations can be requested on every Cloudflare zone that has transformations enabled.</td>
</tr>
<tr>
<td><code>/cdn-cgi/image/</code></td>
<td>A fixed prefix that identifies that this path is a request to optimize an image. To hide this part, you can set up <a href="/images/optimization/transformations/rewrite-rules/">Transform Rules</a> to serve images from a custom path.</td>
</tr>
<tr>
<td><code>&lt;OPTIONS&gt;</code></td>
<td>A list of optimization parameters, separated by a comma. A valid URL must specify at least one parameter.</td>
</tr>
<tr>
<td><code>&lt;SOURCE-IMAGE&gt;</code></td>
<td>The original image that you want to transform. You can use an absolute path on the origin server or an absolute URL (that starts with <code>https://</code> or <code>http://</code>).</td>
</tr>
</tbody>
</table>
</div></details>

</section>

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Hosted image">

<p>For images stored in Cloudflare Images, use the delivery URL with a variant or custom options:</p>
<pre><code class="language-txt">https://imagedelivery.net/&lt;ACCOUNT_HASH&gt;/&lt;IMAGE-ID&gt;/&lt;VARIANT-OR-OPTIONS&gt;
</code></pre>
<details class="nb-details"><summary>URL breakdown</summary><div class="nb-details-body">
<table>
<thead>
<tr>
<th>Part</th>
<th>Description</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>imagedelivery.net</code></td>
<td>A shared, Cloudflare-owned domain for optimizing images that are hosted in Images. As an alternative, you can also <a href="/images/optimization/hosted-images/serve-from-custom-domains/">serve images from your own domain</a>.</td>
</tr>
<tr>
<td><code>&lt;ACCOUNT_HASH&gt;</code></td>
<td>A unique identifier for your Cloudflare account. You can find your account hash in the <a href="https://dash.cloudflare.com/?to=/:account/images/hosted">Cloudflare dashboard</a> under <strong>Images</strong> &gt; <strong>Developer Resources</strong>.</td>
</tr>
<tr>
<td><code>&lt;IMAGE-ID&gt;</code></td>
<td>The unique identifier for a hosted image. When you upload to Images, Cloudflare automatically generates an image ID. You can also set a <a href="/images/storage/upload-images/upload-custom-path/">custom ID</a> to use your own path structure.</td>
</tr>
<tr>
<td><code>&lt;VARIANT-OR-OPTIONS&gt;</code></td>
<td>Here, you can specify a <a href="/images/optimization/hosted-images/create-variants/">predefined variant</a> or a list of optimization parameters, separated by a comma. A valid URL must specify either a variant or at least one parameter.</td>
</tr>
</tbody>
</table>
</div></details>

</section>
