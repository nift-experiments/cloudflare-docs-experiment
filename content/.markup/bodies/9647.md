<p>To edit member permissions using the dashboard:</p>
<ol>
<li>In the Cloudflare dashboard, go to the <strong>Members</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="3">
<li>Select a member record, then select <strong>Edit</strong>.</li>
<li>Update the scope and roles of their permissions.</li>
<li>Select <strong>Continue to summary</strong>.</li>
<li>Review the information, then select <strong>Update</strong>.</li>
</ol>

</section> <section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<p>To edit member permissions using the API, get a <a href="/api/resources/accounts/subresources/roles/methods/list/">list of roles</a> available for an account.</p>
<p>Then, send a <a href="/api/resources/accounts/subresources/members/methods/update/"><code>PUT</code> request</a> to edit their permissions.</p>
<pre><code class="language-bash">
curl --request PUT \
  --url https://api.cloudflare.com/client/v4/accounts/{account_id}/members/{member_id} \
  --header 'Authorization: Bearer &lt;API_TOKEN&gt;' \
  --header 'Content-Type: application/json' \
  --data '{
	  &quot;roles&quot;: [
	        {
	            &quot;id&quot;: &quot;&lt;ROLE_ID1&gt;&quot;
	        },
	        {
	            &quot;id&quot;: &quot;&lt;ROLE_ID2&gt;&quot;
	        }
	  	]
		}'
</code></pre>
