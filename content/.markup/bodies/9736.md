


<aside class="nb-aside note">


<p>You will need your <a href="/fundamentals/account/find-account-and-zone-ids/">account ID</a> and <a href="/fundamentals/api/get-started/account-owned-tokens/">API token</a> to use the API.</p>

<details class="nb-details"><summary>GRE tunnel</summary><div class="nb-details-body">

<p>Create a <code>POST</code> request <a href="/api/resources/magic_transit/subresources/gre_tunnels/methods/create/">using the API</a> to create a GRE tunnel.</p>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
--url https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/gre_tunnels \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--data &#x27;{
&quot;name&quot;: &quot;&lt;TUNNEL_NAME&gt;&quot;,
&quot;description&quot;: &quot;&lt;TUNNEL_DESCRIPTION&gt;&quot;,
&quot;interface_address&quot;: &quot;&lt;INTERFACE_ADDRESS&gt;&quot;,
&quot;cloudflare_gre_endpoint&quot;: &quot;&lt;CLOUDFLARE_ENDPOINT&gt;&quot;,
&quot;customer_gre_endpoint&quot;: &quot;&lt;CUSTOMER_ENDPOINT&gt;&quot;
}&#x27;</code></pre>
<pre><code class="language-json">{
  &quot;errors&quot;: [
    {

    }

      {

<details class="nb-details"><summary>IPsec tunnel</summary><div class="nb-details-body">

<ol>
<li>Create a <code>POST</code> request <a href="/api/resources/magic_transit/subresources/ipsec_tunnels/methods/create/">using the API</a> to create an IPsec tunnel.</li>
</ol>
<p>Note that in the example, replay protection is disabled by default. You can enable it with the flag <code>&quot;replay_protection&quot;: true</code> for each IPsec tunnel, if the devices you use do not support disabling this feature. If you have already created IPsec tunnels, update them with a <a href="/api/resources/magic_transit/subresources/ipsec_tunnels/methods/update/"><code>PUT</code> request</a>. Refer to <a href="/magic-transit/reference/anti-replay-protection/">Anti-replay protection</a> for more information on this topic.</p>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
 --url https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/ipsec_tunnels \
 --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
 --data &#x27;{
 &quot;name&quot;: &quot;&lt;TUNNEL_NAME&gt;&quot;,
 &quot;description&quot;: &quot;&lt;TUNNEL_DESCRIPTION&gt;&quot;,
 &quot;interface_address&quot;: &quot;&lt;INTERFACE_ADDRESS&gt;&quot;,
 &quot;cloudflare_endpoint&quot;: &quot;&lt;CLOUDFLARE_ENDPOINT&gt;&quot;,
 &quot;customer_endpoint&quot;: &quot;&lt;CUSTOMER_ENDPOINT&gt;&quot;
}&#x27;</code></pre>
<pre><code class="language-json">{
	&quot;errors&quot;: [
		{
			&quot;code&quot;: 1000,
			&quot;message&quot;: &quot;message&quot;
		}
	],
	&quot;messages&quot;: [
		{
			&quot;code&quot;: 1000,
			&quot;message&quot;: &quot;message&quot;
		}
	],
	&quot;result&quot;: {
		&quot;ipsec_tunnels&quot;: [
			{
				&quot;id&quot;: &quot;&lt;IPSEC_TUNNEL_ID&gt;&quot;,
				&quot;interface_address&quot;: &quot;&lt;INTERFACE_CIDR&gt;&quot;,
				&quot;name&quot;: &quot;&lt;TUNNEL_NAME&gt;&quot;,
				&quot;cloudflare_endpoint&quot;: &quot;&lt;IP_ADDRESS&gt;&quot;,
				&quot;customer_endpoint&quot;: &quot;&lt;IP_ADDRESS&gt;&quot;,
				&quot;description&quot;: &quot;&lt;TUNNEL_DESCRIPTION&gt;&quot;,
				&quot;health_check&quot;: {
					&quot;direction&quot;: &quot;unidirectional&quot;,
					&quot;enabled&quot;: true,
					&quot;rate&quot;: &quot;low&quot;,
					&quot;type&quot;: &quot;reply&quot;
				},
				&quot;psk_metadata&quot;: {},
				&quot;replay_protection&quot;: false
			}
		]
	},
	&quot;success&quot;: true
}
</code></pre>
<p>Take note of the tunnel <code>id</code> value. We will use it to generate a pre-shared key (PSK).</p>
<ol start="2">
<li>Create a <code>POST</code> <a href="/api/resources/magic_transit/subresources/ipsec_tunnels/methods/psk_generate/">request</a> to generate a PSK. Use the tunnel <code>id</code> value you received from the previous command.</li>
</ol>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \
 --url https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/ipsec_tunnels/{ipsec_tunnel_id}/psk_generate \
 --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;</code></pre>
<pre><code class="language-json">{
	&quot;result&quot;: {
		&quot;ipsec_id&quot;: &quot;&lt;IPSEC_ID&gt;&quot;,
		&quot;ipsec_tunnel_id&quot;: &quot;&lt;IPSEC_TUNNEL_ID&gt;&quot;,
		&quot;psk&quot;: &quot;&lt;PSK_CODE&gt;&quot;,
		&quot;psk_metadata&quot;: {
			&quot;last_generated_on&quot;: &quot;2025-03-13T14:28:47.054317925Z&quot;
		}
	},
	&quot;success&quot;: true,
	&quot;errors&quot;: [],
	&quot;messages&quot;: []
}
</code></pre>
<p>Take note of your <code>psk</code> value.</p>
<ol start="3">
<li>Create a <code>PUT</code> <a href="/api/resources/magic_transit/subresources/ipsec_tunnels/methods/update/">request</a> to update your IPsec tunnel with the PSK.</li>
</ol>
<pre><code class="language-bash">curl --request PUT --url https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/ipsec_tunnels/{ipsec_tunnel_id}</code></pre>
<pre><code class="language-json">{
  &quot;result&quot;: {
    &quot;modified&quot;: true,
    &quot;modified_ipsec_tunnel&quot;: {

      &quot;description&quot;: &quot;&lt;TUNNEL_DESCRIPTION&gt;&quot;,

<details class="nb-details"><summary>Configure bidirectional health checks</summary><div class="nb-details-body">

<p>Bidirectional health checks are available for GRE and IPsec tunnels. For Magic Transit this option defaults to unidirectional.</p>
<p>You can change this setting via the API with <code>&quot;bidirectional&quot;</code> or <code>&quot;unidirectional&quot;</code>:</p>
<pre><code class="language-bash">curl --request PUT --url https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/ipsec_tunnels/{ipsec_tunnel_id}</code></pre>
