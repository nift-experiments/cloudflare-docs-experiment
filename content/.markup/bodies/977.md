
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="PostgreSQL">

<pre><code class="language-txt">
  	postgres://USERNAME:PASSWORD@HOSTNAME_OR_IP_ADDRESS:PORT/database_name
</code></pre>
<p>Most database providers will provide a connection string you can copy-and-paste directly into Hyperdrive.</p>
<p>To create a Hyperdrive connection, run the <code>wrangler</code> command, replacing the placeholder values passed to the <code>--connection-string</code> flag with the values of your existing database:</p>
<pre><code class="language-sh">npx wrangler hyperdrive create &lt;YOUR_CONFIG_NAME&gt; --connection-string=&quot;postgres://user:password@HOSTNAME_OR_IP_ADDRESS:PORT/database_name&quot;
</code></pre>

</section>
