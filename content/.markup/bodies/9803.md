<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<p>You can create a pool within the <a href="/load-balancing/load-balancers/create-load-balancer/">load balancer workflow</a> or in the <strong>Pools</strong> tab:</p>
<ol>
<li>
<p>Go to <strong>Load Balancing</strong>.</p>
</li>
<li>
<p>Select the <strong>Pools</strong> tab and then <strong>Create pool</strong>.</p>
</li>
<li>
<p>For your pool, enter the following information:</p>
</li>
</ol>
<ul>
<li>A name (must be unique)</li>
<li>A description to provide more detail on the name</li>
<li>A choice for <a href="/load-balancing/understand-basics/traffic-steering/origin-level-steering/"><strong>Endpoint Steering</strong></a>, which affects how your pool routes traffic to each endpoint</li>
</ul>
<ol start="4">
<li>For each endpoint, enter the following information:</li>
</ol>
<ul>
<li>A name (must be unique)</li>
<li>The endpoint address or associated hostname</li>
<li>(Optional) A <a href="/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/cloudflared/tunnel-virtual-networks/"><strong>Virtual Network</strong></a>. Required when the endpoint has a private IP address.</li>
<li>A <a href="/load-balancing/understand-basics/traffic-steering/origin-level-steering/#weights"><strong>Weight</strong></a></li>
<li>(Optional) A <a href="/load-balancing/additional-options/override-http-host-headers/">hostname</a> by clicking <strong>Add host header</strong></li>
<li>(Optional) The destination port to which the traffic will be served.</li>
</ul>
<aside class="nb-aside note">
<h3 class="nb-aside-title" id="body-9803-note">Note</h3>
<p>If your endpoint is a website or application hosted on <a href="/pages/">Cloudflare Pages</a>, you will need to fill in the host header field with the project domain for it to resolve correctly.</p>
</aside>
<ol start="5">
<li>
<p>Repeat this process for additional endpoints in the pool.</p>
</li>
<li>
<p>(Optional) Set up coordinates for <a href="/load-balancing/understand-basics/traffic-steering/steering-policies/proximity-steering/">Proximity Steering</a> on the pool.</p>
</li>
<li>
<p>On the pool, update the following information:</p>
</li>
</ol>
<ul>
<li>
<p><strong>Health Threshold</strong>:
The Health Threshold is the number of healthy endpoints for the pool as a whole to be considered <em>Healthy</em> and receive traffic based on pool order in a load balancer. Increasing this number makes the pool more reliable, but also more likely to become unhealthy.</p>
</li>
<li>
<p><strong>Monitor</strong>: Attach a <a href="/load-balancing/monitors/create-monitor/">monitor</a></p>
</li>
<li>
<p><strong>Health Monitor Regions</strong>: Choose whether to check pool health from <a href="/load-balancing/monitors/#health-monitor-regions">multiple locations</a>, which increases accuracy but can lead to probe traffic to your endpoint</p>
</li>
<li>
<p><strong>Pool Notifications</strong>: You can set up new alerts - and view existing alerts - to be notified when pools are enabled or disabled, or pools or endpoints have changes in their <a href="/load-balancing/understand-basics/health-details/">health status</a>.</p>
</li>
</ul>
<ol start="8">
<li>When finished, select <strong>Save</strong>.</li>
</ol>

</section>
