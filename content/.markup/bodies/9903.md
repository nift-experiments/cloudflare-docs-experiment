

1. Add the following permission to your [`cloudflare_api_token`](https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/api_token):
- `Cloudflare Tunnel Write`

2. Create a tunnel using the [`cloudflare_zero_trust_tunnel_cloudflare`](https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_tunnel_cloudflared) resource.

<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_tunnel_cloudflared&quot; &quot;example_tunnel&quot; {
	account_id = var.cloudflare_account_id
	name       = &quot;Example tunnel&quot;
	config_src = &quot;cloudflare&quot;
}
</code></pre>


3. Route the CIDR of your private network through the tunnel using the [`cloudflare_zero_trust_tunnel_cloudflared_route`](https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_tunnel_cloudflared_route) resource:

<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_tunnel_cloudflared_route&quot; &quot;example_tunnel_route&quot; {
	account_id         = var.cloudflare_account_id
	tunnel_id          = cloudflare_zero_trust_tunnel_cloudflared.example_tunnel.id
	network            = &quot;10.0.0.0/8&quot;
	comment            = &quot;Example tunnel route&quot;
}
</code></pre>


4. Get the [token](/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/remote-tunnel-permissions/) used to run the tunnel:


<pre><code class="language-tf">data &quot;cloudflare_zero_trust_tunnel_cloudflared_token&quot; &quot;tunnel_token&quot; {
	account_id = var.cloudflare_account_id
	tunnel_id = cloudflare_zero_trust_tunnel_cloudflared.example_tunnel.id
}
</code></pre>


If your host machine is not managed in Terraform or you want to install the tunnel manually, you can output the token value to the CLI.
<details class="nb-details" open><summary>Example: Output to CLI</summary><div class="nb-details-body">

<ol>
<li>Output the tunnel token to the Terraform state file:</li>
</ol>
<pre><code class="language-tf">output &quot;tunnel_token&quot; {
	value       = data.cloudflare_zero_trust_tunnel_cloudflared_token.tunnel_token.token
	sensitive   = true
}
</code></pre>
<ol start="2">
<li>Apply the configuration:</li>
</ol>
<pre><code class="language-sh">terraform apply
</code></pre>
<ol start="3">
<li>Read the tunnel token:</li>
</ol>
<pre><code class="language-sh">terraform output -raw tunnel_token
</code></pre>
<pre><code class="language-sh">eyJhIj...
</code></pre>

</div></details>

Alternatively, pass `data.cloudflare_zero_trust_tunnel_cloudflared_token.tunnel_token.token` directly into your host's Terraform configuration or store the token in your secret management tool.

<details class="nb-details" open><summary>Example: Store in HashiCorp Vault</summary><div class="nb-details-body">

<pre><code class="language-tf">resource &quot;vault_generic_secret&quot; &quot;tunnel_token&quot; {
	path         = &quot;kv/cloudflare/tunnel_token&quot;

	data_json = jsonencode({
		&quot;TUNNEL_TOKEN&quot; = data.cloudflare_zero_trust_tunnel_cloudflared_token.tunnel_token.token
	})
}
</code></pre>

</div></details>


5. Install `cloudflared` on a host machine in your private network and run the tunnel:
