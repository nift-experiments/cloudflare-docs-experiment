

<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>Log in to the Cloudflare dashboard and go to <strong>Networking</strong> &gt; <strong>Tunnels</strong>.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>
<p>Select <strong>Create a tunnel</strong>.</p>
</li>
<li>
<p>Enter a name for your tunnel. We suggest choosing a name that reflects the type of resources you want to connect through this tunnel (for example, <code>enterprise-VPC-01</code>).</p>
</li>
<li>
<p>Select <strong>Create Tunnel</strong>.</p>
</li>
<li>
<p>Choose your operating system, then copy the installation command and run it in a terminal on your origin server.</p>
</li>
<li>
<p>Wait for the tunnel to connect. Once the connection is established, select <strong>Continue</strong>.</p>
</li>
<li>
<p>In the <strong>CIDR</strong> tab, enter the CIDR of your private network (for example, <code>10.0.0.0/8</code>).</p>
</li>
<li>
<p>Select <strong>Save tunnel</strong>.</p>
</li>
</ol>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Terraform (v5)">

<ol>
<li>Add the following permission to your <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/api_token"><code>cloudflare_api_token</code></a>:</li>
</ol>
<ul>
<li><code>Cloudflare Tunnel Write</code></li>
</ul>
<ol start="2">
<li>Create a tunnel using the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_tunnel_cloudflared"><code>cloudflare_zero_trust_tunnel_cloudflare</code></a> resource.</li>
</ol>
<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_tunnel_cloudflared&quot; &quot;example_tunnel&quot; {
	account_id = var.cloudflare_account_id
	name       = &quot;Example tunnel&quot;
	config_src = &quot;cloudflare&quot;
}
</code></pre>
<ol start="3">
<li>Route the CIDR of your private network through the tunnel using the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_tunnel_cloudflared_route"><code>cloudflare_zero_trust_tunnel_cloudflared_route</code></a> resource:</li>
</ol>
<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_tunnel_cloudflared_route&quot; &quot;example_tunnel_route&quot; {
	account_id         = var.cloudflare_account_id
	tunnel_id          = cloudflare_zero_trust_tunnel_cloudflared.example_tunnel.id
	network            = &quot;10.0.0.0/8&quot;
	comment            = &quot;Example tunnel route&quot;
}
</code></pre>
<ol start="4">
<li>Get the <a href="/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/remote-tunnel-permissions/">token</a> used to run the tunnel:</li>
</ol>
<pre><code class="language-tf">data &quot;cloudflare_zero_trust_tunnel_cloudflared_token&quot; &quot;tunnel_token&quot; {
	account_id = var.cloudflare_account_id
	tunnel_id = cloudflare_zero_trust_tunnel_cloudflared.example_tunnel.id
}
</code></pre>
<p>If your host machine is not managed in Terraform or you want to install the tunnel manually, you can output the token value to the CLI.</p>
<details class="nb-details" open><summary>Example: Output to CLI</summary><div class="nb-details-body">
<ol>
<li>Output the tunnel token to the Terraform state file:</li>
</ol>
<pre><code class="language-tf">output &quot;tunnel_token&quot; {
	value       = data.cloudflare_zero_trust_tunnel_cloudflared_token.tunnel_token.token
	sensitive   = true
}
</code></pre>
<ol start="2">
<li>Apply the configuration:</li>
</ol>
<pre><code class="language-sh">terraform apply
</code></pre>
<ol start="3">
<li>Read the tunnel token:</li>
</ol>
<pre><code class="language-sh">terraform output -raw tunnel_token
</code></pre>
<pre><code class="language-sh">eyJhIj...
</code></pre>
</div></details>
<p>Alternatively, pass <code>data.cloudflare_zero_trust_tunnel_cloudflared_token.tunnel_token.token</code> directly into your host's Terraform configuration or store the token in your secret management tool.</p>
<details class="nb-details" open><summary>Example: Store in HashiCorp Vault</summary><div class="nb-details-body">
<pre><code class="language-tf">resource &quot;vault_generic_secret&quot; &quot;tunnel_token&quot; {
	path         = &quot;kv/cloudflare/tunnel_token&quot;

	data_json = jsonencode({
		&quot;TUNNEL_TOKEN&quot; = data.cloudflare_zero_trust_tunnel_cloudflared_token.tunnel_token.token
	})
}
</code></pre>
</div></details>
