<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="API">

<ol>
<li>Update the default device settings profile:</li>
</ol>
<pre><code class="language-bash">curl --request PATCH \
https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/devices/policy \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--header &quot;Content-Type: application/json&quot; \
--data '{
  &quot;allow_mode_switch&quot;: false,
  &quot;allow_updates&quot;: false,
  &quot;allowed_to_leave&quot;: false,
  &quot;auto_connect&quot;: 900,
  &quot;captive_portal&quot;: 180,
  &quot;disable_auto_fallback&quot;: true,
  &quot;exclude_office_ips&quot;: false,
  &quot;service_mode_v2&quot;: {
    &quot;mode&quot;: &quot;warp&quot;
  },
  &quot;support_url&quot;: &quot;https://it.company.com/help&quot;,
  &quot;switch_locked&quot;: true
}'
</code></pre>
<ol start="2">
<li>Update global settings:</li>
</ol>
<pre><code class="language-bash">curl --request PUT \
https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/devices/settings \
--header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \
--header &quot;Content-Type: application/json&quot; \
--data '{
  &quot;disable_for_time&quot;: 3600,
  &quot;root_certificate_installation_enabled&quot;: true
}'
</code></pre>

<ol>
<li>Add the following permission to your <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/api_token"><code>cloudflare_api_token</code></a>:</li>
</ol>
<ul>
<li><code>Zero Trust Write</code></li>
</ul>
<ol start="2">
<li>Configure default profile settings using the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_device_default_profile"><code>cloudflare_zero_trust_device_default_profile</code></a> resource:</li>
</ol>
<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_device_default_profile&quot; &quot;default_profile&quot; {
	account_id            = var.cloudflare_account_id
	allow_mode_switch     = false
	allow_updates         = false
	allowed_to_leave      = false
	auto_connect          = 600
	captive_portal        = 180
	disable_auto_fallback = true
	exclude_office_ips    = false
	service_mode_v2       = {mode = &quot;warp&quot;}
	support_url           = &quot;https://support.example.com&quot;
	switch_locked         = true
	tunnel_protocol       = &quot;wireguard&quot;
}
</code></pre>
<ol start="3">
<li>Configure <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/configure/settings/#global-settings">global settings</a> using the <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_device_settings"><code>cloudflare_zero_trust_device_settings</code></a> resource:</li>
</ol>
<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_device_settings&quot; &quot;global_warp_settings&quot; {
	account_id            = var.cloudflare_account_id
	disable_for_time      = 3600
	root_certificate_installation_enabled = true
	use_zt_virtual_ip     = false
}
</code></pre>
