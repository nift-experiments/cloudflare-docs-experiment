<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Dashboard">

<ol>
<li>In the <a href="https://dash.cloudflare.com/">Cloudflare dashboard</a>, go to <strong>Zero Trust</strong> &gt; <strong>Traffic policies</strong> &gt; <strong>Firewall policies</strong>. Choose either <strong>Network</strong> or <strong>HTTP</strong>.</li>
<li>Add a policy and select the <em>Allow</em> action. Alternatively, choose any existing <em>Allow</em> policy.</li>
<li>Under <strong>Step 4 - Configure policy settings</strong>, select <strong>Edit</strong> next to <strong>Enforce Cloudflare One Client session duration</strong>.</li>
<li>Enter a session expiration time in <code>1h30m0s</code> format and save.</li>
<li>Save the policy.</li>
</ol>

</section>
<section class="nb-tab-panel" role="tabpanel" data-nb-tabs-content data-nb-tab-label="Terraform (v5)">

<ol>
<li>Add the following permission to your <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/api_token"><code>cloudflare_api_token</code></a>:</li>
</ol>
<ul>
<li><code>Zero Trust Write</code></li>
</ul>
<ol start="2">
<li>
<p>Choose a Network (<code>l4</code>) or HTTP (<code>http</code>) policy with an Allow action.</p>
</li>
<li>
<p>In the policy's <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_gateway_policy"><code>rule_settings</code></a>, use the <code>check_session</code> argument to enable and configure a session timeout:</p>
</li>
</ol>
<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_gateway_policy&quot; &quot;network_allow_wiki_IPs&quot; {
	name        = &quot;Company Wiki Network policy&quot;
	enabled     = true
	account_id  = var.cloudflare_account_id
	description = &quot;Managed by Terraform - Allow employees to access company wiki IPs.&quot;
	precedence  = 103
	action      = &quot;allow&quot;
	filters     = [&quot;l4&quot;]
	traffic     = &quot;net.dst.ip in ${&quot;$&quot;}${cloudflare_zero_trust_list.wiki_IPs.id}&quot;
	identity    = &quot;identity.email matches \&quot;.*@example.com\&quot;&quot;

	rule_settings = {
		check_session = {
			enforce = true
			duration = &quot;1h30m0s&quot;
		}
	}
}
</code></pre>
