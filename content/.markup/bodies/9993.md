

1.  Add the following permission to your [`cloudflare_api_token`](https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/api_token):
- `Zero Trust Write`

2.  Choose a DNS policy with a Block action.

3.  In the policy's [`rule_settings`](https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/zero_trust_gateway_policy), turn on `block_page_enabled`. If you have configured a [custom Gateway block page](/cloudflare-one/reusable-components/custom-pages/gateway-block-page/#customize-the-block-page), you can optionally show an additional `block_reason` when traffic is blocked by this policy.

<pre><code class="language-tf">resource &quot;cloudflare_zero_trust_gateway_policy&quot; &quot;dns_block_security_categories&quot; {
	name        = &quot;Block DNS Security Categories&quot;
	enabled     = true
	account_id  = var.cloudflare_account_id
	description = &quot;Managed by Terraform - Generic security policy based on Cloudflare Threat Intelligence categories.&quot;
	precedence  = 101
	action      = &quot;block&quot;
	filters     = [&quot;dns&quot;]
	/* Categories being enabled here:
		&#45; 80:  &quot;Command and Control &amp; Botnet&quot;
		&#45; 83:  &quot;Cryptomining&quot;
		&#45; 117: &quot;Malware&quot;
		&#45; 131: &quot;Phishing&quot;
		&#45; 153: &quot;Spyware&quot;
		&#45; 175: &quot;DNS Tunneling&quot;
		&#45; 176: &quot;DGA Domains&quot;
		&#45; 178: &quot;Brand Embedding&quot;
	&#42;/
	traffic = &quot;any(dns.security_category[*] in {80 83 117 131 153 175 176 178})&quot;
	identity = &quot;&quot;

	rule_settings = {
		block_page_enabled = true
		block_reason  = &quot;This domain has been flagged as a potential security risk.&quot; // Adds an additional message to the custom block page. Requires enabling custom block page in cloudflare_zero_trust_gateway_settings.
	}
}
</code></pre>
