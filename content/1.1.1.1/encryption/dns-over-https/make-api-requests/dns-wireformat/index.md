<p>Cloudflare respects DNS wireformat as defined in <a href="https://www.rfc-editor.org/rfc/rfc1035.html">RFC 1035</a>.</p>
<p>To send queries using DNS wireformat, set the header <code>accept: application/dns-message</code>, or <code>content-type: application/dns-message</code> if using <code>POST</code> to indicate the media type of the query.</p>
<p>Queries using DNS wireformat can be sent using <code>POST</code> or <code>GET</code>.</p>
<h2 id="using-post">Using POST</h2>
<p>When making requests using <code>POST</code>, the DNS query is included as the message body of the HTTP request, and the MIME type (see below) is included in the <code>Content-Type</code> request header. Cloudflare will use the message body of the HTTP request as sent by the client, so the message body should not be encoded.</p>
<p>The following is an example request. The same DNS query for <code>www.example.com</code>, using the POST method would be:</p>
<pre><code class="language-txt">:method = POST&#10;:scheme = https&#10;:authority = cloudflare-dns.com&#10;:path = /dns-query&#10;accept = application/dns-message&#10;content-type = application/dns-message&#10;content-length = 33&#10;&#10;&lt;33 bytes represented by the following hex encoding&gt;&#10;00 00 01 00 00 01 00 00  00 00 00 00 03 77 77 77&#10;07 65 78 61 6d 70 6c 65  03 63 6f 6d 00 00 01 00&#10;01&#10;</code></pre>
<p>And would return the answer in wireformat:</p>
<pre><code class="language-txt">:status = 200&#10;content-type = application/dns-message&#10;content-length = 64&#10;cache-control = max-age=128&#10;&#10;&lt;64 bytes represented by the following hex encoding&gt;&#10;00 00 81 80 00 01 00 01  00 00 00 00 03 77 77 77&#10;07 65 78 61 6d 70 6c 65  03 63 6f 6d 00 00 01 00&#10;01 03 77 77 77 07 65 78  61 6d 70 6c 65 03 63 6f&#10;6d 00 00 01 00 01 00 00  00 80 00 04 C0 00 02 01&#10;</code></pre>
<p>To try this using cURL, write:</p>
<pre><code class="language-sh">echo -n &#x27;q80BAAABAAAAAAAAA3d3dwdleGFtcGxlA2NvbQAAAQAB&#x27; | base64 --decode | curl --header &#x27;content-type: application/dns-message&#x27; --data-binary @- https://cloudflare-dns.com/dns-query --output - | hexdump&#10;</code></pre>
<h2 id="using-get">Using GET</h2>
<p>When making requests using <code>GET</code>, the DNS query is encoded into the URL. The <code>accept</code> header can be used to indicate the MIME type (default: <code>application/dns-message</code>).</p>
