<p>1.1.1.1 is Cloudflare's public <a href="https://www.cloudflare.com/learning/dns/what-is-dns/">DNS resolver</a>. When you type a domain name like <code>cloudflare.com</code> into your browser, a DNS resolver translates that name into an IP address (for example, <code>104.16.123.96</code>) so your device knows which server to contact.</p>
<p>Most people use the DNS resolver assigned by their Internet Service Provider (ISP). Switching to 1.1.1.1 gives you a faster, more private alternative. Unlike most DNS resolvers, 1.1.1.1 does not sell user data to advertisers.</p>
<p>1.1.1.1 has been measured as the <a href="https://www.dnsperf.com/#!dns-resolvers">fastest public DNS resolver</a>. It runs on Cloudflare's network in <a href="https://www.cloudflare.com/network/">hundreds of cities worldwide</a> and has access to the addresses of millions of domains on the same servers it runs on.</p>
<p>1.1.1.1 is free. Setting it up takes minutes and does not require any special software.</p>
