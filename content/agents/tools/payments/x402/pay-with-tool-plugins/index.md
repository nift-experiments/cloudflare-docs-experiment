<p>The following examples show how to add x402 payment handling to AI coding tools. When the tool encounters a 402 response, it pays automatically and retries.</p>
<p>Both examples require:</p>
<ul>
<li>A wallet private key (set as <code>X402_PRIVATE_KEY</code> environment variable)</li>
<li>The x402 packages: <code>@x402/fetch</code>, <code>@x402/evm</code>, and <code>viem</code></li>
</ul>
<h2 id="opencode-plugin">OpenCode plugin</h2>
<p>OpenCode plugins expose tools to the agent. To create an <code>x402-fetch</code> tool that handles 402 responses, create <code>.opencode/plugins/x402-payment.ts</code>:</p>
<pre tabindex="0"><code class="language-ts">// Use base-sepolia for testing. Get test USDC from https://faucet.circle.com/&#10;import type { Plugin } from &quot;@opencode-ai/plugin&quot;;&#10;import { tool } from &quot;@opencode-ai/plugin&quot;;&#10;import { x402Client, wrapFetchWithPayment } from &quot;@x402/fetch&quot;;&#10;import { registerExactEvmScheme } from &quot;@x402/evm/exact/client&quot;;&#10;import { privateKeyToAccount } from &quot;viem/accounts&quot;;&#10;&#10;export const X402PaymentPlugin: Plugin = async () =&gt; ({&#10;	tool: {&#10;		&quot;x402-fetch&quot;: tool({&#10;			description:&#10;				&quot;Fetch a URL with x402 payment. Use when webfetch returns 402.&quot;,&#10;			args: {&#10;				url: tool.schema.string().describe(&quot;The URL to fetch&quot;),&#10;				timeout: tool.schema.number().optional().describe(&quot;Timeout in seconds&quot;),&#10;			},&#10;			async execute(args) {&#10;				const privateKey = process.env.X402_PRIVATE_KEY;&#10;				if (!privateKey) {&#10;					throw new Error(&quot;X402_PRIVATE_KEY environment variable is not set.&quot;);&#10;				}&#10;&#10;				// Your human-in-the-loop confirmation flow...&#10;				// const approved = await confirmPayment(args.url, estimatedCost);&#10;				// if (!approved) throw new Error(&quot;Payment declined by user&quot;);&#10;&#10;				const account = privateKeyToAccount(privateKey as `0x${string}`);&#10;				const client = new x402Client();&#10;				registerExactEvmScheme(client, { signer: account });&#10;				const paidFetch = wrapFetchWithPayment(fetch, client);&#10;&#10;				const response = await paidFetch(args.url, {&#10;					method: &quot;GET&quot;,&#10;					signal: args.timeout&#10;						? AbortSignal.timeout(args.timeout * 1000)&#10;						: undefined,&#10;				});&#10;&#10;				if (!response.ok) {&#10;					throw new Error(`${response.status} ${response.statusText}`);&#10;				}&#10;&#10;				return await response.text();&#10;			},&#10;		}),&#10;	},&#10;});&#10;</code></pre>
<p>When the built-in <code>webfetch</code> returns a 402, the agent calls <code>x402-fetch</code> to retry with payment.</p>
<h2 id="claude-code-hook">Claude Code hook</h2>
<p>Claude Code hooks intercept tool results. To handle 402s transparently, create a script at <code>.claude/scripts/handle-x402.mjs</code>:</p>
<pre tabindex="0"><code class="language-js">// Use base-sepolia for testing. Get test USDC from https://faucet.circle.com/&#10;import { x402Client, wrapFetchWithPayment } from &quot;@x402/fetch&quot;;&#10;import { registerExactEvmScheme } from &quot;@x402/evm/exact/client&quot;;&#10;import { privateKeyToAccount } from &quot;viem/accounts&quot;;&#10;&#10;const input = JSON.parse(await readStdin());&#10;&#10;const haystack = JSON.stringify(input.tool_response ?? input.error ?? &quot;&quot;);&#10;if (!haystack.includes(&quot;402&quot;)) process.exit(0);&#10;&#10;const url = input.tool_input?.url;&#10;if (!url) process.exit(0);&#10;&#10;const privateKey = process.env.X402_PRIVATE_KEY;&#10;if (!privateKey) {&#10;	console.error(&quot;X402_PRIVATE_KEY not set.&quot;);&#10;	process.exit(2);&#10;}&#10;&#10;try {&#10;	// Your human-in-the-loop confirmation flow...&#10;	// const approved = await confirmPayment(url);&#10;	// if (!approved) process.exit(0);&#10;&#10;	const account = privateKeyToAccount(privateKey);&#10;	const client = new x402Client();&#10;	registerExactEvmScheme(client, { signer: account });&#10;	const paidFetch = wrapFetchWithPayment(fetch, client);&#10;&#10;	const res = await paidFetch(url, { method: &quot;GET&quot; });&#10;	const text = await res.text();&#10;&#10;	if (!res.ok) {&#10;		console.error(`Paid fetch failed: ${res.status}`);&#10;		process.exit(2);&#10;	}&#10;&#10;	console.log(&#10;		JSON.stringify({&#10;			hookSpecificOutput: {&#10;				hookEventName: &quot;PostToolUse&quot;,&#10;				additionalContext: `Paid for &quot;${url}&quot; via x402:\n${text}`,&#10;			},&#10;		}),&#10;	);&#10;} catch (err) {&#10;	console.error(`x402 payment failed: ${err.message}`);&#10;	process.exit(2);&#10;}&#10;&#10;function readStdin() {&#10;	return new Promise((resolve) =&gt; {&#10;		let data = &quot;&quot;;&#10;		process.stdin.on(&quot;data&quot;, (chunk) =&gt; (data += chunk));&#10;		process.stdin.on(&quot;end&quot;, () =&gt; resolve(data));&#10;	});&#10;}&#10;</code></pre>
<p>Register the hook in <code>.claude/settings.json</code>:</p>
<pre tabindex="0"><code class="language-json">{&#10;	&quot;hooks&quot;: {&#10;		&quot;PostToolUse&quot;: [&#10;			{&#10;				&quot;matcher&quot;: &quot;WebFetch&quot;,&#10;				&quot;hooks&quot;: [&#10;					{&#10;						&quot;type&quot;: &quot;command&quot;,&#10;						&quot;command&quot;: &quot;node .claude/scripts/handle-x402.mjs&quot;,&#10;						&quot;timeout&quot;: 30&#10;					}&#10;				]&#10;			}&#10;		]&#10;	}&#10;}&#10;</code></pre>
