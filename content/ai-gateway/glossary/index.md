<h2 id="configuration-hierarchy">Configuration hierarchy</h2>
<p>Settings in AI Gateway can be configured at two levels: <strong>Request</strong> and <strong>Gateway</strong>. Since the same settings can be configured in multiple locations, the following hierarchy determines which value is applied:</p>
<ol>
<li><strong>Request-level headers</strong>:
Headers included in individual requests take precedence over gateway-level settings.</li>
<li><strong>Gateway-level settings</strong>:
Act as the default if no headers are set at the request level.</li>
</ol>
<p>This hierarchy ensures consistent behavior, prioritizing the most specific configurations. Use request-level headers for fine-tuned control, and gateway settings for general defaults.</p>
<p>Some restrictive settings are additive. The <code>cf-aig-no-wholesale</code> header can require provider credentials for a third-party provider request, but it cannot turn off <strong>Require provider credentials</strong> when that gateway setting is on.</p>
