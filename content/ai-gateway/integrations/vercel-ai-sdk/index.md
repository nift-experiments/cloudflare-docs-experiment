<p>The <a href="https://sdk.vercel.ai/">Vercel AI SDK</a> is a TypeScript library for building AI applications. The SDK supports many different AI providers, tools for streaming completions, and more.
To use Cloudflare AI Gateway with Vercel AI SDK, you will need to use the <code>ai-gateway-provider</code> package.</p>
<h2 id="installation">Installation</h2>
<pre><code class="language-bash">npm install ai-gateway-provider&#10;</code></pre>
