<p>Cloudflare's AI Gateway offers an OpenAI-compatible <code>/chat/completions</code> endpoint, enabling integration with multiple AI providers using a single URL. This feature simplifies the integration process, allowing for seamless switching between different models without significant code modifications.</p>
<h2 id="endpoint-url">Endpoint URL</h2>
<pre tabindex="0"><code class="language-txt">https://gateway.ai.cloudflare.com/v1/{account_id}/default/compat/chat/completions&#10;</code></pre>
<p>Replace <code>{account_id}</code> with your Cloudflare account ID. The <code>default</code> gateway is created automatically on your first request — no setup needed. You can also replace <code>default</code> with a specific gateway ID if you have already created one.</p>
<h2 id="parameters">Parameters</h2>
<p>Switch providers by changing the <code>model</code> and <code>apiKey</code> parameters.</p>
<p>Specify the model using <code>{provider}/{model}</code> format. For example:</p>
<ul>
<li><code>openai/gpt-5-mini</code></li>
<li><code>google-ai-studio/gemini-2.5-flash</code></li>
<li><code>anthropic/claude-sonnet-4-5</code></li>
</ul>
