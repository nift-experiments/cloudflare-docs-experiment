<p>This tutorial creates an AI Search instance that indexes your website, then adds a working search bar, chat bubble, and search modal to your site's frontend. It uses the <a href="/ai-search/configuration/retrieval/public-endpoint/embed-search-snippets/">UI snippets</a>, pre-built web components that connect to your instance's public endpoint, so you add search with only a few lines of frontend code.</p>
<p><strong>What you will build:</strong> An AI Search instance that indexes your website, and a search bar, chat bubble, and search modal added to your site's frontend that query that content.</p>
<p><img src="/assets/upstream/images/ai-search/ui-snippet-search-modal.png" alt="The AI Search modal opened over a site, showing a search input, keyboard navigation hints, and a Powered by Cloudflare AI Search label." /></p>

<h2 id="4-add-the-search-components"><ol start="4">
<li>Add the search components</li>
</ol></h2>
<p>Import the snippet library in one of your components and add the tags where you want search to appear. Importing the package once registers the components with the browser. The following example adds a search bar, a floating chat bubble, and a search modal that opens with <code>Cmd/Ctrl+K</code> to the app's root component. Replace <code>&lt;PUBLIC_ENDPOINT_ID&gt;</code> with your public endpoint ID from step two.</p>
<pre><code class="language-tsx">import type { CSSProperties } from &quot;react&quot;;&#10;import &quot;@cloudflare/ai-search-snippet&quot;;&#10;&#10;export default function App() {&#10;	return (&#10;		&lt;div&gt;&#10;			&lt;search-bar-snippet&#10;				api-url=&quot;https://&lt;PUBLIC_ENDPOINT_ID&gt;.search.ai.cloudflare.com/&quot;&#10;				placeholder=&quot;Search...&quot;&#10;				max-results={50}&#10;				max-render-results={10}&#10;				show-url=&quot;true&quot;&#10;				show-date=&quot;true&quot;&#10;			/&gt;&#10;			&lt;chat-bubble-snippet&#10;				api-url=&quot;https://&lt;PUBLIC_ENDPOINT_ID&gt;.search.ai.cloudflare.com/&quot;&#10;				style={&#10;					{&#10;						&quot;--search-snippet-primary-color&quot;: &quot;#F6821F&quot;,&#10;					} as CSSProperties&#10;				}&#10;			/&gt;&#10;			&lt;search-modal-snippet&#10;				api-url=&quot;https://&lt;PUBLIC_ENDPOINT_ID&gt;.search.ai.cloudflare.com/&quot;&#10;				placeholder=&quot;Search documentation...&quot;&#10;				shortcut=&quot;k&quot;&#10;				show-url=&quot;true&quot;&#10;				show-date=&quot;true&quot;&#10;			/&gt;&#10;		&lt;/div&gt;&#10;	);&#10;}&#10;</code></pre>
<h3 id="add-typescript-declarations-for-the-custom-elements">Add TypeScript declarations for the custom elements</h3>
<p>The snippet package ships type definitions for its classes, but it does not tell TypeScript that <code>&lt;search-bar-snippet&gt;</code> and the other tags are valid JSX elements. The Vite development server does not type-check, so the app runs without this step, but adding a declaration file keeps <code>.tsx</code> type checks and editors from reporting errors on the custom tags.</p>
<p>Create a declaration file such as <code>src/ai-search-snippet.d.ts</code>:</p>
<pre><code class="language-ts">import type { HTMLAttributes } from &quot;react&quot;;&#10;&#10;// Register the snippet web components as valid JSX elements. The index&#10;// signature allows their custom attributes (such as api-url and placeholder).&#10;type SnippetElement = HTMLAttributes&lt;HTMLElement&gt; &amp; {&#10;	[attribute: string]: unknown;&#10;};&#10;&#10;declare module &quot;react&quot; {&#10;	namespace JSX {&#10;		interface IntrinsicElements {&#10;			&quot;search-bar-snippet&quot;: SnippetElement;&#10;			&quot;chat-bubble-snippet&quot;: SnippetElement;&#10;			&quot;search-modal-snippet&quot;: SnippetElement;&#10;		}&#10;	}&#10;}&#10;</code></pre>
<p>This types the tags loosely so any attribute is allowed. For stricter, per-component types, refer to the <a href="https://github.com/cloudflare/ai-search-snippet/blob/main/apps/demo-react/index.d.ts">React demo declarations</a> in the snippet repository.</p>
