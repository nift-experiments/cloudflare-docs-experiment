<h2 id="if">if</h2>
<p>Usage:</p>
<pre><code class="language-sql">if(&lt;condition&gt;, &lt;true_expression&gt;, &lt;false_expression&gt;)&#10;</code></pre>
<p>Returns <code>&lt;true_expression&gt;</code> if <code>&lt;condition&gt;</code> evaluates to true, else returns <code>&lt;false_expression&gt;</code>.</p>
<p>Example:</p>
<pre><code class="language-sql">if(temp &gt; 20, &#x27;It is warm&#x27;, &#x27;Bring a jumper&#x27;)&#10;</code></pre>
