<h2 id="touint8">toUInt8 <span class="nb-badge">New</span></h2>
<p>Usage:</p>
<pre tabindex="0"><code class="language-sql">toUInt8(&lt;expression&gt;)&#10;</code></pre>
<p>Converts any numeric expression, or expression resulting in a string representation of a decimal, into an unsigned 8 bit integer.</p>
<p>Behaviour for negative numbers is undefined.</p>
