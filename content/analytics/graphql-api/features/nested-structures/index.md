<p>Two kinds of nested structures that are supported: <strong>arrays</strong> and <strong>maps</strong>. Fields of either of these types are arrays; when they are part of a query result, which is already an array of objects, they become nested arrays.</p>
<h2 id="arrays">Arrays</h2>
<p>The GraphQL API supports two different sorts of arrays:</p>
<ul>
<li>Some arrays contain scalar types (for example, <code>[String]</code>) and function like ordinary fields that <a href="/analytics/graphql-api/features/filtering/">can be filtered</a></li>
<li>Some arrays contain more complex types (for example, <code>[Subrequest]</code>.) The following section describes their behaviour.</li>
</ul>
<p>Arrays of non-scalar types behave as a single value. There is no way to paginate through, filter, filter by, group, or group by the array.</p>
<p>On the other hand, you can choose which fields of the underlying type you want fetched.</p>
<p>For example, given arrays like this:</p>
<pre tabindex="0"><code class="language-javascript">type SubRequest {&#10;    url: String!&#10;    status: Int&#10;}&#10;&#10;type Request {&#10;    date: Date!&#10;    datetime: DateTime!&#10;    subRequests: [SubRequest!]!&#10;}&#10;</code></pre>
<p>You can run a query to get the status by subrequest:</p>
<pre tabindex="0"><code class="language-javascript">{&#10;    requests {&#10;        date&#10;        subRequests {&#10;            &#35; discard the url, only need the status&#10;            status&#10;        }&#10;    }&#10;}&#10;</code></pre>
<p>The results would be:</p>
<pre tabindex="0"><code class="language-javascript">{&#10;    &quot;requests&quot;: [&#10;        {&#10;            &quot;date&quot;: &quot;2018-01-01&quot;,&#10;            &quot;subRequests&quot;: [{&quot;status&quot;: 404}, {&quot;status&quot;: 200}, {&quot;status&quot;: 404}]&#10;        },&#10;        {&#10;            &quot;date&quot;: &quot;2018-01-01&quot;,&#10;            &quot;subRequests&quot;: [{&quot;status&quot;: 200}]&#10;        }&#10;    ]&#10;}&#10;</code></pre>
<h2 id="maps">Maps</h2>
<p>Maps behave like arrays, but can be grouped using the <code>sum</code> function. They are used in aggregated datasets, such as <code>httpRequest1dGroups</code>.</p>
<p>Example maps:</p>
<pre tabindex="0"><code class="language-javascript">type URLStatsMapElem {&#10;    url: String!&#10;    requests: Int&#10;    bytes: Int&#10;}&#10;&#10;type Request {&#10;    date: Date!&#10;    datetime: DateTime!&#10;    urlStatsMap: [URLStatsMapElem!]!&#10;}&#10;</code></pre>
<p>Query:</p>
<pre tabindex="0"><code class="language-javascript">{&#10;    requests {&#10;        sum {&#10;            urlStatsMap {&#10;                url&#10;                requests&#10;                bytes&#10;            }&#10;        }&#10;        dimensions {&#10;            date&#10;        }&#10;    }&#10;}&#10;</code></pre>
<p>Response:</p>
<pre tabindex="0"><code class="language-javascript">{&#10;    &quot;requests&quot;: [&#10;        {&#10;            &quot;sum&quot;: {&#10;                &quot;urlStatsMap&quot;: [&#10;                    {&#10;                        &quot;url&quot;: &quot;hello-world.org/1&quot;,&#10;                        &quot;requests&quot;: 123,&#10;                        &quot;bytes&quot;: 1024&#10;                    },&#10;                    {&#10;                        &quot;url&quot;: &quot;hello-world.org/10&quot;,&#10;                        &quot;requests&quot;: 1230,&#10;                        &quot;bytes&quot;: 10240&#10;                    }&#10;                ]&#10;            }&#10;            &quot;dimensions&quot; {&#10;                &quot;date&quot;: &quot;2018-10-19&quot;&#10;            }&#10;        },&#10;        ...&#10;    ]&#10;}&#10;</code></pre>
<h2 id="examples">Examples</h2>
<p>Query array fields in raw datasets:</p>
<pre tabindex="0"><code class="language-graphql">query NestedFields($zoneTag: string, $start: Time, $end: Time) {&#10;	viewer {&#10;		zones(filter: { zoneTag: $zoneTag }) {&#10;			events(limit: 2, filter: { datetime_geq: $start, datetime_leq: $end }) {&#10;				matches {&#10;					ruleId&#10;					action&#10;					source&#10;				}&#10;			}&#10;		}&#10;	}&#10;}&#10;</code></pre>
<p>Example response:</p>
<pre tabindex="0"><code class="language-javascript">{&#10;  &quot;data&quot;: {&#10;    &quot;viewer&quot;: {&#10;      &quot;zones&quot;: [&#10;        {&#10;          &quot;events&quot;: [&#10;            {&#10;              &quot;matches&quot;: [&#10;                {&#10;                  &quot;action&quot;: &quot;allow&quot;,&#10;                  &quot;ruleId&quot;: &quot;rule-id-one&quot;,&#10;                  &quot;source&quot;: &quot;asn&quot;&#10;                },&#10;                {&#10;                  &quot;action&quot;: &quot;block&quot;,&#10;                  &quot;ruleId&quot;: &quot;rule-id-two&quot;,&#10;                  &quot;source&quot;: &quot;asn&quot;&#10;                }&#10;              ]&#10;            }&#10;          ]&#10;        }&#10;      ]&#10;    }&#10;  },&#10;  &quot;errors&quot;: null&#10;}&#10;</code></pre>
<p>Query maps fields in aggregated datasets:</p>
<pre tabindex="0"><code class="language-graphql">query MapCapacity(&#10;	$zoneTag: string&#10;	$dateStart: Date&#10;	$dateEnd: Date&#10;	$start: Time&#10;	$end: Time&#10;) {&#10;	viewer {&#10;		zones(filter: { zoneTag: $zoneTag }) {&#10;			httpRequests1mGroups(&#10;				limit: 10&#10;				filter: {&#10;					date_geq: $dateStart&#10;					date_leq: $dateEnd&#10;					datetime_geq: $start&#10;					datetime_lt: $end&#10;				}&#10;			) {&#10;				sum {&#10;					countryMap {&#10;						clientCountryName&#10;						requests&#10;						bytes&#10;						threats&#10;					}&#10;				}&#10;				dimensions {&#10;					datetimeHour&#10;				}&#10;			}&#10;		}&#10;	}&#10;}&#10;</code></pre>
