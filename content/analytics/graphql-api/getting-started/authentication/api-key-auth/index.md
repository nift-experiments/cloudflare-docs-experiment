<p>API keys are unique to each Cloudflare user and used only for authentication. An API key does not authorize access to accounts or zones. To ensure that the GraphQL Analytics API authenticates your queries, retrieve your Cloudflare Global API Key.</p>
<p>Learn how to <a href="/fundamentals/api/get-started/keys/">retrieve your API Key in the Cloudflare dashboard</a>.</p>
