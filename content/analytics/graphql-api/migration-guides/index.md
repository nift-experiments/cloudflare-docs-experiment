<h2 id="graphql-migrations">GraphQL migrations</h2>
<p>If you are currently using the deprecated <code>httpRequests1mByColoGroups</code> or <code>httpRequests1dByColoGroups</code> GraphQL API nodes, the <a href="/analytics/graphql-api/migration-guides/graphql-api-analytics/">HTTP Requests by Colo Groups to HTTP Requests by Adaptive Groups</a> guide will help you migrate your queries to use the <code>httpRequestsAdaptiveGroups</code> node.</p>
<h2 id="zone-analytics-migrations">Zone Analytics migrations</h2>
<p>If you are currently using the Zone Analytics API, the following guide will help you migrate your queries to the new GraphQL Analytics API:</p>
<ul>
<li><a href="/analytics/graphql-api/migration-guides/zone-analytics/">Zone Analytics to GraphQL Analytics</a></li>
<li><a href="/analytics/graphql-api/migration-guides/zone-analytics-colos/">Zone Analytics Colos Endpoint to GraphQL Analytics</a></li>
</ul>
<h2 id="network-analytics-migrations">Network Analytics migrations</h2>
<p>If you are currently using the Network Analytics v1 (NAv1) GraphQL nodes, the <a href="/analytics/graphql-api/migration-guides/network-analytics-v2/">Network Analytics v1 to Network Analytics v2</a> guide will help you migrate your queries to the new Network Analytics v2.</p>
