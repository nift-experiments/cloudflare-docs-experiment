<p>The Zone Analytics API allows you to get request data by zone. It offers optional <code>since</code> and <code>until</code> parameters to specify the request time period and a <code>continuous</code> parameter to indicate whether the time period should be moved backward to find a period with completely aggregated data.</p>
<p>For example, here is a sample curl call to get data for a two minute period:</p>
<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/zones/&lt;ZONE_ID&gt;/analytics/dashboard?since=2019-09-08T20:00:00Z&amp;until=2019-09-08T20:02:00Z&amp;continuous=false&quot; \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; --silent | jq .&#10;</code></pre>

<p>As you can see from the response, Zone Analytics returns metrics along many dimensions and does not give you the option to control what you receive. With GraphQL Analytics, you can ask for only the data that you need. However, if you wanted to get exactly the same metrics and dimensions as you would from Zone Analytics, here is the query you would make:</p>
<pre><code class="language-graphql">query ZoneAnalyticsMigrationSample($zoneTag: string, $start: Time, $end: Time) {&#10;	viewer {&#10;		zones(filter: { zoneTag: $zoneTag }) {&#10;			httpRequests1mGroups(&#10;				orderBy: [datetimeFiveMinutes_ASC]&#10;				limit: 100&#10;				filter: { datetime_geq: $start, datetime_lt: $end }&#10;			) {&#10;				dimensions {&#10;					datetimeFiveMinutes&#10;				}&#10;				sum {&#10;					browserMap {&#10;						pageViews&#10;						uaBrowserFamily&#10;					}&#10;					bytes&#10;					cachedBytes&#10;					cachedRequests&#10;					contentTypeMap {&#10;						bytes&#10;						requests&#10;						edgeResponseContentTypeName&#10;					}&#10;					clientSSLMap {&#10;						requests&#10;						clientSSLProtocol&#10;					}&#10;					countryMap {&#10;						bytes&#10;						requests&#10;						threats&#10;						clientCountryName&#10;					}&#10;					encryptedBytes&#10;					encryptedRequests&#10;					ipClassMap {&#10;						requests&#10;						ipType&#10;					}&#10;					pageViews&#10;					requests&#10;					responseStatusMap {&#10;						requests&#10;						edgeResponseStatus&#10;					}&#10;					threats&#10;					threatPathingMap {&#10;						requests&#10;						threatPathingName&#10;					}&#10;				}&#10;				uniq {&#10;					uniques&#10;				}&#10;			}&#10;		}&#10;	}&#10;}&#10;</code></pre>

<p>Notice that you can specify the request time period using a dataset filter (refer to <a href="/analytics/graphql-api/features/filtering/">Filtering</a>). The <code>continuous</code> parameter is no longer needed because GraphQL Analytics is designed to provide data as soon as it is available.</p>
<p>Also, if you want to get the totals for a particular period, rather than a breakdown by time period, simply remove the <code>datetimeFiveMinutes</code> field under <code>dimensions</code>.</p>
