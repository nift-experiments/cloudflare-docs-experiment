<h2 id="aggregated-http-metrics-by-hostname-over-time">Aggregated HTTP metrics by hostname over time</h2>
<p>In this example, we are going to use the GraphQL Analytics API to query aggregated metrics about HTTP events by hostname over a specific period of time.</p>
<p>The following API call will request the number of visits and edge response bytes for the custom hostname <code>hostname.example.com</code> over a four day period. Be sure to replace <code>CLOUDFLARE_ZONE_TAG</code> and <code>API_TOKEN</code><sup><a href="#footnote-1">1</a></sup> with your zone ID and API credentials, and adjust the <code>datetime_geq</code> and <code>datetime_leq</code> values as needed.</p>
<h3 id="api-call">API Call</h3>
<pre><code class="language-bash">echo &#x27;{ &quot;query&quot;:&#10;  &quot;query RequestsAndDataTransferByHostname($zoneTag: string, $filter:filter) {&#10;    viewer {&#10;      zones(filter: {zoneTag: $zoneTag}) {&#10;        httpRequestsAdaptiveGroups(limit: 10, filter: $filter) {&#10;          sum {&#10;            visits&#10;            edgeResponseBytes&#10;          }&#10;          dimensions {&#10;            datetimeHour&#10;          }&#10;        }&#10;      }&#10;    }&#10;  }&quot;,&#10;  &quot;variables&quot;: {&#10;    &quot;zoneTag&quot;: &quot;&lt;CLOUDFLARE_ZONE_TAG&gt;&quot;,&#10;    &quot;filter&quot;: {&#10;      &quot;datetime_geq&quot;: &quot;2022-07-20T11:00:00Z&quot;,&#10;      &quot;datetime_lt&quot;: &quot;2022-07-24T12:00:00Z&quot;,&#10;      &quot;clientRequestHTTPHost&quot;: &quot;hostname.example.com&quot;,&#10;      &quot;requestSource&quot;: &quot;eyeball&quot;&#10;    }&#10;  }&#10;}&#x27; | tr -d &#x27;\n&#x27; | curl --silent \&#10;https://api.cloudflare.com/client/v4/graphql \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \&#10;&#45;-header &quot;Accept: application/json&quot; \&#10;&#45;-header &quot;Content-Type: application/json&quot; \&#10;&#45;-data @- | jq .&#10;</code></pre>

<h2 id="top-10-consuming-urls-in-a-zone">Top 10 consuming URLs in a zone</h2>
<p>We are going to use the GraphQL Analytics API to query the top 10 consuming URLs from a zone, helping you identify the URLs with the highest resource usage. Here are some configuration instructions:</p>
<ul>
<li>To filter on a specific hostname, add the line <code>&quot;clientRequestHTTPHost&quot;: &quot;'$2'&quot;</code> below <code>&quot;requestSource&quot;</code>.&quot;</li>
<li>Replace <code>API_TOKEN</code> with your generated API token using the <code>Read all resources</code> permissions. The script will only access zones available to the token's creator.</li>
<li>Pass the zone ID (<code>zoneTag</code>) as a parameter <code>ARG=$1</code>.</li>
<li>To calculate the current date and the date from 30 days ago, use <code>gdate</code> on Mac:
<ul>
<li><code>CURRENTDATE=$(gdate -u +'%FT%TZ')</code></li>
<li><code>OLDDATE=$(gdate -d '-30 days' -u +'%FT%TZ')</code>.</li>
</ul>
</li>
<li>For specific dates within the last 30 days, set <code>CURRENTDATE</code> and <code>OLDDATE</code> variables in the format <code>&quot;YYYY-MM-DDTHH:MM:SSZ&quot;</code>.</li>
</ul>
<h3 id="api-call-1">API call</h3>
<pre><code class="language-bash">curl --silent \&#10;https://api.cloudflare.com/client/v4/graphql \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \&#10;&#45;-header &quot;Content-Type: application/json&quot; \&#10;&#45;-data &#x27;{&#10;  &quot;query&quot;: &quot;{viewer {zones(filter: {zoneTag: $zoneTag}) {topPaths: httpRequestsAdaptiveGroups(filter: $filter, limit: 10, orderBy: [sum_edgeResponseBytes_DESC]) {count sum {edgeResponseBytes} dimensions {metric: clientRequestPath}}}}}&quot;,&#10;  &quot;variables&quot;: {&#10;    &quot;zoneTag&quot;: &quot;&#x27;$ARG&#x27;&quot;,&#10;    &quot;filter&quot;: {&#10;      &quot;AND&quot;: [&#10;        {&#10;          &quot;datetime_geq&quot;: &quot;&#x27;$OLDDATE&#x27;&quot;,&#10;          &quot;datetime_leq&quot;: &quot;&#x27;$CURRENTDATE&#x27;&quot;&#10;        },&#10;        {&#10;          &quot;requestSource&quot;: &quot;eyeball&quot;&#10;        }&#10;      ]&#10;    }&#10;  }&#10;}&#x27; | jq -r &#x27;try .data.viewer.zones[].topPaths[] | &quot;\&quot;\(.dimensions.metric)\&quot;: \(.sum.edgeResponseBytes)&quot;&#x27; | sort&#10;</code></pre>
