<p>This example uses the GraphQL Analytics API to query metrics for your <a href="/containers/">Containers</a>. Two endpoints are available:</p>
<ul>
<li><code>containersMetricsAdaptiveGroups</code> returns metrics for the code running inside your container, including every process inside it. Use this endpoint to inspect CPU, memory, disk, network, and uptime behavior for your own workload.</li>
<li><code>containersUsageAdaptiveGroups</code> returns the resources consumed by your container together with the micro VM sandbox required to run it. These are the values that populate the usage estimates in the Cloudflare dashboard, and are the ones to use when estimating your billing costs.</li>
</ul>
<p>Both endpoints share the same underlying dataset, but expose different slices of it.</p>
<p>Replace <code>&lt;CLOUDFLARE_ACCOUNT_TAG&gt;</code> and <code>&lt;API_TOKEN&gt;</code><sup><a href="#footnote-1">1</a></sup> with your Account ID and API token, and adjust the <code>datetimeStart</code> and <code>datetimeEnd</code> values for the time range you want to query.</p>

<h3 id="api-call">API call</h3>
<p>The following query returns CPU time and peak memory usage for a single container instance, bucketed by hour:</p>
<pre><code class="language-bash">echo &#x27;{ &quot;query&quot;:&#10;  &quot;query ContainersMetrics($accountTag: String, $datetimeStart: Time, $datetimeEnd: Time, $instanceId: String) {&#10;    viewer {&#10;      accounts(filter: {accountTag: $accountTag}) {&#10;        containersMetricsAdaptiveGroups(&#10;          limit: 100&#10;          filter: {&#10;            datetime_geq: $datetimeStart,&#10;            datetime_leq: $datetimeEnd,&#10;            instanceId: $instanceId&#10;          }&#10;          orderBy: [datetimeHour_ASC]&#10;        ) {&#10;          dimensions {&#10;            datetimeHour&#10;            instanceId&#10;          }&#10;          sum {&#10;            cpuTimeSec&#10;          }&#10;          max {&#10;            memory&#10;          }&#10;          quantiles {&#10;            cpuUtilizationP95&#10;            memoryP95&#10;          }&#10;        }&#10;      }&#10;    }&#10;  }&quot;,&#10;  &quot;variables&quot;: {&#10;    &quot;accountTag&quot;: &quot;&lt;CLOUDFLARE_ACCOUNT_TAG&gt;&quot;,&#10;    &quot;datetimeStart&quot;: &quot;2026-04-15T00:00:00Z&quot;,&#10;    &quot;datetimeEnd&quot;: &quot;2026-04-16T00:00:00Z&quot;,&#10;    &quot;instanceId&quot;: &quot;4c9b1b3c-8e8d-4a2d-9a3f-7f2b1c0a0e55&quot;&#10;  }&#10;}&#x27; | tr -d &#x27;\n&#x27; | curl --silent \&#10;https://api.cloudflare.com/client/v4/graphql \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \&#10;&#45;-header &quot;Accept: application/json&quot; \&#10;&#45;-header &quot;Content-Type: application/json&quot; \&#10;&#45;-data @- | jq .&#10;</code></pre>

<h2 id="filter-and-group-by-labels">Filter and group by labels</h2>
<p>Both endpoints expose container labels through two fields:</p>
<ul>
<li><code>labels</code> is an array of <code>key=value</code> strings, and is designed for filtering. Use the <a href="/analytics/graphql-api/features/filtering/"><code>_has</code> operator</a> to match a specific label.</li>
<li><code>label(name: &quot;...&quot;)</code> is a grouping dimension that returns the value of a named label. Alias it to a convenient field name in your response.</li>
</ul>
<p>For example, the following query returns CPU time and memory usage for production containers, grouped by environment:</p>
<pre><code class="language-graphql">query ContainersByLabel(&#10;	$accountTag: String&#10;	$datetimeStart: Time&#10;	$datetimeEnd: Time&#10;) {&#10;	viewer {&#10;		accounts(filter: { accountTag: $accountTag }) {&#10;			containersMetricsAdaptiveGroups(&#10;				limit: 100&#10;				filter: {&#10;					datetime_geq: $datetimeStart&#10;					datetime_leq: $datetimeEnd&#10;					labels_has: &quot;env=production&quot;&#10;				}&#10;			) {&#10;				dimensions {&#10;					env: label(name: &quot;env&quot;)&#10;					region: label(name: &quot;region&quot;)&#10;				}&#10;				sum {&#10;					cpuTimeSec&#10;				}&#10;				max {&#10;					memory&#10;				}&#10;			}&#10;		}&#10;	}&#10;}&#10;</code></pre>
<p>The aliased dimensions appear directly on each result:</p>
<pre><code class="language-json">{&#10;	&quot;data&quot;: {&#10;		&quot;viewer&quot;: {&#10;			&quot;accounts&quot;: [&#10;				{&#10;					&quot;containersMetricsAdaptiveGroups&quot;: [&#10;						{&#10;							&quot;dimensions&quot;: {&#10;								&quot;env&quot;: &quot;production&quot;,&#10;								&quot;region&quot;: &quot;enam&quot;&#10;							},&#10;							&quot;max&quot;: { &quot;memory&quot;: 412316672 },&#10;							&quot;sum&quot;: { &quot;cpuTimeSec&quot;: 9812.41 }&#10;						},&#10;						{&#10;							&quot;dimensions&quot;: {&#10;								&quot;env&quot;: &quot;production&quot;,&#10;								&quot;region&quot;: &quot;weur&quot;&#10;							},&#10;							&quot;max&quot;: { &quot;memory&quot;: 398458880 },&#10;							&quot;sum&quot;: { &quot;cpuTimeSec&quot;: 7421.08 }&#10;						}&#10;					]&#10;				}&#10;			]&#10;		}&#10;	},&#10;	&quot;errors&quot;: null&#10;}&#10;</code></pre>
