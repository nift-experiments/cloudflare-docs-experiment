<h2 id="activity-logs-api-call">Activity logs API call</h2>
<p>The following API call will request Email Routing activity logs over a one day period, and output the requested fields. <pre><code class="language-bash">echo &#x27;{ &quot;query&quot;:&#10;  &quot;query EmailRoutingActivity($zoneTag: string, $filter: EmailRoutingAdaptiveFilter_InputObject) {&#10;    viewer {&#10;      zones(filter: { zoneTag: $zoneTag }) {&#10;        emailRoutingAdaptive(&#10;          filter: $filter&#10;          limit: 3&#10;          orderBy: [datetime_DESC]&#10;        ) {&#10;          datetime&#10;          id: sessionId&#10;          messageId&#10;          from&#10;          to&#10;          subject&#10;          status&#10;          action&#10;          spf&#10;          dkim&#10;          dmarc&#10;          arc&#10;          errorDetail&#10;          isNDR&#10;          isSpam&#10;          spamThreshold&#10;          spamScore&#10;        }&#10;      }&#10;    }&#10;  }&quot;,&#10;  &quot;variables&quot;: {&#10;    &quot;zoneTag&quot;: &quot;&lt;CLOUDFLARE_ZONE_TAG&gt;&quot;,&#10;    &quot;filter&quot;: {&#10;      &quot;datetime_geq&quot;: &quot;2026-01-18T11:00:00Z&quot;,&#10;      &quot;datetime_leq&quot;: &quot;2026-01-19T11:00:00Z&quot;&#10;    }&#10;  }&#10;}&#x27; | tr -d &#x27;\n&#x27; | curl --silent \&#10;https://api.cloudflare.com/client/v4/graphql \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \&#10;&#45;-header &quot;Accept: application/json&quot; \&#10;&#45;-header &quot;Content-Type: application/json&quot; \&#10;&#45;-data @- | jq .&#10;</code></pre>
