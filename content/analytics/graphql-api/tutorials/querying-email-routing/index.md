<p>This example uses the GraphQL Analytics API to query for Email Routing events over a specified time period.</p>
<h2 id="activity-logs-api-call">Activity logs API call</h2>
<p>The following API call will request Email Routing activity logs over a one day period, and output the requested fields. Be sure to replace <code>&lt;CLOUDFLARE_ZONE_TAG&gt;</code> and <code>&lt;API_TOKEN&gt;</code><sup><a href="#footnote-1">1</a></sup> with your zone tag and API credentials, and adjust the <code>datetime_geg</code> and <code>datetime_leq</code> values as required.</p>
<pre tabindex="0"><code class="language-bash">echo &#x27;{ &quot;query&quot;:&#10;  &quot;query EmailRoutingActivity($zoneTag: string, $filter: EmailRoutingAdaptiveFilter_InputObject) {&#10;    viewer {&#10;      zones(filter: { zoneTag: $zoneTag }) {&#10;        emailRoutingAdaptive(&#10;          filter: $filter&#10;          limit: 3&#10;          orderBy: [datetime_DESC]&#10;        ) {&#10;          datetime&#10;          id: sessionId&#10;          messageId&#10;          from&#10;          to&#10;          subject&#10;          status&#10;          action&#10;          spf&#10;          dkim&#10;          dmarc&#10;          arc&#10;          errorDetail&#10;          isNDR&#10;          isSpam&#10;          spamThreshold&#10;          spamScore&#10;        }&#10;      }&#10;    }&#10;  }&quot;,&#10;  &quot;variables&quot;: {&#10;    &quot;zoneTag&quot;: &quot;&lt;CLOUDFLARE_ZONE_TAG&gt;&quot;,&#10;    &quot;filter&quot;: {&#10;      &quot;datetime_geq&quot;: &quot;2026-01-18T11:00:00Z&quot;,&#10;      &quot;datetime_leq&quot;: &quot;2026-01-19T11:00:00Z&quot;&#10;    }&#10;  }&#10;}&#x27; | tr -d &#x27;\n&#x27; | curl --silent \&#10;https://api.cloudflare.com/client/v4/graphql \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \&#10;&#45;-header &quot;Accept: application/json&quot; \&#10;&#45;-header &quot;Content-Type: application/json&quot; \&#10;&#45;-data @- | jq .&#10;</code></pre>

<h2 id="analytics-api-call">Analytics API Call</h2>
<p>The following API call will count the number of events grouped by hour.</p>
<pre tabindex="0"><code class="language-bash">echo &#x27;{ &quot;query&quot;:&#10;  &quot;query EmailRoutingActivity($zoneTag: string, $filter: EmailRoutingAdaptiveFilter_InputObject) {&#10;     viewer {&#10;       zones(filter: { zoneTag: $zoneTag }) {&#10;         emailRoutingAdaptiveGroups(&#10;           limit: 10000&#10;           filter: $filter&#10;           orderBy: [datetimeHour_ASC]&#10;         ) { count&#10;               dimensions {&#10;                 datetimeHour&#10;               }&#10;             }&#10;           }&#10;     }&#10;  }&quot;,&#10;  &quot;variables&quot;: {&#10;    &quot;zoneTag&quot;: &quot;&lt;CLOUDFLARE_ZONE_TAG&gt;&quot;,&#10;    &quot;filter&quot;: {&#10;      &quot;datetimeHour_geq&quot;: &quot;2026-01-18T11:00:00Z&quot;,&#10;      &quot;datetimeHour_leq&quot;: &quot;2026-01-19T11:00:00Z&quot;&#10;    }&#10;  }&#10;}&#x27; | tr -d &#x27;\n&#x27; | curl --silent \&#10;https://api.cloudflare.com/client/v4/graphql \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \&#10;&#45;-header &quot;Accept: application/json&quot; \&#10;&#45;-header &quot;Content-Type: application/json&quot; \&#10;&#45;-data @- | jq .&#10;</code></pre>
