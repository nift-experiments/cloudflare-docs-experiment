<p>In this example, we are going to use the GraphQL Analytics API to query for Firewall Events over a specified time period.</p>
<p>The following API call will request Firewall Events over a one hour period, and output the requested fields. Be sure to replace <code>&lt;CLOUDFLARE_ZONE_TAG&gt;</code>, <code>&lt;EMAIL&gt;</code>, and <code>&lt;API_TOKEN&gt;</code><sup><a href="#footnote-1">1</a></sup> with your zone tag and API credentials, and adjust the <code>datetime_geg</code> and <code>datetime_leq</code> values to your liking.</p>
<h2 id="api-call">API Call</h2>
<pre tabindex="0"><code class="language-bash">echo &#x27;{ &quot;query&quot;:&#10;  &quot;query ListFirewallEvents($zoneTag: string, $filter: FirewallEventsAdaptiveFilter_InputObject) {&#10;    viewer {&#10;      zones(filter: { zoneTag: $zoneTag }) {&#10;        firewallEventsAdaptive(&#10;          filter: $filter&#10;          limit: 10&#10;          orderBy: [datetime_DESC]&#10;        ) {&#10;          action&#10;          clientAsn&#10;          clientCountryName&#10;          clientIP&#10;          clientRequestPath&#10;          clientRequestQuery&#10;          datetime&#10;          source&#10;          userAgent&#10;        }&#10;      }&#10;    }&#10;  }&quot;,&#10;  &quot;variables&quot;: {&#10;    &quot;zoneTag&quot;: &quot;&lt;CLOUDFLARE_ZONE_TAG&gt;&quot;,&#10;    &quot;filter&quot;: {&#10;      &quot;datetime_geq&quot;: &quot;2022-07-24T11:00:00Z&quot;,&#10;      &quot;datetime_leq&quot;: &quot;2022-07-24T12:00:00Z&quot;&#10;    }&#10;  }&#10;}&#x27; | tr -d &#x27;\n&#x27; | curl --silent \&#10;https://api.cloudflare.com/client/v4/graphql \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \&#10;&#45;-header &quot;Accept: application/json&quot; \&#10;&#45;-header &quot;Content-Type: application/json&quot; \&#10;&#45;-data @-&#10;</code></pre>

<h2 id="retention-and-query-window">Retention and query window</h2>
<p>The <code>firewallEventsAdaptive</code> dataset, which powers <a href="/waf/analytics/security-events/">Security Events</a>, has different data retention limits from the datasets used in <a href="/waf/analytics/security-analytics/#limits">Security Analytics</a>. Queries that exceed the data retention window return an error similar to the following:</p>
<pre tabindex="0"><code class="language-txt">cannot request data older than 2678400s&#10;</code></pre>
<p>For more information on the limits per plan for the <code>firewallEventsAdaptive</code> dataset, refer to <a href="/waf/analytics/security-events/#availability">Security Events</a>.</p>
<p>To discover the exact limits for your zone programmatically, query the <code>settings</code> node:</p>
<pre tabindex="0"><code class="language-graphql">{&#10;	viewer {&#10;		zones(filter: { zoneTag: &quot;&lt;CLOUDFLARE_ZONE_TAG&gt;&quot; }) {&#10;			settings {&#10;				firewallEventsAdaptive {&#10;					maxDuration&#10;					maxPageSize&#10;					notOlderThan&#10;				}&#10;				httpRequestsAdaptive {&#10;					maxDuration&#10;					maxPageSize&#10;					notOlderThan&#10;				}&#10;			}&#10;		}&#10;	}&#10;}&#10;</code></pre>
<p>For more on the <code>settings</code> node, refer to <a href="/analytics/graphql-api/features/discovery/settings/">Settings node</a>.</p>
