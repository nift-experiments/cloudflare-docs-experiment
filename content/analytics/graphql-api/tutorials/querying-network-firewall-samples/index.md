<p>In this example, we are going to use the GraphQL Analytics API to query for Cloudflare Network Firewall Samples over a specified time period.</p>
<p>The following API call will request Cloudflare Network Firewall Samples over a one hour period, and output the requested fields. Be sure to replace <code>&lt;CLOUDFLARE_ACCOUNT_TAG&gt;</code> and <code>&lt;API_TOKEN&gt;</code><sup><a href="#footnote-1">1</a></sup> with your zone tag and API credentials, and adjust the <code>datetime_geg</code> and <code>datetime_leq</code> values to your liking.</p>

<pre><code class="language-bash">echo &#x27;{ &quot;query&quot;:&#10;  &quot;query MFWActivity {&#10;    viewer {&#10;      accounts(filter: { accountTag: $accountTag }) {&#10;        magicFirewallSamplesAdaptiveGroups(&#10;          filter: $filter&#10;          limit: 10&#10;          orderBy: [datetimeFiveMinute_DESC]&#10;        ) {&#10;          sum {&#10;            bits&#10;            packets&#10;          }&#10;          dimensions {&#10;            datetimeFiveMinute&#10;            ruleId&#10;          }&#10;        }&#10;      }&#10;    }&#10;  }&quot;,&#10;  &quot;variables&quot;: {&#10;    &quot;accountTag&quot;: &quot;&lt;CLOUDFLARE_ACCOUNT_TAG&gt;&quot;,&#10;    &quot;filter&quot;: {&#10;      &quot;datetime_geq&quot;: &quot;2022-07-24T11:00:00Z&quot;,&#10;      &quot;datetime_leq&quot;: &quot;2022-07-24T11:10:00Z&quot;&#10;    }&#10;  }&#10;}&#x27; | tr -d &#x27;\n&#x27; | curl --silent \&#10;https://api.cloudflare.com/client/v4/graphql \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \&#10;&#45;-header &quot;Accept: application/json&quot; \&#10;&#45;-header &quot;Content-Type: application/json&quot; \&#10;&#45;-data @-&#10;</code></pre>
