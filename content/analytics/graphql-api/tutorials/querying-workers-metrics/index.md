<p>In this example, we are going to use the GraphQL Analytics API to query for Workers Metrics over a specified time period. We can query up to one month of data for dates up to three months ago.</p>
<p>The following API call will request a Worker script's metrics over a one day period, and output the requested fields. Be sure to replace <code>&lt;CLOUDFLARE_ACCOUNT_TAG&gt;</code> and <code>&lt;API_TOKEN&gt;</code><sup><a href="#footnote-1">1</a></sup> with your API credentials, and adjust the <code>datetimeStart</code>, <code>datetimeEnd</code>, and <code>scriptName</code> variables as needed.</p>
<h2 id="api-call">API Call</h2>
<pre tabindex="0"><code class="language-bash">echo &#x27;{ &quot;query&quot;:&#10;  &quot;query GetWorkersAnalytics($accountTag: string, $datetimeStart: string, $datetimeEnd: string, $scriptName: string) {&#10;    viewer {&#10;      accounts(filter: {accountTag: $accountTag}) {&#10;        workersInvocationsAdaptive(limit: 100, filter: {&#10;          scriptName: $scriptName,&#10;          datetime_geq: $datetimeStart,&#10;          datetime_leq: $datetimeEnd&#10;        }) {&#10;          sum {&#10;            subrequests&#10;            requests&#10;            errors&#10;          }&#10;          quantiles {&#10;            cpuTimeP50&#10;            cpuTimeP99&#10;          }&#10;          dimensions{&#10;            datetime&#10;            scriptName&#10;            status&#10;          }&#10;        }&#10;      }&#10;    }&#10;  }&quot;,&#10;  &quot;variables&quot;: {&#10;    &quot;accountTag&quot;: &quot;&lt;CLOUDFLARE_ACCOUNT_TAG&gt;&quot;,&#10;    &quot;datetimeStart&quot;: &quot;2022-08-04T00:00:00.000Z&quot;,&#10;    &quot;datetimeEnd&quot;: &quot;2022-08-04T01:00:00.000Z&quot;,&#10;    &quot;scriptName&quot;: &quot;worker-subrequest-test-client&quot;&#10;  }&#10;}&#x27; | tr -d &#x27;\n&#x27; | curl --silent \&#10;https://api.cloudflare.com/client/v4/graphql \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \&#10;&#45;-header &quot;Accept: application/json&quot; \&#10;&#45;-header &quot;Content-Type: application/json&quot; \&#10;&#45;-data @-&#10;</code></pre>
