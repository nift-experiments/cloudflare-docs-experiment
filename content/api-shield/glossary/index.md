<p>Review the definitions for terms used across Cloudflare's API Shield documentation.</p>
<table id="glossary-table"><thead><tr><th>Term</th><th>Definition</th></tr></thead><tbody><tr><td>API call</td><td><p>Also known as an API request. An API call is a message sent to a server asking an API to provide a service or information.</p></td></tr><tr><td>API endpoint</td><td><p>The API endpoint is the location where API calls or requests are fulfilled. API Shield defines endpoints as a host, method, and path tuple.</p></td></tr><tr><td>API schema</td><td><p>The API schema defines which API requests are valid based on several request properties like target endpoint, path or query variable format, and HTTP method.</p></td></tr><tr><td>session identifier</td><td><p>A session identifier is a unique identifier that a website assigns to identify a specific user for the duration of their visit.</p></td></tr><tr><td>source endpoint</td><td><p>The source endpoint is the endpoint managed by API Shield in Endpoint Management by its routing feature.</p></td></tr><tr><td>target endpoint</td><td><p>The target endpoint is the ultimate destination that a request is sent to by API Shield's routing feature.</p></td></tr></tbody></table>
