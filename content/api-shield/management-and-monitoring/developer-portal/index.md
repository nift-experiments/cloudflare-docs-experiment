<h3 id="custom-domains">Custom domains</h3>
<p>To create a vanity domain instead of using the pages.dev domain, refer to the <a href="/pages/configuration/custom-domains/">Pages custom domain documentation</a>.</p>
<h2 id="availability">Availability</h2>
<p>Building developer portals is available to all API Shield subscribers. This feature uses Cloudflare Pages to host the resulting portal. Refer to <a href="/pages/">Pages</a> for any limitations of your current subscription plan.</p>
<h2 id="limitations">Limitations</h2>
<p>This feature currently uses the open source <a href="https://github.com/Redocly/redoc">Redoc</a> project from <a href="https://redocly.com/">Redocly</a>. For custom theme and branding options, visit the <a href="https://github.com/Redocly/redoc">Redoc GitHub repository</a>.</p>
<p>To modify the resulting page, download the project files before creating the Pages project. You can create a new Pages project with the modified files you have made to meet your branding guidelines.</p>
