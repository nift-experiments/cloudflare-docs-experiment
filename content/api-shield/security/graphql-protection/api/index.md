<p>Use the <a href="/analytics/graphql-api/getting-started/">Cloudflare GraphQL API</a> to gather data about your GraphQL API’s current usage and configure Cloudflare’s GraphQL malicious query protection to log or block malicious queries.</p>
<h2 id="introduction">Introduction</h2>
<p>Query size is defined as the number of terminal fields (leaves) in the query, whereas query depth is the deepest level at which a leaf is present. For example, the size of this query will be reported as <code>4 (terminalField[1-4] all contribute to this counter)</code>, and the depth will be reported as <code>3 (terminalField3 and terminalField4 are at depth level 3)</code>.</p>
<pre tabindex="0"><code class="language-graphql">{&#10;	terminalField1&#10;	nonTerminalField1(filter: 123) {&#10;		terminalField2&#10;		nonTerminalField2 {&#10;			terminalField3&#10;			terminalField4&#10;		}&#10;	}&#10;}&#10;</code></pre>
<h2 id="gather-graphql-statistics">Gather GraphQL statistics</h2>
<p>Using the new <code>apiGatewayGraphqlQueryAnalyticsGroups</code> node in the Cloudflare GraphQL API, you can retrieve <code>apiGatewayGraphqlQuerySize</code> and <code>apiGatewayGraphqlQueryDepth</code> dimensions.</p>
<pre tabindex="0"><code class="language-graphql">query ApiGatewayGraphqlQueryAnalytics(&#10;	$zoneTag: string&#10;	$start: Time&#10;	$end: Time&#10;) {&#10;	viewer {&#10;		zones(filter: { zoneTag: $zoneTag }) {&#10;			apiGatewayGraphqlQueryAnalyticsGroups(&#10;				limit: 100&#10;				orderBy: [&#10;					apiGatewayGraphqlQuerySize_DESC&#10;					apiGatewayGraphqlQueryDepth_DESC&#10;				]&#10;				filter: { datetime_geq: $start, datetime_leq: $end }&#10;			) {&#10;				count&#10;				dimensions {&#10;					apiGatewayGraphqlQuerySize&#10;					apiGatewayGraphqlQueryDepth&#10;				}&#10;			}&#10;		}&#10;	}&#10;}&#10;</code></pre>
<p>With the above query, you will get the following response:</p>
<pre tabindex="0"><code class="language-json">{&#10;	&quot;data&quot;: {&#10;		&quot;viewer&quot;: {&#10;			&quot;zones&quot;: [&#10;				{&#10;					&quot;apiGatewayGraphqlQueryAnalyticsGroups&quot;: [&#10;						{&#10;							&quot;count&quot;: 10,&#10;							&quot;dimensions&quot;: {&#10;								&quot;apiGatewayGraphqlQueryDepth&quot;: 1,&#10;								&quot;apiGatewayGraphqlQuerySize&quot;: 11&#10;							}&#10;						},&#10;						{&#10;							&quot;count&quot;: 10,&#10;							&quot;dimensions&quot;: {&#10;								&quot;apiGatewayGraphqlQueryDepth&quot;: 1,&#10;								&quot;apiGatewayGraphqlQuerySize&quot;: 2&#10;							}&#10;						}&#10;					]&#10;				}&#10;			]&#10;		}&#10;	},&#10;	&quot;errors&quot;: null&#10;}&#10;</code></pre>
<p>In the response example, Cloudflare observed 10 requests with depth 1 and size 11, and 10 requests with depth 1 and size 2 in the selected timeframe.</p>
<h2 id="analyze-graphql-statistics">Analyze GraphQL statistics</h2>
<p>You can use the response to compute percentiles across the attributes and set a threshold on what is allowed. For example, you can use a simple heuristic like <code>1.5 * p99</code> for query size or depth.</p>
<p>Here is a simple Python script that will report query size and depth p-levels given the GraphQL API response output above (as a JSON file):</p>
<pre tabindex="0"><code class="language-python">&#35;!/usr/bin/env python3&#10;&#10;import json&#10;import numpy as np&#10;import argparse&#10;&#10;parser = argparse.ArgumentParser()&#10;parser.add_argument(&quot;--response&quot;, help=&quot;Path to the API JSON response file with the apiGatewayGraphqlQueryAnalyticsGroups node&quot;, required=True)&#10;args = parser.parse_args()&#10;with open(args.response) as f:&#10;    query_sizes = np.array([], dtype=np.uint16)&#10;    query_depths = np.array([], dtype=np.uint8)&#10;    data = json.load(f)[&#x27;data&#x27;][&#x27;viewer&#x27;][&#x27;zones&#x27;][0][&#x27;apiGatewayGraphqlQueryAnalyticsGroups&#x27;]&#10;    for datapoint in data:&#10;        query_sizes = np.append(query_sizes, [datapoint[&#x27;dimensions&#x27;][&#x27;apiGatewayGraphqlQuerySize&#x27;]] * datapoint[&#x27;count&#x27;])&#10;        query_depths = np.append(query_depths, [datapoint[&#x27;dimensions&#x27;][&#x27;apiGatewayGraphqlQueryDepth&#x27;]] * datapoint[&#x27;count&#x27;])&#10;&#10;    quantiles = [0.99, 0.95, 0.75, 0.5]&#10;    print(&#x27;\n&#x27;.join([f&quot;Query size {int(q * 100)}th percentile is {v}&quot; for q, v in zip(quantiles, np.quantile(query_sizes, quantiles))]))&#10;    print(&#x27;\n&#x27;.join([f&quot;Query depth {int(q * 100)}th percentile is {v}&quot; for q, v in zip(quantiles, np.quantile(query_depths, quantiles))]))&#10;</code></pre>
<p>With the above query, you will get the following output:</p>
<pre tabindex="0"><code class="language-json">./calculator.py --response=response.json&#10;Query size 99th percentile is 11.0&#10;Query size 95th percentile is 11.0&#10;Query size 75th percentile is 11.0&#10;Query size 50th percentile is 6.5&#10;Query depth 99th percentile is 1.0&#10;Query depth 95th percentile is 1.0&#10;Query depth 75th percentile is 1.0&#10;Query depth 50th percentile is 1.0&#10;</code></pre>
<h2 id="set-limits-on-incoming-graphql-queries">Set limits on incoming GraphQL queries</h2>
<p>API Shield customers now have three new fields available in custom rules:</p>
<ul>
<li><code>cf.api_gateway.graphql.query_size</code> describes the size of a GraphQL query.</li>
<li><code>cf.api_gateway.graphql.query_depth</code> describes the depth of a GraphQL query.</li>
<li><code>cf.api_gateway.graphql.parsed_successfully</code> describes whether Cloudflare was able to parse the query. Presently, we run best-effort parsing, meaning we might not be able to parse some valid queries. This means that you must use a <code>and cf.api_gateway.graphql.parsed_successfully</code> filter in your custom rules when deploying GraphQL security rules.</li>
</ul>
<br />
<p>For example, you can deploy the following rule via the API or the dashboard to block queries that are deeply nested and ask for over 30 fields.</p>
<pre tabindex="0"><code class="language-txt">(cf.api_gateway.graphql.query_size &gt; 30 and cf.api_gateway.graphql.query_depth &gt; 7 and cf.api_gateway.graphql.parsed_successfully)&#10;</code></pre>
