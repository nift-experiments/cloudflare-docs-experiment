<h2 id="2026-07-01">2026-07-01</h2><strong>New options to manage AI traffic</strong><p>All customers can now manage AI crawlers by behavior — <a href="/bots/concepts/bot/#ai-bots">Search, Agent, and Training</a> — instead of a single Block AI bots toggle. Configure these options from <a href="/bots/additional-configurations/block-ai-bots/">Block AI Bots</a>. New defaults, in which Training and Agent are blocked on pages that display ads while Search remains allowed, take effect for new domains on September 15, 2026.</p><h2 id="2026-07-01-1">2026-07-01</h2><strong>BotBase and Business Insights for Enterprise Bot Management</strong><p>Enterprise Bot Management customers can now use <a href="/bots/botbase/">BotBase</a>, a searchable directory of all tracked bots and agents with their behavior classification and detection IDs, and <a href="/bots/business-insights/">Business Insights</a>, a dashboard showing site-wide and per-operator crawl-to-referral ratios alongside bot traffic to your content.</p><h2 id="2025-07-02">2025-07-02</h2><strong>Managed robots.txt will prepend existing files</strong><p>Cloudflare will prepend our managed <code>robots.txt</code> before your existing <code>robots.txt</code>, combining both into a single response.</p><h2 id="2025-06-26">2025-06-26</h2><strong>Web Bot Auth is now available for bot verification</strong><p>Web Bot Auth is an authentication method that leverages cryptographic signatures in HTTP messages to verify that a request comes from an automated bot. This provides a more robust way of verifying bots.</p><h2 id="2025-05-14">2025-05-14</h2><strong>Anomaly detection events now receive a bot score of 2</strong><p>Events detected by the <a href="/bots/concepts/bot-detection-engines/#anomaly-detection-enterprise">anomaly detection engine</a> are now given a bot score of 2.</p><h2 id="2025-05-08">2025-05-08</h2><strong>Machine Learning model v9 is now the default model</strong><p><a href="/bots/reference/machine-learning-models/#model-versions-and-release-notes">Machine Learning model v9</a> is now the default model for all new zones and existing zones set to use the latest machine learning model.</p><h2 id="2025-04-28">2025-04-28</h2><strong>Managed robots.txt is now available</strong><p>Direct AI crawlers on what they can and cannot scrape from your website or application by <a href="/bots/additional-configurations/managed-robots-txt/">implementing a <code>robots.txt</code> file</a> to your domain.</p><h2 id="2025-04-24">2025-04-24</h2><strong>Bot Detection Alerts are now available</strong><p>You can now create a <a href="/bots/reference/alerts/">Bot Detection Alert</a> to notify you when Cloudflare detects a spike in Bot traffic on your website.</p><h2 id="2024-08-19">2024-08-19</h2><strong>AI bots is now a managed rule</strong><p><a href="/bots/concepts/bot/#ai-bots">AI bots protection</a> has been upgraded from a custom rule to a managed rule.</p>
