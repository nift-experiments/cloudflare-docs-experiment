<p><a href="/bots/get-started/bot-fight-mode/">Bot Fight Mode (BFM)</a> and <a href="/bots/get-started/bot-fight-mode/">Super Bot Fight Mode (SBFM)</a> are designed to stop active attacks quickly. Due to their aggressive nature, false positives can occur where legitimate human or automated traffic is incorrectly challenged or blocked.</p>
<p>When dealing with false positives, consider the following key differences and solutions:</p>
<ul>
<li>Bot Fight Mode has limited control. You cannot bypass or skip Bot Fight Mode using the <em>Skip</em> action in WAF custom rules or using Page Rules. Bot Fight Mode will be disabled if there are any IP Access rules present. If you turned on BFM during an attack, and the attack has subsided, we recommend either disabling the feature using IP Access rules to bypass BFM, or looking at <a href="/bots/plans/bm-subscription/">Bot Management for Enterprise</a>, which gives you the ability to precisely customize your security threshold and create exception rules as needed.</li>
<li>Super Bot Fight Mode can be bypassed with IP Access <em>Allow</em> action rules. You can use the <em>Skip</em> action in <a href="/waf/custom-rules/skip/">WAF custom rules</a> to specify where Super Bot Fight Mode should not run.</li>
</ul>
<p>In parts of your site where you want bot traffic, you can use the <a href="/waf/custom-rules/skip/"><em>Skip</em> action</a> in <a href="/waf/custom-rules/">WAF custom rules</a> to specify where Super Bot Fight Mode should not run.</p>
<p>You can use the <a href="/ruleset-engine/rules-language/">Rules language</a> and its <a href="/ruleset-engine/rules-language/operators/">operators</a> and <a href="/ruleset-engine/rules-language/fields/">fields</a> in custom rules to configure a scoped rule for approved automated traffic in Super Bot Fight Mode.</p>
<p>You cannot bypass or skip Bot Fight Mode using the <em>Skip</em> action in WAF custom rules or using Page Rules. <em>Skip</em>, <em>Bypass</em>, and <em>Allow</em> actions apply to rules or rulesets running on the <a href="/ruleset-engine/">Ruleset Engine</a>. While Super Bot Fight Mode rules are implemented in the Ruleset Engine, Bot Fight Mode checks are not. This is why you can skip Super Bot Fight Mode, but not Bot Fight Mode. If you need to skip Bot Fight Mode, consider using <a href="/bots/get-started/super-bot-fight-mode/">Super Bot Fight Mode</a>.</p>
<p>Bot Fight Mode can still trigger if you have IP Access rules, but it cannot trigger if an IP Access rule matches the request. For example, the IP Access rule matches the connecting IP.</p>
<p>If you encounter persistent false positives, you can <a href="/bots/get-started/bot-fight-mode/#disable-bot-fight-mode">disable the feature in the Cloudflare dashboard</a>.</p>
