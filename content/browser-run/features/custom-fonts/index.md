<p>Browser Run uses a managed Chromium environment that includes a <a href="/browser-run/reference/supported-fonts/">standard set of pre-installed fonts</a>. When you generate a screenshot or PDF, text is rendered using the fonts available in this environment. If your page specifies a font that is not pre-installed, Chromium will automatically fall back to a similar supported font.</p>
<p>If you need a specific font that is not pre-installed, you can inject it into the page at render time. You can load fonts from an external URL or embed them directly as a Base64 string.</p>
<p>How you add a custom font depends on how you are using Browser Run:</p>
<ul>
<li>If you are using <a href="/browser-run/puppeteer/">Puppeteer</a>, <a href="/browser-run/playwright/">Playwright</a>, or <a href="/browser-run/cdp/">CDP</a>, refer to the <a href="#browser-sessions">Browser sessions</a> section.</li>
<li>If you are using <a href="/browser-run/quick-actions/">Quick Actions</a>, refer to the <a href="#quick-actions">Quick Actions</a> section.</li>
</ul>
<h2 id="browser-sessions">Browser sessions</h2>
<p>Use <code>addStyleTag</code> to inject a <code>@font-face</code> rule into the page before capturing your screenshot or PDF. You can load the font file from a CDN URL or embed it as a Base64-encoded string.</p>
<p>The examples below use <a href="/browser-run/puppeteer/">Puppeteer</a> with <a href="/browser-run/puppeteer/#use-puppeteer-in-a-worker">Workers Bindings</a>. If you are connecting via <a href="/browser-run/cdp/">CDP</a>, the only difference is how you connect to the browser. Once connected, <code>page.addStyleTag()</code> works the same way. Refer to <a href="#cdp-connection-example">CDP connection example</a> for details.</p>

<h3 id="cdp-connection-example">CDP connection example</h3>
<p>When connecting via <a href="/browser-run/cdp/">CDP</a>, you connect to the browser using a WebSocket endpoint instead of a Workers Binding. Once connected, you use <code>page.addStyleTag()</code> the same way as the examples above.</p>
<pre><code class="language-js">import puppeteer from &quot;puppeteer-core&quot;;&#10;&#10;const ACCOUNT_ID = &quot;your-account-id&quot;;&#10;const API_TOKEN = &quot;your-api-token&quot;;&#10;&#10;// Create a browser session via CDP&#10;const response = await fetch(&#10;	`https://api.cloudflare.com/client/v4/accounts/${ACCOUNT_ID}/browser-rendering/devtools/browser`,&#10;	{&#10;		method: &quot;POST&quot;,&#10;		headers: { Authorization: `Bearer ${API_TOKEN}` },&#10;	},&#10;);&#10;const { webSocketDebuggerUrl } = await response.json();&#10;&#10;// Connect Puppeteer to the session&#10;const browser = await puppeteer.connect({&#10;	browserWSEndpoint: webSocketDebuggerUrl,&#10;	headers: { Authorization: `Bearer ${API_TOKEN}` },&#10;});&#10;&#10;const page = await browser.newPage();&#10;&#10;// Add a custom font — same as with Workers Bindings&#10;await page.addStyleTag({&#10;	content: `&#10;    @font-face {&#10;      font-family: &#x27;CustomFont&#x27;;&#10;      src: url(&#x27;https://your-cdn.com/fonts/MyFont.woff2&#x27;) format(&#x27;woff2&#x27;);&#10;      font-weight: normal;&#10;      font-style: normal;&#10;    }&#10;&#10;    body {&#10;      font-family: &#x27;CustomFont&#x27;, sans-serif;&#10;    }&#10;  `,&#10;});&#10;&#10;// Take a screenshot, generate a PDF, etc.&#10;await page.goto(&quot;https://example.com&quot;);&#10;&#10;browser.disconnect();&#10;</code></pre>
<h2 id="quick-actions">Quick Actions</h2>
<p>When using <a href="/browser-run/quick-actions/">Quick Actions</a>, you can load custom fonts by including the <code>addStyleTag</code> parameter in your request body. This works with both the <a href="/browser-run/quick-actions/screenshot-endpoint/">screenshot</a> and <a href="/browser-run/quick-actions/pdf-endpoint/">PDF</a> endpoints.</p>
<h3 id="from-a-cdn-url-1">From a CDN URL</h3>
<pre><code class="language-bash">curl -X POST &#x27;https://api.cloudflare.com/client/v4/accounts/&lt;accountId&gt;/browser-rendering/screenshot&#x27; \&#10;  &#45;H &#x27;Authorization: Bearer &lt;apiToken&gt;&#x27; \&#10;  &#45;H &#x27;Content-Type: application/json&#x27; \&#10;  &#45;d &#x27;{&#10;    &quot;url&quot;: &quot;https://example.com/&quot;,&#10;    &quot;addStyleTag&quot;: [&#10;      {&#10;        &quot;content&quot;: &quot;@font-face { font-family: &#x27;\&#x27;&#x27;CustomFont&#x27;\&#x27;&#x27;; src: url(&#x27;\&#x27;&#x27;https://your-cdn.com/fonts/MyFont.woff2&#x27;\&#x27;&#x27;) format(&#x27;\&#x27;&#x27;woff2&#x27;\&#x27;&#x27;); font-weight: normal; font-style: normal; } body { font-family: &#x27;\&#x27;&#x27;CustomFont&#x27;\&#x27;&#x27;, sans-serif; }&quot;&#10;      }&#10;    ]&#10;  }&#x27; \&#10;  &#45;-output &quot;screenshot.png&quot;&#10;</code></pre>
