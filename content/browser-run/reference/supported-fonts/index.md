<p>Browser Run uses a managed Chromium environment that includes a standard set of fonts. When you generate a screenshot or PDF, text is rendered using the fonts available in this environment.</p>
<p>If your webpage specifies a font that is not supported yet, Chromium will automatically fall back to a similar supported font. If you would like to use a font that is not currently supported, refer to <a href="/browser-run/features/custom-fonts/">Custom fonts</a>.</p>
<h2 id="pre-installed-fonts">Pre-installed fonts</h2>
<p>The following sections list the fonts available in the Browser Run environment.</p>
<h3 id="generic-css-font-family-support">Generic CSS font family support</h3>
<p>The following generic CSS font families are supported:</p>
<ul>
<li><code>serif</code></li>
<li><code>sans-serif</code></li>
<li><code>monospace</code></li>
<li><code>cursive</code></li>
<li><code>fantasy</code></li>
</ul>

<h3 id="international-fonts">International fonts</h3>

<ul>
<li>IPAfont Gothic (Japanese)</li>
<li>Indic fonts (Devanagari, Bengali, Tamil, and others)</li>
<li>KACST fonts (Arabic)</li>
<li>Noto CJK (Chinese, Japanese, Korean)</li>
<li>Noto Color Emoji</li>
<li>TLWG Thai fonts</li>
<li>WenQuanYi Zen Hei (Chinese)</li>
</ul>
