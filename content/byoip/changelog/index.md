<h2 id="2024-07-02">2024-07-02</h2><strong>Address Maps for BYOIP and Static IPs</strong><p>Address Maps is available via <a href="/api/resources/addressing/subresources/address_maps/methods/list/">API</a> and via <a href="https://dash.cloudflare.com/?to=/:account/ip-addresses/proxy-ips">dashboard</a>. Address Maps allows customers with BYOIP prefixes or account-level Static IPs to specify which IP addresses should be mapped to DNS records when they are proxied through Cloudflare. Refer to the <a href="/byoip/address-maps/">documentation</a> for details.</p>
