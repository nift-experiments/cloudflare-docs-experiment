<p>Delivering content quickly and securely to users in Mainland China requires infrastructure within China itself. Traffic routed through servers outside the country faces significant latency and reliability issues due to China's network boundaries.</p>
<p>The <a href="https://www.cloudflare.com/application-services/products/china-network/">Cloudflare China Network</a> solves this by running selected Cloudflare performance and security products on data centers located in Mainland China, operated by Cloudflare's partner JD Cloud. The data centers cover most populated regions in China.</p>
<p>You can use the same configurations and dashboard experience that you use with Cloudflare everywhere else in the world.</p>

<h2 id="main-features">Main features</h2>
<p>The Cloudflare China Network provides:</p>
<ul>
<li>A single solution for both performance improvement and security services such as <a href="/waf/">WAF</a>, <a href="/ddos-protection/">DDoS</a>, and <a href="/bots/">bot management</a>.</li>
<li>A unified experience for managing network traffic and security posture. You can manage all configurations on the same dashboard.</li>
<li>The same customer support capabilities as Cloudflare's global network. You may also have access to premium service and local language support.</li>
<li><a href="/china-network/concepts/china-dns/">In-China Authoritative DNS and in-China nameservers</a> to reduce the time it takes for a user's browser to start receiving content (Time to First Byte).</li>
<li><a href="/china-network/concepts/global-acceleration/">Global Acceleration</a>, a suite of connectivity and performance offerings that simplify deploying your global assets in China.</li>
</ul>
<h2 id="availability">Availability</h2>
<p>The Cloudflare China Network is available as a separate subscription for customers on an <a href="https://www.cloudflare.com/plans/enterprise/">Enterprise plan</a>.</p>
<h2 id="important-notes">Important notes</h2>
<ul>
<li>Not all Cloudflare products are available in the Cloudflare China Network. Refer to <a href="/china-network/reference/available-products/">Available products and features</a> for details.</li>
<li>IPv6 support is mandatory for all Internet-facing services operating in Mainland China. The Cloudflare China Network automatically enables IPv6 on your domains to fulfill this requirement.</li>
<li>All the content inside of Mainland China is monitored by local authorities and must comply with local regulations.</li>
<li>You must have a valid <a href="/china-network/concepts/icp/">ICP (Internet Content Provider) filing or license</a> for each apex domain you wish to onboard to Cloudflare.</li>
</ul>
