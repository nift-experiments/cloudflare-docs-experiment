<p>Cloudflare designed <a href="/warp-client/">Cloudflare WARP</a> and <a href="/1.1.1.1/">1.1.1.1</a> to make Internet browsing more private and secure. These applications encrypt last-mile connections and make it more difficult for others to use client IP addresses in user fingerprinting.</p>
<p>However, unlike legacy VPN applications, we never designed WARP or 1.1.1.1 to hide user locations or allow users to misrepresent their true geographic location. As a web property operator, you can use <strong>Client IP Geolocation</strong> to map Cloudflare egress IP addresses to specific geolocations.</p>
