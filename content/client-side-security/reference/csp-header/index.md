<p>The format of the <span class="nb-glossary-tooltip" title="content security policy (CSP)">Content Security Policy (CSP)</span> report-only HTTP header added by Cloudflare is the following:</p>
<pre tabindex="0"><code class="language-txt">content-security-policy-report-only: script-src &#x27;unsafe-inline&#x27; &#x27;unsafe-eval&#x27;; connect-src &#x27;none&#x27;; report-uri https://csp-reporting.cloudflare.com/cdn-cgi/script_monitor/report?&lt;QUERY_STRING&gt;&#10;</code></pre>
<p>If you <a href="/client-side-security/reference/settings/#reporting-endpoint">configured the reporting endpoint</a> to use the same hostname, the HTTP header will have the following format:</p>
<pre tabindex="0"><code class="language-txt">content-security-policy-report-only: script-src &#x27;unsafe-inline&#x27; &#x27;unsafe-eval&#x27;; connect-src &#x27;none&#x27;; report-uri &lt;YOUR_HOSTNAME&gt;/cdn-cgi/script_monitor/report?&lt;QUERY_STRING&gt;&#10;</code></pre>
