<p>Cloudflare users with the following <a href="/fundamentals/manage-members/roles/">roles</a> have access to client-side security in the Cloudflare dashboard:</p>
<ul>
<li>Administrator</li>
<li>Super Administrator - All Privileges</li>
<li>Page Shield</li>
<li>Page Shield Read <em>(read-only access)</em></li>
<li>Domain Page Shield</li>
<li>Domain Page Shield Read <em>(read-only access)</em></li>
</ul>
<p>The availability of specific features depends on your client-side security bundle. Refer to <a href="/client-side-security/#availability">Availability</a> for more information.</p>
