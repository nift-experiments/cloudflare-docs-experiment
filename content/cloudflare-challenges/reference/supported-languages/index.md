<h2 id="multi-language-support">Multi-language support</h2>
<p>Cloudflare Challenges can detect multiple languages and display the localized challenge experience, which is determined by <code>navigator.language</code> value. The <a href="https://developer.mozilla.org/en-US/docs/Web/API/Navigator/language">Navigator.language read-only property</a> returns a string representing the preferred language of the user, usually the language of the browser user interface.</p>
