<p>Workers for Platforms lets you run untrusted code written by your customers, or by AI, in a secure hosted sandbox. Each customer runs code in their own Worker, a secure and isolated environment.</p>
<h2 id="when-to-use-workers-for-platforms">When to use Workers for Platforms</h2>
<p>Use Workers for Platforms when you need to:</p>
<ul>
<li><strong>Run untrusted code at scale</strong> - Execute code written by your customers or generated by AI in a secure sandbox, with the ability to deploy an unlimited number of applications.</li>
<li><strong>Build multi-tenant platforms</strong> - Give each customer their own isolated compute environment with complete separation between tenants.</li>
<li><strong>Extend Cloudflare's developer platform to your customers</strong> - Use <a href="/cloudflare-for-platforms/workers-for-platforms/configuration/bindings/">bindings</a> to give each customer access to KV stores, D1 databases, R2 storage, and more. Your customers get the same powerful tools, managed through your platform.</li>
<li><strong>Give each application its own domain</strong> - Host applications under a subdomain of your domain (for example, <code>customer-name.myplatform.com</code>) or integrate with <a href="/cloudflare-for-platforms/cloudflare-for-saas/domain-support/">custom hostnames</a> to allow customers to use their own domains.</li>
</ul>
<h2 id="features">Features</h2>
<p>Workers for Platforms provides tools to manage and control your customers' code:</p>
<ul>
<li><strong><a href="/cloudflare-for-platforms/workers-for-platforms/configuration/custom-limits/">Custom limits</a></strong> - Set per-customer limits on CPU time and subrequests.</li>
<li><strong><a href="/cloudflare-for-platforms/workers-for-platforms/configuration/observability/">Observability</a></strong> - Collect logs and metrics across all user Workers in your namespace. Export to third-party platforms like Datadog, Splunk, and Grafana.</li>
<li><strong><a href="/cloudflare-for-platforms/workers-for-platforms/configuration/tags/">Tags</a></strong> - Organize, search, and filter user Workers by custom tags like customer ID, plan type, or environment.</li>
</ul>
