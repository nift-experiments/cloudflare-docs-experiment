<p>You can utilize different <a href="/logs/logpush/logpush-job/filters/">Log filters</a> to only view specific data from Cloudflare Network Firewall (formerly Magic Firewall).</p>
<h2 id="filter-by-enabled-or-disabled-rules">Filter by enabled or disabled rules</h2>
<p>Use the filter examples below to filter your Network Firewall traffic to display events for enabled or disabled rules.</p>
<p>The example below only displays fields relevant to Network Firewall, and the filter only displays events for disabled rules.</p>
<pre tabindex="0"><code class="language-bash">curl https://api.cloudflare.com/client/v4/accounts/{account_id}/logpush/jobs \&#10;&#45;-header &quot;X-Auth-Email: &lt;EMAIL&gt;&quot; \&#10;&#45;-header &quot;X-Auth-Key: &lt;API_KEY&gt;&quot; \&#10;&#45;-header &quot;Content-Type: application/json&quot; \&#10;&#45;-data &#x27;{&#10;  ...&#10;  &quot;output_options&quot;: {&#10;      &quot;field_names&quot;: [&quot;ColoName&quot;, &quot;Datetime&quot;, &quot;Direction&quot;, &quot;IPDestinationAddress&quot;, &quot;IPDestinationSubnet&quot;, &quot;IPProtocol&quot;,&quot;IPSourceAddress&quot;, &quot;IPSourceSubnet&quot;, &quot;Outcome&quot;, &quot;RuleID&quot;, &quot;RulesetID&quot;, &quot;SampleInterval&quot;, &quot;Verdict&quot;],&#10;  },&#10;  &quot;filter&quot;: &quot;{\&quot;where\&quot;:{\&quot;or\&quot;:[{\&quot;and\&quot;:[{\&quot;key\&quot;:\&quot;MitigationSystem\&quot;,\&quot;operator\&quot;:\&quot;eq\&quot;,\&quot;value\&quot;:\&quot;magic-firewall\&quot;},{\&quot;key\&quot;:\&quot;RulesetID\&quot;,\&quot;operator\&quot;:\&quot;!eq\&quot;,\&quot;value\&quot;:\&quot;\&quot;},{\&quot;key\&quot;:\&quot;Outcome\&quot;,\&quot;operator\&quot;:\&quot;eq\&quot;,\&quot;value\&quot;:\&quot;pass\&quot;},{\&quot;key\&quot;:\&quot;Verdict\&quot;,\&quot;operator\&quot;:\&quot;eq\&quot;,\&quot;value\&quot;:\&quot;drop\&quot;}]}]}}&quot;&#10;}&#x27;&#10;</code></pre>
<p>The example below only displays fields relevant to Network Firewall, and the filter only displays events for enabled rules.</p>
<pre tabindex="0"><code class="language-bash">curl https://api.cloudflare.com/client/v4/accounts/{account_id}/logpush/jobs \&#10;&#45;-header &quot;X-Auth-Email: &lt;EMAIL&gt;&quot; \&#10;&#45;-header &quot;X-Auth-Key: &lt;API_KEY&gt;&quot; \&#10;&#45;-header &quot;Content-Type: application/json&quot; \&#10;&#45;-data &#x27;{&#10;  ...&#10;  &quot;output_options&quot;: {&#10;      &quot;field_names&quot;: [&quot;ColoName&quot;, &quot;Datetime&quot;, &quot;Direction&quot;, &quot;IPDestinationAddress&quot;, &quot;IPDestinationSubnet&quot;, &quot;IPProtocol&quot;,&quot;IPSourceAddress&quot;, &quot;IPSourceSubnet&quot;, &quot;Outcome&quot;, &quot;RuleID&quot;, &quot;RulesetID&quot;, &quot;SampleInterval&quot;, &quot;Verdict&quot;],&#10;  },&#10;  &quot;filter&quot;: &quot;{\&quot;where\&quot;:{\&quot;or\&quot;:[{\&quot;and\&quot;:[{\&quot;key\&quot;:\&quot;MitigationSystem\&quot;,\&quot;operator\&quot;:\&quot;eq\&quot;,\&quot;value\&quot;:\&quot;magic-firewall\&quot;},{\&quot;key\&quot;:\&quot;RulesetID\&quot;,\&quot;operator\&quot;:\&quot;!eq\&quot;,\&quot;value\&quot;:\&quot;\&quot;},{\&quot;or\&quot;:[{\&quot;key\&quot;:\&quot;Outcome\&quot;,\&quot;operator\&quot;:\&quot;eq\&quot;,\&quot;value\&quot;:\&quot;drop\&quot;},{\&quot;key\&quot;:\&quot;Verdict\&quot;,\&quot;operator\&quot;:\&quot;eq\&quot;,\&quot;value\&quot;:\&quot;pass\&quot;}]}]}]}}&quot;&#10;}&#x27;&#10;</code></pre>
<h2 id="filter-by-allowed-or-blocked-traffic">Filter by allowed or blocked traffic</h2>
<p>Use the filter examples below to filter your Network Firewall traffic to display events for allowed or blocked traffic.</p>
<p>The example below only displays fields relevant to Network Firewall, and the filter only displays events where no explicit action was taken, for example, a packet &quot;fell through&quot; Network Firewall. This example does not have any rules applied.</p>
<pre tabindex="0"><code class="language-bash">curl https://api.cloudflare.com/client/v4/accounts/{account_id}/logpush/jobs \&#10;&#45;-header &quot;X-Auth-Email: &lt;EMAIL&gt;&quot; \&#10;&#45;-header &quot;X-Auth-Key: &lt;API_KEY&gt;&quot; \&#10;&#45;-header &quot;Content-Type: application/json&quot; \&#10;&#45;-data &#x27;{&#10;  ...&#10;  &quot;output_options&quot;: {&#10;      &quot;field_names&quot;: [&quot;ColoName&quot;, &quot;Datetime&quot;, &quot;Direction&quot;, &quot;IPDestinationAddress&quot;, &quot;IPDestinationSubnet&quot;, &quot;IPProtocol&quot;,&quot;IPSourceAddress&quot;, &quot;IPSourceSubnet&quot;, &quot;Outcome&quot;, &quot;RuleID&quot;, &quot;RulesetID&quot;, &quot;SampleInterval&quot;, &quot;Verdict&quot;],&#10;  },&#10;  &quot;filter&quot;: &quot;{\&quot;where\&quot;:{\&quot;and\&quot;:[{\&quot;key\&quot;:\&quot;MitigationSystem\&quot;,\&quot;operator\&quot;:\&quot;eq\&quot;,\&quot;value\&quot;:\&quot;magic-firewall\&quot;},{\&quot;key\&quot;:\&quot;RulesetID\&quot;,\&quot;operator\&quot;:\&quot;eq\&quot;,\&quot;value\&quot;:\&quot;\&quot;}]}}&quot;&#10;}&#x27;&#10;</code></pre>

<pre tabindex="0"><code class="language-bash">curl https://api.cloudflare.com/client/v4/accounts/{account_id}/logpush/jobs \&#10;&#45;-header &quot;X-Auth-Email: &lt;EMAIL&gt;&quot; \&#10;&#45;-header &quot;X-Auth-Key: &lt;API_KEY&gt;&quot; \&#10;&#45;-header &quot;Content-Type: application/json&quot; \&#10;&#45;-data &#x27;{&#10;  ...&#10;  &quot;output_options&quot;: {&#10;      &quot;field_names&quot;: [&quot;ColoName&quot;, &quot;Datetime&quot;, &quot;Direction&quot;, &quot;IPDestinationAddress&quot;, &quot;IPDestinationSubnet&quot;, &quot;IPProtocol&quot;,&quot;IPSourceAddress&quot;, &quot;IPSourceSubnet&quot;, &quot;Outcome&quot;, &quot;RuleID&quot;, &quot;RulesetID&quot;, &quot;SampleInterval&quot;, &quot;Verdict&quot;],&#10;  },&#10;  &quot;filter&quot;: &quot;{\&quot;where\&quot;:{\&quot;and\&quot;:[{\&quot;key\&quot;:\&quot;MitigationSystem\&quot;,\&quot;operator\&quot;:\&quot;eq\&quot;,\&quot;value\&quot;:\&quot;magic-firewall\&quot;},{\&quot;key\&quot;:\&quot;RulesetID\&quot;,\&quot;operator\&quot;:\&quot;!eq\&quot;,\&quot;value\&quot;:\&quot;\&quot;}]}}&quot;&#10;}&#x27;&#10;</code></pre>
