<p>Cloudflare Network Firewall (formerly Magic Firewall) is a <span class="nb-glossary-tooltip" title="firewall-as-a-service">firewall-as-a-service (FWaaS)</span> delivered from the Cloudflare global network to protect office networks and cloud infrastructure with advanced, scalable protection. With Cloudflare Network Firewall, you can apply filter rules on a variety of criteria, such as protocol and <span class="nb-glossary-tooltip" title="data packet">packet</span> length, to filter unwanted traffic before it reaches your network.</p>
<p>Rules are written using the <a href="/ruleset-engine/rules-language/">Cloudflare Rules language</a>, which is inspired by Wireshark syntax, a widely used packet analysis filter language and the same syntax used across our other products. With this syntax, you can craft powerful rules to precisely allow or deny any traffic in or out of your network.</p>
<p>Cloudflare Network Firewall is available with the purchase of <a href="/magic-transit/">Magic Transit</a> or <a href="/cloudflare-wan/">Cloudflare WAN</a>.</p>
