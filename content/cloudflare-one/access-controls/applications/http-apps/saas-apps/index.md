<p>Cloudflare Access allows you to add an additional authentication layer to your SaaS applications. When you integrate a SaaS application with Access, users log in to the application with Cloudflare as the Single Sign-On provider. The user is then redirected to the configured identity providers for that application and are only granted access if they pass your Access policies.</p>
<p>Cloudflare integrates with the majority of SaaS applications that support the SAML or OIDC authentication protocol. If you do not see your application listed below, refer to our <a href="/cloudflare-one/access-controls/applications/http-apps/saas-apps/generic-saml-saas/">generic SAML</a> or <a href="/cloudflare-one/access-controls/applications/http-apps/saas-apps/generic-oidc-saas/">generic OIDC</a> guide and consult your SaaS application's documentation.</p>
