<p>Detection entries are the reusable detection logic that Cloudflare DLP uses to identify sensitive content in your web traffic and SaaS applications. You can create and manage detection entries independently of DLP profiles, then add the same entry to one or more custom profiles.</p>
<p>Use the following pages to configure detection entries and review Cloudflare-managed predefined detections.</p>
