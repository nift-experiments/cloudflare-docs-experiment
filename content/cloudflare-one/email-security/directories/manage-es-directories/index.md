<p>You can manage your Email security directory by editing and deleting added users.</p>
<aside class="nb-aside note">
<h3 class="nb-aside-title" id="registered-users">Registered users</h3>
@markup("md", "content/.markup/bodies/4924.md")
</aside>
<p>To modify or delete users in the Email security directory:</p>
<ol>
<li>In <a href="https://one.dash.cloudflare.com/">Cloudflare One</a>, go to <strong>Email security</strong> &gt; <strong>Directories</strong>.</li>
<li>Select <strong>Email security Directory</strong>.</li>
</ol>
<h2 id="add-a-user">Add a user</h2>
<p>To manually add a user to the Email security directory:</p>
<ol>
<li>On the sidebar, go to <strong>Settings</strong> &gt; <strong>Impersonation registry</strong> &gt; <strong>View</strong>.</li>
<li>Select <strong>Add a user</strong>:</li>
</ol>
<ul>
<li>Choose <strong>Manual input</strong> as the <strong>Input method</strong>.</li>
<li>Under <strong>User info</strong>, enter the <strong>Display name</strong>.</li>
<li>Under <strong>User email</strong>, enter the <strong>Email addresses</strong>.</li>
</ul>
<ol start="3">
<li>Select <strong>Save</strong>.</li>
</ol>
<p>To view users you manually added:</p>
<ol>
<li>Go to <strong>Directories</strong>.</li>
<li>Select <strong>Email security Directory</strong>.</li>
<li>Any manually added user will be displayed under the table as <strong>REGISTERED</strong>.</li>
</ol>
<h2 id="edit-a-user">Edit a user</h2>
<p>To edit a user in the Email security directory:</p>
<ol>
<li>Select the user you want to edit.</li>
<li>Select the three dots &gt; <strong>Edit</strong>.</li>
<li>Enter a user name and/or email.</li>
<li>Select <strong>Save</strong>.</li>
</ol>
<h2 id="delete-a-user">Delete a user</h2>
<p>To delete a user from the Email security directory:</p>
<ol>
<li>Select the user you want to delete.</li>
<li>Select the three dots &gt; <strong>Delete</strong>.</li>
<li>Read the pop-up message, and then select <strong>Delete user</strong>.</li>
</ol>
<p>To delete multiple users from the registry at once:</p>
<ol>
<li>Select the users you want to delete.</li>
<li>Select the <strong>Action</strong> dropdown list &gt; <strong>Delete</strong>.</li>
</ol>
