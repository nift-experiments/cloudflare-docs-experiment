<p>Email security allows you to view and manage your groups directory and their <a href="/cloudflare-one/email-security/settings/detection-settings/impersonation-registry/">impersonation registry</a>. When a group is added to the registry, all members are registered by default.</p>
<p>To manage a group directory:</p>
<ol>
<li>In <a href="https://one.dash.cloudflare.com/">Cloudflare One</a>, go to <strong>Email security</strong> &gt; <strong>Directories</strong>.</li>
<li>Locate your directory, select the three dots &gt; <strong>View details</strong>.</li>
<li>Select <strong>Groups</strong>.</li>
</ol>
<h2 id="add-groups-to-registry">Add groups to registry</h2>
<p>Email security allows you to add group names to the registry.</p>
<p>To add a single group to the registry:</p>
<ol>
<li>Select the group name you want to add.</li>
<li>Select the three dots &gt; <strong>Add to registry</strong>.</li>
</ol>
<p>To add multiple groups to the registry at once:</p>
<ol>
<li>Select the group names you want to add to the registry.</li>
<li>Select the <strong>Action</strong> dropdown list.</li>
<li>Select <strong>Add to registry</strong>.</li>
</ol>
<h2 id="remove-groups-from-registry">Remove groups from registry</h2>
<p>Email security allows you to remove group names from the registry.</p>
<p>To remove a single group from the registry:</p>
<ol>
<li>Select the group name you want to remove.</li>
<li>Select the three dots &gt; <strong>Remove from registry</strong>.</li>
</ol>
<p>To remove multiple groups from the registry at once:</p>
<ol>
<li>Select the group names you want to remove from registry.</li>
<li>Select the <strong>Action</strong> dropdown list.</li>
<li>Select <strong>Remove from registry</strong>.</li>
</ol>
<h2 id="filter-impersonation-registry">Filter impersonation registry</h2>
<p>You can filter the list of group names by registered and unregistered.</p>
<p>A group name is registered when it is part of the <a href="/cloudflare-one/email-security/settings/detection-settings/impersonation-registry/">impersonation registry</a>. A group name is unregistered when they are not part of the impersonation registry.</p>
<p>To filter the list:</p>
<ol>
<li>Select <strong>Show filters</strong> &gt; <strong>Impersonation registry</strong>.</li>
<li>Select one of the following:
<ul>
<li><strong>All</strong>: To view registered and unregistered groups.</li>
<li><strong>Registered</strong>: To view registered groups.</li>
<li><strong>Unregistered</strong>: To view unregistered groups.</li>
</ul>
</li>
<li>Select <strong>Apply filters</strong>.</li>
</ol>
