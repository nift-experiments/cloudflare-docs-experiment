<p>Email security uses Cloudflare's <a href="/data-localization/">Data Localization Suite (DLS)</a> to allow you to control where your emails are processed. You do not need Data Localization Suite with Email security to choose the different locations.</p>

<li>Germany</li>
<li>India</li>
