<p>PhishNet is an add-in button that helps users to submit directly to Email security <span class="nb-glossary-tooltip" title="phishing">phish</span> samples missed by Email security's detection.</p>
<p>To set up PhishNet Microsoft 365:</p>
<ol>
<li>Get the customized manifest URL from <a href="https://one.dash.cloudflare.com/?to=/:account/email-security/settings/email-policy/phish-submission?tab=phish-submission">Cloudflare One</a>.</li>
<li>Log in to the <a href="https://admin.microsoft.com/">Microsoft admin panel</a>.</li>
<li>Go to <strong>Microsoft 365 admin center</strong> &gt; <strong>Settings</strong> &gt; <strong>Integrated Apps</strong>.</li>
<li>Select <strong>Upload custom apps</strong>.</li>
<li>Choose <strong>Provide link to manifest file</strong> and paste the URL you copied from the Cloudflare One dashboard.</li>
<li>Verify and complete the wizard.</li>
</ol>
