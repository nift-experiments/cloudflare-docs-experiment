<p>If you do not have an integration:</p>
<ol>
<li>In <a href="https://one.dash.cloudflare.com/">Cloudflare One</a>, go to <strong>Email security</strong>.</li>
<li>Go to <strong>Settings</strong> &gt; <strong>Domain management</strong> &gt; <strong>Domains</strong> &gt; select <strong>View</strong>.</li>
<li>Locate your domain, select the three dots &gt; Select <strong>Associate an integration</strong>.</li>
<li>Select <strong>Connect an integration</strong>. You will then be redirected to the <strong>Add an integration</strong> page.</li>
<li>Select <strong>Google Workspace CASB+EMAIL</strong> &gt; <strong>Select Integration</strong>.</li>
<li>Once you select an integration, you can <a href="/cloudflare-one/email-security/setup/post-delivery-deployment/bcc-journaling/bcc-setup/gmail-bcc-setup/enable-gmail-integration/#enable-gmail-bcc-integration">enable Gmail BCC integration</a>.</li>
</ol>
