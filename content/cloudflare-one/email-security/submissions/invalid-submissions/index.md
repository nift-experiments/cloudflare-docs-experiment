<p>A submission is invalid when:</p>
<ul>
<li>A submission has no EML file attached.</li>
<li>A submission has been made with an incorrect file extension.</li>
<li>A submission was made to the wrong team or user alias.</li>
</ul>
<p>To ensure your submission is valid:</p>
<ul>
<li>Ensure your submission has a file attached with a <code>.eml</code> file extension.</li>
<li>Ensure you configure the domain you are submitting emails for.</li>
<li>Ensure policies are configured correctly.</li>
</ul>
<p>To view invalid submissions:</p>
<ol>
<li>Log in to <a href="https://one.dash.cloudflare.com/">Cloudflare One</a>.</li>
<li>Select <strong>Email security</strong> &gt; <strong>Submissions</strong>.</li>
<li>Select <strong>Invalid submissions</strong>.</li>
</ol>
<p>You can search by submission ID or submitted email.</p>
<p>You can filter based on <strong>Date Range</strong> and <strong>Submitted by</strong> (which will list emails that made the invalid submissions). Once you have configured your desired filters, select <strong>Apply filters</strong>.</p>
<h2 id="enable-notifications">Enable notifications</h2>
<p>To enable Invalid submission email notifications:</p>
<ol>
<li>Log in to <a href="https://one.dash.cloudflare.com/">Cloudflare One</a>.</li>
<li>Select <strong>Email security</strong> &gt; <strong>Settings</strong>.</li>
<li>Go to <strong>Invalid submission emails</strong> and turn on <strong>Invalid submission email notifications</strong>.</li>
</ol>
