<p>Posture logs show the results of <a href="/cloudflare-one/reusable-components/posture-checks/">device posture checks</a> — security requirements such as OS version, disk encryption, or endpoint protection status — reported by the Cloudflare One Client. Use these logs to identify which devices are passing or failing your organization's posture requirements and to troubleshoot individual check results.</p>
<p>To view device posture logs, log in to <a href="https://one.dash.cloudflare.com/">Cloudflare One</a> and go to <strong>Insights</strong> &gt; <strong>Logs</strong> &gt; <strong>Posture logs</strong>. Logs will only display if you have configured <a href="/cloudflare-one/reusable-components/posture-checks/">device posture checks</a> for your Zero Trust organization.</p>
<p>Enterprise users can generate more detailed logs with <a href="/cloudflare-one/insights/logs/logpush/">Logpush</a>.</p>

<tr>
<th>Field</th>

</tr>
</thead>

<tr>
<td><strong>Name</strong></td>

</tr>
<tr>
<td><strong>ID</strong></td>
<td>Device ID generated by the Cloudflare One Client.</td>
</tr>
<tr>
<td><strong>Serial number</strong></td>
<td>Serial number of the device.</td>
</tr>
<tr>
<td><strong>Manufacturer</strong></td>

</tr>

</tr>

<h3 id="user-details">User details</h3>
<table>
<thead>
<tr>
<th>Field</th>
<th>Description</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>Email</strong></td>
<td>Email used to register the device with Zero Trust.</td>
</tr>
<tr>
<td><strong>User ID</strong></td>
<td>Unique identifier (UUID) of the user who registered the device.</td>
</tr>

<h3 id="posture-details">Posture details</h3>
<table>
<thead>
<tr>
<th>Field</th>
<th>Description</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>Name</strong></td>
<td>Name of the <a href="/cloudflare-one/reusable-components/posture-checks/">device posture check</a>.</td>
</tr>
<tr>
<td><strong>Type</strong></td>
<td>Whether the check is a <a href="/cloudflare-one/reusable-components/posture-checks/client-checks/">Cloudflare One Client check</a> (evaluated locally on the device) or a <a href="/cloudflare-one/integrations/service-providers/">service provider check</a> (evaluated by a third-party integration).</td>
</tr>
<tr>
<td><strong>Rule ID</strong></td>
<td>UUID of the device posture check.</td>
</tr>
<tr>
<td><strong>Conditions met</strong></td>
<td>Whether the device passed or failed the posture check criteria. Evaluates to <code>true</code> if the <strong>Received values</strong> match the <strong>Expected values</strong>.</td>
</tr>
<tr>
<td><strong>Expected values</strong></td>
<td>Values required to pass the device posture check. Compare with <strong>Received values</strong> to diagnose why a device failed.</td>
</tr>
<tr>
<td><strong>Received values</strong></td>
<td>Actual values detected on the device by the Cloudflare One Client or service provider.</td>
</tr>
</tbody>
</table>
