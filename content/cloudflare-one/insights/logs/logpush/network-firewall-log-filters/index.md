<p>You can apply <a href="/logs/logpush/logpush-job/filters/">Log filters</a> to your Logpush job to export only specific Cloudflare Network Firewall events. The examples below show common filter configurations using the Logpush API. Each filter uses a JSON structure with <code>where</code> clauses containing <code>key</code> (the log field to filter on), <code>operator</code> (the comparison, such as <code>eq</code> for equals or <code>!eq</code> for not equals), and <code>value</code> (the value to match).</p>
<p>The filters in this guide use the following log fields:</p>
<ul>
<li><code>MitigationSystem</code> — Identifies which Cloudflare system sampled the packet. For Network Firewall events, this value is <code>magic-firewall</code>.</li>
<li><code>RulesetID</code> — The unique identifier of the managed ruleset containing the rule that matched the packet, if any. An empty string indicates no managed ruleset matched.</li>
<li><code>Outcome</code> — The action that Cloudflare systems took on the packet (<code>pass</code> or <code>drop</code>).</li>
<li><code>Verdict</code> — The action that Cloudflare systems determined should be taken on the packet (<code>pass</code> or <code>drop</code>). For disabled rules, <code>Verdict</code> may differ from <code>Outcome</code> because the rule evaluated the packet but did not enforce its action.</li>
</ul>
<h2 id="filter-by-enabled-or-disabled-rules">Filter by enabled or disabled rules</h2>
<p>Use the filter examples below to filter your Cloudflare Network Firewall traffic to display events for enabled or disabled rules.</p>
<p>The example below <a href="/api/resources/logpush/subresources/jobs/methods/create/">creates a Logpush job</a> that only displays fields relevant to Cloudflare Network Firewall, and the filter only displays events for disabled rules.</p>
<pre tabindex="0" class="nb-api-request"><code class="language-bash">curl --request POST \&#10;  --url https://api.cloudflare.com/client/v4/accounts/{account_id}/logpush/jobs \&#10;  --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \&#10;  --data &#x27;{&#10;  &quot;destination_conf&quot;: &quot;&lt;DESTINATION_CONF&gt;&quot;,&#10;  &quot;output_options&quot;: {&#10;    &quot;field_names&quot;: [&#10;      &quot;ColoName&quot;,&#10;      &quot;Datetime&quot;,&#10;      &quot;Direction&quot;,&#10;      &quot;IPDestinationAddress&quot;,&#10;      &quot;IPDestinationSubnet&quot;,&#10;      &quot;IPProtocol&quot;,&#10;      &quot;IPSourceAddress&quot;,&#10;      &quot;IPSourceSubnet&quot;,&#10;      &quot;Outcome&quot;,&#10;      &quot;RuleID&quot;,&#10;      &quot;RulesetID&quot;,&#10;      &quot;SampleInterval&quot;,&#10;      &quot;Verdict&quot;&#10;    ]&#10;  },&#10;  &quot;filter&quot;: &quot;{\&quot;where\&quot;:{\&quot;or\&quot;:[{\&quot;and\&quot;:[{\&quot;key\&quot;:\&quot;MitigationSystem\&quot;,\&quot;operator\&quot;:\&quot;eq\&quot;,\&quot;value\&quot;:\&quot;magic-firewall\&quot;},{\&quot;key\&quot;:\&quot;RulesetID\&quot;,\&quot;operator\&quot;:\&quot;!eq\&quot;,\&quot;value\&quot;:\&quot;\&quot;},{\&quot;key\&quot;:\&quot;Outcome\&quot;,\&quot;operator\&quot;:\&quot;eq\&quot;,\&quot;value\&quot;:\&quot;pass\&quot;},{\&quot;key\&quot;:\&quot;Verdict\&quot;,\&quot;operator\&quot;:\&quot;eq\&quot;,\&quot;value\&quot;:\&quot;drop\&quot;}]}]}}&quot;&#10;}&#x27;</code></pre>
<p>The example below <a href="/api/resources/logpush/subresources/jobs/methods/create/">creates a Logpush job</a> that only displays fields relevant to Cloudflare Network Firewall, and the filter only displays events for enabled rules.</p>
<pre tabindex="0" class="nb-api-request"><code class="language-bash">curl --request POST \&#10;  --url https://api.cloudflare.com/client/v4/accounts/{account_id}/logpush/jobs \&#10;  --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \&#10;  --data &#x27;{&#10;  &quot;destination_conf&quot;: &quot;&lt;DESTINATION_CONF&gt;&quot;,&#10;  &quot;output_options&quot;: {&#10;    &quot;field_names&quot;: [&#10;      &quot;ColoName&quot;,&#10;      &quot;Datetime&quot;,&#10;      &quot;Direction&quot;,&#10;      &quot;IPDestinationAddress&quot;,&#10;      &quot;IPDestinationSubnet&quot;,&#10;      &quot;IPProtocol&quot;,&#10;      &quot;IPSourceAddress&quot;,&#10;      &quot;IPSourceSubnet&quot;,&#10;      &quot;Outcome&quot;,&#10;      &quot;RuleID&quot;,&#10;      &quot;RulesetID&quot;,&#10;      &quot;SampleInterval&quot;,&#10;      &quot;Verdict&quot;&#10;    ]&#10;  },&#10;  &quot;filter&quot;: &quot;{\&quot;where\&quot;:{\&quot;or\&quot;:[{\&quot;and\&quot;:[{\&quot;key\&quot;:\&quot;MitigationSystem\&quot;,\&quot;operator\&quot;:\&quot;eq\&quot;,\&quot;value\&quot;:\&quot;magic-firewall\&quot;},{\&quot;key\&quot;:\&quot;RulesetID\&quot;,\&quot;operator\&quot;:\&quot;!eq\&quot;,\&quot;value\&quot;:\&quot;\&quot;},{\&quot;or\&quot;:[{\&quot;key\&quot;:\&quot;Outcome\&quot;,\&quot;operator\&quot;:\&quot;eq\&quot;,\&quot;value\&quot;:\&quot;drop\&quot;},{\&quot;key\&quot;:\&quot;Verdict\&quot;,\&quot;operator\&quot;:\&quot;eq\&quot;,\&quot;value\&quot;:\&quot;pass\&quot;}]}]}]}}&quot;&#10;}&#x27;</code></pre>
<h2 id="filter-by-allowed-or-blocked-traffic">Filter by allowed or blocked traffic</h2>
