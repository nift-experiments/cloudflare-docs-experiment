<p>Service-to-service integrations allow the Cloudflare One Client to get device posture data from a third-party API. To use this feature, you must <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/deployment/">deploy the Cloudflare One Client</a> to your devices and enable the desired posture checks.</p>
<h2 id="supported-client-modes">Supported Client modes</h2>
<ul>
<li>Traffic and DNS mode</li>
<li>Traffic only mode</li>
<li>Posture only mode</li>
</ul>
