<p>Cloudflare recommends creating a <a href="/cloudflare-one/networks/connectors/cloudflare-tunnel/get-started/">remotely-managed tunnel</a> for most use cases. Remotely-managed tunnels store their configuration on Cloudflare, which allows you to manage the tunnel from any machine using the dashboard, API, or Terraform.</p>
