<p>Cloudflare recommends creating a <a href="/cloudflare-one/networks/connectors/cloudflare-tunnel/get-started/create-remote-tunnel/">remotely-managed tunnel</a> for most use cases. Remotely-managed tunnels store their configuration on Cloudflare, which allows you to manage the tunnel from any machine using the dashboard, API, or Terraform.</p>
<p>As an alternative workflow, you can create a locally-managed tunnel by running <code>cloudflared tunnel create &lt;NAME&gt;</code> on the command line. Tunnel configuration is stored in your local <code>cloudflared</code> directory. Locally-managed tunnels are intended for specific scenarios such as local development, testing, or legacy configurations.</p>
