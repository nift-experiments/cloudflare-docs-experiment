<p>With Cloudflare Zero Trust, you can connect private networks and the services running in those networks to Cloudflare's global network. This involves installing a <a href="#connectors">connector</a> on the private network, and then <a href="/cloudflare-one/networks/connectors/cloudflare-tunnel/get-started/create-remote-tunnel/#2b-connect-a-network">setting up routes</a> which define the IP addresses available in that environment. Unlike <a href="/cloudflare-one/networks/connectors/cloudflare-tunnel/routing-to-tunnel/">published applications</a>, private network routes can expose both HTTP and non-HTTP resources.</p>
<p>To reach private network IPs, end users must connect their device to Cloudflare and enroll in your Zero Trust organization. The most common method is to install the <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/">Cloudflare One Client</a> on their device, or you can onboard their network traffic to Cloudflare using <a href="/mesh/">Cloudflare Mesh</a>, <a href="/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/cloudflared/">Cloudflare Tunnel</a>, or <a href="/cloudflare-wan/zero-trust/cloudflare-tunnel/">Cloudflare WAN</a>.</p>
<p>Administrators can optionally set <a href="/cloudflare-one/traffic-policies/network-policies/">Gateway network policies</a> to control access to services based on user identity and device posture.</p>

<h2 id="connectors">Connectors</h2>
<p>Here are the different ways you can connect your private network to Cloudflare:</p>
<ul>
<li><a href="/mesh/"><strong>Cloudflare Mesh</strong></a> creates a private network between mesh nodes, client devices, and the services behind them. Each participant is assigned a <a href="/cloudflare-one/networks/routes/reserved-ips/#device-ips">Mesh IP</a> for direct connectivity. Mesh nodes install on a Linux server and act as subnet routers for site-to-site, bidirectional, and mesh networking. Client devices install the <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/">Cloudflare One Client</a> for device-to-device and device-to-network connectivity.</li>
<li><a href="/cloudflare-one/networks/connectors/cloudflare-tunnel/private-net/cloudflared/"><strong>Cloudflare Tunnel (<code>cloudflared</code>)</strong></a> installs on a server in your private network and creates a secure, outbound-only tunnel to Cloudflare. <code>cloudflared</code> only proxies traffic initiated from a user to a server. Any service or application running behind the tunnel will use the server's default routing table for server-initiated connectivity.</li>
<li><a href="/cloudflare-one/networks/connectors/cloudflare-wan/"><strong>Cloudflare WAN</strong></a> connects entire network locations to Cloudflare using anycast GRE or IPsec tunnels configured on your existing networking equipment.</li>
</ul>
