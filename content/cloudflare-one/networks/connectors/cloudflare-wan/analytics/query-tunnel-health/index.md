<p>This example uses the GraphQL Analytics API to query Cloudflare WAN tunnel health check results. These results are aggregated from individual health checks that Cloudflare servers perform against the tunnels you configured in your account. You can query up to one week of data for dates up to three months in the past.</p>
<p>The following API call requests tunnel health checks for a specific account over a one-day period for a specific Cloudflare data center and outputs the requested fields. Replace <code>&lt;CLOUDFLARE_ACCOUNT_TAG&gt;</code> and <code>&lt;API_TOKEN&gt;</code><sup><a href="#footnote-1">1</a></sup> with your API credentials, and adjust the <code>datetimeStart</code> and <code>datetimeEnd</code> variables as needed.</p>
<p>The API call returns tunnel health check results by Cloudflare data center. Cloudflare aggregates each data center's result from health checks conducted on individual servers. The <code>tunnelState</code> field represents the state of the tunnel. Cloudflare WAN uses these states for routing. A <code>tunnelState</code> value of <code>0</code> represents a down tunnel, <code>0.5</code> represents a degraded tunnel, and <code>1</code> represents a healthy tunnel.</p>
<h2 id="api-call">API Call</h2>
<pre><code class="language-bash">echo &#x27;{ &quot;query&quot;:&#10;  &quot;query GetTunnelHealthCheckResults($accountTag: string, $datetimeStart: string, $datetimeEnd: string) {&#10;    viewer {&#10;      accounts(filter: {accountTag: $accountTag}) {&#10;        magicTransitTunnelHealthChecksAdaptiveGroups(&#10;          limit: 100,&#10;          filter: {&#10;            datetime_geq: $datetimeStart,&#10;            datetime_lt:  $datetimeEnd,&#10;          }&#10;        ) {&#10;          avg {&#10;            tunnelState&#10;          }&#10;          dimensions {&#10;            tunnelName&#10;            edgeColoName&#10;          }&#10;        }&#10;      }&#10;    }&#10;  }&quot;,&#10;  &quot;variables&quot;: {&#10;    &quot;accountTag&quot;: &quot;&lt;CLOUDFLARE_ACCOUNT_TAG&gt;&quot;,&#10;    &quot;datetimeStart&quot;: &quot;2022-08-04T00:00:00.000Z&quot;,&#10;    &quot;datetimeEnd&quot;: &quot;2022-08-04T01:00:00.000Z&quot;&#10;  }&#10;}&#x27; | tr -d &#x27;\n&#x27; | curl --silent \&#10;https://api.cloudflare.com/client/v4/graphql \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \&#10;&#45;-header &quot;Accept: application/json&quot; \&#10;&#45;-header &quot;Content-Type: application/json&quot; \&#10;&#45;-data @-&#10;</code></pre>
<p>The results are returned in JSON (as requested), so piping the output to <code>jq</code> formats them for easier parsing, as in the following example:</p>
