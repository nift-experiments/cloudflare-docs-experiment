<ol>
<li>Log in to <a href="https://one.dash.cloudflare.com/">Cloudflare One</a>, and go to <strong>Networks</strong>.</li>
<li>Go to <strong>Connectors</strong> &gt; <strong>Appliances</strong> &gt; <strong>Appliances</strong>.</li>
<li>Find the Cloudflare One Appliance you want to deactivate, select the three dots next to it &gt; <strong>Edit</strong>.</li>
<li>In <strong>Status</strong>, select <em>Deactivated</em> from the drop-down menu.</li>
<li>Select <strong>Update</strong>.</li>
</ol>
