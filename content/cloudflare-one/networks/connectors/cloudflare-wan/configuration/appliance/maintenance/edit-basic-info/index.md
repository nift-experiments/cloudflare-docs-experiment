<p>In <strong>Basic information</strong>, you can change the name and description of your Cloudflare One Appliance (formerly Magic WAN Connector).</p>
<ol>
<li>Log in to <a href="https://one.dash.cloudflare.com/">Cloudflare One</a>, and go to <strong>Networks</strong>.</li>
<li>Go to <strong>Connectors</strong> &gt; <strong>Appliances</strong> &gt; <strong>Appliances</strong>.</li>
<li>Find the Cloudflare One Appliance that you want to edit &gt; select the three dots next to it &gt; <strong>Edit</strong>.</li>
<li>In <strong>Basic information</strong> make the necessary changes.</li>
<li>Select <strong>Save</strong>.</li>
</ol>
