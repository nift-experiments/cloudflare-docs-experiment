<p>To on-ramp your network traffic to Cloudflare WAN (formerly Magic WAN), you can use <a href="/cloudflare-one/networks/connectors/cloudflare-wan/configuration/appliance/">Cloudflare One Appliance</a>, a lightweight software package you can install in corporate network locations to automatically connect and steer any IP traffic.</p>
<p>You can also use any device that supports <a href="/cloudflare-one/networks/connectors/cloudflare-wan/configuration/third-party/">GRE or IPsec</a> tunnels with the supported configuration parameters.</p>
<p>Additional compatible on-ramps include:</p>
<ul>
<li>
<p><a href="/cloudflare-one/networks/connectors/cloudflare-wan/network-interconnect/">Cloudflare Network Interconnect (CNI)</a>: Connect your network infrastructure directly with Cloudflare - rather than using the public Internet - for a more reliable and secure experience.</p>
</li>
<li>
<p><a href="/cloudflare-one/networks/connectors/cloudflare-wan/zero-trust/cloudflare-tunnel/">Cloudflare Tunnel</a>: Cloudflare WAN can be used together with Cloudflare Tunnel for easy access between your networks and applications.</p>
</li>
<li>
<p><a href="/cloudflare-one/networks/connectors/cloudflare-wan/zero-trust/cloudflare-one-client/">WARP</a>: Protect corporate devices by securely and privately sending traffic from those devices to Cloudflare's global network, where Cloudflare Gateway can apply advanced web filtering.</p>
</li>
<li>
<p><a href="https://www.cloudflare.com/network-onramp-partners/">Network on-ramp partnerships</a>: Refer to our <a href="/cloudflare-one/networks/connectors/cloudflare-wan/configuration/third-party/">third-party integration tutorials</a> for guidance on configuring the most asked for third-party products.</p>
</li>
</ul>
