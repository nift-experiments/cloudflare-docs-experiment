<p>Kandji deploys the Cloudflare One Client (formerly WARP) as a custom app. For an overview of how Kandji deploys custom apps, refer to their <a href="https://support.kandji.io/custom-apps-overview">knowledge base article</a>.</p>
<h2 id="macos">macOS</h2>
<p>For the simplest deployment, Kandji has created a downloadable configuration profile that enables the Cloudflare One Client's user notifications and configures its Privacy Preference Policy Control (<a href="https://support.kandji.io/create-a-privacy-preferences-policy-control-profile">PPPC</a>) to have Full Disk Access.</p>
<ol>
<li>
<p>Download the <a href="https://github.com/kandji-inc/support/blob/64e0d8c8fa393d0967d2519aea60b5c834754563/Configuration%20Profiles/cloudflare_warp.mobileconfig">custom profile</a>.</p>
</li>
<li>
<p>Add the custom profile:</p>
<ol>
<li>Go to <strong>Library</strong> &gt; <strong>Add New</strong> &gt; <strong>Add Library Item</strong> &gt; <strong>Custom Profile</strong>.</li>
<li>Select <strong>Add &amp; Configure</strong>.</li>
</ol>
</li>
<li>
<p>Configure the custom profile:</p>
<ol>
<li>Enter a <strong>Name</strong> for the custom configuration profile.</li>
<li>Assign your custom profile to a test Blueprint.</li>
<li>Set <strong>Device Families</strong> to <em>Mac</em>.</li>
<li>Upload the <code>cloudflare_warp.mobileconfig</code> file you previously downloaded.</li>
<li>Save the custom profile.</li>
</ol>
</li>
</ol>
<p><img src="/assets/upstream/images/cloudflare-one/connections/custom-profile.png" alt="Configuring custom profile for the Cloudflare One Client in Kandji" /></p>
<p><em>Note: Labels in this image may reflect a previous product name.</em></p>
<ol start="4">
<li>
<p>Add a custom app:</p>
<ol>
<li>Go to <strong>Library</strong> &gt; <strong>Add New</strong> &gt; <strong>Add Library Item</strong> &gt; <strong>Custom App</strong>.</li>
<li>Select <strong>Add &amp; Configure</strong>.</li>
</ol>
</li>
<li>
<p>Configure the custom app:</p>
<ol>
<li>
<p>Name the custom app.</p>
</li>
<li>
<p>Assign the custom app to the same test Blueprint used for the profile.</p>
</li>
<li>
<p>Select <strong>Audit and Enforce</strong> as the installation type.</p>
</li>
<li>
<p>Copy the <strong>Audit and Enforce Script</strong> <a href="#audit-and-enforce-script">below</a> and paste it into the <strong>Audit Script</strong> text field.</p>
</li>
<li>
<p>To enforce a minimum app version, update the <strong>ENFORCED_VERSION</strong> variable in the audit script with the version number the audit script should enforce (for example, <code>1.5.207.0</code>).</p>
<p>If <strong>ENFORCED_VERSION</strong> is left blank (<code>&quot;&quot;</code>), the audit script will not check for a version and will only check for the presence of the Cloudflare WARP.app in the Applications folder or a subfolder within <strong>Applications</strong>. Refer to the script comments for more details.</p>
</li>
<li>
<p>In the <strong>Install Details</strong> section, select <strong>Installer Package</strong>.</p>
</li>
<li>
<p>Under <strong>Installer Package</strong>, upload the <code>Cloudflare_WARP_&lt;VERSION&gt;.pkg</code> file. If you do not already have the installer package, <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/download/#macos">download it here</a>.</p>
</li>
<li>
<p>Select <strong>Save</strong>.</p>
</li>
</ol>
</li>
</ol>
<p>To verify that the Cloudflare One Client was installed, select the app in the <strong>Custom App</strong> library and view its <strong>Status</strong> tab.</p>
<p>After deploying the Cloudflare One Client, you can check its connection progress using the <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/troubleshooting/connectivity-status/">Connectivity status</a> messages displayed in the Cloudflare One Client GUI.</p>

<h2 id="tls-decryption">TLS decryption</h2>
<p>The Kandji macOS agent uses certificate pinning, which is incompatible with <a href="/cloudflare-one/traffic-policies/http-policies/tls-decryption/">Gateway TLS decryption</a>. If Gateway TLS decryption is <a href="/cloudflare-one/traffic-policies/http-policies/tls-decryption/#turn-on-tls-decryption">turned on</a>, you must create a <a href="/cloudflare-one/traffic-policies/http-policies/common-policies/#skip-inspection-for-groups-of-applications">Do Not Inspect policy</a> to exempt Kandji from SSL/TLS inspection. For more information, refer to the <a href="https://support.kandji.io/kb/using-kandji-on-enterprise-networks#SSL/TLS-Inspection">Kandji documentation</a>.</p>
