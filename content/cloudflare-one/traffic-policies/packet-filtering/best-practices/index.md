<p>By default, Cloudflare Network Firewall allows all incoming (ingress) traffic that has passed through Cloudflare's core DDoS mitigations. To reduce your exposure to attacks and prevent unwanted traffic from reaching your network, configure rules using the following guidelines.</p>
<p>If you are setting up firewall rules for the first time, start with the <a href="/cloudflare-one/traffic-policies/packet-filtering/best-practices/minimal-ruleset/">Minimal ruleset</a>. If you have existing on-premises or edge firewall rules, the best approach is to replicate those rules in Network Firewall. If you are unable to export your current firewall rules, contact your Cloudflare Implementation Manager for help translating the rules into Network Firewall rules.</p>
