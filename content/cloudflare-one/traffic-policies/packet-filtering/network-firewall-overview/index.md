<p>Unwanted network traffic — from DDoS floods to unauthorized scans — can overwhelm your infrastructure. Cloudflare Network Firewall is a <div class="nb-interactive-component" data-cf-component="GlossaryTooltip"></p>
@markup("md", "content/.markup/bodies/6411.md")
</div> delivered from the Cloudflare global network, meaning Cloudflare runs the firewall for you in the cloud instead of on your own hardware. You can apply filter rules on a variety of criteria, such as protocol (for example, TCP or UDP) and <div class="nb-interactive-component" data-cf-component="GlossaryTooltip">
@markup("md", "content/.markup/bodies/6412.md")
</div> length, to filter unwanted traffic before it reaches your network.
<p>Cloudflare Network Firewall uses Wireshark display filter syntax — a rule language originally from the popular network analysis tool <a href="https://www.wireshark.org/">Wireshark</a>, widely used in networking and the same syntax used across other Cloudflare products. With this syntax, you can craft rules to precisely allow or deny any traffic in or out of your network.</p>
<p>Cloudflare Network Firewall is available with the purchase of <a href="/magic-transit/">Magic Transit</a> or <a href="/cloudflare-wan/">Cloudflare WAN</a>.</p>
