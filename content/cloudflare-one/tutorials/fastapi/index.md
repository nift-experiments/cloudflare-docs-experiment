<p>This tutorial covers how to validate that the <a href="/cloudflare-one/access-controls/applications/http-apps/authorization-cookie/validating-json/">Access JWT</a> is on requests made to FastAPI apps.</p>
<p><strong>Time to complete:</strong> 15 minutes</p>
<h2 id="prerequisites">Prerequisites</h2>
<ul>
<li>A <a href="/cloudflare-one/access-controls/applications/http-apps/self-hosted-public-app/">self-hosted Access application</a> for your FastAPI app</li>
<li>The <a href="/cloudflare-one/access-controls/applications/http-apps/authorization-cookie/validating-json/#get-your-aud-tag">AUD tag</a> for your Access application</li>
</ul>
<h2 id="1-create-a-validation-function"><ol>
<li>Create a validation function</li>
</ol></h2>
<ol>
<li>In your FastAPI project, create a new file called <code>cloudflare.py</code> that contains the following code:</li>
</ol>
<pre tabindex="0"><code class="language-python">from fastapi import Request, HTTPException&#10;&#10;&#35; The Application Audience (AUD) tag for your application&#10;POLICY_AUD = &quot;XXXXX&quot;&#10;&#10;&#35; Your CF Access team domain&#10;TEAM_DOMAIN = &quot;https://&lt;your-team-name&gt;.cloudflareaccess.com&quot;&#10;CERTS_URL = &quot;{}/cdn-cgi/access/certs&quot;.format(TEAM_DOMAIN)&#10;&#10;async def validate_cloudflare(request: Request):&#10;    &quot;&quot;&quot;&#10;    Validate that the request is authenticated by Cloudflare Access.&#10;    &quot;&quot;&quot;&#10;    if verify_token(request) != True:&#10;        raise HTTPException(status_code=400, detail=&quot;Not authenticated properly!&quot;)&#10;&#10;&#10;def _get_public_keys():&#10;    &quot;&quot;&quot;&#10;    Returns:&#10;        List of RSA public keys usable by PyJWT.&#10;    &quot;&quot;&quot;&#10;    r = requests.get(CERTS_URL)&#10;    public_keys = []&#10;    jwk_set = r.json()&#10;    for key_dict in jwk_set[&quot;keys&quot;]:&#10;        public_key = jwt.algorithms.RSAAlgorithm.from_jwk(json.dumps(key_dict))&#10;        public_keys.append(public_key)&#10;    return public_keys&#10;&#10;&#10;def verify_token(request):&#10;    &quot;&quot;&quot;&#10;    Verify the token in the request.&#10;    &quot;&quot;&quot;&#10;    token = &quot;&quot;&#10;&#10;    if &quot;CF_Authorization&quot; in request.cookies:&#10;        token = request.cookies[&quot;CF_Authorization&quot;]&#10;    else:&#10;        raise HTTPException(status_code=400, detail=&quot;missing required cf authorization token&quot;)&#10;&#10;    keys = _get_public_keys()&#10;&#10;    &#35; Loop through the keys since we can&#x27;t pass the key set to the decoder&#10;    valid_token = False&#10;    for key in keys:&#10;        try:&#10;            &#35; decode returns the claims that has the email when needed&#10;            jwt.decode(token, key=key, audience=POLICY_AUD, algorithms=[&quot;RS256&quot;])&#10;            valid_token = True&#10;            break&#10;        except:&#10;            raise HTTPException(status_code=400, detail=&quot;Error decoding token&quot;)&#10;    if not valid_token:&#10;        raise HTTPException(status_code=400, detail=&quot;Invalid token&quot;)&#10;&#10;    return True&#10;</code></pre>
<h2 id="2-use-the-validation-function-in-your-app"><ol start="2">
<li>Use the validation function in your app</li>
</ol></h2>
<p>You can now add the validation function as a dependency in your FastAPI app. One way to do this is by creating an <a href="https://fastapi.tiangolo.com/tutorial/bigger-applications/#another-module-with-apirouter"><code>APIRouter</code> instance</a>. The following example executes the validation function on each request made to paths that start with <code>/admin</code>:</p>
<pre tabindex="0"><code class="language-python">from fastapi import APIRouter, Depends, HTTPException&#10;from cloudflare import validate_cloudflare&#10;&#10;router = APIRouter(&#10;    prefix=&quot;/admin&quot;,&#10;    tags=[&quot;admin&quot;],&#10;    dependencies=[Depends(validate_cloudflare)]&#10;    responses={404: {&quot;description&quot;: &quot;Not found&quot;}},&#10;)&#10;&#10;@router.get(&quot;/&quot;)&#10;async def root():&#10;    return {&quot;message&quot;: &quot;Hello World&quot;}&#10;</code></pre>
