<p>You can only add or remove applications to Breakout traffic and Prioritized traffic. To add or remove applications:</p>
<ol>
<li>Go to the <strong>Connectors</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Go to the <strong>Appliances</strong> tab &gt; <strong>Profiles</strong>.</li>
<li>Find the Appliance that you want to edit &gt; select the three dots next to it &gt; <strong>Edit</strong>.</li>
<li>Go to <strong>Traffic steering</strong> &gt; <strong>Breakout traffic</strong> or <strong>Prioritized traffic</strong>.</li>
<li>Select <strong>Add</strong> to add a new application.</li>
<li>To delete an application, find the one you want to delete from <strong>Breakout traffic</strong> or <strong>Prioritized traffic</strong> &gt; select the three dots next to it &gt; <strong>Remove</strong>.</li>
</ol>
