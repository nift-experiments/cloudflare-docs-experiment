<p>If your network has multiple paths to the same destination — for example, redundant tunnels to a data center — you can use Cloudflare Load Balancing to distribute traffic across those paths. This prevents any single path from becoming a bottleneck and allows traffic to fail over automatically if a path goes down.</p>
<p>Cloudflare WAN (formerly Magic WAN) uses Private Network Load Balancing, which balances traffic across your private network endpoints. It supports both on-ramping (traffic entering Cloudflare's network) and off-ramping (traffic exiting to your sites).</p>
<p>Refer to <a href="/load-balancing/private-network/">Private Network Load Balancing</a> for more information about the feature and how to set it up. Before using this feature, <a href="/load-balancing/">enable Load Balancing</a>.</p>
