<p>Cloudflare WAN (formerly Magic WAN) provides site-to-site connectivity and packet-level security through <a href="/cloudflare-network-firewall/">Cloudflare Network Firewall</a>. The Cloudflare One integrations below extend that foundation with identity-aware security — user-level access policies through <a href="/cloudflare-one/access-controls/">Cloudflare Access</a>, secure Internet egress through <a href="/cloudflare-one/traffic-policies/">Cloudflare Gateway</a>, and device-level routing through the <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/">Cloudflare One Client (formerly WARP)</a>.</p>
