<p>D1 is Cloudflare's managed, serverless database with SQLite's SQL semantics, built-in disaster recovery, and Worker and HTTP API access.</p>
<p>D1 allows you to create thousands of databases at no extra cost for isolation, perfect for scaling out application vibe-coding platforms. D1 pricing is based only on query and storage costs.</p>
<p>Create your first D1 database by <a href="/d1/get-started/">following the Get started guide</a>, learn how to <a href="/d1/best-practices/import-export-data/">import data into a database</a>, and how to <a href="/d1/worker-api/">interact with your database</a> directly from <a href="/workers/">Workers</a> or <a href="/pages/functions/bindings/#d1-databases">Pages</a>.</p>
