<h2 id="typescript-support">TypeScript support</h2>
<p>D1 Worker Bindings API is fully-typed via the runtime types generated by running <a href="/workers/languages/typescript/"><code>wrangler types</code></a> package, and also supports <a href="https://www.typescriptlang.org/docs/handbook/2/generics.html#generic-types">generic types</a> as part of its TypeScript API. A generic type allows you to provide an optional <code>type parameter</code> so that a function understands the type of the data it is handling.</p>
<p>When using the query statement methods <a href="/d1/worker-api/prepared-statements/#run"><code>D1PreparedStatement::run</code></a>, <a href="/d1/worker-api/prepared-statements/#raw"><code>D1PreparedStatement::raw</code></a> and <a href="/d1/worker-api/prepared-statements/#first"><code>D1PreparedStatement::first</code></a>, you can provide a type representing each database row. D1's API will <a href="/d1/worker-api/return-object/#d1result">return the result object</a> with the correct type.</p>
<p>For example, providing an <code>OrderRow</code> type as a type parameter to <a href="/d1/worker-api/prepared-statements/#run"><code>D1PreparedStatement::run</code></a> will return a typed <code>Array&lt;OrderRow&gt;</code> object instead of the default <code>Record&lt;string, unknown&gt;</code> type:</p>
<pre><code class="language-ts">// Row definition&#10;type OrderRow = {&#10;	Id: string;&#10;	CustomerName: string;&#10;	OrderDate: number;&#10;};&#10;&#10;// Elsewhere in your application&#10;// env.MY_DB is the D1 database binding from your Wrangler configuration file&#10;const result = await env.MY_DB.prepare(&#10;	&quot;SELECT Id, CustomerName, OrderDate FROM [Order] ORDER BY ShippedDate DESC LIMIT 100&quot;,&#10;).run&lt;OrderRow&gt;();&#10;</code></pre>
<h2 id="type-conversion">Type conversion</h2>
<p>D1 automatically converts supported JavaScript (including TypeScript) types passed as parameters via the Workers Binding API to their associated D1 types <sup>1</sup>.
This conversion is permanent and one-way only. This means that when reading the written values back in your code, you will get the converted values rather than the originally inserted values.</p>
