<h2 id="verify-regional-services-behavior">Verify Regional Services behavior</h2>
<p>In order to verify that Regional Services is working, customers can confirm the behavior by executing one of the following <code>curl</code> commands on a regionalized hostname:</p>
<pre tabindex="0"><code class="language-bash">curl -X GET -I https://&lt;HOSTNAME&gt;/ 2&gt;&amp;1 | grep cf-ray&#10;</code></pre>
<pre tabindex="0"><code class="language-bash">curl -s https://&lt;HOSTNAME&gt;/cdn-cgi/trace | grep &quot;colo=&quot;&#10;</code></pre>
<p>The first command will return a three-letter IATA code (an airport identifier that corresponds to the nearest Cloudflare data center) in the <a href="/fundamentals/reference/http-headers/#cf-ray">Cf-Ray</a> header, indicating the Cloudflare data center location of processing and/or TLS termination (traffic decryption). The second command will directly return the three-letter IATA code.</p>
<p>For example, when a hostname is configured to use the region European Union (EU), the three-letter IATA code will always return a data center inside of the EU.</p>
