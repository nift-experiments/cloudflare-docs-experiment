<h2 id="autonomous-edge">Autonomous Edge</h2>
<p>The Cloudflare Autonomous Edge is powered by the denial-of-service <span class="nb-glossary-tooltip" title="daemon">daemon</span> (<code>dosd</code>), which is a home-grown software-defined system. The flow tracking daemon, <code>flowtrackd</code>, is our stateful mitigation platform alongside <code>dosd</code>. A <code>dosd</code> instance runs in every single server in every one of <a href="https://www.cloudflare.com/network/">Cloudflare global network's data centers</a> around the world. These <code>dosd</code> instances can detect and mitigate DDoS attacks autonomously without requiring centralized consensus. Cloudflare users can configure this system through <a href="/ddos-protection/managed-rulesets/">DDoS Attack Protection managed rulesets</a>.</p>
<p>Another component of Cloudflare's Autonomous Edge includes the <a href="/ddos-protection/advanced-ddos-systems/overview/advanced-tcp-protection/">Advanced TCP Protection</a> system. This is Cloudflare's TCP state tracking machine for detecting and mitigating the most randomized and sophisticated TCP-based DDoS attacks in unidirectional routing topologies — such as the case of <a href="/magic-transit/">Magic Transit</a>. Advanced TCP Protection is able to identify the state of a TCP connection and then drops, challenges, or rate-limits packets that do not belong to a legitimate connection.</p>
<p>For more information, refer to our blog post <a href="https://blog.cloudflare.com/deep-dive-cloudflare-autonomous-edge-ddos-protection/">A deep-dive into Cloudflare's autonomous edge DDoS protection</a>.</p>
<h2 id="centralized-ddos-protection-system">Centralized DDoS protection system</h2>
<p>Complementary to the Autonomous Edge, Cloudflare's entire global network is overwatched by a global version of <code>dosd</code>. This component protects Cloudflare's entire global network by detecting and mitigating globally distributed volumetric DDoS attacks.</p>
<p>The centralized systems run in Cloudflare's core data centers. They receive samples from every global network data center, analyze them, and automatically send mitigation instructions when detecting an attack. The system is also synchronized to each of our customers' web servers to identify their health and trigger any required mitigation actions.</p>
