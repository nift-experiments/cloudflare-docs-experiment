<p>The following sections contain example requests for common API calls. For a list of available API endpoints, refer to <a href="/ddos-protection/advanced-ddos-systems/api/dns-protection/#endpoints">Endpoints</a>.</p>
<h2 id="get-all-dns-protection-rules">Get all DNS protection rules</h2>
<p>The following example retrieves the currently configured rules for Advanced DNS Protection.</p>
<pre tabindex="0"><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/advanced_dns_protection/configs/dns_protection/rules&quot; \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot;&#10;</code></pre>
<pre tabindex="0"><code class="language-json">&#45;--&#10;{&#10;  &quot;result&quot;: [&#10;    {&#10;      &quot;id&quot;: &quot;&lt;RULE_ID&gt;&quot;,&#10;      &quot;scope&quot;: &quot;&lt;SCOPE&gt;&quot;,&#10;      &quot;name&quot;: &quot;&lt;NAME&gt;&quot;,&#10;      &quot;mode&quot;: &quot;&lt;MODE&gt;&quot;,&#10;      &quot;profile_sensitivity&quot;: &quot;&lt;SENSITIVITY&gt;&quot;,&#10;      &quot;rate_sensitivity&quot;: &quot;&lt;RATE&gt;&quot;,&#10;      &quot;burst_sensitivity&quot;: &quot;&lt;BURST&gt;&quot;,&#10;      &quot;created_on&quot;: &quot;2023-10-01T13:10:38.762503+01:00&quot;,&#10;      &quot;modified_on&quot;: &quot;2023-10-01T13:10:38.762503+01:00&quot;,&#10;      }&#10;    ],&#10;  &quot;success&quot;: true,&#10;  &quot;errors&quot;: [],&#10;  &quot;messages&quot;: []&#10;}&#10;</code></pre>
<h3 id="create-dns-protection-rule">Create DNS protection rule</h3>
<p>The following example creates an Advanced DNS Protection rule with a global scope.</p>
<pre tabindex="0"><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/advanced_dns_protection/configs/dns_protection/rules&quot; \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \&#10;&#45;-data &#x27;{&#10;  &quot;scope&quot;: &quot;global&quot;,&#10;  &quot;name&quot;: &quot;global&quot;,&#10;  &quot;mode&quot;: &quot;&lt;MODE&gt;&quot;,&#10;  &quot;rate_sensitivity&quot;: &quot;&lt;RATE&gt;&quot;,&#10;  &quot;burst_sensitivity&quot;: &quot;&lt;BURST&gt;&quot;,&#10;  &quot;profile_sensitivity&quot;: &quot;&lt;SENSITIVITY&gt;&quot;&#10;}&#x27;&#10;</code></pre>
<pre tabindex="0"><code class="language-json">{&#10;  &quot;result&quot;: {&#10;    &quot;id&quot;: &quot;&lt;RULE_ID&gt;&quot;,&#10;    &quot;scope&quot;: &quot;global&quot;,&#10;    &quot;name&quot;: &quot;global&quot;,&#10;    &quot;mode&quot;: &quot;&lt;MODE&gt;&quot;,&#10;    &quot;rate_sensitivity&quot;: &quot;&lt;RATE&gt;&quot;,&#10;    &quot;burst_sensitivity&quot;: &quot;&lt;BURST&gt;&quot;,&#10;    &quot;profile_sensitivity&quot;: &quot;&lt;SENSITIVITY&gt;&quot;,&#10;    &quot;created_on&quot;: &quot;2023-10-01T13:10:38.762503+01:00&quot;,&#10;    &quot;modified_on&quot;: &quot;2023-10-01T13:10:38.762503+01:00&quot;,&#10;  },&#10;  &quot;success&quot;: true,&#10;  &quot;errors&quot;: [],&#10;  &quot;messages&quot;: []&#10;}&#10;</code></pre>

<h3 id="update-dns-protection-rule">Update DNS protection rule</h3>
<p>The following example updates an existing DNS protection rule with ID <code>{rule_id}</code>.</p>
<p>The request body can contain only the fields you want to update (from <code>mode</code>, <code>profile_sensitivity</code>, <code>rate_sensitivity</code>, and <code>burst_sensitivity</code>).</p>
<pre tabindex="0"><code class="language-bash">curl --request PATCH \&#10;&quot;https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/advanced_dns_protection/configs/dns_protection/rules/{rule_id}&quot; \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \&#10;&#45;-data &#x27;{&#10;  &quot;mode&quot;: &quot;&lt;NEW_MODE&gt;&quot;,&#10;  &quot;profile_sensitivity&quot;: &quot;&lt;NEW_SENSITIVITY&gt;&quot;,&#10;  &quot;rate_sensitivity&quot;: &quot;&lt;NEW_RATE&gt;&quot;,&#10;  &quot;burst_sensitivity&quot;: &quot;&lt;NEW_BURST&gt;&quot;&#10;}&#x27;&#10;</code></pre>
<pre tabindex="0"><code class="language-json">{&#10;  &quot;result&quot;: {&#10;    &quot;id&quot;: &quot;&lt;RULE_ID&gt;&quot;,&#10;    &quot;scope&quot;: &quot;&lt;SCOPE&gt;&quot;,&#10;    &quot;name&quot;: &quot;&lt;NAME&gt;&quot;,&#10;    &quot;mode&quot;: &quot;&lt;NEW_MODE&gt;&quot;,&#10;    &quot;profile_sensitivity&quot;: &quot;&lt;NEW_SENSITIVITY&gt;&quot;,&#10;    &quot;rate_sensitivity&quot;: &quot;&lt;NEW_RATE&gt;&quot;,&#10;    &quot;burst_sensitivity&quot;: &quot;&lt;NEW_BURST&gt;&quot;,&#10;    &quot;created_on&quot;: &quot;2023-10-01T13:10:38.762503+01:00&quot;,&#10;    &quot;modified_on&quot;: &quot;2023-10-01T13:10:38.762503+01:00&quot;,&#10;  },&#10;  &quot;success&quot;: true,&#10;  &quot;errors&quot;: [],&#10;  &quot;messages&quot;: []&#10;}&#10;</code></pre>
<p>Refer to <a href="/ddos-protection/advanced-ddos-systems/api/dns-protection/json-objects/">JSON objects</a> for more information on the fields in the JSON body.</p>
