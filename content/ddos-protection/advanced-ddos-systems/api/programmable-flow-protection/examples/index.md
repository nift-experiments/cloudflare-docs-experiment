<p>The following sections contain example requests for common API calls. For a list of available API endpoints, refer to <a href="/ddos-protection/advanced-ddos-systems/api/programmable-flow-protection/#endpoints">Endpoints</a>.</p>
<h2 id="list-all-programs">List all programs</h2>
<p>This example fetches all Programmable Flow Protection programs in the account.</p>
<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/programmable_flow_protection/configs/programs&quot; \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot;&#10;</code></pre>
<pre><code class="language-json">{&#10;  &quot;result&quot;: [&#10;    {&#10;      &quot;id&quot;: &quot;&lt;PROGRAM_ID&gt;&quot;,&#10;      &quot;name&quot;: &quot;rate-limiter&quot;,&#10;      &quot;status&quot;: &quot;success&quot;,&#10;      &quot;created_on&quot;: &quot;&lt;TIMESTAMP&gt;&quot;,&#10;      &quot;modified_on&quot;: &quot;&lt;TIMESTAMP&gt;&quot;&#10;    }&#10;  ],&#10;  &quot;success&quot;: true,&#10;  &quot;errors&quot;: [],&#10;  &quot;messages&quot;: []&#10;}&#10;</code></pre>
<h2 id="upload-a-program">Upload a program</h2>
<p>This example uploads a new eBPF program written in C. The program source code is sent as the request body with <code>Content-Type: text/plain</code>.</p>
<p>Include the optional <code>X-Program-Name</code> header to specify a human-readable program name. If omitted, the API generates a UUID as the program name.</p>
<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/programmable_flow_protection/configs/programs&quot; \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \&#10;&#45;-header &quot;Content-Type: text/plain&quot; \&#10;&#45;-header &quot;X-Program-Name: my-rate-limiter&quot; \&#10;&#45;-data-binary &quot;@/path/to/program.c&quot;&#10;</code></pre>
<pre><code class="language-json">{&#10;  &quot;result&quot;: {&#10;    &quot;id&quot;: &quot;&lt;PROGRAM_ID&gt;&quot;,&#10;    &quot;name&quot;: &quot;my-rate-limiter&quot;,&#10;    &quot;status&quot;: &quot;success&quot;,&#10;    &quot;created_on&quot;: &quot;&lt;TIMESTAMP&gt;&quot;,&#10;    &quot;modified_on&quot;: &quot;&lt;TIMESTAMP&gt;&quot;&#10;  },&#10;  &quot;success&quot;: true,&#10;  &quot;errors&quot;: [],&#10;  &quot;messages&quot;: []&#10;}&#10;</code></pre>
<p>If the program fails compilation or verification, the API returns a detailed error message:</p>
<pre><code class="language-json">{&#10;  &quot;result&quot;: null,&#10;  &quot;success&quot;: false,&#10;  &quot;errors&quot;: [&#10;    {&#10;      &quot;code&quot;: 1001,&#10;      &quot;message&quot;: &quot;Program verification failed: invalid memory access at line 42&quot;&#10;    }&#10;  ],&#10;  &quot;messages&quot;: []&#10;}&#10;</code></pre>
<h2 id="update-a-program">Update a program</h2>
<p>This example updates an existing program with new source code. You can update a program even if it is currently in use by one or more rules. If the new program fails compilation or verification, the update fails and the existing program remains active.</p>
<pre><code class="language-bash">curl --request PATCH \&#10;&quot;https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/programmable_flow_protection/configs/programs/{program_id}&quot; \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \&#10;&#45;-header &quot;Content-Type: text/plain&quot; \&#10;&#45;-data-binary &quot;@/path/to/updated-program.c&quot;&#10;</code></pre>
<pre><code class="language-json">{&#10;  &quot;result&quot;: {&#10;    &quot;id&quot;: &quot;&lt;PROGRAM_ID&gt;&quot;,&#10;    &quot;name&quot;: &quot;program&quot;,&#10;    &quot;status&quot;: &quot;success&quot;,&#10;    &quot;created_on&quot;: &quot;&lt;TIMESTAMP&gt;&quot;,&#10;    &quot;modified_on&quot;: &quot;&lt;TIMESTAMP&gt;&quot;&#10;  },&#10;  &quot;success&quot;: true,&#10;  &quot;errors&quot;: [],&#10;  &quot;messages&quot;: []&#10;}&#10;</code></pre>
<h2 id="delete-a-program">Delete a program</h2>
<p>This example deletes a program. You cannot delete a program that is currently referenced by an active rule.</p>
<pre><code class="language-bash">curl --request DELETE \&#10;&quot;https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/programmable_flow_protection/configs/programs/{program_id}&quot; \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot;&#10;</code></pre>

<h2 id="debug-a-program-with-pcap">Debug a program with PCAP</h2>
<p>This example runs a program against a PCAP file for debugging. The API returns an annotated PCAP file with the program verdict for each packet.</p>
<p>The request body must contain the PCAP file in binary format. The API automatically detects the IP header offset based on the input PCAP. To override automatic detection, use the optional <code>ip_offset</code> query parameter to specify the number of bytes the IP header is offset by in each packet (for example, <code>14</code> for Ethernet frames).</p>
<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/programmable_flow_protection/configs/programs/{program_id}/pcap&quot; \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \&#10;&#45;-header &quot;Content-Type: application/vnd.tcpdump.pcap&quot; \&#10;&#45;-data-binary &quot;@/path/to/input.pcap&quot; \&#10;&#45;-output output.pcap&#10;</code></pre>
<p>The output PCAP file contains the same packets as the input file, but with annotations on each packet.
The Packet Comment annotation may contain:</p>
<ul>
<li>Program return value: <code>CF_EBPF_PASS</code> or <code>CF_EBPF_DROP</code></li>
<li><code>Ignored</code>: if the incoming packet is not UDP</li>
<li><code>Analytics tag</code>: the custom network analytics tag set by the program on this packet, if any</li>
<li><code>Challenge packet</code>: the challenge packet emitted from the program back to the client, if any</li>
</ul>
