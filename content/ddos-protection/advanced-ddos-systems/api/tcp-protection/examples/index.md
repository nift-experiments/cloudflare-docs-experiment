<p>The following sections contain example requests for common API calls. For a list of available API endpoints, refer to <a href="/ddos-protection/advanced-ddos-systems/api/tcp-protection/#endpoints">Endpoints</a>.</p>
<h2 id="get-advanced-tcp-protection-status">Get Advanced TCP Protection status</h2>
<p>This example obtains the current status of Advanced TCP Protection (enabled or disabled).</p>
<pre><code class="language-bash">curl https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/advanced_tcp_protection/configs/tcp_protection_status \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot;&#10;</code></pre>
<pre><code class="language-json">{&#10;  &quot;result&quot;: {&#10;    &quot;enabled&quot;: false&#10;  },&#10;  &quot;success&quot;: true,&#10;  &quot;errors&quot;: [],&#10;  &quot;messages&quot;: []&#10;}&#10;</code></pre>
<h2 id="enable-advanced-tcp-protection">Enable Advanced TCP Protection</h2>
<p>This example enables Advanced TCP Protection.</p>
<pre><code class="language-bash">curl --request PATCH \&#10;https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/advanced_tcp_protection/configs/tcp_protection_status \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \&#10;&#45;-header &quot;Content-Type: application/json&quot; \&#10;&#45;-data &#x27;{&#10;  &quot;enabled&quot;: true&#10;}&#x27;&#10;</code></pre>
<h2 id="get-existing-prefixes">Get existing prefixes</h2>
<p>This example fetches all existing prefixes in Advanced TCP Protection.</p>
<pre><code class="language-bash">curl https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/advanced_tcp_protection/configs/prefixes \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot;&#10;</code></pre>
<pre><code class="language-json">{&#10;  &quot;result&quot;: [&#10;    {&#10;      &quot;prefix&quot;: &quot;203.0.113/24&quot;,&#10;      &quot;comment&quot;: &quot;My prefix&quot;,&#10;      &quot;excluded&quot;: false&#10;    }&#10;  ],&#10;  &quot;success&quot;: true,&#10;  &quot;errors&quot;: [],&#10;  &quot;messages&quot;: []&#10;}&#10;</code></pre>
<h2 id="add-prefixes">Add prefixes</h2>
<p>This example <code>POST</code> request adds two prefixes. The second prefix excludes a subset of the first prefix from Advanced TCP Protection.</p>
<pre><code class="language-bash">curl https://api.cloudflare.com/client/v4/accounts/{account_id}/magic/advanced_tcp_protection/configs/prefixes/bulk \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \&#10;&#45;-header &quot;Content-Type: application/json&quot; \&#10;&#45;-data &#x27;[&#10;  {&#10;    &quot;prefix&quot;: &quot;192.0.2.0/24&quot;,&#10;    &quot;comment&quot;: &quot;Game ranges&quot;,&#10;    &quot;excluded&quot;: false&#10;  },&#10;  {&#10;    &quot;prefix&quot;: &quot;192.0.2.2/26&quot;,&#10;    &quot;comment&quot;: &quot;Range for a specific game&quot;,&#10;    &quot;excluded&quot;: true&#10;  }&#10;]&#x27;&#10;</code></pre>
<pre><code class="language-json">{&#10;  &quot;result&quot;: [&#10;    {&#10;      &quot;id&quot;: &quot;&lt;PREFIX_1_ID&gt;&quot;,&#10;      &quot;prefix&quot;: &quot;192.0.2.0/24&quot;,&#10;      &quot;excluded&quot;: false,&#10;      &quot;comment&quot;: &quot;Game ranges&quot;,&#10;      &quot;created_on&quot;: &quot;&lt;TIMESTAMP&gt;&quot;,&#10;      &quot;modified_on&quot;: &quot;&lt;TIMESTAMP&gt;&quot;&#10;    },&#10;    {&#10;      &quot;id&quot;: &quot;&lt;PREFIX_2_ID&gt;&quot;,&#10;      &quot;prefix&quot;: &quot;192.0.2.2/26&quot;,&#10;      &quot;excluded&quot;: true,&#10;      &quot;comment&quot;: &quot;Range for a specific game&quot;,&#10;      &quot;created_on&quot;: &quot;&lt;TIMESTAMP&gt;&quot;,&#10;      &quot;modified_on&quot;: &quot;&lt;TIMESTAMP&gt;&quot;&#10;    }&#10;  ],&#10;  &quot;success&quot;: true,&#10;  &quot;errors&quot;: [],&#10;  &quot;messages&quot;: []&#10;}&#10;</code></pre>
