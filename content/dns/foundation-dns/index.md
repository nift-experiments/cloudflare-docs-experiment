<p>Foundation DNS is the Cloudflare DNS offering for enterprise customers.</p>
<p>With Foundation DNS, you get access to increased reliability, security, and insights. Features include the following:</p>
<ul>
<li><a href="/dns/foundation-dns/advanced-nameservers/">Advanced nameservers</a> that provide:
<ul>
<li>Strategically distributed IPs to enhance resiliency</li>
<li>Reduced exposure to incidents or software regression</li>
<li>More consistent nameserver assignment</li>
</ul>
</li>
<li><a href="/dns/foundation-dns/dnssec-keys/">DNSSEC keys</a> unique to your account</li>
<li>Additional DNS settings, including:
<ul>
<li><a href="/dns/additional-options/dns-zone-defaults/">Zone defaults</a></li>
<li><a href="/dns/nameservers/custom-nameservers/account-custom-nameservers/">Account custom nameservers</a></li>
<li>Custom <a href="/dns/manage-dns-records/reference/dns-record-types/#soa">SOA record</a> and <a href="/dns/nameservers/nameserver-options/#nameserver-ttl">Nameserver TTL</a></li>
</ul>
</li>
</ul>
<h2 id="availability">Availability</h2>
<p>Foundation DNS is only available to Enterprise customers.</p>
