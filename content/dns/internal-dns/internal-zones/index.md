<p>Internal DNS zones are groupings of internal DNS records. While <a href="/dns/manage-dns-records/">public DNS records</a> contain information about resources that you want to make available to the public Internet, <a href="/dns/internal-dns/internal-zones/internal-dns-records/">internal DNS records</a> allow you to manage resources that should only be available within your private network.</p>
<p>Refer to <a href="/dns/internal-dns/internal-zones/setup/">Manage internal zones</a> for a full list of configuration conditions and step-by-step instructions.</p>
<p>Internal DNS zones do not get assigned Cloudflare nameservers and can only be queried via <a href="/cloudflare-one/traffic-policies/resolver-policies/">Cloudflare Gateway</a> when linked to a <a href="/dns/internal-dns/dns-views/">DNS view</a>. The Gateway configuration must exist within the same Cloudflare account where the internal zone exists.</p>
