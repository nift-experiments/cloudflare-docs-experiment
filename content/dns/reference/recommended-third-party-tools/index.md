<p>You can use the third-party tools listed below to test and troubleshoot DNS settings.</p>
<ul>
<li>
<p><a href="https://dnsviz.net">DNSViz</a>: A web-based tool for visualizing the status of a DNS zone to understand and troubleshoot the deployment of DNS Security Extensions (DNSSEC).</p>
</li>
<li>
<p><a href="https://digwebinterface.com">Dig Web Interface</a>: An online DNS lookup tool based on the command line interface <code>dig</code>. Users can skip the process of entering commands with complicated parameters in the terminal by entering the same information in this web tool and getting the same results.</p>
</li>
<li>
<p><a href="https://dns.google">dns.google</a>: A web-based tool, similar to Dig Web Interface, where users can get DNS responses for specific queries.</p>
</li>
<li>
<p><a href="https://messwithdns.net">Mess with DNS</a>: An educational resource that encourages users to experiment with DNS records by providing users with a domain where they are free to play around and break things during the learning process.</p>
</li>
</ul>
