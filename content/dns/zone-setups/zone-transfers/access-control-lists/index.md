<p>Access Control Lists (ACLs) define allowed source IP addresses from where servers accept incoming data or control messages.</p>
<p>When setting up new DNS zone transfers (<a href="/dns/zone-setups/zone-transfers/cloudflare-as-secondary/">incoming</a> or <a href="/dns/zone-setups/zone-transfers/cloudflare-as-primary/">outgoing</a>), you will need to update the ACL at your other DNS provider(s) to allow Cloudflare to communicate with their server(s). You can find the Cloudflare IP addresses you need to allow at your other DNS provider(s) at <a href="/dns/zone-setups/zone-transfers/access-control-lists/cloudflare-ip-addresses/">Cloudflare IP addresses</a>.</p>
<p>For your Cloudflare account, you only need to <a href="/dns/zone-setups/zone-transfers/access-control-lists/create-new-list/">create a new ACL</a> if you want to specify additional NOTIFY IPs that Cloudflare should listen to.</p>
