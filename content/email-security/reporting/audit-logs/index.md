<p>You can use Email security logs to review actions performed on your account:</p>
<ol>
<li>Log in to the <a href="https://horizon.area1security.com/">Email security dashboard</a>.</li>
<li>Go to <strong>Settings</strong> (the gear icon).</li>
<li>Go to <strong>Users and Actions</strong> &gt; <strong>Audit Log</strong>.</li>
<li>Review the logs. You can also filter by type of log from the dropdown menu.</li>
</ol>
<h2 id="logs-preview">Logs preview</h2>
<p>You can use one of the Preview logs to preview how Email security handles post delivery retractions. With Audit logs Preview, Email security shows you the emails that would have been retracted with Post Delivery Response (PDR) or Phish Submissions Response (PSR) enabled.</p>
<p>Refer to <strong>Post delivery retractions for new threats</strong> for <a href="/email-security/deployment/api/setup/gsuite-bcc-setup/add-retraction/#post-delivery-retractions-for-new-threats">Gmail</a> or <a href="/email-security/email-configuration/retract-settings/office365-retraction/#post-delivery-retractions-for-new-threats">Office 365</a> to learn more about this feature.</p>
<p>To review preview logs:</p>
<ol>
<li>Log in to the <a href="https://horizon.area1security.com/">Email security dashboard</a>.</li>
<li>Go to <strong>Settings</strong> (the gear icon).</li>
<li>Go to <strong>Users and Actions</strong> &gt; <strong>Audit Log</strong>.</li>
<li>From the dropdown, select one of the <strong>Preview</strong> logs. This will show you what would have been retracted with Post Delivery Response or Phish Submission Response enabled.</li>
</ol>
