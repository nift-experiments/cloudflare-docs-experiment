<h2 id="store-emails-in-kv">Store emails in KV</h2>
<p>Store emails in a KV namespace for later processing. This example uses <a href="https://www.npmjs.com/package/mimetext"><code>mimetext</code></a> to build replies, which requires the <a href="/workers/runtime-apis/nodejs/"><code>nodejs_compat</code></a> compatibility flag.</p>

<h2 id="queue-based-processing">Queue-based processing</h2>
<p>Process emails asynchronously using Cloudflare Queues. The <code>email()</code> handler sends a threaded acknowledgement with <code>message.reply()</code> and enqueues the message for later processing. The queue consumer runs in a separate invocation where the original <code>EmailMessage</code> is no longer available, so any follow-up emails it sends use <code>env.EMAIL.send()</code> instead.</p>
