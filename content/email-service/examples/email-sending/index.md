<p>Advanced patterns and examples for sending emails with Cloudflare Email Service. Most examples use the <a href="/email-service/api/send-emails/workers-api/">Workers binding</a>; the same <a href="/email-service/api/send-emails/workers-api/#send-method"><code>EmailMessageBuilder</code></a> fields (<code>to</code>, <code>from</code>, <code>subject</code>, <code>html</code>, <code>text</code>, <code>cc</code>, <code>bcc</code>, <code>replyTo</code>, <code>attachments</code>, <code>headers</code>) apply to the <a href="/email-service/api/send-emails/rest-api/">REST API</a> as JSON in your HTTP request body. The <a href="/email-service/examples/email-sending/smtp/">Send email over SMTP</a> example covers sending over SMTP from several languages and clients.</p>
