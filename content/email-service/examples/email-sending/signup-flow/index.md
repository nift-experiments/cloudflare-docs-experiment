<p class="article-summary">Send welcome and verification emails during user signup with secure token-based email verification.</p>
<p>This example demonstrates a complete user registration system with welcome emails and email verification.</p>
<p>Configure the email binding and KV namespaces in your Wrangler configuration file:</p>

<p>The Worker exposes two routes: <code>POST /signup</code> creates a user, stores it in KV, and sends both a welcome email and a verification email containing a tokenized link; <code>GET /verify</code> validates that token and marks the user verified. The following code implements both handlers.</p>

{&#10;		const url = new URL(request.url);&#10;&#10;		if (url.pathname === &quot;/signup&quot; &amp;&amp; request.method === &quot;POST&quot;) {&#10;			return handleSignup(request, env);&#10;		}&#10;&#10;		if (url.pathname === &quot;/verify&quot; &amp;&amp; request.method === &quot;GET&quot;) {&#10;			return handleVerification(request, env);&#10;		}&#10;&#10;		return new Response(&quot;Not Found&quot;, { status: 404 });&#10;	},&#10;};&#10;&#10;async function handleSignup(request: Request, env: Env): Promise&lt;Response&gt;
