<h2 id="filter-object-structure-and-properties">Filter object structure and properties</h2>
<p>A JSON response for the <a href="/api/resources/filters/methods/list/">Filters API</a> has this structure:</p>
<pre tabindex="0"><code class="language-json">{&#10;	&quot;id&quot;: &quot;6f58318e7fa2477a23112e8118c66f61&quot;,&#10;	&quot;expression&quot;: &quot;http.request.uri.path ~ \&quot;^.*/wp-login.php$\&quot; or http.request.uri.path ~ \&quot;^.*/xmlrpc.php$\&quot;&quot;,&#10;	&quot;paused&quot;: true,&#10;	&quot;description&quot;: &quot;WordPress login paths&quot;,&#10;	&quot;ref&quot;: &quot;&quot;&#10;}&#10;</code></pre>

</td>

				<p>Unique, read only</p>
