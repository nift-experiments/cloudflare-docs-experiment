<h2 id="update-multiple-filters">Update multiple filters</h2>
<p>This example updates two filters with IDs <code>&lt;FILTER_ID_1&gt;</code> and <code>&lt;FILTER_ID_2&gt;</code> using a single API call.</p>
<pre><code class="language-bash">curl --request PUT \&#10;&quot;https://api.cloudflare.com/client/v4/zones/{zone_id}/filters&quot; \&#10;&#45;-header &quot;X-Auth-Email: &lt;EMAIL&gt;&quot; \&#10;&#45;-header &quot;X-Auth-Key: &lt;API_KEY&gt;&quot; \&#10;&#45;-header &quot;Content-Type: application/json&quot; \&#10;&#45;-data &#x27;[&#10;  {&#10;    &quot;id&quot;: &quot;&lt;FILTER_ID_1&gt;&quot;,&#10;    &quot;paused&quot;: false,&#10;    &quot;expression&quot;: &quot;ip.src eq 93.184.216.0&quot;,&#10;    &quot;description&quot;: &quot;IP of example.org&quot;&#10;  },&#10;  {&#10;    &quot;id&quot;: &quot;&lt;FILTER_ID_2&gt;&quot;,&#10;    &quot;expression&quot;: &quot;http.request.uri.path matches \&quot;^/api/.*$\&quot;&quot;,&#10;    &quot;description&quot;: &quot;/api&quot;&#10;  }&#10;]&#x27;&#10;</code></pre>
<pre><code class="language-json">{&#10;  &quot;result&quot;: [&#10;    {&#10;      &quot;id&quot;: &quot;&lt;FILTER_ID&gt;&quot;,&#10;      &quot;paused&quot;: false,&#10;      &quot;description&quot;: &quot;IP of example.org&quot;,&#10;      &quot;expression&quot;: &quot;ip.src eq 93.184.216.0&quot;&#10;    },&#10;    {&#10;      &quot;id&quot;: &quot;&lt;FILTER_ID_2&gt;&quot;,&#10;      &quot;paused&quot;: false,&#10;      &quot;description&quot;: &quot;/api&quot;,&#10;      &quot;expression&quot;: &quot;http.request.uri.path matches \&quot;^/api/.*$\&quot;&quot;&#10;    }&#10;  ],&#10;  &quot;success&quot;: true,&#10;  &quot;errors&quot;: [],&#10;  &quot;messages&quot;: []&#10;}&#10;</code></pre>
<h2 id="update-a-single-filter">Update a single filter</h2>
<p>This example updates the filter with ID <code>{filter_id}</code>.</p>
<pre><code class="language-bash">curl --request PUT \&#10;&quot;https://api.cloudflare.com/client/v4/zones/{zone_id}/filters/{filter_id}&quot; \&#10;&#45;-header &quot;X-Auth-Email: &lt;EMAIL&gt;&quot; \&#10;&#45;-header &quot;X-Auth-Key: &lt;API_KEY&gt;&quot; \&#10;&#45;-header &quot;Content-Type: application/json&quot; \&#10;&#45;-data &#x27;{&#10;  &quot;id&quot;: &quot;&lt;FILTER_ID&gt;&quot;,&#10;  &quot;paused&quot;: false,&#10;  &quot;description&quot;: &quot;Login from office&quot;,&#10;  &quot;expression&quot;: &quot;ip.src in {2400:cb00::/32 2a06:98c0::/29} and (http.request.uri.path ~ \&quot;^.*/wp-login.php$\&quot; or http.request.uri.path ~ \&quot;^.*/xmlrpc.php$\&quot;)&quot;&#10;}&#x27;&#10;</code></pre>
