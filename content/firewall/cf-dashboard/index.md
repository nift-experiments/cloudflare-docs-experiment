<p>To configure firewall rules in the Cloudflare dashboard, open <strong>Firewall rules</strong> in <strong>Security</strong> &gt; <strong>WAF</strong>.</p>
<aside class="nb-aside caution">
<h3 class="nb-aside-title" id="deprecation-notice">Deprecation notice</h3>
@markup("md", "content/.markup/bodies/8697.md")
</aside>
<p>As depicted in the image below, the <strong>Firewall rules</strong> dashboard interface lets you:</p>
<ul>
<li>View the list of existing rules, both enabled and disabled.</li>
<li><a href="/firewall/cf-dashboard/create-edit-delete-rules/">Create, edit, and delete</a> firewall rules.</li>
<li>Enable or disable rules.</li>
<li>Search and filter the list of existing rules.</li>
<li>Reorder firewall rules when using <a href="/firewall/cf-firewall-rules/order-priority/#managing-rule-evaluation-by-list-order">list ordering</a>.</li>
</ul>
