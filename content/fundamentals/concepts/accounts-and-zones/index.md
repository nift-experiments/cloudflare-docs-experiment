<p>Within the Cloudflare ecosystem, there are three organizing concepts that control where specific settings live: user profiles, accounts, and zones.</p>

<h2 id="user-profiles">User profiles</h2>
<p>Each user has a profile that contains several settings, such as <a href="/fundamentals/user-profiles/customize-account/#notifications">Communication preferences</a> and <a href="/fundamentals/user-profiles/customize-account/#language">Language preferences</a>.</p>
<p>To access your profile, select the user icon and then <strong>My Profile</strong> from any page within the <a href="https://dash.cloudflare.com">Cloudflare dashboard</a>.</p>
<h2 id="accounts">Accounts</h2>
<p>An account refers to an organization account, which contains one or more users and zones. Users can belong to multiple accounts, and each account maintains its own settings, including <a href="/billing/get-started/create-billing-profile/">billing profiles</a>, <a href="/fundamentals/manage-members/">account members</a>, <a href="/waf/tools/lists/">lists</a>, and other configurations.</p>
<p>Several account-level products - such as <a href="/workers/">Workers</a>, <a href="/pages/">Pages</a>, <a href="/security-center/">Security Center</a>, and <a href="/rules/url-forwarding/bulk-redirects/">Bulk redirects</a> - can affect some or all zones contained within that account.</p>
<p>After you <a href="https://dash.cloudflare.com">log in</a> and select an account - but before you select a zone - the sidebar will list account-level products.</p>
<p>When you log into the <a href="https://dash.cloudflare.com">Cloudflare dashboard</a>, you can access all accounts where your user is a member. To access account settings and account-level products from within a zone, use the <strong>Accounts</strong> option from the navigation sidebar.</p>
<h2 id="zones">Zones</h2>
<p>Domains (or <a href="/dns/zone-setups/subdomain-setup/">subdomains</a>) that are added to Cloudflare become zones<sup><a href="#footnote-1">1</a></sup>, which have a direct impact on the security and performance of your website, application, or API. Use your zone to monitor security and performance, update configurations, and apply zone-level products and services.</p>
<p>Zone-level services - such as <a href="/load-balancing/">Load Balancers</a> and <a href="/cache/how-to/cache-rules/">Cache rules</a> - only affect your website, application, or API for that zone and not other zones, even if they are contained within the same account.</p>
<p>When you log into the <a href="https://dash.cloudflare.com">Cloudflare dashboard</a> and choose an account, you can view a list of all zones within that account.</p>
<p>Once you are within a zone, items within the sidebar will be zone-related products. If you need to change to another zone, use the forward arrow next to the zone name or by go back to the homepage of your account.</p>
