<p>Before you can begin using Cloudflare products, first <a href="/fundamentals/account/create-account/">create an account</a>. If multiple people manage your Cloudflare account, <a href="/fundamentals/manage-members/">set up member permissions</a> to control which resources each person can access.</p>
<h2 id="learn-about-cloudflare-s-offerings">Learn about Cloudflare's offerings</h2>
<h3 id="build">Build</h3>
<p><strong>Build</strong> is where developers create and deploy simple sites and full-stack applications on the <a href="/workers/">Workers compute platform</a>, and connect them to storage and database primitives like <a href="/kv/">KV</a> (key-value data store), <a href="/d1/">D1</a> (SQL database), <a href="/r2/">R2</a> (object storage), <a href="/queues/">Queues</a> (asynchronous messaging), <a href="/durable-objects/">Durable Objects</a> (stateful coordination), and more.</p>
<p>Our compute, orchestration, AI, storage, media, and security services are integrated, so you can quickly extend existing apps or launch new ones while Cloudflare's global network takes care of infrastructure, scaling, and performance for you.</p>
<h3 id="protect-connect">Protect &amp; Connect</h3>
<p><strong>Protect &amp; Connect</strong> is where you establish fast and reliable connections between your websites, apps, and users, while protecting them from attackers and unwanted traffic.</p>
<p>Application security and performance focuses on resources available on the public Internet. Manage delivery performance by controlling and speeding up primarily <a href="/fundamentals/reference/network-layers/">Layer 7 (Application) traffic</a>, in addition to managing media such as video and images. Get started by <a href="/fundamentals/manage-domains/add-site/">onboarding a domain</a>.</p>
<p>Zero Trust protects private, internal users/devices and the resources they access. <a href="/cloudflare-one/setup/">Get started with Zero Trust</a>.</p>
<p>Network services extend protection and acceleration to cloud, on-premise, or hybrid networks, and you can also manage network connections and optimize Layer 3 (Network) and 4 (Transport) traffic. Get started with <a href="/magic-transit/">Magic Transit</a> or <a href="/cloudflare-wan/">Cloudflare WAN</a> (formerly Magic WAN).</p>
