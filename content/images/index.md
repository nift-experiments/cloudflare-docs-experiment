<p>Images is designed to help developers deploy media-rich applications faster.</p>
<p>With Images, you can dynamically resize, optimize, and manipulate images at Cloudflare's edge to serve the optimal version for each user in real time — without manually creating or storing multiple copies of the same image for different use cases, browsers, or device breakpoints.</p>
