<p>You can apply blur to image variants by creating a specific variant for this effect first or by editing a previously created variant. Note that you cannot blur an SVG file.</p>
<p>Refer to <a href="/images/optimization/hosted-images/create-variants/">Resize images</a> for help creating variants. You can also refer to the API to learn how to use blur using flexible variants.</p>
<p>To blur an image:</p>
<ol>
<li>In the Cloudflare dashboard, go to the <strong>Hosted Images</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Select the <strong>Delivery</strong> tab.</li>
<li>Find the variant you want to blur and select <strong>Edit</strong> &gt; <strong>Customization Options</strong>.</li>
<li>Use the slider to adjust the blurring effect. You can use the preview image to see how strong the blurring effect will be.</li>
<li>Select <strong>Save</strong>.</li>
</ol>
<p>The image should now display the blurred effect.</p>
