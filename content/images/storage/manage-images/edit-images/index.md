<p>The Edit option provides you available options to modify a specific image. After choosing to edit an image, you can:</p>
<ul>
<li>Require signed URLs to use with that particular image.</li>
<li>Use a cURL command you can use as an example to access the image.</li>
<li>Use fully-formed URLs for all the variants configured in your account.</li>
</ul>
<p>To edit an image:</p>
<ol>
<li>In the Cloudflare dashboard, go to the <strong>Hosted Images</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Locate the image you want to modify and select <strong>Edit</strong>.</li>
</ol>
