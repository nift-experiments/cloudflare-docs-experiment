<p>You can use a custom ID path to upload an image instead of the path automatically generated by Cloudflare Images’ Universal Unique Identifier (UUID).</p>
<p>Custom paths support:</p>
<ul>
<li>Up to 1,024 characters.</li>
<li>Any number of subpaths.</li>
<li>The <a href="https://en.wikipedia.org/wiki/UTF-8">UTF-8 encoding standard</a> for characters.</li>
</ul>
<aside class="nb-aside note">
@markup("md", "content/.markup/bodies/9476.md")
</aside>
<p>Make a <code>POST</code> request using the example below as reference. You can use custom ID paths when you upload via a URL or with a direct file upload.</p>
<pre tabindex="0"><code class="language-bash">curl --request POST https://api.cloudflare.com/client/v4/accounts/{account_id}/images/v1 \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \&#10;&#45;-form &#x27;url=https://&lt;REMOTE_PATH_TO_IMAGE&gt;&#x27; \&#10;&#45;-form &#x27;id=&lt;PATH_TO_YOUR_IMAGE&gt;&#x27;&#10;</code></pre>
<p>After successfully uploading the image, you will receive a response similar to the example below.</p>
<pre tabindex="0"><code class="language-json">{&#10;	&quot;result&quot;: {&#10;		&quot;id&quot;: &quot;&lt;PATH_TO_YOUR_IMAGE&gt;&quot;,&#10;		&quot;filename&quot;: &quot;&lt;YOUR_IMAGE&gt;&quot;,&#10;		&quot;uploaded&quot;: &quot;2022-04-20T09:51:09.559Z&quot;,&#10;		&quot;requireSignedURLs&quot;: false,&#10;		&quot;variants&quot;: [&#10;			&quot;https://imagedelivery.net/Vi7wi5KSItxGFsWRG2Us6Q/&lt;PATH_TO_YOUR_IMAGE&gt;/public&quot;&#10;		]&#10;	},&#10;	&quot;result_info&quot;: null,&#10;	&quot;success&quot;: true,&#10;	&quot;errors&quot;: [],&#10;	&quot;messages&quot;: []&#10;}&#10;</code></pre>
