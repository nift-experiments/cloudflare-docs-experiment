<h2 id="2024-11-14">2024-11-14</h2><strong>Workers KV REST API bulk operations provide granular errors</strong><p>The REST API endpoints for bulk operations (<a href="/api/resources/kv/subresources/namespaces/subresources/keys/methods/bulk_update/">write</a>, <a href="/api/resources/kv/subresources/namespaces/subresources/keys/methods/bulk_delete/">delete</a>) now return the keys of operations that failed during the bulk operation. The updated response bodies are documented in the <a href="/api/resources/kv/subresources/namespaces/methods/list/">REST API documentation</a> and contain the following information in the <code>result</code> field:</p>
<pre tabindex="0"><code>{&#10;  &quot;successful_key_count&quot;: number,&#10;  &quot;unsuccessful_keys&quot;: string[]&#10;}&#10;</code></pre>
<p>The unsuccessful keys are an array of keys that were not written successfully to all storage backends and therefore should be retried.</p><h2 id="2024-08-08">2024-08-08</h2><strong>New KV Analytics API</strong><p>Workers KV now has a new <a href="/kv/observability/metrics-analytics/#view-metrics-in-the-dashboard">metrics dashboard</a> and <a href="/kv/observability/metrics-analytics/#query-via-the-graphql-api">analytics API</a> that leverages the <a href="/analytics/graphql-api/">GraphQL Analytics API</a> used by many other Cloudflare products. The new analytics API provides per-account and per-namespace metrics for both operations and storage, including latency metrics for read and write operations to Workers KV.</p>
<p>The legacy Workers KV analytics REST API will be turned off as of January 31st, 2025.
Developers using this API will receive a series of email notifications prior to the shutdown of the legacy API.</p>
