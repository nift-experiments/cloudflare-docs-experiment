<h2 id="deprecations">Deprecations</h2>
<p>Below are deprecations to Wrangler commands for Workers KV.</p>
<h3 id="kv-syntax-deprecation"><code>kv:...</code> syntax deprecation</h3>
<p>Since version 3.60.0, Wrangler supports the <code>kv ...</code> syntax. If you are using versions below 3.60.0, the command follows the <code>kv:...</code> syntax.</p>
<p>The <code>kv:...</code> syntax is deprecated in versions 3.60.0 and beyond and will be removed in a future major version.</p>
<p>For example, commands using the <code>kv ...</code> syntax look as such:</p>
<pre tabindex="0"><code class="language-sh">wrangler kv namespace list&#10;wrangler kv key get &lt;KEY&gt;&#10;wrangler kv bulk put &lt;FILENAME&gt;&#10;</code></pre>
<p>The same commands using the <code>kv:...</code> syntax look as such:</p>
<pre tabindex="0"><code class="language-sh">wrangler kv:namespace list&#10;wrangler kv:key get &lt;KEY&gt;&#10;wrangler kv:bulk put &lt;FILENAME&gt;&#10;</code></pre>
