<p>In the Cloudflare dashboard, you can view a list of active sessions associated with your email address.</p>
<p>Each time your email is used to log in to your Cloudflare account, a session begins. The Cloudflare dashboard provides session information including if the device is currently viewing the dashboard, the IP address, location, device type, browser type, and last active login.</p>
<p>If you notice any suspicious activity, you can also revoke any active sessions.</p>

<p>If you navigate to <strong>My Profile</strong> &gt; <strong>Sessions</strong>, you can view active sessions and revoke any session that you do not recognize.</p>
