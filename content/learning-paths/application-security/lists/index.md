<p>Cloudflare Lists is a WAF feature that enables administrators to groups identifiers together, such as IPs, hostnames or ASNs, and reference the list by other Cloudflare products such as <a href="/waf/custom-rules/">Custom rules</a>. Cloudflare currently supports the following types of lists:</p>
<ul>
<li><a href="/waf/tools/lists/custom-lists/">Custom Lists</a>: Includes custom IP lists, hostname lists, and ASN lists.</li>
<li><a href="/waf/tools/lists/managed-lists/">Managed Lists</a>: Lists managed and updated by Cloudflare, such as Managed IP Lists.</li>
</ul>
