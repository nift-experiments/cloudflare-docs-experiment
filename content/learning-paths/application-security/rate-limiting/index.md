<p>Rate Limiting mitigates excessive request rates for specific URLs or for an entire domain. Request rates are calculated locally for individual Cloudflare data centers. You can configure thresholds and define responses by IP. If traffic from a specific IP exceeds the threshold, then you can take action on the offending IP for a defined period of time.</p>

<ul>
<li>Understand all the options Cloudflare's Rate Limiting product offers</li>
