<p>Cloudflare Access offers several ways to customize the look and feel of the user login experience.</p>
<h2 id="objectives">Objectives</h2>
<p>By the end of this module, you will be able to:</p>
<ul>
<li>Configure the App Launcher so that users can open all applications from single dashboard.</li>
<li>Add bookmarks to the App Launcher for applications that are not behind Access.</li>
<li>Customize the Access login page with your organization's branding.</li>
<li>Display custom block pages when a user is blocked by your Access policies.</li>
</ul>
