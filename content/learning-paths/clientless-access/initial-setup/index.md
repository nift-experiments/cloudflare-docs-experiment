<p>In this guide, you will learn how to deliver clientless access using the Cloudflare Zero Trust suite of products. This guide will focus on browser-based applications that do not require users to install a device client of any kind. It will discuss both common and complex scenarios, and should give you the tools to provide secure user access to internal web applications following a <a href="https://www.cloudflare.com/learning/security/glossary/what-is-zero-trust/">Zero Trust model</a>.</p>
<p>If you need to deliver access to non-browser based applications, refer to our complementary guide for <a href="/learning-paths/clientless-access/concepts/">replacing your VPN</a>.</p>
<h2 id="objectives">Objectives</h2>
<p>By the end of this module, you will be able to:</p>
<ul>
<li>Set up a Cloudflare account.</li>
<li>Add your domain to Cloudflare.</li>
<li>Create a Zero Trust organization to manage applications and policies.</li>
<li>Configure an identity provider (IdP) for user authentication.</li>
</ul>
