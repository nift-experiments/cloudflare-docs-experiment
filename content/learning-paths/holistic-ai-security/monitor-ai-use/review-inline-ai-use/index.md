<p>To review how your organization uses AI apps, start with the Cloudflare <a href="/cloudflare-one/insights/analytics/shadow-it-discovery/">Shadow IT dashboard</a>. You can filter the dashboard by application type and sort by Artificial Intelligence, which allows you to take several valuable actions, such as:</p>
<ul>
<li>Reviewing application usage: See which applications your users are engaging with and how often, based on traffic from connected devices or sites.</li>
<li>Accessing application details: Learn more about the applications in use by reviewing their entries in the App Library.</li>
<li>Designating application status: Use a <a href="/cloudflare-one/insights/analytics/shadow-it-discovery/#approval-status">status marker</a> to categorize applications, so you can apply specific security policies to them.</li>
</ul>
<p><img src="/assets/upstream/images/learning-paths/holistic-ai-security/shadowit-dashboard-ai-apps.png" alt="Shadow IT dashboard showing utilization of application statuses (Approved, Unapproved, In Review, Unreviewed)." /></p>
<p>This approach is most relevant for applications that your organization has not yet sanctioned. For example, if your business uses Google Workspace and its primary AI tool is Gemini, you would likely mark Gemini as <em>Approved</em>. While you can configure more specific data loss policies later, you can also target approved applications with greater specificity to detect risks unique to your organization.</p>
