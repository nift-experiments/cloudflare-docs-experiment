<p>Learn the concepts behind load balancing, whether you are using Cloudflare or another provider.</p>
<h2 id="objectives">Objectives</h2>
<p>By the end of this module, you will be able to:</p>
<ul>
<li>Explain what load balancing is.</li>
<li>Describe the differences between load balancers, pools, and servers.</li>
<li>Explain what pool health is and how it affects load balancer traffic.</li>
<li>List the different ways your traffic can be routed.</li>
</ul>
