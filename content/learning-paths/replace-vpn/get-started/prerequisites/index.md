<p>To make the most of this learning path, make sure that you have the following:</p>
<ul>
<li>A device that can run <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/download/">Cloudflare One Client</a>, Cloudflare's endpoint agent.</li>
<li>A private network with applications or services that are available locally or via a VPN.</li>
<li>A <a href="/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/tunnel-availability/system-requirements/#recommendations">host server</a> on the private network that can run the lightweight Cloudflare Tunnel daemon process.</li>
<li>(Optional) A <a href="/cloudflare-one/team-and-resources/devices/cloudflare-one-client/download/#linux">Linux host server</a> on the private network that can run Cloudflare Mesh. This is only needed for server-initiated traffic flows such as Microsoft SCCM, Active Directory (AD) updates, and DevOps workflows that require server-initiated connections.</li>
</ul>
