<h2 id="what-is-1-1-1-1">What is 1.1.1.1?</h2>
<p>1.1.1.1 is Cloudflare's free, fast, and secure public DNS resolver.</p>
<p>For more information, refer to the <a href="https://www.cloudflare.com/learning/dns/what-is-1.1.1.1/">Learning Center</a> and <a href="/1.1.1.1/">1.1.1.1 documentation</a>.</p>
<h2 id="what-is-a-secure-web-gateway-swg">What is a secure web gateway (SWG)?</h2>
<p>A secure web gateway (SWG) is a cyber security product that protects company data and enforces security policies.</p>
<div class="nb-glossary-definition"><p>Cloudflare Gateway is a modern next-generation firewall between your user, device, or network and the public Internet. It includes DNS filtering to inspect and apply policies to all Internet-bound DNS queries.</p></div>
<p>For more information, refer to the <a href="https://www.cloudflare.com/learning/access-management/what-is-a-secure-web-gateway/">Learning Center</a> and <a href="/cloudflare-one/traffic-policies/">Gateway documentation</a>.</p>
<h2 id="what-is-https-inspection">What is HTTPS inspection?</h2>
<p>HTTPS inspection (also known as TLS decryption) is the process of filtering traffic by decrypting traffic sent to or from your organization, inspecting it and applying policies, then re-encrypting the traffic as it ingresses or egresses.</p>
<p>For more information, refer to the <a href="https://www.cloudflare.com/learning/security/what-is-https-inspection/">Learning Center</a> and <a href="/cloudflare-one/traffic-policies/http-policies/tls-decryption/">TLS decryption documentation</a>.</p>
<h2 id="what-is-data-loss-prevention-dlp">What is data loss prevention (DLP)?</h2>
<p>Data loss prevention checks for sensitive data sent in uploads and downloads.</p>
<div class="nb-glossary-definition"><p>Cloudflare <a href="https://www.cloudflare.com/learning/access-management/what-is-dlp/">Data Loss Prevention</a> (DLP) allows you to scan your web traffic and SaaS applications for the presence of sensitive data such as social security numbers, financial information, secret keys, and source code.</p></div>
<p>For more information, refer to the <a href="https://www.cloudflare.com/learning/access-management/what-is-dlp/">Learning Center</a> and <a href="/cloudflare-one/data-loss-prevention/">DLP documentation</a>.</p>
<h2 id="what-is-a-cloud-access-security-broker-casb">What is a cloud access security broker (CASB)?</h2>
<p>A cloud access security broker protects cloud services from security threats.</p>
<div class="nb-glossary-definition"><p>Cloudflare CASB provides comprehensive visibility and control over SaaS apps to prevent data leaks and compliance violations. It helps detect insider threats, shadow IT, risky data sharing, and bad actors.</p></div>
<p>For more information, refer to the <a href="https://www.cloudflare.com/learning/access-management/what-is-a-casb/">Learning Center</a> and <a href="/cloudflare-one/integrations/cloud-and-saas/">CASB documentation</a>.</p>
<h2 id="what-is-browser-isolation">What is browser isolation?</h2>
<p>Browser isolation prevents users from interacting directly with malicious websites by rendering pages in an isolated browser offsite.</p>
<div class="nb-glossary-definition"><p>Cloudflare Browser Isolation seamlessly executes active webpage content in a secure isolated browser to protect users from zero-day attacks, malware, and phishing.</p></div>
<p>For more information, refer to the <a href="https://www.cloudflare.com/learning/access-management/what-is-a-casb/">Learning Center</a> and <a href="/cloudflare-one/remote-browser-isolation/">Browser Isolation documentation</a>.</p>
