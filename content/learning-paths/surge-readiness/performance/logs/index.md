<h2 id="logpush">Logpush</h2>
<p>Use <a href="/logs/logpush/">Logpush</a> to push your request or event logs to your cloud service provider using Logpush, which can be configured via the Cloudflare dashboard or API.</p>
<h2 id="instant-logs">Instant Logs</h2>
<p>Use <a href="/logs/instant-logs/">Instant Logs</a> to view HTTP request logs instantly in the Cloudflare dashboard or the CLI.</p>
<h2 id="logs-engine">Logs Engine</h2>
<p>Use the <a href="/logs/r2-log-retrieval/">Logs Engine</a> to store your logs in R2 and query them directly.</p>
<h2 id="log-explorer">Log Explorer</h2>
<p>Use the <a href="/log-explorer/">Log Explorer</a> to store and explore your Cloudflare logs directly within the Cloudflare dashboard or API.</p>
