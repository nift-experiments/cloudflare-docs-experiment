<h2 id="orange-cloud-all-proper-subdomains">Orange cloud all proper subdomains</h2>
<p>When a subdomain is set to Proxied (also known as orange-clouded), Cloudflare proxying is active for that record and the record will resolve to a Cloudflare IP.</p>
<p>Refer to <a href="/dns/proxy-status/">Proxy status</a> for more information.</p>
