<p>Configuration and Log searches are also available via a public API.</p>
<h2 id="authentication">Authentication</h2>
<p>Authentication with the API can be done via an API token or API key with an email. Refer to <a href="/fundamentals/api/get-started/create-token/">Create API token</a> for further instructions.</p>
<p>For detailed information on permissions required for each Log Explorer feature, refer to the <a href="/log-explorer/#permissions">Permissions</a> section.</p>
<h2 id="query-data">Query data</h2>
<p>Log Explorer includes a SQL API for submitting queries.</p>
<p>For example, to find an HTTP request with a specific <a href="/fundamentals/reference/cloudflare-ray-id/">Ray ID</a>, use the following SQL query:</p>
<pre><code class="language-bash">curl https://api.cloudflare.com/client/v4/zones/{zone_id}/logs/explorer/query/sql \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \&#10;&#45;-url-query query=&quot;SELECT clientRequestScheme, clientRequestHost, clientRequestMethod, edgeResponseStatus, clientRequestUserAgent FROM http_requests WHERE RayID = &#x27;806c30a3cec56817&#x27; LIMIT 1&quot;&#10;</code></pre>
<p>This command returns the following HTTP request details:</p>
<pre><code class="language-json">{&#10;	&quot;result&quot;: [&#10;		{&#10;			&quot;clientrequestscheme&quot;: &quot;https&quot;,&#10;			&quot;clientrequesthost&quot;: &quot;example.com&quot;,&#10;			&quot;clientrequestmethod&quot;: &quot;GET&quot;,&#10;			&quot;clientrequestuseragent&quot;: &quot;curl/7.88.1&quot;,&#10;			&quot;edgeresponsestatus&quot;: 200&#10;		}&#10;	],&#10;	&quot;success&quot;: true,&#10;	&quot;errors&quot;: [],&#10;	&quot;messages&quot;: []&#10;}&#10;</code></pre>
<p>As another example, you could find Cloudflare Access requests with selected columns from a specific timeframe by performing the following SQL query:</p>
<pre><code class="language-bash">curl https://api.cloudflare.com/client/v4/accounts/{account_id}/logs/explorer/query/sql \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \&#10;&#45;-url-query query=&quot;SELECT CreatedAt, AppDomain, AppUUID, Action, Allowed, Country, RayID, Email, IPAddress, UserUID FROM access_requests WHERE Date &gt;= &#x27;2025-02-06&#x27; AND Date &lt;= &#x27;2025-02-06&#x27; AND CreatedAt &gt;= &#x27;2025-02-06T12:28:39Z&#x27; AND CreatedAt &lt;= &#x27;2025-02-06T12:58:39Z&#x27;&quot;&#10;</code></pre>
<p>This command returns the following request details:</p>
<pre><code class="language-json">{&#10;	&quot;result&quot;: [&#10;		{&#10;			&quot;createdat&quot;: &quot;2025-01-14T18:17:55Z&quot;,&#10;			&quot;appdomain&quot;: &quot;example.com&quot;,&#10;			&quot;appuuid&quot;: &quot;a66b4ab0-ccdf-4d60-a6d0-54a59a827d92&quot;,&#10;			&quot;action&quot;: &quot;login&quot;,&#10;			&quot;allowed&quot;: true,&#10;			&quot;country&quot;: &quot;us&quot;,&#10;			&quot;rayid&quot;: &quot;90fbb07c0b316957&quot;,&#10;			&quot;email&quot;: &quot;user@example.com&quot;,&#10;			&quot;ipaddress&quot;: &quot;1.2.3.4&quot;,&#10;			&quot;useruid&quot;: &quot;52859e81-711e-4de0-8b31-283336060e79&quot;&#10;		}&#10;	],&#10;	&quot;success&quot;: true,&#10;	&quot;errors&quot;: [],&#10;	&quot;messages&quot;: []&#10;}&#10;</code></pre>
