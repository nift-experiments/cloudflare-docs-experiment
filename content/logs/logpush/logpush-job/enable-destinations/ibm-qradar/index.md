<p>To configure a QRadar/Cloudflare integration you have the option to use one of the following methods:</p>
<ul>
<li><a href="/logs/logpush/logpush-job/enable-destinations/ibm-qradar/#http-receiver-protocol">HTTP Receiver protocol</a></li>
<li><a href="/logs/logpush/logpush-job/enable-destinations/ibm-qradar/#amazon-aws-s3-rest-api">Amazon AWS S3 Rest API</a></li>
</ul>
<h2 id="http-receiver-protocol">HTTP Receiver Protocol</h2>
<p>To send Cloudflare logs to QRadar you need to create a <a href="/logs/logpush/logpush-job/enable-destinations/http/">Logpush job to HTTP endpoints</a> via API. Below you can find two curl examples of how to send Cloudflare Firewall events and Cloudflare HTTP events to QRadar.</p>

<pre class="nb-api-request"><code class="language-bash">curl --request POST \&#10;  --url https://api.cloudflare.com/client/v4/zones/{zone_id}/logpush/jobs \&#10;  --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \&#10;  --data &#x27;{&#10;  &quot;name&quot;: &quot;&lt;NAME&gt;&quot;,&#10;  &quot;output_options&quot;: {&#10;    &quot;field_names&quot;: [&#10;      &quot;Action&quot;,&#10;      &quot;ClientIP&quot;,&#10;      &quot;ClientASN&quot;,&#10;      &quot;ClientASNDescription&quot;,&#10;      &quot;ClientCountry&quot;,&#10;      &quot;ClientIPClass&quot;,&#10;      &quot;ClientRefererHost&quot;,&#10;      &quot;ClientRefererPath&quot;,&#10;      &quot;ClientRefererQuery&quot;,&#10;      &quot;ClientRefererScheme&quot;,&#10;      &quot;ClientRequestHost&quot;,&#10;      &quot;ClientRequestMethod&quot;,&#10;      &quot;ClientRequestPath&quot;,&#10;      &quot;ClientRequestProtocol&quot;,&#10;      &quot;ClientRequestQuery&quot;,&#10;      &quot;ClientRequestScheme&quot;,&#10;      &quot;ClientRequestUserAgent&quot;,&#10;      &quot;EdgeColoCode&quot;,&#10;      &quot;EdgeResponseStatus&quot;,&#10;      &quot;Kind&quot;,&#10;      &quot;MatchIndex&quot;,&#10;      &quot;Metadata&quot;,&#10;      &quot;OriginResponseStatus&quot;,&#10;      &quot;OriginatorRayID&quot;,&#10;      &quot;RayID&quot;,&#10;      &quot;RuleID&quot;,&#10;      &quot;Source&quot;,&#10;      &quot;Datetime&quot;&#10;    ],&#10;    &quot;timestamp_format&quot;: &quot;rfc3339&quot;&#10;  },&#10;  &quot;destination_conf&quot;: &quot;&lt;QRADAR_URL&gt;:&lt;LOG_SOURCE_PORT&gt;&quot;,&#10;  &quot;max_upload_bytes&quot;: 5000000,&#10;  &quot;max_upload_records&quot;: 1000,&#10;  &quot;dataset&quot;: &quot;firewall_events&quot;,&#10;  &quot;enabled&quot;: true&#10;}&#x27;</code></pre>

<p>Cloudflare checks the accessibility of the IP address, port, and validates the certificate of the HTTP Receive log source. If all parameters are valid, a Logpush is created, and starts to send events to HTTP Receiver log source.</p>
<h2 id="amazon-aws-s3-rest-api">Amazon AWS S3 Rest API</h2>
<p>When you use the Amazon S3 REST API protocol, IBM QRadar collects Cloudflare Log events from an Amazon S3 bucket. To use this option, you need to:</p>
<ol>
<li>Create an <a href="https://docs.aws.amazon.com/AmazonS3/latest/userguide/creating-bucket.html">Amazon S3 bucket</a> to store your Cloudflare Logs. Make a note of the bucket name and the AWS access key ID and secret access key with sufficient permissions to write to the bucket.</li>
<li><a href="/logs/logpush/logpush-job/enable-destinations/aws-s3/">Enable a Logpush to Amazon S3</a>.</li>
<li>In the AWS Management Console, go to the Amazon S3 service. Create a bucket endpoint to allow Cloudflare to send logs directly to the S3 bucket.</li>
<li>Follow the steps in <a href="https://www.ibm.com/docs/en/dsm?topic=configuration-cloudflare-logs">Integrate Cloudflare Logs with QRadar by using the Amazon AWS S3 REST API protocol</a>.</li>
<li>Test the configuration by generating some logs in Cloudflare and ensuring that they are delivered to the S3 bucket and subsequently forwarded to QRadar.</li>
</ol>
