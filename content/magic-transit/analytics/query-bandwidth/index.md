<p>This example uses the GraphQL Analytics API to query Magic Transit ingress tunnel traffic over a specified time period.</p>
<p>The following API call requests Magic Transit ingress tunnel traffic over a one-hour period and outputs the requested fields. Replace <code>&lt;CLOUDFLARE_ACCOUNT_TAG&gt;</code> with your account ID, <code>&lt;EMAIL&gt;</code>, <code>&lt;API_KEY&gt;</code><sup><a href="#footnote-networking-services-graphql-query-magic-transit-bandwidth-graphql-mdx-1">1</a></sup> (legacy), or <code>&lt;API_TOKEN&gt;</code><sup><a href="#footnote-networking-services-graphql-query-magic-transit-bandwidth-graphql-mdx-2">2</a></sup> (preferred) with your API credentials, and adjust the <code>datetime_geq</code> and <code>datetime_leq</code> values as needed.</p>
<p>The example queries for ingress traffic. To query for egress traffic, change the value in the <code>direction</code> filter.</p>
<h2 id="api-call">API Call</h2>
<pre tabindex="0"><code class="language-bash">PAYLOAD=&#x27;{ &quot;query&quot;:&#10;  &quot;query GetTunnelHealthCheckResults($accountTag: string, $datetimeStart: string, $datetimeEnd: string) {&#10;      viewer {&#10;        accounts(filter: {accountTag: $accountTag}) {&#10;          magicTransitTunnelTrafficAdaptiveGroups(&#10;            limit: 100,&#10;            filter: {&#10;              datetime_geq: $datetimeStart,&#10;              datetime_lt:  $datetimeEnd,&#10;              direction: $direction&#10;            }&#10;          ) {&#10;            avg {&#10;              bitRateFiveMinutes&#10;            }&#10;            dimensions {&#10;              tunnelName&#10;              datetimeFiveMinutes&#10;            }&#10;          }&#10;        }&#10;      }&#10;  }&quot;,&#10;    &quot;variables&quot;: {&#10;      &quot;accountTag&quot;: &quot;&lt;CLOUDFLARE_ACCOUNT_TAG&gt;&quot;,&#10;      &quot;direction&quot;: &quot;ingress&quot;,&#10;      &quot;datetimeStart&quot;: &quot;2022-05-04T11:00:00.000Z&quot;,&#10;      &quot;datetimeEnd&quot;: &quot;2022-05-04T12:00:00.000Z&quot;&#10;    }&#10;  }&#10;}&#x27;&#10;&#10;&#35; curl with Legacy API Key&#10;curl https://api.cloudflare.com/client/v4/graphql \&#10;&#45;-header &quot;X-Auth-Email: &lt;EMAIL&gt;&quot; \&#10;&#45;-header &quot;X-Auth-Key: &lt;API_KEY&gt;&quot; \&#10;&#45;-header &quot;Accept: application/json&quot; \&#10;&#45;-header &quot;Content-Type: application/json&quot; \&#10;&#45;-data &quot;$(echo $PAYLOAD)&quot;&#10;&#10;&#35; curl with API Token&#10;curl https://api.cloudflare.com/client/v4/graphql \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \&#10;&#45;-header &quot;Accept: application/json&quot; \&#10;&#45;-header &quot;Content-Type: application/json&quot; \&#10;&#45;-data &quot;$(echo $PAYLOAD)&quot;&#10;</code></pre>
<p>The returned values represent the total bandwidth in bits per second during the five-minute interval for a particular tunnel. To use aggregations other than five minutes, use the same time window for both your metric and datetime. For example, to analyze hourly groups, use <code>bitRateHour</code> and <code>datetimeHour</code>.</p>
<p>The result is in JSON (as requested), so piping the output to <code>jq</code> formats it for easier parsing, as in the following example:</p>
<pre tabindex="0"><code class="language-bash">curl https://api.cloudflare.com/client/v4/graphql \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot; \&#10;&#45;-header &quot;Accept: application/json&quot; \&#10;&#45;-header &quot;Content-Type: application/json&quot; \&#10;&#45;-data &quot;$(echo $PAYLOAD)&quot; | jq .&#10;&#10;&#35;# Example response:&#10;&#35;=&gt; {&#10;&#35;=&gt;   &quot;data&quot;: {&#10;&#35;=&gt;     &quot;viewer&quot;: {&#10;&#35;=&gt;       &quot;accounts&quot;: [&#10;&#35;=&gt;         {&#10;&#35;=&gt;           &quot;magicTransitTunnelTrafficAdaptiveGroups&quot;: [&#10;&#35;=&gt;             {&#10;&#35;=&gt;               avg: { bitRateFiveMinutes:  327680 },&#10;&#35;=&gt;               dimensions: {&#10;&#35;=&gt;                 datetimeFiveMinute: &#x27;2021-05-12T22:00-00:00&#x27;,&#10;&#35;=&gt;                 tunnelName: &#x27;tunnel_name&#x27;&#10;&#35;=&gt;               }&#10;&#35;=&gt;             },&#10;&#35;=&gt;             {&#10;&#35;=&gt;               avg: { bitRateFiveMinutes:  627213680 },&#10;&#35;=&gt;               dimensions: {&#10;&#35;=&gt;                 datetimeFiveMinute: &#x27;2021-05-12T22:05-00:00&#x27;,&#10;&#35;=&gt;                 tunnelName: &#x27;another_tunnel&#x27;&#10;&#35;=&gt;              }&#10;&#35;=&gt;             }&#10;&#35;=&gt;           ]&#10;&#35;=&gt;         }&#10;&#35;=&gt;       ]&#10;&#35;=&gt;     }&#10;&#35;=&gt;   },&#10;&#35;=&gt;   &quot;errors&quot;: null&#10;&#35;=&gt; }&#10;</code></pre>
