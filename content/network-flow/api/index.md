<p>Use Network Flow's (formerly Magic Network Monitoring) API to configure your account and rules.</p>
<h2 id="account-configuration">Account configuration</h2>
<p>Refer to <a href="/api/resources/magic_network_monitoring/subresources/configs/methods/get/">Account configuration API methods</a> to:</p>
<ul>
<li>Create, list, update, and delete Network Flow configurations</li>
<li>List default sampling, router IPs, and rules for an account</li>
</ul>
<h2 id="rules-configuration">Rules configuration</h2>
<p>Refer to <a href="/api/resources/magic_network_monitoring/subresources/rules/methods/list/">Rules configuration API methods</a> to:</p>
<ul>
<li>Create, list, update, and delete rules</li>
<li>Update advertisement for a rule</li>
</ul>
