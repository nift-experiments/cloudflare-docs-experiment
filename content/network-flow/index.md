<p>Understanding what is happening on your network is essential for troubleshooting performance issues, detecting threats, and planning capacity. Network Flow (formerly Magic Network Monitoring) gives you this visibility by analyzing network <span class="nb-glossary-tooltip" title="flow data">flow data</span> that your routers or cloud environment send. The service supports NetFlow v5, NetFlow v9, IPFIX, and sFlow. In cloud environments, it supports AWS VPC flow logs through AWS Firehose.</p>
<p>Network Flow is available to all users with a Cloudflare account. You can log in to your Cloudflare dashboard, select your account, then go to the <a href="https://dash.cloudflare.com/?to=/:account/networking-insights/analytics/network-analytics/flow-analytics">Network flow</a> page to get started.</p>
<p>All users can use the <a href="/network-flow/network-flow-free/">free version</a> in a home network, network lab, or business to get end-to-end visibility across their network traffic. Potential enterprise customers are encouraged to use the free version to run a proof of concept.</p>
<p>Enterprise customers can use Network Flow with <a href="/magic-transit/on-demand/">Magic Transit on-demand</a> to monitor their network, identify volumetric DDoS attacks, and activate Magic Transit on-demand to mitigate those attacks.</p>
<p>Refer to <a href="/network-flow/get-started/">Get started</a>.</p>
