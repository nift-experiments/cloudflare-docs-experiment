<p>The free version of Network Flow (formerly Magic Network Monitoring) is available to all Cloudflare accounts.</p>
<p>Join <a href="https://discord.com/invite/cloudflaredev">Cloudflare's Discord server</a> to discuss Network Flow use cases, configuration, and troubleshooting. The Network Flow product and engineering team regularly engages with the community.</p>
<p>In the Discord server, find the <strong>magic-network-monitoring</strong> channel under the <strong>Cloudflare One</strong> category.</p>
<h2 id="access-the-free-version-of-network-flow">Access the free version of Network Flow</h2>
<p>The free version includes all features of the enterprise version, with network flow volume and configuration limits.</p>
<ol>
<li>Go to the <strong>Network flow</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>Complete the onboarding wizard to configure Network Flow. Refer to <a href="/network-flow/get-started/">Get started</a> for detailed configuration instructions.</li>
</ol>
