<p>The <a href="/api/resources/pages/subresources/projects/methods/list/">Pages API</a> empowers you to build automations and integrate Pages with your development workflow. At a high level, the API endpoints let you manage deployments and builds and configure projects. Cloudflare supports <a href="/pages/configuration/deploy-hooks/">Deploy Hooks</a> for headless CMS deployments. Refer to the <a href="https://api.cloudflare.com/">API documentation</a> for a full breakdown of object types and endpoints.</p>
<h2 id="how-to-use-the-api">How to use the API</h2>
<h3 id="get-an-api-token">Get an API token</h3>
<p>To create an API token:</p>
<ol>
<li>In the Cloudflare dashboard, go to the <strong>Account API tokens</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
2. Select **Create Token**.
3. You can go to **Edit Cloudflare Workers** template > **Use template** or go to **Create Custom Token** > **Get started**. If you create a custom token, you will need to make sure to add the **Cloudflare Pages** permission with **Edit** access.
<h3 id="make-requests">Make requests</h3>
<p>After creating your token, you can authenticate and make requests to the API using your API token in the request headers. For example, here is an API request to get all deployments in a project.</p>
<pre class="nb-api-request"><code class="language-bash">curl --request GET \&#10;  --url https://api.cloudflare.com/client/v4/accounts/{account_id}/pages/projects/{project_name}/deployments \&#10;  --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;</code></pre>
<p>Try it with one of your projects by replacing <code>{account_id}</code>, <code>{project_name}</code>, and <code>&lt;API_TOKEN&gt;</code>. Refer to <a href="/fundamentals/account/find-account-and-zone-ids/">Find your account ID</a> for more information.</p>
<h2 id="examples">Examples</h2>
<p>The API is even more powerful when combined with Cloudflare Workers: the easiest way to deploy serverless functions on Cloudflare's global network. The following section includes three code examples on how to use the Pages API. To build and deploy these samples, refer to the <a href="/workers/get-started/guide/">Get started guide</a>.</p>
<h3 id="triggering-a-new-build-every-hour">Triggering a new build every hour</h3>
<p>Suppose we have a CMS that pulls data from live sources to compile a static output. You can keep the static content as recent as possible by triggering new builds periodically using the API.</p>
<pre><code class="language-js">const endpoint =&#10;	&quot;https://api.cloudflare.com/client/v4/accounts/{account_id}/pages/projects/{project_name}/deployments&quot;;&#10;&#10;export default {&#10;	async scheduled(_, env) {&#10;		const init = {&#10;			method: &quot;POST&quot;,&#10;			headers: {&#10;				&quot;Content-Type&quot;: &quot;application/json;charset=UTF-8&quot;,&#10;				// We recommend you store the API token as a secret using the Workers dashboard or using Wrangler as documented here: https://developers.cloudflare.com/workers/wrangler/commands/general/#secret&#10;				Authorization: `Bearer ${env.API_TOKEN}`,&#10;			},&#10;		};&#10;&#10;		await fetch(endpoint, init);&#10;	},&#10;};&#10;</code></pre>
<p>After you have deployed the JavaScript Worker, set a cron trigger in your Worker to run this script periodically. Refer to <a href="/workers/configuration/cron-triggers/">Cron Triggers</a> for more details.</p>
<h3 id="deleting-old-deployments-after-a-week">Deleting old deployments after a week</h3>
<p>Cloudflare Pages hosts and serves all project deployments on preview links. Suppose you want to keep your project private and prevent access to your old deployments. You can use the API to delete deployments after a month, so that they are no longer public online. The latest deployment for a branch cannot be deleted.</p>

</aside>
<pre><code class="language-js">const endpoint =&#10;	&quot;https://api.cloudflare.com/client/v4/accounts/{account_id}/pages/projects/{project_name}/deployments&quot;;&#10;const expirationDays = 7;&#10;&#10;export default {&#10;	async scheduled(_, env) {&#10;		const init = {&#10;			headers: {&#10;				&quot;Content-Type&quot;: &quot;application/json;charset=UTF-8&quot;,&#10;				// We recommend you store the API token as a secret using the Workers dashboard or using Wrangler as documented here: https://developers.cloudflare.com/workers/wrangler/commands/general/#secret&#10;				Authorization: `Bearer ${env.API_TOKEN}`,&#10;			},&#10;		};&#10;&#10;		const response = await fetch(endpoint, init);&#10;		const deployments = await response.json();&#10;&#10;		for (const deployment of deployments.result) {&#10;			// Check if the deployment was created within the last x days (as defined by `expirationDays` above)&#10;			if (&#10;				(Date.now() - new Date(deployment.created_on)) / 86400000 &gt;&#10;				expirationDays&#10;			) {&#10;				// Delete the deployment&#10;				await fetch(`${endpoint}/${deployment.id}`, {&#10;					method: &quot;DELETE&quot;,&#10;					headers: {&#10;						&quot;Content-Type&quot;: &quot;application/json;charset=UTF-8&quot;,&#10;						Authorization: `Bearer ${env.API_TOKEN}`,&#10;					},&#10;				});&#10;			}&#10;		}&#10;	},&#10;};&#10;</code></pre>
<p>After you have deployed the JavaScript Worker, you can set a cron trigger in your Worker to run this script periodically. Refer to the <a href="/workers/configuration/cron-triggers/">Cron Triggers guide</a> for more details.</p>
<h3 id="sharing-project-information">Sharing project information</h3>
<p>Imagine you are working on a development team using Pages to build your websites. You would want an easy way to share deployment preview links and build status without having to share Cloudflare accounts. Using the API, you can easily share project information, including deployment status and preview links, and serve this content as HTML from a Cloudflare Worker.</p>

font-family: sans-serif; } h1 { color: #f6821f }`;&#10;		let content = &quot;&lt;h2&gt;Project&lt;/h2&gt;&quot;;&#10;&#10;		let response = await fetch(projectEndpoint, init);&#10;		const projectResponse = await response.json();&#10;		content += `&lt;p&gt;Project Name: ${projectResponse.result.name}&lt;/p&gt;`;&#10;		content += `&lt;p&gt;Project ID: ${projectResponse.result.id}&lt;/p&gt;`;&#10;		content += `&lt;p&gt;Pages Subdomain: ${projectResponse.result.subdomain}&lt;/p&gt;`;&#10;		content += `&lt;p&gt;Domains: ${projectResponse.result.domains}&lt;/p&gt;`;&#10;		content += `&lt;a href=&quot;${projectResponse.result.canonical_deployment.url}&quot;&gt;&lt;p&gt;Latest preview: ${projectResponse.result.canonical_deployment.url}&lt;/p&gt;&lt;/a&gt;`;&#10;&#10;		content += `&lt;h2&gt;Deployments&lt;/h2&gt;`;&#10;		response = await fetch(deploymentsEndpoint, init);&#10;		const deploymentsResponse = await response.json();&#10;&#10;		for (const deployment of deploymentsResponse.result) {&#10;			content += `&lt;a href=&quot;${deployment.url}&quot;&gt;&lt;p&gt;Deployment: ${deployment.id}&lt;/p&gt;&lt;/a&gt;`;&#10;		}&#10;&#10;		let html = `&#10;      &lt;!DOCTYPE html&gt;&#10;      &lt;head&gt;&#10;        &lt;title&gt;Example Pages Project&lt;/title&gt;&#10;      &lt;/head&gt;&#10;      &lt;body&gt;&#10;        &lt;style&gt;${style}&lt;/style&gt;&#10;
