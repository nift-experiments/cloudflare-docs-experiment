<p><a href="https://remix.run/">Remix</a> is a framework that focused on web standard. The framework is no longer recommended for new projects by the authors and its successor React Router should be used instead.</p>
<p>To start a new React Router project please refer to the <a href="/workers/framework-guides/web-apps/react-router">React Router Workers guide</a>.</p>
<p>And if you have an existing Remix application consider migrating it to React Router as described in the <a href="https://reactrouter.com/upgrading/remix">official Remix upgrade documentation</a>.</p>
