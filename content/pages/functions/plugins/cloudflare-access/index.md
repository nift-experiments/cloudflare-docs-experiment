<p>The Cloudflare Access Pages Plugin is a middleware to validate Cloudflare Access JWT assertions. It also includes an API to lookup additional information about a given user's JWT.</p>

<h2 id="usage">Usage</h2>
<pre tabindex="0"><code class="language-typescript">import cloudflareAccessPlugin from &quot;@cloudflare/pages-plugin-cloudflare-access&quot;;&#10;&#10;export const onRequest: PagesFunction = cloudflareAccessPlugin({&#10;	domain: &quot;https://test.cloudflareaccess.com&quot;,&#10;	aud: &quot;4714c1358e65fe4b408ad6d432a5f878f08194bdb4752441fd56faefa9b2b6f2&quot;,&#10;});&#10;</code></pre>
<p>The Plugin takes an object with two properties: the <code>domain</code> of your Cloudflare Access account, and the policy <code>aud</code> (audience) to validate against. Any requests which fail validation will be returned a <code>403</code> status code.</p>
<h3 id="access-the-jwt-payload">Access the JWT payload</h3>
<p>If you need to use the JWT payload in your application (for example, you need the user's email address), this Plugin will make this available for you at <code>data.cloudflareAccess.JWT.payload</code>.</p>
<p>For example:</p>
<pre tabindex="0"><code class="language-typescript">import type { PluginData } from &quot;@cloudflare/pages-plugin-cloudflare-access&quot;;&#10;&#10;export const onRequest: PagesFunction&lt;unknown, any, PluginData&gt; = async ({&#10;	data,&#10;}) =&gt; {&#10;	return new Response(&#10;		`Hello, ${data.cloudflareAccess.JWT.payload.email || &quot;service user&quot;}!`,&#10;	);&#10;};&#10;</code></pre>
<p>The <a href="/cloudflare-one/access-controls/applications/http-apps/authorization-cookie/application-token/#payload">entire JWT payload</a> will be made available on <code>data.cloudflareAccess.JWT.payload</code>. Be aware that the fields available differ between identity authorizations (for example, a user in a browser) and non-identity authorizations (for example, a service token).</p>
<h3 id="look-up-identity">Look up identity</h3>
<p>In order to get more information about a given user's identity, use the provided <code>getIdentity</code> API function:</p>
<pre tabindex="0"><code class="language-typescript">import { getIdentity } from &quot;@cloudflare/pages-plugin-cloudflare-access/api&quot;;&#10;&#10;export const onRequest: PagesFunction = async ({ data }) =&gt; {&#10;	const identity = await getIdentity({&#10;		jwt: &quot;eyJhbGciOiJIUzI1NiIsImtpZCI6IjkzMzhhYmUxYmFmMmZlNDkyZjY0NmE3MzZmMjVhZmJmN2IwMjVlMzVjNjI3YmU0ZjYwYzQxNGQ0YzczMDY5YjgiLCJ0eXAiOiJKV1QifQ.eyJhdWQiOlsiOTdlMmFhZTEyMDEyMWY5MDJkZjhiYzk5ZmMzNDU5MTNhYjE4NmQxNzRmMzA3OWVhNzI5MjM2NzY2YjJlN2M0YSJdLCJlbWFpbCI6ImFkbWluQGV4YW1wbGUuY29tIiwiZXhwIjoxNTE5NDE4MjE0LCJpYXQiOjE1MTkzMzE4MTUsImlzcyI6Imh0dHBzOi8vdGVzdC5jbG91ZGZsYXJlYWNjZXNzLmNvbSIsIm5vbmNlIjoiMWQ4MDgzZjcwOGE0Nzk4MjI5NmYyZDk4OTZkNzBmMjA3YTI3OTM4ZjAyNjU0MGMzOTJiOTAzZTVmZGY0ZDZlOSIsInN1YiI6ImNhNjM5YmI5LTI2YWItNDJlNS1iOWJmLTNhZWEyN2IzMzFmZCJ9.05vGt-_0Mw6WEFJF3jpaqkNb88PUMplsjzlEUvCEfnQ&quot;,&#10;		domain: &quot;https://test.cloudflareaccess.com&quot;,&#10;	});&#10;&#10;	return new Response(`Hello, ${identity.name || &quot;service user&quot;}!`);&#10;};&#10;</code></pre>
<p>The <code>getIdentity</code> function takes an object with two properties: a <code>jwt</code> string, and a <code>domain</code> string. It returns a <code>Promise</code> of <a href="/cloudflare-one/access-controls/applications/http-apps/authorization-cookie/application-token/#user-identity">the object returned by the <code>/cdn-cgi/access/get-identity</code> endpoint</a>. This is particularly useful if you want to use a user's group membership for something like application permissions.</p>
<p>For convenience, this same information can be fetched for the current request's JWT with the <code>data.cloudflareAccess.JWT.getIdentity</code> function, (assuming you have already validated the request with the Plugin as above):</p>
<pre tabindex="0"><code class="language-typescript">import type { PluginData } from &quot;@cloudflare/pages-plugin-cloudflare-access&quot;;&#10;&#10;export const onRequest: PagesFunction&lt;unknown, any, PluginData&gt; = async ({&#10;	data,&#10;}) =&gt; {&#10;	const identity = await data.cloudflareAccess.JWT.getIdentity();&#10;&#10;	return new Response(`Hello, ${identity.name || &quot;service user&quot;}!`);&#10;};&#10;</code></pre>
<h3 id="login-and-logout-urls">Login and logout URLs</h3>
<p>If you want to force a login or logout, use these utility functions to generate URLs and redirect a user:</p>
<pre tabindex="0"><code class="language-typescript">import { generateLoginURL } from &quot;@cloudflare/pages-plugin-cloudflare-access/api&quot;;&#10;&#10;export const onRequest = () =&gt; {&#10;	const loginURL = generateLoginURL({&#10;		redirectURL: &quot;https://example.com/greet&quot;,&#10;		domain: &quot;https://test.cloudflareaccess.com&quot;,&#10;		aud: &quot;4714c1358e65fe4b408ad6d432a5f878f08194bdb4752441fd56faefa9b2b6f2&quot;,&#10;	});&#10;&#10;	return new Response(null, {&#10;		status: 302,&#10;		headers: { Location: loginURL },&#10;	});&#10;};&#10;</code></pre>
<pre tabindex="0"><code class="language-typescript">import { generateLogoutURL } from &quot;@cloudflare/pages-plugin-cloudflare-access/api&quot;;&#10;&#10;export const onRequest = () =&gt;&#10;	new Response(null, {&#10;		status: 302,&#10;		headers: {&#10;			Location: generateLogoutURL({&#10;				domain: &quot;https://test.cloudflareaccess.com&quot;,&#10;			}),&#10;		},&#10;	});&#10;</code></pre>
