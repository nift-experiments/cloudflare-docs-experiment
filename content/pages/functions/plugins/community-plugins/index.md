<p>The following are some of the community-maintained Pages Plugins. If you have created a Pages Plugin and would like to share it with developers, create a PR to add it to this alphabetically-ordered list using the link in the footer.</p>
<ul>
<li>
<p><a href="https://github.com/Cherry/pages-plugin-asset-negotiation">pages-plugin-asset-negotiation</a></p>
<p>Given a folder of assets in multiple formats, this Plugin will automatically negotiate with a client to serve an optimized version of a requested asset.</p>
</li>
<li>
<p><a href="https://github.com/flaregun-net/proxyflare-for-pages">proxyflare-for-pages</a></p>
<p>Move traffic around your Cloudflare Pages domain with ease. Proxyflare is a reverse-proxy that enables you to:</p>
<ul>
<li>Port forward, redirect, and reroute HTTP and websocket traffic anywhere on the Internet.</li>
<li>Mount an entire website on a subpath (for example, <code>mysite.com/docs</code>) on your apex domain.</li>
<li>Serve static text (like <code>robots.txt</code> and other structured metadata) from any endpoint.</li>
</ul>
<p>Refer to <a href="https://proxyflare.works">Proxyflare</a> for more information.</p>
</li>
<li>
<p><a href="https://github.com/hckr-studio/cloudflare-pages-plugin-rollbar">cloudflare-pages-plugin-rollbar</a></p>
<p>The <a href="https://rollbar.com/">Rollbar</a> Pages Plugin captures and logs all exceptions which occur below it in the execution chain
of your <a href="/pages/functions/">Pages Functions</a>. Discover, predict, and resolve errors in real-time.</p>
</li>
<li>
<p><a href="https://github.com/toyamarinyon/cloudflare-pages-plugin-trpc">cloudflare-pages-plugin-trpc</a></p>
<p>Allows developers to quickly create a tRPC server with a Cloudflare Pages Function.</p>
</li>
<li>
<p><a href="https://github.com/helloimalastair/twind-plugin">pages-plugin-twind</a></p>
<p>Automatically injects Tailwind CSS styles into HTML pages after analyzing which classes are used.</p>
</li>
</ul>
