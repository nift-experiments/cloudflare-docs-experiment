<p>The Google Chat Pages Plugin creates a Google Chat bot which can respond to messages. It also includes an API for interacting with Google Chat (for example, for creating messages) without the need for user input. This API is useful for situations such as alerts.</p>

<h2 id="usage">Usage</h2>
<pre><code class="language-typescript">import googleChatPlugin from &quot;@cloudflare/pages-plugin-google-chat&quot;;&#10;&#10;export const onRequest: PagesFunction = googleChatPlugin(async (message) =&gt; {&#10;	if (message.text.includes(&quot;ping&quot;)) {&#10;		return { text: &quot;pong&quot; };&#10;	}&#10;&#10;	return { text: &quot;Sorry, I could not understand your message.&quot; };&#10;});&#10;</code></pre>
<p>The Plugin takes a function, which in turn takes an incoming message, and returns a <code>Promise</code> of a response message (or <code>void</code> if there should not be any response).</p>
<p>The Plugin only exposes a single route, which is the URL you should set in the Google Cloud Console when creating the bot.</p>

<h3 id="api">API</h3>
<p>The Google Chat API can be called directly using the <code>GoogleChatAPI</code> class:</p>
<pre><code class="language-typescript">import { GoogleChatAPI } from &quot;@cloudflare/pages-plugin-google-chat/api&quot;;&#10;&#10;export const onRequest: PagesFunction = () =&gt; {&#10;	// Initialize a GoogleChatAPI with your service account&#x27;s credentials&#10;	const googleChat = new GoogleChatAPI({&#10;		credentials: {&#10;			client_email: &quot;SERVICE_ACCOUNT_EMAIL_ADDRESS&quot;,&#10;			private_key: &quot;SERVICE_ACCOUNT_PRIVATE_KEY&quot;,&#10;		},&#10;	});&#10;&#10;	// Post a message&#10;	// https://developers.google.com/chat/api/reference/rest/v1/spaces.messages/create&#10;	const message = await googleChat.createMessage(&#10;		{ parent: &quot;spaces/AAAAAAAAAAA&quot; },&#10;		undefined,&#10;		{&#10;			text: &quot;I&#x27;m an alert!&quot;,&#10;		},&#10;	);&#10;&#10;	return new Response(&quot;Alert sent.&quot;);&#10;};&#10;</code></pre>
<p>We recommend storing your service account's credentials in KV rather than in plain text as above.</p>
<p>The following functions are available on a <code>GoogleChatAPI</code> instance. Each take up to three arguments: an object of path parameters, an object of query parameters, and an object of the request body; as described in the <a href="https://developers.google.com/chat/api/reference/rest">Google Chat API's documentation</a>.</p>
