<p>The GraphQL Pages Plugin creates a GraphQL server which can respond to <code>application/json</code> and <code>application/graphql</code> <code>POST</code> requests. It responds with <a href="https://github.com/graphql/graphql-playground">the GraphQL Playground</a> for <code>GET</code> requests.</p>

<h2 id="usage">Usage</h2>
<pre><code class="language-typescript">import graphQLPlugin from &quot;@cloudflare/pages-plugin-graphql&quot;;&#10;import {&#10;	graphql,&#10;	GraphQLSchema,&#10;	GraphQLObjectType,&#10;	GraphQLString,&#10;} from &quot;graphql&quot;;&#10;&#10;const schema = new GraphQLSchema({&#10;	query: new GraphQLObjectType({&#10;		name: &quot;RootQueryType&quot;,&#10;		fields: {&#10;			hello: {&#10;				type: GraphQLString,&#10;				resolve() {&#10;					return &quot;Hello, world!&quot;;&#10;				},&#10;			},&#10;		},&#10;	}),&#10;});&#10;&#10;export const onRequest: PagesFunction = graphQLPlugin({&#10;	schema,&#10;	graphql,&#10;});&#10;</code></pre>
<p>This Plugin only exposes a single route, so wherever it is mounted is wherever it will be available. In the above example, because it is mounted in <code>functions/graphql.ts</code>, the server will be available on <code>/graphql</code> of your Pages project.</p>
