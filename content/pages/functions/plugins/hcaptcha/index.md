<h2 id="usage">Usage</h2>
<pre><code class="language-typescript">import hCaptchaPlugin from &quot;@cloudflare/pages-plugin-hcaptcha&quot;;&#10;&#10;export const onRequestPost: PagesFunction[] = [&#10;	hCaptchaPlugin({&#10;		secret: &quot;0x0000000000000000000000000000000000000000&quot;,&#10;		sitekey: &quot;10000000-ffff-ffff-ffff-000000000001&quot;,&#10;	}),&#10;	async (context) =&gt; {&#10;		// Request has been validated as coming from a human&#10;&#10;		const formData = await context.request.formData();&#10;&#10;		// Store user credentials&#10;&#10;		return new Response(&quot;Successfully registered!&quot;);&#10;	},&#10;];&#10;</code></pre>
<p>This Plugin only exposes a single route. It will be available wherever it is mounted. In the above example, because it is mounted in <code>functions/register.ts</code>, it will validate requests to <code>/register</code>. The Plugin is mounted with a single object parameter with the following properties.</p>
<p><a href="https://dashboard.hcaptcha.com/settings"><code>secret</code></a> (mandatory) and <a href="https://dashboard.hcaptcha.com/sites"><code>sitekey</code></a> (optional) can both be found in your hCaptcha dashboard.</p>
<p><code>response</code> and <code>remoteip</code> are optional strings. <code>response</code> the hCaptcha token to verify (defaults to extracting <code>h-captcha-response</code> from a <code>multipart/form-data</code> request). <code>remoteip</code> should be requester's IP address (defaults to the <code>CF-Connecting-IP</code> header of the request).</p>
<p><code>onError</code> is an optional function which takes the Pages Function context object and returns a <code>Promise</code> of a <code>Response</code>. By default, it will return a human-readable error <code>Response</code>.</p>
<p><code>data.hCaptcha</code> will be populated in subsequent Pages Functions (including for the <code>onError</code> function) with <a href="https://docs.hcaptcha.com/#verify-the-user-response-server-side">the hCaptcha response object</a>.</p>
