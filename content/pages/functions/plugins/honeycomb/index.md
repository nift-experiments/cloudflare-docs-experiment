<h2 id="usage">Usage</h2>
<p>The following usage example uses environment variables you will need to set in your Pages project settings.</p>
<pre tabindex="0"><code class="language-typescript">import honeycombPlugin from &quot;@cloudflare/pages-plugin-honeycomb&quot;;&#10;&#10;export const onRequest: PagesFunction&lt;{&#10;	HONEYCOMB_API_KEY: string;&#10;	HONEYCOMB_DATASET: string;&#10;}&gt; = (context) =&gt; {&#10;	return honeycombPlugin({&#10;		apiKey: context.env.HONEYCOMB_API_KEY,&#10;		dataset: context.env.HONEYCOMB_DATASET,&#10;	})(context);&#10;};&#10;</code></pre>
<p>Alternatively, you can hard-code (not advisable for API key) your settings the following way:</p>
<pre tabindex="0"><code class="language-typescript">import honeycombPlugin from &quot;@cloudflare/pages-plugin-honeycomb&quot;;&#10;&#10;export const onRequest = honeycombPlugin({&#10;	apiKey: &quot;YOUR_HONEYCOMB_API_KEY&quot;,&#10;	dataset: &quot;YOUR_HONEYCOMB_DATASET_NAME&quot;,&#10;});&#10;</code></pre>
<p>This Plugin is based on the <code>@cloudflare/workers-honeycomb-logger</code> and accepts the same <a href="https://github.com/cloudflare/workers-honeycomb-logger#config">configuration options</a>.</p>
<p>Ensure that you enable the option to <strong>Automatically unpack nested JSON</strong> and set the <strong>Maximum unpacking depth</strong> to <strong>5</strong> in your Honeycomb dataset settings.</p>
<p><img src="/assets/upstream/images/pages/platform/functions/honeycomb.png" alt="Follow the instructions above to toggle on Automatically unpack nested JSON and set the Maximum unpacking depth option to 5 in the Honeycomb dashboard" /></p>
<h3 id="additional-context">Additional context</h3>
<p><code>data.honeycomb.tracer</code> has two methods for attaching additional information about a given trace:</p>
<ul>
<li><code>data.honeycomb.tracer.log</code> which takes a single argument, a <code>String</code>.</li>
<li><code>data.honeycomb.tracer.addData</code> which takes a single argument, an object of arbitrary data.</li>
</ul>
<p>More information about these methods can be seen on <a href="https://github.com/cloudflare/workers-honeycomb-logger#adding-logs-and-other-data"><code>@cloudflare/workers-honeycomb-logger</code>'s documentation</a>.</p>
<p>For example, if you wanted to use the <code>addData</code> method to attach user information:</p>
<pre tabindex="0"><code class="language-typescript">import type { PluginData } from &quot;@cloudflare/pages-plugin-honeycomb&quot;;&#10;&#10;export const onRequest: PagesFunction&lt;unknown, any, PluginData&gt; = async ({&#10;	data,&#10;	next,&#10;	request,&#10;}) =&gt; {&#10;	// Authenticate the user from the request and extract user&#x27;s email address&#10;	const email = await getEmailFromRequest(request);&#10;&#10;	data.honeycomb.tracer.addData({ email });&#10;&#10;	return next();&#10;};&#10;</code></pre>
