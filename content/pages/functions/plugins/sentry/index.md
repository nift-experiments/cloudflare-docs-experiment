<p>The Sentry Pages Plugin captures and logs all exceptions which occur below it in the execution chain of your Pages Functions. It is therefore recommended that you install this Plugin at the root of your application in <code>functions/_middleware.ts</code> as the very first Plugin.</p>

<h2 id="usage">Usage</h2>
<pre tabindex="0"><code class="language-typescript">import sentryPlugin from &quot;@cloudflare/pages-plugin-sentry&quot;;&#10;&#10;export const onRequest: PagesFunction = sentryPlugin({&#10;	dsn: &quot;https://sentry.io/welcome/xyz&quot;,&#10;});&#10;</code></pre>
<p>The Plugin uses <a href="https://github.com/robertcepa/toucan-js">Toucan</a>. Refer to the Toucan README to <a href="https://github.com/robertcepa/toucan-js#other-options">review the options it can take</a>. <code>context</code>, <code>request</code>, and <code>event</code> are automatically populated and should not be manually configured.</p>
<p>If your <a href="https://docs.sentry.io/product/sentry-basics/dsn-explainer/">DSN</a> is held as an environment variable or in KV, you can access it like so:</p>
<pre tabindex="0"><code class="language-typescript">import sentryPlugin from &quot;@cloudflare/pages-plugin-sentry&quot;;&#10;&#10;export const onRequest: PagesFunction&lt;{&#10;	SENTRY_DSN: string;&#10;}&gt; = (context) =&gt; {&#10;	return sentryPlugin({ dsn: context.env.SENTRY_DSN })(context);&#10;};&#10;</code></pre>
<pre tabindex="0"><code class="language-typescript">import sentryPlugin from &quot;@cloudflare/pages-plugin-sentry&quot;;&#10;&#10;export const onRequest: PagesFunction&lt;{&#10;	KV: KVNamespace;&#10;}&gt; = async (context) =&gt; {&#10;	return sentryPlugin({ dsn: await context.env.KV.get(&quot;SENTRY_DSN&quot;) })(context);&#10;};&#10;</code></pre>
<h3 id="additional-context">Additional context</h3>
<p>If you need to set additional context for Sentry (for example, user information or additional logs), use the <code>data.sentry</code> instance in any Function below the Plugin in the execution chain.</p>
<p>For example, you can access <code>data.sentry</code> and set user information like so:</p>
<pre tabindex="0"><code class="language-typescript">import type { PluginData } from &quot;@cloudflare/pages-plugin-sentry&quot;;&#10;&#10;export const onRequest: PagesFunction&lt;unknown, any, PluginData&gt; = async ({&#10;	data,&#10;	next,&#10;}) =&gt; {&#10;	// Authenticate the user from the request and extract user&#x27;s email address&#10;	const email = await getEmailFromRequest(request);&#10;&#10;	data.sentry.setUser({ email });&#10;&#10;	return next();&#10;};&#10;</code></pre>
<p>Again, the full list of features can be found in <a href="https://github.com/robertcepa/toucan-js#features">Toucan's documentation</a>.</p>
