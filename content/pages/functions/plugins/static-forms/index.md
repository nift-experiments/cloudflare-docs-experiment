<p>The Static Forms Pages Plugin intercepts all form submissions made which have the <code>data-static-form-name</code> attribute set. This allows you to take action on these form submissions by, for example, saving the submission to KV.</p>

<h2 id="usage">Usage</h2>
<pre><code class="language-typescript">import staticFormsPlugin from &quot;@cloudflare/pages-plugin-static-forms&quot;;&#10;&#10;export const onRequest: PagesFunction = staticFormsPlugin({&#10;	respondWith: ({ formData, name }) =&gt; {&#10;		const email = formData.get(&quot;email&quot;);&#10;		return new Response(&#10;			`Hello, ${email}! Thank you for submitting the ${name} form.`,&#10;		);&#10;	},&#10;});&#10;</code></pre>
<pre><code class="language-html">&lt;body&gt;&#10;	&lt;h1&gt;Sales enquiry&lt;/h1&gt;&#10;	&lt;form data-static-form-name=&quot;sales&quot;&gt;&#10;		&lt;label&gt;Email address &lt;input type=&quot;email&quot; name=&quot;email&quot; /&gt;&lt;/label&gt;&#10;		&lt;label&gt;Message &lt;textarea name=&quot;message&quot;&gt;&lt;/textarea&gt;&lt;/label&gt;&#10;		&lt;button type=&quot;submit&quot;&gt;Submit&lt;/button&gt;&#10;	&lt;/form&gt;&#10;&lt;/body&gt;&#10;</code></pre>
<p>The Plugin takes a single argument, an object with a <code>respondWith</code> property. This function takes an object with a <code>formData</code> property (the <a href="https://developer.mozilla.org/en-US/docs/Web/API/FormData"><code>FormData</code></a> instance) and <code>name</code> property (the name value of your <code>data-static-form-name</code> attribute). It should return a <code>Response</code> or <code>Promise</code> of a <code>Response</code>. It is in this <code>respondWith</code> function that you can take action such as serializing the <code>formData</code> and saving it to a KV namespace.</p>
<p>The <code>method</code> and <code>action</code> attributes of the HTML form do not need to be set. The Plugin will automatically override them to allow it to intercept the submission.</p>
