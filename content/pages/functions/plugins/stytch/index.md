<h2 id="usage">Usage</h2>
<pre tabindex="0"><code class="language-typescript">import stytchPlugin from &quot;@cloudflare/pages-plugin-stytch&quot;;&#10;import { envs } from &quot;@cloudflare/pages-plugin-stytch/api&quot;;&#10;&#10;export const onRequest: PagesFunction = stytchPlugin({&#10;	project_id: &quot;YOUR_STYTCH_PROJECT_ID&quot;,&#10;	secret: &quot;YOUR_STYTCH_PROJECT_SECRET&quot;,&#10;	env: envs.live,&#10;});&#10;</code></pre>
<p>We recommend storing your secret in KV rather than in plain text as above.</p>
<p>The Stytch Plugin takes a single argument, an object with several properties. <code>project_id</code> and <code>secret</code> are mandatory strings and can be found in <a href="https://stytch.com/dashboard/api-keys">Stytch's dashboard</a>. <code>env</code> is also a mandatory string, and can be populated with the <code>envs.test</code> or <code>envs.live</code> variables in the API. By default, the Plugin validates a <code>session_token</code> cookie of the incoming request, but you can also optionally pass in a <code>session_token</code> or <code>session_jwt</code> string yourself if you are using some other mechanism to identify user sessions. Finally, you can also pass in a <code>session_duration_minutes</code> in order to extend the lifetime of the session. More information on these parameters can be found in <a href="https://stytch.com/docs/api/session-auth">Stytch's documentation</a>.</p>
<p>The validated session response containing user information is made available to subsequent Pages Functions on <code>data.stytch.session</code>.</p>
