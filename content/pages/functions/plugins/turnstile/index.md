<p>This Plugin only exposes a single route to verify an incoming Turnstile response in a <code>POST</code> as the <code>cf-turnstile-response</code> parameter. It will be available wherever it is mounted. In the example above, it is mounted in <code>functions/register.ts</code>. As a result, it will validate requests to <code>/register</code>.</p>
<h2 id="properties">Properties</h2>
<p>The Plugin is mounted with a single object parameter with the following properties:</p>
<p><a href="https://dash.cloudflare.com/login"><code>secret</code></a> is mandatory and can both be found in your Turnstile dashboard.</p>
<p><code>response</code> and <code>remoteip</code> are optional strings. <code>response</code> is the Turnstile token to verify. If it is not provided, the plugin will default to extracting <code>cf-turnstile-response</code> value from a <code>multipart/form-data</code> request). <code>remoteip</code> is the requester's IP address. This defaults to the <code>CF-Connecting-IP</code> header of the request.</p>
<p><code>onError</code> is an optional function which takes the Pages Function context object and returns a <code>Promise</code> of a <code>Response</code>. By default, it will return a human-readable error <code>Response</code>.</p>
<p><code>context.data.turnstile</code> will be populated in subsequent Pages Functions (including for the <code>onError</code> function) with <a href="/turnstile/get-started/server-side-validation/">the Turnstile Siteverify response object</a>.</p>
