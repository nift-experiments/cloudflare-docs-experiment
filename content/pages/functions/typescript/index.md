<p>Pages Functions supports TypeScript. Author any files in your <code>/functions</code> directory with a <code>.ts</code> extension instead of a <code>.js</code> extension to start using TypeScript.</p>
<p>You can add runtime types and Env types by running:</p>
<div class="nb-package-managers" data-nb-pm><div role="tablist" aria-label="Package manager"><button type="button" role="tab" data-nb-pm-tab aria-selected="true" tabindex="0">npm</button><button type="button" role="tab" data-nb-pm-tab aria-selected="false" tabindex="-1">yarn</button><button type="button" role="tab" data-nb-pm-tab aria-selected="false" tabindex="-1">pnpm</button></div><div role="tabpanel" data-nb-pm-panel><pre tabindex="0"><code data-nb-pm-code>npx wrangler types --path=&#x27;./functions/types.d.ts&#x27;</code></pre><button type="button" data-nb-pm-copy data-nb-command="npx wrangler types --path=&#x27;./functions/types.d.ts&#x27;" aria-label="Copy to clipboard">Copy</button></div><div role="tabpanel" data-nb-pm-panel hidden><pre tabindex="0"><code data-nb-pm-code>yarn wrangler types --path=&#x27;./functions/types.d.ts&#x27;</code></pre><button type="button" data-nb-pm-copy data-nb-command="yarn wrangler types --path=&#x27;./functions/types.d.ts&#x27;" aria-label="Copy to clipboard">Copy</button></div><div role="tabpanel" data-nb-pm-panel hidden><pre tabindex="0"><code data-nb-pm-code>pnpm wrangler types --path=&#x27;./functions/types.d.ts&#x27;</code></pre><button type="button" data-nb-pm-copy data-nb-command="pnpm wrangler types --path=&#x27;./functions/types.d.ts&#x27;" aria-label="Copy to clipboard">Copy</button></div></div>
<p>Then configure the types by creating a <code>functions/tsconfig.json</code> file:</p>
<pre tabindex="0"><code class="language-json">{&#10;	&quot;compilerOptions&quot;: {&#10;		&quot;target&quot;: &quot;esnext&quot;,&#10;		&quot;module&quot;: &quot;esnext&quot;,&#10;		&quot;lib&quot;: [&quot;esnext&quot;],&#10;		&quot;types&quot;: [&quot;./types.d.ts&quot;]&#10;	}&#10;}&#10;</code></pre>
<p>See <a href="/workers/wrangler/commands/general/#types">the <code>wrangler types</code> command docs</a> for more details.</p>
<p>If you already have a <code>tsconfig.json</code> at the root of your project, you may wish to explicitly exclude the <code>/functions</code> directory to avoid conflicts. To exclude the <code>/functions</code> directory:</p>
<pre tabindex="0"><code class="language-json">{&#10;	&quot;include&quot;: [&quot;src/**/*&quot;],&#10;	&quot;exclude&quot;: [&quot;functions/**/*&quot;],&#10;	&quot;compilerOptions&quot;: {}&#10;}&#10;</code></pre>
<p>Pages Functions can be typed using the <code>PagesFunction</code> type. This type accepts an <code>Env</code> parameter. The <code>Env</code> type should have been generated by <code>wrangler types</code> and can be found at the top of <code>types.d.ts</code>.</p>
<p>Alternatively, you can define the <code>Env</code> type manually. For example:</p>
<pre tabindex="0"><code class="language-ts">interface Env {&#10;	KV: KVNamespace;&#10;}&#10;&#10;export const onRequest: PagesFunction&lt;Env&gt; = async (context) =&gt; {&#10;	const value = await context.env.KV.get(&quot;example&quot;);&#10;	return new Response(value);&#10;};&#10;</code></pre>
<p>If you are using <code>nodejs_compat</code>, make sure you have installed <code>@types/node</code> and updated your <code>tsconfig.json</code>.</p>
<pre tabindex="0"><code class="language-json">{&#10;	&quot;compilerOptions&quot;: {&#10;		&quot;target&quot;: &quot;esnext&quot;,&#10;		&quot;module&quot;: &quot;esnext&quot;,&#10;		&quot;lib&quot;: [&quot;esnext&quot;],&#10;		&quot;types&quot;: [&quot;./types.d.ts&quot;, &quot;node&quot;]&#10;	}&#10;}&#10;</code></pre>
