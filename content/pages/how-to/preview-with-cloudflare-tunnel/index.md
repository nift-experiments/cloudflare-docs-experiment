<p><a href="/cloudflare-one/networks/connectors/cloudflare-tunnel/">Cloudflare Tunnel</a> runs a lightweight daemon (<code>cloudflared</code>) in your infrastructure that establishes outbound connections (Tunnels) between your origin web server and the Cloudflare global network. In practical terms, you can use Cloudflare Tunnel to allow remote access to services running on your local machine. It is an alternative to popular tools like <a href="https://ngrok.com">Ngrok</a>, and provides free, long-running tunnels via the <a href="/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/">TryCloudflare</a> service.</p>
<p>While Cloudflare Pages provides unique <a href="/pages/configuration/preview-deployments/">deploy preview URLs</a> for new branches and commits on your projects, Cloudflare Tunnel can be used to provide access to locally running applications and servers during the development process. In this guide, you will install Cloudflare Tunnel, and create a new tunnel to provide access to a locally running application. You will need a Cloudflare account to begin using Cloudflare Tunnel.</p>
<h2 id="installing-cloudflare-tunnel">Installing Cloudflare Tunnel</h2>
<p>Cloudflare Tunnel can be installed on Windows, Linux, and macOS. To learn about installing Cloudflare Tunnel, refer to the <a href="/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/">Install cloudflared</a> page in the Cloudflare for Teams documentation.</p>
<p>Confirm that <code>cloudflared</code> is installed correctly by running <code>cloudflared --version</code> in your command line:</p>
<pre tabindex="0"><code class="language-sh">cloudflared --version&#10;</code></pre>
<pre tabindex="0"><code class="language-sh">cloudflared version 2021.5.9 (built 2021-05-21-1541 UTC)&#10;</code></pre>
<h2 id="run-a-local-service">Run a local service</h2>
<p>The easiest way to get up and running with Cloudflare Tunnel is to have an application running locally, such as a <a href="/pages/framework-guides/deploy-a-react-site/">React</a> or <a href="/pages/framework-guides/deploy-a-svelte-kit-site/">SvelteKit</a> site. When you are developing an application with these frameworks, they will often make use of a <code>npm run develop</code> script, or something similar, which mounts the application and runs it on a <code>localhost</code> port. For example, the popular <code>vite</code> tool runs your in-development React application on port <code>5173</code>, making it accessible at the <code>http://localhost:5173</code> address.</p>
<h2 id="start-a-cloudflare-tunnel">Start a Cloudflare Tunnel</h2>
<p>With a local development server running, a new Cloudflare Tunnel can be instantiated by running <code>cloudflared tunnel</code> in a new command line window, passing in the <code>--url</code> flag with your <code>localhost</code> URL and port. <code>cloudflared</code> will output logs to your command line, including a banner with a tunnel URL:</p>

<h2 id="next-steps">Next Steps</h2>
<p>Cloudflare Tunnel can be configured in a variety of ways and can be used beyond providing access to your in-development applications. For example, you can provide <code>cloudflared</code> with a <a href="/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/local-management/configuration-file/">configuration file</a> to add more complex routing and tunnel setups that go beyond a simple <code>--url</code> flag. You can also <a href="/cloudflare-one/networks/connectors/cloudflare-tunnel/routing-to-tunnel/dns/">attach a Cloudflare DNS record</a> to a domain or subdomain for an easily accessible, long-lived tunnel to your local machine.</p>
<p>Finally, by incorporating Cloudflare Access, you can provide <a href="/cloudflare-one/access-controls/applications/http-apps/self-hosted-public-app/">secure access to your tunnels</a> without exposing your entire server, or compromising on security. Refer to the <a href="/cloudflare-one/">Cloudflare for Teams documentation</a> to learn more about what you can do with Cloudflare's entire suite of Zero Trust tools.</p>
