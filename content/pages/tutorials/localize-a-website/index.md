<p>In this tutorial, you will build an example internationalization and localization engine (commonly referred to as <strong>i18n</strong> and <strong>l10n</strong>) for your application, serve the content of your site, and automatically translate the content based on your visitors’ location in the world.</p>
<p>This tutorial uses the <a href="/workers/runtime-apis/html-rewriter/"><code>HTMLRewriter</code></a> class built into the Cloudflare Workers runtime, which allows for parsing and rewriting of HTML on the Cloudflare global network. This gives developers the ability to efficiently and transparently customize their Workers applications.</p>

<p>This tutorial is designed to use an existing website. To simplify this process, you will use a free HTML5 template from <a href="https://html5up.net">HTML5 UP</a>. With this website as the base, you will use the <code>HTMLRewriter</code> functionality in the Workers platform to overlay an i18n layer, automatically translating the site based on the user’s language.</p>

<h2 id="understanding-data-i18n-key">Understanding <code>data-i18n-key</code></h2>
<p>The <code>HTMLRewriter</code> class provided in the Workers runtime allows developers to parse HTML and write JavaScript to query and transform every element of the page.</p>
<p>The example website in this tutorial is a basic single-page HTML project that lives in the <code>public</code> directory. It includes an <code>h1</code> element with the text <code>Example Site</code> and a number of <code>p</code> elements with different text:</p>
<p><img src="/assets/upstream/images/workers/tutorials/localize-website/code-example.png" alt="Demo code shown in Chrome DevTools with the elements described above" /></p>
<p>What is unique about this page is the addition of <a href="https://developer.mozilla.org/en-US/docs/Learn/HTML/Howto/Use_data_attributes">data attributes</a> in the HTML – custom attributes defined on a number of elements on this page. The <code>data-i18n-key</code> on the <code>h1</code> tag on this page, as well as many of the <code>p</code> tags, indicates that there is a corresponding internationalization key, which should be used to look up a translation for this text:</p>
<pre tabindex="0"><code class="language-html">&lt;!-- source clipped from i18n-example site --&gt;&#10;&#10;&lt;div class=&quot;inner&quot;&gt;&#10;	&lt;h1 data-i18n-key=&quot;headline&quot;&gt;Example Site&lt;/h1&gt;&#10;	&lt;p data-i18n-key=&quot;subtitle&quot;&gt;This is my example site. Depending o...&lt;/p&gt;&#10;	&lt;p data-i18n-key=&quot;disclaimer&quot;&gt;Disclaimer: the initial translations...&lt;/p&gt;&#10;&lt;/div&gt;&#10;</code></pre>
<p>Using <code>HTMLRewriter</code>, you will parse the HTML within the <code>./public/index.html</code> page. When a <code>data-i18n-key</code> attribute is found, you should use the attribute's value to retrieve a matching translation from the <code>strings</code> object. With <code>HTMLRewriter</code>, you can query elements to accomplish tasks like finding a data attribute. However, as the name suggests, you can also rewrite elements by taking a translated string and directly inserting it into the HTML.</p>
<p>Another feature of this project is based on the <code>Accept-Language</code> header, which exists on incoming requests. You can set the translation language per request, allowing users from around the world to see a locally relevant and translated page.</p>
<h2 id="using-the-html-rewriter-api">Using the HTML Rewriter API</h2>
<p>Begin with the <code>functions/index.js</code> file. Your application in this tutorial will live entirely in this file.</p>
<p>Inside of this file, start by adding the default code for running a <a href="/pages/functions/get-started/#create-a-function">Pages Function</a>.</p>
<pre tabindex="0"><code class="language-js">export function onRequest(context) {&#10;	return new Response(&quot;Hello, world!&quot;);&#10;}&#10;</code></pre>
<p>The important part of the code lives in the <code>onRequest</code> function. To implement translations on the site, take the HTML response retrieved from <code>env.ASSETS.fetch(request)</code> this allows you to fetch a static asset from your Pages project and pass it into a new instance of <code>HTMLRewriter</code>. When instantiating <code>HTMLRewriter</code>, you can attach handlers using the <code>on</code> function. For this tutorial, you will use the <code>[data-i18n-key]</code> selector (refer to the <a href="/workers/runtime-apis/html-rewriter/">HTMLRewriter documentation</a> for more advanced usage) to locate all elements with the <code>data-i18n-key</code> attribute, which means that they must be translated. Any matching element will be passed to an instance of your <code>ElementHandler</code> class, which will contain the translation logic. With the created instance of <code>HTMLRewriter</code>, the <code>transform</code> function takes a <code>response</code> and can be returned to the client:</p>
<pre tabindex="0"><code class="language-js">export async function onRequest(context) {&#10;	const { request, env } = context;&#10;	const response = await env.ASSETS.fetch(request);&#10;	return new HTMLRewriter()&#10;		.on(&quot;[data-i18n-key]&quot;, new ElementHandler(countryStrings))&#10;		.transform(response);&#10;}&#10;</code></pre>
<h2 id="transforming-html">Transforming HTML</h2>
<p>Your <code>ElementHandler</code> will receive every element parsed by the <code>HTMLRewriter</code> instance, and due to the expressive API, you can query each incoming element for information.</p>
<p>In <a href="#understanding-data-i18n-key">How it works</a>, the documentation describes <code>data-i18n-key</code>, a custom data attribute that could be used to find a corresponding translated string for the website’s user interface. In <code>ElementHandler</code>, you can define an <code>element</code> function, which will be called as each element is parsed. Inside of the <code>element</code> function, you can query for the custom data attribute using <code>getAttribute</code>:</p>
<pre tabindex="0"><code class="language-js">class ElementHandler {&#10;	element(element) {&#10;		const i18nKey = element.getAttribute(&quot;data-i18n-key&quot;);&#10;	}&#10;}&#10;</code></pre>
<p>With <code>i18nKey</code> defined, you can use it to search for a corresponding translated string. You will now set up a <code>strings</code> object with key-value pairs corresponding to the <code>data-i18n-key</code> value. For now, you will define a single example string, <code>headline</code>, with a German <code>string</code>, <code>&quot;Beispielseite&quot;</code> (<code>&quot;Example Site&quot;</code>), and retrieve it in the <code>element</code> function:</p>
<pre tabindex="0"><code class="language-js">const strings = {&#10;	headline: &quot;Beispielseite&quot;,&#10;};&#10;&#10;class ElementHandler {&#10;	element(element) {&#10;		const i18nKey = element.getAttribute(&quot;data-i18n-key&quot;);&#10;		const string = strings[i18nKey];&#10;	}&#10;}&#10;</code></pre>
<p>Take your translated <code>string</code> and insert it into the original element, using the <code>setInnerContent</code> function:</p>
<pre tabindex="0"><code class="language-js">const strings = {&#10;	headline: &quot;Beispielseite&quot;,&#10;};&#10;&#10;class ElementHandler {&#10;	element(element) {&#10;		const i18nKey = element.getAttribute(&quot;data-i18n-key&quot;);&#10;		const string = strings[i18nKey];&#10;		if (string) {&#10;			element.setInnerContent(string);&#10;		}&#10;	}&#10;}&#10;</code></pre>
<p>To review that everything looks as expected, use the preview functionality built into Wrangler. Call <a href="/workers/wrangler/commands/general/#dev"><code>wrangler pages dev ./public</code></a> to open up a live preview of your project. The command is refreshed after every code change that you make.</p>
<p>You can expand on this translation functionality to provide country-specific translations, based on the incoming request’s <code>Accept-Language</code> header. By taking this header, parsing it, and passing the parsed language into your <code>ElementHandler</code>, you can retrieve a translated string in your user’s home language, provided that it is defined in <code>strings</code>.</p>
<p>To implement this:</p>
<ol>
<li>Update the <code>strings</code> object, adding a second layer of key-value pairs and allowing strings to be looked up in the format <code>strings[country][key]</code>.</li>
<li>Pass a <code>countryStrings</code> object into our <code>ElementHandler</code>, so that it can be used during the parsing process.</li>
<li>Grab the <code>Accept-Language</code> header from an incoming request, parse it, and pass the parsed language to <code>ElementHandler</code>.</li>
</ol>
<p>To parse the <code>Accept-Language</code> header, install the <a href="https://www.npmjs.com/package/accept-language-parser"><code>accept-language-parser</code></a> npm package:</p>
<pre tabindex="0"><code class="language-sh">npm i accept-language-parser&#10;</code></pre>
<p>Once imported into your code, use the package to parse the most relevant language for a client based on <code>Accept-Language</code> header, and pass it to <code>ElementHandler</code>. Your final code for the project, with an included sample translation for Germany and Japan (using Google Translate) looks like this:</p>
