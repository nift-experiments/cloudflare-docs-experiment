<p class="article-summary">Example of how to use Queues and Browser Run to power a web crawler.</p>
<p>This tutorial explains how to build and deploy a web crawler with Queues, <a href="/browser-run/">Browser Run</a>, and <a href="/browser-run/puppeteer/">Puppeteer</a>.</p>
<p>Puppeteer is a high-level library used to automate interactions with Chrome/Chromium browsers. On each submitted page, the crawler will find the number of links to <code>cloudflare.com</code> and take a screenshot of the site, saving results to <a href="/kv/">Workers KV</a>.</p>
<p>You can use Puppeteer to request all images on a page, save the colors used on a site, and more.</p>

<p>This will accept requests to any subpath and forwards the request's body to be crawled. It expects that the request body only contains a URL. In production, you should check that the request was a <code>POST</code> request and contains a well-formed URL in its body. This has been omitted for simplicity.</p>
<h2 id="7-crawl-with-puppeteer"><ol start="7">
<li>Crawl with Puppeteer</li>
</ol></h2>
<p>Add a <code>queue()</code> handler to the Worker to process the links you send.</p>
<pre><code class="language-ts">import puppeteer from &quot;@cloudflare/puppeteer&quot;;&#10;import robotsParser from &quot;robots-parser&quot;;&#10;&#10;async queue(batch, env, ctx): Promise&lt;void&gt; {&#10;  let browser: puppeteer.Browser | null = null;&#10;  try {&#10;    browser = await puppeteer.launch(env.CRAWLER_BROWSER);&#10;  } catch {&#10;    batch.retryAll();&#10;	return;&#10;  }&#10;&#10;  for (const message of batch.messages) {&#10;    const { url } = message.body;&#10;&#10;    let isAllowed = true;&#10;    try {&#10;      const robotsTextPath = new URL(url).origin + &quot;/robots.txt&quot;;&#10;      const response = await fetch(robotsTextPath);&#10;&#10;      const robots = robotsParser(robotsTextPath, await response.text());&#10;      isAllowed = robots.isAllowed(url) ?? true; // respect robots.txt!&#10;    } catch {}&#10;&#10;    if (!isAllowed) {&#10;      message.ack();&#10;      continue;&#10;    }&#10;&#10;	// TODO: crawl!&#10;    message.ack();&#10;  }&#10;&#10;  await browser.close();&#10;},&#10;</code></pre>
<p>This is a skeleton for the crawler. It launches the Puppeteer browser and iterates through the Queue's received messages. It fetches the site's <code>robots.txt</code> and uses <code>robots-parser</code> to check that this site allows crawling. If crawling is not allowed, the message is <code>ack</code>'ed, removing it from the Queue. If crawling is allowed, you can continue to crawl the site.</p>
<p>The <code>puppeteer.launch()</code> is wrapped in a <code>try...catch</code> to allow the whole batch to be retried if the browser launch fails. The browser launch may fail due to going over the limit for number of browsers per account.</p>
<pre><code class="language-ts">type Result = {&#10;	numCloudflareLinks: number;&#10;	screenshot: ArrayBuffer;&#10;};&#10;&#10;const crawlPage = async (url: string): Promise&lt;Result&gt; =&gt; {&#10;	const page = await (browser as puppeteer.Browser).newPage();&#10;&#10;	await page.goto(url, {&#10;		waitUntil: &quot;load&quot;,&#10;	});&#10;&#10;	const numCloudflareLinks = await page.$$eval(&quot;a&quot;, (links) =&gt; {&#10;		links = links.filter((link) =&gt; {&#10;			try {&#10;				return new URL(link.href).hostname.includes(&quot;cloudflare.com&quot;);&#10;			} catch {&#10;				return false;&#10;			}&#10;		});&#10;		return links.length;&#10;	});&#10;&#10;	await page.setViewport({&#10;		width: 1920,&#10;		height: 1080,&#10;		deviceScaleFactor: 1,&#10;	});&#10;&#10;	return {&#10;		numCloudflareLinks,&#10;		screenshot: ((await page.screenshot({ fullPage: true })) as Buffer).buffer,&#10;	};&#10;};&#10;</code></pre>
<p>This helper function opens a new page in Puppeteer and navigates to the provided URL. <code>numCloudflareLinks</code> uses Puppeteer's <code>$$eval</code> (equivalent to <code>document.querySelectorAll</code>) to find the number of links to a <code>cloudflare.com</code> page. Checking if the link's <code>href</code> is to a <code>cloudflare.com</code> page is wrapped in a <code>try...catch</code> to handle cases where <code>href</code>s may not be URLs.</p>
<p>Then, the function sets the browser viewport size and takes a screenshot of the full page. The screenshot is returned as a <code>Buffer</code> so it can be converted to an <code>ArrayBuffer</code> and written to KV.</p>
<p>To enable recursively crawling links, add a snippet after checking the number of Cloudflare links to send messages recursively from the queue consumer to the queue itself. Recursing too deep, as is possible with crawling, will cause a Durable Object <code>Subrequest depth limit exceeded.</code> error. If one occurs, it is caught, but the links are not retried.</p>
<pre><code class="language-ts">// const numCloudflareLinks = await page.$$eval(&quot;a&quot;, (links) =&gt; { ...&#10;&#10;await page.$$eval(&quot;a&quot;, async (links) =&gt; {&#10;	const urls: MessageSendRequest&lt;Message&gt;[] = links.map((link) =&gt; {&#10;		return {&#10;			body: {&#10;				url: link.href,&#10;			},&#10;		};&#10;	});&#10;	try {&#10;		await env.CRAWLER_QUEUE.sendBatch(urls);&#10;	} catch {} // do nothing, likely hit subrequest limit&#10;});&#10;&#10;// await page.setViewport({ ...&#10;</code></pre>
<p>Then, in the <code>queue</code> handler, call <code>crawlPage</code> on the URL.</p>
<pre><code class="language-ts">// in the `queue` handler:&#10;// ...&#10;if (!isAllowed) {&#10;	message.ack();&#10;	continue;&#10;}&#10;&#10;try {&#10;	const { numCloudflareLinks, screenshot } = await crawlPage(url);&#10;	const timestamp = new Date().getTime();&#10;	const resultKey = `${encodeURIComponent(url)}-${timestamp}`;&#10;	await env.CRAWLER_LINKS_KV.put(resultKey, numCloudflareLinks.toString(), {&#10;		metadata: { date: timestamp },&#10;	});&#10;	await env.CRAWLER_SCREENSHOTS_KV.put(resultKey, screenshot, {&#10;		metadata: { date: timestamp },&#10;	});&#10;	message.ack();&#10;} catch {&#10;	message.retry();&#10;}&#10;&#10;// ...&#10;</code></pre>
<p>This snippet saves the results from <code>crawlPage</code> into the appropriate KV namespaces. If an unexpected error occurred, the URL will be retried and resent to the queue again.</p>
<p>Saving the timestamp of the crawl in KV helps you avoid crawling too frequently.</p>
<p>Add a snippet before checking <code>robots.txt</code> to check KV for a crawl within the last hour. This lists all KV keys beginning with the same URL (crawls of the same page), and check if any crawls have been done within the last hour. If any crawls have been done within the last hour, the message is <code>ack</code>'ed and not retried.</p>
<pre><code class="language-ts">type KeyMetadata = {&#10;  date: number;&#10;};&#10;&#10;// in the `queue` handler:&#10;// ...&#10;for (const message of batch.messages) {&#10;  const sameUrlCrawls = await env.CRAWLER_LINKS_KV.list({&#10;    prefix: `${encodeURIComponent(url)}`,&#10;  });&#10;&#10;  let shouldSkip = false;&#10;  for (const key of sameUrlCrawls.keys) {&#10;    if (timestamp - (key.metadata as KeyMetadata)?.date &lt; 60 * 60 * 1000) {&#10;      // if crawled in last hour, skip&#10;      message.ack();&#10;      shouldSkip = true;&#10;      break;&#10;    }&#10;  }&#10;  if (shouldSkip) {&#10;    continue;&#10;  }&#10;&#10;  let isAllowed = true;&#10;  // ...&#10;</code></pre>
