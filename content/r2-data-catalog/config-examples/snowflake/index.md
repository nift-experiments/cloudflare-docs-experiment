<p>Below is an example of using <a href="https://docs.snowflake.com/en/user-guide/tables-iceberg-configure-catalog-integration-rest">Snowflake</a> to connect and query data from R2 Data Catalog (read-only).</p>
<h2 id="prerequisites">Prerequisites</h2>
<ul>
<li>Sign up for a <a href="https://dash.cloudflare.com/sign-up/workers-and-pages">Cloudflare account</a>.</li>
<li><a href="/r2/buckets/create-buckets/">Create an R2 bucket</a> and <a href="/r2-data-catalog/manage-catalogs/#enable-r2-data-catalog-on-a-bucket">enable the data catalog</a>.</li>
<li><a href="/r2/api/tokens/">Create an R2 API token</a> with both <a href="/r2/api/tokens/#permissions">R2 and data catalog permissions</a>.</li>
<li>A <a href="https://www.snowflake.com/">Snowflake</a> account with the necessary privileges to create external volumes and catalog integrations.</li>
</ul>
<h2 id="example-usage">Example usage</h2>
<p>In your Snowflake <a href="https://docs.snowflake.com/en/user-guide/ui-snowsight-worksheets-gs">SQL worksheet</a> or <a href="https://docs.snowflake.com/en/user-guide/ui-snowsight/notebooks">notebook</a>, run the following commands:</p>
<pre><code class="language-sql">&#45;- Create a database (if you don&#x27;t already have one) to organize your external data&#10;CREATE DATABASE IF NOT EXISTS r2_example_db;&#10;&#10;&#45;- Create an external volume pointing to your R2 bucket&#10;CREATE OR REPLACE EXTERNAL VOLUME ext_vol_r2&#10;    STORAGE_LOCATIONS = (&#10;        (&#10;            NAME = &#x27;my_r2_storage_location&#x27;&#10;            STORAGE_PROVIDER = &#x27;S3COMPAT&#x27;&#10;            STORAGE_BASE_URL = &#x27;s3compat://&lt;bucket-name&gt;&#x27;&#10;            CREDENTIALS = (&#10;                AWS_KEY_ID = &#x27;&lt;access_key&gt;&#x27;&#10;                AWS_SECRET_KEY = &#x27;&lt;secret_access_key&gt;&#x27;&#10;            )&#10;            STORAGE_ENDPOINT = &#x27;&lt;account_id&gt;.r2.cloudflarestorage.com&#x27;&#10;        )&#10;    )&#10;    ALLOW_WRITES = FALSE;&#10;&#10;&#45;- Create a catalog integration for R2 Data Catalog (read-only)&#10;CREATE OR REPLACE CATALOG INTEGRATION r2_data_catalog&#10;    CATALOG_SOURCE = ICEBERG_REST&#10;    TABLE_FORMAT = ICEBERG&#10;    CATALOG_NAMESPACE = &#x27;default&#x27;&#10;    REST_CONFIG = (&#10;        CATALOG_URI = &#x27;&lt;catalog_uri&gt;&#x27;&#10;        CATALOG_NAME = &#x27;&lt;warehouse_name&gt;&#x27;&#10;    )&#10;    REST_AUTHENTICATION = (&#10;        TYPE = BEARER&#10;        BEARER_TOKEN = &#x27;&lt;token&gt;&#x27;&#10;    )&#10;    ENABLED = TRUE;&#10;&#10;&#45;- Create an Apache Iceberg table in your selected Snowflake database&#10;CREATE ICEBERG TABLE my_iceberg_table&#10;    CATALOG = &#x27;r2_data_catalog&#x27;&#10;    EXTERNAL_VOLUME = &#x27;ext_vol_r2&#x27;&#10;    CATALOG_TABLE_NAME = &#x27;my_table&#x27;;  -- Name of existing table in your R2 data catalog&#10;&#10;&#45;- Query your Iceberg table&#10;SELECT * FROM my_iceberg_table;&#10;</code></pre>
