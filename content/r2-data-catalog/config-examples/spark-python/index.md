<p>Below is an example of using <a href="https://spark.apache.org/docs/latest/api/python/index.html">PySpark</a> to connect to R2 Data Catalog.</p>
<h2 id="prerequisites">Prerequisites</h2>
<ul>
<li>Sign up for a <a href="https://dash.cloudflare.com/sign-up/workers-and-pages">Cloudflare account</a>.</li>
<li><a href="/r2/buckets/create-buckets/">Create an R2 bucket</a> and <a href="/r2-data-catalog/manage-catalogs/#enable-r2-data-catalog-on-a-bucket">enable the data catalog</a>.</li>
<li><a href="/r2/api/tokens/">Create an R2 API token</a> with both <a href="/r2/api/tokens/#permissions">R2 and data catalog permissions</a>.</li>
<li>Install the <a href="https://spark.apache.org/docs/latest/api/python/getting_started/install.html">PySpark</a> library.</li>
</ul>
<h2 id="example-usage">Example usage</h2>
<pre tabindex="0"><code class="language-py">from pyspark.sql import SparkSession&#10;&#10;&#35; Define catalog connection details (replace variables)&#10;WAREHOUSE = &quot;&lt;WAREHOUSE&gt;&quot;&#10;TOKEN = &quot;&lt;TOKEN&gt;&quot;&#10;CATALOG_URI = &quot;&lt;CATALOG_URI&gt;&quot;&#10;&#10;&#35; Build Spark session with Iceberg configurations&#10;spark = SparkSession.builder \&#10;  .appName(&quot;R2DataCatalogExample&quot;) \&#10;  .config(&#x27;spark.jars.packages&#x27;, &#x27;org.apache.iceberg:iceberg-spark-runtime-3.5_2.12:1.6.1,org.apache.iceberg:iceberg-aws-bundle:1.6.1&#x27;) \&#10;  .config(&quot;spark.sql.extensions&quot;, &quot;org.apache.iceberg.spark.extensions.IcebergSparkSessionExtensions&quot;) \&#10;  .config(&quot;spark.sql.catalog.my_catalog&quot;, &quot;org.apache.iceberg.spark.SparkCatalog&quot;) \&#10;  .config(&quot;spark.sql.catalog.my_catalog.type&quot;, &quot;rest&quot;) \&#10;  .config(&quot;spark.sql.catalog.my_catalog.uri&quot;, CATALOG_URI) \&#10;  .config(&quot;spark.sql.catalog.my_catalog.warehouse&quot;, WAREHOUSE) \&#10;  .config(&quot;spark.sql.catalog.my_catalog.token&quot;, TOKEN) \&#10;  .config(&quot;spark.sql.catalog.my_catalog.header.X-Iceberg-Access-Delegation&quot;, &quot;vended-credentials&quot;) \&#10;  .config(&quot;spark.sql.catalog.my_catalog.s3.remote-signing-enabled&quot;, &quot;false&quot;) \&#10;  .config(&quot;spark.sql.defaultCatalog&quot;, &quot;my_catalog&quot;) \&#10;  .getOrCreate()&#10;spark.sql(&quot;USE my_catalog&quot;)&#10;&#10;&#35; Create namespace if it does not exist&#10;spark.sql(&quot;CREATE NAMESPACE IF NOT EXISTS default&quot;)&#10;&#10;&#35; Create a table in the namespace using Iceberg&#10;spark.sql(&quot;&quot;&quot;&#10;    CREATE TABLE IF NOT EXISTS default.my_table (&#10;        id BIGINT,&#10;        name STRING&#10;    )&#10;    USING iceberg&#10;&quot;&quot;&quot;)&#10;&#10;&#35; Create a simple DataFrame&#10;df = spark.createDataFrame(&#10;    [(1, &quot;Alice&quot;), (2, &quot;Bob&quot;), (3, &quot;Charlie&quot;)],&#10;    [&quot;id&quot;, &quot;name&quot;]&#10;)&#10;&#10;&#35; Write the DataFrame to the Iceberg table&#10;df.write \&#10;    .format(&quot;iceberg&quot;) \&#10;    .mode(&quot;append&quot;) \&#10;    .save(&quot;default.my_table&quot;)&#10;&#10;&#35; Read the data back from the Iceberg table&#10;result_df = spark.read \&#10;    .format(&quot;iceberg&quot;) \&#10;    .load(&quot;default.my_table&quot;)&#10;&#10;result_df.show()&#10;</code></pre>
