<p>Below is an example of how you can build an <a href="https://spark.apache.org/">Apache Spark</a> application (with Scala) which connects to R2 Data Catalog. This application is built to run locally, but it can be adapted to run on a cluster.</p>
<h2 id="prerequisites">Prerequisites</h2>
<ul>
<li>Sign up for a <a href="https://dash.cloudflare.com/sign-up/workers-and-pages">Cloudflare account</a>.</li>
<li><a href="/r2/buckets/create-buckets/">Create an R2 bucket</a> and <a href="/r2-data-catalog/manage-catalogs/#enable-r2-data-catalog-on-a-bucket">enable the data catalog</a>.</li>
<li><a href="/r2/api/tokens/">Create an R2 API token</a> with both <a href="/r2/api/tokens/#permissions">R2 and data catalog permissions</a>.</li>
<li>Install Java 17, Spark 3.5.3, and SBT 1.10.11
<ul>
<li>Note: The specific versions of tools are critical for getting things to work in this example.</li>
<li>Tip: <a href="https://sdkman.io/">“SDKMAN”</a> is a convenient package manager for installing SDKs.</li>
</ul>
</li>
</ul>
<h2 id="example-usage">Example usage</h2>
<p>To start, create a new empty project directory somewhere on your machine.</p>
<p>Inside that directory, create the following file at <code>src/main/scala/com/example/R2DataCatalogDemo.scala</code>. This will serve as the main entry point for your Spark application.</p>
<pre><code class="language-java">package com.example&#10;&#10;import org.apache.spark.sql.SparkSession&#10;&#10;object R2DataCatalogDemo {&#10;    def main(args: Array[String]): Unit = {&#10;&#10;        val uri = sys.env(&quot;CATALOG_URI&quot;)&#10;        val warehouse = sys.env(&quot;WAREHOUSE&quot;)&#10;        val token = sys.env(&quot;TOKEN&quot;)&#10;&#10;        val spark = SparkSession.builder()&#10;            .appName(&quot;My R2 Data Catalog Demo&quot;)&#10;            .master(&quot;local[*]&quot;)&#10;            .config(&quot;spark.sql.extensions&quot;, &quot;org.apache.iceberg.spark.extensions.IcebergSparkSessionExtensions&quot;)&#10;            .config(&quot;spark.sql.catalog.mydemo&quot;, &quot;org.apache.iceberg.spark.SparkCatalog&quot;)&#10;            .config(&quot;spark.sql.catalog.mydemo.type&quot;, &quot;rest&quot;)&#10;            .config(&quot;spark.sql.catalog.mydemo.uri&quot;, uri)&#10;            .config(&quot;spark.sql.catalog.mydemo.warehouse&quot;, warehouse)&#10;            .config(&quot;spark.sql.catalog.mydemo.token&quot;, token)&#10;            .getOrCreate()&#10;&#10;        import spark.implicits._&#10;&#10;        val data = Seq(&#10;            (1, &quot;Alice&quot;, 25),&#10;            (2, &quot;Bob&quot;, 30),&#10;            (3, &quot;Charlie&quot;, 35),&#10;            (4, &quot;Diana&quot;, 40)&#10;        ).toDF(&quot;id&quot;, &quot;name&quot;, &quot;age&quot;)&#10;&#10;        spark.sql(&quot;USE mydemo&quot;)&#10;&#10;        spark.sql(&quot;CREATE NAMESPACE IF NOT EXISTS demoNamespace&quot;)&#10;&#10;        data.writeTo(&quot;demoNamespace.demotable&quot;).createOrReplace()&#10;&#10;        val readResult = spark.sql(&quot;SELECT * FROM demoNamespace.demotable WHERE age &gt; 30&quot;)&#10;        println(&quot;Records with age &gt; 30:&quot;)&#10;        readResult.show()&#10;    }&#10;}&#10;</code></pre>
<p>For building this application and managing dependencies, we will use <a href="https://www.scala-sbt.org/">sbt (“simple build tool”)</a>. The following is an example <code>build.sbt</code> file to place at the root of your project. It is configured to produce a &quot;fat JAR&quot;, bundling all required dependencies.</p>
<pre><code class="language-java">name := &quot;R2DataCatalogDemo&quot;&#10;&#10;version := &quot;1.0&quot;&#10;&#10;val sparkVersion = &quot;3.5.3&quot;&#10;val icebergVersion = &quot;1.8.1&quot;&#10;&#10;// You need to use binaries of Spark compiled with either 2.12 or 2.13; and 2.12 is more common.&#10;// If you download Spark 3.5.3 with sdkman, then it comes with 2.12.18&#10;scalaVersion := &quot;2.12.18&quot;&#10;&#10;libraryDependencies ++= Seq(&#10;    &quot;org.apache.spark&quot; %% &quot;spark-core&quot; % sparkVersion,&#10;    &quot;org.apache.spark&quot; %% &quot;spark-sql&quot; % sparkVersion,&#10;    &quot;org.apache.iceberg&quot; % &quot;iceberg-core&quot; % icebergVersion,&#10;    &quot;org.apache.iceberg&quot; % &quot;iceberg-spark-runtime-3.5_2.12&quot; % icebergVersion,&#10;    &quot;org.apache.iceberg&quot; % &quot;iceberg-aws-bundle&quot; % icebergVersion,&#10;)&#10;&#10;// build a fat JAR with all dependencies&#10;assembly / assemblyMergeStrategy := {&#10;    case PathList(&quot;META-INF&quot;, &quot;services&quot;, xs @ _*) =&gt; MergeStrategy.concat&#10;    case PathList(&quot;META-INF&quot;, xs @ _*) =&gt; MergeStrategy.discard&#10;    case &quot;reference.conf&quot; =&gt; MergeStrategy.concat&#10;    case &quot;application.conf&quot; =&gt; MergeStrategy.concat&#10;    case x if x.endsWith(&quot;.properties&quot;) =&gt; MergeStrategy.first&#10;    case x =&gt; MergeStrategy.first&#10;}&#10;&#10;// For Java  17 Compatibility&#10;Compile / javacOptions ++= Seq(&quot;--release&quot;, &quot;17&quot;)&#10;</code></pre>
<p>To enable the <a href="https://github.com/sbt/sbt-assembly?tab=readme-ov-file">sbt-assembly plugin</a> (used to build fat JARs), add the following to a new file at <code>project/assembly.sbt</code>:</p>
<pre><code>addSbtPlugin(&quot;com.eed3si9n&quot; % &quot;sbt-assembly&quot; % &quot;1.2.0&quot;)&#10;</code></pre>
<p>Make sure Java, Spark, and sbt are installed and available in your shell. If you are using SDKMAN, you can install them as shown below:</p>
<pre><code class="language-bash">sdk install java 17.0.14-amzn&#10;sdk install spark 3.5.3&#10;sdk install sbt 1.10.11&#10;</code></pre>
<p>With everything installed, you can now build the project using sbt. This will generate a single bundled JAR file.</p>
<pre><code class="language-bash">sbt clean assembly&#10;</code></pre>
<p>After building, the output JAR should be located at <code>target/scala-2.12/R2DataCatalogDemo-assembly-1.0.jar</code>.</p>
<p>To run the application, you will use <code>spark-submit</code>. Below is an example shell script (<code>submit.sh</code>) that includes the necessary Java compatibility flags for Spark on Java 17:</p>
<pre><code>&#35; We need to set these &quot;--add-opens&quot; so that Spark can run on Java 17 (it needs access to&#10;&#35; parts of the JVM which have been modularized and made internal).&#10;JAVA_17_COMPATIBILITY=&quot;--add-opens=java.base/sun.nio.ch=ALL-UNNAMED --add-opens=java.base/java.nio=ALL-UNNAMED --add-opens=java.base/java.lang=ALL-UNNAMED --add-opens=java.base/java.util=ALL-UNNAMED --add-opens=java.base/java.util.concurrent=ALL-UNNAMED&quot;&#10;&#10;spark-submit \&#10;&#45;-conf &quot;spark.driver.extraJavaOptions=$JAVA_17_COMPATIBILITY&quot; \&#10;&#45;-conf &quot;spark.executor.extraJavaOptions=$JAVA_17_COMPATIBILITY&quot; \&#10;&#45;-class com.example.R2DataCatalogDemo target/scala-2.12/R2DataCatalogDemo-assembly-1.0.jar&#10;</code></pre>
<p>Before running it, make sure the script is executable:</p>
<pre><code class="language-bash">chmod +x submit.sh&#10;</code></pre>
<p>At this point, your project directory should be structured like this:</p>
<pre class="nb-file-tree">&#10;&#10;&#10;@markup("md", "content/.markup/bodies/11322.md")&#10;&#10;&#10;</pre>
<p>Before submitting the job, make sure you have the required environment variable set for your catalog URI, warehouse, and <a href="/r2/api/tokens/">Cloudflare API token</a>.</p>
<pre><code class="language-bash">export CATALOG_URI=&#10;export WAREHOUSE=&#10;export TOKEN=&#10;</code></pre>
<p>You are now ready to run the job:</p>
<pre><code class="language-bash">./submit.sh&#10;</code></pre>
