<p>The following examples show how to generate R2 <a href="/r2/api/s3/temporary-credentials/">temporary credentials</a> via both the Temporary Credentials API and local client-side signing, and how to use the resulting credentials with an S3 client.</p>
<h2 id="prerequisites">Prerequisites</h2>
<ul>
<li>A parent <a href="/r2/api/tokens/">R2 API token</a> with at least the permissions you plan to delegate. Never ship parent credentials to a client.</li>
<li>Your Cloudflare <a href="/fundamentals/account/find-account-and-zone-ids/">account ID</a>.</li>
<li>An S3 client that supports session tokens. The examples below use <a href="https://www.npmjs.com/package/aws4fetch">aws4fetch</a>.</li>
</ul>
<h2 id="generate-via-the-temporary-credentials-api">Generate via the Temporary Credentials API</h2>
<p>Call the <a href="/api/resources/r2/subresources/temporary_credentials/methods/create/">Temporary Credentials API</a> from a trusted server, then use the returned credentials with any S3 client.</p>
<pre><code class="language-sh">curl https://api.cloudflare.com/client/v4/accounts/&lt;ACCOUNT_ID&gt;/r2/temp-access-credentials \&#10;  &#45;-header &quot;Authorization: Bearer &lt;PARENT_API_TOKEN&gt;&quot; \&#10;  &#45;-header &quot;Content-Type: application/json&quot; \&#10;  &#45;-data &#x27;{&#10;    &quot;bucket&quot;: &quot;my-bucket&quot;,&#10;    &quot;parentAccessKeyId&quot;: &quot;&lt;PARENT_ACCESS_KEY_ID&gt;&quot;,&#10;    &quot;permission&quot;: &quot;object-read-only&quot;,&#10;    &quot;ttlSeconds&quot;: 900,&#10;    &quot;objects&quot;: [&quot;reports/2026-q1.pdf&quot;]&#10;  }&#x27;&#10;</code></pre>
<p>The response wraps the credentials in a <code>result</code> object:</p>
<pre><code class="language-json">{&#10;  &quot;result&quot;: {&#10;    &quot;accessKeyId&quot;: &quot;&lt;accessKeyId&gt;&quot;,&#10;    &quot;secretAccessKey&quot;: &quot;&lt;secretAccessKey&gt;&quot;,&#10;    &quot;sessionToken&quot;: &quot;&lt;sessionToken&gt;&quot;&#10;  },&#10;  &quot;errors&quot;: [],&#10;  &quot;messages&quot;: [],&#10;  &quot;success&quot;: true&#10;}&#10;</code></pre>
<h2 id="generate-locally-client-side-signing">Generate locally (client-side signing)</h2>
<p>This example uses <a href="https://www.npmjs.com/package/jose"><code>jose</code></a> to sign the JWT and <a href="https://www.npmjs.com/package/aws4fetch"><code>aws4fetch</code></a> to issue signed requests.</p>

<p>The following helper signs a JWT with your parent secret access key and derives the temporary secret access key and session token:</p>
<pre><code class="language-ts">import { SignJWT } from &quot;jose&quot;;&#10;&#10;type R2Scope =&#10;  | &quot;object-read-only&quot;&#10;  | &quot;object-read-write&quot;&#10;  | &quot;admin-read-only&quot;&#10;  | &quot;admin-read-write&quot;;&#10;&#10;export interface TempCredentialOptions {&#10;  scope: R2Scope;&#10;  // Optional: narrow the credential to specific S3 operations.&#10;  actions?: string[];&#10;  // Time-to-live in seconds. Defaults to 1 hour.&#10;  ttlSeconds?: number;&#10;  // Optional: restrict access to specific prefixes or objects.&#10;  paths?: { prefixPaths?: string[]; objectPaths?: string[] };&#10;}&#10;&#10;export async function createTempCredentials(&#10;  endpoint: string,&#10;  accountId: string,&#10;  parentAccessKeyId: string,&#10;  parentSecretAccessKey: string,&#10;  bucket: string,&#10;  opts: TempCredentialOptions,&#10;): Promise&lt;{&#10;  accessKeyId: string;&#10;  secretAccessKey: string;&#10;  sessionToken: string;&#10;}&gt; {&#10;  const ttl = opts.ttlSeconds ?? 3600;&#10;&#10;  const claims: Record&lt;string, unknown&gt; = {&#10;    bucket,&#10;    scope: opts.scope,&#10;  };&#10;&#10;  if (opts.actions !== undefined &amp;&amp; opts.actions.length &gt; 0) {&#10;    claims.actions = opts.actions;&#10;  }&#10;&#10;  if (opts.paths !== undefined) {&#10;    claims.paths = {&#10;      prefixPaths: opts.paths.prefixPaths ?? [],&#10;      objectPaths: opts.paths.objectPaths ?? [],&#10;    };&#10;  }&#10;&#10;  // Sign the JWT with the parent secret access key. R2 validates this signature.&#10;  const jwt = await new SignJWT(claims)&#10;    .setProtectedHeader({ alg: &quot;HS256&quot;, typ: &quot;JWT&quot; })&#10;    .setSubject(accountId)&#10;    .setIssuer(parentAccessKeyId)&#10;    .setAudience(new URL(endpoint).host)&#10;    .setIssuedAt()&#10;    .setExpirationTime(`${ttl}s`)&#10;    .sign(new TextEncoder().encode(parentSecretAccessKey));&#10;&#10;  // The temporary secret access key is the SHA-256 hex digest of the signed JWT.&#10;  const digest = await crypto.subtle.digest(&#10;    &quot;SHA-256&quot;,&#10;    new TextEncoder().encode(jwt),&#10;  );&#10;  const secretAccessKey = Array.from(new Uint8Array(digest))&#10;    .map((b) =&gt; b.toString(16).padStart(2, &quot;0&quot;))&#10;    .join(&quot;&quot;);&#10;&#10;  return {&#10;    // Reuse the parent access key ID as the temporary access key ID.&#10;    accessKeyId: parentAccessKeyId,&#10;    secretAccessKey,&#10;    // The session token is base64(&quot;jwt/&quot; + signed JWT).&#10;    sessionToken: btoa(`jwt/${jwt}`),&#10;  };&#10;}&#10;</code></pre>
<p>The following example returns a credential that is valid for 15 minutes and can only <code>GetObject</code> and <code>HeadObject</code> under the <code>data/</code> prefix:</p>
<pre><code class="language-ts">import { createTempCredentials } from &quot;./temp-credentials&quot;;&#10;&#10;const R2_URL = `https://${ACCOUNT_ID}.r2.cloudflarestorage.com`;&#10;&#10;const creds = await createTempCredentials(&#10;  R2_URL,&#10;  ACCOUNT_ID,&#10;  PARENT_ACCESS_KEY_ID,&#10;  PARENT_SECRET_ACCESS_KEY,&#10;  &quot;my-bucket&quot;,&#10;  {&#10;    scope: &quot;object-read-only&quot;,&#10;    actions: [&quot;GetObject&quot;, &quot;HeadObject&quot;],&#10;    ttlSeconds: 900,&#10;    paths: { prefixPaths: [&quot;data/&quot;] },&#10;  },&#10;);&#10;</code></pre>
<h2 id="use-the-credentials">Use the credentials</h2>
<p>Once you have a temporary credential, usage is the same regardless of how it was generated. Pass the three values to your S3 client and issue requests. The following example uses credentials scoped to the <code>data/</code> prefix to demonstrate one permitted and one rejected request:</p>
<pre><code class="language-ts">import { AwsClient } from &quot;aws4fetch&quot;;&#10;&#10;const R2_URL = `https://${ACCOUNT_ID}.r2.cloudflarestorage.com`;&#10;&#10;const client = new AwsClient({&#10;  accessKeyId: ACCESS_KEY_ID,&#10;  secretAccessKey: SECRET_ACCESS_KEY,&#10;  sessionToken: SESSION_TOKEN,&#10;  service: &quot;s3&quot;,&#10;});&#10;&#10;// Allowed: object under the data/ prefix.&#10;const ok = await client.fetch(`${R2_URL}/my-bucket/data/file.bin`);&#10;console.log(ok.status); // 200&#10;&#10;// Rejected with 403 AccessDenied because the object is outside the data/ prefix.&#10;const denied = await client.fetch(`${R2_URL}/my-bucket/other/file.bin`);&#10;console.log(denied.status); // 403&#10;</code></pre>
