<p>You must <a href="/r2/api/tokens/">generate an Access Key</a> before getting started. All examples will utilize <code>access_key_id</code> and <code>access_key_secret</code> variables which represent the <strong>Access Key ID</strong> and <strong>Secret Access Key</strong> values you generated.</p>
<br />
<p>With the <a href="https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html"><code>aws</code></a> CLI installed, you may run <a href="https://docs.aws.amazon.com/cli/latest/userguide/cli-configure-quickstart.html#cli-configure-quickstart-config"><code>aws configure</code></a> to configure a new profile. You will be prompted with a series of questions for the new profile's details.</p>
<pre tabindex="0"><code class="language-shell">aws configure&#10;</code></pre>
<pre tabindex="0"><code class="language-sh">AWS Access Key ID [None]: &lt;ACCESS_KEY_ID&gt;&#10;AWS Secret Access Key [None]: &lt;SECRET_ACCESS_KEY&gt;&#10;Default region name [None]: auto&#10;Default output format [None]: json&#10;</code></pre>
<p>The <code>region</code> value can be set to <code>auto</code> since it is required by the SDK but not used by R2.</p>
<p>You may then use the <code>aws</code> CLI for any of your normal workflows.</p>
<pre tabindex="0"><code class="language-sh">&#35; Provide your Cloudflare account ID&#10;aws s3api list-buckets --endpoint-url https://&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com&#10;&#35; {&#10;&#35;     &quot;Buckets&quot;: [&#10;&#35;         {&#10;&#35;             &quot;Name&quot;: &quot;my-bucket&quot;,&#10;&#35;             &quot;CreationDate&quot;: &quot;2022-05-18T17:19:59.645000+00:00&quot;&#10;&#35;         }&#10;&#35;     ],&#10;&#35;     &quot;Owner&quot;: {&#10;&#35;         &quot;DisplayName&quot;: &quot;134a5a2c0ba47b38eada4b9c8ead10b6&quot;,&#10;&#35;         &quot;ID&quot;: &quot;134a5a2c0ba47b38eada4b9c8ead10b6&quot;&#10;&#35;     }&#10;&#35; }&#10;&#10;aws s3api list-objects-v2 --endpoint-url https://&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com --bucket my-bucket&#10;&#35; {&#10;&#35;     &quot;Contents&quot;: [&#10;&#35;         {&#10;&#35;             &quot;Key&quot;: &quot;ferriswasm.png&quot;,&#10;&#35;             &quot;LastModified&quot;: &quot;2022-05-18T17:20:21.670000+00:00&quot;,&#10;&#35;             &quot;ETag&quot;: &quot;\&quot;eb2b891dc67b81755d2b726d9110af16\&quot;&quot;,&#10;&#35;             &quot;Size&quot;: 87671,&#10;&#35;             &quot;StorageClass&quot;: &quot;STANDARD&quot;&#10;&#35;         }&#10;&#35;     ]&#10;&#35; }&#10;</code></pre>
<h2 id="generate-presigned-urls">Generate presigned URLs</h2>
<p>You can also generate presigned links which allow you to share public access to a file temporarily.</p>
<pre tabindex="0"><code class="language-sh">&#35; You can pass the --expires-in flag to determine how long the presigned link is valid.&#10;aws s3 presign --endpoint-url https://&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com  s3://my-bucket/ferriswasm.png --expires-in 3600&#10;&#35; https://&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com/my-bucket/ferriswasm.png?X-Amz-Algorithm=AWS4-HMAC-SHA256&amp;X-Amz-Credential=&lt;credential&gt;&amp;X-Amz-Date=&lt;timestamp&gt;&amp;X-Amz-Expires=3600&amp;X-Amz-SignedHeaders=host&amp;X-Amz-Signature=&lt;signature&gt;&#10;</code></pre>
