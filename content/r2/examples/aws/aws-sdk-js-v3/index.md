<h2 id="generate-presigned-urls">Generate presigned URLs</h2>
<p>You can also generate presigned links that can be used to share public read or write access to a bucket temporarily.</p>
<pre tabindex="0"><code class="language-ts">import { getSignedUrl } from &quot;@aws-sdk/s3-request-presigner&quot;;&#10;&#10;// Use the expiresIn property to determine how long the presigned link is valid.&#10;console.log(&#10;	await getSignedUrl(&#10;		S3,&#10;		new GetObjectCommand({ Bucket: &quot;my-bucket&quot;, Key: &quot;dog.png&quot; }),&#10;		{ expiresIn: 3600 },&#10;	),&#10;);&#10;// You can also create links for operations such as PutObject to allow temporary write access to a specific key.&#10;// Specify ContentType to restrict uploads to a specific file type.&#10;console.log(&#10;	await getSignedUrl(&#10;		S3,&#10;		new PutObjectCommand({&#10;			Bucket: &quot;my-bucket&quot;,&#10;			Key: &quot;dog.png&quot;,&#10;			ContentType: &quot;image/png&quot;,&#10;		}),&#10;		{ expiresIn: 3600 },&#10;	),&#10;);&#10;</code></pre>
<pre tabindex="0"><code class="language-sh">https://my-bucket.&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com/dog.png?X-Amz-Algorithm=AWS4-HMAC-SHA256&amp;X-Amz-Content-Sha256=UNSIGNED-PAYLOAD&amp;X-Amz-Credential=&lt;credential&gt;&amp;X-Amz-Date=&lt;timestamp&gt;&amp;X-Amz-Expires=3600&amp;X-Amz-SignedHeaders=host&amp;X-Amz-Signature=&lt;signature&gt;&amp;x-id=GetObject&#10;https://my-bucket.&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com/dog.png?X-Amz-Algorithm=AWS4-HMAC-SHA256&amp;X-Amz-Content-Sha256=UNSIGNED-PAYLOAD&amp;X-Amz-Credential=&lt;credential&gt;&amp;X-Amz-Date=&lt;timestamp&gt;&amp;X-Amz-Expires=3600&amp;X-Amz-SignedHeaders=content-type%3Bhost&amp;X-Amz-Signature=&lt;signature&gt;&amp;x-id=PutObject&#10;</code></pre>
<p>You can use the link generated by the <code>PutObject</code> example to upload to the specified bucket and key, until the presigned link expires. When using a presigned URL with <code>ContentType</code>, the client must include a matching <code>Content-Type</code> header in the request.</p>
<pre tabindex="0"><code class="language-sh">curl -X PUT &quot;https://my-bucket.&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com/dog.png?X-Amz-Algorithm=...&quot; \&#10;  &#45;H &quot;Content-Type: image/png&quot; \&#10;  &#45;-data-binary @dog.png&#10;</code></pre>
<h2 id="restrict-uploads-with-cors-and-content-type">Restrict uploads with CORS and Content-Type</h2>
<p>When generating presigned URLs for uploads, you can limit abuse and misuse by:</p>
<ol>
<li>
<p><strong>Restricting Content-Type</strong>: Specify the allowed content type in the <code>PutObjectCommand</code>. The upload will fail if the client sends a different <code>Content-Type</code> header.</p>
</li>
<li>
<p><strong>Configuring CORS</strong>: Set up <a href="/r2/buckets/cors/#add-cors-policies-from-the-dashboard">CORS rules</a> on your bucket to control which origins can upload files. Configure CORS via the <a href="https://dash.cloudflare.com/?to=/:account/r2/overview">Cloudflare dashboard</a> by adding a JSON policy to your bucket settings:</p>
</li>
</ol>
<pre tabindex="0"><code class="language-json">[&#10;  {&#10;    &quot;AllowedOrigins&quot;: [&quot;https://example.com&quot;],&#10;    &quot;AllowedMethods&quot;: [&quot;PUT&quot;],&#10;    &quot;AllowedHeaders&quot;: [&quot;Content-Type&quot;],&#10;    &quot;ExposeHeaders&quot;: [&quot;ETag&quot;],&#10;    &quot;MaxAgeSeconds&quot;: 3600&#10;  }&#10;]&#10;</code></pre>
<p>Then generate a presigned URL with a Content-Type restriction:</p>
<pre tabindex="0"><code class="language-ts">const putUrl = await getSignedUrl(&#10;	S3,&#10;	new PutObjectCommand({&#10;		Bucket: &quot;my-bucket&quot;,&#10;		Key: &quot;dog.png&quot;,&#10;		ContentType: &quot;image/png&quot;,&#10;	}),&#10;	{ expiresIn: 3600 },&#10;);&#10;</code></pre>
<p>When a client uses this presigned URL, they must:</p>
<ul>
<li>Make the request from an allowed origin (enforced by CORS)</li>
<li>Include the <code>Content-Type: image/png</code> header (enforced by the signature)</li>
</ul>
