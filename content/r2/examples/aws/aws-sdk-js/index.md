<p>You must <a href="/r2/api/tokens/">generate an Access Key</a> before getting started. All examples will utilize <code>access_key_id</code> and <code>access_key_secret</code> variables which represent the <strong>Access Key ID</strong> and <strong>Secret Access Key</strong> values you generated.</p>
<br />
<p>If you are interested in the newer version of the AWS JavaScript SDK visit this <a href="/r2/examples/aws/aws-sdk-js-v3/">dedicated aws-sdk-js-v3 example page</a>.</p>
<p>JavaScript or TypeScript users may continue to use the <a href="https://www.npmjs.com/package/aws-sdk"><code>aws-sdk</code></a> npm package as per normal. You must pass in the R2 configuration credentials when instantiating your <code>S3</code> service client:</p>
<pre><code class="language-ts">import S3 from &quot;aws-sdk/clients/s3.js&quot;;&#10;&#10;const s3 = new S3({&#10;	// Provide your Cloudflare account ID&#10;	endpoint: `https://${ACCOUNT_ID}.r2.cloudflarestorage.com`,&#10;	// Retrieve your S3 API credentials for your R2 bucket via API tokens (see: https://developers.cloudflare.com/r2/api/tokens)&#10;	accessKeyId: `${ACCESS_KEY_ID}`,&#10;	secretAccessKey: `${SECRET_ACCESS_KEY}`,&#10;	signatureVersion: &quot;v4&quot;,&#10;});&#10;&#10;console.log(await s3.listBuckets().promise());&#10;//=&gt; {&#10;//=&gt;   Buckets: [&#10;//=&gt;     { Name: &#x27;user-uploads&#x27;, CreationDate: 2022-04-13T21:23:47.102Z },&#10;//=&gt;     { Name: &#x27;my-bucket&#x27;, CreationDate: 2022-05-07T02:46:49.218Z }&#10;//=&gt;   ],&#10;//=&gt;   Owner: {&#10;//=&gt;     DisplayName: &#x27;...&#x27;,&#10;//=&gt;     ID: &#x27;...&#x27;&#10;//=&gt;   }&#10;//=&gt; }&#10;&#10;console.log(await s3.listObjects({ Bucket: &quot;my-bucket&quot; }).promise());&#10;//=&gt; {&#10;//=&gt;   IsTruncated: false,&#10;//=&gt;   Name: &#x27;my-bucket&#x27;,&#10;//=&gt;   CommonPrefixes: [],&#10;//=&gt;   MaxKeys: 1000,&#10;//=&gt;   Contents: [&#10;//=&gt;     {&#10;//=&gt;       Key: &#x27;cat.png&#x27;,&#10;//=&gt;       LastModified: 2022-05-07T02:50:45.616Z,&#10;//=&gt;       ETag: &#x27;&quot;c4da329b38467509049e615c11b0c48a&quot;&#x27;,&#10;//=&gt;       ChecksumAlgorithm: [],&#10;//=&gt;       Size: 751832,&#10;//=&gt;       Owner: [Object]&#10;//=&gt;     },&#10;//=&gt;     {&#10;//=&gt;       Key: &#x27;todos.txt&#x27;,&#10;//=&gt;       LastModified: 2022-05-07T21:37:17.150Z,&#10;//=&gt;       ETag: &#x27;&quot;29d911f495d1ba7cb3a4d7d15e63236a&quot;&#x27;,&#10;//=&gt;       ChecksumAlgorithm: [],&#10;//=&gt;       Size: 279,&#10;//=&gt;       Owner: [Object]&#10;//=&gt;     }&#10;//=&gt;   ]&#10;//=&gt; }&#10;</code></pre>
<h2 id="generate-presigned-urls">Generate presigned URLs</h2>
<p>You can also generate presigned links that can be used to share public read or write access to a bucket temporarily.</p>
<pre><code class="language-ts">// Use the expires property to determine how long the presigned link is valid.&#10;console.log(&#10;await s3.getSignedUrlPromise(&quot;getObject&quot;, {&#10;	Bucket: &quot;my-bucket&quot;,&#10;	Key: &quot;dog.png&quot;,&#10;	Expires: 3600,&#10;}),&#10;);&#10;// You can also create links for operations such as putObject to allow temporary write access to a specific key.&#10;// Specify ContentType to restrict uploads to a specific file type.&#10;console.log(&#10;	await s3.getSignedUrlPromise(&quot;putObject&quot;, {&#10;		Bucket: &quot;my-bucket&quot;,&#10;		Key: &quot;dog.png&quot;,&#10;		Expires: 3600,&#10;		ContentType: &quot;image/png&quot;,&#10;	}),&#10;);&#10;</code></pre>
<pre><code class="language-sh">https://my-bucket.&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com/dog.png?X-Amz-Algorithm=AWS4-HMAC-SHA256&amp;X-Amz-Credential=&lt;credential&gt;&amp;X-Amz-Date=&lt;timestamp&gt;&amp;X-Amz-Expires=3600&amp;X-Amz-SignedHeaders=host&amp;X-Amz-Signature=&lt;signature&gt;&#10;https://my-bucket.&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com/dog.png?X-Amz-Algorithm=AWS4-HMAC-SHA256&amp;X-Amz-Credential=&lt;credential&gt;&amp;X-Amz-Date=&lt;timestamp&gt;&amp;X-Amz-Expires=3600&amp;X-Amz-SignedHeaders=content-type%3Bhost&amp;X-Amz-Signature=&lt;signature&gt;&#10;</code></pre>
<p>You can use the link generated by the <code>putObject</code> example to upload to the specified bucket and key, until the presigned link expires. When using a presigned URL with <code>ContentType</code>, the client must include a matching <code>Content-Type</code> header in the request.</p>
<pre><code class="language-sh">curl -X PUT &quot;https://my-bucket.&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com/dog.png?X-Amz-Algorithm=...&quot; \&#10;  &#45;H &quot;Content-Type: image/png&quot; \&#10;  &#45;-data-binary @dog.png&#10;</code></pre>
<h2 id="restrict-uploads-with-cors-and-content-type">Restrict uploads with CORS and Content-Type</h2>
<p>When generating presigned URLs for uploads, you can limit abuse and misuse by:</p>
<ol>
<li>
<p><strong>Restricting Content-Type</strong>: Specify the allowed content type in the presigned URL parameters. The upload will fail if the client sends a different <code>Content-Type</code> header.</p>
</li>
<li>
<p><strong>Configuring CORS</strong>: Set up <a href="/r2/buckets/cors/#add-cors-policies-from-the-dashboard">CORS rules</a> on your bucket to control which origins can upload files. Configure CORS via the <a href="https://dash.cloudflare.com/?to=/:account/r2/overview">Cloudflare dashboard</a> by adding a JSON policy to your bucket settings:</p>
</li>
</ol>
<pre><code class="language-json">[&#10;  {&#10;    &quot;AllowedOrigins&quot;: [&quot;https://example.com&quot;],&#10;    &quot;AllowedMethods&quot;: [&quot;PUT&quot;],&#10;    &quot;AllowedHeaders&quot;: [&quot;Content-Type&quot;],&#10;    &quot;ExposeHeaders&quot;: [&quot;ETag&quot;],&#10;    &quot;MaxAgeSeconds&quot;: 3600&#10;  }&#10;]&#10;</code></pre>
<p>Then generate a presigned URL with a Content-Type restriction:</p>
<pre><code class="language-ts">const putUrl = await s3.getSignedUrlPromise(&quot;putObject&quot;, {&#10;	Bucket: &quot;my-bucket&quot;,&#10;	Key: &quot;user-upload.png&quot;,&#10;	Expires: 3600,&#10;	ContentType: &quot;image/png&quot;,&#10;});&#10;</code></pre>
<p>When a client uses this presigned URL, they must:</p>
<ul>
<li>Make the request from an allowed origin (enforced by CORS)</li>
<li>Include the <code>Content-Type: image/png</code> header (enforced by the signature)</li>
</ul>
