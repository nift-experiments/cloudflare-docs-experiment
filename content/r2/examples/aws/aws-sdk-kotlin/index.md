<p>You must <a href="/r2/api/tokens/">generate an Access Key</a> before getting started. All examples will utilize <code>access_key_id</code> and <code>access_key_secret</code> variables which represent the <strong>Access Key ID</strong> and <strong>Secret Access Key</strong> values you generated.</p>
<br />
<p>This example uses the <a href="https://github.com/aws/aws-sdk-kotlin">aws-sdk-kotlin</a>. You must pass in the R2 configuration credentials when instantiating your <code>S3</code> client:</p>
<h2 id="basic-usage">Basic Usage</h2>
<pre><code class="language-kotlin">import aws.sdk.kotlin.runtime.auth.credentials.StaticCredentialsProvider&#10;import aws.sdk.kotlin.services.s3.S3Client&#10;import aws.sdk.kotlin.services.s3.listObjects&#10;import aws.sdk.kotlin.services.s3.model.GetObjectRequest&#10;import aws.sdk.kotlin.services.s3.model.PutObjectRequest&#10;import aws.sdk.kotlin.services.s3.presigners.presignGetObject&#10;import aws.sdk.kotlin.services.s3.presigners.presignPutObject&#10;import aws.smithy.kotlin.runtime.auth.awscredentials.Credentials&#10;import aws.smithy.kotlin.runtime.net.url.Url&#10;import kotlinx.coroutines.runBlocking&#10;import kotlin.time.Duration.Companion.minutes&#10;&#10;val ACCOUNT_ID = &quot;&lt;ACCOUNT_ID&gt;&quot;&#10;val ACCESS_KEY = &quot;&lt;ACCESS_KEY&gt;&quot;&#10;val SECRET_KEY = &quot;&lt;SECRET_KEY&gt;&quot;&#10;&#10;fun main() = runBlocking {&#10;    val r2Client = S3Client.fromEnvironment {&#10;        region = &quot;auto&quot; // Required by SDK, but not used by R2&#10;        endpointUrl = Url.parse(&quot;https://${ACCOUNT_ID}.r2.cloudflarestorage.com&quot;)&#10;        credentialsProvider = StaticCredentialsProvider(&#10;            Credentials(&#10;                accessKeyId = ACCESS_KEY,&#10;                secretAccessKey = SECRET_KEY&#10;            ),&#10;        )&#10;    }&#10;&#10;    println(&quot;Available buckets:&quot;)&#10;    r2Client.listBuckets().buckets?.forEach { bucket -&gt;&#10;        println(&quot;* ${bucket.name}&quot;)&#10;    }&#10;&#10;    val bucketName = &quot;&lt;BUCKET_NAME&gt;&quot;&#10;    println(&quot;\nObjects in bucket &#x27;${bucketName}&#x27;:&quot;)&#10;    r2Client.listObjects { bucket = bucketName }.contents?.forEach {&#10;        println(&quot;* ${it.key} (size: ${it.size} bytes, modified: ${it.lastModified})&quot;)&#10;    }&#10;&#10;    r2Client.close()&#10;}&#10;</code></pre>

<h2 id="generate-presigned-urls">Generate presigned URLs</h2>
<p>You can also generate presigned links that can be used to temporarily share public read or write access to a bucket.</p>
<pre><code class="language-kotlin">val uploadUrl = r2Client.presignPutObject(&#10;    input = PutObjectRequest {&#10;        bucket = bucketName&#10;        key = &quot;README.md&quot;&#10;    },&#10;    duration = 15.minutes,&#10;).url&#10;println(uploadUrl)&#10;&#10;val getUrl = r2Client.presignGetObject(&#10;    input = GetObjectRequest {&#10;        bucket = bucketName&#10;        key = &quot;README.md&quot;&#10;    },&#10;    duration = 15.minutes,&#10;).url&#10;println(getUrl)&#10;</code></pre>
<p>You can use these presigned URLs with any HTTP client. For example, to upload a file using the PUT URL:</p>
<pre><code class="language-bash">curl -X PUT &quot;https://&lt;your-presigned-put-url&gt;&quot; -H &quot;Content-Type: application/octet-stream&quot; --data-binary &quot;@local-file.txt&quot;&#10;</code></pre>
<p>To download a file using the GET URL:</p>
<pre><code class="language-bash">curl -X GET &quot;https://&lt;your-presigned-get-url&gt;&quot; -o downloaded-file.txt&#10;</code></pre>
