<p>You must <a href="/r2/api/tokens/">generate an Access Key</a> before getting started. All examples will utilize <code>access_key_id</code> and <code>access_key_secret</code> variables which represent the <strong>Access Key ID</strong> and <strong>Secret Access Key</strong> values you generated.</p>
<br />
<p>This example uses version 3 of the <a href="https://www.nuget.org/packages/AWSSDK.S3">aws-sdk-net</a> package. You must pass in the R2 configuration credentials when instantiating your <code>S3</code> service client:</p>
<h2 id="client-setup">Client setup</h2>
<p>In this example, you will pass credentials explicitly to the <code>IAmazonS3</code> initialization. If you wish, use a shared AWS credentials file or the SDK store in-line with other AWS SDKs. Refer to <a href="https://docs.aws.amazon.com/sdk-for-net/v3/developer-guide/net-dg-config-creds.html">Configure AWS credentials</a> for more details.</p>
<pre tabindex="0"><code class="language-csharp">private static IAmazonS3 s3Client;&#10;&#10;public static void Main(string[] args)&#10;{&#10;	// Retrieve your S3 API credentials for your R2 bucket via API tokens (see: https://developers.cloudflare.com/r2/api/tokens)&#10;	var accessKey = &quot;&lt;ACCESS_KEY_ID&gt;&quot;;&#10;	var secretKey = &quot;&lt;SECRET_ACCESS_KEY&gt;&quot;;&#10;	var credentials = new BasicAWSCredentials(accessKey, secretKey);&#10;	s3Client = new AmazonS3Client(credentials, new AmazonS3Config&#10;		{&#10;			// Provide your Cloudflare account ID&#10;			ServiceURL = &quot;https://&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com&quot;,&#10;		});&#10;}&#10;</code></pre>
<h2 id="list-buckets-and-objects">List buckets and objects</h2>
<p>The <a href="https://docs.aws.amazon.com/sdkfornet/v3/apidocs/items/S3/MIS3ListBucketsAsyncListBucketsRequestCancellationToken.html">ListBucketsAsync</a> and <a href="https://docs.aws.amazon.com/sdkfornet/v3/apidocs/items/S3/MIS3ListObjectsV2AsyncListObjectsV2RequestCancellationToken.html">ListObjectsAsync</a> methods can be used to list buckets under your account and the contents of those buckets respectively.</p>

<h2 id="generate-presigned-urls">Generate presigned URLs</h2>
<p>The <a href="https://docs.aws.amazon.com/sdkfornet/v3/apidocs/items/S3/MIS3GetPreSignedURLGetPreSignedUrlRequest.html">GetPreSignedURL</a> method allows you to sign ahead of time, giving temporary access to a specific operation. In this case, presigning a <code>PutObject</code> request for <code>sdk-example/file.txt</code>.</p>
<pre tabindex="0"><code class="language-csharp">static string? GeneratePresignedUrl()&#10;{&#10;	AWSConfigsS3.UseSignatureVersion4 = true;&#10;	var presign = new GetPreSignedUrlRequest&#10;	{&#10;		BucketName = &quot;my-bucket&quot;,&#10;		Key = &quot;file.txt&quot;,&#10;		Verb = HttpVerb.GET,&#10;		Expires = DateTime.Now.AddDays(7),&#10;	};&#10;&#10;	var presignedUrl = s3Client.GetPreSignedURL(presign);&#10;&#10;	Console.WriteLine(presignedUrl);&#10;&#10;	return presignedUrl;&#10;}&#10;</code></pre>
