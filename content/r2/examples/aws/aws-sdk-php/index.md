<p class="article-summary">Example of how to configure `aws-sdk-php` to use R2.</p>
<p>You must <a href="/r2/api/tokens/">generate an Access Key</a> before getting started. All examples will utilize <code>access_key_id</code> and <code>access_key_secret</code> variables which represent the <strong>Access Key ID</strong> and <strong>Secret Access Key</strong> values you generated.</p>
<br />
<p>This example uses version 3 of the <a href="https://packagist.org/packages/aws/aws-sdk-php">aws-sdk-php</a> package. You must pass in the R2 configuration credentials when instantiating your <code>S3</code> service client:</p>

<h2 id="generate-presigned-urls">Generate presigned URLs</h2>
<p>You can also generate presigned links that can be used to share public read or write access to a bucket temporarily.</p>
<pre><code class="language-php">$cmd = $s3_client-&gt;getCommand(&#x27;GetObject&#x27;, [&#10;    &#x27;Bucket&#x27; =&gt; $bucket_name,&#10;    &#x27;Key&#x27; =&gt; &#x27;ferriswasm.png&#x27;&#10;]);&#10;&#10;// The second parameter allows you to determine how long the presigned link is valid.&#10;$request = $s3_client-&gt;createPresignedRequest($cmd, &#x27;+1 hour&#x27;);&#10;&#10;print_r((string)$request-&gt;getUri());&#10;// https://my-bucket.&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com/ferriswasm.png?X-Amz-Content-Sha256=UNSIGNED-PAYLOAD&amp;X-Amz-Algorithm=AWS4-HMAC-SHA256&amp;X-Amz-Credential=&lt;credential&gt;&amp;X-Amz-Date=&lt;timestamp&gt;&amp;X-Amz-SignedHeaders=host&amp;X-Amz-Expires=3600&amp;X-Amz-Signature=&lt;signature&gt;&#10;&#10;// You can also create links for operations such as putObject to allow temporary write access to a specific key.&#10;$cmd = $s3_client-&gt;getCommand(&#x27;PutObject&#x27;, [&#10;    &#x27;Bucket&#x27; =&gt; $bucket_name,&#10;    &#x27;Key&#x27; =&gt; &#x27;ferriswasm.png&#x27;&#10;]);&#10;&#10;$request = $s3_client-&gt;createPresignedRequest($cmd, &#x27;+1 hour&#x27;);&#10;&#10;print_r((string)$request-&gt;getUri());&#10;</code></pre>
<p>You can use the link generated by the <code>putObject</code> example to upload to the specified bucket and key, until the presigned link expires.</p>
<pre><code class="language-sh">curl -X PUT &quot;https://my-bucket.&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com/ferriswasm.png?X-Amz-Content-Sha256=UNSIGNED-PAYLOAD&amp;X-Amz-Algorithm=AWS4-HMAC-SHA256&amp;X-Amz-Credential=&lt;credential&gt;&amp;X-Amz-Date=&lt;timestamp&gt;&amp;X-Amz-SignedHeaders=host&amp;X-Amz-Expires=3600&amp;X-Amz-Signature=&lt;signature&gt;&quot; --data-binary @ferriswasm.png&#10;</code></pre>
