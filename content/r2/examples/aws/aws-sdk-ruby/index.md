<p>You must <a href="/r2/api/tokens/">generate an Access Key</a> before getting started. All examples will utilize <code>access_key_id</code> and <code>access_key_secret</code> variables which represent the <strong>Access Key ID</strong> and <strong>Secret Access Key</strong> values you generated.</p>
<br />
<p>Many Ruby projects also store these credentials in environment variables instead.</p>
<p>Add the following dependency to your <code>Gemfile</code>:</p>
<pre><code class="language-ruby">gem &quot;aws-sdk-s3&quot;&#10;</code></pre>
<p>Then you can use Ruby to operate on R2 buckets:</p>
<pre><code class="language-ruby">require &quot;aws-sdk-s3&quot;&#10;&#10;@r2 = Aws::S3::Client.new(&#10;  &#35; Retrieve your S3 API credentials for your R2 bucket via API tokens (see: https://developers.cloudflare.com/r2/api/tokens)&#10;  access_key_id: &quot;#{ACCESS_KEY_ID}&quot;,&#10;  secret_access_key: &quot;#{SECRET_ACCESS_KEY}&quot;,&#10;  &#35; Provide your Cloudflare account ID&#10;  endpoint: &quot;https://#{ACCOUNT_ID}.r2.cloudflarestorage.com&quot;,&#10;  region: &quot;auto&quot;, # Required by SDK but not used by R2&#10;)&#10;&#10;&#35; List all buckets on your account&#10;puts @r2.list_buckets&#10;&#10;&#35;=&gt; {&#10;&#35;=&gt;   :buckets =&gt; [{&#10;&#35;=&gt;     :name =&gt; &quot;your-bucket&quot;,&#10;&#35;=&gt;     :creation_date =&gt; &quot;…&quot;,&#10;&#35;=&gt;   }],&#10;&#35;=&gt;   :owner =&gt; {&#10;&#35;=&gt;     :display_name =&gt; &quot;…&quot;,&#10;&#35;=&gt;     :id =&gt; &quot;…&quot;&#10;&#35;=&gt;   }&#10;&#35;=&gt; }&#10;&#10;&#35; List the first 20 items in a bucket&#10;puts @r2.list_objects_v2(bucket: &quot;your-bucket&quot;, max_keys: 20)&#10;&#10;&#35;=&gt; {&#10;&#35;=&gt;   :is_truncated =&gt; false,&#10;&#35;=&gt;   :name =&gt; &quot;your-bucket&quot;,&#10;&#35;=&gt;   :prefix =&gt; nil,&#10;&#35;=&gt;   :delimiter =&gt; nil,&#10;&#35;=&gt;   :max_keys =&gt; 20,&#10;&#35;=&gt;   :common_prefixes =&gt; [],&#10;&#35;=&gt;   :encoding_type =&gt; nil,&#10;&#35;=&gt;   :key_count =&gt; 3,&#10;&#35;=&gt;   :contents =&gt; [&#10;&#35;=&gt;     …,&#10;&#35;=&gt;     …,&#10;&#35;=&gt;     …,&#10;&#35;=&gt;   ]&#10;&#35;=&gt; }&#10;</code></pre>
