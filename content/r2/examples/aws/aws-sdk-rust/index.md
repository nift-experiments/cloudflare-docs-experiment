<p>You must <a href="/r2/api/tokens/">generate an Access Key</a> before getting started. All examples will utilize <code>access_key_id</code> and <code>access_key_secret</code> variables which represent the <strong>Access Key ID</strong> and <strong>Secret Access Key</strong> values you generated.</p>
<br />
<p>This example uses the <a href="https://crates.io/crates/aws-sdk-s3">aws-sdk-s3</a> crate from the <a href="https://github.com/awslabs/aws-sdk-rust">AWS SDK for Rust</a>. You must pass in the R2 configuration credentials when instantiating your <code>S3</code> client:</p>
<h2 id="basic-usage">Basic Usage</h2>
<pre tabindex="0"><code class="language-rust">use aws_sdk_s3 as s3;&#10;use aws_smithy_types::date_time::Format::DateTime;&#10;&#10;&#35;[tokio::main]&#10;async fn main() -&gt; Result&lt;(), s3::Error&gt; {&#10;    let bucket_name = &quot;sdk-example&quot;;&#10;    // Provide your Cloudflare account ID&#10;    let account_id = &quot;&lt;ACCOUNT_ID&gt;&quot;;&#10;    // Retrieve your S3 API credentials for your R2 bucket via API tokens&#10;    // (see: https://developers.cloudflare.com/r2/api/tokens)&#10;    let access_key_id = &quot;&lt;ACCESS_KEY_ID&gt;&quot;;&#10;    let access_key_secret = &quot;&lt;SECRET_ACCESS_KEY&gt;&quot;;&#10;&#10;    // Configure the client&#10;    let config = aws_config::from_env()&#10;        .endpoint_url(format!(&quot;https://{}.r2.cloudflarestorage.com&quot;, account_id))&#10;        .credentials_provider(aws_sdk_s3::config::Credentials::new(&#10;            access_key_id,&#10;            access_key_secret,&#10;            None, // session token is not used with R2&#10;            None,&#10;            &quot;R2&quot;,&#10;        ))&#10;        .region(&quot;auto&quot;) // Required by SDK but not used by R2&#10;        .load()&#10;        .await;&#10;&#10;    let client = s3::Client::new(&amp;config);&#10;&#10;    // List buckets&#10;    let list_buckets_output = client.list_buckets().send().await?;&#10;&#10;    println!(&quot;Buckets:&quot;);&#10;    for bucket in list_buckets_output.buckets() {&#10;        println!(&quot;  - {}: {}&quot;,&#10;            bucket.name().unwrap_or_default(),&#10;            bucket.creation_date().map_or_else(&#10;                || &quot;Unknown creation date&quot;.to_string(),&#10;                |date| date.fmt(DateTime).unwrap()&#10;            )&#10;        );&#10;    }&#10;&#10;    // List objects in a specific bucket&#10;    let list_objects_output = client&#10;        .list_objects_v2()&#10;        .bucket(bucket_name)&#10;        .send()&#10;        .await?;&#10;&#10;    println!(&quot;\nObjects in {}:&quot;, bucket_name);&#10; <h2 id="upload-objects">Upload Objects</h2>
<p>To upload an object to R2:</p>
<pre tabindex="0"><code class="language-rust">use aws_sdk_s3::primitives::ByteStream;&#10;use std::path::Path;&#10;&#10;async fn upload_object(&#10;    client: &amp;s3::Client,&#10;    bucket: &amp;str,&#10;    key: &amp;str,&#10;    file_path: &amp;str,&#10;) -&gt; Result&lt;(), s3::Error&gt; {&#10;    let body = ByteStream::from_path(Path::new(file_path)).await.unwrap();&#10;&#10;    client&#10;        .put_object()&#10;        .bucket(bucket)&#10;        .key(key)&#10;        .body(body)&#10;        .send()&#10;        .await?;&#10;&#10;    println!(&quot;Uploaded {} to {}/{}&quot;, file_path, bucket, key);&#10;    Ok(())&#10;}&#10;</code></pre>
<h2 id="download-objects">Download Objects</h2>
<p>To download an object from R2:</p>
<pre tabindex="0"><code class="language-rust">use std::fs;&#10;use std::io::Write;&#10;&#10;async fn download_object(&#10;    client: &amp;s3::Client,&#10;    bucket: &amp;str,&#10;    key: &amp;str,&#10;    output_path: &amp;str,&#10;) -&gt; Result&lt;(), Box&lt;dyn std::error::Error&gt;&gt; {&#10;    let resp = client&#10;        .get_object()&#10;        .bucket(bucket)&#10;        .key(key)&#10;        .send()&#10;        .await?;&#10;&#10;    let data = resp.body.collect().await?;&#10;    let bytes = data.into_bytes();&#10;&#10;    let mut file = fs::File::create(output_path)?;&#10;    file.write_all(&amp;bytes)?;&#10;&#10;    println!(&quot;Downloaded {}/{} to {}&quot;, bucket, key, output_path);&#10;    Ok(())&#10;}&#10;</code></pre>
<h2 id="generate-presigned-urls">Generate Presigned URLs</h2>
<p>You can also generate presigned links that can be used to temporarily share public read or write access to a bucket.</p>
<pre tabindex="0"><code class="language-rust">use aws_sdk_s3::presigning::PresigningConfig;&#10;use std::time::Duration;&#10;&#10;async fn generate_get_presigned_url(&#10;    client: &amp;s3::Client,&#10;    bucket: &amp;str,&#10;    key: &amp;str,&#10;    expires_in: Duration,&#10;) -&gt; Result&lt;String, s3::Error&gt; {&#10;    let presigning_config = PresigningConfig::expires_in(expires_in)?;&#10;&#10;    // Generate a presigned URL for GET (download)&#10;    let presigned_get_request = client&#10;        .get_object()&#10;        .bucket(bucket)&#10;        .key(key)&#10;        .presigned(presigning_config)&#10;        .await?;&#10;&#10;    Ok(presigned_get_request.uri().to_string())&#10;}&#10;&#10;async fn generate_upload_presigned_url(&#10;    client: &amp;s3::Client,&#10;    bucket: &amp;str,&#10;    key: &amp;str,&#10;    expires_in: Duration,&#10;) -&gt; Result&lt;String, s3::Error&gt; {&#10;    let presigning_config = PresigningConfig::expires_in(expires_in)?;&#10;&#10;    // Generate a presigned URL for PUT (upload)&#10;    let presigned_put_request = client&#10;        .put_object()&#10;        .bucket(bucket)&#10;        .key(key)&#10;        .presigned(presigning_config)&#10;        .await?;&#10;&#10;    Ok(presigned_put_request.uri().to_string())&#10;}&#10;</code></pre>
<p>You can use these presigned URLs with any HTTP client. For example, to upload a file using the PUT URL:</p>
<pre tabindex="0"><code class="language-bash">curl -X PUT &quot;https://&lt;your-presigned-put-url&gt;&quot; -H &quot;Content-Type: application/octet-stream&quot; --data-binary &quot;@local-file.txt&quot;&#10;</code></pre>
<p>To download a file using the GET URL:</p>
<pre tabindex="0"><code class="language-bash">curl -X GET &quot;https://&lt;your-presigned-get-url&gt;&quot; -o downloaded-file.txt&#10;</code></pre>
