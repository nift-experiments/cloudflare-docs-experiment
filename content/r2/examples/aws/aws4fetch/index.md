<p>You must <a href="/r2/api/tokens/">generate an Access Key</a> before getting started. All examples will utilize <code>access_key_id</code> and <code>access_key_secret</code> variables which represent the <strong>Access Key ID</strong> and <strong>Secret Access Key</strong> values you generated.</p>
<br />
<p>JavaScript or TypeScript users may continue to use the <a href="https://www.npmjs.com/package/aws4fetch"><code>aws4fetch</code></a> npm package as per normal. This package uses the <code>fetch</code> and <code>SubtleCrypto</code> APIs which you will be familiar with when working in browsers or with Cloudflare Workers.</p>
<p>You must pass in the R2 configuration credentials when instantiating your <code>S3</code> service client:</p>
<pre><code class="language-ts">import { AwsClient } from &quot;aws4fetch&quot;;&#10;&#10;// Provide your Cloudflare account ID&#10;const R2_URL = `https://${ACCOUNT_ID}.r2.cloudflarestorage.com`;&#10;&#10;const client = new AwsClient({&#10;	// Retrieve your S3 API credentials for your R2 bucket via API tokens (see: https://developers.cloudflare.com/r2/api/tokens)&#10;	accessKeyId: ACCESS_KEY_ID,&#10;	secretAccessKey: SECRET_ACCESS_KEY,&#10;});&#10;&#10;const ListBucketsResult = await client.fetch(R2_URL);&#10;console.log(await ListBucketsResult.text());&#10;// &lt;ListAllMyBucketsResult&gt;&#10;//     &lt;Buckets&gt;&#10;//         &lt;Bucket&gt;&#10;//             &lt;CreationDate&gt;2022-04-13T21:23:47.102Z&lt;/CreationDate&gt;&#10;//             &lt;Name&gt;user-uploads&lt;/Name&gt;&#10;//         &lt;/Bucket&gt;&#10;//         &lt;Bucket&gt;&#10;//             &lt;CreationDate&gt;2022-05-07T02:46:49.218Z&lt;/CreationDate&gt;&#10;//             &lt;Name&gt;my-bucket&lt;/Name&gt;&#10;//         &lt;/Bucket&gt;&#10;//     &lt;/Buckets&gt;&#10;//     &lt;Owner&gt;&#10;//         &lt;DisplayName&gt;...&lt;/DisplayName&gt;&#10;//         &lt;ID&gt;...&lt;/ID&gt;&#10;//     &lt;/Owner&gt;&#10;// &lt;/ListAllMyBucketsResult&gt;&#10;&#10;const ListObjectsV2Result = await client.fetch(&#10;	`${R2_URL}/my-bucket?list-type=2`,&#10;);&#10;console.log(await ListObjectsV2Result.text());&#10;// &lt;ListBucketResult&gt;&#10;//   &lt;Name&gt;my-bucket&lt;/Name&gt;&#10;//   &lt;Contents&gt;&#10;//     &lt;Key&gt;cat.png&lt;/Key&gt;&#10;//     &lt;Size&gt;751832&lt;/Size&gt;&#10;//     &lt;LastModified&gt;2022-05-07T02:50:45.616Z&lt;/LastModified&gt;&#10;//     &lt;ETag&gt;&quot;c4da329b38467509049e615c11b0c48a&quot;&lt;/ETag&gt;&#10;//     &lt;StorageClass&gt;STANDARD&lt;/StorageClass&gt;&#10;//   &lt;/Contents&gt;&#10;//   &lt;Contents&gt;&#10;//     &lt;Key&gt;todos.txt&lt;/Key&gt;&#10;//     &lt;Size&gt;278&lt;/Size&gt;&#10;//     &lt;LastModified&gt; <h2 id="generate-presigned-urls">Generate presigned URLs</h2>
<p>You can also generate presigned links that can be used to share public read or write access to a bucket temporarily.</p>
<pre><code class="language-ts">import { AwsClient } from &quot;aws4fetch&quot;;&#10;&#10;const client = new AwsClient({&#10;	service: &quot;s3&quot;, // Required by SDK but not used by R2&#10;	region: &quot;auto&quot;, // Required by SDK but not used by R2&#10;	// Retrieve your S3 API credentials for your R2 bucket via API tokens (see: https://developers.cloudflare.com/r2/api/tokens)&#10;	accessKeyId: ACCESS_KEY_ID,&#10;	secretAccessKey: SECRET_ACCESS_KEY,&#10;});&#10;&#10;// Provide your Cloudflare account ID&#10;const R2_URL = `https://${ACCOUNT_ID}.r2.cloudflarestorage.com`;&#10;&#10;// Use the `X-Amz-Expires` query param to determine how long the presigned link is valid.&#10;console.log(&#10;	(&#10;		await client.sign(&#10;			new Request(`${R2_URL}/my-bucket/dog.png?X-Amz-Expires=${3600}`),&#10;			{&#10;				aws: { signQuery: true },&#10;			},&#10;		)&#10;	).url.toString(),&#10;);&#10;// You can also create links for operations such as PutObject to allow temporary write access to a specific key.&#10;// Specify Content-Type header to restrict uploads to a specific file type.&#10;console.log(&#10;	(&#10;		await client.sign(&#10;			new Request(`${R2_URL}/my-bucket/dog.png?X-Amz-Expires=${3600}`, {&#10;				method: &quot;PUT&quot;,&#10;				headers: {&#10;					&quot;Content-Type&quot;: &quot;image/png&quot;,&#10;				},&#10;			}),&#10;			{&#10;				aws: { signQuery: true },&#10;			},&#10;		)&#10;	).url.toString(),&#10;);&#10;</code></pre>
<pre><code class="language-sh">https://&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com/my-bucket/dog.png?X-Amz-Expires=3600&amp;X-Amz-Date=&lt;timestamp&gt;&amp;X-Amz-Algorithm=AWS4-HMAC-SHA256&amp;X-Amz-Credential=&lt;credential&gt;&amp;X-Amz-SignedHeaders=host&amp;X-Amz-Signature=&lt;signature&gt;&#10;https://&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com/my-bucket/dog.png?X-Amz-Expires=3600&amp;X-Amz-Date=&lt;timestamp&gt;&amp;X-Amz-Algorithm=AWS4-HMAC-SHA256&amp;X-Amz-Credential=&lt;credential&gt;&amp;X-Amz-SignedHeaders=content-type%3Bhost&amp;X-Amz-Signature=&lt;signature&gt;&#10;</code></pre>
<p>You can use the link generated by the <code>PutObject</code> example to upload to the specified bucket and key, until the presigned link expires. When using a presigned URL with <code>Content-Type</code>, the client must include a matching <code>Content-Type</code> header in the request.</p>
<pre><code class="language-sh">curl -X PUT &quot;https://&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com/my-bucket/dog.png?X-Amz-Expires=3600&amp;X-Amz-Date=&lt;timestamp&gt;&amp;X-Amz-Algorithm=AWS4-HMAC-SHA256&amp;X-Amz-Credential=&lt;credential&gt;&amp;X-Amz-SignedHeaders=content-type%3Bhost&amp;X-Amz-Signature=&lt;signature&gt;&quot; \&#10;  &#45;H &quot;Content-Type: image/png&quot; \&#10;  &#45;-data-binary @dog.png&#10;</code></pre>
<h2 id="restrict-uploads-with-cors-and-content-type">Restrict uploads with CORS and Content-Type</h2>
<p>When generating presigned URLs for uploads, you can limit abuse and misuse by:</p>
<ol>
<li>
<p><strong>Restricting Content-Type</strong>: Specify the <code>Content-Type</code> header in the request when signing. The upload will fail if the client sends a different <code>Content-Type</code> header.</p>
</li>
<li>
<p><strong>Configuring CORS</strong>: Set up <a href="/r2/buckets/cors/#add-cors-policies-from-the-dashboard">CORS rules</a> on your bucket to control which origins can upload files. Configure CORS via the <a href="https://dash.cloudflare.com/?to=/:account/r2/overview">Cloudflare dashboard</a> by adding a JSON policy to your bucket settings:</p>
</li>
</ol>
<pre><code class="language-json">[&#10;  {&#10;    &quot;AllowedOrigins&quot;: [&quot;https://example.com&quot;],&#10;    &quot;AllowedMethods&quot;: [&quot;PUT&quot;],&#10;    &quot;AllowedHeaders&quot;: [&quot;Content-Type&quot;],&#10;    &quot;ExposeHeaders&quot;: [&quot;ETag&quot;],&#10;    &quot;MaxAgeSeconds&quot;: 3600&#10;  }&#10;]&#10;</code></pre>
<p>Then generate a presigned URL with a Content-Type restriction:</p>
<pre><code class="language-ts">const signedRequest = await client.sign(&#10;	new Request(`${R2_URL}/my-bucket/user-upload.png?X-Amz-Expires=${3600}`, {&#10;		method: &quot;PUT&quot;,&#10;		headers: {&#10;			&quot;Content-Type&quot;: &quot;image/png&quot;,&#10;		},&#10;	}),&#10;	{&#10;		aws: { signQuery: true },&#10;	},&#10;);&#10;const putUrl = signedRequest.url.toString();&#10;</code></pre>
<p>When a client uses this presigned URL, they must:</p>
<ul>
<li>Make the request from an allowed origin (enforced by CORS)</li>
<li>Include the <code>Content-Type: image/png</code> header (enforced by the signature)</li>
</ul>
