<p>You must <a href="/r2/api/tokens/">generate an Access Key</a> before getting started. All examples will utilize <code>access_key_id</code> and <code>access_key_secret</code> variables which represent the <strong>Access Key ID</strong> and <strong>Secret Access Key</strong> values you generated.</p>
<br />
<p>Configure <a href="https://boto3.amazonaws.com/v1/documentation/api/latest/index.html"><code>boto3</code></a> to use your R2 endpoint:</p>
<pre tabindex="0"><code class="language-python">import boto3&#10;&#10;s3 = boto3.client(&#10;    service_name=&quot;s3&quot;,&#10;    endpoint_url=&quot;https://&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com&quot;,&#10;    aws_access_key_id=&quot;&lt;ACCESS_KEY_ID&gt;&quot;,&#10;    aws_secret_access_key=&quot;&lt;SECRET_ACCESS_KEY&gt;&quot;,&#10;    region_name=&quot;auto&quot;,&#10;)&#10;</code></pre>
<p>You can omit <code>aws_access_key_id</code> and <code>aws_secret_access_key</code> if you set the <code>AWS_ACCESS_KEY_ID</code> and <code>AWS_SECRET_ACCESS_KEY</code> <a href="https://boto3.amazonaws.com/v1/documentation/api/latest/guide/configuration.html#using-environment-variables">environment variables</a>.</p>
<p>Common operations using the client:</p>
<pre tabindex="0"><code class="language-python">&#35; Get object metadata&#10;s3.head_object(Bucket=&quot;my-bucket&quot;, Key=&quot;dog.png&quot;)&#10;&#10;&#35; Get object&#10;response = s3.get_object(Bucket=&quot;my-bucket&quot;, Key=&quot;dog.png&quot;)&#10;&#10;&#35; Upload single file&#10;with open(&quot;./dog.png&quot;, &quot;rb&quot;) as f:&#10;    s3.upload_fileobj(f, &quot;my-bucket&quot;, &quot;dog.png&quot;)&#10;&#10;&#35; Delete object&#10;s3.delete_object(Bucket=&quot;my-bucket&quot;, Key=&quot;dog.png&quot;)&#10;</code></pre>
<h2 id="optimizing-upload-performance">Optimizing upload performance</h2>
<p>For large objects (multi-GB files such as training data or video), <code>upload_fileobj</code> can become a throughput bottleneck. Its internal thread pool is limited by Python's <a href="https://en.wikipedia.org/wiki/Global_interpreter_lock">GIL</a>, and increasing <code>max_concurrency</code> via <code>TransferConfig</code> gives diminishing returns beyond ~10 threads.</p>
<p>Use the low-level multipart API with <code>ThreadPoolExecutor</code> instead:</p>
<pre tabindex="0"><code class="language-python">import boto3&#10;import math&#10;import os&#10;from concurrent.futures import ThreadPoolExecutor&#10;&#10;s3 = boto3.client(&#10;    service_name=&quot;s3&quot;,&#10;    endpoint_url=&quot;https://&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com&quot;,&#10;    aws_access_key_id=&quot;&lt;ACCESS_KEY_ID&gt;&quot;,&#10;    aws_secret_access_key=&quot;&lt;SECRET_ACCESS_KEY&gt;&quot;,&#10;    region_name=&quot;auto&quot;,&#10;)&#10;&#10;bucket = &quot;my-bucket&quot;&#10;key = &quot;large-file.bin&quot;&#10;file_path = &quot;./large-file.bin&quot;&#10;part_size = 16 * 1024 * 1024  # 16 MiB per part&#10;max_workers = 10&#10;&#10;&#35; Step 1: Create the multipart upload&#10;upload_id = None&#10;mpu = s3.create_multipart_upload(Bucket=bucket, Key=key)&#10;upload_id = mpu[&quot;UploadId&quot;]&#10;&#10;def upload_part(part_number, data):&#10;    response = s3.upload_part(&#10;        Bucket=bucket,&#10;        Key=key,&#10;        UploadId=upload_id,&#10;        PartNumber=part_number,&#10;        Body=data,&#10;    )&#10;    return {&quot;PartNumber&quot;: part_number, &quot;ETag&quot;: response[&quot;ETag&quot;]}&#10;&#10;try:&#10;    file_size = os.path.getsize(file_path)&#10;    part_count = math.ceil(file_size / part_size)&#10;&#10;    &#35; Step 2: Upload parts in parallel&#10;    with ThreadPoolExecutor(max_workers=max_workers) as pool:&#10;        futures = []&#10;        with open(file_path, &quot;rb&quot;) as f:&#10;            for i in range(part_count):&#10;                data = f.read(part_size)&#10;                futures.append(pool.submit(upload_part, i + 1, data))&#10;&#10;        parts = [future.result() for future in futures]&#10;&#10;    &#35; Step 3: Complete the upload&#10;    s3.complete_multipart_upload(&#10;        Bucket=bucket,&#10;        Key=key,&#10;        UploadId=upload_id,&#10;        MultipartUpload={&quot;Parts&quot;: parts},&#10;    )&#10;    print(&quot;Multipart upload complete.&quot;)&#10;except Exception:&#10;    if upload_id:&#10;        try:&#10;            s3.abort_multipart_upload(Bucket=bucket, Key=key, UploadId=upload_id)&#10;        except Exception:&#10;            pass&#10;    raise&#10;</code></pre>
<p>For more on multipart uploads including part size limits and lifecycle management, refer to <a href="/r2/objects/upload-objects/">Upload objects</a>.</p>
<h2 id="generate-presigned-urls">Generate presigned URLs</h2>
<p>Generate presigned links to share temporary public read or write access to a bucket.</p>
<pre tabindex="0"><code class="language-python">&#35; Generate presigned URL for reading (GET)&#10;get_url = s3.generate_presigned_url(&#10;    &quot;get_object&quot;,&#10;    Params={&quot;Bucket&quot;: &quot;my-bucket&quot;, &quot;Key&quot;: &quot;dog.png&quot;},&#10;    ExpiresIn=3600,  # Valid for 1 hour&#10;)&#10;&#10;&#35; Generate presigned URL for writing (PUT)&#10;put_url = s3.generate_presigned_url(&#10;    &quot;put_object&quot;,&#10;    Params={&#10;        &quot;Bucket&quot;: &quot;my-bucket&quot;,&#10;        &quot;Key&quot;: &quot;dog.png&quot;,&#10;        &quot;ContentType&quot;: &quot;image/png&quot;,&#10;    },&#10;    ExpiresIn=3600,&#10;)&#10;</code></pre>
<pre tabindex="0"><code class="language-txt">https://&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com/my-bucket/dog.png?X-Amz-Algorithm=AWS4-HMAC-SHA256&amp;X-Amz-Credential=...&amp;X-Amz-Date=&lt;timestamp&gt;&amp;X-Amz-Expires=3600&amp;X-Amz-SignedHeaders=host&amp;X-Amz-Signature=&lt;signature&gt;&#10;https://&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com/my-bucket/dog.png?X-Amz-Algorithm=AWS4-HMAC-SHA256&amp;X-Amz-Credential=...&amp;X-Amz-Date=&lt;timestamp&gt;&amp;X-Amz-Expires=3600&amp;X-Amz-SignedHeaders=content-type%3Bhost&amp;X-Amz-Signature=&lt;signature&gt;&#10;</code></pre>
<p>Upload using the presigned PUT URL. When using a presigned URL with <code>ContentType</code>, the client must include a matching <code>Content-Type</code> header:</p>
<pre tabindex="0"><code class="language-sh">curl -X PUT &quot;https://&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com/my-bucket/dog.png?X-Amz-Algorithm=...&quot; \&#10;  &#45;H &quot;Content-Type: image/png&quot; \&#10;  &#45;-data-binary @dog.png&#10;</code></pre>
<h2 id="restrict-uploads-with-cors-and-content-type">Restrict uploads with CORS and Content-Type</h2>
<p>When generating presigned URLs for uploads, you can limit abuse and misuse by:</p>
<ol>
<li>
<p><strong>Restricting Content-Type</strong>: Specify the allowed content type in the presigned URL parameters. The upload will fail if the client sends a different <code>Content-Type</code> header.</p>
</li>
<li>
<p><strong>Configuring CORS</strong>: Set up <a href="/r2/buckets/cors/#add-cors-policies-from-the-dashboard">CORS rules</a> on your bucket to control which origins can upload files. Configure CORS via the <a href="https://dash.cloudflare.com/?to=/:account/r2/overview">Cloudflare dashboard</a> by adding a JSON policy to your bucket settings:</p>
</li>
</ol>
<pre tabindex="0"><code class="language-json">[&#10;	{&#10;		&quot;AllowedOrigins&quot;: [&quot;https://example.com&quot;],&#10;		&quot;AllowedMethods&quot;: [&quot;PUT&quot;],&#10;		&quot;AllowedHeaders&quot;: [&quot;Content-Type&quot;],&#10;		&quot;ExposeHeaders&quot;: [&quot;ETag&quot;],&#10;		&quot;MaxAgeSeconds&quot;: 3600&#10;	}&#10;]&#10;</code></pre>
<p>Then generate a presigned URL with a Content-Type restriction:</p>
<pre tabindex="0"><code class="language-python">put_url = s3.generate_presigned_url(&#10;    &quot;put_object&quot;,&#10;    Params={&#10;        &quot;Bucket&quot;: &quot;my-bucket&quot;,&#10;        &quot;Key&quot;: &quot;dog.png&quot;,&#10;        &quot;ContentType&quot;: &quot;image/png&quot;,&#10;    },&#10;    ExpiresIn=3600,&#10;)&#10;</code></pre>
<p>When a client uses this presigned URL, they must:</p>
<ul>
<li>Make the request from an allowed origin (enforced by CORS)</li>
<li>Include the <code>Content-Type: image/png</code> header (enforced by the signature)</li>
</ul>
