<p>Some of R2's <a href="/r2/api/s3/extensions/">extensions</a> require setting a specific header when using them in the S3 compatible API. For some functionality you may want to set a request header on an entire category of requests. Other times you may want to configure a different header for each individual request. This page contains some examples on how to do so with <code>boto3</code> and with <code>aws-sdk-js-v3</code>.</p>
<h2 id="setting-a-custom-header-on-all-requests">Setting a custom header on all requests</h2>
<p>When using certain functionality, like the <code>cf-create-bucket-if-missing</code> header, you may want to set a constant header for all <code>PutObject</code> requests you're making.</p>
<h3 id="set-a-header-for-all-requests-with-boto3">Set a header for all requests with <code>boto3</code></h3>
<p><code>Boto3</code> has an event system which allows you to modify requests. Here we register a function into the event system which adds our header to every <code>PutObject</code> request being made.</p>
<pre tabindex="0"><code class="language-python">import boto3&#10;&#10;client = boto3.resource(&#x27;s3&#x27;,&#10;  &#35; Provide your Cloudflare account ID&#10;  endpoint_url = &#x27;https://&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com&#x27;,&#10;  &#35; Retrieve your S3 API credentials for your R2 bucket via API tokens (see: https://developers.cloudflare.com/r2/api/tokens)&#10;  aws_access_key_id = &#x27;&lt;ACCESS_KEY_ID&gt;&#x27;,&#10;  aws_secret_access_key = &#x27;&lt;SECRET_ACCESS_KEY&gt;&#x27;&#10;)&#10;&#10;event_system = client.meta.events&#10;&#10;&#35; Define function responsible for adding the header&#10;def add_custom_header(params, **kwargs):&#10;    params[&quot;headers&quot;][&#x27;cf-create-bucket-if-missing&#x27;] = &#x27;true&#x27;&#10;&#10;event_system.register(&#x27;before-call.s3.PutObject&#x27;, add_custom_header)&#10;&#10;response = client.put_object(Bucket=&quot;my-bucket&quot;, Key=&quot;my_file&quot;, Body=&quot;file_contents&quot;)&#10;print(response)&#10;</code></pre>
<h3 id="set-a-header-for-all-requests-with-aws-sdk-js-v3">Set a header for all requests with <code>aws-sdk-js-v3</code></h3>
<p><code>aws-sdk-js-v3</code> allows the customization of request behavior through the use of its <a href="https://aws.amazon.com/blogs/developer/middleware-stack-modular-aws-sdk-js/">middleware stack</a>. This example adds a middleware to the client which adds a header to every <code>PutObject</code> request being made.</p>
<pre tabindex="0"><code class="language-ts">import { PutObjectCommand, S3Client } from &quot;@aws-sdk/client-s3&quot;;&#10;import { HttpRequest } from &quot;@smithy/core/protocols&quot;;&#10;&#10;const client = new S3Client({&#10;	region: &quot;auto&quot;, // Required by SDK but not used by R2&#10;	endpoint: `https://${ACCOUNT_ID}.r2.cloudflarestorage.com`,&#10;	// Retrieve your S3 API credentials for your R2 bucket via API tokens (see: https://developers.cloudflare.com/r2/api/tokens)&#10;	credentials: {&#10;		accessKeyId: ACCESS_KEY_ID,&#10;		secretAccessKey: SECRET_ACCESS_KEY,&#10;	},&#10;});&#10;&#10;client.middlewareStack.add(&#10;	(next) =&gt; async (args) =&gt; {&#10;		const request = args.request;&#10;&#10;		if (HttpRequest.isInstance(request)) {&#10;			request.headers[&quot;cf-create-bucket-if-missing&quot;] = &quot;true&quot;;&#10;		}&#10;&#10;		return next(args);&#10;	},&#10;	{ step: &quot;build&quot;, name: &quot;customHeaders&quot; },&#10;);&#10;&#10;const command = new PutObjectCommand({&#10;	Bucket: &quot;my-bucket&quot;,&#10;	Key: &quot;my_key&quot;,&#10;	Body: &quot;my_data&quot;,&#10;});&#10;&#10;const response = await client.send(command);&#10;&#10;console.log(response);&#10;</code></pre>
<h2 id="set-a-different-header-on-each-request">Set a different header on each request</h2>
<p>Certain extensions that R2 has provided in the S3 compatible api may require setting a different header on each request. For example, you may want to only want to overwrite an object if its etag matches a certain expected value. This value will likely be different for each object that is being overwritten, which requires the <code>If-Match</code> header to be different with each request you make. This section shows examples of how to accomplish that.</p>
<h3 id="set-a-header-per-request-in-boto3">Set a header per request in <code>boto3</code></h3>
<p>To enable us to pass custom headers as an extra argument into the call to <code>client.put_object()</code> we need to register 2 functions into <code>boto3</code>'s event system. This is necessary because <code>boto3</code> performs a parameter validation step which rejects extra method arguments. Since this parameter validation occurs before we can set headers on the request, we first need to move the custom argument into the request context before the parameter validation happens. In a subsequent step we can now actually set the headers based on the information we put in the request context.</p>
<pre tabindex="0"><code class="language-python">import boto3&#10;&#10;client = boto3.resource(&#x27;s3&#x27;,&#10;  &#35; Provide your Cloudflare account ID&#10;  endpoint_url = &#x27;https://&lt;ACCOUNT_ID&gt;.r2.cloudflarestorage.com&#x27;,&#10;  &#35; Retrieve your S3 API credentials for your R2 bucket via API tokens (see: https://developers.cloudflare.com/r2/api/tokens)&#10;  aws_access_key_id = &#x27;&lt;ACCESS_KEY_ID&gt;&#x27;,&#10;  aws_secret_access_key = &#x27;&lt;SECRET_ACCESS_KEY&gt;&#x27;&#10;)&#10;&#10;event_system = client.meta.events&#10;&#10;&#35; Moves the custom headers from the parameters to the request context&#10;def process_custom_arguments(params, context, **kwargs):&#10;    if (custom_headers := params.pop(&quot;custom_headers&quot;, None)):&#10;        context[&quot;custom_headers&quot;] = custom_headers&#10;&#10;&#35; Here we extract the headers from the request context and actually set them&#10;def add_custom_headers(params, context, **kwargs):&#10;    if (custom_headers := context.get(&quot;custom_headers&quot;)):&#10;        params[&quot;headers&quot;].update(custom_headers)&#10;&#10;event_system.register(&#x27;before-parameter-build.s3.PutObject&#x27;, process_custom_arguments)&#10;event_system.register(&#x27;before-call.s3.PutObject&#x27;, add_custom_headers)&#10;&#10;custom_headers = {&#x27;If-Match&#x27; : &#x27;&quot;29d911f495d1ba7cb3a4d7d15e63236a&quot;&#x27;}&#10;&#10;&#35; Note that boto3 will throw an exception if the precondition failed. Catch this exception if necessary&#10;response = client.put_object(Bucket=&quot;my-bucket&quot;, Key=&quot;my_key&quot;, Body=&quot;file_contents&quot;, custom_headers=custom_headers)&#10;print(response)&#10;</code></pre>
<h3 id="set-a-header-per-request-in-aws-sdk-js-v3">Set a header per request in <code>aws-sdk-js-v3</code></h3>
<p>Here we again configure the header we would like to set by creating a middleware, but this time we add the middleware to the request itself instead of to the whole client.</p>
<pre tabindex="0"><code class="language-ts">import { PutObjectCommand, S3Client } from &quot;@aws-sdk/client-s3&quot;;&#10;import { HttpRequest } from &quot;@smithy/core/protocols&quot;;&#10;&#10;const client = new S3Client({&#10;	region: &quot;auto&quot;, // Required by SDK but not used by R2&#10;	// Provide your Cloudflare account ID&#10;	endpoint: `https://${ACCOUNT_ID}.r2.cloudflarestorage.com`,&#10;	// Retrieve your S3 API credentials for your R2 bucket via API tokens (see: https://developers.cloudflare.com/r2/api/tokens)&#10;	credentials: {&#10;		accessKeyId: ACCESS_KEY_ID,&#10;		secretAccessKey: SECRET_ACCESS_KEY,&#10;	},&#10;});&#10;&#10;const command = new PutObjectCommand({&#10;	Bucket: &quot;my-bucket&quot;,&#10;	Key: &quot;my_key&quot;,&#10;	Body: &quot;my_data&quot;,&#10;});&#10;&#10;const headers = { &quot;If-Match&quot;: &#x27;&quot;29d911f495d1ba7cb3a4d7d15e63236a&quot;&#x27; };&#10;command.middlewareStack.add(&#10;	(next) =&gt; (args) =&gt; {&#10;		const request = args.request;&#10;&#10;		if (HttpRequest.isInstance(request)) {&#10;			Object.assign(request.headers, headers);&#10;		}&#10;&#10;		return next(args);&#10;	},&#10;	{ step: &quot;build&quot;, name: &quot;customHeaders&quot; },&#10;);&#10;const response = await client.send(command);&#10;&#10;console.log(response);&#10;</code></pre>
