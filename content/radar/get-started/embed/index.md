<p>Radar allows you to download an image of a chart, as well as embed interactive cards of most charts into your own web pages.</p>
<p>Charts supporting this feature will have a share icon next to its description.</p>
<h2 id="download-a-chart-in-png-format">Download a chart in PNG format</h2>
<ol>
<li>Select the Share icon next to the description of the chart you wish to share.</li>
<li>Select <code>Download Image.</code></li>
<li>A .png file containing the requested chart will be downloaded.</li>
</ol>
<h2 id="embed-an-interactive-chart-in-your-website">Embed an interactive chart in your website</h2>
<ol>
<li>Select the Share icon next to the description of the chart you wish to share.</li>
<li>Select between Fixed Time and Real Time.
<ul>
<li>Real Time uses a “sliding window” based on the selected date range, and will display data points looking back over that duration from the current date/time.</li>
<li>Fixed Time will always display a chart with only the currently visible data points.</li>
</ul>
</li>
<li>Select Copy Code and paste the code into your web page.</li>
</ol>
<p><strong>Note</strong>: Your current selections, such as date range, location, autonomous system (ASN), and visible series, will be reflected in the shared chart.</p>
