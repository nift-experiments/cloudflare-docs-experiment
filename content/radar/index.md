<p><a href="https://radar.cloudflare.com">Cloudflare Radar</a> is a hub that showcases global Internet traffic, attacks, and technology trends and insights. It is powered by data from <a href="https://www.cloudflare.com/network/">Cloudflare’s global network</a>, as well as aggregated and <a href="/1.1.1.1/privacy/public-dns-resolver/">anonymized data</a> from Cloudflare’s <a href="/1.1.1.1/">1.1.1.1 public DNS resolver</a>.</p>
<p>Using <a href="/api/resources/radar/">Radar's API</a> you can access Cloudflare's data on global Internet traffic.
Radar's API is free, allowing academics, technology professionals, and other web enthusiasts to investigate Internet usage across the globe.</p>
<p>Data available via Radar API endpoints is made available under the <a href="https://creativecommons.org/licenses/by-nc/4.0/">CC BY-NC 4.0</a> license.</p>
