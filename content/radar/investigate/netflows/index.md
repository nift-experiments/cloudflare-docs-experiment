<p><a href="https://en.wikipedia.org/wiki/NetFlow">NetFlows</a> shows network traffic data from end users collected from Cloudflare's edge routers. NetFlows' data also feeds the <a href="https://radar.cloudflare.com/">Internet traffic change</a> chart.</p>
<p>NetFlows includes all types of traffic from Cloudflare's routers, not just traffic to websites served by Cloudflare's <a href="https://www.cloudflare.com/en-gb/learning/cdn/what-is-a-cdn/">CDN</a>.</p>
<h2 id="list-of-endpoints">List of endpoints</h2>
<h3 id="timeseries">Timeseries</h3>
<h4 id="example-filtering-by-product">Example: filtering by product</h4>
<p>Besides comparing time series across locations or date ranges (discussed in <a href="/radar/get-started/making-comparisons/">Make comparisons</a>), we can also examine <code>ALL</code> traffic versus only <code>HTTP</code> traffic using the <code>product</code> filter. For more information, refer to the <a href="/api/resources/radar/subresources/netflows/methods/timeseries/">API reference</a> for this endpoint.</p>
<aside class="nb-aside note">
<h3 class="nb-aside-title" id="netflow-products">NetFlow products</h3>
@markup("md", "content/.markup/bodies/11553.md")
</aside>
<p>In the following example, we will examine both <code>ALL</code> and <code>HTTP</code> traffic in two <a href="https://www.cloudflare.com/en-gb/learning/network-layer/what-is-an-autonomous-system/">autonomous systems</a>. First, we will examine <a href="https://radar.cloudflare.com/as3243">AS3243</a>, a Portuguese local Internet Service Provider (ISP). The parameters for all traffic are <code>name=AS3243_all&amp;product=ALL&amp;dateRange=1d&amp;asn=3243</code>, and for just the HTTP traffic are <code>name=AS3243_http&amp;product=HTTP&amp;dateRange=1d&amp;asn=3243</code>):</p>
<pre tabindex="0"><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/radar/netflows/timeseries?name=meo_all&amp;product=ALL&amp;dateRange=1d&amp;asn=3243&amp;name=meo_http&amp;product=HTTP&amp;dateRange=1d&amp;asn=3243&amp;format=json&amp;aggInterval=1h&quot; \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot;&#10;</code></pre>
<p>This is the abbreviated response:</p>
<pre tabindex="0"><code class="language-json">{&#10;  &quot;success&quot;: true,&#10;  &quot;errors&quot;: [],&#10;  &quot;result&quot;: {&#10;		&quot;AS3243_all&quot;: {&#10;			&quot;timestamps&quot;: [&quot;2022-11-08T14:00:00Z&quot;, &quot;2022-11-08T15:00:00Z&quot;, &quot;...&quot;],&#10;			&quot;values&quot;: [&quot;0.565885&quot;, &quot;0.586434&quot;, &quot;...&quot;]&#10;		},&#10;		&quot;AS3243_http&quot;: {&#10;			&quot;timestamps&quot;: [&quot;2022-11-08T14:00:00Z&quot;, &quot;2022-11-08T15:00:00Z&quot;, &quot;...&quot;],&#10;			&quot;values&quot;: [&quot;0.548564&quot;, &quot;0.568329&quot;, &quot;...&quot;]&#10;		}&#10;	}&#10;}&#10;</code></pre>
<p><code>HTTP</code> traffic values are similar to <code>ALL</code> traffic values. This means that most traffic Cloudflare receives from this AS is traffic to websites served by Cloudflare's <a href="https://www.cloudflare.com/en-gb/learning/cdn/what-is-a-cdn/">CDN</a> product.</p>
<p>In this other example, we will examine <a href="https://radar.cloudflare.com/as174">AS174</a>, another autonomous system that is not an ISP:</p>
<pre tabindex="0"><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/radar/netflows/timeseries?name=AS174_all&amp;product=ALL&amp;dateRange=1d&amp;asn=174&amp;name=AS174_http&amp;product=HTTP&amp;dateRange=1d&amp;asn=174&amp;format=json&amp;aggInterval=1h&quot; \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot;&#10;</code></pre>
<p>The abbreviated response is:</p>
<pre tabindex="0"><code class="language-json">{&#10;  &quot;success&quot;: true,&#10;  &quot;errors&quot;: [],&#10;  &quot;result&quot;: {&#10;		&quot;AS174_all&quot;: {&#10;			&quot;timestamps&quot;: [&quot;2022-11-08T14:00:00Z&quot;, &quot;2022-11-08T15:00:00Z&quot;, &quot;...&quot;],&#10;			&quot;values&quot;: [&quot;0.917348&quot;, &quot;1.0&quot;, &quot;...&quot;]&#10;		},&#10;		&quot;AS174_http&quot;: {&#10;			&quot;timestamps&quot;: [&quot;2022-11-08T14:00:00Z&quot;, &quot;2022-11-08T15:00:00Z&quot;, &quot;...&quot;],&#10;			&quot;values&quot;: [&quot;0.381777&quot;, &quot;0.408091&quot;, &quot;...&quot;]&#10;		}&#10;	}&#10;}&#10;</code></pre>
<p>Here, there is less <code>HTTP</code> traffic compared to other types of traffic — which makes sense, since this is not an ISP serving end-users.</p>
<p>Note that here we made two separate requests since we are only interested in whether <code>HTTP</code> comprises the majority of the traffic in each AS or not. If we wanted to actually <a href="/radar/get-started/making-comparisons/">compare</a> the traffic values between them to, for example, examine who has more traffic, we would have to make a single request including all series. Here is how we could do that:</p>
<pre tabindex="0"><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/radar/netflows/timeseries?name=AS174_all&amp;product=ALL&amp;dateRange=1d&amp;asn=174&amp;name=AS174_http&amp;product=HTTP&amp;dateRange=1d&amp;asn=174&amp;name=AS3243_all&amp;product=ALL&amp;dateRange=1d&amp;asn=3243&amp;name=AS3243_http&amp;product=HTTP&amp;dateRange=1d&amp;asn=3243&amp;format=json&amp;aggInterval=1h&quot; \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot;&#10;</code></pre>
<p>which would lead to a response like this:</p>
<pre tabindex="0"><code class="language-json">{&#10;  &quot;success&quot;: true,&#10;  &quot;errors&quot;: [],&#10;  &quot;result&quot;: {&#10;		&quot;AS174_all&quot;: {&#10;			&quot;timestamps&quot;: [&quot;2022-11-08T14:00:00Z&quot;, &quot;2022-11-08T15:00:00Z&quot;, &quot;...&quot;],&#10;			&quot;values&quot;: [&quot;0.917348&quot;, &quot;1.0&quot;, &quot;...&quot;]&#10;		},&#10;		&quot;AS174_http&quot;: {&#10;			&quot;timestamps&quot;: [&quot;2022-11-08T14:00:00Z&quot;, &quot;2022-11-08T15:00:00Z&quot;, &quot;...&quot;],&#10;			&quot;values&quot;: [&quot;0.381777&quot;, &quot;0.408091&quot;, &quot;...&quot;]&#10;		},&#10;		&quot;AS3243_all&quot;: {&#10;			&quot;timestamps&quot;: [&quot;2022-11-08T14:00:00Z&quot;, &quot;2022-11-08T15:00:00Z&quot;, &quot;...&quot;],&#10;			&quot;values&quot;: [&quot;0.317136&quot;, &quot;0.328652&quot;, &quot;...&quot;]&#10;		},&#10;		&quot;AS3243_http&quot;: {&#10;			&quot;timestamps&quot;: [&quot;2022-11-08T14:00:00Z&quot;, &quot;2022-11-08T15:00:00Z&quot;, &quot;...&quot;],&#10;			&quot;values&quot;: [&quot;0.307429&quot;, &quot;0.318505&quot;, &quot;...&quot;]&#10;		}&#10;	}&#10;}&#10;</code></pre>
<p>This response shows how Cloudflare receives more traffic from AS174 than from AS3243.</p>
