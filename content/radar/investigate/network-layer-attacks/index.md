<p>Network layer attacks show <a href="https://www.cloudflare.com/en-gb/learning/ddos/layer-3-ddos-attacks/">DDoS</a> attack trends at the network layer. These attacks can be split by the network protocol they use: <a href="https://www.cloudflare.com/en-gb/learning/ddos/glossary/internet-control-message-protocol-icmp/">ICMP</a>, <a href="https://www.cloudflare.com/learning/ddos/glossary/tcp-ip/">TCP</a>, <a href="https://www.cloudflare.com/en-gb/learning/ddos/glossary/user-datagram-protocol-udp/">UDP</a> and others.</p>
<aside class="nb-aside note">
@markup("md", "content/.markup/bodies/11552.md")
</aside>
<p>When filtering by location or autonomous system (AS), we are filtering by the source location/AS of the attack
— which can be very different to the location of the human orchestrator of the attack. Refer to <a href="https://www.cloudflare.com/learning/ddos/what-is-a-ddos-botnet/">botnets</a> for more information.</p>
<h2 id="list-of-endpoints">List of endpoints</h2>
<h3 id="timeseries">Timeseries</h3>
<h4 id="example-hourly-percentage-breakdown-by-attack-method">Example: hourly percentage breakdown by attack method</h4>
<p>In the following example, we will examine the worldwide versus Singapore distribution of mitigated attacks by network protocol:</p>
<pre tabindex="0"><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/radar/attacks/layer3/timeseries_groups?name=global&amp;dateRange=1d&amp;location=&amp;name=singapore&amp;location=SG&amp;dateRange=1d&amp;aggInterval=1h&amp;format=json&quot; \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot;&#10;</code></pre>
<p>If we inspect the abbreviated response below, we can conclude that globally, at those timestamps, <code>UDP</code> and <code>TCP</code> attacks were mostly evenly split.</p>
<pre tabindex="0"><code class="language-json">{&#10;  &quot;success&quot;: true,&#10;  &quot;errors&quot;: [],&#10;  &quot;result&quot;: {&#10;    &quot;global&quot;: {&#10;      &quot;timestamps&quot;: [&quot;2022-11-06T13:00:00Z&quot;, &quot;2022-11-06T14:00:00Z&quot;, &quot;...&quot;],&#10;      &quot;udp&quot;: [&quot;50.784034&quot;, &quot;51.055221&quot;, &quot;...&quot;],&#10;      &quot;tcp&quot;: [&quot;49.213944&quot;, &quot;48.943769&quot;, &quot;...&quot;],&#10;      &quot;icmp&quot;: [&quot;0.002023&quot;, &quot;0.001009&quot;, &quot;...&quot;],&#10;      &quot;gre&quot;: [&quot;0.0&quot;, &quot;0.0&quot;, &quot;0.0&quot;, &quot;...&quot;]&#10;    },&#10;    &quot;singapore&quot;: {&#10;      &quot;timestamps&quot;: [&quot;2022-11-06T13:00:00Z&quot;, &quot;2022-11-06T14:00:00Z&quot;, &quot;...&quot;],&#10;      &quot;tcp&quot;: [&quot;79.605287&quot;, &quot;83.943885&quot;, &quot;...&quot;],&#10;      &quot;udp&quot;: [&quot;20.394594&quot;, &quot;16.056115&quot;, &quot;...&quot;],&#10;      &quot;icmp&quot;: [&quot;0.000119&quot;, &quot;0.0&quot;, &quot;...&quot;],&#10;      &quot;gre&quot;: [&quot;0.0&quot;, &quot;0.0&quot;, &quot;...&quot;]&#10;    },&#10;    &quot;meta&quot;: {&#10;      &quot;dateRange&quot;: {&#10;        &quot;startTime&quot;: &quot;2022-11-06T13:00:00Z&quot;,&#10;        &quot;endTime&quot;: &quot;2022-11-07T13:00:00Z&quot;&#10;      },&#10;      &quot;normalization&quot;: &quot;PERCENTAGE&quot;,&#10;			// ...&#10;    }&#10;  }&#10;}&#10;</code></pre>
<p>We can also conclude that the distribution of network layer attacks coming from Singapore  — or, more accurately, reaching Cloudflare's data center located in Singapore — differs quite a bit from the worldwide distribution. At those times, the distribution of network layer attacks clearly favors <a href="https://www.cloudflare.com/learning/ddos/glossary/tcp-ip/">TCP</a>.</p>
<p>For more information refer to the <a href="/api/resources/radar/subresources/attacks/subresources/layer3/methods/timeseries/">API reference</a> for this endpoint.</p>
<h3 id="summary">Summary</h3>
<h4 id="example-russia-overall-percentage-breakdown-by-network-protocol">Example: Russia - overall percentage breakdown by network protocol</h4>
<p>We can also filter by source location and examine attacks coming from Russia:</p>
<pre tabindex="0"><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/radar/attacks/layer3/summary?location=RU&amp;name=attacks_ru&amp;dateRange=1d&amp;format=json&quot; \&#10;&#45;-header &quot;Authorization: Bearer &lt;API_TOKEN&gt;&quot;&#10;</code></pre>
<pre tabindex="0"><code class="language-json">{&#10;  &quot;success&quot;: true,&#10;  &quot;errors&quot;: [],&#10;  &quot;result&quot;: {&#10;    &quot;attacks_ru&quot;: {&#10;      &quot;udp&quot;: &quot;86.682356&quot;,&#10;      &quot;tcp&quot;: &quot;11.928664&quot;,&#10;      &quot;gre&quot;: &quot;1.381015&quot;,&#10;      &quot;icmp&quot;: &quot;0.007965&quot;&#10;    },&#10;    &quot;meta&quot;: {&#10;      &quot;dateRange&quot;: {&#10;        &quot;startTime&quot;: &quot;2022-11-06T15:00:00Z&quot;,&#10;        &quot;endTime&quot;: &quot;2022-11-07T15:00:00Z&quot;&#10;      },&#10;      &quot;normalization&quot;: &quot;PERCENTAGE&quot;,&#10;			// ...&#10;    }&#10;  }&#10;}&#10;</code></pre>
<p>The response shows that the attacks coming from Russia to other locations tended to use the <a href="https://www.cloudflare.com/en-gb/learning/ddos/glossary/user-datagram-protocol-udp/">UDP</a> network protocol at those timestamps.</p>
