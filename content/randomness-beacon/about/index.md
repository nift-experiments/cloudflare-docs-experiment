<p>The drand project aims to address the current lack of services providing distributed public randomness. Distributed to increase the resilience and trustworthiness, drand provides a standalone randomness-as-a-service network that is application agnostic. This is similar to how NTP networks serve timing information across the globe.</p>
<p>drand follows the <a href="https://en.wikipedia.org/wiki/KISS_principle">KISS principle</a>. It relies on well-researched cryptographic building blocks and open-source software design principles and libraries, such as protobuf and gRPC, to ensure high performance and interoperability. drand also attempts to use sane security defaults, such as having TLS enabled by default.</p>
<p>Beyond that, drand adds new features important for its practical deployment, such as being able to securely add and remove members of the network through <a href="https://ieeexplore.ieee.org/document/1183515">resharing</a> while keeping the same shared public key necessary for randomness verification.</p>
