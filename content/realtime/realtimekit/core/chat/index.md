<h2 id="export-chat-messages">Export chat messages</h2>
<p>You can programmatically retrieve all chat messages of a RealtimeKit session in the following ways:</p>
<ul>
<li>Using the Chat Replay API</li>
<li>Setting up webhook for the <code>meeting.chatSynced</code> event</li>
</ul>
<h3 id="get-chat-download-url">Get chat download URL</h3>
<p>To get the chat download URL, make an HTTP <code>GET</code> request to the <a href="/api/resources/realtime_kit/subresources/sessions/methods/get_session_chat/">Chat Replay API endpoint</a>. The API returns:</p>
<pre><code class="language-json">{&#10;	&quot;success&quot;: true,&#10;	&quot;data&quot;: {&#10;		&quot;chat_download_url&quot;: &quot;string&quot;,&#10;		&quot;chat_download_url_expiry&quot;: &quot;string&quot;&#10;	}&#10;}&#10;</code></pre>
<ul>
<li><strong><code>chat_download_url</code></strong> - A URL that allows you to download the entire chat dump of a session in CSV format from AWS S3</li>
<li><strong><code>chat_download_url_expiry</code></strong> - The expiry timestamp of the <code>chat_download_url</code>. If the URL expires, call this endpoint again to obtain a new download URL</li>
</ul>
<p>For details on the Chat Replay API endpoint, refer to the <a href="/api/resources/realtime_kit/subresources/sessions/methods/get_session_chat/">Realtime Kit API documentation</a>.</p>
<h3 id="download-the-chat-dump-file">Download the chat dump file</h3>
<p>You can download the chat dump file in CSV format by making an HTTP <code>GET</code> request to the <code>chat_download_url</code> obtained in the previous step.</p>
<p>The process of downloading a file from an HTTP URL differs based on whether you are downloading on the client side or server side.</p>
<h4 id="download-on-the-client">Download on the client</h4>
<p>To download at client side:</p>
<ol>
<li>Make a <code>GET</code> request to the <code>chat_download_url</code></li>
<li>Convert the response to a blob</li>
<li>Create an invisible <code>&lt;a&gt;</code> HTML element with a <code>download</code> attribute and add the blob to its <code>href</code></li>
<li>Programmatically click on the <code>&lt;a&gt;</code> element so that the browser automatically starts downloading, then remove the <code>&lt;a&gt;</code> element</li>
</ol>
<h4 id="download-on-the-server">Download on the server</h4>
<p>To download on the server using Node.js streams:</p>
<ol>
<li>Create a writable stream for a local file</li>
<li>Make a <code>GET</code> request to <code>chat_download_url</code></li>
<li>Get a readable stream using <code>res.body</code> and pipe to the writable stream created in the first step</li>
</ol>
<h3 id="csv-chat-dump-format">CSV chat dump format</h3>
<p>The CSV file contains all chat messages along with participant information and metadata. It includes the following column headings:</p>
<ul>
<li><strong><code>id</code></strong> - Unique chat message ID</li>
<li><strong><code>participantId</code></strong> - ID of the participant who sent the message</li>
<li><strong><code>sessionId</code></strong> - The session ID from which the chat message was sent</li>
<li><strong><code>meetingId</code></strong> - The ID of the meeting to which this session belongs</li>
<li><strong><code>displayName</code></strong> - Display name of the participant who sent this message</li>
<li><strong><code>pinned</code></strong> - A boolean that indicates if the current message was pinned</li>
<li><strong><code>isEdited</code></strong> - A boolean that indicates if the current message was edited</li>
<li><strong><code>payloadType</code></strong> - An ENUM that indicates the type of payload sent in the chat message. It can be one of <code>TEXT_MESSAGE</code>, <code>IMAGE_MESSAGE</code>, <code>FILE_MESSAGE</code></li>
<li><strong><code>payload</code></strong> - The actual payload sent in the chat message</li>
<li><strong><code>createdAt</code></strong> - Timestamp when this chat message was sent</li>
</ul>
