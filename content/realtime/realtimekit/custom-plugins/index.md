<p>Plugins are interactive real-time applications that run inside a meeting, such as a shared whiteboard or a document viewer. RealtimeKit lets you build your own plugins and render them alongside the meeting UI.</p>
<p>A custom plugin is a DOM element that you register with the Core SDK. When a participant activates it, RealtimeKit makes it active for everyone in the session and renders it through the UI Kit.</p>
<p>To learn how plugins are registered and controlled through the SDK, refer to <a href="/realtime/realtimekit/core/plugins/">Plugins</a>.</p>
