<p>A collection of UI Kit addons that extend RealtimeKit's prebuilt UI Kit capabilities with additional interactive components and controls for enhanced meeting experiences.</p>
<div class="nb-interactive-component" data-cf-component="RTKSDKSelector"></div>
<aside class="nb-aside note">
@markup("md", "content/.markup/bodies/11798.md")
</aside>
<p>The UI Kit addons library provides the following categories of components:</p>
<h4 id="host-controls">Host Controls</h4>
<p>Host controls allow meeting hosts to manage participant permissions:</p>
<ul>
<li><strong>Camera Host Control</strong> - Control participant camera permissions</li>
<li><strong>Mic Host Control</strong> - Control participant microphone permissions</li>
<li><strong>Chat Host Control</strong> - Control participant chat permissions</li>
</ul>
<h4 id="reactions">Reactions</h4>
<p>Interactive engagement features for participants:</p>
<ul>
<li><strong>Hand Raise</strong> - Allow participants to raise their hand to signal they want to speak</li>
<li><strong>Reactions Manager</strong> - Display emoji reactions during meetings</li>
</ul>
<h4 id="participant-tile">Participant Tile</h4>
<p>Customize the participant tile interface:</p>
<ul>
<li><strong>Participant Tile Menu</strong> - Add custom menu options to participant tiles</li>
</ul>
<h4 id="participant-tab-actions">Participant Tab Actions</h4>
<p>Add custom actions to the participants tab:</p>
<ul>
<li><strong>Participant Menu Item</strong> - Add custom menu items to participant actions</li>
<li><strong>Participants Tab Action</strong> - Add custom action buttons to the participants tab</li>
<li><strong>Participants Tab Toggle</strong> - Add custom toggle controls to the participants tab</li>
</ul>
<h4 id="video-background">Video Background</h4>
<p>Apply visual effects to participant video:</p>
<ul>
<li><strong>Video Background</strong> - Apply blur or virtual backgrounds to video streams</li>
</ul>
<h4 id="control-bar">Control Bar</h4>
<p>Customize the meeting control bar:</p>
<ul>
<li><strong>Custom Control Bar Button</strong> - Add custom buttons to the control bar</li>
</ul>
