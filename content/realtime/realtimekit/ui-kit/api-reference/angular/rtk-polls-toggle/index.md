<p>A button which toggles visibility of polls.
You need to pass the <code>meeting</code> object to it to see the unread polls count badge.
When clicked it emits a <code>rtkStateUpdate</code> event with the data:</p>
<pre><code class="language-ts">{ activeSidebar: boolean; sidebar: &#x27;polls&#x27; }&#10;</code></pre>
