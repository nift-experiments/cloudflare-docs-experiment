<h2 id="create-your-first-app">Create your first app</h2>
<p>Every Realtime App is a separate environment, so you can make one for development, staging and production versions for your product.
Either using <a href="https://dash.cloudflare.com/?to=/:account/realtime/sfu">Dashboard</a>, or the <a href="/api/resources/calls/subresources/sfu/methods/create/">API</a> create a Realtime App. When you create a Realtime App, you will get:</p>
<ul>
<li>App ID</li>
<li>App Secret</li>
</ul>
<p>These two combined will allow you to make API Realtime from your backend server to Realtime.</p>
