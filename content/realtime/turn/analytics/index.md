<p>Cloudflare Realtime TURN service counts ingress and egress usage in bytes. You can access this real-time and historical data using the TURN analytics API. You can see TURN usage data in a time series or aggregate that shows traffic in bytes over time.</p>
<p>Cloudflare TURN analytics is available over the GraphQL API only.</p>

<h2 id="available-metrics-and-dimensions">Available metrics and dimensions</h2>
<p>TURN analytics provides rich data that you can query and aggregate in various ways.</p>
<h3 id="metrics">Metrics</h3>
<p>You can query the following metrics:</p>
<ul>
<li><strong>egressBytes</strong>: Total bytes sent from TURN servers to clients</li>
<li><strong>ingressBytes</strong>: Total bytes received by TURN servers from clients</li>
<li><strong>concurrentConnections</strong>: Average number of concurrent connections</li>
</ul>
<p>These metrics support aggregations using <code>sum</code> and <code>avg</code> functions.</p>
<h3 id="dimensions">Dimensions</h3>
<p>You can break down your data by the following dimensions:</p>
<ul>
<li><strong>Time aggregations</strong>: <code>datetime</code>, <code>datetimeMinute</code>, <code>datetimeFiveMinutes</code>, <code>datetimeFifteenMinutes</code>, <code>datetimeHour</code></li>
<li><strong>Geographic</strong>: <code>datacenterCity</code>, <code>datacenterCountry</code>, <code>datacenterRegion</code> (Cloudflare data center location)</li>
<li><strong>Identity</strong>: <code>keyId</code>, <code>customIdentifier</code>, <code>username</code></li>
</ul>
<h3 id="filters">Filters</h3>
<p>You can filter the data in TURN analytics on:</p>
<ul>
<li>Datetime range</li>
<li>TURN Key ID</li>
<li>TURN Username</li>
<li>Custom identifier</li>
</ul>

<pre tabindex="0"><code class="language-graphql">query {&#10;	viewer {&#10;		accounts(filter: { accountTag: $accountId }) {&#10;			callsTurnUsageAdaptiveGroups(&#10;				limit: 10&#10;				filter: { date_geq: $dateFrom, date_leq: $dateTo }&#10;				orderBy: [sum_egressBytes_DESC, sum_ingressBytes_DESC]&#10;			) {&#10;				dimensions {&#10;					keyId&#10;					customIdentifier&#10;				}&#10;				sum {&#10;					egressBytes&#10;					ingressBytes&#10;				}&#10;				avg {&#10;					concurrentConnectionsFiveMinutes&#10;				}&#10;			}&#10;		}&#10;	}&#10;}&#10;</code></pre>
