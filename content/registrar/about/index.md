<p>Cloudflare Registrar offers several advantages over other <a href="https://www.cloudflare.com/learning/dns/glossary/what-is-a-domain-name-registrar/">registrars</a>, such as domain name registration renewal <a href="https://www.cloudflare.com/products/registrar/">without markups fees</a>. You only pay what is charged by registries and <a href="https://www.icann.org/">ICANN</a>. Cloudflare Registrar also offers additional security features, such as free, one-click activation for <a href="/registrar/get-started/enable-dnssec/">Domain Name System Security Extensions (DNSSEC)</a>, <a href="/registrar/custom-domain-protection/">custom domain protection</a>, and <a href="/registrar/account-options/whois-redaction/">WHOIS redaction</a>.</p>
<p>You can buy your domain from Cloudflare Registrar or from a third party. Even when you buy it from a third party, you can manage your domain with Cloudflare to benefit from all the features Cloudflare offers.</p>
