<p>Cloudflare Registrar provides personal data redaction on WHOIS information, if permitted by the registry.</p>
<p>WHOIS is a standard for publishing the contact and nameserver information for all registered domains. Each registrar maintains their own WHOIS service. Anyone can query the registrar’s WHOIS service to reveal the data behind a given domain.</p>
<p>However, broadcasting the registrant contact information via the WHOIS service can cause spam mail to be delivered to your personal addresses. Cloudflare Registrar offers personal data redaction on WHOIS for free, that meets current ICANN guidelines.</p>
<p>Cloudflare’s WHOIS service can be found at <a href="https://rdap.cloudflare.com/">https://rdap.cloudflare.com/</a>. Select <strong>WHOIS</strong> as the search type.</p>
<h2 id="what-is-whois-redaction">What is WHOIS redaction?</h2>
<p>WHOIS redaction removes most contact information categorized as personal data (such as registrant name, email address, postal address) from the published WHOIS record for a domain. These fields will read <code>Data Redacted</code>. The nameserver, domain lock information, and date records for a domain are still available publicly. The following fields will continue to show in WHOIS, due to ICANN policy:</p>
<ul>
<li>Registrant state/province</li>
<li>Registrant country</li>
</ul>
<p>Cloudflare still maintains the authoritative, unredacted, record of your WHOIS data. You can modify this information at any time. Refer to <a href="/registrar/account-options/domain-contact-updates">Registrant contact updates</a> for more information.</p>
<h2 id="what-is-rdap">What is RDAP?</h2>
<p>RDAP (Registration Data Access Protocol) is a new standard for querying domain contact and nameserver information for all registered domains. This new protocol offers some advantages over WHOIS, including standardized data access, support for internationalization, and secure access controls. RDAP is intended to eventually replace WHOIS. However, Cloudflare currently provides both WHOIS and RDAP search capability.</p>
<p>Cloudflare’s RDAP service can be found at <a href="https://rdap.cloudflare.com/">https://rdap.cloudflare.com/</a>. Select <strong>RDAP</strong> as the search type.</p>
<h2 id="how-can-third-parties-reach-registrants">How can third parties reach registrants?</h2>
<p>As part of the ICANN guidelines, registrars must have a method for third parties to reach the registrant without revealing their identity. Cloudflare has a form available where third parties can <a href="https://www.cloudflare.com/abuse/form">submit a message for a given domain on Cloudflare Registrar</a>. Cloudflare will forward the message to the registrant email on file for that domain.</p>
