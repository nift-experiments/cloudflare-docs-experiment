<h2 id="2024-04-15">2024-04-15</h2><strong>Cloudflare Trace now supports Workers</strong><p>Starting today, customers can use Cloudflare Trace to confirm if a request to a specific URL within their zone is routed through a <a href="/workers/">Workers script</a>.</p><h2 id="2024-03-18">2024-03-18</h2><strong>Cloudflare Trace now supports BYOIP zones</strong><p>Customers can now use Cloudflare Trace to trace HTTP/S requests through their <a href="/byoip/">BYOIP</a> zones.</p><h2 id="2024-03-12">2024-03-12</h2><strong>Cloudflare Trace now supports grey-clouded hostnames</strong><p>Even if the hostname is <a href="/dns/proxy-status/#dns-only-records">not proxied by Cloudflare</a>, Cloudflare Trace will now return all the configurations that Cloudflare would have applied to the request.</p>
