<p>The <strong>name</strong> of the HTTP request header you want to set or remove can only contain:</p>
<ul>
<li>Alphanumeric characters: <code>a</code>-<code>z</code>, <code>A</code>-<code>Z</code>, and <code>0</code>-<code>9</code></li>
<li>The following special characters: <code>-</code> and <code>_</code></li>
</ul>
<p>The <strong>value</strong> of the HTTP request header you want to set can only contain:</p>
<ul>
<li>Alphanumeric characters: <code>a</code>-<code>z</code>, <code>A</code>-<code>Z</code>, and <code>0</code>-<code>9</code></li>
<li>The following special characters: <code>_ :;.,\/&quot;'?!(){}[]@&lt;&gt;=-+*#$&amp;`|~^%</code></li>
</ul>
<p>The maximum length of the HTTP request header value is 4 KB (~4,096 characters).</p>
