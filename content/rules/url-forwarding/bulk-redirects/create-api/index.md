<h2 id="1-create-a-bulk-redirect-list-via-api"><ol>
<li>Create a Bulk Redirect List via API</li>
</ol></h2>
<p>Use the <a href="/api/resources/rules/subresources/lists/methods/create/">Create a list</a> operation to create a new Bulk Redirect List. The list <code>kind</code> must be <code>redirect</code>.</p>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \&#10;  --url https://api.cloudflare.com/client/v4/accounts/{account_id}/rules/lists \&#10;  --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \&#10;  --data &#x27;{&#10;  &quot;name&quot;: &quot;my_redirect_list&quot;,&#10;  &quot;description&quot;: &quot;My redirect list.&quot;,&#10;  &quot;kind&quot;: &quot;redirect&quot;&#10;}&#x27;</code></pre>
<pre><code class="language-json">{&#10;	&quot;result&quot;: {&#10;		&quot;id&quot;: &quot;f848b6ccb07647749411f504d6f88794&quot;,&#10;		&quot;name&quot;: &quot;my_redirect_list&quot;,&#10;		&quot;description&quot;: &quot;My redirect list.&quot;,&#10;		&quot;kind&quot;: &quot;redirect&quot;,&#10;		&quot;num_items&quot;: 0,&#10;		&quot;num_referencing_filters&quot;: 0,&#10;		&quot;created_on&quot;: &quot;2021-10-28T09:11:42Z&quot;,&#10;		&quot;modified_on&quot;: &quot;2021-10-28T09:11:42Z&quot;&#10;	},&#10;	&quot;success&quot;: true,&#10;	&quot;errors&quot;: [],&#10;	&quot;messages&quot;: []&#10;}&#10;</code></pre>
<p>Take note of the list ID — you will need it in the next step.</p>
<p>For more information on list operations, refer to the <a href="/waf/tools/lists/lists-api/">Lists API</a> documentation.</p>
<h2 id="2-add-items-to-the-list"><ol start="2">
<li>Add items to the list</li>
</ol></h2>
<p>Use the <a href="/api/resources/rules/subresources/lists/subresources/items/methods/create/">Create list items</a> operation to add URL redirect items to the list. Enter the list ID from the previous step in the endpoint URL:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \&#10;  --url https://api.cloudflare.com/client/v4/accounts/{account_id}/rules/lists/{list_id}/items \&#10;  --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \&#10;  --data &#x27;[&#10;  {&#10;    &quot;redirect&quot;: {&#10;      &quot;source_url&quot;: &quot;example.com/blog/&quot;,&#10;      &quot;target_url&quot;: &quot;https://example.com/blog/latest&quot;&#10;    }&#10;  },&#10;  {&#10;    &quot;redirect&quot;: {&#10;      &quot;source_url&quot;: &quot;example.net/&quot;,&#10;      &quot;target_url&quot;: &quot;https://example.net/under-construction.html&quot;,&#10;      &quot;status_code&quot;: 307&#10;    }&#10;  }&#10;]&#x27;</code></pre>
<pre><code class="language-json">{&#10;	&quot;result&quot;: {&#10;		&quot;operation_id&quot;: &quot;92558f8b296d4dbe9d0419e0e53f6622&quot;&#10;	},&#10;	&quot;success&quot;: true,&#10;	&quot;errors&quot;: [],&#10;	&quot;messages&quot;: []&#10;}&#10;</code></pre>
<p>This is an asynchronous operation. The response will contain an <code>operation_id</code> which you will use to check if the operation completed successfully using the <a href="/api/resources/rules/subresources/lists/subresources/bulk_operations/methods/get/">Get bulk operation status</a> operation:</p>
<pre class="nb-api-request"><code class="language-bash">curl --request GET \&#10;  --url https://api.cloudflare.com/client/v4/accounts/{account_id}/rules/lists/bulk_operations/{operation_id} \&#10;  --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;</code></pre>
<p>Once the operation has completed successfully, the response will be similar to the following:</p>
<pre><code class="language-json">{&#10;	&quot;result&quot;: {&#10;		&quot;id&quot;: &quot;92558f8b296d4dbe9d0419e0e53f6622&quot;,&#10;		&quot;status&quot;: &quot;completed&quot;,&#10;		&quot;completed&quot;: &quot;2021-10-28T09:15:42Z&quot;&#10;	},&#10;	&quot;success&quot;: true,&#10;	&quot;errors&quot;: [],&#10;	&quot;messages&quot;: []&#10;}&#10;</code></pre>
<h2 id="3-create-a-bulk-redirect-rule-via-api"><ol start="3">
<li>Create a Bulk Redirect Rule via API</li>
</ol></h2>
<p>Since Bulk Redirect Lists are essentially containers of URL redirects, you have to enable the URL redirects in the list by creating a Bulk Redirect Rule.</p>
<p>Add Bulk Redirect Rules to the <a href="/ruleset-engine/about/rulesets/#entry-point-ruleset">entry point ruleset</a> of the <code>http_request_redirect</code> phase at the account level. Refer to the <a href="/ruleset-engine/rulesets-api/">Rulesets API</a> documentation for more information on <a href="/ruleset-engine/rulesets-api/create/">creating a ruleset</a> and supplying a list of rules for the ruleset.</p>
<p>A Bulk Redirect Rule must have:</p>
<ul>
<li><code>action</code> set to <code>redirect</code></li>
<li>An <code>action_parameters</code> object with additional configuration settings — refer to <a href="/rules/url-forwarding/bulk-redirects/reference/json-objects/#bulk-redirect-rule">Bulk Redirects API JSON objects</a> for details.</li>
</ul>
<p>The following request of the <a href="/api/resources/rulesets/methods/create/">Create an account ruleset</a> operation creates a phase entry point ruleset for the <code>http_request_redirect</code> phase at the account level, and defines a single redirect rule. Use this operation if you have not created a phase entry point ruleset for the <code>http_request_redirect</code> phase yet.</p>
<pre class="nb-api-request"><code class="language-bash">curl --request POST \&#10;  --url https://api.cloudflare.com/client/v4/accounts/{account_id}/rulesets \&#10;  --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \&#10;  --data &#x27;{&#10;  &quot;name&quot;: &quot;My redirect ruleset&quot;,&#10;  &quot;kind&quot;: &quot;root&quot;,&#10;  &quot;phase&quot;: &quot;http_request_redirect&quot;,&#10;  &quot;rules&quot;: [&#10;    {&#10;      &quot;ref&quot;: &quot;enable_my_redirect_list&quot;,&#10;      &quot;expression&quot;: &quot;http.request.full_uri in $my_redirect_list&quot;,&#10;      &quot;description&quot;: &quot;Bulk Redirect rule.&quot;,&#10;      &quot;action&quot;: &quot;redirect&quot;,&#10;      &quot;action_parameters&quot;: {&#10;        &quot;from_list&quot;: {&#10;          &quot;name&quot;: &quot;my_redirect_list&quot;,&#10;          &quot;key&quot;: &quot;http.request.full_uri&quot;&#10;        }&#10;      }&#10;    }&#10;  ]&#10;}&#x27;</code></pre>
<pre><code class="language-json">{&#10;	&quot;result&quot;: {&#10;		&quot;id&quot;: &quot;528f4f03bf0da53a29907199625867be&quot;,&#10;		&quot;name&quot;: &quot;My redirect ruleset&quot;,&#10;		&quot;kind&quot;: &quot;root&quot;,&#10;		&quot;version&quot;: &quot;1&quot;,&#10;		&quot;rules&quot;: [&#10;			{&#10;				&quot;ref&quot;: &quot;enable_my_redirect_list&quot;,&#10;				&quot;id&quot;: &quot;8da312df846b4258a05bcd454ea943be&quot;,&#10;				&quot;version&quot;: &quot;1&quot;,&#10;				&quot;expression&quot;: &quot;http.request.full_uri in $my_redirect_list&quot;,&#10;				&quot;description&quot;: &quot;Bulk Redirect rule.&quot;,&#10;				&quot;action&quot;: &quot;redirect&quot;,&#10;				&quot;action_parameters&quot;: {&#10;					&quot;from_list&quot;: {&#10;						&quot;name&quot;: &quot;my_redirect_list&quot;,&#10;						&quot;key&quot;: &quot;http.request.full_uri&quot;&#10;					}&#10;				},&#10;				&quot;last_updated&quot;: &quot;2021-10-28T09:20:42Z&quot;&#10;			}&#10;		],&#10;		&quot;last_updated&quot;: &quot;2021-10-28T09:20:42Z&quot;,&#10;		&quot;phase&quot;: &quot;http_request_redirect&quot;&#10;	},&#10;	&quot;success&quot;: true,&#10;	&quot;errors&quot;: [],&#10;	&quot;messages&quot;: []&#10;}&#10;</code></pre>
<p>Use the <code>ref</code> field to get stable rule IDs across updates when using Terraform. Adding this field prevents Terraform from recreating the rule on changes. For more information, refer to <a href="/terraform/troubleshooting/rule-id-changes/#how-to-keep-the-same-rule-id-between-modifications">Troubleshooting</a> in the Terraform documentation.</p>
