<p>You can create Bulk Redirect Lists and Bulk Redirect Rules in the Cloudflare dashboard:</p>
<ul>
<li>At the account level, in <strong>Bulk redirects</strong>.</li>
<li>At the zone level, go to <strong>Rules</strong> &gt; <strong>Settings</strong> and select the <strong>Bulk Redirects</strong> tab.</li>
</ul>
<p>However, the lists and rules only exist at the account level and every zone in the same account will show the same items.</p>
