<p>Single Redirects allow you to create static or dynamic URL <span class="nb-glossary-tooltip" title="redirect">redirects</span>. Static redirects send users to a fixed target URL, while dynamic redirects build the target URL from components of the original request. A <a href="/ruleset-engine/rules-language/operators/#wildcard-matching">wildcard-based</a> interface allows you to define source and target URL patterns without complex functions or regular expressions, efficiently handling thousands of URLs with a single rule. Dynamic URL redirects also support advanced features such as string replacement operations and <a href="/ruleset-engine/rules-language/values/#string-values-and-regular-expressions">regular expressions</a> (depending on your Cloudflare plan).</p>
<p>For more complex and customized redirect logic, consider using <a href="/rules/snippets/">Snippets</a>.</p>
