<p>A <a href="/ruleset-engine/about/rulesets/#entry-point-ruleset">phase entry point ruleset</a> contains an ordered list of rules that run in that phase. A rule in an entry point ruleset can execute a different ruleset. You can have entry point rulesets for each phase at the account level and at the zone level.</p>
<p>To add one or more rules to a phase entry point ruleset, use one of the <a href="/ruleset-engine/rulesets-api/update/">ruleset update operations</a> of the <a href="/ruleset-engine/rulesets-api/">Rulesets API</a>. When you add a rule to an entry point ruleset, the entry point ruleset is created automatically if it does not exist. This API method requires that you include in the request all rules you want to keep in the ruleset, or else they will be removed.</p>
<p>If you are adding a single rule to a ruleset, consider using one of the <a href="/ruleset-engine/rulesets-api/add-rule/">rule creation operations</a> instead. In this case, the request only includes the definition of the new rule.</p>
