<h2 id="view-available-rulesets">View available rulesets</h2>
<p>You can list the available rulesets for a zone or account.</p>
<p>For a list of API endpoints refer to <a href="/ruleset-engine/rulesets-api/view/">List and view rulesets</a>.</p>
<h3 id="example-view-available-rulesets-at-the-zone-level">Example: View available rulesets at the zone level</h3>
<p>The response to the <a href="/api/resources/rulesets/methods/list/">GET request</a> obtaining the list of rulesets at the zone level will include the following rulesets:</p>
<ul>
<li>Managed rulesets you can deploy, indicated by <code>&quot;kind&quot;: &quot;managed&quot;</code>.</li>
<li>Zone-level phase entry point rulesets, if configured, indicated by <code>&quot;kind&quot;: &quot;zone&quot;</code>.</li>
<li>Custom rulesets, if configured, indicated by <code>&quot;kind&quot;: &quot;custom&quot;</code>.</li>
</ul>

<h2 id="get-an-entry-point-ruleset">Get an entry point ruleset</h2>
<p>You can get the definition of the <a href="/ruleset-engine/about/rulesets/#entry-point-ruleset">entry point ruleset</a> of a given <a href="/ruleset-engine/about/phases/">phase</a> at the zone or account level.</p>
<p>If the entry point ruleset exists, the API will return a <code>200 OK</code> HTTP status code, along with the ruleset definition.</p>
<p>If the entry point ruleset does not exist, the API will return a <code>404 Not Found</code> HTTP status code.</p>
<h3 id="example-get-an-entry-point-ruleset-at-the-zone-level">Example: Get an entry point ruleset at the zone level</h3>
<p>The following <a href="/api/resources/rulesets/subresources/phases/methods/get/">GET request</a> obtains the definition of the entry point ruleset for the <code>http_request_firewall_managed</code> phase at the zone level. In this case, the entry point ruleset exists and contains one rule.</p>
<pre class="nb-api-request"><code class="language-bash">curl --request GET \&#10;  --url https://api.cloudflare.com/client/v4/zones/{zone_id}/rulesets/phases/{ruleset_phase}/entrypoint \&#10;  --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;</code></pre>
<pre><code class="language-json">{&#10;	&quot;result&quot;: {&#10;		&quot;id&quot;: &quot;&lt;RULESET_ID&gt;&quot;,&#10;		&quot;name&quot;: &quot;Zone-level phase entry point ruleset&quot;,&#10;		&quot;description&quot;: &quot;This ruleset executes a managed ruleset.&quot;,&#10;		&quot;kind&quot;: &quot;zone&quot;,&#10;		&quot;version&quot;: &quot;2&quot;,&#10;		&quot;rules&quot;: [&#10;			{&#10;				&quot;id&quot;: &quot;&lt;RULE_ID&gt;&quot;,&#10;				&quot;version&quot;: &quot;1&quot;,&#10;				&quot;action&quot;: &quot;execute&quot;,&#10;				&quot;expression&quot;: &quot;true&quot;,&#10;				&quot;action_parameters&quot;: {&#10;					&quot;id&quot;: &quot;&lt;MANAGED_RULESET_ID&gt;&quot;&#10;				},&#10;				&quot;last_updated&quot;: &quot;2021-03-17T15:42:37.917815Z&quot;&#10;			}&#10;		],&#10;		&quot;last_updated&quot;: &quot;2021-03-17T15:42:37.917815Z&quot;,&#10;		&quot;phase&quot;: &quot;http_request_firewall_managed&quot;&#10;	},&#10;	&quot;success&quot;: true,&#10;	&quot;errors&quot;: [],&#10;	&quot;messages&quot;: []&#10;}&#10;</code></pre>
<h3 id="example-get-an-entry-point-ruleset-at-the-account-level">Example: Get an entry point ruleset at the account level</h3>
<p>The following <a href="/api/resources/rulesets/subresources/phases/methods/get/">GET request</a> obtains the definition of the entry point ruleset for the <code>http_request_firewall_managed</code> phase at the account level.</p>
<pre class="nb-api-request"><code class="language-bash">curl --request GET \&#10;  --url https://api.cloudflare.com/client/v4/accounts/{account_id}/rulesets/phases/{ruleset_phase}/entrypoint \&#10;  --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;</code></pre>
<h2 id="view-the-rules-included-in-a-ruleset">View the rules included in a ruleset</h2>
<p>You can view all versions of phase entry point rulesets (at the account and zone levels) and custom rulesets, but you can only view the most recent version of managed rulesets.</p>
<h3 id="example-view-rules-in-a-phase-entry-point-ruleset-at-the-zone-level">Example: View rules in a phase entry point ruleset at the zone level</h3>
<p>The following <a href="/api/resources/rulesets/subresources/phases/subresources/versions/methods/get/">GET request</a> lists the rules in version <code>2</code> of the <code>http_request_firewall_managed</code> phase entry point ruleset at the zone level.</p>
<pre class="nb-api-request"><code class="language-bash">curl --request GET \&#10;  --url https://api.cloudflare.com/client/v4/zones/{zone_id}/rulesets/phases/{ruleset_phase}/entrypoint/versions/{ruleset_version} \&#10;  --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;</code></pre>
