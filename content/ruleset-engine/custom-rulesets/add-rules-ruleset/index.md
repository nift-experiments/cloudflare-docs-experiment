<p>To add rules to an existing custom ruleset, use the <a href="/api/resources/rulesets/methods/update/">Update an account or zone ruleset</a> operation and pass the rules in an array. Each rule has an expression and an action.</p>

<h2 id="add-rules">Add rules</h2>
<p>The following request adds two rules to a custom ruleset at the account level with ID <code>$RULESET_ID</code>. These will be the only two rules in the ruleset.</p>
<p>The response will include the rule ID of the new rules in the <code>id</code> field.</p>

<h2 id="update-rules">Update rules</h2>
<p>To update one or more rules in a custom ruleset, use the <a href="/api/resources/rulesets/methods/update/">Update an account or zone ruleset</a> operation. Include the ID of the rules you want to modify in the rules array and add the fields you wish to update. The request replaces the entire ruleset with a new version. Therefore, you must include the ID of all the rules you wish to keep.</p>
<p>The following <code>PUT</code> request edits one rule in a custom ruleset at the account level and updates the execution order of the rules.</p>
<p>The response will include the modified custom ruleset. Note that the updated rule and ruleset version number increment.</p>
<pre class="nb-api-request"><code class="language-bash">curl --request PUT \&#10;  --url https://api.cloudflare.com/client/v4/accounts/{account_id}/rulesets/{ruleset_id} \&#10;  --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \&#10;  --data &#x27;{&#10;  &quot;rules&quot;: [&#10;    {&#10;      &quot;id&quot;: &quot;&lt;CUSTOM_RULE_ID_2&gt;&quot;,&#10;      &quot;expression&quot;: &quot;not http.request.uri.path matches \&quot;^/api/.*$\&quot;&quot;,&#10;      &quot;action&quot;: &quot;js_challenge&quot;,&#10;      &quot;description&quot;: &quot;js_challenge when not /api&quot;&#10;    },&#10;    {&#10;      &quot;id&quot;: &quot;&lt;CUSTOM_RULE_ID_1&gt;&quot;&#10;    }&#10;  ]&#10;}&#x27;</code></pre>
