<p>To deploy a custom ruleset, add a rule with <code>execute</code> action to the list of rules of a phase <a href="/ruleset-engine/about/rulesets/#entry-point-ruleset">entry point ruleset</a> at the account or zone level. The expression of the new rule will define when the custom ruleset will run.</p>
<p>You can only deploy custom rulesets in an entry point ruleset with the same scope. For example, a custom ruleset defined at the account level can only be deployed at the account level.</p>
<p>If you are using Terraform, refer to <a href="/terraform/additional-configurations/waf-custom-rules/#create-and-deploy-a-custom-ruleset">WAF custom rules configuration using Terraform</a> for examples of creating and deploying custom rulesets.</p>
<p>If you are using the Cloudflare dashboard, refer to <a href="/waf/account/custom-rulesets/create-dashboard/">Work with custom rulesets in the dashboard</a>.</p>

<h2 id="before-you-begin">Before you begin</h2>
<ol>
<li>Obtain the name of the <a href="/ruleset-engine/reference/phases-list/">phase</a> where you want to deploy the custom ruleset.</li>
<li><a href="/ruleset-engine/custom-rulesets/create-custom-ruleset/">Create a custom ruleset</a> and keep the ID of the new custom ruleset.</li>
<li><a href="/ruleset-engine/basic-operations/view-rulesets/#view-the-rules-included-in-a-ruleset">Fetch the rules already present in the phase entry point ruleset</a>. You must include in the <code>PUT</code> request all existing rules you want to keep.</li>
</ol>
<h2 id="example-a-account-level-deployment">Example A - Account-level deployment</h2>
<p>The following <code>PUT</code> request adds a rule that executes a custom ruleset when the zone name matches <code>example.com</code>.</p>
<p>In the <code>PUT</code> request, you must include the IDs of all existing rules you want to keep. The response will include all the rules in the phase entry point ruleset after the update.</p>

<h2 id="example-b-zone-level-deployment">Example B - Zone-level deployment</h2>
<p>The following <code>PUT</code> request adds a rule to a zone-level entry point ruleset that executes a custom ruleset with ID <code>&quot;&lt;CUSTOM_RULESET_ID&gt;&quot;</code> for requests targeting the <code>/login</code> URI path.</p>
<p>You must include in the <code>PUT</code> request the IDs of all existing rules you want to keep. The response will include all the rules in the phase entry point ruleset after the update.</p>
