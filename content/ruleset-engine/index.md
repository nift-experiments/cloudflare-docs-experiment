<p>The Cloudflare Ruleset Engine allows you to create and deploy rules and rulesets in different Cloudflare products using the same basic syntax.</p>
<h2 id="main-features">Main features</h2>
<ul>
<li><strong>Powerful syntax</strong>: Rule expressions use a powerful Rules language similar to the wirefilter syntax that allows you to create complex rules.</li>
<li><strong>High-performance rule evaluation</strong>: Allows you to have many rules in different Cloudflare products with almost no impact on performance.</li>
<li><strong>Engine powering different Cloudflare products</strong>: Cloudflare keeps building products on top of the Ruleset Engine, which means that you can use the same API methods for configuring different products, with the same customization possibilities. Additionally, the Ruleset Engine supports the different phases of the request life cycle at Cloudflare.</li>
</ul>
<h2 id="availability">Availability</h2>
<p>The Ruleset Engine supports different Cloudflare products. Refer to <a href="/ruleset-engine/reference/phases-list/">Phases list</a> and to each product's documentation for details.</p>
