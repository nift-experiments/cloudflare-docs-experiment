<h1 id="cf-api-gateway-auth-id-present">cf.api_gateway.auth_id_present</h1>

**Data type:** Boolean

<p>Indicates whether the request contained an API session authentication token, as defined by API Shield's saved <a href="/api-shield/get-started/#session-identifiers">session identifiers</a>.</p>
