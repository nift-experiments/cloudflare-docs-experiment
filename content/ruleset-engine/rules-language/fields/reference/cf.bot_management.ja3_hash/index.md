<h1 id="cf-bot-management-ja3-hash">cf.bot_management.ja3_hash</h1>

**Data type:** String

<p>Provides an SSL/TLS fingerprint to help you identify potential bot requests.</p>

<p>For more details, refer to <a href="/bots/additional-configurations/ja3-ja4-fingerprint/">JA3/JA4 Fingerprint</a>.</p>
<p>Requires a Cloudflare Enterprise plan with <a href="/bots/plans/bm-subscription/">Bot Management</a> enabled.</p>
