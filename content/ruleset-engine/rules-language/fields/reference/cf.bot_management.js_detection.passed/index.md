<h1 id="cf-bot-management-js-detection-passed">cf.bot_management.js_detection.passed</h1>

**Data type:** Boolean

<p>Indicates whether the visitor has previously passed a JS Detection.</p>

<p>For more details, refer to <a href="/bots/additional-configurations/javascript-detections/">JavaScript detections</a>.</p>
<p>Requires a Cloudflare Enterprise plan with <a href="/bots/plans/bm-subscription/">Bot Management</a> enabled.</p>
