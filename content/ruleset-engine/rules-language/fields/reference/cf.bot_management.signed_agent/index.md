<h1 id="cf-bot-management-signed-agent">cf.bot_management.signed_agent</h1>

**Data type:** Boolean

<p>Indicates whether or not the request originated from a known agent that self-identifies with Web Bot Auth, now classified as a <a href="/bots/concepts/bot/verified-bots/">verified bot or agent</a> labeled as intermediary.</p>

<p>Requires a Cloudflare Enterprise plan with <a href="/bots/plans/bm-subscription/">Bot Management</a> enabled.</p>

- Request
- Bots

**Keywords:** request, bots, client, visitor, agent, web bot auth
