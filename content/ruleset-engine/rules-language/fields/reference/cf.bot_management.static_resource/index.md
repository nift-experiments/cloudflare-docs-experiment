<h1 id="cf-bot-management-static-resource">cf.bot_management.static_resource</h1>

**Data type:** Boolean

<p>Indicates whether static resources should be included when you create a rule using <a href="/ruleset-engine/rules-language/fields/reference/cf.bot_management.score/"><code>cf.bot_management.score</code></a>.</p>

<p>For more details, refer to <a href="/bots/additional-configurations/static-resources/">Static resource protection</a>.</p>
<p>Requires a Cloudflare Enterprise plan with <a href="/bots/plans/bm-subscription/">Bot Management</a> enabled.</p>
