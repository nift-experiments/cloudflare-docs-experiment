<h1 id="cf-bot-management-verified-bot">cf.bot_management.verified_bot</h1>

**Data type:** Boolean

<p>Indicates whether the request originated from a known good bot or crawler.</p>

<p>Provides the same information as <a href="/ruleset-engine/rules-language/fields/reference/cf.client.bot/"><code>cf.client.bot</code></a>.</p>
<p>Requires a Cloudflare Enterprise plan with <a href="/bots/plans/bm-subscription/">Bot Management</a> enabled.</p>

- Request
- Bots
