<h1 id="cf-edge-server-ip">cf.edge.server_ip</h1>

**Data type:** IP address

<p>Represents the global network's IP address to which the HTTP request has resolved.</p>

<p>This field is only meaningful for <a href="/byoip/">BYOIP customers</a>.</p>
