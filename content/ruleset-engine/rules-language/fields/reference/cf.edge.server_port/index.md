<h1 id="cf-edge-server-port">cf.edge.server_port</h1>

**Data type:** Number

<p>Represents the port number at which the Cloudflare global network received the request.</p>

<p>Use this field to filter traffic on a specific port. The value is a port number in the range 1–65535.</p>
