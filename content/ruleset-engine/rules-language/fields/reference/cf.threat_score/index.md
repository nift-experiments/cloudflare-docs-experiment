<h1 id="cf-threat-score">cf.threat_score</h1>

**Data type:** Number

<p>Represents a Cloudflare threat score.</p>

<p>Previously, a threat score represented a Cloudflare threat score from 0–100, where 0 indicated low risk. Now, the threat score is always <code>0</code> (zero).</p>
