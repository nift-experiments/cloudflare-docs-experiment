<h1 id="cf-tls-ciphers-sha1">cf.tls_ciphers_sha1</h1>

**Data type:** String

<p>The SHA-1 fingerprint of the client TLS cipher list in received order, encoded in Base64 using big-endian format.</p>

**Example value:**

```txt
"GXSPDLP4G3X+prK73a4wBuOaHRc="
```
