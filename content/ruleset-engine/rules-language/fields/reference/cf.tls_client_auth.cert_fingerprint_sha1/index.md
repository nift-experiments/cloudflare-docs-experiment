<h1 id="cf-tls-client-auth-cert-fingerprint-sha1">cf.tls_client_auth.cert_fingerprint_sha1</h1>

**Data type:** String

<p>The SHA-1 fingerprint of the mTLS client certificate.</p>

<p>This field defaults to <code>&quot;&quot;</code> if the connection does not use <a href="/ssl/client-certificates/enable-mtls/">mTLS authentication</a>.</p>

**Example value:**

```txt
"933ad5282c560ae3f482a43ecd73bc9de878a190"
```
