<h1 id="cf-tls-client-auth-cert-issuer-serial">cf.tls_client_auth.cert_issuer_serial</h1>

**Data type:** String

<p>Serial number of the direct issuer of the mTLS client certificate.</p>

<p>This field defaults to <code>&quot;&quot;</code> if the connection does not use <a href="/ssl/client-certificates/enable-mtls/">mTLS authentication</a>.</p>

**Example value:**

```txt
"2688201DBA77402EA87118876F2E1B24CF8B0395"
```
