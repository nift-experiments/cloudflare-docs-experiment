<h1 id="cf-tls-client-auth-cert-presented">cf.tls_client_auth.cert_presented</h1>

**Data type:** Boolean

<p>Returns <code>true</code> when an mTLS client presents a certificate (valid or not).</p>

<p>This field defaults to <code>false</code> if the connection does not use <a href="/ssl/client-certificates/enable-mtls/">mTLS authentication</a>.</p>
