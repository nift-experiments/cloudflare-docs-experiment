<h1 id="cf-tls-client-auth-cert-ski">cf.tls_client_auth.cert_ski</h1>

**Data type:** String

<p>The Subject Key Identifier (SKI) of the mTLS client certificate.</p>

<p>This field defaults to <code>&quot;&quot;</code> if the connection does not use <a href="/ssl/client-certificates/enable-mtls/">mTLS authentication</a>.</p>

**Example value:**

```txt
"27846FAE6EAC4A8DAD9101B519CF1EB460242831"
```
