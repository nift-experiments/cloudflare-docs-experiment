<h1 id="cf-tls-client-extensions-sha1">cf.tls_client_extensions_sha1</h1>

**Data type:** String

<p>The SHA-1 fingerprint of TLS client extensions, encoded in Base64 using big-endian format.</p>

<p>For the little-endian version of this field, refer to <a href="/ruleset-engine/rules-language/fields/reference/cf.tls_client_extensions_sha1_le/"><code>cf.tls_client_extensions_sha1_le</code></a>.</p>

**Example value:**

```txt
"OWFiM2I5ZDc0YWI0YWYzZmFkMGU0ZjhlYjhiYmVkMjgxNTU5YTU2Mg=="
```
