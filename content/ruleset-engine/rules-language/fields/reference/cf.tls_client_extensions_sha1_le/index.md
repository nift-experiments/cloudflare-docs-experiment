<h1 id="cf-tls-client-extensions-sha1-le">cf.tls_client_extensions_sha1_le</h1>

**Data type:** String

<p>The SHA-1 fingerprint of TLS client extensions, encoded in Base64 using little-endian format.</p>

<p>For the big-endian version of this field, refer to <a href="/ruleset-engine/rules-language/fields/reference/cf.tls_client_extensions_sha1/"><code>cf.tls_client_extensions_sha1</code></a>.</p>

**Example value:**

```txt
"7zIpdDU5pvFPPBI2/PCzqbaXnRA="
```
