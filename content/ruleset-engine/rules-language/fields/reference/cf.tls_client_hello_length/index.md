<h1 id="cf-tls-client-hello-length">cf.tls_client_hello_length</h1>

**Data type:** Number

<p>The length of the client hello message sent in a <a href="https://www.cloudflare.com/learning/ssl/what-happens-in-a-tls-handshake">TLS handshake</a>.</p>

<p>Specifically, the length of the bytestring of the client hello.</p>

**Example value:**

```txt
508
```
