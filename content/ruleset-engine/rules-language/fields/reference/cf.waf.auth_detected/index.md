<h1 id="cf-waf-auth-detected">cf.waf.auth_detected</h1>

**Data type:** Boolean

<p>Indicates whether the Cloudflare WAF detected authentication credentials in the request.</p>

<p>Requires a Cloudflare Enterprise plan. You must also enable <a href="/waf/detections/leaked-credentials/">leaked credentials detection</a>.</p>

**Keywords:** request, cloudflare, leaked credentials, exposed credentials, client, visitor
