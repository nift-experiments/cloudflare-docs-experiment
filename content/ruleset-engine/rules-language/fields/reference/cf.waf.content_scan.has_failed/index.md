<h1 id="cf-waf-content-scan-has-failed">cf.waf.content_scan.has_failed</h1>

**Data type:** Boolean

<p>Indicates whether the file scanner was unable to scan any of the content objects detected in the request.</p>

<p>Requires a Cloudflare Enterprise plan with <a href="/waf/detections/malicious-uploads/">malicious uploads detection</a>.</p>
