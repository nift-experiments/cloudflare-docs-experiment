<h1 id="cf-waf-credential-check-password-leaked">cf.waf.credential_check.password_leaked</h1>

**Data type:** Boolean

<p>Indicates whether the password detected in the request was previously leaked.</p>

<p>Only available when <a href="/waf/detections/leaked-credentials/">leaked credentials detection</a> is enabled.</p>
