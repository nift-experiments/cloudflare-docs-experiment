<h1 id="cf-waf-credential-check-username-and-password-leaked">cf.waf.credential_check.username_and_password_leaked</h1>

**Data type:** Boolean

<p>Indicates whether the auth credentials detected in the request (username-password pair) were previously leaked.</p>

<p>Requires a Cloudflare Pro plan or above. You must also enable <a href="/waf/detections/leaked-credentials/">leaked credentials detection</a>.</p>
