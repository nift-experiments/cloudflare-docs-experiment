<h1 id="cf-waf-credential-check-username-leaked">cf.waf.credential_check.username_leaked</h1>

**Data type:** Boolean

<p>Indicates whether the username detected in the request was previously leaked.</p>

<p>Requires a Cloudflare Enterprise plan. You must also enable <a href="/waf/detections/leaked-credentials/">leaked credentials detection</a>.</p>
