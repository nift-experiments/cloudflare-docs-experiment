<h1 id="cf-waf-credential-check-username-password-similar">cf.waf.credential_check.username_password_similar</h1>

**Data type:** Boolean

<p>Indicates whether a similar version of the username and password credentials detected in the request were previously leaked.</p>

<p>Requires a Cloudflare Enterprise plan. You must also enable <a href="/waf/detections/leaked-credentials/">leaked credentials detection</a>.</p>
