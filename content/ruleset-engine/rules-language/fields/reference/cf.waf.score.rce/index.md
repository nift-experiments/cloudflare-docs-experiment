<h1 id="cf-waf-score-rce">cf.waf.score.rce</h1>

**Data type:** Number

<p>An attack score from 1–99 classifying the command injection or Remote Code Execution (RCE) attack vector.</p>

<p>Requires a Cloudflare Enterprise plan. You must also enable <a href="/waf/detections/attack-score/">attack score detection</a>.</p>
