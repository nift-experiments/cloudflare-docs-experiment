<h1 id="cf-waf-score-xss">cf.waf.score.xss</h1>

**Data type:** Number

<p>An attack score from 1–99 classifying the cross-site scripting (XSS) attack vector.</p>

<p>Requires a Cloudflare Enterprise plan. You must also enable <a href="/waf/detections/attack-score/">attack score detection</a>.</p>
