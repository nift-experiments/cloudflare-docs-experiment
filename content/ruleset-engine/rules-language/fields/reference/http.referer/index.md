<h1 id="http-referer">http.referer</h1>

**Data type:** String

<p>The HTTP <code>Referer</code> request header, which contains the address of the web page that linked to the currently requested page.</p>

**Example value:**

```txt
"https://developer.example.org/en-US/docs/Web/JavaScript"
```
