<h1 id="http-request-full-uri">http.request.full_uri</h1>

**Data type:** String

<p>The full URI as received by the web server.</p>

<p>The value will not include the <code>#fragment</code> part, which is not sent to web servers.</p>

**Example value:**

```txt
"https://www.example.org/articles/index?section=539061&expand=comments"
```
