<h1 id="http-request-jwt-claims-jti-values">http.request.jwt.claims.jti.values</h1>

**Data type:** Array<String>

<p>The <code>jti</code> (JWT ID) claim provides a unique identifier for the JWT.</p>

<p>For details, refer to the <a href="https://datatracker.ietf.org/doc/html/rfc7519#section-4.1">Registered Claim Names</a> in RFC 7519.</p>
<p>Requires a Cloudflare Enterprise plan with a paid add-on.</p>
<p>For more information on validating JSON Web Tokens, refer to <a href="/api-shield/security/jwt-validation/">JSON Web Tokens Validation</a> in the API Shield documentation.</p>
