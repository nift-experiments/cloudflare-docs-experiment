<h1 id="http-request-jwt-claims-sub">http.request.jwt.claims.sub</h1>

**Data type:** Map<Array<String>>

<p>The <code>sub</code> (subject) claim identifies the principal that is the subject of the JWT.</p>

<p>The claims in a JWT are normally statements about the subject. For details, refer to the <a href="https://datatracker.ietf.org/doc/html/rfc7519#section-4.1">Registered Claim Names</a> in RFC 7519.</p>
<p>Requires a Cloudflare Enterprise plan with a paid add-on.</p>
<p>For more information on validating JSON Web Tokens, refer to <a href="/api-shield/security/jwt-validation/">JSON Web Tokens Validation</a> in the API Shield documentation.</p>
