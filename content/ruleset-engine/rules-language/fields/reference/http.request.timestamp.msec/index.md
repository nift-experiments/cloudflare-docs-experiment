<h1 id="http-request-timestamp-msec">http.request.timestamp.msec</h1>

**Data type:** Integer

<p>The millisecond when Cloudflare received the request, between 0–999.</p>

<p>To obtain the complete timestamp, use both <a href="/ruleset-engine/rules-language/fields/reference/http.request.timestamp.sec/"><code>http.request.timestamp.sec</code></a> and <a href="/ruleset-engine/rules-language/fields/reference/http.request.timestamp.msec/"><code>http.request.timestamp.msec</code></a> fields.</p>

**Example value:**

```txt
857
```
