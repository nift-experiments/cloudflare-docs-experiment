<h1 id="http-request-version">http.request.version</h1>

**Data type:** String

<p>The version of the HTTP protocol used. Use this field when different checks are needed for different versions.</p>

<p>Example values:</p>
<ul>
<li><code>&quot;HTTP/1.1&quot;</code></li>
<li><code>&quot;HTTP/3&quot;</code></li>
</ul>
