<h1 id="http-response-code">http.response.code</h1>

**Data type:** Integer

<p>The HTTP status code returned to the client, either set by a Cloudflare product or returned by the origin server.</p>

<p><strong>Note</strong>: The availability of HTTP response fields depends on the exact Cloudflare feature and your Cloudflare plan.</p>

**Example value:**

```txt
403
```
