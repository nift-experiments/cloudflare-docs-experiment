<h1 id="http-user-agent">http.user_agent</h1>

**Data type:** String

<p>The HTTP <code>User-Agent</code> request header, which contains a characteristic string to identify the client operating system and web browser.</p>

**Example value:**

```txt
"Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/65.0.3325.181 Safari/537.36"
```
