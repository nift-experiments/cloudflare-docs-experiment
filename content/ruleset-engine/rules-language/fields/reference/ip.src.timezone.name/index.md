<h1 id="ip-src-timezone-name">ip.src.timezone.name</h1>

**Data type:** String

<p>The name of the timezone associated with the incoming request.</p>

<p>This field is only available in rewrite expressions of <a href="/rules/transform/">Transform Rules</a>.</p>

**Example value:**

```txt
"America/Chicago"
```
