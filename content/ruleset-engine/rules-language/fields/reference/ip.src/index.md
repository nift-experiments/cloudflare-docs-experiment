<h1 id="ip-src">ip.src</h1>

**Data type:** IP address

<p>The client TCP IP address, which may be adjusted to reflect the actual address of the client using HTTP headers such as <code>X-Forwarded-For</code> or <code>X-Real-IP</code>.</p>

**Example value:**

```txt
93.184.216.34
```
