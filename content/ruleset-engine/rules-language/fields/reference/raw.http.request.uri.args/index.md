<h1 id="raw-http-request-uri-args">raw.http.request.uri.args</h1>

**Data type:** Map<Array<String>>

<p>The raw HTTP URI arguments associated with a request represented as a Map (associative array).</p>

<p>This is the raw field version of the <a href="/ruleset-engine/rules-language/fields/reference/http.request.uri.args/"><code>http.request.uri.args</code></a> field. Raw fields, prefixed with <code>raw.</code>, preserve original request values for later evaluations. These fields are immutable during the entire request evaluation workflow, and they are not affected by the actions of previously matched rules.</p>
