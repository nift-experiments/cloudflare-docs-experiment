<h1 id="raw-http-request-uri-path-extension">raw.http.request.uri.path.extension</h1>

**Data type:** String

<p>The raw file extension in the request URI path without any transformation.</p>

<p>This is the raw field version of the <a href="/ruleset-engine/rules-language/fields/reference/http.request.uri.path.extension/"><code>http.request.uri.path.extension</code></a> field. Raw fields, prefixed with <code>raw.</code>, preserve original request values for later evaluations. These fields are immutable during the entire request evaluation workflow, and they are not affected by the actions of previously matched rules.</p>
