<p>The Cloudflare Rules language is a flexible and intuitive specification for building rule expressions. Based on the widely known <a href="https://www.wireshark.org/docs/wsug_html_chunked/ChWorkBuildDisplayFilterSection.html">Wireshark display filters</a>, the Rules language allows you to precisely target HTTP requests with a syntax and semantics familiar to security engineers.</p>
