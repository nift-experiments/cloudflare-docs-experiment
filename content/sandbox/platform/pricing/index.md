<p>Sandbox SDK pricing is determined by the underlying <a href="/containers/">Containers</a> platform it's built on.</p>

<p>Refer to <a href="/containers/platform/pricing/">Containers pricing</a> for complete details on:</p>
<ul>
<li>vCPU, memory, and disk usage rates</li>
<li>Network egress pricing</li>
<li>Instance types and their costs</li>
</ul>

<p>When using Sandbox, you'll also be billed for:</p>
<ul>
<li><a href="/workers/platform/pricing/">Workers</a> - Handles incoming requests to your sandbox</li>
<li><a href="/durable-objects/platform/pricing/">Durable Objects</a> - Powers each sandbox instance</li>
<li><a href="/workers/observability/logs/workers-logs/#pricing">Workers Logs</a> - Optional observability (if enabled)</li>
