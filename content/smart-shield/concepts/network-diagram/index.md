<p>The diagram below shows how requests flow through the Cloudflare network when Smart Shield is active, and where each feature applies along that path.</p>
<p><img src="/assets/upstream/images/smart-shield/network-diagram.png" alt="Network diagram of requests being processed with all Smart Shield features" /></p>
<p>Requests from visitors first reach a nearby lower-tier data center. For static (cacheable) content, the lower-tier checks its local cache. On a cache miss, the request moves to an upper-tier data center — selected by <a href="/smart-shield/configuration/smart-tiered-cache/">Smart Tiered Cache</a> based on lowest latency to your origin. If <a href="/smart-shield/configuration/regional-tiered-cache/">Regional Tiered Cache</a> is configured, a regional hub is checked before the upper-tier. Persistent storage through <a href="/smart-shield/configuration/cache-reserve/">Cache Reserve</a> provides a final cache layer before requesting content from your origin.</p>
<p>For dynamic (non-cacheable) requests, <a href="/smart-shield/configuration/argo/">Argo Smart Routing</a> finds the fastest network path to your origin. Between Cloudflare's upper-tier data centers and your origin, <a href="/smart-shield/concepts/connection-reuse/">connection reuse</a> packages multiple requests into a single connection, reducing the total number of connections your origin handles.</p>
<p><a href="/smart-shield/configuration/health-checks/">Health Checks</a> run from multiple data centers to monitor whether your origin is online and responsive. <a href="/smart-shield/configuration/dedicated-egress-ips/">Dedicated CDN Egress IPs</a> provide reserved IP addresses for traffic from Cloudflare to your origin, allowing you to restrict your origin firewall to a small allowlist.</p>
