<p>Since IPv6 address ranges are deployed globally, no forwarding is needed.</p>
<p>For IPv4 traffic, based on <a href="/smart-shield/configuration/dedicated-egress-ips/how-it-works/egress-ips/#ips-allocation">IPs allocation</a>, not all egress data centers will have access to an applicable dedicated CDN egress IP.</p>
<p>Dedicated CDN egress IPs do not forward to another location in response to traffic spikes. Instead, each IPv4 can be split across up to four locations, where some of these locations may have multiple data centers. IP capacity in each data center can also be adjusted in accordance with the amount of traffic that reaches each location.</p>
<p>After a request reaches Cloudflare on an ingress data center, and the cache service sends a request for the egress router to connect to your origin, the following scenarios are possible.</p>
<h3 id="traffic-can-egress-from-the-same-server">Traffic can egress from the same server</h3>
<p>If the server running the egress router has access to an applicable dedicated CDN egress IP, traffic egresses from that server.</p>

<h3 id="connection-forwarding-is-needed">Connection forwarding is needed</h3>
<p>If the server does not have access to an applicable IP, the following options are checked and the first that is possible will take place:</p>
<ul>
<li>Another server in the same data center has access to an applicable IP and the connection is forwarded to that server.</li>
</ul>
<pre tabindex="0"><code class="language-mermaid">flowchart LR&#10;        accTitle: Dedicated CDN Egress IPs and connection forwarding&#10;        accDescr: Diagram showing IPv4 connection forwarding for Dedicated CDN Egress IPs - Same data center.&#10;        A[Client]&#10;        subgraph Data center A&#10;        X[(Cache service)] --&gt; B[(Egress router &lt;br/&gt; &lt;small&gt;*no applicable IP&lt;/small&gt;)]&#10;        B --&gt; Y[(Egress server &lt;br/&gt; &lt;small&gt;*has applicable IP&lt;/small&gt;)]&#10;        end&#10;        C[(Origin server)]&#10;&#10;        A --ingress--&gt; X&#10;        Y --egress--&gt; C&#10;</code></pre>
<ul>
<li>Another data center in the same location has access to an applicable IP and the connection is forwarded to that data center.</li>
</ul>
<pre tabindex="0"><code class="language-mermaid">flowchart LR&#10;        accTitle: Dedicated CDN Egress IPs and connection forwarding&#10;        accDescr: Diagram showing IPv4 connection forwarding for Dedicated CDN Egress IPs - Different data center.&#10;        A[Client]&#10;        subgraph Location 1&#10;        subgraph Data center A&#10;        X[(Cache service)] --&gt; B[(Egress router &lt;br/&gt; &lt;small&gt;*no applicable IP&lt;/small&gt;)]&#10;        end&#10;        subgraph Data center B&#10;        B --&gt; Y[(Egress server &lt;br/&gt; &lt;small&gt;*has applicable IP&lt;/small&gt;)]&#10;        end&#10;        end&#10;        C[(Origin server)]&#10;&#10;&#10;        A --ingress--&gt; X&#10;        Y --egress--&gt; C&#10;</code></pre>
<ul>
<li>Another data center in a different location has access to an applicable IP. The closest location is selected and connection is forwarded to that location.</li>
</ul>
