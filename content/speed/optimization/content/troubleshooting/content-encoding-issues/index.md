<p>If you are noticing any encoding errors with your HTML pages, we recommend verifying that the impacted pages are explicitly setting the correct charset in the <code>Content-Type</code> header from your origin for all text/html pages, for example <code>Content-Type: text/html; charset=utf-8</code>. This is particularly important if you are not using <a href="https://en.wikipedia.org/wiki/UTF-8">UTF-8 encoding standard</a> for characters. Alternatively you can set the correct charset within the HTML.</p>
<p>If you believe these settings are correct, please inform us. You can find more information in <a href="https://www.w3.org/International/articles/http-charset/index">setting the HTTP charset parameter</a> and in <a href="https://www.w3schools.com/tags/att_meta_charset.asp">HTML charset attribute</a>.</p>
<p>Alternatively, you can use a <a href="/rules/configuration-rules/">Configuration Rule</a> to disable features that rewrite HTML. This will send the content as-is to the browser.</p>
<p>You also have the option to turn off these features site-wide within the dashboard:</p>
<ul>
<li><a href="/waf/tools/scrape-shield/email-address-obfuscation/">Email Obfuscation</a>, located in the <strong>Security</strong> &gt; <strong>Settings</strong> section.</li>
<li><a href="/speed/optimization/content/rocket-loader/">Rocket Loader</a>, located in <strong>Speed</strong> &gt; <strong>Settings</strong> &gt; <strong>Content Optimization</strong> section.</li>
<li><a href="/ssl/edge-certificates/additional-options/automatic-https-rewrites/">Automatic HTTPS Rewrites</a>, located in the <strong>SSL/TLS</strong> &gt; <strong>Edge Certificates</strong> section.</li>
</ul>
<p>Misconfiguring the <code>Content-Type</code> or charset within HTML, or leaving them unspecified can lead to unintended consequences. This can disrupt the intended content presentation, resulting in disorganized rendering and potentially unclear characters. Properly configuring these elements ensures consistent and accurate interpretation, correct HTML modifications, and accurate rendering for browsers. This creates a seamless user experience and aligns with best practices in web development.</p>
