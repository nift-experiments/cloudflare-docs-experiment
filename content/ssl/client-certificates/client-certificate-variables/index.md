<p>When a request includes a client certificate for <a href="/ssl/client-certificates/enable-mtls/">mTLS authentication</a>, Cloudflare exposes certificate details as variables in the Ruleset Engine and as properties on the Workers <code>request.cf</code> object.</p>
<h2 id="ruleset-engine-fields">Ruleset Engine fields</h2>
<p>Client certificate fields are available as <a href="/ruleset-engine/rules-language/fields/reference/?field-category=mTLS">mTLS fields</a> in Ruleset Engine-based products such as <a href="/waf/custom-rules/">WAF custom rules</a> and <a href="/rules/transform/request-header-modification/">request header modification rules</a>.</p>
<h2 id="workers-variables">Workers variables</h2>
<p>These variables are also available as part of the <a href="/workers/runtime-apis/request/#incomingrequestcfproperties"><code>request.cf.tlsClientAuth</code></a> object via Cloudflare Workers. Refer to the linked Rules language field for the full definition.</p>
<aside class="nb-aside note">
@markup("md", "content/.markup/bodies/14030.md")
</aside>
<ul>
<li><a href="/ruleset-engine/rules-language/fields/reference/cf.tls_client_auth.cert_revoked/"><code>request.cf.tlsClientAuth.certRevoked</code></a> — Indicates whether the mTLS client presented a valid but revoked client certificate. In Workers, this is a string (<code>&quot;1&quot;</code> for revoked, <code>&quot;0&quot;</code> for not revoked) rather than a boolean.</li>
<li><a href="/ruleset-engine/rules-language/fields/reference/cf.tls_client_auth.cert_verified/"><code>request.cf.tlsClientAuth.certVerified</code></a> — Indicates whether the mTLS client presented a valid client certificate. In Workers, this is a string (<code>&quot;SUCCESS&quot;</code> when valid, <code>&quot;NONE&quot;</code> when not present) rather than a boolean. On failure, the string contains the error reason (for example, <code>&quot;FAILED:unable to get local issuer certificate&quot;</code>).</li>
<li><a href="/ruleset-engine/rules-language/fields/reference/cf.tls_client_auth.cert_presented/"><code>request.cf.tlsClientAuth.certPresented</code></a> — Indicates whether the mTLS client presented a certificate (valid or not). In Workers, this is a string (<code>&quot;1&quot;</code> when a certificate is presented, <code>&quot;0&quot;</code> otherwise) rather than a boolean.</li>
<li><a href="/ruleset-engine/rules-language/fields/reference/cf.tls_client_auth.cert_issuer_dn/"><code>request.cf.tlsClientAuth.certIssuerDN</code></a> — The Distinguished Name (DN) of the Certificate Authority (CA) that issued the mTLS client certificate.</li>
<li><a href="/ruleset-engine/rules-language/fields/reference/cf.tls_client_auth.cert_subject_dn/"><code>request.cf.tlsClientAuth.certSubjectDN</code></a> — The Distinguished Name (DN) of the owner (or requester) of the mTLS client certificate.</li>
<li><a href="/ruleset-engine/rules-language/fields/reference/cf.tls_client_auth.cert_issuer_dn_rfc2253/"><code>request.cf.tlsClientAuth.certIssuerDNRFC2253</code></a> — The Distinguished Name (DN) of the Certificate Authority (CA) that issued the mTLS client certificate in <a href="https://www.rfc-editor.org/rfc/rfc2253">RFC 2253</a> format.</li>
<li><a href="/ruleset-engine/rules-language/fields/reference/cf.tls_client_auth.cert_subject_dn_rfc2253/"><code>request.cf.tlsClientAuth.certSubjectDNRFC2253</code></a> — The Distinguished Name (DN) of the owner (or requester) of the mTLS client certificate in <a href="https://www.rfc-editor.org/rfc/rfc2253">RFC 2253</a> format.</li>
<li><a href="/ruleset-engine/rules-language/fields/reference/cf.tls_client_auth.cert_issuer_dn_legacy/"><code>request.cf.tlsClientAuth.certIssuerDNLegacy</code></a> — The Distinguished Name (DN) of the Certificate Authority (CA) that issued the mTLS client certificate in a legacy format.</li>
<li><a href="/ruleset-engine/rules-language/fields/reference/cf.tls_client_auth.cert_subject_dn_legacy/"><code>request.cf.tlsClientAuth.certSubjectDNLegacy</code></a> — The Distinguished Name (DN) of the owner (or requester) of the mTLS client certificate in a legacy format.</li>
<li><a href="/ruleset-engine/rules-language/fields/reference/cf.tls_client_auth.cert_serial/"><code>request.cf.tlsClientAuth.certSerial</code></a> — Serial number of the mTLS client certificate.</li>
<li><a href="/ruleset-engine/rules-language/fields/reference/cf.tls_client_auth.cert_issuer_serial/"><code>request.cf.tlsClientAuth.certIssuerSerial</code></a> — Serial number of the direct issuer of the mTLS client certificate.</li>
<li><a href="/ruleset-engine/rules-language/fields/reference/cf.tls_client_auth.cert_fingerprint_sha256/"><code>request.cf.tlsClientAuth.certFingerprintSHA256</code></a> — The SHA-256 fingerprint of the mTLS client certificate.</li>
<li><a href="/ruleset-engine/rules-language/fields/reference/cf.tls_client_auth.cert_fingerprint_sha1/"><code>request.cf.tlsClientAuth.certFingerprintSHA1</code></a> — The SHA-1 fingerprint of the mTLS client certificate.</li>
<li><a href="/ruleset-engine/rules-language/fields/reference/cf.tls_client_auth.cert_not_before/"><code>request.cf.tlsClientAuth.certNotBefore</code></a> — The mTLS client certificate is not valid before this date.</li>
<li><a href="/ruleset-engine/rules-language/fields/reference/cf.tls_client_auth.cert_not_after/"><code>request.cf.tlsClientAuth.certNotAfter</code></a> — The mTLS client certificate is not valid after this date.</li>
<li><a href="/ruleset-engine/rules-language/fields/reference/cf.tls_client_auth.cert_ski/"><code>request.cf.tlsClientAuth.certSKI</code></a> — The Subject Key Identifier (SKI) of the mTLS client certificate.</li>
<li><a href="/ruleset-engine/rules-language/fields/reference/cf.tls_client_auth.cert_issuer_ski/"><code>request.cf.tlsClientAuth.certIssuerSKI</code></a> — The Subject Key Identifier (SKI) of the direct issuer of the mTLS client certificate.</li>
<li><a href="/ruleset-engine/rules-language/fields/reference/cf.tls_client_auth.cert_rfc9440/"><code>request.cf.tlsClientAuth.certRFC9440</code></a> — The client leaf certificate encoded in <a href="https://www.rfc-editor.org/rfc/rfc9440">RFC 9440</a> format (DER, Base64-encoded, colon-wrapped).</li>
<li><a href="/ruleset-engine/rules-language/fields/reference/cf.tls_client_auth.cert_rfc9440_too_large/"><code>request.cf.tlsClientAuth.certRFC9440TooLarge</code></a> — <code>true</code> if the leaf certificate exceeded the 10 KiB encoding limit and was omitted from <code>certRFC9440</code>.</li>
<li><a href="/ruleset-engine/rules-language/fields/reference/cf.tls_client_auth.cert_chain_rfc9440/"><code>request.cf.tlsClientAuth.certChainRFC9440</code></a> — The intermediate certificate chain in <a href="https://www.rfc-editor.org/rfc/rfc9440">RFC 9440</a> format as a comma-separated list.</li>
<li><a href="/ruleset-engine/rules-language/fields/reference/cf.tls_client_auth.cert_chain_rfc9440_too_large/"><code>request.cf.tlsClientAuth.certChainRFC9440TooLarge</code></a> — <code>true</code> if the intermediate chain exceeded the 16 KiB encoding limit and was omitted from <code>certChainRFC9440</code>.</li>
</ul>
