<p>This tutorial demonstrates how to configure your Internet-of-things (IoT) device and mobile application to use client certificates with <a href="/api-shield/">API Shield</a>.</p>
<h2 id="scenario-details">Scenario details</h2>
<p>This walkthrough uses the example of a device that captures temperature readings and transmits them by sending a POST request to a Cloudflare-protected API. A mobile application built in Swift for iOS retrieves those readings and displays them.</p>
<p>To keep this example simple, the API is implemented as a Cloudflare Worker (borrowing code from the <a href="/workers/tutorials/build-a-jamstack-app/">To-Do List tutorial on building a jamstack app</a>).</p>
<p>Temperatures are stored in <a href="/kv/concepts/how-kv-works/">Workers KV</a> using the source IP address as a key, but you can easily use a <a href="/cloudflare-one/access-controls/service-credentials/mutual-tls-authentication/">value from the client certificate</a>, such as the fingerprint.</p>
<p>The example API code below saves a temperature and timestamp into KV when a POST is made and returns the most recent five temperatures when a GET request is made.</p>
<pre tabindex="0"><code class="language-js">const defaultData = { temperatures: [] };&#10;&#10;const getCache = (key) =&gt; TEMPERATURES.get(key);&#10;const setCache = (key, data) =&gt; TEMPERATURES.put(key, data);&#10;&#10;async function addTemperature(request) {&#10;	// Pull previously recorded temperatures for this client.&#10;	const ip = request.headers.get(&quot;CF-Connecting-IP&quot;);&#10;	const cacheKey = `data-${ip}`;&#10;	let data;&#10;	const cache = await getCache(cacheKey);&#10;	if (!cache) {&#10;		await setCache(cacheKey, JSON.stringify(defaultData));&#10;		data = defaultData;&#10;	} else {&#10;		data = JSON.parse(cache);&#10;	}&#10;&#10;	// Append the recorded temperatures with the submitted reading (assuming it has both temperature and a timestamp).&#10;	try {&#10;		const body = await request.text();&#10;		const val = JSON.parse(body);&#10;&#10;		if (val.temperature &amp;&amp; val.time) {&#10;			data.temperatures.push(val);&#10;			await setCache(cacheKey, JSON.stringify(data));&#10;			return new Response(&quot;&quot;, { status: 201 });&#10;		} else {&#10;			return new Response(&#10;				&quot;Unable to parse temperature and/or timestamp from JSON POST body&quot;,&#10;				{ status: 400 },&#10;			);&#10;		}&#10;	} catch (err) {&#10;		return new Response(err, { status: 500 });&#10;	}&#10;}&#10;&#10;function compareTimestamps(a, b) {&#10;	return -1 * (Date.parse(a.time) - Date.parse(b.time));&#10;}&#10;&#10;// Return the 5 most recent temperature measurements.&#10;async function getTemperatures(request) {&#10;	const ip = request.headers.get(&quot;CF-Connecting-IP&quot;);&#10;	const cacheKey = `data-${ip}`;&#10;&#10;	const cache = await getCache(cacheKey);&#10;	if (!cache) {&#10;		return new Response(JSON.stringify(defaultData), {&#10;			status: 200,&#10;			headers: { &quot;content-type&quot;: &quot;application/json&quot; },&#10;		});&#10;	} else {&#10;		data = JSON.parse(cache);&#10;		const retval = JSON.stringify(&#10;			data.temperatures.sort(compareTimestamps).splice(0, 5),&#10;		);&#10;		return new Response(retval, {&#10;			status: 200,&#10;			headers: { &quot;content-type&quot;: &quot;application/json&quot; },&#10;		});&#10;	}&#10;}&#10;&#10;export default {&#10;	async fetch(request, env, ctx) {&#10;		return request.method === &quot;POST&quot;&#10;			? addTemperature(request)&#10;			: getTemperatures(request);&#10;	},&#10;};&#10;</code></pre>

<h2 id="2-create-cloudflare-issued-certificates"><ol start="2">
<li>Create Cloudflare-issued certificates</li>
</ol></h2>
<p>Before you can use API Shield to protect your API or web application, create Cloudflare-issued client certificates.</p>
<p>You can <a href="/ssl/client-certificates/create-a-client-certificate/">create a client certificate in the Cloudflare dashboard</a>.</p>
<p>However, since most developers working at scale generate their own private keys and certificate signing requests via API, this example uses the Cloudflare API to create client certificates.</p>

<h2 id="3-embed-the-client-certificate-in-your-mobile-app"><ol start="3">
<li>Embed the client certificate in your mobile app</li>
</ol></h2>
<p>To configure the mobile app to securely request temperature data submitted by the IoT device, embed the client certificate in the mobile app.</p>
<p>For simplicity, this example embeds a “bootstrap” certificate and key in the application bundle as a PKCS#12-formatted file:</p>
<pre tabindex="0"><code class="language-sh">$ openssl pkcs12 -export -out bootstrap-cert.pfx -inkey ios-key.pem -in ios.pem&#10;Enter Export Password:&#10;Verifying - Enter Export Password:&#10;</code></pre>
<p>In a real-world deployment, a bootstrap certificate should only be used in conjunction with users' credentials to authenticate with an API endpoint that can return a unique user certificate. Corporate users will want to use mobile device management (MDM) to distribute certificates.</p>
<h3 id="embed-the-client-certificate-in-an-android-app">Embed the client certificate in an Android app</h3>
<p>The following is an example of how you may use a client certificate in an Android app to make HTTP calls. You need to add the following permission in <code>AndroidManifest.xml</code> to allow an Internet connection.</p>
<pre tabindex="0"><code class="language-xml">&lt;uses-permission android:name=&quot;android.permission.INTERNET&quot; /&gt;&#10;</code></pre>
<p>For demonstration purposes, the certificate in this example is stored in <code>app/src/main/res/raw/cert.pem</code> and the private key is stored in <code>app/src/main/res/raw/key.pem</code>. You may also store these files in other secure manners.</p>
<p>The following example uses an <code>OkHttpClient</code>, but you may also use other clients such as <code>HttpURLConnection</code> in similar ways. The key is to use the <code>SSLSocketFactory</code>.</p>
<pre tabindex="0"><code class="language-java">private OkHttpClient setUpClient() {&#10;    try {&#10;        final String SECRET = &quot;secret&quot;; // You may also store this String somewhere more secure.&#10;        CertificateFactory certificateFactory = CertificateFactory.getInstance(&quot;X.509&quot;);&#10;&#10;        // Get private key&#10;        InputStream privateKeyInputStream = getResources().openRawResource(R.raw.key);&#10;        byte[] privateKeyByteArray = new byte[privateKeyInputStream.available()];&#10;        privateKeyInputStream.read(privateKeyByteArray);&#10;&#10;        String privateKeyContent = new String(privateKeyByteArray, Charset.defaultCharset())&#10;                .replace(&quot;-----BEGIN PRIVATE KEY-----&quot;, &quot;&quot;)&#10;                .replaceAll(System.lineSeparator(), &quot;&quot;)&#10;                .replace(&quot;-----END PRIVATE KEY-----&quot;, &quot;&quot;);&#10;&#10;        // Get certificate&#10;        InputStream certificateInputStream = getResources().openRawResource(R.raw.cert);&#10;        Certificate certificate = certificateFactory.generateCertificate(certificateInputStream);&#10;&#10;        // Set up KeyStore&#10;        KeyStore keyStore = KeyStore.getInstance(KeyStore.getDefaultType());&#10;        keyStore.load(null, SECRET.toCharArray());&#10;        keyStore.setKeyEntry(&quot;client&quot;, keyFactory.generatePrivate(keySpec), SECRET.toCharArray(), new Certificate[]{certificate});&#10;        certificateInputStream.close();&#10;&#10;        // Set up Trust Managers&#10;        TrustManagerFactory trustManagerFactory = TrustManagerFactory.getInstance(TrustManagerFactory.getDefaultAlgorithm());&#10;        trustManagerFactory.init((KeyStore) null);&#10;        TrustManager[] trustManagers = trustManagerFactory.getTrustManagers();&#10;&#10;        // Set up Key Managers&#10;        KeyManagerFactory keyManagerFactory = KeyManagerFactory.getInstance(KeyManagerFactory.getDefaultAlgorithm());&#10;        keyManagerFactory.init(keyStore, SECRET.toCharArray());&#10;        KeyManager[] keyManagers = keyManagerFactory.getKeyManagers();&#10;&#10;        // Obtain SSL Socket Factory&#10;        SSLContext sslContext = SSLContext.getInstance(&quot;TLS&quot;);&#10;        sslContext.init(keyManagers, trustManagers, new SecureRandom());&#10;        SSLSocketFactory sslSocketFactory = sslContext.getSocketFactory();&#10;&#10;        // Finally, return the client, which will then be used to make HTTP calls.&#10;        OkHttpClient client = new OkHttpClient.Builder()&#10;                .sslSocketFactory(sslSocketFactory, (X509TrustManager) trustManagers[0])&#10;                .build();&#10;&#10;        return client;&#10;&#10;    } catch (CertificateException | IOException | NoSuchAlgorithmException | KeyStoreException | UnrecoverableKeyException | KeyManagementException | InvalidKeySpecException e) {&#10;        e.printStackTrace();&#10;        return null;&#10;    }&#10;}&#10;</code></pre>
<p>The above function returns an <code>OkHttpClient</code> embedded with the client certificate. You can now use this client to make HTTP requests to your API endpoint protected with mTLS.</p>

<h2 id="4-embed-the-client-certificate-on-your-iot-device"><ol start="4">
<li>Embed the client certificate on your IoT device</li>
</ol></h2>
<p>To prepare the IoT device for secure communication with the API endpoint, embed the certificate on the device and configure the device to use the certificate when making POST requests.</p>
<p>This example assumes the certificate and the private key are securely copied to <code>/etc/ssl/private/sensor-key.pem</code> and <code>/etc/ssl/certs/sensor.pem</code>.</p>
<p>The sample script is modified to point to these files:</p>
<pre tabindex="0"><code class="language-python">import requests&#10;import json&#10;from datetime import datetime&#10;&#10;def readSensor():&#10;&#10;    &#35; Takes a reading from a temperature sensor and store it to temp_measurement&#10;&#10;    dateTimeObj = datetime.now()&#10;    timestampStr = dateTimeObj.strftime(&#x27;%Y-%m-%dT%H:%M:%SZ&#x27;)&#10;&#10;    measurement = {&#x27;temperature&#x27;:str(temp_measurement),&#x27;time&#x27;:timestampStr}&#10;    return measurement&#10;&#10;def main():&#10;&#10;    print(&quot;Cloudflare API Shield [IoT device demonstration]&quot;)&#10;&#10;    temperature = readSensor()&#10;    payload = json.dumps(temperature)&#10;&#10;    url = &#x27;https://shield.upinatoms.com/temps&#x27;&#10;    json_headers = {&#x27;Content-Type&#x27;: &#x27;application/json&#x27;}&#10;    cert_file = (&#x27;/etc/ssl/certs/sensor.pem&#x27;, &#x27;/etc/ssl/private/sensor-key.pem&#x27;)&#10;&#10;    r = requests.post(url, headers = json_headers, data = payload, cert = cert_file)&#10;&#10;    print(&quot;Request body: &quot;, r.request.body)&#10;    print(&quot;Response status code: %d&quot; % r.status_code)&#10;</code></pre>
<p>When the script attempts to connect to <code>https://shield.upinatoms.com/temps</code>, Cloudflare requests that a client certificate is sent and the script sends the contents of <code>/etc/ssl/certs/sensor.pem</code>. Then, as required to complete the SSL/TLS handshake, the script demonstrates it has possession of <code>/etc/ssl/private/sensor-key.pem</code>.</p>
<p>Without the client certificate, the Cloudflare rejects the request:</p>
<pre tabindex="0"><code class="language-txt">Cloudflare API Shield [IoT device demonstration]&#10;Request body:  {&quot;temperature&quot;: &quot;36.5&quot;, &quot;time&quot;: &quot;2020-09-28T15:52:19Z&quot;}&#10;Response status code: 403&#10;</code></pre>
<p>When the IoT device presents a valid client certificate, the POST request succeeds and the temperature reading is recorded:</p>
<pre tabindex="0"><code class="language-txt">Cloudflare API Shield [IoT device demonstration]&#10;Request body:  {&quot;temperature&quot;: &quot;36.5&quot;, &quot;time&quot;: &quot;2020-09-28T15:56:45Z&quot;}&#10;Response status code: 201&#10;</code></pre>

<h2 id="6-configure-api-shield-to-require-client-certificates"><ol start="6">
<li>Configure API Shield to require client certificates</li>
</ol></h2>
<p>To configure API Shield to require client certificates, <a href="/api-shield/security/mtls/configure/#create-an-mtls-rule">create a mTLS rule</a>.</p>
