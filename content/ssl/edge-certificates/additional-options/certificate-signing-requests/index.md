<p>Generate a Certificate Signing Request (CSR) to get a custom certificate from the Certificate Authority (CA) of your choice while maintaining control of the private key on Cloudflare. The private key associated with the CSR will be generated by Cloudflare and will never leave our network.</p>
<p>A CSR contains information about your domain: your organization name and address, the common name (domain name), and Subject Alternative Names (SANs).</p>

<h2 id="types-of-csrs">Types of CSRs</h2>
<p>You can create two types of CSRs:</p>
<ul>
<li><strong>Zone-level</strong>: Meant only for sign certificates associated with the current zone.</li>
<li><strong>Account-level</strong>: Meant for organizations that issue certificates across multiple domains.</li>
</ul>
<h2 id="create-and-use-a-csr">Create and use a CSR</h2>
<p>To create a CSR:</p>
<ol>
<li>In the Cloudflare dashboard, go to the <strong>Edge Certificates</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
<ol start="2">
<li>On <strong>Certificate Signing Request (CSR)</strong>, select <strong>Generate</strong>.</li>
<li>Choose a <strong>Scope</strong> (only <a href="#types-of-csrs">certain customers</a> can choose <strong>Account</strong>).</li>
<li>Enter relevant information on the form and select <strong>Create</strong>.</li>
</ol>
<p>To use a CSR:</p>
<ol>
<li>On the <a href="https://dash.cloudflare.com/?to=/:account/:zone/ssl-tls/edge-certificates"><strong>Edge Certificates</strong></a> page, select the CSR record you just created under <strong>Certificate Signing Request (CSR)</strong>.</li>
<li>Copy (or select <strong>Click to copy</strong>) the value for <strong>Certificate Signing Request</strong>.</li>
<li>Obtain a certificate from the Certificate Authority (CA) of your choice using your CSR.</li>
<li>When you <a href="/ssl/edge-certificates/custom-certificates/uploading/">upload the custom certificate</a> to Cloudflare, select an <strong>Encoding mode</strong> of <strong>Certificate Signing Request (CSR)</strong> and enter the associated value.</li>
</ol>

<h2 id="renew-a-certificate">Renew a certificate</h2>
<p>When you <a href="/ssl/edge-certificates/custom-certificates/renewing/">renew a custom certificate</a>, you need to reuse a previously generated CSR.</p>
<p>Note that it is not possible to use a different CSR with the same certificate. In this case, you must upload the certificate as a new certificate, selecting the new CSR.</p>
