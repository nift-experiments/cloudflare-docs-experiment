<p>You can use Cloudflare Keyless SSL with <a href="https://www.fortanix.com/platform/data-security-manager">Fortanix Data Security Manager (DSM)</a>, a FIPS 140-2 Level 3 certified implementation.</p>
<p>You must have a <a href="https://www.fortanix.com/start-your-free-trial">Data Security Manager Enterprise Tier</a> and set up a group and an application assigned to the group.</p>
<p>For detailed guidance, follow the tutorial in the <a href="https://support.fortanix.com/docs/fortanix-data-security-manager-with-cloudflare-integration#50-configure-fortanix-dsm">Fortanix documentation</a>. This guide is based on the Keyless SSL <a href="/ssl/keyless-ssl/configuration/public-dns/">public DNS</a> option and has been tested using a virtual machine (VM) deployed to Azure running Ubuntu 22.04.3 LTS.</p>
