<p>Cloudflare does not support <span class="nb-glossary-tooltip" title="certificate pinning">HTTP public key pinning (HPKP)</span> for universal, advanced, or custom hostname certificates.</p>
<p>Cloudflare regularly rotates the edge certificates provisioned for your domain. If HPKP was enabled, your domain would go offline each time a certificate rotates because the new certificate would not match the pinned key. Additionally, <a href="https://scotthelme.co.uk/im-giving-up-on-hpkp/">industry experts</a> discourage using HPKP. For a detailed overview, refer to the Cloudflare blog post on <a href="https://blog.cloudflare.com/why-certificate-pinning-is-outdated/">why certificate pinning is outdated</a>.</p>
<h2 id="recommended-alternative">Recommended alternative</h2>
<p>The problem HPKP tries to solve is preventing certificate misissuance. A safer way to detect misissuance without risking downtime is <a href="/ssl/edge-certificates/additional-options/certificate-transparency-monitoring/">Certificate Transparency Monitoring</a>, which alerts you when a certificate is issued for your domain.</p>
<h2 id="if-you-must-pin-certificates">If you must pin certificates</h2>
<p>If your use case requires certificate pinning, the only advisable approach is to upload a <a href="/ssl/edge-certificates/custom-certificates/">custom certificate</a> to Cloudflare and pin to that certificate. Because you control the certificate lifecycle — including renewal timing, CA selection, and key material — you can ensure pin continuity. However, pinning still carries outage risk: if a renewal deploys a new key, clients pinned to the old key will fail TLS. If you need pin continuity, you must intentionally reuse the same key material during renewal. Test renewed certificates in the <a href="/ssl/edge-certificates/staging-environment/">staging environment</a> before production.</p>
<p>Select the <a href="/ssl/edge-certificates/custom-certificates/bundling-methodologies/#user-defined"><strong>user-defined</strong> bundle method</a> so that you control exactly which CA, intermediate, and leaf certificate are served.</p>
