<p class="article-summary">Example of video playback with Cloudflare Stream and Shaka Player</p>
<p>First, create a video element, using the poster attribute to set a preview thumbnail image. Refer to <a href="/stream/viewing-videos/displaying-thumbnails/">Display thumbnails</a> for instructions on how to generate a thumbnail image using Cloudflare Stream.</p>
<pre><code class="language-html">&lt;video&#10;	id=&quot;video&quot;&#10;	width=&quot;640&quot;&#10;	poster=&quot;https://customer-f33zs165nr7gyfy4.cloudflarestream.com/6b9e68b07dfee8cc2d116e4c51d6a957/thumbnails/thumbnail.jpg&quot;&#10;	controls&#10;	autoplay&#10;&gt;&lt;/video&gt;&#10;</code></pre>
<p>Then listen for <code>DOMContentLoaded</code> event, create a new instance of Shaka Player, and load the manifest URI.</p>
<pre><code class="language-javascript">// Replace the manifest URI with an HLS or DASH manifest from Cloudflare Stream&#10;const manifestUri =&#10;	&#x27;https://customer-f33zs165nr7gyfy4.cloudflarestream.com/6b9e68b07dfee8cc2d116e4c51d6a957/manifest/video.mpd&#x27;;&#10;&#10;document.addEventListener(&#x27;DOMContentLoaded&#x27;, () =&gt; {&#10;	const video = document.getElementById(&#x27;video&#x27;);&#10;  const player = new shaka.Player(video);&#10;	await player.load(manifestUri);&#10;});&#10;</code></pre>
<p>Refer to the <a href="https://github.com/shaka-project/shaka-player">Shaka Player documentation</a> for more information.</p>
