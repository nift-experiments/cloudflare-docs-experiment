<p>Live streams are automatically recorded, and available instantly once a live stream ends. To get a list of recordings for a given input ID, make a <a href="/api/resources/stream/subresources/live_inputs/methods/get/"><code>GET</code> request to <code>/live_inputs/&lt;UID&gt;/videos</code></a> and filter for videos where <code>state</code> is set to <code>ready</code>:</p>
