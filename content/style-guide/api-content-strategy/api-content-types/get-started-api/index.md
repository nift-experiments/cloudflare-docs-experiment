<h2 id="purpose">Purpose</h2>
<p>The Get started section provides a brief overview of the Cloudflare’s API and lists requirements and tasks users must complete before successfully making their first request.</p>
<h2 id="structure">Structure</h2>
<h3 id="required-components">Required components</h3>
<p><strong>Overview</strong>: High-level explanation of Cloudflare’s API and includes information about our architectural style, schema, and base URL.</p>
<p><strong>Authentication</strong>: Explains how users can authenticate with the Cloudflare API and how users should or can utilize API tokens, API token templates, and API token permissions.</p>
<h2 id="example">Example</h2>
<p><strong>Overview</strong>: Cloudflare's API exposes the entire Cloudflare infrastructure via a standardized programmatic interface. Cloudflare’s API uses <code>REST</code> and returns <code>JSON</code> responses, and the latest version is <code>v4</code>.</p>
<p><strong>Recommended workflow</strong>:</p>
<ol>
<li>Sign up for a Cloudflare account.</li>
<li>Create an API token.</li>
<li>(Optional) Use API token templates and token permissions.</li>
<li>Make your first request.</li>
</ol>
