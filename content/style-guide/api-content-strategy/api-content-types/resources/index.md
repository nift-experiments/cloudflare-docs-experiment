<h2 id="purpose">Purpose</h2>
<p>The resource groups all of the associated endpoints together.</p>
<h2 id="structure">Structure</h2>
<h3 id="required-components">Required components</h3>
<p><strong>Name</strong>: Name of the resource that serves as a top-level grouping. Short noun phrase.</p>
<p><strong>Description</strong>: Describes the collective group of endpoints that fall under the resource and provides a high-level description of the endpoints.</p>
<h2 id="example">Example</h2>
<p><strong>Name</strong>: Audit logs</p>
<p><strong>Description</strong>: A log of changes made to your Cloudflare account.</p>
