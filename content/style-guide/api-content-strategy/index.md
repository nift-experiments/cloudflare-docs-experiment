<p>Our approach to API documentation aims to:</p>
<ul>
<li>Reduce internal and external user frustration</li>
<li>Align with industry standards in terms of naming conventions and descriptions</li>
<li>Create world-class content that is just as good, or better, than very popular API documentation</li>
</ul>
<p>By ensuring Cloudflare's API content is straightforward, easy to navigate, and consistent, we can create world-class API content that eliminates user frustration and serves as an example of good API documentation.</p>
