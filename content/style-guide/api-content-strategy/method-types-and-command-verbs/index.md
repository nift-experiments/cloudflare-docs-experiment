<p>The verb examples are a small handful of commonly used verbs associated with a method, but you should not feel limited and only use the verbs in the examples.</p>
<p>When writing the endpoint title, use the root form of the verb. For example, “Create a namespace.”</p>
<p>For the endpoint description, use the present tense of the verb. For example, “Creates a namespace under the given title.”</p>
<p>Additionally, using the method type as the verb in the title and description is okay. For example, using the method GET and including it in the description as “Gets embed code” is acceptable.</p>
