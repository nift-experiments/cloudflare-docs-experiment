<p>While we recommend the use of <code>DashButton</code>, you can continue to use deeplinks (as a link, without the component), if necessary.</p>

<h3 id="url"><code>url</code></h3>
<p><strong>type:</strong> <code>string</code></p>
<p>The Cloudflare dashboard deeplink to navigate to. See the below list for available routes.</p>
<h3 id="buttonname"><code>buttonName</code></h3>
<p><strong>type:</strong> <code>string</code></p>
<p><strong>default:</strong> The name of the route.</p>
<p>Additional name to override the default name of the route.</p>

<p><strong>type:</strong> <code>boolean</code></p>
<p><strong>default:</strong> <code>false</code></p>
