<p>We have added specific custom <a href="/style-guide/build-the-page/frontmatter/">frontmatter</a> properties to meet specific needs.</p>
<aside class="nb-aside note">
@markup("md", "content/.markup/bodies/14623.md")
</aside>
<h2 id="properties">Properties</h2>
<h3 id="banner">banner</h3><p><strong>Type:</strong> configuration value <span class="nb-metainfo">optional</span></p><p><strong>Description:</strong> Displays a Banner on the current docs page.</p><h3 id="canonical">canonical</h3><p><strong>Type:</strong> configuration value <span class="nb-metainfo">optional</span></p><p><strong>Description:</strong> A canonical URL or path to set as the link rel canonical in the page head, overriding the default derived from the page URL.</p><h3 id="difficulty">difficulty</h3><p><strong>Type:</strong> configuration value <span class="nb-metainfo">optional</span></p><p><strong>Description:</strong> Difficulty is displayed as a column in the ListTutorials component.</p><h3 id="external-link">external_link</h3><p><strong>Type:</strong> configuration value <span class="nb-metainfo">optional</span></p><p><strong>Description:</strong> Path to another page in our docs or elsewhere. Used to add a crosslink entry to the lefthand navigation sidebar.</p><h3 id="feedback">feedback</h3><p><strong>Type:</strong> configuration value <span class="nb-metainfo">optional</span></p><p><strong>Description:</strong> Whether to show the FeedbackPrompt on the page, defaults to true.</p><h3 id="hidechildren">hideChildren</h3><p><strong>Type:</strong> configuration value <span class="nb-metainfo">optional</span></p><p><strong>Description:</strong> Renders this group as a single link on the sidebar, to the index page.</p><h3 id="noindex">noindex</h3><p><strong>Type:</strong> configuration value <span class="nb-metainfo">optional</span></p><p><strong>Description:</strong> If true, this property adds a noindex declaration to the page, which tells internal and external search crawlers to ignore this page.</p><h3 id="pcx-content-type">pcx_content_type</h3><p><strong>Type:</strong> configuration value <span class="nb-metainfo">optional</span></p><p><strong>Description:</strong> The purpose of the page, defined through specific pages in Content strategy.</p><h3 id="products">products</h3><p><strong>Type:</strong> configuration value <span class="nb-metainfo">optional</span></p><p><strong>Description:</strong> The names of related directory entries according to their file name in src/content/directory.</p><h3 id="release-notes-file-name">release_notes_file_name</h3><p><strong>Type:</strong> configuration value <span class="nb-metainfo">optional</span></p><p><strong>Description:</strong> Required for the ProductReleaseNotes component.</p><h3 id="reviewed">reviewed</h3><p><strong>Type:</strong> configuration value <span class="nb-metainfo">optional</span></p><p><strong>Description:</strong> A YYYY-MM-DD value that signals when the page was last explicitly reviewed from beginning to end.</p><h3 id="sidebar">sidebar</h3><p><strong>Type:</strong> configuration value <span class="nb-metainfo">optional</span></p><p><strong>Description:</strong> Controls the label, order, visibility, badge, attributes, and group shown in the navigation sidebar.</p><h3 id="styleguide">styleGuide</h3><p><strong>Type:</strong> configuration value <span class="nb-metainfo">optional</span></p><p><strong>Description:</strong> Used by style guide component documentation to display usage counts directly on the component page.</p><h3 id="summary">summary</h3><p><strong>Type:</strong> configuration value <span class="nb-metainfo">optional</span></p><p><strong>Description:</strong> Renders a summary description directly below the page title.</p><h3 id="tags">tags</h3><p><strong>Type:</strong> configuration value <span class="nb-metainfo">optional</span></p><p><strong>Description:</strong> A group of related keywords relating to the purpose of the page.</p>
