<h2 id="definition">Definition</h2>
<p>Dynamic lists automatically add or remove elements based on set criteria.</p>
<h2 id="used-in">Used in</h2>
<p>When at all possible, Cloudflare seeks to avoid creating static representations of dynamic options.</p>
<h2 id="structure">Structure</h2>
<p>Potential examples include:</p>
<ul>
<li>Exhaustive listing of fields</li>
<li>Replicating API content in developer docs</li>
<li>Maintaining lists of potential options in the UI (i.e., Alert types)</li>
<li>Verified Bots</li>
</ul>
<p>The preferred approach would be speak more generally to the categories or specific, high-value fields.</p>
