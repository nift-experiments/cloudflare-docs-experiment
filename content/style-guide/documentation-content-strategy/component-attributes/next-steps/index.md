<h2 id="definition">Definition</h2>
<p>The end result of a procedure and the actionable steps to take after completing it.</p>
<h2 id="when-to-use-it">When to use it</h2>
<p>Use next steps in <a href="/style-guide/documentation-content-strategy/content-types/how-to/">how-to</a> and <a href="/style-guide/documentation-content-strategy/content-types/tutorial/">tutorial</a> pages, at the end of the page.</p>
<h2 id="structure">Structure</h2>
<p>Write one to two sentences that answer:</p>
<ul>
<li>What happens now?</li>
<li>What was the end result of the procedure?</li>
<li>What should the reader do next?</li>
</ul>
<h2 id="example">Example</h2>
<pre><code class="language-md">You now have a Worker deployed to your account. Next, add a custom domain so visitors can reach it, or explore Workers KV to store data at the edge.&#10;</code></pre>
<h2 id="related">Related</h2>
<p>Next steps should link to related pages based on the content type of the current page. For example, a how-to page should link to relevant troubleshooting or configuration pages, and a get-started page should link to next-level how-to pages.</p>
<p>For the full set of required cross-linking patterns by content type, and for link mechanics, refer to <a href="/style-guide/style-and-grammar/formatting/structure/links/#cross-linking-requirements">Cross-linking requirements</a>.</p>
