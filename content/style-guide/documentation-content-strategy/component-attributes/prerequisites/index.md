<h2 id="definition">Definition</h2>
<p>Tasks that must be completed or conditions that must be met before a user can complete the steps on a page.</p>
<h2 id="when-to-use-it">When to use it</h2>
<p>Use prerequisites in <a href="/style-guide/documentation-content-strategy/content-types/how-to/">how-to</a> and <a href="/style-guide/documentation-content-strategy/content-types/tutorial/">tutorial</a> pages, before the first step.</p>
<h2 id="structure">Structure</h2>
<p>Write prerequisites as a bulleted list. If there is only one prerequisite task or condition, summarize it in a single sentence instead of a list.</p>
<h2 id="example">Example</h2>
<pre tabindex="0"><code class="language-md">Before you begin, make sure that you have:&#10;&#10;&#45; A Cloudflare account with your domain added.&#10;&#45; An API token scoped to that domain.&#10;&#45; Node.js 18 or later installed locally.&#10;</code></pre>
<h2 id="related">Related</h2>
<p>For how to format the list itself, refer to <a href="/style-guide/style-and-grammar/formatting/structure/lists/">Lists</a>.</p>
