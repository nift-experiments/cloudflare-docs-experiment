<h2 id="subtitles">Subtitles</h2>
<h3 id="definition-1">Definition</h3>
<p>The first line of text on a page. H2, H3, etc.</p>
<h3 id="used-in-1">Used in</h3>
<p>All content types</p>
<p><a href="/style-guide/documentation-content-strategy/content-types/overview/">Overview</a>, <a href="/style-guide/documentation-content-strategy/content-types/how-to/">How to</a>, <a href="/style-guide/documentation-content-strategy/content-types/configuration/">Configuration</a>, <a href="/style-guide/documentation-content-strategy/content-types/faq/">FAQ</a>, <a href="/style-guide/documentation-content-strategy/content-types/changelog/">Changelog</a>, <a href="/style-guide/documentation-content-strategy/content-types/concept/">Concept</a>, <a href="/style-guide/documentation-content-strategy/content-types/reference/">Reference</a>, <a href="/style-guide/documentation-content-strategy/content-types/tutorial/">Tutorial</a>, <a href="/style-guide/documentation-content-strategy/content-types/navigation/">Navigation</a></p>
<h3 id="structure-1">Structure</h3>
<p>Subtitles are verb or noun phrase that describes the sub-pages in the section. If using verb, do not use the gerund. Write &quot;Install Wrangler&quot;, not &quot;Installing Wrangler&quot;.</p>
<p>Subtitles should never be a question (&quot;How do I install Wrangler?&quot;) or a call to action (&quot;Reach out to us if you have a problem&quot;).</p>
