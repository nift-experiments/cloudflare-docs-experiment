<p>Our goal is to integrate video directly into the documentation so it accelerates the user experience and learning experience, not for videos to exist in a separate silo.</p>
<h2 id="embed-locations">Embed locations</h2>
<ul>
<li>Doc pages: We embed videos directly in the relevant pages. This gives users a comprehensive learning experience with visual context and accurate technical details.</li>
<li><a href="https://developers.cloudflare.com/videos/page">Video hub</a>: For learners who prefer a video-first experience, we maintain a dedicated page for videos.</li>
<li><a href="https://developers.cloudflare.com/resources/">Resources</a>: Video is a core content type in our system. You can filter specifically for videos in the resources page.</li>
</ul>
<h2 id="chapters">Chapters</h2>
<p>We add time-stamped chapters to our videos to make relevant information more accessible by users and searchable by machines.</p>
<p>Chapters allow users to:</p>
<ul>
<li><strong>Skip ahead</strong>: Jump directly to the specific information you need.</li>
<li><strong>Find answers</strong>: Search engines and LLMs can index these chapters, making it easier to retrieve specific visual segments when a user asks a technical question.</li>
</ul>
