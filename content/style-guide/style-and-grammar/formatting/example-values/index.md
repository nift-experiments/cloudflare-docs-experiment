<h2 id="dns-domains">DNS Domains</h2>
<p>As described in <a href="https://datatracker.ietf.org/doc/html/rfc2606">RFC 2606</a> and <a href="https://datatracker.ietf.org/doc/html/rfc6761">RFC 6761</a>, a number of domains such as <code>example.com</code> and <code>example.org</code> are maintained for documentation purposes. Sometimes you also need to differentiate between a customer domain and your own application domain, so Cloudflare has also registered some domains for you to use.</p>
<p>Examples:</p>
<ul>
<li><code>example.com</code></li>
<li><code>example.org</code></li>
<li><code>myappexample.com</code></li>
<li><code>mycustomerexample.com</code></li>
</ul>
<p>IANA also maintains more example domains in their <a href="https://www.iana.org/domains/reserved">domain names documentation</a>.</p>
<h2 id="ipv4-ranges">IPv4 ranges</h2>
<p>According to the Internet Engineering Task Force (IETF), there are specific <a href="https://datatracker.ietf.org/doc/html/rfc5737">IPv4 ranges used for documentation</a>:</p>
<p>Examples:</p>
<ul>
<li><code>192.0.2.0/24</code></li>
<li><code>198.51.100.0/24</code></li>
<li><code>203.0.113.0/24</code></li>
</ul>
<p>These IP addresses are reserved and will not take anyone to live origins.</p>
<h2 id="autonomous-system-numbers-asns">Autonomous System Numbers (ASNs)</h2>
<p>According to the Internet Assigned Numbers Authority (IANA), there are specific <a href="https://datatracker.ietf.org/doc/html/rfc5398">ASN ranges reserved for documentation</a>:</p>
<ul>
<li><code>64496-64511</code> (16-bit ASN range)</li>
<li><code>65536-65551</code> (32-bit ASN range)</li>
</ul>
