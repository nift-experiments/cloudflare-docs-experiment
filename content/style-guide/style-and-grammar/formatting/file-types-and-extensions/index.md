<p>You can refer both to file types and file extensions in documentation:</p>
<ul>
<li>File types: Accepted file formats are JSON and YAML.</li>
<li>File extensions: Upload the <code>.txt</code> file to the dashboard.</li>
</ul>
<p>When referring to a specific file type, always use regular text formatting, write the file type in uppercase, and avoid the initial dot (you are referring to the file type, not the file extension).</p>
<p>When referring to a specific extension, always monospace the file, include a dot, write the extension in lowercase, and always specify a noun after mentioning a file extension (for example: &quot;file&quot; or &quot;file extension&quot;). Do not leave the extension hanging.</p>
