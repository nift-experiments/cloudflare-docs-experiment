<h2 id="wording">Wording</h2>
<ul>
<li>Use <strong>select</strong> instead of <strong>click</strong> when directing users to choose or select objects, commands, or options.</li>
<li>Use <strong>press</strong> only when referring to pressing keys on a keyboard.</li>
</ul>
<h2 id="formatting-keyboard-shortcuts">Formatting keyboard shortcuts</h2>
<p>When telling readers what keyboard shortcuts to use to achieve a result:</p>
<ul>
<li>Place the keyboard shortcut in between backticks (monospace formatting)</li>
<li>Use uppercase letters with the abbreviated version of the key (<code>CTRL</code> instead of <code>CONTROL</code>, <code>CMD</code> instead of <code>COMMAND</code>for example)</li>
<li>Wrap the complete keyboard shortcut in between backticks, including the plus sign:
<ul>
<li><strong>Do</strong>:</li>
</ul>
</li>
</ul>
<pre tabindex="0"><code class="language-mdx">`CTRL + C`&#10;</code></pre>
<pre tabindex="0"><code>- **Don't**:&#10;</code></pre>
<pre tabindex="0"><code class="language-mdx">`CTRL` + `C`&#10;</code></pre>
<ul>
<li>Do not use the old <code>&lt;kbd&gt;&lt;/kbd&gt;</code> component</li>
</ul>
