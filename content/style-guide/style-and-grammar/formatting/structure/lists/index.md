<p>There are three types of lists:</p>
<ul>
<li>Bulleted lists for unordered items</li>
<li>Numbered lists for ordered items</li>
<li>Embedded lists for items within a sentence</li>
</ul>
<p>Here are some tips when creating lists:</p>
<ul>
<li>Keep list items parallel</li>
<li>Start numbered lists with a command (imperative verb)</li>
<li>Consistently punctuate by using appropriate sentence + punctuation within the list (periods for full sentences, etc.)</li>
</ul>
<h2 id="bullet-points">Bullet points</h2>
<p>Bullet points help the reader's eye focus on a list of important elements.</p>
<p>However, as with any other aspect of writing, they should be used mindfully. Below is a list of when you should and should not resort to bullet points.</p>
<table>
<thead>
<tr>
<th>❌ Do not use bullet points</th>
<th>✅ Use bullet points</th>
</tr>
</thead>
<tbody>
<tr>
<td>To outline <b>processes</b> (prefer numbered lists)</td>
<td>To list <b>facts</b></td>
</tr>
<tr>
<td>To explain your reasoning (it is a blog post, not a list of system requirements)</td>
<td>To list <b>data</b></td>
</tr>
<tr>
<td>-</td>
<td>To list <b>options</b></td>
</tr>
</tbody>
</table>
<h2 id="bulleted-lists">Bulleted lists</h2>
<p>Instructions should be numbered steps and not bullet points. See <a href="/style-guide/documentation-content-strategy/component-attributes/steps-tasks-procedures/">steps/tasks/procedures</a> for additional information.</p>
<p>Do not punctuate bullet points unless each item is a full sentence.</p>
<p>If bullet point items are followed by a description, use a colon after the heading and capitalize the description. For example,</p>
<ul>
<li><strong>Item 1</strong>: Description 1</li>
<li><strong>Item 2</strong>: Description 2</li>
</ul>
<p>For bullet points, try to stick to the &quot;six-pack&quot; rule: no more than six bullets, each made up of six words or less.</p>
<p>Refer to <a href="https://thewritinghabit.blog/2016/08/22/best-way-to-use-bullet-points/">The best way to use bullet points</a> for additional guidance.</p>
<h3 id="bulleted-list-checklist">Bulleted list checklist</h3>
<p>When you find yourself creating a list of bullet points, go through this checklist:</p>
<ol>
<li>Do all bullet points belong together?
<ul>
<li>Check that all the elements in the list are logically connected.</li>
</ul>
</li>
<li>Do I have more three or more bullet points, but less than six?
<ul>
<li>Readers get lost when reading long lists; at the same time, if you have less than three elements to list, is it necessary to use bullet points?</li>
</ul>
</li>
<li>Are all bullet points shorter than three lines of text?
<ul>
<li>Bullet points should not be used as section headers. If you have excessively long bullet points, consider breaking up the list into several subsections.</li>
</ul>
</li>
<li>Is punctuation consistent?
<ul>
<li>End all elements of a bulleted list with a period if each element is a full sentence; do not add any punctuation if you are just listing nouns or parameters.</li>
</ul>
</li>
<li>Do all bullet points start with the most important word we want the reader to remember?
<ul>
<li>Make sure the &quot;head&quot; of your bullet point is not hiding after a long circumlocution.</li>
</ul>
</li>
<li>Do all bullet points start with the same part of speech?
<ul>
<li>If your bullet points start with verbs, make sure all verbs are in the same mood/tense.</li>
</ul>
</li>
</ol>
