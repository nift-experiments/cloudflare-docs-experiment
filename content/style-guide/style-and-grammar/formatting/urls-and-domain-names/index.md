<p>When referring to a URL in text, do not use <code>http://</code> or <code>www</code> with a Cloudflare web address. Use <code>www</code> only when referring to URLs outside of Cloudflare. For example, use <code>cloudflare.com</code> when referring to <a href="https://www.cloudflare.com/">cloudflare.com</a> and <code>www.example.com</code> when referring to <a href="https://www.example.com/">www.example.com</a>.</p>
