<p>In general, avoid the <code>'s</code> construction to show possession by an inanimate object. Doing so personifies the object.</p>
<p>Example: the device's address.</p>
<h2 id="usage">Usage</h2>
<p>Do not use <code>“ ” ‘ ’</code>, which are double or single typographer's (&quot;curly&quot;) quotation marks. Use standard quotation marks instead.</p>
