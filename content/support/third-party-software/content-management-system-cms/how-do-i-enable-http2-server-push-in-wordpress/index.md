<p>HTTP/2 Server Push allows a website to push content to a browser, without having to wait for the HTML of one page to render first. In conjunction with the concurrency support built into HTTP/2, Server Push is able to dramatically reduce the amount of requests needed to load your website.</p>
<p><img src="/assets/upstream/images/support/hc-import-http2_server_push_2.png" alt="Old URL: https://support.cloudflare.com/hc/en-us/article_attachments/115005733367/http2-server-push-2.png Article IDs: 115002816808 | How do I enable HTTP/2 Server Push in WordPress " /></p>
<p>Cloudflare supports HTTP/2 Server Push and it can be enabled for stylesheets and scripts using Cloudflare’s WordPress plugin. In order to utilise this feature, you must first ensure you have the Cloudflare WordPress plugin <a href="/automatic-platform-optimization/">installed and set up on your site</a>.</p>
<p>Once the plugin is installed, you can enable HTTP/2 Server Push by adding the following line to your <code>wp-config.php</code> file:</p>
<pre tabindex="0"><code class="language-php">define(&#x27;CLOUDFLARE_HTTP2_SERVER_PUSH_ACTIVE&#x27;, true);&#10;</code></pre>
<p>You should insert this line above where it says <em>&quot;/* That's all, stop editing! Happy blogging. */</em>&quot;, like follows:|</p>
<p><img src="/assets/upstream/images/support/hc-import-screen_shot_2017_02_09_at_16_09_31.png" alt="Old URL: https://support.cloudflare.com/hc/en-us/article_attachments/115005733547/Screen_Shot_2017-02-09_at_16.09.31.png Article IDs: 115002816808 | How do I enable HTTP/2 Server Push in WordPress " /></p>
<p>You should then start to see requests coming in which are initiated through Server Push, for example, in the Network tab of Chrome Development Tools you should see some assets have &quot;Push&quot; as the initiator:</p>
<p><img src="/assets/upstream/images/support/hc-import-screen_shot_2016_04_26_at_15_08_59.png" alt="Old URL: https://support.cloudflare.com/hc/en-us/article_attachments/115005787688/Screen-Shot-2016-04-26-at-15-08-59.png Article IDs: 115002816808 | How do I enable HTTP/2 Server Push in WordPress " /></p>
