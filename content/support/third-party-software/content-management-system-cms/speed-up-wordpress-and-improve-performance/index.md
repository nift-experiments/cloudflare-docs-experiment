<p>Cloudflare's CDN services can help cache your content across our giant global network, but performance isn't just about moving static files closer to your visitor. Cloudflare does more than offer a CDN, Cloudflare's optimisation features allow you to enhance the performance of your WordPress site beyond what a traditional CDN can do.</p>
<h3 id="caching-anonymous-page-views">Caching Anonymous Page Views</h3>
<p><img src="/assets/upstream/images/support/hc-import-screen_shot_2017_03_09_at_16_54_36_1_.png" alt="Creating a cache rule for anonymous page views." /></p>
<p>Cloudflare's &quot;<a href="/cache/how-to/cache-rules/examples/bypass-cache-on-cookie/">Bypass Cache on Cookie</a>&quot; functionality allows non-logged-in pages to be fully cached by Cloudflare. This means your server can save time and resources by not having to regenerate pages where the HTML is effectively static, whilst not interfering with dynamic behaviour - as soon as a user logs-in to the WordPress dashboard or adds something to their WooCommerce, the Edge cache is bypassed.</p>
<h3 id="optimise-images">Optimise Images</h3>
<p>Images can be incredibly costly to page load times; fortunately, Cloudflare can dramatically help improve image load times. You can find these features in the Cloudflare dashboard by going to <strong>Speed</strong> &gt; <strong>Settings</strong> &gt; <strong>Image Optimization</strong>.</p>
<p>After enabling <a href="/images/polish/"><strong>Polish</strong></a>, you can dramatically improve image and web page load times by compressing images and stripping metadata. Lossless will strip most metadata (<code>EXIF</code> data, for example) but doesn't change the image detail. Lossy will strip most metadata and compresses images by approximately 48 percent.</p>
<h3 id="enable-http-2">Enable HTTP/2</h3>
<p><strong>HTTP/2</strong> allows for a multitude of performance features including multiplexing, header compression. In order to enable HTTP/2 on your WordPress site, ensure that your site is loaded over HTTPS.</p>
<p>After <strong>enabling SSL</strong> you must also ensure that users are redirected to the HTTPS version so that it can be loaded over HTTP/2. You can do this using an <em>Always use HTTPS</em> <strong>Page Rule</strong>:</p>
<p><img src="/assets/upstream/images/support/hc-import-screen_shot_2016_09_30_at_15_34_14.png" alt="Create a page rule to ensure your Wordpress website is correctly loaded over HTTP/2" /></p>
<p>Cloudflare's <strong>WordPress plugin</strong> allows you to push necessary assets to your users using HTTP/2 Server Push, dramatically reducing the amount of roundtrips required to load CSS and JavaScript. Refer to <a href="https://developers.cloudflare.com/support/third-party-software/content-management-system-cms/how-do-i-enable-http2-server-push-in-wordpress/">How do I enable HTTP/2 Server Push in WordPress</a> for a tutorial on setting it up.</p>
<h3 id="minify-assets">Minify Assets</h3>
<p>If you are using Grunt or Gulp as part of a build process, you can implement minification in your builds.</p>
<p>Due to HTTP/2 multiplexing requests, we advise against concatenating CSS or JavaScript files together or installing anything on your server which may do this.</p>
<h3 id="advanced-performance-tools">Advanced Performance Tools</h3>
<p>Enterprise users can utilise <a href="/speed/optimization/content/prefetch-urls/">Prefetching URLs From HTML Headers</a> and <a href="/cache/how-to/cache-keys/">custom cache keys</a> to enhance caching.</p>
