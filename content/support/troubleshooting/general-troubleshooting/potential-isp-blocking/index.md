<p>Cloudflare cannot guarantee that your assigned IP addresses are not blocked by any country or Internet service provider (ISP). When Cloudflare proxies your zone, it assigns an IP address to the zone from a shared pool in the Cloudflare network. Cloudflare does not offer dedicated or exclusive IP addresses for users on Free, Pro, or Business plans, nor does Cloudflare rotate assigned IP addresses upon request.</p>
<p>When an ISP blocks your website, you should expect that:</p>
<ul>
<li>This is not due to a misconfiguration of your Cloudflare settings.</li>
<li>You may see a drop in traffic in your <a href="/analytics/">Cloudflare Analytics</a>.</li>
<li>As these actions are taken at the ISP level, Cloudflare does not have the ability to restore Internet connectivity for impacted users.</li>
</ul>
<p>Enterprise users can lease <a href="/byoip/concepts/static-ips/">static IPs</a> or get their own IPs advertised using <a href="/byoip/">Bring Your Own IP (BYOIP)</a>. For more information, contact the <a href="https://www.cloudflare.com/plans/enterprise/contact/">Cloudflare Sales team</a>.</p>
<p>It is important to note that an ISP-level block is distinct from other types of website blocking. For example, website owners may enforce certain restrictions (based upon IP, ASN, country, or other factors such as rate limiting) that will return <a href="/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/"><code>1XXX</code> errors</a> in the HTML body of the response. Website owners configure these blocks, so issues need to be addressed directly with the website owner. For more information on website blocking, refer to the <a href="/waf/troubleshooting/faq/#why-have-i-been-blocked">Web Application Firewall FAQ</a>.</p>
<p>For information on individual users being challenged when visiting Cloudflare-protected websites, refer to <a href="/cloudflare-challenges/troubleshooting/#challenges-on-cloudflare-protected-sites">Challenges on Cloudflare-protected sites</a>.</p>
