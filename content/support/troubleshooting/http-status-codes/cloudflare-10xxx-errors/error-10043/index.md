<h2 id="error-10043-source-url-in-redirect-is-too-long">Error 10043: Source URL in redirect is too long</h2>
<p>This error indicates that the source URL in a redirect exceeds the maximum allowed length.</p>
<h3 id="common-causes">Common causes</h3>
<p>This error occurs when the source URL value of a URL redirect is too long. The maximum length of a source URL is 32,768 characters. Possible causes of this error are:</p>
<ul>
<li>Dynamic URLs that contain excessive query parameters or tracking codes.</li>
<li>Unnecessary path segments or redundant subdirectories in the URL.</li>
</ul>
<h3 id="resolution">Resolution</h3>
<p>You need to use a shorter URL as the source URL.</p>
