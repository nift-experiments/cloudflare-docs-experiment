<h2 id="error-10046-invalid-redirect-target-url">Error 10046: Invalid redirect target URL</h2>
<p>This error indicates that the target URL provided for a URL redirect is not valid.</p>
<h3 id="common-causes">Common causes</h3>
<p>This error occurs when the target URL provided for a URL redirect is not valid, preventing the redirect from functioning properly due to missing components, such as the scheme (for instance, <code>http</code> or <code>https</code>) or improper formatting.</p>
<h3 id="resolution">Resolution</h3>
<p>You need to specify a valid URL as the target URL. Refer to <a href="/rules/url-forwarding/bulk-redirects/reference/url-components/">Supported URL components in Bulk Redirects</a> for details on the supported URL components for redirect target URLs.</p>
