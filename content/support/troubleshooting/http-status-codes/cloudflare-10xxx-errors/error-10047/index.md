<h2 id="error-10047-invalid-redirect-status-code">Error 10047: Invalid redirect status code</h2>
<p>This error indicates that an unsupported or incorrectly formatted status code was specified for the URL redirect.</p>
<h3 id="common-causes">Common causes</h3>
<p>This error occurs when you specify a URL redirect status code that is not supported, typically due to entering an invalid number or using an unsupported or deprecated status code.</p>
<h3 id="resolution">Resolution</h3>
<p>Use one of the supported status codes in the URL redirect: <code>301</code>, <code>302</code>, <code>307</code>, or <code>308</code>.</p>
