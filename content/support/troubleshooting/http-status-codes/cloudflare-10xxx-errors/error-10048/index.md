<h2 id="error-10048-preserve-path-suffix-requires-subpath-matching-enabled">Error 10048: Preserve path suffix requires subpath matching enabled</h2>
<p>This error indicates a configuration mismatch where the <strong>Preserve path suffix</strong> option is used without enabling <strong>Subpath matching</strong> in a URL redirect.</p>
<h3 id="common-causes">Common causes</h3>
<p>This error occurs when you enable the <strong>Preserve path suffix</strong> option in a redirect without enabling the <strong>Subpath matching</strong> option. The <strong>Preserve path suffix</strong> option of a URL redirect is only applicable when the <strong>Subpath matching</strong> option is also enabled.</p>
<h3 id="resolution">Resolution</h3>
<p>Enable <strong>Subpath matching</strong> for the URL redirect with <strong>Preserve path suffix</strong> enabled.</p>
