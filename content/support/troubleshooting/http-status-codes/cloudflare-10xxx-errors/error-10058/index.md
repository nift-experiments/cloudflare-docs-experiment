<h2 id="error-10058-list-items-incompatible-with-list-type">Error 10058: List items incompatible with list type</h2>
<p>This error indicates that incompatible items were added to the wrong list type.</p>
<h3 id="common-causes">Common causes</h3>
<p>This error occurs when you are adding items to a list (either IP list, hostname list, or Bulk Redirect List) and the list items are incompatible with the list type.</p>
<h3 id="resolution">Resolution</h3>
<p>Make sure you are adding the items to the correct list:</p>
<ul>
<li>Custom lists with IP addresses (IP lists) can only contain IP addresses as list items.</li>
<li>Custom lists with hostnames can only contain hostnames as list items.</li>
<li>Bulk Redirect Lists can only contain URL redirects as list items.</li>
</ul>
