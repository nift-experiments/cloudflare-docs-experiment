<h2 id="error-1003-access-denied-direct-ip-access-not-allowed">Error 1003 Access Denied: Direct IP Access Not Allowed</h2>
<p>This error indicates that direct access to a Cloudflare IP address is not allowed.</p>
<h3 id="common-cause">Common cause</h3>
<p>A client or browser directly accesses a <a href="https://www.cloudflare.com/ips">Cloudflare IP address</a>.</p>
<h3 id="resolution">Resolution</h3>
<p>Browse to the website domain name in your URL instead of the Cloudflare IP address.</p>
