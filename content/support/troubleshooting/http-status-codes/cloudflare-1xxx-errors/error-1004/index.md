<h2 id="error-1004-host-not-configured-to-serve-web-traffic">Error 1004: Host Not Configured to Serve Web Traffic</h2>
<p>This error indicates that the host is not configured to serve web traffic.</p>
<h3 id="common-causes">Common causes</h3>
<ul>
<li>Cloudflare staff disabled proxying for the domain due to abuse or terms of service violations.</li>
<li>DNS changes have not yet propagated or the site owner's DNS A records point to <a href="https://www.cloudflare.com/ips">Cloudflare IP addresses</a>.</li>
</ul>
<h3 id="resolution">Resolution</h3>
<p>If the issue persists beyond five minutes, <a href="/support/contacting-cloudflare-support/">contact Cloudflare Support</a>.</p>
