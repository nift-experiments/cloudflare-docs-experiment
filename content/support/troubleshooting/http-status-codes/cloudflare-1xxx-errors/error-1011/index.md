<h2 id="error-1011-access-denied-hotlinking-denied">Error 1011: Access Denied (Hotlinking Denied)</h2>
<p>This error indicates that access to the resource is denied due to hotlinking protection.</p>
<h3 id="common-cause">Common cause</h3>
<p>A request is made for a resource that uses <a href="/waf/tools/scrape-shield/hotlink-protection/">Cloudflare hotlink protection</a>.</p>
<h3 id="resolution">Resolution</h3>
<p>Notify the website owner of the blocking. If you cannot determine how to contact the website owner, lookup contact information for the domain via the <a href="https://lookup.icann.org/">Whois database</a>.</p>
