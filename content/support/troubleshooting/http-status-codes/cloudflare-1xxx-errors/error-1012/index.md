<h2 id="error-1012-access-denied">Error 1012: Access Denied</h2>
<p>This error indicates that access to the website is denied.</p>
<h3 id="common-cause">Common cause</h3>
<p>A website owner forbids access based on malicious activity detected from the visitor's computer or network (ip_address). The most likely cause is a virus or malware infection on the visitor's computer.</p>
<h3 id="resolution">Resolution</h3>
<p>Update your antivirus software and run a full system scan. Cloudflare can not override the security settings the site owner has set for the domain. To request website access, contact the site owner to allow your IP address. If you cannot determine how to contact the website owner, lookup contact information for the domain via the <a href="https://lookup.icann.org/">Whois database</a>.</p>
