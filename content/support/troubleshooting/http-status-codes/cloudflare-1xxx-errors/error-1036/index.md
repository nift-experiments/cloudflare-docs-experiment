<h2 id="error-1036-invalid-request-rewrite-maximum-length-exceeded">Error 1036: Invalid request rewrite (maximum length exceeded)</h2>
<p>This error indicates that the rewritten URI path or query string exceeds the maximum allowed length.</p>
<h3 id="common-cause">Common cause</h3>
<p>The value or expression of your rewritten URI path or query string is too long.</p>
<h3 id="resolution">Resolution</h3>
<p>Use a shorter value or expression for the new URI path/query string value.</p>
