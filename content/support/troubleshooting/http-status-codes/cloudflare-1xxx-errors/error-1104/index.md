<h2 id="error-1104-a-variation-of-this-email-address-is-already-taken-in-our-system-only-one-variation-is-allowed">Error 1104: A variation of this email address is already taken in our system. Only one variation is allowed.</h2>
<p>This error indicates that the email address you are trying to add is already taken in the system.</p>
<h3 id="common-cause">Common cause</h3>
<p>This error can occur if an email has been added with some variation of the email you're trying to add. For example, <code>my+user@example.com</code> and <code>my.user@example.com</code> will be treated the same in our system.</p>
<h3 id="resolution">Resolution</h3>
<p>Log in as the old user and change email to a &quot;throwaway&quot; address, which will free up the new email.</p>
