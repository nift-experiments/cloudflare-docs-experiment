<h2 id="error-530">Error 530</h2>
<p>This error indicates that Cloudflare is unable to resolve the origin hostname, preventing it from establishing a connection to the origin server.</p>
<h3 id="common-causes">Common causes</h3>
<p>An HTTP error <code>530</code> is returned when Cloudflare is encountering an issue resolving the origin hostname.
In this case the body of the response contains an <a href="/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/">1XXX error</a> code.</p>
<h3 id="resolution">Resolution</h3>
<p>Refer to the specific <a href="/support/troubleshooting/http-status-codes/cloudflare-1xxx-errors/">1XXX error</a> for troubleshooting information.</p>
