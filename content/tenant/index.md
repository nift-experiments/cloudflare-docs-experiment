<p>The Cloudflare Tenant API is a provisioning mechanism to help Channel and Alliance partners set up and manage Cloudflare accounts and services for their customers.</p>
<p>These APIs are built into our Client v4 API library to provide a streamlined onboarding and setup experience.</p>
