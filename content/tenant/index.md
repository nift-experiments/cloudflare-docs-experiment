<p>The Cloudflare Tenant API is a provisioning mechanism to help Channel and Alliance partners set up and manage Cloudflare accounts and services for their customers.</p>
<p>These APIs are built into our Client v4 API library to provide a streamlined onboarding and setup experience.</p>
<h2 id="available-resources">Available resources</h2>
<p>As you dive into the Tenant API, take advantage of the following resources:</p>
<ul>
<li><a href="/tenant/structure/">Tenant structure</a> explains some basic ideas behind the Tenant API and how it works.</li>
<li><a href="/tenant/get-started/">Get started</a> provides the quickest path to get your customer accounts up and running.</li>
<li><a href="/tenant/how-to/">How to</a> offers step-by-step instructions for specific tasks.</li>
<li><a href="/tenant/reference/">Reference topics</a> contains detailed information about the Tenant API, including a list of available zone and account-level subscriptions.</li>
</ul>
