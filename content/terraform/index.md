<p>Configure Cloudflare using HashiCorp's “Infrastructure as Code” tool, Terraform. With <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs">Cloudflare’s Terraform provider</a>, you can manage the Cloudflare global network using the same familiar tools you use to automate the rest of your infrastructure. Define and store configuration in source code repositories like GitHub, track and version changes over time, and roll back when needed — all without needing to use the Cloudflare APIs.</p>
<p>Report Terraform configuration issues via <a href="https://github.com/cloudflare/terraform-provider-cloudflare/issues/new/choose">GitHub</a>.</p>
