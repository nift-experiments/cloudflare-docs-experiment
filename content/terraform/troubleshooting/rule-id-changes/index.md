<p>For <a href="https://registry.terraform.io/providers/cloudflare/cloudflare/latest/docs/resources/ruleset"><code>cloudflare_ruleset</code></a> resources, the Cloudflare provider may delete a rule and create a new one when you modify a ruleset in your Terraform configuration. This happens because the API cannot match rules in your new Terraform configuration with existing rules in your Cloudflare configuration. Modifying a ruleset in your Terraform configuration and applying the changes will create new rules with different rule IDs in your Cloudflare account or zone.</p>
<p>This behavior may have an impact on any automation or monitoring systems you may have configured that rely on having immutable rule IDs between rule modifications.</p>
<h2 id="how-to-keep-the-same-rule-id-between-modifications">How to keep the same rule ID between modifications</h2>
<p>To keep existing rule IDs when making changes to a ruleset through Terraform, add a <code>ref</code> field to each rule.</p>
<p>The <code>ref</code> field is a user-defined external identifier that must be unique for each rule in a ruleset. When you provide a <code>ref</code> value, the provider will match the rule in your updated Terraform configuration with the existing rule with the same <code>ref</code> external identifier, and the rule ID will be preserved.</p>
<p><code>ref</code> values have a string data type with a minimum length of one character. For example, <code>my_ref</code>.</p>
<p>Once you set the <code>ref</code> field of a rule, changing the <code>ref</code> field value will make Terraform create a new rule.</p>
<h2 id="cf-terraforming-support-for-ref-field-values"><code>cf-terraforming</code> support for <code>ref</code> field values</h2>
<p>By default, when you create a rule, its <code>ref</code> value will be equal to the rule ID. You can set <code>ref</code> values via Cloudflare API.</p>
<p>When you <a href="/terraform/advanced-topics/import-cloudflare-resources/">import your existing Cloudflare configuration to Terraform</a> using <a href="https://github.com/cloudflare/cf-terraforming"><code>cf-terraforming</code></a>, the generated Terraform configuration will have <code>ref</code> values for each rule, with the same value as the rule ID.</p>
<p>If you manually created your Terraform configuration and your rules' configuration does not have a <code>ref</code> field, add a <code>ref</code> field to each rule so that each ruleset modification does not generate new rule IDs.</p>
