<p>Understanding how your APIs are used — request volume, latency, error rates, and undocumented endpoints — is essential for reliability and security. Cloudflare API Shield Analytics discovers endpoints from observed traffic, Logpush streams logs to your analytics platform, and Workers Analytics Engine tracks custom business metrics.</p>
<h2 id="solutions">Solutions</h2>
<h3 id="api-shield-analytics">API Shield Analytics</h3>
<p>Discover endpoints and monitor API traffic patterns. <a href="/api-shield/security/api-discovery/">Learn more about API Shield Analytics</a>.</p>
<ul>
<li><strong>API discovery</strong> - Automatically find undocumented endpoints from observed traffic</li>
<li><strong>Traffic analysis</strong> - Understand request volume, latency, and usage patterns per endpoint</li>
</ul>
<h3 id="logpush">Logpush</h3>
<p>Stream logs from Cloudflare products to external destinations. <a href="/logs/">Learn more about Logpush</a>.</p>
<ul>
<li><strong>Log export</strong> - Stream detailed API request logs to your Security Information and Event Management (SIEM) system, data warehouse, or analytics platform</li>
</ul>
<h3 id="workers-analytics-engine">Workers Analytics Engine</h3>
<p>Store and query time-series analytics data from Workers. <a href="/analytics/analytics-engine/">Learn more about Workers Analytics Engine</a>.</p>
<ul>
<li><strong>Custom metrics</strong> - Track business-specific Key Performance Indicators (KPIs) such as per-customer usage and error rates</li>
</ul>
