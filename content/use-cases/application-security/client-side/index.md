<p>Third-party scripts on your site can be compromised to exfiltrate data or inject malicious code. Cloudflare's client-side security (previously known as Page Shield) monitors every JavaScript resource loading on your pages, detects suspicious behavior, and helps you manage Content Security Policies (CSPs).</p>
<h2 id="solutions">Solutions</h2>
<h3 id="client-side-security">Client-side security</h3>
<p>Monitor and control third-party scripts and outbound connections on your pages. <a href="/client-side-security/">Learn more about client-side security</a>.</p>
<ul>
<li><strong>Script monitoring</strong> - Track every JavaScript resource loading on your pages, including third-party scripts</li>
<li><strong>Malicious script detection</strong> - Receive alerts when scripts exhibit suspicious behavior such as data exfiltration patterns</li>
<li><strong>Connection monitoring</strong> - See which external endpoints scripts are sending data to</li>
<li><strong>CSP management</strong> - Generate and manage Content Security Policies (CSPs) based on observed script behavior</li>
</ul>
