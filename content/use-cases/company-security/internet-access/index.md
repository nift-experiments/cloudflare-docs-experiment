<p>Employees browsing the Internet encounter malware, phishing, and data exfiltration risks. Cloudflare Gateway filters DNS and HTTP traffic to block threats and enforce acceptable use policies, while browser isolation executes risky content in a remote browser.</p>
<h2 id="solutions">Solutions</h2>
<h3 id="gateway">Gateway</h3>
<p>Secure web gateway with DNS, HTTP, and network filtering. <a href="/cloudflare-one/traffic-policies/">Learn more about Gateway</a>.</p>
<ul>
<li><strong>Threat protection</strong> - Block malware, phishing, and command-and-control domains at the DNS and HTTP layers</li>
<li><strong>Content filtering</strong> - Enforce acceptable use policies by blocking categories of domains across the organization</li>
<li><strong>Data protection</strong> - Inspect HTTP traffic and prevent sensitive data from being uploaded to unauthorized destinations</li>
</ul>
<h3 id="cloudflare-one">Cloudflare One</h3>
<p>Secure your organization with a cloud security platform that replaces legacy perimeters with Cloudflare's global network. <a href="/cloudflare-one/">Learn more about Cloudflare One</a>.</p>
<ul>
<li><strong>Browser isolation</strong> - Execute risky web content in a remote browser, keeping malware away from user devices</li>
</ul>
