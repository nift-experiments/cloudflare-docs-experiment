<p>Understanding how shoppers experience your store — page load times, security events, and traffic patterns — requires analytics that do not slow down your site. Cloudflare Web Analytics collects real user metrics without cookies, Security Analytics shows WAF and bot activity, and Logpush exports logs for compliance.</p>
<h2 id="solutions">Solutions</h2>
<h3 id="web-analytics">Web analytics</h3>
<p>Privacy-first, cookie-free analytics for websites. <a href="/web-analytics/">Learn more about Web analytics</a>.</p>
<ul>
<li><strong>Real user metrics</strong> - Core Web Vitals and performance data collected from actual visitors without cookies or sampling</li>
</ul>
<h3 id="security-analytics">Security analytics</h3>
<p>Analyze security events and fine-tune your Application Security configuration. <a href="/waf/analytics/">Learn more about Security analytics</a>.</p>
<ul>
<li><strong>Security visibility</strong> - Understand application security rule triggers, bot activity patterns, and attack trends in one view</li>
</ul>
<h3 id="logpush">Logpush</h3>
<p>Stream logs from Cloudflare products to external destinations. <a href="/logs/">Learn more about Logpush</a>.</p>
<ul>
<li><strong>Compliance logging</strong> - Export detailed request logs to your Security Information and Event Management (SIEM) system or data warehouse for audit trails and forensic analysis</li>
</ul>
