<p>Online stores are targets for DDoS attacks, credential stuffing, payment fraud, and supply chain script injections. Cloudflare provides layered security — from SSL/TLS encryption and application security managed rulesets to bot detection and client-side script monitoring — that protects your store without adding friction for shoppers.</p>
<h2 id="solutions">Solutions</h2>
<h3 id="ssl-tls">SSL/TLS</h3>
<p>Encrypt all traffic with free, automatic SSL certificates. <a href="/ssl/">Learn more about SSL/TLS</a>.</p>
<ul>
<li><strong>PCI DSS compliance support</strong> - Transport Layer Security (TLS) encryption and application security managed rulesets help meet Payment Card Industry (PCI) payment security requirements</li>
</ul>
<h3 id="application-security">Application security</h3>
<p>Get automatic protection from vulnerabilities and create your own custom rules. <a href="/waf/">Learn more about application security</a>.</p>
<h3 id="ddos-protection">DDoS protection</h3>
<p>Automatic mitigation of volumetric and application-layer DDoS attacks. <a href="/ddos-protection/">Learn more about DDoS protection</a>.</p>
<ul>
<li><strong>HTTP DDoS protection</strong> - Automatic, always-on mitigation of HTTP flood attacks, cache-busting attacks, and application-layer Distributed Denial of Service (DDoS) attacks at layer 7. No configuration required — active on all Cloudflare domains by default</li>
</ul>
<h3 id="bot-security">Bot security</h3>
<p>Machine learning powered bot detection with granular control over bot traffic. <a href="/bots/">Learn more about Bot security</a>.</p>
<ul>
<li><strong>Credential stuffing protection</strong> - ML-powered bot detection blocks automated login and account takeover attacks</li>
</ul>
<h3 id="turnstile">Turnstile</h3>
<p>Privacy-preserving CAPTCHA alternative for forms and user interactions. <a href="/turnstile/">Learn more about Turnstile</a>.</p>
<ul>
<li><strong>Payment form security</strong> - Privacy-preserving CAPTCHA alternative that protects checkout without adding user friction</li>
</ul>
<h3 id="client-side-security">Client-side security</h3>
<p>Monitor and control third-party scripts and outbound connections on your pages. <a href="/client-side-security/">Learn more about Client-side security</a>.</p>
<ul>
<li><strong>Supply chain protection</strong> - Detects malicious scripts injected by compromised third-party vendors (Magecart-style attacks)</li>
</ul>
