<p>Serving images at multiple sizes and formats traditionally requires pre-generating variants for every resolution and device. Cloudflare Images transforms images on-the-fly via URL parameters — resizing, cropping, and converting to WebP or AVIF — while Polish compresses originals without visible quality loss.</p>

<h3 id="images">Images</h3>
<p>Transform, optimize, and deliver images at scale. <a href="/images/">Learn more about Images</a>.</p>

<li><strong>Modern formats</strong> - Automatically serve WebP or AV1 Image File Format (AVIF) to supported browsers, falling back to JPEG/PNG for others</li>
<li><strong>Responsive images</strong> - Generate size variants on demand for different screen sizes and pixel densities</li>
</ul>
