<p>Media assets are vulnerable to hotlinking, unauthorized downloads, and piracy. Cloudflare Hotlink Protection blocks other sites from embedding your media, Stream signed URLs provide time-limited access tokens, and Access gates premium content behind identity policies.</p>
<h2 id="solutions">Solutions</h2>
<h3 id="hotlink-protection">Hotlink Protection</h3>
<p>Block unauthorized embedding of resources from external sites. <a href="/waf/tools/scrape-shield/hotlink-protection/">Learn more about Hotlink Protection</a>.</p>
<ul>
<li><strong>Hotlink protection</strong> - Block other sites from embedding or hot-linking your images and video without permission</li>
</ul>
<h3 id="stream">Stream</h3>
<p>Live streaming with automatic recording and instant playback. <a href="/stream/stream-live/">Learn more about Stream Live</a>.</p>
<ul>
<li><strong>Token authentication</strong> - Issue time-limited access tokens so only authorized viewers can access protected media</li>
</ul>
<h3 id="access">Access</h3>
<p>Zero Trust access control for applications and infrastructure. <a href="/cloudflare-one/access-controls/policies/">Learn more about Access</a>.</p>
<ul>
<li><strong>Identity-based access</strong> - Gate premium or subscriber-only content behind Cloudflare Access identity policies</li>
</ul>
