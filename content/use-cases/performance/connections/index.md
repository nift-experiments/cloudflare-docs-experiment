<p>Network congestion and suboptimal routing between your origin and visitors add latency. Cloudflare Argo Smart Routing uses real-time network telemetry to route requests through the fastest paths, while Early Hints preloads assets before the full HTML response arrives.</p>
<h2 id="solutions">Solutions</h2>
<h3 id="argo-smart-routing">Argo Smart Routing</h3>
<p>Route traffic through the fastest paths across Cloudflare's network. <a href="/argo-smart-routing/">Learn more about Argo Smart Routing</a>.</p>
<ul>
<li><strong>Smart routing</strong> - Automatically route requests through uncongested network paths, reducing latency between edge and origin</li>
<li><strong>Optimized paths</strong> - Real-time network telemetry selects the fastest available route for each request</li>
</ul>
<h3 id="speed">Speed</h3>
<p>Improve the performance of your website or web application. <a href="/speed/">Learn more about Speed</a>.</p>
<ul>
<li><strong>Faster handshakes</strong> - Assess the performance of your website and gain recommendations on how to optimize your website</li>
</ul>
<h3 id="early-hints">Early Hints</h3>
<p>Preload assets before the HTML response arrives. <a href="/speed/optimization/content/early-hints/">Learn more about Early Hints</a>.</p>
<ul>
<li><strong>Asset preloading</strong> - Send <code>103 Early Hints</code> responses so browsers start fetching assets before the full HTML arrives</li>
</ul>
