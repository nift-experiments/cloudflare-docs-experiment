<p>Images are often the largest assets on a page and the biggest contributor to slow load times. Cloudflare Images resizes and converts images on-the-fly to modern formats like WebP and AVIF, while Polish compresses existing images without visible quality loss.</p>
<h2 id="solutions">Solutions</h2>
<h3 id="images">Images</h3>
<p>Transform, optimize, and deliver images at scale. <a href="/images/">Learn more about Images</a>.</p>
<ul>
<li><strong>Modern formats</strong> - Automatically serve WebP or AV1 Image File Format (AVIF) to supported browsers, falling back gracefully for others</li>
<li><strong>Responsive images</strong> - Resize and transform images on-the-fly via URL parameters without pre-generating variants</li>
</ul>
<h3 id="polish">Polish</h3>
<p>Automatic image compression without quality loss. <a href="/images/polish/">Learn more about Polish</a>.</p>
<ul>
<li><strong>Automatic compression</strong> - Reduce image file sizes through lossless or lossy compression without visible quality loss</li>
</ul>
<h3 id="speed">Speed</h3>
<p>Improve page load performance with built-in optimizations. <a href="/speed/">Learn more about Speed</a>.</p>
<ul>
<li><strong>Lazy loading</strong> - Defer loading of off-screen images to improve initial page load and Core Web Vitals</li>
</ul>
