<p>Accelerate websites and applications with Cloudflare CDN (Content Delivery Network) caching, image optimization, smart routing, load balancing, and web analytics.</p>
<ul class="directory-listing"><li><a href="/use-cases/performance/caching/">Cache content globally</a></li><li><a href="/use-cases/performance/image-optimization/">Optimize images</a></li><li><a href="/use-cases/performance/connections/">Accelerate connections</a></li><li><a href="/use-cases/performance/web-assets/">Optimize web assets</a></li><li><a href="/use-cases/performance/load-balancing/">Balance traffic across origins</a></li><li><a href="/use-cases/performance/monitoring/">Monitor performance</a></li></ul>
<h2 id="prerequisites">Prerequisites</h2>
<ul>
<li>A <a href="https://dash.cloudflare.com/sign-up">Cloudflare account</a>.</li>
<li>A domain <a href="/fundamentals/manage-domains/add-site/">added to Cloudflare</a> with DNS records proxied through Cloudflare's network. Caching, image optimization, speed optimizations, Argo Smart Routing, and Load Balancing all operate at the edge and require traffic to pass through Cloudflare.</li>
<li>Web Analytics can be added to any site without a proxied domain by <a href="/web-analytics/get-started/">adding the JavaScript snippet</a> to your pages directly.</li>
</ul>
