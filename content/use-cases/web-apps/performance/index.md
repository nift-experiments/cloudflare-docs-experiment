<p>Slow page loads increase bounce rates and reduce conversions. Cloudflare accelerates your application with edge caching, Argo Smart Routing to avoid congested network paths, and automatic asset optimization that improves Core Web Vitals scores.</p>
<h2 id="solutions">Solutions</h2>
<h3 id="cache">Cache</h3>
<p>Cache content at Cloudflare's global network of edge locations. <a href="/cache/">Learn more about Cache</a>.</p>
<ul>
<li><strong>Edge caching</strong> - Serve responses from the nearest Cloudflare location to reduce latency and origin load</li>
</ul>
<h3 id="argo-smart-routing">Argo Smart Routing</h3>
<p>Route traffic through the fastest paths across Cloudflare's network. <a href="/argo-smart-routing/">Learn more about Argo Smart Routing</a>.</p>
<ul>
<li><strong>Smart routing</strong> - Automatically avoid congested network paths between edge and origin</li>
</ul>
<h3 id="speed">Speed</h3>
<p>Automatic optimizations for HTML, CSS, JavaScript, and fonts. <a href="/speed/">Learn more about Speed</a>.</p>
<ul>
<li><strong>Asset optimization</strong> - Automatic minification of HTML, CSS, and JavaScript plus Brotli compression</li>
<li><strong>Core Web Vitals</strong> - Improve Largest Contentful Paint (LCP), Interaction to Next Paint (INP), and Cumulative Layout Shift (CLS) scores with built-in optimizations</li>
</ul>
<h3 id="workers">Workers</h3>
<p>Build and deploy serverless applications on Cloudflare's global network. <a href="/workers/">Learn more about Workers</a>.</p>
<ul>
<li><strong>Edge logic</strong> - Run custom performance optimizations at the edge, such as HTML rewriting and dynamic content assembly, without round-trips to your origin</li>
</ul>
