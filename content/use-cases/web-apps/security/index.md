<p>Web applications face threats at every layer: unencrypted traffic, injection attacks, DDoS floods, credential stuffing bots, and malicious third-party scripts. Cloudflare provides defense in depth from automatic SSL/TLS encryption through application security, DDoS protection, bot scoring, and client-side script monitoring.</p>
<h2 id="solutions">Solutions</h2>
<h3 id="ssl-tls">SSL/TLS</h3>
<p>Encrypt all traffic with free, automatic SSL certificates. <a href="/ssl/">Learn more about SSL/TLS</a>.</p>
<ul>
<li><strong>Automatic HTTPS</strong> - Free Universal SSL certificates provisioned and renewed automatically</li>
</ul>
<h3 id="application-security">Application security</h3>
<p>Get automatic protection from vulnerabilities and create your own custom rules. <a href="/waf/">Learn more about Application security</a>.</p>
<ul>
<li><strong>Attack protection</strong> - Application security's managed rulesets block SQL injection, Cross-Site Scripting (XSS), and Open Web Application Security Project (OWASP) Top 10 vulnerabilities</li>
</ul>
<h3 id="ddos-protection">DDoS protection</h3>
<p>Automatic mitigation of volumetric and application-layer DDoS attacks. <a href="/ddos-protection/">Learn more about DDoS protection</a>.</p>
<ul>
<li><strong>DDoS mitigation</strong> - Always-on layer 3/4 and layer 7 Distributed Denial of Service (DDoS) protection included at no extra cost</li>
</ul>
<h3 id="bot-security">Bot security</h3>
<p>Machine learning powered bot detection with granular control over bot traffic. <a href="/bots/">Learn more about Bot security</a>.</p>
<ul>
<li><strong>Bot defense</strong> - Stop credential stuffing and content scraping with ML-powered bot scoring</li>
</ul>
<h3 id="turnstile">Turnstile</h3>
<p>Privacy-preserving CAPTCHA alternative for forms and user interactions. <a href="/turnstile/">Learn more about Turnstile</a>.</p>
<ul>
<li><strong>Form protection</strong> - Privacy-preserving CAPTCHA alternative for login and signup forms</li>
</ul>
<h3 id="client-side-security">Client-side security</h3>
<p>Monitor and control third-party scripts and outbound connections on your pages. <a href="/client-side-security/">Learn more about Client-side security</a>.</p>
<ul>
<li><strong>Script security</strong> - Detect and block malicious third-party JavaScript injections</li>
</ul>
