<p>Querying an index, or vector search, enables you to search an index by providing an input vector and returning the nearest vectors based on the <a href="/vectorize/best-practices/create-indexes/#distance-metrics">configured distance metric</a>.</p>
<p>Optionally, you can apply <a href="/vectorize/reference/metadata-filtering/">metadata filters</a> or a <a href="/vectorize/best-practices/insert-vectors/#namespaces">namespace</a> to narrow the vector search space.</p>
<h2 id="example-query">Example query</h2>
<p>To pass a vector as a query to an index, use the <code>query()</code> method on the index itself.</p>
<p>A query vector is either an array of JavaScript numbers, 32-bit floating point or 64-bit floating point numbers: <code>number[]</code>, <code>Float32Array</code>, or <code>Float64Array</code>. Unlike when <a href="/vectorize/best-practices/insert-vectors/">inserting vectors</a>, a query vector does not need an ID or metadata.</p>
<pre tabindex="0"><code class="language-ts">// query vector dimensions must match the Vectorize index dimension being queried&#10;let queryVector = [54.8, 5.5, 3.1, ...];&#10;let matches = await env.YOUR_INDEX.query(queryVector);&#10;</code></pre>
<p>This would return a set of matches resembling the following, based on the distance metric configured for the Vectorize index. Example response with <code>cosine</code> distance metric:</p>
<pre tabindex="0"><code class="language-json">{&#10;	&quot;count&quot;: 5,&#10;	&quot;matches&quot;: [&#10;		{ &quot;score&quot;: 0.999909486, &quot;id&quot;: &quot;5&quot; },&#10;		{ &quot;score&quot;: 0.789848214, &quot;id&quot;: &quot;4&quot; },&#10;		{ &quot;score&quot;: 0.720476967, &quot;id&quot;: &quot;4444&quot; },&#10;		{ &quot;score&quot;: 0.463884663, &quot;id&quot;: &quot;6&quot; },&#10;		{ &quot;score&quot;: 0.378282232, &quot;id&quot;: &quot;1&quot; }&#10;	]&#10;}&#10;</code></pre>
<p>You can optionally change the number of results returned and/or whether results should include metadata and values:</p>
<pre tabindex="0"><code class="language-ts">// query vector dimensions must match the Vectorize index dimension being queried&#10;let queryVector = [54.8, 5.5, 3.1, ...];&#10;// topK defaults to 5; returnValues defaults to false; returnMetadata defaults to &quot;none&quot;&#10;let matches = await env.YOUR_INDEX.query(queryVector, {&#10;	topK: 1,&#10;	returnValues: true,&#10;	returnMetadata: &quot;all&quot;,&#10;});&#10;</code></pre>
<p>This would return a set of matches resembling the following, based on the distance metric configured for the Vectorize index. Example response with <code>cosine</code> distance metric:</p>
<pre tabindex="0"><code class="language-json">{&#10;	&quot;count&quot;: 1,&#10;	&quot;matches&quot;: [&#10;		{&#10;			&quot;score&quot;: 0.999909486,&#10;			&quot;id&quot;: &quot;5&quot;,&#10;			&quot;values&quot;: [58.79999923706055, 6.699999809265137, 3.4000000953674316, ...],&#10;			&quot;metadata&quot;: { &quot;url&quot;: &quot;/products/sku/55519183&quot; }&#10;		}&#10;	]&#10;}&#10;</code></pre>
<p>Refer to <a href="/vectorize/reference/client-api/">Vectorize API</a> for additional examples.</p>
<h2 id="query-by-vector-identifier">Query by vector identifier</h2>
<p>Vectorize now offers the ability to search for vectors similar to a vector that is already present in the index using the <code>queryById()</code> operation. This can be considered as a single operation that combines the <code>getById()</code> and the <code>query()</code> operation.</p>
<pre tabindex="0"><code class="language-ts">// the query operation would yield results if a vector with id `some-vector-id` is already present in the index.&#10;let matches = await env.YOUR_INDEX.queryById(&quot;some-vector-id&quot;);&#10;</code></pre>
<h2 id="control-over-scoring-precision-and-query-accuracy">Control over scoring precision and query accuracy</h2>
<p>When querying vectors, you can specify to either use high-precision scoring, thereby increasing the precision of the query matches scores as well as the accuracy of the query results, or use approximate scoring for faster response times.
Using approximate scoring, returned scores will be an approximation of the real distance/similarity between your query and the returned vectors; this is the query's default as it's a nice trade-off between accuracy and latency.</p>
<p>High-precision scoring is enabled by setting <code>returnValues: true</code> on your query. This setting tells Vectorize to use the original vector values for your matches, allowing the computation of exact match scores and increasing the accuracy of the results. Because it processes more data, though, high-precision scoring will increase the latency of queries.</p>
<h2 id="workers-ai">Workers AI</h2>
<p>If you are generating embeddings from a <a href="/workers-ai/models/?tasks=Text+Embeddings">Workers AI</a> text embedding model, the response type from <code>env.AI.run()</code> is an object that includes both the <code>shape</code> of the response vector - e.g. <code>[1,768]</code> - and the vector <code>data</code> as an array of vectors:</p>
<pre tabindex="0"><code class="language-ts">interface EmbeddingResponse {&#10;	shape: number[];&#10;	data: number[][];&#10;}&#10;&#10;let userQuery = &quot;a query from a user or service&quot;;&#10;const queryVector: EmbeddingResponse = await env.AI.run(&#10;	&quot;@cf/baai/bge-base-en-v1.5&quot;,&#10;	{&#10;		text: [userQuery],&#10;	},&#10;);&#10;</code></pre>
<p>When passing the vector to the <code>query()</code> method of a Vectorize index, pass only the vector embedding itself on the <code>.data</code> sub-object, and not the top-level response.</p>
<p>For example:</p>
<pre tabindex="0"><code class="language-ts">let matches = await env.TEXT_EMBEDDINGS.query(queryVector.data[0], { topK: 1 });&#10;</code></pre>
<p>Passing <code>queryVector</code> or <code>queryVector.data</code> will cause <code>query()</code> to return an error.</p>
<h2 id="openai">OpenAI</h2>
<p>When using OpenAI's <a href="https://github.com/openai/openai-node">JavaScript client API</a> and <a href="https://platform.openai.com/docs/guides/embeddings/what-are-embeddings">Embeddings API</a>, the response type from <code>embeddings.create</code> is an object that includes the model, usage information and the requested vector embedding.</p>
<pre tabindex="0"><code class="language-ts">const openai = new OpenAI({ apiKey: env.YOUR_OPENAPI_KEY });&#10;&#10;let userQuery = &quot;a query from a user or service&quot;;&#10;&#10;let embeddingResponse = await openai.embeddings.create({&#10;	input: userQuery,&#10;	model: &quot;text-embedding-ada-002&quot;,&#10;});&#10;</code></pre>
<p>Similar to Workers AI, you will need to provide the vector embedding itself (<code>.embedding[0]</code>) and not the <code>EmbeddingResponse</code> wrapper when querying a Vectorize index:</p>
<pre tabindex="0"><code class="language-ts">let matches = await env.TEXT_EMBEDDINGS.query(embeddingResponse.embedding[0], {&#10;	topK: 1,&#10;});&#10;</code></pre>
