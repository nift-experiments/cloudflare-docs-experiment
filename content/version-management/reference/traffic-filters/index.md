<p>When you <a href="/version-management/how-to/environments/#create-environment">create an environment</a>, you specify a traffic filter for that environment. This filter ensures that all traffic reaching the environment and, by extension, the configuration changes associated with the environment's version is intentional.</p>
<p>To send traffic to a specific environment, send requests to your zone that match the pattern specified in your filter. These could be characteristics such as <strong>Edge Server IP</strong>, <strong>Cookie</strong>, <strong>Hostname</strong>, or <strong>User Agent</strong>.</p>
<p>To make sure requests are reaching an environment, review the <a href="/version-management/how-to/versions/#view-metrics">Metrics</a> associated with your environment. These metrics will also help you evaluate whether your configuration changes are affecting traffic in the way you expect.</p>
