I'll walk you through the interface,</p><p>show you what goes under them and how to use each page to monitor,</p><p>investigate, and manage your security protections.</p><p>First, select the domain you would like to manage your application security on.</p><p>Once you have selected a domain, open up the Application Security dashboard by</p><p>clicking security on the navigation bar here.</p><p>Now on the overview page.</p><p>The Security Overview page gives you a high level summary of your security posture for</p><p>this domain. You'll find alerts for Misconfigurations detected threats and</p><p>suggested actions on how to improve your security posture.</p><p>This is a good place to start and review what needs attention across your environment.</p><p>Under analytics, you can analyze security data across two different views traffic and</p><p>events. Use this page to understand what kind of traffic your domain is receiving and how</p><p>Cloudflare is securing your domain based on the detection tools that are enabled.</p><p>This page also serves as a starting point to identify how you may want to configure your</p><p>application security settings based on the patterns of traffic you're receiving.</p><p>The traffic tab shows data on incoming HTTP requests to your domain,</p><p>including ones that have not been affected by any security tools.</p><p>The events tab shows data on security actions that have been performed by Cloudflare</p><p>Security tools on incoming requests.</p><p>Under web assets, you can manage and monitor the security of various types of web related</p><p>assets. For example, use the endpoints tab to get recommendations and insights about your</p><p>endpoint usage. Use the Schema Validation tab to protect your origin from invalid API</p><p>requests and malicious payloads.</p><p>Schema validation works by validating requests against your own API schema.</p><p>The Client Side Resources tab is used to monitor resources such as scripts,</p><p>connections, and cookies that are running on your visitor's web browsers for your domain.</p><p>If you notice unexpected scripts or connections on the dashboard.</p><p>Check them here for signs of malicious activity.</p><p>Security rules is where you manage and define what security actions are.</p><p>Perform on incoming requests.</p><p>Under the Security Rules tab.</p><p>You can manage and create different types of rules to secure your domain.</p><p>You can create your own custom security rules from scratch or use predefined templates to</p><p>help you get started. Under the DDoS protection tab,</p><p>you'll find a DDoS rulesets that mitigate DDoS attacks on your domain.</p><p>The DDoS Attack Protection rule sets are automatically managed and updated by</p><p>Cloudflare, so you only need to use this tab if you want to create an override rule that</p><p>changes how Cloudflare DDoS protection functions.</p><p>In settings, you can configure Cloudflare detection tools and your domain security</p><p>posture. Security settings and detection tools are categorized by the type of threat</p><p>they detect and mitigate.</p><p>Use the filters on this page to find detection tools and settings that are</p><p>relevant to your security needs.</p><p>Thank you for choosing Cloudflare.</p><p>For more information, please refer to our developer documentation.</p></div></details>
