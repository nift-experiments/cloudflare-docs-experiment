<details class="nb-details"><summary>Transcript</summary><div class="nb-details-body video-transcript"><p>An API token allows secure, fine grained access to specific resources</p><p>without exposing your full account credentials.</p><p>They have a limited lifespan and expire automatically.</p><p>This reduces risk if they are compromised.</p><p>For example, if you want to grant someone access to specific apps or data.</p><p>You can create an API token for them.</p><p>There are two types of tokens user token and account token.</p><p>User tokens are directly tied to an individual and their account.</p><p>While account tokens are typically tied to services which can help prevent an</p><p>interruption in service.</p><p>If an employee leaves their organization.</p><p>In this video, we'll walk through how to create an API token in the Cloudflare</p><p>dashboard. Before you begin, make sure you know your account and zone IDs.</p><p>So let's do that. First, the account ID identifies your Cloudflare</p><p>account, while the zone ID identifies a specific domain you've added to Cloudflare.</p><p>From the accounts page, locate your account at the end of the account</p><p>row, open the menu and select Copy Account ID.</p><p>If you only have one account, it looks a little bit different.</p><p>Login and go to the account home page next to your account name,</p><p>select the menu button from the drop down.</p><p>Choose Copy Account ID to find your zone ID, log in and go to the accounts page.</p><p>Select your account, then go to the overview page for your domain.</p><p>Scroll to the API section near the bottom.</p><p>Here you'll see the zone ID and an option to click to copy.</p><p>This section also lists your account ID for convenience.</p><p>Now we can create an API token to create a token.</p><p>Start from the Cloudflare dashboard.</p><p>For a user token, go to profile API tokens.</p><p>For an account token, go to Manage Account account API tokens.</p><p>You will only see this option if you are a Superadmin.</p><p>Select Create token. You can choose from predefined templates or build a custom token.</p><p>For example, let's use the Edit Zone DNS template.</p><p>Give your token a descriptive name such as DNS updates for example.com.</p><p>The template will fulfill permissions, but you can adjust them as needed.</p><p>Next assign permissions.</p><p>Permissions are organized by account, user or zone and usually offer either read</p><p>access or edit access.</p><p>Edit allows full control, create, read, update,</p><p>delete, and list, while read provides viewing rights only.</p><p>Then select the resources the token applies to.</p><p>For instance, granting zone DNS read access for example.com will let the token view DNS</p><p>records for that zone only.</p><p>If the token is used on a different zone, it will return an error.</p><p>Optionally, you can add restrictions such as filtering by client IP or setting a time to</p><p>live value for the token.</p><p>Click continue to summary to review your selections.</p><p>If everything looks correct, choose Create Token.</p><p>The dashboard will now display your new token secret.</p><p>Copy it immediately to a secure location.</p><p>The secret is shown only once.</p><p>Anyone with a token can perform the actions you've authorized,</p><p>so treat it like a password.</p><p>With that, you've successfully created an API token and can begin using it with a</p><p>Cloudflare API. For more information, visit our developer documentation.</p></div></details>
