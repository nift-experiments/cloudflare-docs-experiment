<p>To add a managed rules exception using the API, create a rule with <code>skip</code> action in a <a href="/ruleset-engine/about/rulesets/#entry-point-ruleset">phase entry point ruleset</a> of the <code>http_request_firewall_managed</code> phase. You can define exceptions at the account level and at the zone level. Exceptions are also called skip rules.</p>
<p>To configure the exception, define the <code>action_parameters</code> object according to the exception type. Refer to the following examples:</p>
<ul>
<li><a href="#skip-all-remaining-rules">Skip all remaining rules</a></li>
<li><a href="#skip-the-cloudflare-managed-ruleset">Skip the Cloudflare Managed Ruleset</a></li>
<li><a href="#skip-one-or-more-rules-of-waf-managed-rulesets">Skip one or more rules of WAF managed rulesets</a></li>
</ul>
<p>For more information on creating exceptions using the API, refer to <a href="/ruleset-engine/managed-rulesets/create-exception/">Create an exception</a> in the Ruleset Engine documentation.</p>

<h2 id="examples">Examples</h2>
<h3 id="skip-all-remaining-rules">Skip all remaining rules</h3>
<p>The following example adds a rule that skips all remaining rules in the entry point ruleset for requests matching the <code>dev.example.com</code> hostname.</p>
<ol>
<li>Invoke the <a href="/api/resources/rulesets/subresources/phases/methods/get/">Get a zone entry point ruleset</a> operation to obtain the current configuration of the entry point ruleset of the <code>http_request_firewall_managed</code> phase.</li>
</ol>
<pre tabindex="0" class="nb-api-request"><code class="language-bash">curl --request GET \&#10;  --url https://api.cloudflare.com/client/v4/zones/{zone_id}/rulesets/phases/{ruleset_phase}/entrypoint \&#10;  --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;</code></pre>
<pre tabindex="0"><code class="language-json">{&#10;	&quot;result&quot;: {&#10;		&quot;id&quot;: &quot;060013b1eeb14c93b0dcd896537e0d2c&quot;, // entry point ruleset ID&#10;		&quot;name&quot;: &quot;default&quot;,&#10;		&quot;description&quot;: &quot;&quot;,&#10;		&quot;source&quot;: &quot;firewall_managed&quot;,&#10;		&quot;kind&quot;: &quot;zone&quot;,&#10;		&quot;version&quot;: &quot;3&quot;,&#10;		&quot;rules&quot;: [&#10;			// (...)&#10;		],&#10;		&quot;last_updated&quot;: &quot;2024-01-20T14:29:00.190643Z&quot;,&#10;		&quot;phase&quot;: &quot;http_request_firewall_managed&quot;&#10;	},&#10;	&quot;success&quot;: true,&#10;	&quot;errors&quot;: [],&#10;	&quot;messages&quot;: []&#10;}&#10;</code></pre>
<pre tabindex="0"><code>Save the entry point ruleset ID (`060013b1eeb14c93b0dcd896537e0d2c`) for the next step.&#10;</code></pre>
<ol start="2">
<li>Invoke the <a href="/api/resources/rulesets/subresources/rules/methods/create/">Create a zone ruleset rule</a> operation (a <code>POST</code> request) to add an exception (or skip rule) at the beginning of the rules list, since a skip rule applies only to rules listed after it. The exact rule location is defined in the <a href="/ruleset-engine/rulesets-api/add-rule/#define-the-rule-position-in-the-ruleset"><code>position</code> object</a>.</li>
</ol>
<pre tabindex="0" class="nb-api-request"><code class="language-bash">curl --request POST \&#10;  --url https://api.cloudflare.com/client/v4/zones/{zone_id}/rulesets/{ruleset_id}/rules \&#10;  --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot; \&#10;  --data &#x27;{&#10;  &quot;expression&quot;: &quot;(http.host eq \&quot;dev.example.com\&quot;)&quot;,&#10;  &quot;description&quot;: &quot;Skip managed rules for dev.example.com&quot;,&#10;  &quot;action&quot;: &quot;skip&quot;,&#10;  &quot;action_parameters&quot;: {&#10;    &quot;ruleset&quot;: &quot;current&quot;&#10;  },&#10;  &quot;position&quot;: {&#10;    &quot;before&quot;: &quot;&quot;&#10;  }&#10;}&#x27;</code></pre>
<p>For more information on skipping all remaining rules via API, refer to <a href="/ruleset-engine/managed-rulesets/create-exception/#skip-all-remaining-rules">Create an exception</a> in the Ruleset Engine documentation.</p>
<h3 id="skip-the-cloudflare-managed-ruleset">Skip the Cloudflare Managed Ruleset</h3>

</ol>
<pre tabindex="0" class="nb-api-request"><code class="language-bash">curl --request GET \&#10;  --url https://api.cloudflare.com/client/v4/zones/{zone_id}/rulesets/phases/{ruleset_phase}/entrypoint \&#10;  --header &quot;Authorization: Bearer $CLOUDFLARE_API_TOKEN&quot;</code></pre>
<pre tabindex="0"><code class="language-json">{&#10;	&quot;result&quot;: {&#10;		&quot;id&quot;: &quot;060013b1eeb14c93b0dcd896537e0d2c&quot;, // entry point ruleset ID&#10;		&quot;name&quot;: &quot;default&quot;,&#10;		&quot;description&quot;: &quot;&quot;,&#10;		&quot;source&quot;: &quot;firewall_managed&quot;,&#10;		&quot;kind&quot;: &quot;zone&quot;,&#10;		&quot;version&quot;: &quot;3&quot;,&#10;		&quot;rules&quot;: [&#10;			// (...)&#10;			{&#10;				&quot;id&quot;: &quot;1bdb49371c1f46958fc8b985efcb79e7&quot;, // `execute` rule ID&#10;				&quot;version&quot;: &quot;1&quot;,&#10;				&quot;action&quot;: &quot;execute&quot;,&#10;				&quot;expression&quot;: &quot;true&quot;,&#10;				&quot;last_updated&quot;: &quot;2024-01-20T14:21:28.643979Z&quot;,&#10;				&quot;ref&quot;: &quot;1bdb49371c1f46958fc8b985efcb79e7&quot;,&#10;				&quot;enabled&quot;: true,&#10;				&quot;action_parameters&quot;: {&#10;					&quot;id&quot;: &quot;efb7b8c949ac4650a09736fc376e9aee&quot;, // &quot;Cloudflare Managed Ruleset&quot; ID&#10;					&quot;version&quot;: &quot;latest&quot;&#10;				}&#10;			}&#10;			// (...)&#10;		],&#10;		&quot;last_updated&quot;: &quot;2024-01-20T14:29:00.190643Z&quot;,&#10;		&quot;phase&quot;: &quot;http_request_firewall_managed&quot;&#10;	},&#10;	&quot;success&quot;: true,&#10;	&quot;errors&quot;: [],&#10;	&quot;messages&quot;: []&#10;}&#10;</code></pre>

<pre tabindex="0"><code>Save the following IDs for the next step:&#10;- The ID of the entry point ruleset (`060013b1eeb14c93b0dcd896537e0d2c` in this example)&#10;- The ID of the `execute` rule deployment the managed ruleset (`1bdb49371c1f46958fc8b985efcb79e7` in this example)&#10;</code></pre>
<ol start="2">
<li>Invoke the <a href="/api/resources/rulesets/subresources/rules/methods/create/">Create a zone ruleset rule</a> operation (a <code>POST</code> request) to add an exception (or skip rule) immediately before the <code>execute</code> rule deploying the Cloudflare Managed Ruleset, since a skip rule applies only to rules listed after it. <h3 id="skip-one-or-more-rules-of-waf-managed-rulesets">Skip one or more rules of WAF managed rulesets</h3>

<ol>
<li>Invoke the <a href="/api/resources/rulesets/methods/get/">Get a zone ruleset</a> operation to obtain a list of rules in the Cloudflare Managed Ruleset (ruleset ID <code class="nb-rule-id" title="efb7b8c949ac4650a09736fc376e9aee">376e9aee</code>).<br/>
You can get the managed ruleset details using the account-level endpoint (<a href="/api/resources/rulesets/methods/get/">Get an account ruleset</a>) or the zone-level endpoint (<a href="/api/resources/rulesets/methods/get/">Get a zone ruleset</a>).</li>
