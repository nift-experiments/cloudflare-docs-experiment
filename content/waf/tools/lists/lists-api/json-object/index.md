<h2 id="list-object-structure-and-properties">List object structure and properties</h2>
<p>A JSON response for the <a href="/api/resources/rules/subresources/lists/">Lists API</a> has this structure:</p>
<pre><code class="language-json">{&#10;	&quot;id&quot;: &quot;2c0fc9fa937b11eaa1b71c4d701ab86e&quot;,&#10;	&quot;name&quot;: &quot;my_list_name&quot;,&#10;	&quot;description&quot;: &quot;List description.&quot;,&#10;	&quot;kind&quot;: &quot;(ip|hostname|asn|redirect)&quot;,&#10;	&quot;num_items&quot;: 10,&#10;	&quot;num_referencing_filters&quot;: 2,&#10;	&quot;created_on&quot;: &quot;2021-01-01T08:00:00Z&quot;,&#10;	&quot;modified_on&quot;: &quot;2021-01-10T14:00:00Z&quot;&#10;}&#10;</code></pre>
<p>This table summarizes the object properties:</p>
<table>
<thead>
<tr>
<th>Property</th>
<th>Description</th>
<th>Constraints</th>
</tr>
</thead>
<tbody style="vertical-align:top">
<tr>
<td>
				<code>id</code><br />
				<span class="nb-type">String</span>
</td>
<td>A UUIDv4 identifier generated by Cloudflare.</td>
<td>
				<p>Unique, read only.</p>
				<p>Length: 32 characters.</p>
</td>
</tr>
<tr>
<td>
				<code>name</code><br />
				<span class="nb-type">String</span>
</td>
<td>An informative name for the list.</td>
<td>
				<p>Maximum length: 50 characters.</p>
				<p>Only alphanumeric and underscore (<code>\_</code>) characters are valid.</p>
				<p>A valid name satisfies this regular expression: <code>^[a-zA-Z0-9_]+$</code>.</p>
</td>
</tr>
<tr>
<td>
				<code>description</code><br />
				<span class="nb-type">String</span>
</td>
<td>An informative summary of the list.</td>
<td>Maximum length: 500 characters.</td>
</tr>
<tr>
<td>
				<code>kind</code><br />
				<span class="nb-type">String</span>
</td>
<td>The type of data in the list.</td>
<td>Valid values: <code>ip</code>, <code>hostname</code>, <code>asn</code>, <code>redirect</code>.</td>
</tr>
<tr>
<td>
				<code>num_items</code><br />
				<span class="nb-type">Number</span>
</td>
<td>The number of items in the list.</td>
<td>Read only.</td>
</tr>
<tr>
<td>
				<code>num_referencing_filters</code><br />
				<span class="nb-type">Number</span>
</td>
<td>The number of filters that reference this list.</td>
<td>Read only.</td>
</tr>
<tr>
<td>
				<code>created_on</code><br />
				<span class="nb-type">String</span>
</td>
<td>The <a href='https://datatracker.ietf.org/doc/html/rfc3339'>RFC 3339</a> timestamp the list was created.</td>
<td>Read only.</td>
</tr>
<tr>
<td>
				<code>modified_on</code><br />
				<span class="nb-type">String</span>
</td>
<td>The <a href='https://datatracker.ietf.org/doc/html/rfc3339'>RFC 3339</a> timestamp when the list was last modified.</td>
<td>Read only.</td>
</tr>
</tbody>
</table>
<h2 id="list-item-object-structure-and-properties">List item object structure and properties</h2>
<p>Each list type (IP address, hostname, ASN, redirects) can only contain items of the same type.</p>
<h3 id="ip-address">IP address</h3>
<p>A fully populated JSON object for an IP address list item has the following structure:</p>
<pre><code class="language-json">{&#10;	&quot;id&quot;: &quot;7c5dae5552338874e5053f2534d2767a&quot;,&#10;	&quot;ip&quot;: &quot;10.0.0.1/32&quot;,&#10;	&quot;comment&quot;: &quot;CF DNS server&quot;,&#10;	&quot;created_on&quot;: &quot;2021-10-01T05:20:00.12345Z&quot;,&#10;	&quot;modified_on&quot;: &quot;2021-10-01T05:20:00.12345Z&quot;&#10;}&#10;</code></pre>
<h3 id="hostname">Hostname</h3>
<p>A fully populated JSON object for a hostname list item has the following structure:</p>
<pre><code class="language-json">{&#10;	&quot;id&quot;: &quot;7c5dae5552338874e5053f2534d2767a&quot;,&#10;	&quot;hostname&quot;: {&#10;		&quot;url_hostname&quot;: &quot;*.example.com&quot;&#10;	},&#10;	&quot;created_on&quot;: &quot;2021-10-11T12:39:02Z&quot;,&#10;	&quot;modified_on&quot;: &quot;2021-10-11T12:39:02Z&quot;&#10;}&#10;</code></pre>
<h3 id="asn">ASN</h3>
<p>A fully populated JSON object for an ASN list item has the following structure:</p>
<pre><code class="language-json">{&#10;	&quot;id&quot;: &quot;7c5dae5552338874e5053f2534d2767a&quot;,&#10;	&quot;asn&quot;: 13335,&#10;	&quot;comment&quot;: &quot;My provider&#x27;s ASN&quot;,&#10;	&quot;created_on&quot;: &quot;2021-10-11T12:39:02Z&quot;,&#10;	&quot;modified_on&quot;: &quot;2021-10-11T12:39:02Z&quot;&#10;}&#10;</code></pre>
<h3 id="url-redirect">URL redirect</h3>
<p>A fully populated JSON object for a Bulk Redirect List item has the following structure:</p>
<pre><code class="language-json">{&#10;	&quot;id&quot;: &quot;7c5dae5552338874e5053f2534d2767a&quot;,&#10;	&quot;redirect&quot;: {&#10;		&quot;source_url&quot;: &quot;https://example.com/blog&quot;,&#10;		&quot;target_url&quot;: &quot;https://example.com/blog/latest&quot;,&#10;		&quot;status_code&quot;: 301,&#10;		&quot;include_subdomains&quot;: false,&#10;		&quot;subpath_matching&quot;: false,&#10;		&quot;preserve_query_string&quot;: false,&#10;		&quot;preserve_path_suffix&quot;: true&#10;	},&#10;	&quot;created_on&quot;: &quot;2021-10-11T12:39:02Z&quot;,&#10;	&quot;modified_on&quot;: &quot;2021-10-11T12:39:02Z&quot;&#10;}&#10;</code></pre>
<h3 id="properties-reference">Properties reference</h3>
<p>The JSON object properties for a list item are defined as follows:</p>
<table>
<thead>
<tr>
<th>Property</th>
<th>Description</th>
<th>Constraints</th>
</tr>
</thead>
<tbody style="vertical-align:top">
<tr>
<td>
				<code>id</code><br />
				<span class="nb-type">String</span>
</td>
<td>A UUIDv4 identifier generated by Cloudflare.</td>
<td>
				<p>Unique, read only.</p>
				<p>Length: 32 characters.</p>
</td>
</tr>
<tr>
<td>
				<code>ip</code><br />

				<p>

					<ul>
<pre><code>					&lt;li&gt;IPv4 address&lt;/li&gt;&#10;					&lt;li&gt;IPv6 address&lt;/li&gt;&#10;					&lt;li&gt;IPv4 ranges as &lt;code&gt;/8&lt;/code&gt; through &lt;code&gt;/32&lt;/code&gt; CIDRs&lt;/li&gt;&#10;					&lt;li&gt;IPv6 ranges as &lt;code&gt;/12&lt;/code&gt; through &lt;code&gt;/128&lt;/code&gt; CIDRs&lt;/li&gt;&#10;&#10;				&lt;/ul&gt;&#10;			&lt;/p&gt;&#10;</code></pre>
</td>
</tr>
<tr>
<td>
				<code>comment</code><br />
				<span class="nb-type">String</span>
</td>
<td>An informative summary of the item.</td>
<td><p>Maximum length: 500 characters.</p></td>
</tr>
<tr>
<td>
				<code>redirect</code><br />
				<span class="nb-type">Object</span>
</td>
<td>An object that contains the definition of a URL redirect. Refer to <a href="/rules/url-forwarding/bulk-redirects/reference/parameters/">URL redirect parameters</a> for details.</td>

</tr>
<tr>
<td>
				<code>hostname</code><br />

</td>

<td><p>Applies only to custom lists with hostnames.</p></td>
</tr>
<tr>
<td>
				<code>asn</code><br />
				<span class="nb-type">Integer</span>
</td>
<td>An ASN value.</td>

<tr>
<td>
				<code>created_on</code><br />

</td>

<td>Read only.</td>
</tr>
<tr>
<td>
				<code>modified_on</code><br />
				<span class="nb-type">String</span>
</td>
<td>The  <a href='https://datatracker.ietf.org/doc/html/rfc3339'>RFC 3339</a> timestamp when the item was last modified.</td>
<td>Read only.</td>
</tr>
</tbody>
</table>
