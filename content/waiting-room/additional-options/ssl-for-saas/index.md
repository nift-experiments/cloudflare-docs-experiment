<p>If your application is using a custom hostname — meaning your SaaS provider is using <a href="/cloudflare-for-platforms/cloudflare-for-saas/security/certificate-management/">Cloudflare for SaaS</a> — your application can support a waiting room.</p>
<h2 id="applications-on-cloudflare">Applications on Cloudflare</h2>
<p>If your application is already using Cloudflare, create a waiting room using the <a href="/waiting-room/how-to/create-waiting-room/">typical process</a>.</p>
<h2 id="applications-not-on-cloudflare">Applications not on Cloudflare</h2>
<p>If your application is not using Cloudflare, you need to ask your SaaS provider to configure a waiting room on <a href="/waiting-room/how-to/place-waiting-room/#custom-hostnames">your Cloudflare for SaaS zone</a>.</p>
