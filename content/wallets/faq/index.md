<p>Common questions about Cloudflare Wallet handles.</p>
<h2 id="where-can-i-reserve-a-cloudflare-wallet-handle">Where can I reserve a Cloudflare Wallet handle?</h2>
<p>Cloudflare Wallet handles can be reserved at <a href="https://cloudflare.pay/">cloudflare.pay</a>.</p>
<h2 id="how-much-does-it-cost-to-reserve-a-cloudflare-wallet-handle">How much does it cost to reserve a Cloudflare Wallet handle?</h2>
<p>Reserving a Cloudflare Wallet handle is free.</p>
<h2 id="how-many-cloudflare-wallet-handles-can-i-reserve-per-account">How many Cloudflare Wallet handles can I reserve per account?</h2>
<p>Each Cloudflare account can reserve one handle. Reserving a handle does not guarantee access to a Cloudflare Wallet on release.</p>
<h2 id="who-can-reserve-a-cloudflare-wallet-handle">Who can reserve a Cloudflare Wallet handle?</h2>
<p>Anyone with a Cloudflare account can reserve a Cloudflare Wallet handle. Each account can reserve one handle. Cloudflare reserves the right to reject or reclaim wallet handle reservations for any reason.</p>
<h2 id="how-can-i-change-a-handle-release-a-handle-or-move-a-handle-to-another-account">How can I change a handle, release a handle, or move a handle to another account?</h2>
<p>Handles are allocated first come, first served, and Cloudflare does not currently offer a way to change, release, or move a handle once it is reserved. This includes changing a handle after a rebrand. To ask about a change, <a href="/support/contacting-cloudflare-support/">contact Cloudflare Support</a>.</p>
<h2 id="where-can-i-report-trademark-infringements-abuse-or-spam">Where can I report trademark infringements, abuse or spam?</h2>
<p>Submit abuse reports to Cloudflare via <a href="https://abuse.cloudflare.com/">abuse.cloudflare.com</a>.</p>
