<p>Cloudflare occasionally updates the <code>beacon.min.js</code> file to improve Web Analytics functionality. The table below includes a log of what changed in the <code>beacon.min.js</code> file and when.</p>
<h2 id="2026-09-02">2026-09-02</h2><ol>
<li>Bug fix to prevent rounding of Cumulative Layout Shift (CLS)</li>
<li>Polyfills introduced for <code>Array.prototype.findLast</code> and <code>.at</code> to improve browser compatibility</li>
<li>Google's web-vitals library upgraded to version 6.2.1</li>
<li>OS/browser/engine versions included in beacon payload</li>
<li>Timing durations rounded to 1 millisecond to minimise beacon payload size</li>
</ol><h2 id="2026-08-20">2026-08-20</h2><p>Updated Google's web-vitals library to version 6.1.0. In order to improve the accuracy of tracking soft navigations (i.e. those used by Single Page Applications), we've introduced support for <a href="https://developer.chrome.com/docs/web-platform/soft-navigations">Google's new Soft Navigations API</a> available in Chromium-based browsers (e.g. Chrome, Edge, Opera) and added an improved fallback for non-Chromium browsers (e.g. Safari and Firefox) using <a href="https://developer.mozilla.org/en-US/docs/Web/API/Navigation_API">the Navigation API</a>. For more information, see <a href="/web-analytics/get-started/web-analytics-spa/">Web Analytics for SPAs</a>.</p><h2 id="2026-07-13">2026-07-13</h2><p>The beacon script is now injected with <code>type=&quot;module&quot;</code> to intentionally exclude long EOL'd (End-of-Life'd) browsers like Internet Explorer from loading the script, given they don't support it anyway. <a href="/web-analytics/faq/#why-am-i-seeing-syntax-errors-from-the-beacon-script-in-internet-explorer">See FAQ entry for more information</a>.</p><h2 id="2026-06-16">2026-06-16</h2><p>Updated Google's web-vitals library to version 5.3.0 and updated the JavaScript build output target to ES2015.</p><h2 id="2026-05-15">2026-05-15</h2><p>Updated Google's web-vitals library to version 4.2.4 and captured Interaction to Next Paint (INP) sub-part metrics (Input Delay, Processing Duration, Presentation Delay)</p><h2 id="2024-06-11">2024-06-11</h2><p>Enhanced to include reporting of Server-Timing headers.</p><h2 id="2024-05-22">2024-05-22</h2><p>Introducing new metric fields, transferSize and decodedBodySize are included.</p><h2 id="2024-04-17">2024-04-17</h2><p>Introducing new metric fields, deliveryType (dt) and navigationType (nt) are included.</p><h2 id="2023-10-18">2023-10-18</h2><p>Manages A/B testing tags.</p><h2 id="2023-07-25">2023-07-25</h2><p>Fixed ETag format in the response header.</p><h2 id="2023-07-13">2023-07-13</h2><p>Fixed the issue that was causing an illegal invocation error.</p><h2 id="2023-04-19">2023-04-19</h2><p>Reports additional LCP diagnostic information using web-vitals library's attribution build.</p><h2 id="2023-04-06">2023-04-06</h2><p>Updated webpack configuration to output code in ECMAScript 3 (ES3) format.</p><h2 id="2023-03-23">2023-03-23</h2><p>Updated Google's web-vitals library (version 3.1.1) and removed experimental <code>server-timing</code> header.</p><h2 id="2022-10-17">2022-10-17</h2><p>Updated to report new metrics such as time to first byte (TTFB), interaction to next paint (INP), and first contentful paint (FCP). Additionally, it reports <code>navigator.webdriver</code>, <code>server-timing</code> header (experimental), and protocol info (<code>nextHopProtocol</code>).</p><h2 id="2021-12-14">2021-12-14</h2><p>Improved site filtering.</p><h2 id="2021-11-16">2021-11-16</h2><p>When using the automatic installation feature of the JavaScript Beacon (available only to customers proxied through Cloudflare - also known as orange-clouded customers),
<a href="https://developer.mozilla.org/en-US/docs/Web/Security/Subresource_Integrity">Subresource Integrity (SRI)</a> is now enabled by default. SRI is a security feature that enables browsers to
verify that resources they fetch are delivered without unexpected manipulation.</p><h2 id="2021-09-01">2021-09-01</h2><p>Improved to report debugging information for Core Web Vitals.</p><h2 id="2021-05-28">2021-05-28</h2><p><code>startsWith</code> function replaced with <code>indexOf</code> function, which prevents rendering if multiple beacon scripts are loaded.</p><h2 id="2021-05-12">2021-05-12</h2><p>Reporting endpoint changed from <code>/cdn-cgi/beacon/performance</code> to <code>/cdn-cgi/rum</code> (for Browser Insights only).</p>
