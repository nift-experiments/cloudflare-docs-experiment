<p>Understanding the key metrics in web analytics is essential for optimizing your website’s performance and user experience. Here are the high-level metrics tracked by Cloudflare Web Analytics:</p>
<ul>
<li><strong>Visits</strong> - A page view that originated from a different website or direct link. Cloudflare checks where the HTTP referer does not match the hostname. One visit can consist of multiple page views.</li>
<li><strong>Page views</strong> - A successful HTTP response with a content-type of HTML.</li>
<li><strong>Page load time</strong> - The total amount of time required to load the page.</li>
<li><strong><a href="https://www.cloudflare.com/learning/performance/what-are-core-web-vitals/">Core Web Vitals</a></strong> - Higher-level metrics designed by Google to capture the user experience more completely.</li>
</ul>
