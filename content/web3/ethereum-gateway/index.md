<p>Cloudflare's Ethereum Gateway gives you read and write access to the <a href="/web3/ethereum-gateway/concepts/ethereum/">Ethereum network</a> without installing any software on your computer.</p>
<p>In particular, users can read all information that has been agreed upon by the consensus of existing nodes in the network. In addition, they can write their own transactions and smart contracts to be stored by these nodes in a distributed manner. Anyone else on the network will be able to view these transactions, and even run your smart contracts using their own supply of the Ethereum currency.</p>
<p>These interactions take place through the official <a href="https://github.com/ethereum/execution-apis">Ethereum JSON-RPC API</a> and use <a href="/web3/ethereum-gateway/reference/supported-api-methods/">Cloudflare-supported API methods</a>.</p>
