<p>Though Cloudflare's Ethereum Gateway launched with support for the Rinkeby testnet, Rinkeby did not run through <a href="https://ethereum.org/en/upgrades/merge/">The Merge</a> and - as a result - will no longer be a reliable staging environment for mainnet.</p>
<p>Cloudflare will be deprecating support for Rinkeby on January 30, 2023.</p>
<h2 id="migration">Migration</h2>
<p>To avoid any issues with your Web3 development or debugging, you should switch over to the <a href="/web3/ethereum-gateway/reference/supported-networks/">Sepolia testnet</a>, which is fully supported with your Ethereum Gateway.</p>
<p>To migrate, you should update the endpoints you use when <a href="/web3/how-to/use-ethereum-gateway/">reading from or writing to</a> the Ethereum network.</p>
<p>For example, you might have been using the previous endpoints to interact with your Ethereum Gateway.</p>
<pre><code class="language-bash">curl https://web3-trial.cloudflare-eth.com/v1/rinkeby \&#10;&#45;-header &#x27;Content-Type: application/json&#x27; \&#10;&#45;-data &#x27;{&#10;  &quot;jsonrpc&quot;: &quot;2.0&quot;,&#10;  &quot;method&quot;: &quot;eth_getBlockByNumber&quot;,&#10;  &quot;params&quot;: [&quot;0x2244&quot;, true],&#10;  &quot;id&quot;: 1&#10;}&#x27;&#10;</code></pre>
<pre><code class="language-js">await fetch(&#10;  new Request(&#x27;https://web3-trial.cloudflare-eth.com/v1/rinkeby&#x27;, {&#10;    method: &#x27;POST&#x27;,&#10;    body: JSON.stringify({&#10;      jsonrpc: &#x27;2.0&#x27;,&#10;      method: &#x27;eth_getBlockByNumber&#x27;,&#10;      params: [&#x27;0x2244&#x27;, true],&#10;      id: 1,&#10;    }),&#10;    headers: {&#10;      &#x27;Content-Type&#x27;: &#x27;application/json&#x27;,&#10;    },&#10;  })&#10;).then(resp =&gt; {&#10;  return resp.json();&#10;});&#10;</code></pre>
<p>To migrate away from Rinkeby, change the end of your endpoint to use another testnet.</p>
<pre><code class="language-bash">curl https://web3-trial.cloudflare-eth.com/v1/sepolia \&#10;&#45;-header &#x27;Content-Type: application/json&#x27; \&#10;&#45;-data &#x27;{&#10;  &quot;jsonrpc&quot;: &quot;2.0&quot;,&#10;  &quot;method&quot;: &quot;eth_getBlockByNumber&quot;,&#10;  &quot;params&quot;: [&quot;0x2244&quot;, true],&#10;  &quot;id&quot;: 1&#10;}&#x27;&#10;</code></pre>
<pre><code class="language-js">await fetch(&#10;  new Request(&#x27;https://web3-trial.cloudflare-eth.com/v1/sepolia&#x27;, {&#10;    method: &#x27;POST&#x27;,&#10;    body: JSON.stringify({&#10;      jsonrpc: &#x27;2.0&#x27;,&#10;      method: &#x27;eth_getBlockByNumber&#x27;,&#10;      params: [&#x27;0x2244&#x27;, true],&#10;      id: 1,&#10;    }),&#10;    headers: {&#10;      &#x27;Content-Type&#x27;: &#x27;application/json&#x27;,&#10;    },&#10;  })&#10;).then(resp =&gt; {&#10;  return resp.json();&#10;});&#10;</code></pre>
