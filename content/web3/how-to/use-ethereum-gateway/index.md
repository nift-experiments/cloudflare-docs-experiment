<p>Once you have an Ethereum gateway — meaning that you <a href="/web3/how-to/manage-gateways/#create-a-gateway">create a new gateway</a> with a <code>target</code> of <strong>Ethereum</strong> — you can interact with <a href="/web3/ethereum-gateway/reference/supported-networks/">different Ethereum networks</a> by specifying the correct JSON blob for your query.</p>
<h2 id="read-from-the-network">Read from the network</h2>
<p>The Cloudflare Ethereum Gateway allows HTTP requests where the body of the request is set to be the JSON body of the request you would like to make. For example, if you would like to read the block that is at number <code>0x2244</code>, then your JSON blob takes the form:</p>
<pre><code class="language-json">{&#10;	&quot;jsonrpc&quot;: &quot;2.0&quot;,&#10;	&quot;method&quot;: &quot;eth_getBlockByNumber&quot;,&#10;	&quot;params&quot;: [&quot;0x2244&quot;, true],&#10;	&quot;id&quot;: 1&#10;}&#10;</code></pre>
<p>Each blob use a valid <a href="/web3/ethereum-gateway/reference/supported-api-methods/"><code>method</code> parameter</a>. The <code>params</code> array here contains the block number that we would like to locate and a boolean expressing whether each individual transaction in the block should be shown in their entirety (<code>true</code>) or as stubs (<code>false</code>).</p>
<p>To send this query to your <a href="/web3/how-to/manage-gateways/">custom Ethereum Gateway</a>, you could use a cURL command:</p>
<pre><code class="language-sh">curl https://web3-trial.cloudflare-eth.com/v1/mainnet -H &#x27;Content-Type: application/json&#x27; --data &#x27;{&quot;jsonrpc&quot;:&quot;2.0&quot;,&quot;method&quot;:&quot;eth_getBlockByNumber&quot;,&quot;params&quot;:[&quot;0x2244&quot;, true],&quot;id&quot;:1}&#x27;&#10;</code></pre>
<p>You can also write the same query using the JS Fetch API:</p>
<pre><code class="language-js">await fetch(&#10;	new Request(&quot;https://web3-trial.cloudflare-eth.com/v1/mainnet&quot;, {&#10;		method: &quot;POST&quot;,&#10;		body: JSON.stringify({&#10;			jsonrpc: &quot;2.0&quot;,&#10;			method: &quot;eth_getBlockByNumber&quot;,&#10;			params: [&quot;0x2244&quot;, true],&#10;			id: 1,&#10;		}),&#10;		headers: {&#10;			&quot;Content-Type&quot;: &quot;application/json&quot;,&#10;		},&#10;	}),&#10;).then((resp) =&gt; {&#10;	return resp.json();&#10;});&#10;</code></pre>

<h2 id="write-to-the-network">Write to the network</h2>
<p>Currently, the Ethereum Gateway allows you to write to the network using the <code>eth_sendRawTransaction</code> RPC method. This creates a new message call transaction or a contract creation for signed transactions. The transactions are signed using a secret key corresponding to your own <a href="https://www.ethereum.org/use/#_3-what-is-a-wallet-and-which-one-should-i-use">Ethereum wallet</a>.</p>
<p>Once you have a wallet set up and a method of signing your own transactions, you can write that transaction to the Ethereum network via the <a href="/web3/ethereum-gateway/reference/supported-api-methods/">Cloudflare Ethereum Gateway</a>. Signed transactions use hexadecimal strings of the form:</p>
<pre><code class="language-json">&quot;0xd46e8dd67c5d32be8d46e8dd67c5d32be8058bb8eb970870f072445675058bb8eb970870f072445675&quot;&#10;</code></pre>
<p>Then you can use your <a href="/web3/how-to/manage-gateways/">custom Gateway</a> to send the transaction to the network with a cURL command:</p>
<pre><code class="language-sh">curl https://web3-trial.cloudflare-eth.com/v1/mainnet -H &#x27;Content-Type: application/json&#x27; --data &#x27;{&quot;jsonrpc&quot;:&quot;2.0&quot;,&quot;method&quot;:&quot;eth_sendRawTransaction&quot;,&quot;params&quot;:[&quot;0xd46e8dd67c5d32be8d46e8dd67c5d32be8058bb8eb970870f072445675058bb8eb970870f072445675&quot;],&quot;id&quot;:1}&#x27;&#10;</code></pre>
<p>You could also use a JS Fetch API request:</p>
<pre><code class="language-js">await fetch(&#10;	new Request(&quot;https://web3-trial.cloudflare-eth.com/v1/mainnet&quot;, {&#10;		method: &quot;POST&quot;,&#10;		body: JSON.stringify({&#10;			jsonrpc: &quot;2.0&quot;,&#10;			method: &quot;eth_sendRawTransaction&quot;,&#10;			params: [&#10;				&quot;0xd46e8dd67c5d32be8d46e8dd67c5d32be8058bb8eb970870f072445675058bb8eb970870f072445675&quot;,&#10;			],&#10;			id: 1,&#10;		}),&#10;		headers: {&#10;			&quot;Content-Type&quot;: &quot;application/json&quot;,&#10;		},&#10;	}),&#10;).then((resp) =&gt; {&#10;	return resp.json();&#10;});&#10;</code></pre>
<p><em>(The actual command above will not work — you need to provide your own signed transaction.)</em></p>
