<p>Cloudflare's IPFS gateway provides a read-only, HTTP-accessible interface to the <a href="/web3/ipfs-gateway/concepts/ipfs/">Interplanetary File System (IPFS)</a>. This gateway does not require you to download any special software or give up any storage space on your computer.</p>
