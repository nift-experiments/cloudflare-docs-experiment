<p>Once you <a href="/web3/how-to/manage-gateways/#create-a-gateway">create a gateway</a>, it can have one of several statuses.</p>
<table>
<thead>
<tr>
<th>Status</th>
<th>Definition</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>Active</strong></td>
<td>The DNS records for your gateway have been created and are functioning correctly.</td>
</tr>
<tr>
<td><strong>Pending</strong></td>
<td>Your Web3 gateway is in the process of becoming <strong>Active</strong>.</td>
</tr>
<tr>
<td><strong>Deleting</strong></td>
<td>Your Web3 gateway is being deleted.</td>
</tr>
<tr>
<td><strong>Error</strong></td>
<td>The DNS records for your gateway are misconfigured or do not exist. To fix, try <a href="/web3/how-to/manage-gateways/#refresh-a-gateway">refreshing the gateway</a>.</td>
</tr>
</tbody>
</table>
