<p>Workers AI can be used with the <a href="https://sdk.vercel.ai/">Vercel AI SDK</a> for JavaScript and TypeScript codebases.</p>
<h2 id="setup">Setup</h2>
<p>Install the <a href="https://sdk.vercel.ai/providers/community-providers/cloudflare-workers-ai"><code>workers-ai-provider</code> provider</a>:</p>

<p>Then, add an AI binding in your Workers project Wrangler file:</p>
<pre tabindex="0"><code class="language-toml">[ai]&#10;binding = &quot;AI&quot;&#10;</code></pre>
<h2 id="models">Models</h2>
<p>The AI SDK can be configured to work with <a href="/workers-ai/models/">any AI model</a>.</p>
<pre tabindex="0"><code class="language-js">import { createWorkersAI } from &quot;workers-ai-provider&quot;;&#10;&#10;const workersai = createWorkersAI({ binding: env.AI });&#10;&#10;// Choose any model: https://developers.cloudflare.com/workers-ai/models/&#10;const model = workersai(&quot;@cf/meta/llama-3.1-8b-instruct&quot;, {});&#10;</code></pre>
<h2 id="generate-text">Generate Text</h2>
<p>Once you have selected your model, you can generate text from a given prompt.</p>
<pre tabindex="0"><code class="language-js">import { createWorkersAI } from &#x27;workers-ai-provider&#x27;;&#10;import { generateText } from &#x27;ai&#x27;;&#10;&#10;type Env = {&#10;  AI: Ai;&#10;};&#10;&#10;export default {&#10;  async fetch(_: Request, env: Env) {&#10;    const workersai = createWorkersAI({ binding: env.AI });&#10;    const result = await generateText({&#10;      model: workersai(&#x27;@cf/meta/llama-2-7b-chat-int8&#x27;),&#10;      prompt: &#x27;Write a 50-word essay about hello world.&#x27;,&#10;    });&#10;&#10;    return new Response(result.text);&#10;  },&#10;};&#10;</code></pre>
<h2 id="stream-text">Stream Text</h2>
<p>For longer responses, consider streaming responses to provide as the generation completes.</p>
<pre tabindex="0"><code class="language-js">import { createWorkersAI } from &#x27;workers-ai-provider&#x27;;&#10;import { streamText } from &#x27;ai&#x27;;&#10;&#10;type Env = {&#10;  AI: Ai;&#10;};&#10;&#10;export default {&#10;  async fetch(_: Request, env: Env) {&#10;    const workersai = createWorkersAI({ binding: env.AI });&#10;    const result = streamText({&#10;      model: workersai(&#x27;@cf/meta/llama-2-7b-chat-int8&#x27;),&#10;      prompt: &#x27;Write a 50-word essay about hello world.&#x27;,&#10;    });&#10;&#10;    return result.toTextStreamResponse({&#10;      headers: {&#10;        // add these headers to ensure that the&#10;        // response is chunked and streamed&#10;        &#x27;Content-Type&#x27;: &#x27;text/x-unknown&#x27;,&#10;        &#x27;content-encoding&#x27;: &#x27;identity&#x27;,&#10;        &#x27;transfer-encoding&#x27;: &#x27;chunked&#x27;,&#10;      },&#10;    });&#10;  },&#10;};&#10;</code></pre>
<h2 id="generate-structured-objects">Generate Structured Objects</h2>
<p>You can provide a Zod schema to generate a structured JSON response.</p>
<pre tabindex="0"><code class="language-js">import { createWorkersAI } from &#x27;workers-ai-provider&#x27;;&#10;import { generateObject } from &#x27;ai&#x27;;&#10;import { z } from &#x27;zod&#x27;;&#10;&#10;type Env = {&#10;  AI: Ai;&#10;};&#10;&#10;export default {&#10;  async fetch(_: Request, env: Env) {&#10;    const workersai = createWorkersAI({ binding: env.AI });&#10;    const result = await generateObject({&#10;      model: workersai(&#x27;@cf/meta/llama-3.1-8b-instruct&#x27;),&#10;      prompt: &#x27;Generate a Lasagna recipe&#x27;,&#10;      schema: z.object({&#10;        recipe: z.object({&#10;          ingredients: z.array(z.string()),&#10;          description: z.string(),&#10;        }),&#10;      }),&#10;    });&#10;&#10;    return Response.json(result.object);&#10;  },&#10;};&#10;</code></pre>
