<p>If you prefer to work directly with the REST API instead of a <a href="/workers-ai/features/batch-api/workers-binding/">Cloudflare Worker</a>, below are the steps on how to do it:</p>
<h2 id="1-sending-a-batch-request"><ol>
<li>Sending a Batch Request</li>
</ol></h2>
<p>Make a POST request using the following pattern. You can pass <code>external_reference</code> as a unique ID per-request that will be returned in the response.</p>
<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/ai/run/@cf/baai/bge-m3?queueRequest=true&quot; \&#10; &#45;-header &quot;Authorization: Bearer $API_TOKEN&quot; \&#10; &#45;-header &#x27;Content-Type: application/json&#x27; \&#10; &#45;-json &#x27;{&#10;    &quot;requests&quot;: [&#10;        {&#10;            &quot;query&quot;: &quot;This is a story about Cloudflare&quot;,&#10;            &quot;contexts&quot;: [&#10;                {&#10;                    &quot;text&quot;: &quot;This is a story about an orange cloud&quot;&#10;                },&#10;                {&#10;                    &quot;text&quot;: &quot;This is a story about a llama&quot;&#10;                },&#10;                {&#10;                    &quot;text&quot;: &quot;This is a story about a hugging emoji&quot;&#10;                }&#10;            ],&#10;            &quot;external_reference&quot;: &quot;reference-1&quot;&#10;        }&#10;    ]&#10;  }&#x27;&#10;</code></pre>
<pre><code class="language-json">{&#10;	&quot;result&quot;: {&#10;		&quot;status&quot;: &quot;queued&quot;,&#10;		&quot;request_id&quot;: &quot;768f15b7-4fd6-4498-906e-ad94ffc7f8d2&quot;,&#10;		&quot;model&quot;: &quot;@cf/baai/bge-m3&quot;&#10;	},&#10;	&quot;success&quot;: true,&#10;	&quot;errors&quot;: [],&#10;	&quot;messages&quot;: []&#10;}&#10;</code></pre>
<h2 id="2-retrieving-the-batch-response"><ol start="2">
<li>Retrieving the Batch Response</li>
</ol></h2>
<p>After receiving a <code>request_id</code> from your initial POST, you can poll for or retrieve the results with another POST request:</p>
<pre><code class="language-bash">curl &quot;https://api.cloudflare.com/client/v4/accounts/$ACCOUNT_ID/ai/run/@cf/baai/bge-m3?queueRequest=true&quot; \&#10; &#45;-header &quot;Authorization: Bearer $API_TOKEN&quot; \&#10; &#45;-header &#x27;Content-Type: application/json&#x27; \&#10; &#45;-json &#x27;{&#10;    &quot;request_id&quot;: &quot;&lt;uuid&gt;&quot;&#10;  }&#x27;&#10;</code></pre>
<pre><code class="language-json">{&#10;	&quot;result&quot;: {&#10;		&quot;responses&quot;: [&#10;			{&#10;				&quot;id&quot;: 0,&#10;				&quot;result&quot;: {&#10;					&quot;response&quot;: [&#10;						{ &quot;id&quot;: 0, &quot;score&quot;: 0.73974609375 },&#10;						{ &quot;id&quot;: 1, &quot;score&quot;: 0.642578125 },&#10;						{ &quot;id&quot;: 2, &quot;score&quot;: 0.6220703125 }&#10;					]&#10;				},&#10;				&quot;success&quot;: true,&#10;				&quot;external_reference&quot;: &quot;reference-1&quot;&#10;			}&#10;		],&#10;		&quot;usage&quot;: { &quot;prompt_tokens&quot;: 12, &quot;completion_tokens&quot;: 0, &quot;total_tokens&quot;: 12 }&#10;	},&#10;	&quot;success&quot;: true,&#10;	&quot;errors&quot;: [],&#10;	&quot;messages&quot;: []&#10;}&#10;</code></pre>
