<p>Interact with persistent storage to retrieve or store information enables for powerful use cases.</p>
<p>In this example we show how embedded function calling can interact with other resources on the Cloudflare Developer Platform with a few lines of code.</p>
<h2 id="pre-requisites">Pre-Requisites</h2>
<p>For this example to work, you need to provision a <a href="/kv/">KV</a> namespace first. To do so, follow the <a href="/kv/get-started/">KV - Get started </a> guide.</p>
<p>Importantly, your Wrangler file must be updated to include the <code>KV</code> binding definition to your respective namespace.</p>
<h2 id="worker-code">Worker code</h2>
<pre><code class="language-ts">import { runWithTools } from &quot;@cloudflare/ai-utils&quot;;&#10;&#10;type Env = {&#10;	AI: Ai;&#10;	KV: KVNamespace;&#10;};&#10;&#10;export default {&#10;	async fetch(request, env, ctx) {&#10;		// Define function&#10;		const updateKvValue = async ({&#10;			key,&#10;			value,&#10;		}: {&#10;			key: string;&#10;			value: string;&#10;		}) =&gt; {&#10;			const response = await env.KV.put(key, value);&#10;			return `Successfully updated key-value pair in database: ${response}`;&#10;		};&#10;&#10;		// Run AI inference with function calling&#10;		const response = await runWithTools(&#10;			env.AI,&#10;			&quot;@hf/nousresearch/hermes-2-pro-mistral-7b&quot;,&#10;			{&#10;				messages: [&#10;					{ role: &quot;system&quot;, content: &quot;Put user given values in KV&quot; },&#10;					{ role: &quot;user&quot;, content: &quot;Set the value of banana to yellow.&quot; },&#10;				],&#10;				tools: [&#10;					{&#10;						name: &quot;KV update&quot;,&#10;						description: &quot;Update a key-value pair in the database&quot;,&#10;						parameters: {&#10;							type: &quot;object&quot;,&#10;							properties: {&#10;								key: {&#10;									type: &quot;string&quot;,&#10;									description: &quot;The key to update&quot;,&#10;								},&#10;								value: {&#10;									type: &quot;string&quot;,&#10;									description: &quot;The value to update&quot;,&#10;								},&#10;							},&#10;							required: [&quot;key&quot;, &quot;value&quot;],&#10;						},&#10;						function: updateKvValue,&#10;					},&#10;				],&#10;			},&#10;		);&#10;		return new Response(JSON.stringify(response));&#10;	},&#10;} satisfies ExportedHandler&lt;Env&gt;;&#10;</code></pre>
