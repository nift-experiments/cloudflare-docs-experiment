<p>This page shows how you can do traditional function calling, as defined by industry standards. Workers AI also offers <a href="/workers-ai/features/function-calling/embedded/">embedded function calling</a>, which is drastically easier than traditional function calling.</p>
<p>With traditional function calling, you define an array of tools with the name, description, and tool arguments. The example below shows how you would pass a tool called <code>getWeather</code> in an inference request to a model.</p>
<pre tabindex="0"><code class="language-js">const response = await env.AI.run(&quot;@hf/nousresearch/hermes-2-pro-mistral-7b&quot;, {&#10;	messages: [&#10;		{&#10;			role: &quot;user&quot;,&#10;			content: &quot;what is the weather in london?&quot;,&#10;		},&#10;	],&#10;	tools: [&#10;		{&#10;			name: &quot;getWeather&quot;,&#10;			description: &quot;Return the weather for a latitude and longitude&quot;,&#10;			parameters: {&#10;				type: &quot;object&quot;,&#10;				properties: {&#10;					latitude: {&#10;						type: &quot;string&quot;,&#10;						description: &quot;The latitude for the given location&quot;,&#10;					},&#10;					longitude: {&#10;						type: &quot;string&quot;,&#10;						description: &quot;The longitude for the given location&quot;,&#10;					},&#10;				},&#10;				required: [&quot;latitude&quot;, &quot;longitude&quot;],&#10;			},&#10;		},&#10;	],&#10;});&#10;&#10;return new Response(JSON.stringify(response.tool_calls));&#10;</code></pre>
<p>The LLM will then return a JSON object with the required arguments and the name of the tool that was called. You can then pass this JSON object to make an API call.</p>
<pre tabindex="0"><code class="language-json">[&#10;	{&#10;		&quot;arguments&quot;: { &quot;latitude&quot;: &quot;51.5074&quot;, &quot;longitude&quot;: &quot;-0.1278&quot; },&#10;		&quot;name&quot;: &quot;getWeather&quot;&#10;	}&#10;]&#10;</code></pre>
<p>For a working example on how to do function calling, take a look at our <a href="https://github.com/craigsdennis/lightbulb-moment-tool-calling/blob/main/src/index.ts">demo app</a>.</p>
