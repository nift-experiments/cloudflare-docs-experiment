<p>The easiest way to get started with <a href="/workers-ai/">Workers AI</a> is to try it out in the <a href="https://multi-modal.ai.cloudflare.com/">Multi-modal Playground</a> and the <a href="https://playground.ai.cloudflare.com/">LLM playground</a>. If you decide that you want to integrate your code with Workers AI, you may then decide to use its <a href="/workers-ai/get-started/rest-api/">REST API endpoints</a> or a <a href="/workers-ai/configuration/bindings/">Worker binding</a>.</p>
<p>But what about the data? What if you want these models to ingest data that is stored outside Cloudflare?</p>
<p>In this tutorial, you will learn how to bring data from Google BigQuery to a Cloudflare Worker so that it can be used as input for Workers AI models.</p>
<h2 id="prerequisites">Prerequisites</h2>
<p>You will need:</p>
<ul>
<li>A <a href="/workers/">Cloudflare Worker</a> project running a <a href="/workers/get-started/guide/">Hello World script</a>.</li>
<li>A Google Cloud Platform <a href="https://cloud.google.com/iam/docs/service-accounts-create#iam-service-accounts-create-console">service account</a> with an <a href="https://cloud.google.com/iam/docs/keys-create-delete#iam-service-account-keys-create-console">associated key</a> file downloaded that has read access to BigQuery.</li>
<li>Access to a BigQuery table with some test data that allows you to create a <a href="https://cloud.google.com/bigquery/docs/reference/rest/v2/jobs/query">BigQuery Job Query</a>. For this tutorial it is recommended you that you create your own table as <a href="https://cloud.google.com/bigquery/public-data#sample_tables">sampled tables</a>, unless cloned to your own GCP namespace, won't allow you to run job queries against them. For this example, the <a href="https://www.kaggle.com/datasets/hacker-news/hacker-news-corpus">Hacker News Corpus</a> was used under its MIT licence.</li>
</ul>
<h2 id="1-set-up-your-cloudflare-worker"><ol>
<li>Set up your Cloudflare Worker</li>
</ol></h2>
<p>To ingest the data into Cloudflare and feed it into Workers AI, you will be using a <a href="/workers/">Cloudflare Worker</a>. If you have not created one yet, please review our <a href="/workers/get-started/">tutorial on how to get started</a>.</p>
<p>After following the steps to create a Worker, you should have the following code in your new Worker project:</p>
<pre><code class="language-javascript">export default {&#10;	async fetch(request, env, ctx) {&#10;		return new Response(&quot;Hello World!&quot;);&#10;	},&#10;};&#10;</code></pre>
<p>If the Worker project has successfully been created, you should also be able to run <code>npx wrangler dev</code> in a console to run the Worker locally:</p>
<pre><code class="language-sh">[wrangler:inf] Ready on http://localhost:8787&#10;</code></pre>
<p>Open a browser tab at <code>http://localhost:8787/</code> to see your deployed Worker. Please note that the port <code>8787</code> may be a different one in your case.</p>
<p>You should be seeing <code>Hello World!</code> in your browser:</p>
<pre><code class="language-sh">Hello World!&#10;</code></pre>
<p>If you run into any issues during this step, please review the <a href="/workers/get-started/guide/">Worker's Get Started Guide</a>.</p>
<h2 id="2-import-gcp-service-key-into-the-worker-as-secrets"><ol start="2">
<li>Import GCP Service key into the Worker as Secrets</li>
</ol></h2>
<p>Now that you have verified that the Worker has been created successfully, you will need to reference the Google Cloud Platform service key created in the <a href="#prerequisites">Prerequisites</a> section of this tutorial.</p>
<p>Your downloaded key JSON file from Google Cloud Platform should have the following format:</p>
<pre><code class="language-json">{&#10;	&quot;type&quot;: &quot;service_account&quot;,&#10;	&quot;project_id&quot;: &quot;&lt;your_project_id&gt;&quot;,&#10;	&quot;private_key_id&quot;: &quot;&lt;your_private_key_id&gt;&quot;,&#10;	&quot;private_key&quot;: &quot;&lt;your_private_key&gt;&quot;,&#10;	&quot;client_email&quot;: &quot;&lt;your_service_account_id&gt;@&lt;your_project_id&gt;.iam.gserviceaccount.com&quot;,&#10;	&quot;client_id&quot;: &quot;&lt;your_oauth2_client_id&gt;&quot;,&#10;	&quot;auth_uri&quot;: &quot;https://accounts.google.com/o/oauth2/auth&quot;,&#10;	&quot;token_uri&quot;: &quot;https://oauth2.googleapis.com/token&quot;,&#10;	&quot;auth_provider_x509_cert_url&quot;: &quot;https://www.googleapis.com/oauth2/v1/certs&quot;,&#10;	&quot;client_x509_cert_url&quot;: &quot;https://www.googleapis.com/robot/v1/metadata/x509/&lt;your_service_account_id&gt;%40&lt;your_project_id&gt;.iam.gserviceaccount.com&quot;,&#10;	&quot;universe_domain&quot;: &quot;googleapis.com&quot;&#10;}&#10;</code></pre>
<p>For this tutorial, you will only need the values of the following fields: <code>client_email</code>, <code>private_key</code>, <code>private_key_id</code>, and <code>project_id</code>.</p>
<p>Instead of storing this information in plain text in the Worker, you will use <a href="/workers/configuration/secrets/">Secrets</a> to make sure its unencrypted content is only accessible via the Worker itself.</p>
<p>Import those three values from the JSON file into Secrets, starting with the field from the JSON key file called <code>client_email</code>, which we will now call <code>BQ_CLIENT_EMAIL</code> (you can use another variable name):</p>
<pre><code class="language-sh">npx wrangler secret put BQ_CLIENT_EMAIL&#10;</code></pre>
<p>You will be asked to enter a secret value, which will be the value of the field <code>client_email</code> in the JSON key file.</p>

<p>You now have access to the GCP credentials from a Worker. Next, you will install a library to help with the creation of the JSON Web Token needed to interact with GCP's API.</p>
<h2 id="3-install-library-to-handle-jwt-operations"><ol start="3">
<li>Install library to handle JWT operations</li>
</ol></h2>
<p>To interact with BigQuery's REST API, you will need to generate a <a href="https://jwt.io/introduction">JSON Web Token</a> to authenticate your requests using the credentials that you have loaded into Worker secrets in the previous step.</p>
<p>For this tutorial, you will be using the <a href="https://www.npmjs.com/package/jose?activeTab=readme">jose</a> library for JWT-related operations. Install it by running the following command in a console:</p>
<pre><code class="language-sh">npm i jose&#10;</code></pre>
<p>To verify that the installation succeeded, you can run <code>npm list</code>, which lists all the installed packages, to check if the <code>jose</code> dependency has been added:</p>
<pre><code class="language-sh">&lt;project_name&gt;@0.0.0&#10;/&lt;path_to_your_project&gt;/&lt;project_name&gt;&#10;├── @cloudflare/vitest-pool-workers@0.4.29&#10;├── jose@5.9.2&#10;├── vitest@1.5.0&#10;└── wrangler@3.75.0&#10;</code></pre>
<h2 id="4-generate-json-web-token"><ol start="4">
<li>Generate JSON web token</li>
</ol></h2>
<p>Now that you have installed the <code>jose</code> library, it is time to import it and add a function to your code that generates a signed JSON Web Token (JWT):</p>
<pre><code class="language-javascript">import * as jose from &#x27;jose&#x27;;&#10;...&#10;const generateBQJWT = async (aCryptoKey, env) =&gt; {&#10;const algorithm = &quot;RS256&quot;;&#10;const audience = &quot;https://bigquery.googleapis.com/&quot;;&#10;const expiryAt = (new Date().valueOf() / 1000);&#10;	const privateKey = await jose.importPKCS8(env.BQ_PRIVATE_KEY, algorithm);&#10;&#10;	// Generate signed JSON Web Token (JWT)&#10;	return new jose.SignJWT()&#10;    	.setProtectedHeader({&#10;        	typ: &#x27;JWT&#x27;,&#10;        	alg: algorithm,&#10;        	kid: env.BQ_PRIVATE_KEY_ID&#10;    	})&#10;    	.setIssuer(env.BQ_CLIENT_EMAIL)&#10;    	.setSubject(env.BQ_CLIENT_EMAIL)&#10;    	.setAudience(audience)&#10;    	.setExpirationTime(expiryAt)&#10;    	.setIssuedAt()&#10;    	.sign(privateKey)&#10;}&#10;&#10;export default {&#10;	async fetch(request, env, ctx) {&#10;       ...&#10;// Create JWT to authenticate the BigQuery API call&#10;    	let bqJWT;&#10;    	try {&#10;        	bqJWT = await generateBQJWT(env);&#10;    	} catch (e) {&#10;        	return new Response(&#x27;An error has occurred while generating the JWT&#x27;, { status: 500 })&#10;    	}&#10;	},&#10;       ...&#10;};&#10;</code></pre>

<h2 id="5-make-authenticated-requests-to-google-bigquery"><ol start="5">
<li>Make authenticated requests to Google BigQuery</li>
</ol></h2>
<p>With the JWT token created in the previous step, issue an API request to BigQuery's API to retrieve data from a table.</p>
<p>You will now query the table that you created in BigQuery earlier in this tutorial. This example uses a sampled version of the <a href="https://www.kaggle.com/datasets/hacker-news/hacker-news-corpus">Hacker News Corpus</a> that was used under its MIT licence and uploaded to BigQuery.</p>
<pre><code class="language-javascript">const queryBQ = async (bqJWT, path) =&gt; {&#10;	const bqEndpoint = `https://bigquery.googleapis.com${path}`&#10;	// In this example, text is a field in the BigQuery table that is being queried (hn.news_sampled)&#10;	const query = &#x27;SELECT text FROM hn.news_sampled LIMIT 3&#x27;;&#10;	const response = await fetch(bqEndpoint, {&#10;    	method: &quot;POST&quot;,&#10;    	body: JSON.stringify({&#10;        	&quot;query&quot;: query&#10;    	}),&#10;    	headers: {&#10;        	Authorization: `Bearer ${bqJWT}`&#10;    	}&#10;	})&#10;	return response.json()&#10;}&#10;...&#10;export default {&#10;	async fetch(request, env, ctx) {&#10;		...&#10;    		let ticketInfo;&#10;    		try {&#10;    		ticketInfo = await queryBQ(bqJWT);&#10;    	} catch (e) {&#10;        	return new Response(&#x27;An error has occurred while querying BQ&#x27;, { status: 500 });&#10;    	}&#10;	...&#10;	},&#10;};&#10;</code></pre>

<h2 id="6-format-results-from-the-query"><ol start="6">
<li>Format results from the query</li>
</ol></h2>
<p>Now that you have retrieved the data from BigQuery, your BigQuery API response should look something like this:</p>
<pre><code class="language-json">{&#10;	...&#10;	&quot;schema&quot;: {&#10;    	&quot;fields&quot;: [&#10;        	{&#10;            	&quot;name&quot;: &quot;title&quot;,&#10;            	&quot;type&quot;: &quot;STRING&quot;,&#10;            	&quot;mode&quot;: &quot;NULLABLE&quot;&#10;        	},&#10;        	{&#10;            	&quot;name&quot;: &quot;text&quot;,&#10;            	&quot;type&quot;: &quot;STRING&quot;,&#10;            	&quot;mode&quot;: &quot;NULLABLE&quot;&#10;        	}&#10;    	]&#10;	},&#10;	...&#10;	&quot;rows&quot;: [&#10;    	{&#10;        	&quot;f&quot;: [&#10;            	{&#10;                	&quot;v&quot;: &quot;&lt;some_value&gt;&quot;&#10;            	},&#10;            	{&#10;                	&quot;v&quot;: &quot;&lt;some_value&gt;&quot;&#10;            	}&#10;        	]&#10;    	},&#10;    	{&#10;        	&quot;f&quot;: [&#10;            	{&#10;                	&quot;v&quot;: &quot;&lt;some_value&gt;&quot;&#10;            	},&#10;            	{&#10;                	&quot;v&quot;: &quot;&lt;some_value&gt;&quot;&#10;            	}&#10;        	]&#10;    	},&#10;    	{&#10;        	&quot;f&quot;: [&#10;            	{&#10;                	&quot;v&quot;: &quot;&lt;some_value&gt;&quot;&#10;            	},&#10;            	{&#10;                	&quot;v&quot;: &quot;&lt;some_value&gt;&quot;&#10;            	}&#10;        	]&#10;    	}&#10;	],&#10;	...&#10;}&#10;</code></pre>
<p>This format may be difficult to read and work with when iterating through results. So you will now implement a function that maps the schema into each individual value, and the resulting output will be easier to read, as shown below. Each row corresponds to an object within an array.</p>
<pre><code class="language-javascript">[&#10;	{&#10;		title: &quot;&lt;some_value&gt;&quot;,&#10;		text: &quot;&lt;some_value&gt;&quot;,&#10;	},&#10;	{&#10;		title: &quot;&lt;some_value&gt;&quot;,&#10;		text: &quot;&lt;some_value&gt;&quot;,&#10;	},&#10;	{&#10;		title: &quot;&lt;some_value&gt;&quot;,&#10;		text: &quot;&lt;some_value&gt;&quot;,&#10;	},&#10;];&#10;</code></pre>
<p>Create a <code>formatRows</code> function that takes a number of rows and fields returned from the BigQuery response body and returns an array of results as objects with named fields.</p>
<pre><code class="language-javascript">const formatRows = (rowsWithoutFieldNames, fields) =&gt; {&#10;	// Index to fieldName&#10;	const fieldsByIndex = new Map();&#10;&#10;	// Load all fields by name and have their index in the array result as their key&#10;	fields.forEach((field, index) =&gt; {&#10;    	fieldsByIndex.set(index, field.name)&#10;	})&#10;&#10;	// Iterate through rows&#10;	const rowsWithFieldNames = rowsWithoutFieldNames.map(row =&gt; {&#10;    	// Per each row represented by an array f, iterate through the unnamed values and find their field names by searching them in the fieldsByIndex.&#10;    	let newRow = {}&#10;    	row.f.forEach((field, index) =&gt; {&#10;        	const fieldName = fieldsByIndex.get(index);&#10;        	if (fieldName) {&#10;		// For every field in a row, add them to newRow&#10;            	newRow = ({ ...newRow, [fieldName]: field.v });&#10;        	}&#10;    	})&#10;    	return newRow&#10;	})&#10;&#10;	return rowsWithFieldNames&#10;}&#10;&#10;export default {&#10;	async fetch(request, env, ctx) {&#10;		...&#10;    	// Transform output format into array of objects with named fields&#10;    	let formattedResults;&#10;&#10;    	if (&#x27;rows&#x27; in ticketInfo) {&#10;        	formattedResults = formatRows(ticketInfo.rows, ticketInfo.schema.fields);&#10;        	console.log(formattedResults)&#10;    	} else if (&#x27;error&#x27; in ticketInfo) {&#10;        	return new Response(ticketInfo.error.message, { status: 500 })&#10;    	}&#10;	...&#10;	},&#10;};&#10;</code></pre>
