<p>Workers AI allows you to run AI models in a serverless way, without having to worry about scaling, maintaining, or paying for unused infrastructure. You can invoke models running on GPUs on Cloudflare's network from your own code — from <a href="/workers/">Workers</a>, <a href="/pages/">Pages</a>, or anywhere via <a href="/api/resources/ai/methods/run/">the Cloudflare API</a>.</p>
<p>Workers AI gives you access to:</p>
<ul>
<li><strong>50+ <a href="/workers-ai/models/">open-source models</a></strong>, available as a part of our model catalog</li>
<li>Serverless, <strong>pay-for-what-you-use</strong> <a href="/workers-ai/platform/pricing/">pricing model</a></li>
<li>All as part of a <strong>fully-featured developer platform</strong>, including <a href="/ai-gateway/">AI Gateway</a>, <a href="/vectorize/">Vectorize</a>, <a href="/workers/">Workers</a> and more...</li>
</ul>
