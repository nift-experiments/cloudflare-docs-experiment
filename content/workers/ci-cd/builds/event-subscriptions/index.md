<p><a href="/queues/event-subscriptions/">Event subscriptions</a> allow you to receive messages when events occur across your Cloudflare account. Cloudflare products (e.g., <a href="/kv/">KV</a>, <a href="/workers-ai/">Workers AI</a>, <a href="/workers/">Workers</a>) can publish structured events to a <a href="/queues/">queue</a>, which you can then consume with Workers or <a href="/queues/configuration/pull-consumers/">HTTP pull consumers</a> to build custom workflows, integrations, or logic.</p>
<p>For more information on <a href="/queues/event-subscriptions/">Event Subscriptions</a>, refer to the <a href="/queues/event-subscriptions/manage-event-subscriptions/">management guide</a>.</p>
<h2 id="send-build-notifications">Send build notifications</h2>
<p>You can deploy a Worker that consumes build events and sends notifications to Slack, Discord, or any webhook endpoint:</p>
<p><a href="https://deploy.workers.cloudflare.com/?url=https://github.com/cloudflare/templates/tree/main/workers-builds-notifications-template"><img src="https://deploy.workers.cloudflare.com/button" alt="Deploy to Cloudflare" /></a></p>
<p>The template sends notifications for:</p>
<ul>
<li>Successful builds with preview or live deployment URLs</li>
<li>Failed builds with error messages</li>
<li>Cancelled builds</li>
</ul>
<p><img src="/assets/upstream/images/changelog/workers/builds-notifications-slack.png" alt="Example Slack notifications for Workers Builds events" /></p>
<p>You can customize the Worker to format messages for your webhook provider. For setup instructions, refer to the <a href="https://github.com/cloudflare/templates/tree/main/workers-builds-notifications-template#readme">template README</a>.</p>
