<p>You can create Workers applications from simple prompts in your favorite agent or editor, including Cursor, Windsurf, VS Code, Claude Code, Codex, and OpenCode.</p>
<h2 id="teach-your-agent-about-workers">Teach your agent about Workers</h2>
<p>Connect the <a href="https://github.com/cloudflare/mcp-server-cloudflare/tree/main/apps/docs-ai-search"><code>cloudflare-docs</code></a> MCP (Model Context Protocol) server to teach your agent about Workers. Add the server URL <code>https://docs.mcp.cloudflare.com/mcp</code> to your agent configuration (<a href="/agents/model-context-protocol/cloudflare/servers-for-cloudflare/">learn more</a>).</p>
<p>You can also connect the <a href="https://github.com/cloudflare/mcp-server-cloudflare/tree/main/apps/workers-observability"><code>cloudflare-observability</code></a> MCP server (<code>https://observability.mcp.cloudflare.com/mcp</code>). This helps your agent check logs, look for exceptions, and automatically fix issues.</p>
<h2 id="example-prompts">Example prompts</h2>
<pre tabindex="0"><code class="language-txt">Create a Cloudflare Workers application that serves as a backend API server.&#10;</code></pre>
<pre tabindex="0"><code class="language-txt">Show me how to use Hyperdrive to connect my Worker to an existing Postgres database.&#10;</code></pre>
<pre tabindex="0"><code class="language-txt">Create an AI chat Agent using the Cloudflare Agents SDK that responds to user messages and maintains conversation history.&#10;</code></pre>
<pre tabindex="0"><code class="language-txt">Build a WebSocket-based pub/sub application using Durable Objects Hibernation APIs, where the server allows me to POST to /send-message with {topic: &quot;foo&quot;, message: &quot;bar&quot;} and delivers that message to any connected client listening to that topic.&#10;</code></pre>
<pre tabindex="0"><code class="language-txt">Build an image upload application using R2 pre-signed URLs that allows users to securely upload images directly to object storage without exposing bucket credentials.&#10;</code></pre>

<h2 id="use-docs-in-your-editor">Use docs in your editor</h2>
<p>AI-enabled editors, including Cursor and Windsurf, can index documentation. Cursor includes the Cloudflare Developer Docs by default: you can use the <a href="https://cursor.com/docs/context/mentions#docs"><code>@Docs</code></a> command.</p>
<p>In other editors, such as Zed or Windsurf, you can use <code>llms-full.txt</code> files to provide comprehensive documentation context for indexing. For Workers-specific documentation indexing, use <a href="https://developers.cloudflare.com/workers/llms-full.txt"><code>https://developers.cloudflare.com/workers/llms-full.txt</code></a>. For the complete Cloudflare documentation archive, use the root level <a href="https://developers.cloudflare.com/llms-full.txt"><code>https://developers.cloudflare.com/llms-full.txt</code></a> instead.</p>
<p>You can also link an agent to <code>llms.txt</code> files while prompting to provide similar context without the need for offline indexing. For workers-specific documentation, use <a href="https://developers.cloudflare.com/workers/llms.txt"><code>https://developers.cloudflare.com/workers/llms.txt</code></a>. For context of the entire Cloudflare documentation, use the root level <a href="https://developers.cloudflare.com/llms.txt"><code>https://developers.cloudflare.com/llms.txt</code></a>.</p>
<p>The <em>Copy Page</em> button is also available on any individual page to paste that page's content directly.</p>
<p>You can combine these with the Workers system prompt on this page to improve your editor or agent's understanding of the Workers APIs.</p>
