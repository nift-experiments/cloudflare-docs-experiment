<p>Review the definitions for terms used across Cloudflare's Workers documentation.</p>
<table id="glossary-table"><thead><tr><th>Term</th><th>Definition</th></tr></thead><tbody><tr><td>Auxiliary Worker</td><td><p>A Worker created locally via the <a request.</p></td></tr><tr><td>Cron Triggers</td><td><p><a href="/workers/configuration/cron-triggers/">Cron Triggers</a> allow users to map a cron expression to a Worker using a <a Cloudflare's native serverless database.</p></td></tr><tr><td>deployment</td><td><p><a href="/workers/versions-and-deployments/#deployments">Deployments</a> track the version(s) of your Worker that storage.</p></td></tr><tr><td>duration</td><td><p><a href="/workers/platform/limits/#duration">Duration</a> is a measurement of wall-clock time — the total amount of time from the start to end of an invocation of a Worker.</p></td></tr><tr><td>environment</td><td><p><a href="/workers/wrangler/environments/">Environments</a> allow you to deploy the same Worker application with different Worker.</p></td></tr><tr><td>handler</td><td><p><a href="/workers/runtime-apis/handlers/">Handlers</a> are methods on Workers that can receive and process external inputs, and can be invoked from outside your Worker.</p></td></tr><tr><td>isolate</td><td><p><a href="/workers/reference/how-workers-works/#isolates">Isolates</a> are lightweight contexts that provide your code with variables it can hosted.</p></td></tr><tr><td>Pages</td><td><p><a href="/pages/">Cloudflare Pages</a> is Cloudflare's product offering for building and deploying full-stack
