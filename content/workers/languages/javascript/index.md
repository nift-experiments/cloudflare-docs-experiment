<p>The Workers platform is designed to be <a href="https://ecma-international.org/publications-and-standards/standards/ecma-262/">JavaScript standards compliant</a> and web-interoperable, and supports JavaScript standards, as defined by <a href="https://tc39.es/">TC39</a> (ECMAScript). Wherever possible, it uses web platform APIs, so that code can be reused across client and server, as well as across <a href="https://wintercg.org/">WinterCG</a> JavaScript runtimes.</p>
<p>Refer to <a href="/workers/runtime-apis/">Runtime APIs</a> for more information on specific JavaScript APIs available in Workers.</p>
