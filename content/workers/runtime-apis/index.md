<p>The <a href="https://blog.cloudflare.com/workerd-open-source-workers-runtime/">Workers runtime</a> is designed to be <a href="https://ecma-international.org/publications-and-standards/standards/ecma-262/">JavaScript standards compliant</a> and web-interoperable. Wherever possible, it uses web platform APIs, so that code can be reused across client and server, as well as across <a href="https://wintercg.org/">WinterCG</a> JavaScript runtimes.</p>
<p><a href="/workers/runtime-apis/">Workers runtime features</a> are <a href="/workers/runtime-apis/nodejs">compatible with a subset of Node.js APIs</a> and the ability to set a <a href="/workers/configuration/compatibility-dates/">compatibility date or compatibility flag</a>.</p>
