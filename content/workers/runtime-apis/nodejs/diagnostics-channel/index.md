<p>The <a href="https://nodejs.org/dist/latest-v20.x/docs/api/diagnostics_channel.html"><code>diagnostics_channel</code></a> module provides an API to create named channels to report arbitrary message data for diagnostics purposes. The API is essentially a simple event pub/sub model that is specifically designed to support low-overhead diagnostics reporting.</p>
<pre><code class="language-js">import {&#10;	channel,&#10;	hasSubscribers,&#10;	subscribe,&#10;	unsubscribe,&#10;	tracingChannel,&#10;} from &quot;node:diagnostics_channel&quot;;&#10;&#10;// For publishing messages to a channel, acquire a channel object:&#10;const myChannel = channel(&quot;my-channel&quot;);&#10;&#10;// Any JS value can be published to a channel.&#10;myChannel.publish({ foo: &quot;bar&quot; });&#10;&#10;// For receiving messages on a channel, use subscribe:&#10;&#10;subscribe(&quot;my-channel&quot;, (message) =&gt; {&#10;	console.log(message);&#10;});&#10;</code></pre>
<p>All <code>Channel</code> instances are singletons per each Isolate/context (for example, the same entry point). Subscribers are always invoked synchronously and in the order they were registered, much like an <code>EventTarget</code> or Node.js <code>EventEmitter</code> class.</p>
<h2 id="integration-with-tail-workers">Integration with Tail Workers</h2>
<p>When using <a href="/workers/observability/logs/tail-workers/">Tail Workers</a>, all messages published to any channel will be forwarded also to the <a href="/workers/observability/logs/tail-workers/">Tail Worker</a>. Within the Tail Worker, the diagnostic channel messages can be accessed via the <code>diagnosticsChannelEvents</code> property:</p>
<pre><code class="language-js">export default {&#10;	async tail(events) {&#10;		for (const event of events) {&#10;			for (const messageData of event.diagnosticsChannelEvents) {&#10;				console.log(&#10;					messageData.timestamp,&#10;					messageData.channel,&#10;					messageData.message,&#10;				);&#10;			}&#10;		}&#10;	},&#10;};&#10;</code></pre>
<p>Note that message published to the tail worker is passed through the <a href="https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API/Structured_clone_algorithm">structured clone algorithm</a> (same mechanism as the <a href="https://developer.mozilla.org/en-US/docs/Web/API/structuredClone"><code>structuredClone()</code></a> API) so only values that can be successfully cloned are supported.</p>
<h2 id="tracingchannel"><code>TracingChannel</code></h2>
<p>Per the Node.js documentation, &quot;<a href="https://nodejs.org/api/diagnostics_channel.html#class-tracingchannel"><code>TracingChannel</code></a> is a collection of [Channels] which together express a single traceable action. <code>TracingChannel</code> is used to formalize and simplify the process of producing events for tracing application flow.&quot;</p>
<pre><code class="language-js">import { tracingChannel } from &quot;node:diagnostics_channel&quot;;&#10;import { AsyncLocalStorage } from &quot;node:async_hooks&quot;;&#10;&#10;const channels = tracingChannel(&quot;my-channel&quot;);&#10;const requestId = new AsyncLocalStorage();&#10;channels.start.bindStore(requestId);&#10;&#10;channels.subscribe({&#10;	start(message) {&#10;		console.log(requestId.getStore()); // { requestId: &#x27;123&#x27; }&#10;		// Handle start message&#10;	},&#10;	end(message) {&#10;		console.log(requestId.getStore()); // { requestId: &#x27;123&#x27; }&#10;		// Handle end message&#10;	},&#10;	asyncStart(message) {&#10;		console.log(requestId.getStore()); // { requestId: &#x27;123&#x27; }&#10;		// Handle asyncStart message&#10;	},&#10;	asyncEnd(message) {&#10;		console.log(requestId.getStore()); // { requestId: &#x27;123&#x27; }&#10;		// Handle asyncEnd message&#10;	},&#10;	error(message) {&#10;		console.log(requestId.getStore()); // { requestId: &#x27;123&#x27; }&#10;		// Handle error message&#10;	},&#10;});&#10;&#10;// The subscriber handlers will be invoked while tracing the execution of the async&#10;// function passed into `channel.tracePromise`...&#10;channel.tracePromise(&#10;	async () =&gt; {&#10;		// Perform some asynchronous work...&#10;	},&#10;	{ requestId: &quot;123&quot; },&#10;);&#10;</code></pre>
<p>Refer to the <a href="https://nodejs.org/dist/latest-v20.x/docs/api/diagnostics_channel.html">Node.js documentation for <code>diagnostics_channel</code></a> for more information.</p>
