<p>The <a href="https://nodejs.org/api/path.html"><code>node:path</code></a> module provides utilities for working with file and directory paths. The <code>node:path</code> module can be accessed using:</p>
<pre tabindex="0"><code class="language-js">import path from &quot;node:path&quot;;&#10;path.join(&quot;/foo&quot;, &quot;bar&quot;, &quot;baz/asdf&quot;, &quot;quux&quot;, &quot;..&quot;);&#10;// Returns: &#x27;/foo/bar/baz/asdf&#x27;&#10;</code></pre>
<p>Refer to the <a href="https://nodejs.org/api/path.html">Node.js documentation for <code>path</code></a> for more information.</p>
