<p>The node:zlib module provides compression functionality implemented using Gzip, Deflate/Inflate, and Brotli.
To access it:</p>
<pre><code class="language-js">import zlib from &quot;node:zlib&quot;;&#10;</code></pre>
<p>The full <code>node:zlib</code> API is documented in the <a href="https://nodejs.org/api/zlib.html">Node.js documentation for <code>node:zlib</code></a>.</p>
