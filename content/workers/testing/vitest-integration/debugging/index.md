<p>This guide shows you how to debug your Workers tests with Vitest and <code>@cloudflare/vitest-plugin</code>.</p>
<h2 id="open-inspector-with-vitest">Open inspector with Vitest</h2>
<p>To start debugging, run Vitest with the following command and attach a debugger to port <code>9229</code>:</p>
<pre><code class="language-sh">vitest --inspect --no-file-parallelism&#10;</code></pre>
<h2 id="customize-the-inspector-port">Customize the inspector port</h2>
<p>By default, the inspector will be opened on port <code>9229</code>. If you need to use a different port (for example, <code>3456</code>), you can run the following command:</p>
<pre><code class="language-sh">vitest --inspect=3456 --no-file-parallelism&#10;</code></pre>
<p>Alternatively, you can define it in your Vitest configuration file:</p>
<pre><code class="language-ts">import { cloudflareTest } from &quot;@cloudflare/vitest-plugin&quot;;&#10;import { defineConfig } from &quot;vitest/config&quot;;&#10;&#10;export default defineConfig({&#10;	plugins: [&#10;		cloudflareTest({&#10;			// ...&#10;		}),&#10;	],&#10;	test: {&#10;		inspector: {&#10;			port: 3456,&#10;		},&#10;	},&#10;});&#10;</code></pre>
<h2 id="setup-vs-code-to-use-breakpoints">Setup VS Code to use breakpoints</h2>
<p>To setup VS Code for breakpoint debugging in your Worker tests, create a <code>.vscode/launch.json</code> file that contains the following configuration:</p>
<pre><code class="language-json">{&#10;	&quot;configurations&quot;: [&#10;		{&#10;			&quot;type&quot;: &quot;node&quot;,&#10;			&quot;request&quot;: &quot;launch&quot;,&#10;			&quot;name&quot;: &quot;Open inspector with Vitest&quot;,&#10;			&quot;program&quot;: &quot;${workspaceRoot}/node_modules/vitest/vitest.mjs&quot;,&#10;			&quot;console&quot;: &quot;integratedTerminal&quot;,&#10;			&quot;args&quot;: [&quot;--inspect=9229&quot;, &quot;--no-file-parallelism&quot;]&#10;		},&#10;		{&#10;			&quot;name&quot;: &quot;Attach to Workers Runtime&quot;,&#10;			&quot;type&quot;: &quot;node&quot;,&#10;			&quot;request&quot;: &quot;attach&quot;,&#10;			&quot;port&quot;: 9229,&#10;			&quot;cwd&quot;: &quot;/&quot;,&#10;			&quot;resolveSourceMapLocations&quot;: null,&#10;			&quot;attachExistingChildren&quot;: false,&#10;			&quot;autoAttachChildProcesses&quot;: false&#10;		}&#10;	],&#10;	&quot;compounds&quot;: [&#10;		{&#10;			&quot;name&quot;: &quot;Debug Workers tests&quot;,&#10;			&quot;configurations&quot;: [&#10;				&quot;Open inspector with Vitest&quot;,&#10;				&quot;Attach to Workers Runtime&quot;&#10;			],&#10;			&quot;stopAll&quot;: true&#10;		}&#10;	]&#10;}&#10;</code></pre>
<p>Select <strong>Debug Workers tests</strong> at the top of the <strong>Run &amp; Debug</strong> panel to open an inspector with Vitest and attach a debugger to the Workers runtime. Then you can add breakpoints to your test files and start debugging.</p>
