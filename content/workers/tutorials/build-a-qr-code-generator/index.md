<p>In this tutorial, you will build and publish a Worker application that generates QR codes.</p>
<p>If you would like to review the code for this tutorial, the final version of the codebase is <a href="https://github.com/kristianfreeman/workers-qr-code-generator">available on GitHub</a>. You can take the code provided in the example repository, customize it, and deploy it for use in your own projects.</p>
<h2 id="before-you-start">Before you start</h2>
<p>All of the tutorials assume you have already completed the <a href="/workers/get-started/guide/">Get started guide</a>, which gets you set up with a Cloudflare Workers account, <a href="https://github.com/cloudflare/workers-sdk/tree/main/packages/create-cloudflare">C3</a>, and <a href="/workers/wrangler/install-and-update/">Wrangler</a>.</p>
<h2 id="1-create-a-new-workers-project"><ol>
<li>Create a new Workers project</li>
</ol></h2>
<p>First, use the <a href="/pages/get-started/c3"><code>create-cloudflare</code> CLI</a> to create a new Cloudflare Workers project. To do this, open a terminal window and run the following command:</p>

<p>Then, move into your newly created directory:</p>
<pre tabindex="0"><code class="language-sh">cd qr-code-generator&#10;</code></pre>
<p>Inside of your new <code>qr-code-generator</code> Worker project directory, <code>index.js</code> represents the entry point to your Cloudflare Workers application.</p>
<p>All Cloudflare Workers applications start by listening for <code>fetch</code> events, which are triggered when a client makes a request to a Workers route. After a request is received by the Worker, the response your application constructs will be returned to the user. This tutorial will guide you through understanding how the request/response pattern works and how you can use it to build fully featured applications.</p>
<pre tabindex="0"><code class="language-js">export default {&#10;	async fetch(request, env, ctx) {&#10;		return new Response(&quot;Hello Worker!&quot;);&#10;	},&#10;};&#10;</code></pre>
<p>In your default <code>index.js</code> file, you can see that request/response pattern in action. The <code>fetch</code> constructs a new <code>Response</code> with the body text <code>'Hello Worker!'</code>.</p>
<p>When a Worker receives a <code>fetch</code> event, the Worker returns the newly constructed response to the client. Your Worker will serve new responses directly from <a href="https://www.cloudflare.com/network">Cloudflare's global network</a> instead of continuing to your origin server. A standard server would accept requests and return responses. Cloudflare Workers allows you to respond quickly by constructing responses directly on the Cloudflare global network.</p>
<h2 id="2-handle-incoming-request"><ol start="2">
<li>Handle Incoming Request</li>
</ol></h2>
<p>Any project you publish to Cloudflare Workers can make use of modern JavaScript tooling like ES modules, <code>npm</code> packages, and <a href="https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/async_function"><code>async</code>/<code>await</code></a> functions to build your application. In addition to writing Workers, you can use Workers to <a href="/workers/tutorials/build-a-slackbot/">build full applications</a> using the same tooling and process as in this tutorial.</p>
<p>The QR code generator you will build in this tutorial will be a Worker that runs on a single route and receives requests. Each request will contain a text message (a URL, for example), which the function will encode into a QR code. The function will then respond with the QR code in PNG image format.</p>
<p>At this point in the tutorial, your Worker function can receive requests and return a simple response with the text <code>&quot;Hello Worker!&quot;</code>. To handle data coming into your Worker, check if the incoming request is a <code>POST</code> request:</p>
<pre tabindex="0"><code class="language-js">export default {&#10;	async fetch(request, env, ctx) {&#10;		if (request.method === &quot;POST&quot;) {&#10;			return new Response(&quot;Hello Worker!&quot;);&#10;		}&#10;	},&#10;};&#10;</code></pre>
<p>Currently, if an incoming request is not a <code>POST</code>, the function will return <code>undefined</code>. However, a Worker always needs to return a <code>Response</code>. Since the function should only accept incoming <code>POST</code> requests, return a new <code>Response</code> with a <a href="https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Status/405"><code>405</code> status code</a> if the incoming request is not a <code>POST</code>:</p>
<pre tabindex="0"><code class="language-js">export default {&#10;	async fetch(request, env, ctx) {&#10;		if (request.method === &quot;POST&quot;) {&#10;			return new Response(&quot;Hello Worker!&quot;);&#10;		}&#10;&#10;		return new Response(&quot;Expected POST request&quot;, {&#10;			status: 405,&#10;		});&#10;	},&#10;};&#10;</code></pre>
<p>You have established the basic flow of the request. You will now set up a response to incoming valid requests. If a <code>POST</code> request comes in, the function should generate a QR code. To start, move the <code>&quot;Hello Worker!&quot;</code> response into a new function, <code>generateQRCode</code>, which will ultimately contain the bulk of your function’s logic:</p>
<pre tabindex="0"><code class="language-js">export default {&#10;	async fetch(request, env, ctx) {&#10;		if (request.method === &quot;POST&quot;) {&#10;		}&#10;	},&#10;};&#10;&#10;async function generateQRCode(request) {&#10;	// TODO: Include QR code generation&#10;	return new Response(&quot;Hello worker!&quot;);&#10;}&#10;</code></pre>
<p>With the <code>generateQRCode</code> function filled out, call it within <code>fetch</code> function and return its result directly to the client:</p>
<pre tabindex="0"><code class="language-js">export default {&#10;	async fetch(request, env, ctx) {&#10;		if (request.method === &quot;POST&quot;) {&#10;			return generateQRCode(request);&#10;		}&#10;	},&#10;};&#10;</code></pre>
<h2 id="3-build-a-qr-code-generator"><ol start="3">
<li>Build a QR code generator</li>
</ol></h2>
<p>All projects deployed to Cloudflare Workers support npm packages. This support makes it easy to rapidly build out functionality in your Workers. The <a href="https://github.com/papnkukn/qrcode-svg">'qrcode-svg'</a> package is a great way to take text and encode it into a QR code. In the command line, install and save 'qrcode-svg' to your project’s 'package.json':</p>
<div class="nb-package-managers" data-nb-pm><div role="tablist" aria-label="Package manager"><button type="button" role="tab" data-nb-pm-tab aria-selected="true" tabindex="0">npm</button><button type="button" role="tab" data-nb-pm-tab aria-selected="false" tabindex="-1">yarn</button><button type="button" role="tab" data-nb-pm-tab aria-selected="false" tabindex="-1">pnpm</button><button type="button" role="tab" data-nb-pm-tab aria-selected="false" tabindex="-1">bun</button></div><div role="tabpanel" data-nb-pm-panel><pre tabindex="0"><code data-nb-pm-code>npm i qrcode-svg</code></pre><button type="button" data-nb-pm-copy data-nb-command="npm i qrcode-svg" aria-label="Copy to clipboard">Copy</button></div><div role="tabpanel" data-nb-pm-panel hidden><pre tabindex="0"><code data-nb-pm-code>yarn add qrcode-svg</code></pre><button type="button" data-nb-pm-copy data-nb-command="yarn add qrcode-svg" aria-label="Copy to clipboard">Copy</button></div><div role="tabpanel" data-nb-pm-panel hidden><pre tabindex="0"><code data-nb-pm-code>pnpm add qrcode-svg</code></pre><button type="button" data-nb-pm-copy data-nb-command="pnpm add qrcode-svg" aria-label="Copy to clipboard">Copy</button></div><div role="tabpanel" data-nb-pm-panel hidden><pre tabindex="0"><code data-nb-pm-code>bun add qrcode-svg</code></pre><button type="button" data-nb-pm-copy data-nb-command="bun add qrcode-svg" aria-label="Copy to clipboard">Copy</button></div></div>
<p>In <code>index.js</code>, import the <code>qrcode-svg</code> package as the variable <code>QRCode</code>. In the <code>generateQRCode</code> function, parse the incoming request as JSON using <code>request.json</code>, and generate a new QR code using the <code>qrcode-svg</code> package. The QR code is generated as an SVG. Construct a new instance of <code>Response</code>, passing in the SVG data as the body, and a <code>Content-Type</code> header of <code>image/svg+xml</code>. This will allow browsers to properly parse the data coming back from your Worker as an image:</p>
<pre tabindex="0"><code class="language-js">import QRCode from &quot;qrcode-svg&quot;;&#10;&#10;async function generateQRCode(request) {&#10;	const { text } = await request.json();&#10;	const qr = new QRCode({ content: text || &quot;https://workers.dev&quot; });&#10;	return new Response(qr.svg(), {&#10;		headers: { &quot;Content-Type&quot;: &quot;image/svg+xml&quot; },&#10;	});&#10;}&#10;</code></pre>
<h2 id="4-test-in-an-application-ui"><ol start="4">
<li>Test in an application UI</li>
</ol></h2>
<p>The Worker will execute when a user sends a <code>POST</code> request to a route, but it is best practice to also provide a proper interface for testing the function. At this point in the tutorial, if any request is received by your function that is not a <code>POST</code>, a <code>405</code> response is returned. The new version of <code>fetch</code> should return a new <code>Response</code> with a static HTML document instead of the <code>405</code> error:</p>
<pre tabindex="0"><code class="language-js">export default {&#10;	async fetch(request, env, ctx) {&#10;		if (request.method === &quot;POST&quot;) {&#10;			return generateQRCode(request);&#10;		}&#10;&#10;		return new Response(landing, {&#10;			headers: {&#10;				&quot;Content-Type&quot;: &quot;text/html&quot;,&#10;			},&#10;		});&#10;	},&#10;};&#10;&#10;async function generateQRCode(request) {&#10;	const { text } = await request.json();&#10;	const qr = new QRCode({ content: text || &quot;https://workers.dev&quot; });&#10;	return new Response(qr.svg(), {&#10;		headers: { &quot;Content-Type&quot;: &quot;image/svg+xml&quot; },&#10;	});&#10;}&#10;&#10;const landing = `&#10;&lt;h1&gt;QR Generator&lt;/h1&gt;&#10;&lt;p&gt;Click the below button to generate a new QR code. This will make a request to your Worker.&lt;/p&gt;&#10;&lt;input type=&quot;text&quot; id=&quot;text&quot; value=&quot;https://workers.dev&quot;&gt;&lt;/input&gt;&#10;&lt;button onclick=&quot;generate()&quot;&gt;Generate QR Code&lt;/button&gt;&#10;&lt;p&gt;Generated QR Code Image&lt;/p&gt;&#10;&lt;img id=&quot;qr&quot; src=&quot;#&quot; /&gt;&#10;&lt;script&gt;&#10;	function generate() {&#10;		fetch(window.location.pathname, {&#10;			method: &quot;POST&quot;,&#10;			headers: { &quot;Content-Type&quot;: &quot;application/json&quot; },&#10;			body: JSON.stringify({ text: document.querySelector(&quot;#text&quot;).value })&#10;		})&#10;		.then(response =&gt; response.blob())&#10;		.then(blob =&gt; {&#10;			const reader = new FileReader();&#10;			reader.onloadend = function () {&#10;				document.querySelector(&quot;#qr&quot;).src = reader.result; // Update the image source with the newly generated QR code&#10;			}&#10;			reader.readAsDataURL(blob);&#10;		})&#10;	}&#10;&lt;/script&gt;&#10;`;&#10;</code></pre>
<p>The <code>landing</code> variable, which is a static HTML string, sets up an <code>input</code> tag and a corresponding <code>button</code>, which calls the <code>generateQRCode</code> function. This function will make an HTTP <code>POST</code> request back to your Worker, allowing you to see the corresponding QR code image returned on the page.</p>
<p>With the above steps complete, your Worker is ready. The full version of the code looks like this:</p>
<pre tabindex="0"><code class="language-js">const QRCode = require(&quot;qrcode-svg&quot;);&#10;&#10;export default {&#10;	async fetch(request, env, ctx) {&#10;		if (request.method === &quot;POST&quot;) {&#10;			return generateQRCode(request);&#10;		}&#10;&#10;		return new Response(landing, {&#10;			headers: {&#10;				&quot;Content-Type&quot;: &quot;text/html&quot;,&#10;			},&#10;		});&#10;	},&#10;};&#10;&#10;async function generateQRCode(request) {&#10;	const { text } = await request.json();&#10;	const qr = new QRCode({ content: text || &quot;https://workers.dev&quot; });&#10;	return new Response(qr.svg(), {&#10;		headers: { &quot;Content-Type&quot;: &quot;image/svg+xml&quot; },&#10;	});&#10;}&#10;&#10;const landing = `&#10;&lt;h1&gt;QR Generator&lt;/h1&gt;&#10;&lt;p&gt;Click the below button to generate a new QR code. This will make a request to your Worker.&lt;/p&gt;&#10;&lt;input type=&quot;text&quot; id=&quot;text&quot; value=&quot;https://workers.dev&quot;&gt;&lt;/input&gt;&#10;&lt;button onclick=&quot;generate()&quot;&gt;Generate QR Code&lt;/button&gt;&#10;&lt;p&gt;Generated QR Code Image&lt;/p&gt;&#10;&lt;img id=&quot;qr&quot; src=&quot;#&quot; /&gt;&#10;&lt;script&gt;&#10;	function generate() {&#10;		fetch(window.location.pathname, {&#10;			method: &quot;POST&quot;,&#10;			headers: { &quot;Content-Type&quot;: &quot;application/json&quot; },&#10;			body: JSON.stringify({ text: document.querySelector(&quot;#text&quot;).value })&#10;		})&#10;		.then(response =&gt; response.blob())&#10;		.then(blob =&gt; {&#10;			const reader = new FileReader();&#10;			reader.onloadend = function () {&#10;				document.querySelector(&quot;#qr&quot;).src = reader.result; // Update the image source with the newly generated QR code&#10;			}&#10;			reader.readAsDataURL(blob);&#10;		})&#10;	}&#10;&lt;/script&gt;&#10;`;&#10;</code></pre>
