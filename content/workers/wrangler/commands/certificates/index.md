<p>Use these commands to manage certificates for mTLS connections.</p>
<p>The <code>mtls-certificate</code> commands manage client certificates for Worker subrequests. The <code>cert</code> commands manage both mTLS client certificates and Certificate Authority (CA) chain certificates, primarily for use with <a href="/workers/wrangler/commands/hyperdrive/">Hyperdrive</a> configurations.</p>
<hr />
<h2 id="mtls-certificate"><code>mtls-certificate</code></h2>
<p>Manage client certificates used for mTLS connections in subrequests.</p>
<p>These certificates can be used in <a href="/workers/runtime-apis/bindings/mtls"><code>mtls_certificate</code> bindings</a>, which allow a Worker to present the certificate when establishing a connection with an origin that requires client authentication (mTLS).</p>
