</li><li><code>--connection-string</code> <small>string</small><p>The connection string for the database you want Hyperdrive to connect to - ex: protocol://user:password@host:port/database</p>
</li><li><code>--service-id</code> <small>string</small><p>The Workers VPC Service ID of the origin database</p>
</li><li><code>--origin-host</code> <small>string</small><p>The host of the origin database</p>
</li><li><code>--origin-port</code> <small>number</small><p>The port number of the origin database</p>
</li><li><code>--origin-scheme</code> <small>string, default: postgresql</small><p>The scheme used to connect to the origin database</p>
</li><li><code>--database</code> <small>string</small><p>The name of the database within the origin database</p>
</li><li><code>--origin-user</code> <small>string</small><p>The username used to connect to the origin database</p>
</li><li><code>--origin-password</code> <small>string</small><p>The password used to connect to the origin database</p>
</li><li><code>--access-client-id</code> <small>string</small><p>The Client ID of the Access token to use when connecting to the origin database</p>
</li><li><code>--access-client-secret</code> <small>string</small><p>The Client Secret of the Access token to use when connecting to the origin database</p>
</li><li><code>--caching-disabled</code> <small>boolean</small><p>Disables the caching of SQL responses</p>
</li><li><code>--max-age</code> <small>number</small><p>Specifies max duration for which items should persist in the cache, cannot be set when caching is disabled</p>
</li><li><code>--swr</code> <small>number</small><p>Indicates the number of seconds cache may serve the response after it becomes stale, cannot be set when caching is disabled</p>
</li><li><code>--ca-certificate-id</code> <small>string</small><p>Sets custom CA certificate when connecting to origin database. Must be valid UUID of already uploaded CA certificate.</p>
</li><li><code>--mtls-certificate-id</code> <small>string</small><p>Sets custom mTLS client certificates when connecting to origin database. Must be valid UUID of already uploaded public/private key certificates.</p>
</li><li><code>--sslmode</code> <small>string</small><p>Sets sslmode for connecting to database. For PostgreSQL: 'require, verify-ca, verify-full'. For MySQL: 'REQUIRED, VERIFY_CA, VERIFY_IDENTITY'.</p>
</li><li><code>--origin-connection-limit</code> <small>number</small><p>The (soft) maximum number of connections that Hyperdrive may establish to the origin database</p>
</li><li><code>--binding</code> <small>string</small><p>The binding name of this resource in your Worker</p>
</li><li><code>--update-config</code> <small>boolean</small><p>Automatically update your config file with the newly added resource</p>
