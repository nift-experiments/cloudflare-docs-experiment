<p class="article-summary">Send invoice when shopping cart is checked out and paid for</p>
<p>In this example, we implement a Workflow for an e-commerce website that is triggered every time a shopping cart is created.</p>
<p>Once a Workflow instance is triggered, it starts polling a <a href="/d1">D1</a> database for the cart ID until it has been checked out. Once the shopping cart is checked out, we proceed to process the payment with an external provider doing a fetch POST. Finally, assuming everything goes well, we try to send an email using <a href="/email-service/api/route-emails/email-handler/">Email Workers</a> with the invoice to the customer.</p>
<p>As you can see, Workflows handles all the different service responses and failures; it will retry D1 until the cart is checked out, retry the payment processor if it fails for some reason, and retry sending the email with the invoice if it can't. The developer doesn't have to care about any of that logic, and the workflow can run for hours, handling all the possible conditions until it is completed.</p>
<p>This is a simplified example of processing a shopping cart. We would assume more steps and additional logic in a real-life scenario, but this example gives you a good idea of what you can do with Workflows.</p>
<pre><code class="language-ts">import {&#10;	WorkflowEntrypoint,&#10;	WorkflowStep,&#10;	WorkflowEvent,&#10;} from &quot;cloudflare:workers&quot;;&#10;import { EmailMessage } from &quot;cloudflare:email&quot;;&#10;import { createMimeMessage } from &quot;mimetext&quot;;&#10;&#10;// We are using Email Routing to send emails out and D1 for our cart database&#10;type Env = {&#10;	CART_WORKFLOW: Workflow;&#10;	SEND_EMAIL: any;&#10;	DB: any;&#10;};&#10;&#10;// Workflow parameters: we expect a cartId&#10;type Params = {&#10;	cartId: string;&#10;};&#10;&#10;// Adjust this to your Cloudflare zone using Email Routing&#10;const merchantEmail = &quot;merchant@example.com&quot;;&#10;&#10;// Uses mimetext npm to generate Email&#10;const genEmail = (email: string, amount: number) =&gt; {&#10;	const msg = createMimeMessage();&#10;	msg.setSender({ name: &quot;Pet shop&quot;, addr: merchantEmail });&#10;	msg.setRecipient(email);&#10;	msg.setSubject(&quot;You invoice&quot;);&#10;	msg.addMessage({&#10;		contentType: &quot;text/plain&quot;,&#10;		data: `Your invoice for ${amount} has been paid. Your products will be shipped shortly.`,&#10;	});&#10;&#10;	return new EmailMessage(merchantEmail, email, msg.asRaw());&#10;};&#10;&#10;// Workflow logic&#10;export class cartInvoicesWorkflow extends WorkflowEntrypoint&lt;Env, Params&gt;
