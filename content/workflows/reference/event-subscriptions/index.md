<p><a href="/queues/event-subscriptions/">Event subscriptions</a> allow you to receive messages when events occur across your Cloudflare account. Cloudflare products (e.g., <a href="/kv/">KV</a>, <a href="/workers-ai/">Workers AI</a>, <a href="/workers/">Workers</a>) can publish structured events to a <a href="/queues/">queue</a>, which you can then consume with Workers or <a href="/queues/configuration/pull-consumers/">HTTP pull consumers</a> to build custom workflows, integrations, or logic.</p>
<p>For more information on <a href="/queues/event-subscriptions/">Event Subscriptions</a>, refer to the <a href="/queues/event-subscriptions/manage-event-subscriptions/">management guide</a>.</p>
<h2 id="available-workflows-events">Available Workflows events</h2>
<h4 id="instance-queued"><code>instance.queued</code></h4>

<p><strong>Example:</strong></p>
<pre><code class="language-json">{&#10;  &quot;type&quot;: &quot;cf.workflows.workflow.instance.queued&quot;,&#10;  &quot;source&quot;: {&#10;    &quot;type&quot;: &quot;workflows.workflow&quot;,&#10;    &quot;workflowName&quot;: &quot;my-workflow&quot;&#10;  },&#10;  &quot;payload&quot;: {&#10;    &quot;versionId&quot;: &quot;v1&quot;,&#10;    &quot;instanceId&quot;: &quot;inst-12345678-90ab-cdef-1234-567890abcdef&quot;&#10;  },&#10;  &quot;metadata&quot;: {&#10;    &quot;accountId&quot;: &quot;f9f79265f388666de8122cfb508d7776&quot;,&#10;    &quot;eventSubscriptionId&quot;: &quot;1830c4bb612e43c3af7f4cada31fbf3f&quot;,&#10;    &quot;eventSchemaVersion&quot;: 1,&#10;    &quot;eventTimestamp&quot;: &quot;2025-05-01T02:48:57.132Z&quot;&#10;  }&#10;}&#10;</code></pre>
