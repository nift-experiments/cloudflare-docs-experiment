<p>Review the definitions for terms used across Cloudflare's Workflows documentation.</p>
<table id="glossary-table"><thead><tr><th>Term</th><th>Definition</th></tr></thead><tbody><tr><td>Durable Execution</td><td><p>&quot;Durable Execution&quot; is a programming model that allows applications to execute reliably, automatically persist state, retry, and be resistant to errors caused by API, network or even machine/infrastructure failures. Cloudflare Workflows provide a way to build and deploy applications that align with this model.</p></td></tr><tr><td>Event</td><td><p>The event that triggered the Workflow instance. A <code>WorkflowEvent</code> may contain optional parameters (data) that a Workflow can operate on.</p></td></tr><tr><td>instance</td><td><p>A specific instance (running, paused, errored) of a Workflow. A Workflow can have a potentially infinite number of instances.</p></td></tr><tr><td>step</td><td><p>A step is self-contained, individually retryable component of a Workflow. Steps may emit (optional) state that allows a Workflow to persist and continue from that step, even if a Workflow fails due to a network or infrastructure issue. A Workflow can have one or more steps up to the <a href="/workflows/reference/limits/">step limit</a>.</p></td></tr><tr><td>Workflow</td><td><p>The named Workflow definition, associated with a single Workers script.</p></td></tr></tbody></table>
