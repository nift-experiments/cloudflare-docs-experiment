<p>Tools on Zaraz must have actions configured in order to do something. Often, using Automatic Actions is enough for configuring a tool. But you might want to use Custom Actions to create a more customized setup, or perhaps you are using a tool that does not support Automatic Actions. In these cases, you will need to configure Custom Actions manually.</p>
<p>Every action has firing triggers assigned to it. When the conditions of the firing triggers are met, the action will start. An action can be anything the tool can do - sending analytics information, showing a widget, adding a script and much more.</p>
<p>To start using actions, first <a href="/zaraz/custom-actions/create-trigger/">create a trigger</a> to determine when this action will start. If you have already set up a trigger, or if you are using one of the built-in triggers, follow these steps to <a href="/zaraz/custom-actions/create-action/">create an action</a>.</p>
