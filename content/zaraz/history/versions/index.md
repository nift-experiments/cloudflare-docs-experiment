<p>Version History enables you to keep track of all the Zaraz configuration changes made in your website. With Version History you can also revert changes to previous settings should there be a problem.</p>
<p>To access Version History you need to enable <a href="/zaraz/history/preview-mode/">Preview &amp; Publish mode</a> first. Then, you can access Version History under <strong>Zaraz</strong> &gt; <strong>History</strong>.</p>
<h2 id="access-version-history">Access Version History</h2>
<ol>
<li>In the Cloudflare dashboard, go to the <strong>History</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
3. If this is your first time using this feature, this page will be empty. Otherwise, you will have a list of changes made to your account with the following information:
   * Date of change
   * User who made the change
   * Description of the change
<h2 id="revert-changes">Revert changes</h2>
<p>Version History enables you to revert any changes made to your Zaraz settings.</p>
<ol>
<li>In the Cloudflare dashboard, go to the <strong>History</strong> page.</li>
</ol>
<div class="nb-dash-button"></div>
2. Find the changes you want to revert, and select **Restore**.
3. Confirm you want to revert your changes.
4. Select **Publish** to publish your changes.
