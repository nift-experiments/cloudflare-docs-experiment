<p>Zaraz is available to all Cloudflare users, across all tiers. Each month, every Cloudflare account gets 1,000,000 free Zaraz Events. For additional usage, the Zaraz Paid plan costs $5 per month for each additional 1,000,000 Zaraz Events.</p>
<p>All Zaraz features and tools are always available on all accounts. Learn more about our pricing in <a href="https://blog.cloudflare.com/zaraz-announces-new-pricing">the following pricing announcement</a></p>
<h2 id="the-zaraz-event-unit">The Zaraz Event unit</h2>
<p>One Zaraz Event is an event you are sending to Zaraz, whether that is a page view, a <code>zaraz.track</code> event, or similar. You can easily see the total number of Zaraz Events you are currently using on the <strong>Monitoring</strong> page of the Cloudflare dashboard:</p>
