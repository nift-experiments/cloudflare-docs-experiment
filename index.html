Cloudflare Developer Docs

Last updated Sep 18, 2026  |  Copy as Markdown  |  View as Markdown  |  Agent setup

This CP2 shell is the design-system reference surface for the Nift port. Bulk Cloudflare content is intentionally deferred until the content-model checkpoints.

Design system

The shell now uses the frozen upstream Nimbus colour, typography, layout and theme tokens rather than an approximate visual palette.

Geometry

The 56px sticky header, 18.75rem sidebar, 18rem table of contents and 43.5rem article width mirror the upstream documentation layout.

Theme

The theme bootstrap follows the upstream ui-mode preference contract and supports light, dark and automatic system modes before paint.
